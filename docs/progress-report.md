# Отчёт о графовой памяти кодового агента

Добрый день! После прошлого отчёта проверил, какую историю изменений стоит хранить, помогает ли она агенту выбрать следующий файл и сколько стоит точное обновление памяти в SQLite.

- **Какие связи сохранять.** На независимой выборке из 880 многофайловых правок в шести проектах раскрывали один изменённый файл и по истории Git предсказывали остальные. По восьми рекомендациям частота файлов дала 29,58% Recall@8, связи за последние 32 коммита — 34,75%, вся доступная история связей открытого файла — 48,83%. Если брать только восемь прошлых событий этого файла, получилось 48,14% при снижении среднего числа учитываемых событий с 9,55 до 4,90. [Результаты](../experiments/graph_memory_round55/cochange/continuation/REPORT_RU.md)
- **Перенос на задачи программирования.** На 54 задачах Agent Retrieval Bench подтверждение кандидата прошлыми совместными правками повысило Recall@5 с 48,92% до 50,46% при пяти новых чтениях. Выигрыш пришёлся на две задачи. В исходном режиме авторов уже известный файл занимает одну из позиций, и результат снизился с 43,36% до 41,20%. На исполняемых тестах ClassEval Qwen3-4B с графовым и текстовым поиском прошла тесты одних и тех же 43 из 61 методов при лимите 768 выходных токенов. [Поиск файлов](../experiments/graph_memory_round55/benchmark_history/REPORT_RU.md) · [Исполняемые тесты](../experiments/graph_memory_round54/execution/REPORT_RU.md)
- **Стоимость для БД.** На 3 023 обновлениях графа все варианты точно сохранили восемь лучших файлов и их оценки. При одинаковых 72 байтах полезных данных кеша сохранение границы рейтинга вернуло меньше строк (848 против 888), но потребовало больше обращений к индексу (308 против 214). [Измерения SQLite](../experiments/graph_memory_round55/cochange/physical/REPORT_RU.md)

Для ICDE подготовлены четырёхстраничная рукопись, работающая демонстрация и новое видео. Наиболее перспективный результат — компактная история для каждого уже открытого файла. Её преимущество над общим коротким окном воспроизвелось; устойчивое превосходство над SOTA по качеству решения задач пока не установлено.
