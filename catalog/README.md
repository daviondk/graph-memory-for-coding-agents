## Загрузка и проверка

Из клона репозитория выполните:

```sh
python tools/records.py list
python tools/records.py get graph-memory-round6-records.zip --directory downloads --crc
python tools/records.py verify graph-memory-round6-records.zip --directory downloads --crc
```

Для загрузки используется GitHub CLI с учётной записью, имеющей доступ; после ручной загрузки достаточно команды `verify` и стандартного Python. Режим без имён обрабатывает все 18 файлов релиза. Хеши и размеры — в [release-assets.json](release-assets.json) и [archived-evidence-sha256.txt](archived-evidence-sha256.txt). В [archive-members.jsonl.gz](archive-members.jsonl.gz) перечислены 34 286 элементов опубликованных исторических ZIP, для каждого указаны контейнер, путь, число байтов и CRC-32 опубликованной копии. У дополнительного архива свой внутренний `SHA256.json`.

Для повтора отдельной серии распакуйте именно её архив в отдельный каталог и следуйте вложенному README или REPRODUCE. Формат старых архивов различается: часть начинается с каталогов опытов, поздние серии сохраняют дерево `work/...`. Общие директории с разными ревизиями кода не следует смешивать. В источниках сохранились пути и особенности старого Windows/WSL-окружения. Табличные метрики и журналы можно исследовать без модели; для нового инференса потребуются соответствующие веса, среда и тестовые данные.

## Источники для повторения

В каталоге первичных данных записаны прямые ссылки, ревизии и контрольные суммы для девяти наборов или компонентов. Для 46 задач SymPy указаны SHA базового коммита и SHA-256 скачанного архива. В двух вариантах Parquet различаются хеши файлов. Для каждой из этих 46 задач независимо сравнены постановка, патч, тестовый патч, списки тестов, версия и идентификаторы. Все девять полей совпали у каждой задачи. В файле с полным перечнем квитанций сохранено имя поля, из которого взята ссылка. [Основные данные](primary-inputs.json) · [Все квитанции](source-pins.json)

## Опубликованные версии исходных логов

В поисковых метаданных обзора и в шести исходных и производных файлах CompactBench удалены временные параметры подписанных URL. В двух шардах публичного корпуса SWE-smith и в одном контексте LongMemEval удалены фрагменты ключей, встречавшиеся в сторонних данных. Число записей сохранилось. Для повторения опытов с исходными входами доступны опубликованные ревизии и хеши. В R5 сторонний архив CrossCodeEval заменён внутри ZIP на файл с окончанием `.source.json`. Он содержит ссылку, SHA-256 и размер оригинала. Для повторения R5 скачайте данные по этому адресу, проверьте SHA-256 и положите файл рядом, удалив суффикс `.source.json` из имени назначения. [SWE-smith](https://huggingface.co/datasets/SWE-bench/SWE-smith-trajectories/tree/08e109b4a59eaeebf80e4675cd125d42e7ac99a4) · [Первичные входы](primary-inputs.json)

Архивы содержат исторические протоколы и файлы фиксации, характеризующие исходные байты. Для проверки распространяемых версий используйте каталог релиза. В разделе `publication_changes` указаны оригинальные и новые хеши каждого изменённого файла, включая служебные манифесты. Десять из четырнадцати исторических ZIP побайтово совпадают с оригиналами. [Манифест релиза](release-assets.json) · [Проверка архива](publication-verification.json)
