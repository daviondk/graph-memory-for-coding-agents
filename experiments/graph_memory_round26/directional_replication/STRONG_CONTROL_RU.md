# Последующая проверка сильного одностороннего контроля

Основной результат both/right уже получен. На новом срезе при лимите 256 по общей доле успехов сильнейшим из замороженных односторонних вариантов оказался ранее определённый критерий adaptive, выбирающий левый или правый край по лексике видимого текста. Поэтому сравним с ним both при точно одинаковом фактическом расходе на каждом вопросе. Зафиксированные компонента, выбор стороны и обе реальные строки сохраняются, используем ту же симметричную процедуру переразметки бюджета. Из 5 304 агрегированных исходов выбирался сильнейший контроль. Это постфактум вторичное сравнение, а не дополнительная априорная проверка. Печатаем числе выигрышей/потерь, 95% ДИ по статье и p знакопеременного теста. Отдельно разбираем, сколько первичных выигрышей требует информации слева и сколько потерь приходится на укороченную правую сторону. Этот разбор использует gold только после фиксации всех адресов.
