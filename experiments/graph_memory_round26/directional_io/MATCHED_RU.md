# Разделение цены SQL и размера окна токенизатора

Первый онлайн-опыт передавал токенизатору разные начальные окна для полного поля и локальной выборки. Дополняем после просмотра его результатов парным контролем. В новой паре на обоих плечах выполняется одна и та же функция выбора и ретокенизации с начальным окном 2 048 символов, одним и тем же anchor и двумя заголовками. На одном плече SQLite отдаёт нужные два диапазона, на другом одна SQL-команда передаёт полный текст, после чего ровно те же диапазоны нарезает Python. Порядок рандомизирован, девять повторов для каждой из 288 заявок, кластеры по 215 полям. Байты, времена и проверка совпадения всех возвращённых строк публикуются отдельно.
