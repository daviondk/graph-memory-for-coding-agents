# Направление чтения и конечный ответ на SQuAD v1.1

Зафиксированы до расчёта ответов все 576 ранее выбранных вопросов из 48 статей официальной dev-выборки (12 по SHA256 на каждую статью). R25 уже оценил доступность эталонных координат на этих примерах. Это знакомая выборка и новая проверка способа использования памяти. Никакого обучения, обращения к train или отбора по исходам и типам вопроса в этом прогоне.

Четыре фактических контекста. Общая база сохраняет исполнившиеся в R25 координаты начальной памяти. Далее сравниваем продолжение вправо, чтение с обеих сторон и адаптивный выбор одной стороны по числу совпавших терминов на границах. Все варианты берут адреса из запечатанных артефактов R25, абзац-источник вопроса ридеру не известен. Сериализация открытий сохраняет адрес начальной точки операции, для левой стороны это правая граница возвращаемого фрагмента. Считаем каждый адресный заголовок, каждую переданную часть. Сначала берём полный платный ответ R25 ≤256 uncased WP, затем обрезаем со стороны, дальней от якоря. Для двустороннего ответа делим допустимый бюджет примерно поровну; доли не перераспределяем при достижении границы. Ищем максимальную общую достижимую длину в **нативных cased WordPiece** для всех трёх политик при лимите 256 этих токенов. Нулевой слот допустим. Фактические исходные uncased токены показываем отдельно. Размер базовой памяти идентичен для каждого вопроса; для чистой базы добавочная стоимость нулевая.

Reader получает вопрос и сериализацию фрагментов памяти полностью, со служебными координатами. Скользящие окна общей длиной до 384 нативных токенов, включая вопрос и специальные токены, перекрытие контекста 128 токенов. Ответ — не более 30 последовательных токенов, оба конца и все символы находятся внутри одного непрерывно доставленного фрагмента текста, координаты/вопрос исключены. Из всех окон берём максимум суммы начального и конечного логита; разрешение равенства — по порядку окон, затем по более раннему началу и концу. Веса и алгоритм фиксированы. Байт-идентичные входы модели на уровне окна кэшируем; источник и семантика ответа восстанавливаются из конкретного предъявленного контекста. Отчёт измеряет уникальные физические вычисления и логические токены для каждого режима.

Главные парные сравнения Answer F1 — обе стороны минус правая и обе стороны минус адаптивная. EM и адаптивная минус правая — дополнительные. Официальный max over gold references по нормализованным Exact Match и F1, 20 000 парных bootstrap-выборок по 48 статьям с seed 260731, 95% интервалы и 97,5% интервалы для индивидуальных двух главных контрастов. Источник читаем только по ID и координатам R25, запись ответов запечатываем до оценки. Помимо QA считаем наличие хотя бы одного полного размеченного span и долю случаев, где конкретный выбранный span попал в размеченные координаты. Основное сравнение с обычным чтением и с адаптивным правилом проводится на всех 576. Абсолютный балл опубликованного DistilBERT на исходном размеченном абзаце относится к другой постановке.
