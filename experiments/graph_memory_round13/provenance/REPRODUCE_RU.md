# Воспроизведение R13/provenance

Для чтения отчёта и численных таблиц достаточно файлов этого каталога. Локальная проверка чисел из сохранённых артефактов выполняется стандартным Python 3 командой python verify_standalone.py. Она проверяет данные реальной и внешней панелей, целостность управляемых пар, количества рисковых запросов, основные risk–coverage кривые и локальные замки; Git, NumPy и исходные публичные датасеты для неё не нужны. Полные SHA-256 всех переносимых записей перечислены в MANIFEST_SHA256.json. Файл не включает собственный хеш.

Для пересбора прогнозов нужны Python 3.12 и NumPy, исполняемый git, архивы публичных траекторий VibeMemBench и локальные объекты замороженного R12/negative_external. Ожидаемые пути взяты из оригинальных extract.py и objects.py той серии. В forecast_lock.json перечислены отдельные имена, SHA исходных траекторий и скрипты. Архив признаков не содержит полных текстов всех исходных сообщений и blob, поэтому измерения на другом компьютере требуют получения исходных объектов. Подробности расположения зеркал даны в REPRODUCE_RU.md серии R12/negative_external. Рабочая копия репозитория не проверяется и произвольные прежние команды не исполняются: выполняется только чтение списка Git-объектов, их содержимого и нативный поиск по фиксированным строкам. Источники R11/negative_actions требуются только для external/.

    python forecast13.py
    python grade13.py
    python twins.py
    python root_analysis.py
    python scope_diagnostic.py
    python prefixcost.py
    python external/external13.py predict
    python external/external13.py grade
    python verify_standalone.py

Для перепроверки источников и того, что все использованные свидетельства доступны до текущего наблюдения, можно запустить python audit_prefix.py при наличии публичных входных логов и каталога R12. Метрические таблицы results.json и external/results.json включают условные перестановки и 10 000 кластерных bootstrap с фиксированным seed. При отсутствии сохранений или ошибок в целой панели часть статистических заключений принципиально неидентифицируема.

В состав поставки входят журнал объектных операций, SHA и длины, полные признаки и сохранённые решения на уровне каждого наблюдения, три повторных нативных поиска, подписи контролируемых текстовых деревьев и коды возврата. Индивидуальные длительности и общий пакет могут отличаться при повторении на другом компьютере. Параметры 5 предыдущих вызовов и 3 совпадения по 32 символа исследовательские. Отчёт явно помечает анализ корней и типа области как появившийся после просмотра меток.
