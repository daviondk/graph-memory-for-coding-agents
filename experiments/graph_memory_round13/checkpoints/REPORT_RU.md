# Что осталось в рабочем дереве после официальной сдачи

**Один правильный патч существовал в рабочей копии, хотя агент его не сдал.** В эпизоде flake8-comprehensions с памятью в форме исходных фрагментов BM25 последний снимок (2721 Б) прошёл целевой тест и все 102 регрессионных у оригинального оценщика. Официальная строка сдачи была пустой. Напротив, извлечённый патч mpmath с графовой памятью (487 Б) не прошёл целевой тест, все 11 регрессионных сохранились. Это различие между наличием правки и её функциональной корректностью. [Официальные логи обоих вмешательств](grading/REPORT_RU.md)

Идея изучить незавершённое рабочее состояние возникла после первых двух пустых сдач. Они исключены. Для остававшихся четырёх эпизодов правило выбора последнего снимка было зафиксировано до его оценки. В одном из четырёх наблюдатель подключился посреди эпизода. Собраны 236 наблюдений, 10 различных состояний, суммарно 5083 байта сжатых уникальных патчей. Последний снимок взят за 0,69–5,60 с до зарегистрированного окончания родительского запуска. Наблюдатель запрашивал tracked diff относительно HEAD и не видел неотслеживаемые файлы. Он не отправлял сведения решателю. [Назначение](assignment.json) · [Наблюдения](events.jsonl) · [Запечатанный выбор](selection.json)

Для четырёх наблюдавшихся эпизодов счёт официально поданных решений равен **0/4**, оценка последних рабочих снимков дала **1/4**. Единица здесь — запуск; уникальных задач всего две. Из четырёх финальных снимков два побайтно совпали с соответствующей официальной сдачей. Для остальных двух действительно запустили исходный нативный оценщик. Простой автоматический экспорт tracked diff перед уничтожением контейнера остаётся сильным инженерным контролем. Преимущество частого сохранения истории относительно однократного экспорта и вклад графа в этот результат не установлены. [Индивидуальные исходы](grading/results.json) · [Протокол](PROTOCOL_RU.md)
