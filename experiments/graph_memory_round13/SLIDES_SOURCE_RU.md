# Источник темы на фотографиях ICDM

На третьей фотографии явно указан MemOS 1.0. В полном техническом отчёте Zhiyu Li и соавторов описаны слои plaintext, activation и parametric memory и механизмы управления памятью. Для цитирования архитектуры подходит «MemOS: A Memory OS for AI System». В более ранней короткой работе авторы вводят идею операционной системы памяти. На первых двух снимках видны общие схемы о триггерах retrieval и обновлении памяти. Эти слайды не содержат названия отдельной статьи или списка авторов. [Полный отчёт](https://arxiv.org/abs/2507.03724) · [Короткая работа](https://arxiv.org/abs/2505.22101)

В программе пленарных выступлений ICDM доклад в соответствующий день закреплён за My T. Thai, его тема — исследование внутренних механизмов foundation models. В программе tutorial в тот же день участвовали Haofen Wang и Meng Wang из Tongji University. В биографии Haofen Wang указана memory engineering, он также входит в состав авторов MemOS. Сами фотографии и названия в расписании недостаточны, чтобы уверенно приписать ему показанный комплект слайдов. В качестве отдельного первичного источника по этой теме доступно описание его лекции «Memory Engineering: Building Agent Memory Systems» в другой школе.
