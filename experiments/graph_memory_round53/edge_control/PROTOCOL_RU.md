# Равное число кандидатов для истинных ссылок и видимых текстовых совпадений

Фиксируем анализ до расчёта новых баллов и исходов. Сохраняем прежний вопрос, первый документ, 192-токенный предел, базовую адресацию и фиксированную ветвь прямого выбора (DF ≤ 59). Ранее опубликованные агрегаты прежних методов на обеих панелях известны. При проверке формата входа до регистрации отображалась одна строка с двумя эталонными заголовками 2Wiki; строка осталась в полном наборе. Все новые процедуры предсказания, включая обучение, не читают файлов с эталонными опорами. Панели анализа: HotpotQA validation 1 280 и независимая от обучения выборка 2Wiki train 12 000 из R52; основной исход — полное покрытие эталонных заголовков каждой фактически прочитанной парой.

Обозначим H разрешённые истинные адреса, L буквальные вхождения полного заголовка, K=min(|H|, |L|), исключая уже прочитанную страницу. Без срабатывания прямой ветви и при K=0 оба метода выбирают одинаковый прежний базовый адрес. При K>0 каждый получает ровно K кандидатов. Основное сравнение: для обоих источников ранжируем кандидатов суммой трёх обратных рангов с нумерацией от нуля: 1/(1+min(r_BM25,4)) + 1/(1+r_first) + 1/(1+r_width). При равенствах ранга позиции или длины используем competition rank. r_first упорядочивает по самому раннему началу в видимом тексте; r_width — по убыванию длины этого вхождения в токенах. Для href используются наблюдаемые анкоры, для literal — наблюдаемое целое название. На границе K разрешаем равенства ключом исходного BM25, page ID и Row ID. Среди K оставшихся выбираем исходным BM25 по вопросу и уже прочитанному тексту.

Вторичные контроли: (1) взять топ-K по BM25 и им же выбрать итоговый адрес — при K>0 победитель равен лидеру исходного множества; (2) точное среднее по всем равновероятным K-подмножествам, для каждого оставляем лучший BM25; (3) текстовый предиктор вероятности ссылки без аннотаций задачи. Для последнего фиксируем логистическую регрессию C=1 на буквальных кандидатах старого 2Wiki dev, метка — адрес есть среди наблюдаемых href. Признаки ограничены позицией, длиной видимого названия, частотой его вхождений, BM25 и обратным рангом. Вес каждого вопроса равен единице. Параметры не подбираем, условные вероятности используем только для упорядочивания буквальных кандидатов, итоговый выбор снова BM25. Сравниваем этот ресурсно усиленный контроль с основным href. Также сохраняем исходные неодинаковые по размеру политики R52.

Показываем все вопросы, подгруппу fallback c K>0, размеры исходных множеств и их пересечения, выигрыши/потери, средний recall. ДИ из 10 000 парных bootstrap-повторов кластеров по фактическому первому адресу (seed 530223); дополнительные интервалы номинальные. Случайный контроль оценивает математическое ожидание внутри вопроса. Одинаковое число кандидатов не означает одинакового состава или новых источников доказательств. Конечные ответы не генерируются.
