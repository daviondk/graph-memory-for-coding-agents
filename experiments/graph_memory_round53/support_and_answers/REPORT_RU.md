# Когда найденная опора меняет оценку ответа

На архивных токенных входах и ответах R52 сопоставлены две величины на одном вопросе: изменение полного покрытия эталонных заголовков и изменение официального Answer F1. Это ретроспективное разложение уже известного эффекта по наблюдаемым случаям. Заранее опубликованное первичное сравнение и модель остаются описаны в [исходном эксперименте](../../graph_memory_round52/global_answers/confirm/supplement/REPORT_RU.md).

При фиксированном обученном переключателе и попарно выровненном количестве токенов на 512 вопросах переход по истинной ссылке восстановил последнюю недостающую опору в 48 случаях. **В 19 из них ответ Qwen улучшился, в 28 сохранился тот же F1, в одном F1 снизился.** У одного другого вопроса исчезло полное покрытие и F1 снизился. На оставшихся 463 вопросах статус полного покрытия сохранился; F1 вырос в шести и снизился в 11 случаях. В 308 из 512 случаев обе политики передали абсолютно одинаковые токены.

| Набор и сравнение | Изменение Answer F1, п.п. | Вклад вопросов с потерей полного покрытия | Вклад при неизменном покрытии | Вклад вопросов с приобретённым полным покрытием |
|---|---:|---:|---:|---:|
| 2Wiki dev, 384, ссылка против буквального совпадения | +1,434 | −0,521 | +0,137 | +1,818 |
| 2Wiki, 512, фиксированное правило, четыре плеча | +2,610 | −0,084 | +0,071 | +2,622 |
| Те же 512, обученное правило, попарный бюджет | +2,566 | −0,084 | +0,027 | +2,622 |
| HotpotQA, 1 280, маленький каталог, переранжировщик с признаком связи против модели без него | +0,531 | −0,658 | +0,152 | +1,036 |
| 2Wiki, 1 280, тот же переранжировщик | −0,120 | −0,112 | −0,382 | +0,373 |

Каждый вклад равен сумме индивидуальных разностей F1 в группе, делённой на число вопросов всей панели, поэтому три столбца дают общий эффект до округления. Для трёх вкладов в дополнительной паре 512 групповой 95% bootstrap дал соответственно [−0,252; 0,000], [−0,798; 0,916] и [1,325; 4,068] п.п. Единица перевыборки — общий первый документ. Группы определены по результату retrieval, а полное покрытие говорит только о названиях документов. Причинный вклад текста, заголовка и знаний модели из этой таблицы по отдельности вывести нельзя.

`python -B analyze.py` повторяет разложение на всех пяти панелях из сохранённых R52 данных; требуется NumPy. В [строках](rows.json.gz) для каждого вопроса сохранены пара адресов, разность покрытия, полная разность F1 и признак идентичности токенных входов. В [результатах](results.json) приведены все пересечения трёх исходов по каждому показателю и хеши исходных файлов.
