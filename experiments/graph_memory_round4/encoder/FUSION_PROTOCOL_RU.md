# Вторичная гипотеза о взаимодополняющих сигналах

Исход фиксируется во время исполнения энкодера до создания его файла предсказаний и до вычисления его метрик. На прежних 320 Java-задачах проверяем ровно одно симметричное правило, складывая 1/r_G + 1/r_U для кандидата из полного списка графа и UniXcoder. При точном равенстве рациональных чисел побеждает исходный индекс. Без обучения на тесте, отсечения списка, изменения коэффициентов или выбора подгрупп. Гипотеза состоит в том, что порядок, полученный из локальных признаков графа, и геометрия обученных представлений различают разные подходящие фрагменты. Голоса подтверждающих друг друга кандидатов повысят качество, но равное взвешивание способно ухудшить сильнейший сигнал. Метрики Top-1, MRR, интервалы кластерного парного бутстрэпа, сравнение с каждым компонентом раздельно, основное окно три строки. Указываем долю допустимых строк, где хотя бы у одного из двух методов верное первое место. Последнее количество вычисляется с известным эталоном и служит только потолком для селектора, выбирающего одно из первых мест двух методов. Предшествующие результаты графа на панели уже известны. Новой независимой проверкой улучшения на полностью неизученных задачах это соединение считаться не может.
