# Повторение CPU-опыта

Папка находится рядом с repo, содержащей исходные 5 Parquet-шардов Java, strict_roster.json, paired_roster.json, прежние запечатанные ранги графа и Semlith, их манифесты и реализации авторов. На чистой машине сначала восстанавливаются материалы repo по инструкции всего отчёта или соответствующего эксперимента. Фиксированная модель скачивается с Hugging Face без ключа. Контрольная сумма весов 6732b60037b086557e4c731c3748c99b4fec735d9ffe3c4c70061fd142e6b9d9. Unixcoder нужен как авторская модель RepoBench для получения векторов. Генератором исправлений он не является.

На Windows в копии каталога для нового запуска (существующие результаты сохраняйте отдельно) выполните в PowerShell:

```powershell
$env:UV_CACHE_DIR = Join-Path $PWD ".uvcache"
uv venv --python 3.12 .venv
uv pip sync --python .venv/Scripts/python.exe environment.txt
.venv/Scripts/python.exe download.py
.venv/Scripts/python.exe prepare.py
.venv/Scripts/python.exe -u infer.py
.venv/Scripts/python.exe fusion.py
.venv/Scripts/python.exe score.py
.venv/Scripts/python.exe score_fusion.py
.venv/Scripts/python.exe audit_author.py
```

Сначала образуется файл blind.jsonl.gz без целевых столбцов. Утилита infer.py не содержит обращения к Parquet, ответам или результатам других систем. Из него и исходных весов получаются predictions.jsonl.gz и prediction_lock.json. Если две различные токенизации в одной выдаче имеют зазор меньше 0,00002 по косинусу, эта выдача пересчитывается на одиночных входах. Программа fusion.py получает только запечатанные предсказания. Эталоны открывает score.py после проверки SHA у решений и исходных контрольных систем. Повторные запуски gzip могут менять timestamp заголовка и SHA контейнера при идентичных решениях, поэтому решения между запусками сравнивайте также построчно после распаковки.

Отдельный файл scores.jsonl.gz содержит одну строку на ID и окно, с эталоном и наблюдаемым рангом для каждого метода. В results.json сохранены результаты каждой страты, размер выборки и интервалы по репозиториям. Файлы fusion* описывают отдельное вторичное исследование, включая результаты интеграции методов. Для передачи достаточно исходников, текстов и JSON/JSONL.GZ, без локального окружения, кэша uv и скачиваемых весов. Текущая версия исходников и весов перечислена в method_lock.json, контрольные суммы исходных шардов в inputs_receipt.json.
