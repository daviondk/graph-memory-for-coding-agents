# Независимая проверка затрат новой записи графа на исходном архиве ICLR
После разработки на 320 задачах из конвертации Hugging Face правило Lean(live=True) и его код замораживаются. Заранее определяем 24 задачи в каждой страте из другого авторского архива с разными между собой репозиториями и исключаем проекты 240 предыдущих архивных микроизмерений. Выбор по хешу без разметки и длины. Исходный порядок кандидатов имитирует поступление. Оцениваем холодный запуск — перед каждой задачей и стратегией сбрасываем кеш разбора. Сразу после каждой вставки (i) только запрашиваем готовый граф или (ii) ещё вычисляем все 43 признака, запускаем тот же обученный GBDT, читаем полный ранжированный список. Все порядки должны совпасть на каждом шаге. Для каждого режима два независимых последовательных измерения, порядок стратегий обращается во втором. Метрики — отношение сумм тактов одного потока и отдельно стеночное время, парный 95% bootstrap по разным проектам. Это измерение поиска в имитируемом потоке, без генерации патча.
