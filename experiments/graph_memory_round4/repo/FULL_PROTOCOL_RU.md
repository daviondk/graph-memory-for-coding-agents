# Полный авторский Java test в текущей Parquet-конвертации

Зафиксировано после фиксированных подвыборок, без изменения обученных весов. Все Java test_easy и test_hard авторских RepoBench-R/Hugging Face c9daeba525cb28cfb9fbe17886f32b8ea34fc870, обе категории first/random и каждый шард. Вычисляем полный граф и одинаково обученный контроль owner при трёх строках, отдельно фактический Jaccard из исходников RepoBench на CodeGen и детерминированное исходное разрешение равных оценок. Для второго протокола crop_code_lines официально использует split('\\n'), в отличие от scorecard Semlith splitlines(). Ранжировщик получает только переданный результат такого crop, без доступа к более раннему коду. Прочие размеченные поля и next_line не открываются на этапе прогнозов. Оценка проводится отдельно с сохранением всех рангов и исходов. Число задач и веса по стратам, общая микродоля, CI с группировкой по репозиторию, разрез easy/hard — обязательно указываются. В первоначальной выборке и её новых проверках те же исходные файлы, поэтому эти данные частично использовались ранее. Результаты этой дополнительной серии — оценка замороженного решения на всей публичной доступной конвертации; общая полная выборка не полностью независима от предыдущих проверок.
