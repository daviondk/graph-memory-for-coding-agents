# Прототип с повторным использованием уже разобранных множеств слов
После измерений прежнего инвертированного словаря на панели 320 фиксируем инженерское улучшение. Новые правила будут проверены на тех же 320 задачах, нулевое расхождение с полным пересчётом — обязательное условие. Поэтому это парная доработка на открытой панели, независимое подтверждение затрат отдельно. На входе уже хранятся множества слов каждого прочитанного фрагмента. Проверим две идеи: при поступлении нового объявления посмотреть только одно слово в каждом таком множестве, сэкономив отдельный обратный список по всем словам; при чтении возвращать существующие веса рёбер, обновляя их только когда новое объявление меняет неоднозначность конкретного имени. Допуск к виду графа только для немедленного чтения, сохранение неизменяемых версий не измеряется. Сравним затраты на все вставки с чтением после каждой вставки и на всё построение с чтением только в конце. Те же 320 задач, два порядка, одинаковые заранее разобранные записи, CPU-такты текущего потока, 3 парных повтора, 32 случая для дополнительной памяти; оценщик не читает ответы бенчмарка.
