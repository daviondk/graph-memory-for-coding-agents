# Уточнение разрешения таймера, до второй серии измерений
Первая попытка с process_time_ns на Windows вернула множество нулевых коротких интервалов и отношения, кратные 15,625 мс. Сохраняем первичный лог как диагностику. Для вывода о скорости повторяем без изменения графа или панели с QueryThreadCycleTime, который считает такты текущего потока с высокой частотой независимо от вытеснения. Время, мощность и денежные затраты по тактам не оцениваем. На запрос и порядок — три повторения процедуры с прямым и обратным порядком вариантов. Берём медиану трёх средних. По 32 детерминированно выбранным по четырём стратам задачам отдельно измерим живую Python-память после последней вставки и сборки представления через tracemalloc (общий исходный текст и заранее подготовленные записи извне отсчёта), кеш только итоговых объектов как у дорогостоящего пересчёта, память и итоговый вид вместе для инкрементальной схемы.
