# Полный внешний оценщик как проверка чувствительности

До раскрытия метрик восстановления берём уже заказанные поколения тех же 64 функций. В дополнительной проверке запустим неизменённую функцию check из авторского HumanEval+ OriginFmt v0.1.10 со всеми её аргументами в отдельном ограниченном процессе, как у эталона, исходного кода и каждого уникального предложенного патча. Отдельно — первоначальный полный check из HumanEvalPack. Эталон и ошибочная функция проходят те же два запуска. Входы полной авторской проверки могут пересекаться с уже виденными агентом тестами. Основная независимая оценка остаётся на новых, поаргументно отделённых входах. Отмечаем таймауты на долгих наборах и приводим отдельно поднабор с проходящим эталоном и падающим исходником. Проверка реальных программ даёт сильный внешний контроль процедуры, но изменённые доступ к прошлым тестам и выбор задач не соответствуют официальному open leaderboard.
