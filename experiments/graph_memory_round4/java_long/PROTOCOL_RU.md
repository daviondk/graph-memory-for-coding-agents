# Длинный локальный префикс при неизменном графовом поиске, план до генерации

Берём только ранее зафиксированные B_packets, по 24 задания на каждую из четырёх страт java_cff_test_easy/hard и java_cfr_test_easy/hard. Упорядочиваем внутри страты по SHA256('r4-java-long-prefix-30-v1|'+id), берём первые 24 исходных ID допустимой панели и фиксируем выбор до запуска генератора. При отсутствии допустимого контекста по тому же фильтру безопасных задач пополняем в том же порядке, отмечая все исключённые ID. Оценки B, реальные/сгенерированные следующие строки, ошибки и альтернативы подвыборку не определяют.

Единственное изменение в тексте, видимом решателю, — последние 30 строк кода текущего файла, не более 1024 последних токенов по прежнему Qwen-токенизатору. Граф и Semlith выбрали первые внешние фрагменты ранее по запросу из трёх строк. Их индексы и 256-токеновые фрагменты остаются из B без нового ранжирования. Контроли — пустой фрагмент и идеализированный недоступный в работе вариант со знанием золотого индекса фрагмента среди тех же кандидатов. Для всех четырёх вариантов одинаковые веса, системная инструкция, формат, Q4_K_M, максимум 80 выходных токенов, детерминированная температура 0 и тот же вычисляемый от ID seed, что у B. Истинная строка отсутствует в подготовке, генерации и выборе ответа. Поштучные входы запечатываются до первого вызова localhost:18904. Идентичные байтовые запросы дедуплицируются, авторизовано повторное использование ранее зафиксированного ответа только при совпадении полной сериализации входа и его SHA256. Отдельно сообщаем новые физические вызовы и повторы/логические назначения. Код из строк Java не выполняется.

Основной показатель — exact next-line match (EM). Дополнительно считаем авторосовместимый edit similarity, F1 идентификаторов, токены, выбор золотого фрагмента и число реально разных текстов у методов. Парные разности и 95% bootstrap по проектам (10000 раз) для сравнения графа с Semlith, отсутствием фрагмента и недостижимым oracle. По зафиксированным ответам B отдельно оцениваем изменение в качестве при 3 и 30 строках в тех же заданиях и вариантах. Одни и те же задачи и исходный решатель не означают независимого набора. Прямое сравнение с полным лидербордом RepoBench-P требует другой постановки.
