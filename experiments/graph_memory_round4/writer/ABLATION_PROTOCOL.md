Разведочная абляция после открытия C. Замороженный cal_pages назначает начальной странице вероятность, оценённую на A, а набору из 1–3 последовательных частей — массу в соответствии с обученной шириной. Изменяем только награду при отборе. В cal_add делим массу каждого полного интервала поровну между его частями, при вытеснении их веса сохраняются. Это оптимизация ожидаемой доли страниц вместо ожидаемого полного события при тех же оценённых вероятностях и той же сырой байтовой цене страниц. В cal_first вознаграждается только вероятная первая страница. Все остальные операции, метаданные, кодек, лимит и кандидаты остаются идентичными cal_pages до возвращения части последней страницы. Запускаем эти два контроля по A, B и C без настройки параметров. Только C не использовалась для подбора исходной модели; добавление самих контролей было решено уже после подсчёта C. Сравниваем каждое действие с исходным cal_pages, учитываем покрытие целиком, покрытие первой строки и ширину доверительных интервалов по задачам.
