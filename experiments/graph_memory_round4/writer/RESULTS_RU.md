# Сколько наблюдённого кода остаётся доступно на следующей операции

**204 ранее не использованные задачи SWE-bench Verified дали 833 измеримые правки. Новый алгоритм сохранил целиком 425 будущих участков при строгих 4096 байтах, исходный LRU — 408. При одинаковом словаре у сильного переключателя 417.** При переносе на другие реальные действия CodeSweep с Kimi K2 Instruct эффект заметно слабее. Эта серия измеряет качество хранимого текста при заданной последовательности действий. Доля успешно исправленных issues здесь не оценивалась.

## Чем отличаются алгоритмы

На 413 однозначно расположенных будущих правках открытой панели A обучили условную логистическую модель начальной страницы. Для каждого кандидата вычисляются 22 признака. Среди них ранг по числу более свежих наблюдений, давность файла, расстояние до последнего центра просмотра, совпадение с ранее редактировавшимся файлом и упомянутые в задаче идентификаторы. Целевая вероятность нормирована по видимым страницам как exp(β·xᵢ)/Σⱼ exp(β·xⱼ). Веса получены минимизацией условного логарифмического проигрыша с L2-штрафом. Для каждого интервала из одной, двух или трёх смежных страниц вероятность начала умножается на оценённую массу его ширины. При переполнении жадно вытесняется страница с наименьшим отношением утраченной массы ещё целых интервалов к цене адресованного текста. Бинарным поиском измеряется фактический размер сериализованного буфера. Если последнюю вытесненную страницу можно вернуть частично, отдельно пробуются её левый и правый края. За конец, примыкающий к сохранённому соседу, функция даёт больший вес. Когда оба конца дороги, сохраняется уже получившийся полностью допустимый снимок.

Время, пути, текст и необходимые для следующих действий метаданные включены в 4096 байт. Одновременно существует один сохраняемый буфер на метод и задачу. Промежуточные вычисления перехода в лимит постоянного состояния не входят. Общее неизменяемое условие задачи, константы модели и словарь кодека доступны извне. Словарь DEFLATE объёмом 32 767 байт состоит из 2 376 повторяющихся фрагментов, найденных на 1 350 тренировочных траекториях 51 другого проекта SWE-smith. При сравнении с dict_lru и dict_mixed используется тот же словарь и тот же формат. Кодек и идея совместной ценности набора страниц имеют предшественников. Проверяем конкретное сочетание условий и измеряем вклад компонентов. [Руководство zlib](https://zlib.net/manual.html) · [Системная постановка file-bundle caching](https://arxiv.org/abs/2011.03212)

## Что объясняет разницу

На 463 наблюдениях с однозначно известной начальной страницей C многоклассовый Brier у калиброванной модели — 0,898, у равномерного назначения массы только последним увиденным страницам — 1,066. Модель поставила верный старт на первое место в 23,33% случаев. Такие числа применимы условно к уже видимым и локализованным целям. Ошибка калибровки по десяти корзинам уверенности составила 0,052.

После открытия основного результата выполнен контроль с теми же вероятностями старта и ширины. При награде за первую страницу / аддитивной награде за долю страниц / награде за полный интервал на трёх панелях получили A 372/379/377, B 297/298/302, C 420/425/424. Использование соседних страниц принесло пользу против прогноза только начала. Предпочтение награды за целую группу перед аддитивной не воспроизвелось во всех трёх случаях. Общая прибавка нового метода включает вклад кодека, калибровки и выбора соседей.
