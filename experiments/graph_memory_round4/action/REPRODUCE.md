# Воспроизведение серии чтений

Рабочая папка на D — D:/CodexResearch/x20-bench-workspace/work/graph_memory_round4/action. Использован Python 3.14.4 на CPU, NumPy и Python-пакет Brotli. Для чтения публичного SWE-smith Parquet использовался отдельный CPython 3.12 с PyArrow из сохранённого окружения R3. Параметры кодеков — zlib уровня 6 и Brotli качества 4, проверяется также несжатое представление. Перед повторной записью скопируйте исходники и наблюдения в отдельную рабочую папку. Обязательные для быстрого аудита SHA, бинарные записи и состояния идут вместе с архивом. Новых модельных весов не требуется.

## Быстрый аудит

При наличии input_*, answer_*, opt_raw_*, opt_cost_*, opt_results.json и lock-файлов выполните python verify.py. Проверяются поштучные длины запросов и ответов, размеры пакетов повторов, необходимость каждого повтора, SHA каждой проверяемой выдачи и равенство каждой восстановленной строки авторской записи. Результат — wire_audit.json. Скрипт strict-проверки также сверяет хеши первичных прогнозов и методов. Для повторения только расчёта статистики выполните python opt_stats.py (или python analyze.py для предыдущего опыта). Для просмотра каждого естественного случая несовпадения выполните python cases.py. Документ RESULTS_RU.md строит python report.py. Файлы счётчиков содержат фактические исходы, а не модельные оценки.

## Повторный запуск по исходным данным

Старые зависимости R3 используются только для повторного создания контрольных состояний или добычи сырого набора; полный повтор на D использует соседние каталоги graph_memory_round3, graph_memory_round2 и memory_session5. Три исходных серии — graph_memory_round3/real_swe, real_swe_followup и demand. Загрузки acquire_ranges.py ограничены только 293 старыми issue A и B из R3 и уже сверенными SHA официального авторского запуска. Ветка записи, протестированная на новых issues R4, не используется. В отдельной копии порядок команд:

```powershell
python acquire_ranges.py
python prepare.py
python experiment.py request
python experiment.py A
python experiment.py seal
python experiment.py B
python analyze.py
python delta.py A
python delta.py B
& 'C:/Users/Admin/AppData/Roaming/uv/python/cpython-3.12.13-windows-x86_64-none/python.exe' source_c.py
python prepare_c.py
python optimistic.py freeze
python optimistic.py score
python opt_stats.py
python short_tags.py
python cases.py
python verify.py
python report.py
```

Исходный parquet для C лежит на D в work/memory_session4/compact/.scratch. Для каждого из восьми файлов source_c.py сравнивает SHA с публичной ревизией, затем находит тот же instance, номер строки, traj_id и SHA полного сообщения. Сохраняются только диапазоны вызовов редактора. На A и B входы в виде .traj скачиваются без аутентификации, результат сопоставляется с двумя прежними представлениями, оригинальное содержимое на диск повторно не записывается. Подробные receipts и ссылки на публичные источники есть в ranges/, source_C_receipt.json и документах R3.

Этапы разделены. prepare.py и prepare_c.py последовательно применяют события, учитывают сжатый предел 4096 байт после каждого действия и передают эксперименту только предыдущее состояние. experiment.py request строит все запросы без чтения файлов answer. В режиме A обычные и совместные гипотезы обучаются на затратах A, в seal решения B фиксируются в decision_B.jsonl.gz. Решения скользящего блочного контроля зафиксированы отдельно в delta_lock.json. Для позднего кандидата opt_plan и opt_lock закрыты до расчёта C. short_tags.py — анализ после открытия C, он не меняет первичных решений. Во всех методах присутствует точное сравнение последовательности адресов и UTF-8 байтов; выполняется исключительно локальное кодирование и декодирование фактически наблюдавшихся текстов, без выполнения программ или команд из трасс.

Числовой seed и единица bootstrap указаны в analyze.py и opt_stats.py. Повторные просмотры одной и той же задачи учитываются в общем счётчике; дублирование 10 раз одного и того же issue не создаёт 10 независимых задач. Для проверки пересечений репозиториев, отказов и их концентрации доступен stale_cases.json.
