# Дополнительная проверка коротких отпечатков

Задано после первичных результатов A/B/C. Первые контроли адресного сравнения платили 16 байт для каждой предложенной страницы. Проверяем, не объясняется ли весь положительный результат завышенной ценой подписи у контроля. У четырёх вариантов совпадают области, бинарный протокол и политика LRU. Для 12-строчной страницы либо максимального непрерывного диапазона достаточно отправить первые один или четыре байта криптографического отпечатка, после чего сервер принимает совпавшие блоки и передаёт остальные строки. На ответе с отсылками дополнительно передаётся одна сильная BLAKE2b-128 подпись всей собранной версии. При несовпадении оплачивается обычный повтор, как у новой политики. Замена сравнивается на всех трёх панелях. Этот опыт — разбор чувствительности уже открытых показателей. Подбор параметров на C и выбор победителя без показа остальных вариантов не проводится.
