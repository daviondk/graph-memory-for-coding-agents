# Рабочая графовая память кодового агента
> Серия 4. Какие связи помогают находить код, как поддерживать их по мере работы и меняет ли найденная информация результат самой модели.
На исходном Java-архиве RepoBench из 36 000 запросов граф чаще выбирал нужное объявление первым, чем контроль с тем же обучением. Граф дал 6 663 попадания, контроль — 6 152. Прибавка составила 511 задач, или 1,42 процентного пункта, 95% интервал по репозиториям [0,99; 1,84]. Все 349 проектов отделены от обучения и от другой полной проверки на 24 000 примеров.

Самое перспективное для статьи — сочетание проверяемого выигрыша поиска с возможностью точно обновлять его граф по частям. Вывод о мировом SOTA делать рано. Все пять показателей Java численно превысили максимумы исходной таблицы ICLR 2024, но её контроль Jaccard разошёлся с нашим, а граф обучался на дополнительных открытых примерах.
