# Как выбирать строки для вытеснения
> На ранее отложенных задачах SWE-bench Verified новое правило при лимите 4 096 байт сохранило целиком 425 будущих правок из 833. Обычное вытеснение по давности сохранило 408.
Правило оценивает вероятность начала правки по истории просмотров, расстоянию до последнего показанного участка и словам из условия задачи. При переполнении можно оставить край удаляемой страницы, если он дополняет оставшийся фрагмент. Общий словарь сжатия занимает 32 767 байт, построен на 51 другом проекте и доступен всем вариантам со словарём. В лимит одной сессии входят код, адреса и изменяемые метаданные.
@ 7.0 4.0 4.0
| Политика записи | Claude, из 833 | Kimi, из 218 |
| Вытеснение по давности | 408 | 92 |
| Давность с общим словарём | 413 | 93 |
| Прежний графовый переключатель со словарём | 417 | 92 |
| Калиброванное ранжирование целых страниц | 424 | 93 |
| С сохранением края страницы | 425 | 93 |
Модель обучена на 413 локализованных правках первой открытой панели. Кандидат выбран до расчёта на третьей панели Claude. В неё вошли 204 задачи, а на Django пришлось 746 из 833 действий. Выигрыш у давности составил 2,04 п.п. [0,48; 3,81] при повторной выборке задач внутри двух проектов. Относительно прежнего переключателя с тем же словарём разность составила 0,96 п.п. [−0,37; 2,53]. В абляции на тех же вероятностях сложение ценностей соседей дало 425 попаданий, награда за целую группу — 424.
Затем те же правила получили журналы CodeSweep с Kimi K2 Instruct. В 101 истории из 12 проектов нашлось 218 будущих замен. На этих действиях давность со словарём достигла результата калиброванного правила. Все числа характеризуют содержание памяти перед действиями агента.
