# Проверка комплекта

Для демонстрации откройте index.html. Для автономной сверки полного комплекта достаточно Python стандартной поставки

```powershell
python -B -X utf8 verify.py
```

verify.py читает встроенные в HTML числа, заново рассчитывает состояние сертификатов и сравнивает его с 84 нативными префиксами из oracle.json. Также сверяет хеши финального HTML, браузерных снимков и всех материалов по manifest.json. Интернет и исследовательская среда при этом не нужны.

Для пересборки на исследовательской машине в **копии** этой папки рядом с external_budget выполните

```powershell
$readoutPython = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $readoutPython -B -X utf8 build.py
python -B -X utf8 browser_check.py
python -B -X utf8 verify.py --seal
```

Для browser_check.py нужны уже установленные Playwright и Chrome или Edge. Можно указать собственный путь в переменной CHROME_PATH. Скрипт ничего не скачивает. Отдельный временный браузер открывает локальный файл с сетевым доступом, отключённым на уровне браузерного контекста. Числовые префиксы при создании сверяются с авторским scorer SERBench из закреплённой локальной копии и подписанными данными R37. Снимки текущей версии браузера могут отличаться на другой платформе.
