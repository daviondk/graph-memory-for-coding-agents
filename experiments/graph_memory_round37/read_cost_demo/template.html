Method and scope

Both cases come from the public machine-labelled SERBench Cal500 split by repository. BGE ranks code fragments by the current agent state. The calibrated union_cost reader also uses length, dense rank and prior mentions of the path. These states were selected to explain two mechanisms.

A group is covered when its quota of distinct acceptable units is met. Complete-MSS accepts all groups or one complete alternative set. Costs sum Qwen tokens for each serialized path and excerpt. A candidate exceeding the budget stops the prefix. The source study used a maximum of eight candidates; larger depths here are diagnostic. The first sufficient prefix uses the evaluation certificate. These measurements cover retrieval, not generated answers or task completion.
