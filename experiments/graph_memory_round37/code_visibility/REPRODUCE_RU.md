# Воспроизведение

Быстрая проверка всех сохранённых прогнозов, поштучных метрик и основных средних требует только стандартного Python.

~~~powershell
python verify.py
~~~

Полный повтор выполнить в копии каталога на том же уровне. Нужны локальные 319 опубликованных шардов Handoff Debt закреплённой ревизии, метаданные безопасной когорты SWE-bench Verified и предыдущий каталог graph_memory_round31/natural_handoff. Старые каталоги используются для чтения. Из каждого шарда читаются записи как данные, SHA-256 источников проверяются. В прогнозе и файлах результатов хранятся хеши строк и их номера, событийные идентификаторы и числовые метрики; файловые команды не выполняются.

~~~powershell
$pythonResearch='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $pythonResearch project.py
& $pythonResearch predict.py
& $pythonResearch score.py
& $pythonResearch fixtures.py
& $pythonResearch forensics.py
& $pythonResearch verify.py
~~~

Параметры и отпечатки проекции перечислены в source-seal.json, итогового пакета до открытия следующего просмотра — в prediction-seal.json. В predictions.json.gz входят предсказания, в observations.json.gz лежат адреса следующего реального просмотра и закрытые диагностические проверки. Файл outcomes.json.gz содержит числители и знаменатели каждого метода для каждого эпизода. В results.json приведены основные и дополнительные результаты, разбивка по каждому репозиторию и анализ при его исключении. Поиск остаточных несоответствий дополнительно использует служебные снимки, проверка обычного прогноза обходится без них.
