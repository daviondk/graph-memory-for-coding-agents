Если перенос адресов когда-либо освободит место, которого нет среди исходных номеров при сохранении приоритета квитанции, два метода нельзя честно уравнять одним добавлением записи в H. Поэтому сравнение равных размеров использует общую доступную квоту минимума: H выбирает по хешу на старых номерах, T* сокращает свои переносимые старые записи до того же числа. Если такой случай не встретится, T*=T. В остальных основных сравнениях T работает с изначальной квотой. Эта поправка добавлена до получения проекции и подсчёта исходов.
