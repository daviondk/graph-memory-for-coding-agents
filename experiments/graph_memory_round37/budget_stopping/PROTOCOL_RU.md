# Правило остановки чтения до исчерпания контекста

Зафиксирован один ранжировщик R35 с четырьмя коэффициентами, обученными на 3 894 вопросах, и семантический порядок штатного Dense-FT seed 13. Для каждого вопроса исходный читатель принимает максимально длинный строгий префикс целых узлов стоимостью до 2 048 токенов. Ищем более короткий префикс, который сохранит все эталонные символы, уже доступные в исходной выдаче. Критерий защищает и частичное покрытие вопроса, когда полный ответ в исходном бюджете невозможен. При чтении известны только баллы, порядок, стоимости и роли узлов; эталоны используются только для обучения, калибровки и оценки.

Основная панель — 2 000 вопросов / 1 207 траекторий официального test. Калибруем на 580 вопросах / 352 траекториях официального dev. Допустимый риск хотя бы одной потери покрытия на целую траекторию α=0,05. Для сравнения при α=0,01 и 0,10 покажем чувствительность без подбора. Модель бюджета — квантильная регрессия градиентным бустингом (квантиль 0,9, 100 деревьев глубины 2, минимум 30 наблюдений в листе, learning rate 0,05, seed 37012). При обучении на 3 894 train-вопросах целевая стоимость — конец последнего размеченного положительного узла исходного 2 048-префикса, ноль если такого узла нет. Структурный и порядковый признаки вычисляются с исключением своей группы траекторий для первой стадии. Surrogate может переоценивать стоимость из-за взаимозаменяемых фрагментов. На dev и test целевой порог вычисляется точно по исходным атомарным интервалам. Состав признаков фиксирует код до открытия тестовых результатов.

Способы остановки — единая граница токенов, граница количества узлов, доля от фактической исходной стоимости, порог падения балла относительно первого узла, предсказанный деревьями бюджет с общей добавкой. Для каждого метода на каждой dev-траектории берём максимум требуемого порога среди её вопросов. Глобальная установленная поправка или граница — элемент с рангом ceil((m+1)(1−α)) среди m максимумов, выход за m означает исходное полное чтение. Это стандартная split-conformal калибровка по историческим группам. Контроли проходят ту же процедуру. Для дробных токенных границ используем округление вверх. Дополнительно выберем на dev единую границу, обеспечивающую среднее число фактически отданных токенов, ближайшее к методу деревьев при α=0,05; на test границу замораживаем.

Основной контраст стоимости — деревья против единой риск-калиброванной токенной границы при α=0,05. Первичные исходы — доля траекторий, где утрачена какая-либо доля эталонного контекста, и разность среднего фактически выданного числа токенов на вопрос. Вторично измеряем потерю Full Support, сдвиг среднего Coverage, долю сокращённых выдач, отношение к несокращённому читателю, остальные контролируемые способы. Парная перевыборка целых траекторий для стоимости и качества, 10 000 повторов. Для частоты затронутых траекторий — двусторонний точный биномиальный интервал как модельная оценка при независимости траекторий. Проверка полезности адаптации требует экономии относительно единой откалиброванной границы и наблюдаемой частоты утраты не выше α на test. Различаем это эмпирическое условие и распределительную гарантию для нового обменного кластера. Предыдущий опыт выбора ранжировщика на этом корпусе ограничивает подтверждающую роль прогона.
