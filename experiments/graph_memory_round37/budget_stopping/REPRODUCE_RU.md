# Воспроизведение правила остановки

Исходный эксперимент использует зафиксированные папки R33/budget_loss, R34/interval_witness, R35/calibration_scale и локальный кэш числовых структурных признаков R33. В рабочем дереве прежние серии находятся рядом с graph_memory_round37. Полный драйвер предполагает Windows, Python исследовательского окружения на D и доступность исходного корпуса ISETrace для нативной сверки. Для просмотра исходов и проверки архивных сумм достаточно файлов этой серии. Ранжировщик, train-инвентаризация, версия калибровки, предсказанные длины, эталонные пересечения и оценки связаны контрольными суммами.

```powershell
$researchPython='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $researchPython -X utf8 policy.py
& $researchPython -X utf8 evaluate.py
& $researchPython -X utf8 native_check.py
& $researchPython -X utf8 risk_diagnostic.py
```

Обучение выполнено на CPU со scikit-learn 1.8.0. Линейное ранжирование, дерево и алгоритм проекции сохранены в числовом виде. Прогноз бюджета использует открытую реализацию обхода узлов деревьев. На 3 894 train-примерах она совпала с предсказаниями sklearn в пределах 10⁻⁸. Для воспроизведения таблиц достаточно двух файлов исходов и скрипта оценки. Полный нативный прогон требует ранжированных кандидатов и эталонов прежних серий. Пропуск дорогих этапов возможен с использованием приложенных сохранённых прогнозов.
