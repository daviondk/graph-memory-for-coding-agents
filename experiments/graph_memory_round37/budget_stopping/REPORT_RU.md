# Когда агент может прекратить читать память

При почти одинаковом числе выданных токенов обученная политика сохранила полный набор свидетельств в **76,10%** вопросов ISETrace, единая граница — в **74,85%**. Разность **+1,25 п.п. [0,45; 2,05]**. Однако основной критерий эксперимента оказался строже. Допускалась потеря какой-либо части ранее доступных свидетельств максимум в 5% траекторий. Обученная политика потеряла их в **112 из 1 207 траекторий (9,28%, 95% ДИ 7,70–11,06%)**. Экономия при таком риске недостаточна для принятия метода. ## Что мог знать агент

Задача состоит в выборе длины префикса уже ранжированных узлов графа. Исходный читатель принимает подряд целые узлы в пределах 2 048 токенов. В среднем он передаёт 1 847,41 токена. Читатель имеет метаданные всего списка, включая стоимость узлов, баллы и роли. Экономия относится к числу токенов передаваемого контекста. Стоимость первоначального ранжирования сохраняется. Ответы LLM и точность выполнения задач в этом опыте не измерялись.

Для вопроса q и эталонного элементарного интервала a обозначим через r(a) ранг первого узла, несущего a. Интервал может встретиться в нескольких узлах. Если полный префикс содержит K узлов, достаточно сохранить первые Y = max{r(a) | r(a) ≤ K}, с Y=0 для пустого множества. Любой более короткий префикс теряет хотя бы один ранее покрытый интервал. Поэтому так проверяется сохранение даже частичного ответа. По всей тестовой панели читателю с доступом к разметке понадобилось бы в среднем 557,00 токена. Это нижняя граница для данного порядка.

На 3 894 train-вопросах обучен квантильный бустинг, целевой бюджет определяется по последнему положительному узлу в исходном префиксе. Для большинства применений в реальном времени вычисляются лишь наблюдаемые входы модели. На dev использованы точные целевые интервалы. Для каждой из 352 траекторий берём максимум требуемой поправки среди вопросов. При α=0,05 фиксируем 336-й по возрастанию максимум. При обменности траекторий и независимо обученном предикторе место новой траектории в объединённом порядке равномерно при случайном разрешении совпадений. Это даёт маргинальную верхнюю границу вероятности ошибки, усреднённую и по выбору калибровки. Снимки test-прогнозов для всех 2 000 вопросов записаны до чтения их разметки в этом опыте. На корпусе уже проводились отбор ранжировщика и другие сравнения. [Алгоритм и заморозка](policy.py) · [Калибровка](selection.json) · [Хеши прогнозов](seal.json)

## Сравнение правил

Единый предел, число узлов, доля доступной стоимости, падение балла относительно первого узла и адаптивная поправка независимо калибровались на тех же траекториях. Правило с подобранной средней стоимостью использует единую границу 1 536 токенов, выбранную по средней фактической выдаче на dev. Указанные ниже токены и качество измерены на test. Только столбец риска агрегирует наблюдения по траекториям. Остальные столбцы дают равный вес вопросу. [Все результаты при рисках 1%, 5%, 10%](test-results.json)

|---|---:|---:|---:|---:|
| Исходный префикс | 1 847,41 | 81,15% | 85,68% | 0/1 207 |
| Общая граница 1 764 токена | 1 549,37 | 77,25% | 82,66% | 86/1 207 (7,13%) |

Относительно общей риск-калиброванной границы адаптация сэкономила **217,39 токена [197,94; 236,78]**, одновременно снизив Full Support на **1,15 п.п. [0,35; 1,96]**. Относительно единой границы с подобранной стоимостью разность расходов **+3,54 токена [−15,52; 22,46]**. Это две разные постановки. Для сравнения стоимости и качества использовали 10 000 парных перевыборок траекторий, для доли затронутых траекторий — точный биномиальный интервал при независимости траекторий. До восьми узлов и порог падения балла уложились в наблюдаемый предел. Среди заранее заданных вариантов результат правила по падению балла заслуживает отдельной репликации. Его 95% интервал риска **3,67–6,17%**.

После оценки разложили сбой по размеру траектории. У обученного правила утрата затронула 4/124 dev и 26/414 test траекторий с одним вопросом, а также 12/228 dev и 86/793 test с двумя. Разница в частотах присутствует в обеих группах. Дополнительно рассчитан ориентир с учётом случайности самой калибровки. При фиксированном независимом предикторе, непрерывных баллах и совместной обменности число превышений калибровочной порядковой статистики имеет бета-биномиальное распределение с параметрами 1 207, 17, 336. Его центральный 95% диапазон **31–92**, в опыте наблюдалось **112** повреждённых траекторий. Совпадения баллов и округление бюджета вверх могут снижать число потерь. Эта диагностика не устанавливает причину отклонения, поскольку история экспериментов нарушает чистоту проверки предпосылок. ## Сверка и связь с литературой

На dev и test проверены 43 860 решений правил, соответствующих 11 497 различным парам вопрос–префикс. В каждом случае официальный интерваловый оценщик ISETrace и независимый подсчёт покрытия дали одинаковый результат. Исходные цены узлов восстановлены из нативных записей. [Сверка](native-audit.json) · [Код](native_check.py)

Обучаемое сокращение ранжированного списка исследовано в Choppy. Для нашей постановки существенны целые узлы переменной стоимости, метрика исходных интервалов и одновременная защита всех вопросов одной траектории. Split-conformal порог для максимума группы — стандартное применение ранговой симметрии. Работы о контроле риска и иерархических данных дают ориентиры по предпосылкам и более общим процедурам.
