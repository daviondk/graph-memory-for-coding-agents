# Проверка и повтор

Быстрый независимый аудит проверяет каждое из 4117 окон, обе обработки непрозрачных шагов, терминальные условия и 1282 сопоставления с прежним опытом. Нужен стандартный Python и соседние неизменённые каталоги code_visibility и code_store.

~~~powershell
python verify.py
~~~

Для нового физического измерения или полного воспроизведения исходных событий скопировать каталог на диск D рядом с прежними исследованиями и выполнять команды из копии:

~~~powershell
$pythonResearch='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $pythonResearch native.py
& $pythonResearch count.py
& $pythonResearch fixtures.py
& $pythonResearch physical.py
& $pythonResearch summarize.py
& $pythonResearch verify.py
~~~

native.py требует локальные 319 шардов Handoff Debt зафиксированной ревизии, таблицы метаданных и исходный список разрешённых научных задач. Записки, команды и исходный текст файлов не исполняются. Скрипт сохраняет компактные границы и числовые подтверждения редакторских операций. Файл prefixes.json.gz содержит только информацию, доступную при записи. Файл followup.json.gz отдельно содержит зарегистрированные просмотры, причины окончания и правую цензуру. Выборку для времени фиксирует physical-plan.json до запуска измерений. Предыдущие реализации БД подключаются по зафиксированным контрольным суммам. Временные файлы SQLite создаются и удаляются самим скриптом внутри рабочего каталога. При новом запуске тайминги изменятся.
