# Независимый библиотечный контроль перемещения адресов

До запуска сравнения фиксируем публичную реализацию ChangeSet из @codemirror/state 6.7.6 и все 1 282 перехода уже разобранных Handoff Debt. Для изоляции оператора обе реализации получают одну подтверждённую область замены, один ответ инструмента, один набор старых наблюдений и общий лимит 128. Виртуальное адресное пространство содержит по одной позиции на строку. Целая старая строка, затронутая заменой, перестаёт быть свидетельством. Наблюдения из результата правки получают приоритет. Если начало замены недоступно, сохраняются только наблюдения из ответа.

Проверяем гипотезу эквивалентности множества всех пар «номер, хеш строки» для каждого перехода с реализацией R37. Хешируем итоговый ответ до чтения эталонных результатов. Любое несовпадение требует разбора. Это сравнение сильного оператора адресации при общей политике памяти. Обработка неполного ответа агента, локализация правки, выбор строк и ёмкость находятся за границей этого сравнения. Отдельно сопоставим условие «не менять номера и забыть только затронутый интервал» из исходного опыта. Метрики по задачам и разбиение уже были изучены в соседнем опыте, независимой репликацией это сравнение не является.
