# Воспроизведение SERBench reference

Из serbench_reference команда `python -B verify.py` проверяет 18 подписанных файлов, хеши прогнозов, состав обеих новых выдач, поштучные успехи, переходы, суммы и выбор λ на dev. Хватит стандартной библиотеки, архив с публикацией не требуется. Все исходные числовые результаты можно просмотреть в results.json. Сохранённые предсказания содержат только ID.

Для полного повторения запустите в отдельной копии того же дерева D: следующие команды PowerShell.

~~~powershell
$refPy = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
uv pip install --python $refPy --target runtime/pylib --no-deps onnxruntime==1.23.2
& $refPy -B sources.py
& $refPy -B mmr.py
& $refPy -B rerank.py
& $refPy -B freeze.py
& $refPy -B grade.py
& $refPy -B verify.py
~~~

Использовались Python 3.12.13, NumPy 2.5.5, tokenizers и ONNX Runtime 1.23.2 CPUExecutionProvider; пять потоков внутри операции, один между операциями. Размер пакета 16, детерминированная сортировка по длине токенизированной пары, ID состояния и исходному рангу. Поля документов, форматирование и обработка длинных входов записаны в протоколе. Инференс занял около 70 секунд после подготовки входов, это вспомогательный замер. Результат квантованного инференса может зависеть от CPU и версии ONNX. Папка runtime — локальный кэш зависимостей и весов, исключена из компактного комплекта. Контрольные суммы ONNX и токенизатора сохранены в availability.json.

sources.py выполняет входящие загрузки первичных метаданных, двух публичных файлов модели и инвентаризацию архива arXiv. Статус интерактивной проверки OpenReview фиксируется как наблюдение при аудите. При изменении доступности архивов, списка веток и релизов их снимок закономерно изменится; для точного автономного повторения аналитической части сохраните подписанный availability.json и используйте соответствующие ему веса. На входе требуются memory_session5/serbench/upstream, dense_vectors.npy и dense_inputs.jsonl.gz из того же дерева, исходные приоритеты и стоимость D из graph_memory_round34/external_transfer. Повторное оценивание готовой выдачи не требует весов или векторов: grade.py использует только сертификаты и числовые данные R34. Полное пересоздание манифеста возможно через verify.py --seal и предназначено для новой версии исследования.
