Measurement notes

Counts cover result rows transferred by each reader from SQLite to Python. Each stored text digest is 32 bytes. Digest bytes exclude coordinates, headers, SQLite pages, and the separate explanatory queries used by this interface. Each answer signature hashes the ordered line and full text-digest pairs. Real issue IDs and line coordinates are retained; the text is shown only as a hash. A gap means the memory provides no retained fact for that line.
