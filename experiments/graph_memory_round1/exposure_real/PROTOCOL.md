# Observed demand for dependency/call graph tools in SWE-smith trajectories

Eligibility: the identical 4,310 shard/row IDs and SHA-256 of raw messages in the previously frozen local memory_session6/validity/exposure.jsonl.gz. Read local dataset only, never run collected commands or import third-party repository code. Source tables contain public historical shell records. Primary denominator all unique historical task trajectories; secondary denominators are successful paired shell-call/tool-feedback records and trajectories with ≥1 confirmed edit. Use the previous definition of successful edit (str_replace* editor call and success wording in the tool response). Count exposure to commands irrespective of success of the graph utility. Distinguish any after an edit from repeating after an intervening edit.

Predefined narrow graph tool family: direct executable pydeps, lint-imports, import-linter, grimp, pyreverse, modulegraph, modulegraph2, pyan, pyan3; or python[version] -m followed by pydeps, importlinter, import_linter, grimp, pyreverse, pylint.pyreverse, modulegraph, modulegraph2, pyan, pyan3 (including submodules of these). Accept absolute paths, env assignments and one ordinary invocation prefix uv run / poetry run; tokenize shell strings as data, only examine beginning of command segments divided by ordinary top-level shell separators. Exclude multiline strings, heredocs or nested shell interpreters for specificity and report how many shell calls had analyzable simple syntax. Does not detect custom scripts, Python -c imports, grep searches, IDE or implicit use of graph information.

Secondary observational proxy: simple one-line rg/grep/git grep invocation with literal/regex pattern starting with the Python keyword import or from after removal of leading caret and optional conventional leading whitespace regex. Parse -e/--regexp and ordinary bare pattern; skip ambiguous flags. Track exact repeated pattern under this normalization and whether a confirmed edit occurred since its previous use. Repeating a search for an import statement does not establish a need for a graph. Save denominators, event counts, task counts, per-repo counts, and only hashed patterns/commands and row provenance. No task selection or manual exclusions by outcomes, no human reads raw prompts.
