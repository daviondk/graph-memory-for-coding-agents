# Был ли в журнале агента явный спрос на граф импортов или вызовов

Проверены все 4 310 ранее отобранных траекторий SWE-smith из 67 репозиториев. В них 54 463 shell-вызова, для которых вызов удалось сопоставить с ответом инструмента. Однострочный парсер разобрал 54 268 из них (99,64%). **Зафиксировано 0 явных запусков инструментов из предопределённого семейства анализа графа.** Поэтому этот корпус не подтверждает частого явного использования таких CLI. По этим данным нельзя оценить, как часто агенту фактически требовалось понять зависимости.

| Наблюдение | Вызовы | Траектории |
|---|---:|---:|
| Прямой запуск отслеживаемого анализатора | 0 | 0 |
| Поиск rg/grep/git grep с шаблоном, начинающимся со слова import или from | 128 | 66 |
| Такой поиск после хотя бы одной подтверждённой правки | 65 | 27 |
| Повтор того же нормализованного поискового шаблона | 31 | 10 |
| Повтор того же шаблона с подтверждённой правкой между обращениями | 4 | 3 |

У 4 207 траекторий была хотя бы одна подтверждённая замена текста редактором. Три траектории с наблюдаемым повтором после правки составляют 0,071% этого знаменателя; исходная семантика запроса, влияние правки на результат и полезность потенциального кеширования не оценивались. Всего зарегистрировано 21 883 подтверждённых замены. Для каждой исходной траектории числа shell-вызовов и таких замен полностью совпали с ранее зафиксированной проекцией. За вызов считалась попытка обращения, включая возможность ошибки запущенного инструмента.

Детектор искал исполняемые имена pydeps, lint-imports, import-linter, grimp, pyreverse, modulegraph, modulegraph2, pyan, pyan3 и указанные в протоколе варианты python -m. Допускались простые составные shell-команды и обёртки uv run / poetry run. За пределами наблюдения остаются чтение исходников, поиск использования конкретного символа, собственные Python-скрипты, IDE/LSP, намерения модели и сложные текстовые команды. Поиск import/from специально учтён отдельно и сам по себе не запрашивает графовую достижимость.

Использованы только восемь уже имеющихся исходных Parquet на D. Для каждого проверен опубликованный LFS SHA, для каждой использованной строки — ранее сохранённый SHA текста сообщений. Строки команд разбирались как данные. Интернет, модели и выполнение команд из корпуса не использовались. Протокол и скрипт зафиксированы перед подсчётом. Индивидуальные совпадения по командам хранятся в виде хешей в `matches.jsonl.gz`, покомпонентные и порепозиторные итоги — в `results.json`. Проверка восьми сконструированных положительных и отрицательных примеров парсера прошла.
