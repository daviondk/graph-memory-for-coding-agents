# Результаты проверки свидетельств
> В двух группах проектов несколько путей подтверждали больше старых фактов без чтения исходников. Вклад исторической модели рисков был меньше вклада самих альтернатив.
Группа A содержит 12 ранее использованных репозиториев и 3 023 проверяемых запроса. Группа B содержит четыре других проекта — Black, Flask, Werkzeug и Sphinx — и 1 536 запросов. Между версиями 48 и 22 первоначально верных утверждения соответственно перестали выполняться. Они остаются в знаменателе. В столбцах быстрого подтверждения указано число записей, которые удалось безопасно переиспользовать без чтения содержимого файла после обновления.
@ 7.9 4.5 4.4
| Какие прежние пути сохранены | Быстро подтверждено в A | Быстро подтверждено в B |
| Один кратчайший | 1 070 / 3 023 | 386 / 1 536 |
| Три кратчайших | 1 204 / 3 023 | 514 / 1 536 |
| Три с учётом разных источников | 1 217 / 3 023 | 544 / 1 536 |
| Три с учётом источников и Git | 1 215 / 3 023 | 554 / 1 536 |
Определённый до расчёта контраст «с историей минус три кратчайших» по среднему для репозиториев составил +0,31 п.п. в A, интервал [0,00; +0,76], и +2,60 п.п. в B, интервал [+0,91; +3,78]. Внутри B метод с историей выиграл 44 индивидуальных запроса и проиграл 4.
Относительно выбора по разнообразию без Git результат составил −0,03 п.п. в A и +0,65 п.п. в B. В B интервал начинается с нуля. Идентичность существующей цепочки является строгим достаточным условием повторного ответа в заданном графе. Данные подсказывают, что альтернативы помогают, но добавочная ценность прошлой статистики изменений мала и неоднородна между репозиториями.
В истории Flask между e4e4bf6 и 05e9c6b кратчайшие сохранённые пути от flask.helpers до flask.cli проходили через изменённый flask.app. Цепочка через flask.wrappers, flask и flask.blueprints позволила подтвердить прежний вывод. Факт изменения сверялся с Git diff.
## Какие операции учитывались
«Не читать содержимое» допускает обращения к метаданным Git. В группе A более бережный способ с проверкой изменённых поставщиков у трёх кратчайших путей прочитал в сумме 2 886 файлов, у метода с историей 2 862. В B соответствующие величины 2 101 и 2 028. Следующее измерение отделяет логические счётчики от реальных операций чтения на диске.
