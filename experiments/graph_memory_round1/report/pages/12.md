# Сколько стоит записать и перечитать
> Дополнительные свидетельства дешевле перепроверять, но дороже добывать. Экономия на втором обращении ещё не означает экономию за весь цикл.
Операционный аудит прошёл на 156 заранее отобранных запросах из 16 репозиториев. Хеш-отбор не использовал число альтернатив или будущий исход. Старый и новый запросы выполнялись через Git в отдельных холодных прикладных кэшах. Начальный полный индекс не строился. Исходный и целевой модули были известны. Два утверждения к новому снимку перестали выполняться. Итоги совпали с независимо построенными эталонами во всех 156 случаях.

| Метод | Чтения blob при первой записи | Чтения blob при повторе | Всего за одну запись и один повтор |
| Прямой поиск без памяти | 996 | 998 | 1 994 |
| Один путь | 996 | 215 | 1 211 |
| Три кратчайших | 2 262 | 165 | 2 427 |
| Три по разнообразию | 2 993 | 164 | 3 157 |
| Три с историей Git | 2 993 | 160 | 3 153 |
Blob здесь — содержимое файла, переданное из Git. Например, исторический выбор потребовал 54,87 МБ этих данных при первой записи и 6,48 МБ при повторе. Прямой поиск — 20,69 и 20,89 МБ. Для исторического варианта дополнительно выполнено 3 493 команды сравнения прошлых изменений, возвращено 1,65 МБ списков имён. При первой записи были также прочитаны 793 объекта дерева и 156 объектов коммита, при повторе 546 и 156 соответственно. У прямого поиска — 708 и 156 при записи, 705 и 156 при повторе. Общий кэш ОС мог оставаться тёплым.
**На один повтор дешевле всего один прежний путь.** Его число прочитанных blob за весь цикл на 783 меньше прямого поиска. Три исторических дали на самом повторе ещё 55 чтений экономии против одного, но обошлись на 1 997 лишних чтений при первой записи. Для обоснования более дорогой памяти нужны реальные повторные обращения, изменение числа запросов на версию и учёт общей истории между ними.
Для трёх кратчайших дополнительные 1 266 чтений при записи против одного пути окупились бы только после 26 повторов с той же экономией 50 чтений за цикл. Это условный порог; измерялся один повтор.
