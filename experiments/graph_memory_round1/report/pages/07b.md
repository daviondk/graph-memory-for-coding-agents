# Оптимальный вес на прошлой истории
> Можно вывести вес ребра из самой метрики. Это даёт точный результат для наблюдённых коммитов и проверяемую гипотезу о следующих.
Перед изучением третьей группы зафиксировали десять репозиториев. Рассмотрим старый коммит размера m. Вероятность сообщить конкретный путь как первый известный равна 1/m. Нахождение любого из остальных файлов вносит 1/(m−1) в полноту. Поэтому вклад направленной пары при равновероятной подсказке равен произведению этих величин, то есть 1/[m(m−1)]. Суммирование таких вкладов и выбор верхних k для каждого якоря максимизирует эмпирическую полноту на старых событиях при фиксированном пуле кандидатов и неизменных правилах выдачи. Утверждение справедливо без сглаживания и без смены распределения.
Более крупные коммиты теперь сильнее подавлены. Перед сравнением доступные веса по каждому начальному файлу масштабировались до той же суммы, что и для графа 1/(m−1), затем прибавлялось одно и то же сглаживание. Так ни одна из двух систем не получает преимущества за счёт разной общей силы графового сигнала.

Из десяти закреплённых проектов девять дали оценочные события. Первичный контраст составил −0,34 п.п., интервал по репозиториям [−0,97; +0,35]. В одном проекте результат улучшился, в трёх совпал и в пяти ухудшился. Все десять репозиториев остались в перечне исходных данных. Нулевой вклад проекта без оценочных событий нельзя подставить как точность 0%.
Результат иллюстрирует границу математического объяснения. Можно вывести оптимум прошлого несглаженного функционала и всё же получить слабый прогноз на будущем.
