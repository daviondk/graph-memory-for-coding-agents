# Почему одинаковые графы дают разные ответы
> Для агента важно, какой материал дошёл до решателя. Удачный выбор вершины мало помогает, если в ней сохранилось только общее название темы.
В контролируемом исследовании Does Memory Need Graphs? авторы меняли отдельные части памяти на одних и тех же вопросах LongMemEval‑S. Для извлечения использовалась GPT‑4o-mini, для финального ответа — GPT‑4o. Когда возвращался полный исходный сеанс, графовый вариант дал 89,2% верных ответов против 76,0% у плоского. Когда возвращались только производные ключи, показатели стали 69,0% и 75,2%. Направление разницы поменялось. [Статья ACL 2026, таблицы 6–7](https://aclanthology.org/2026.acl-long.1232.pdf)

Даже в одной работе два определения значения узла приводят к разному выводу о графе. Полная запись может содержать детали для ответа, которые теряются при построении производного описания. Полученный результат также зависит от длины переданного контекста, способа выбора первых кандидатов и качества разметки. Для программного агента точное имя поля, текст исключения и версия файла могут определять, сможет ли он воспроизвести прошлое решение.
## Почему важны временные границы
Zep хранит время события и связи с источником. TAPE демонстрирует поиск в графе исторических сведений персонального агента. Для кода аналогичная проверка должна учитывать версию исходников, возможный возврат правки и момент, когда агент узнал результат. В IMCA можно отдельно менять момент истинности и границу доступного знания. Сравнивая системы, полезно дать им одни и те же исходные записи и один предел чтения, поменяв лишь допустимость ребра.
