## Как отбирались публикации
Это целевой обзор работ с реализованной памятью, графовым поиском, историей ПО и проверкой опыта агентом. Поиск шёл в arXiv, ACL Anthology, ICLR, NeurIPS и материалах IEEE. Переходили по ссылкам из ближайших работ, проверяли описания архитектур и первичные таблицы. Отдельно включены классические методы рекомендации совместных изменений и результаты об оптимизации покрытия. Для ряда свежих работ доступен статус препринта. Отбор источников не проходил двойного независимого рецензирования. Полный перечень, запросы и ограничения даны в graph_literature_ru.md.
## Что хранится в исследовательской папке
Корень — D:/CodexResearch/x20-bench-workspace/work/graph_memory_round1. В git_prediction/ хранятся контрольные суммы репозиториев, прогнозы по коммитам и отчёты переноса. В git_reader/ лежат маскированные и перемешанные варианты подсказок, ответы, версия модели, замеры токенов и журнал вызовов. В official_retrieval/ — полный граф, предсказания с объяснениями, эталоны и скрипт перепроверки по официальным Parquet.
В proofs/ находятся поштучные результаты для исходной группы и четырёх внешних проектов. В proofs/transfer/ — повтор на других репозиториях и неизменных сохранённых цепочках. В proofs/lazy/ — полная стоимость холодной записи и повторного чтения, в proofs/free/ — эксперимент с графом уже открытых из Git фактов. Все фазовые итоги сохраняются независимо от знака разницы.
## Какие выводы можно защищать
Совместное изменение файлов несёт полезный сигнал в задаче с заранее известным первым файлом. Одной близости имён в прошлых сессиях для сильного поиска оказалось недостаточно. Для ограниченной модели импортов ранее проверенное свидетельство позволяет точно пропустить часть чтений. Перенос этих результатов на автономное исправление программ потребует проверки на полном цикле. Сообщать о победе над SOTA по генерации исправлений на основании этого раунда оснований нет.
