# Графовая память кодового агента

Материалы исследовательской серии. Все исходящие решения и оценки сохранялись локально. Состояние публикационной новизны и новые мировые рекорды не установлены. Критерии правил и сравнений фиксировались в локальных файлах до соответствующих прогонов. Эти файлы не являются публичной пререгистрацией. Ориентация — работа агента после первого обращения к незнакомому коду, запись происхождения фактов, доступность прошлых действий, проверка после обновления.

Базовая структура материалов каждого запуска содержит протокол, исходники, хеши закреплённых данных и оценки для отдельных запросов. Первая и переносные панели имеют различный вес репозиториев, акторов и конечные точки. Сумма количеств задач разных экспериментов не является размером одной независимой выборки. Выходящие за пределы использованного формального определения изменения в рантайме требуют отдельной проверки.

Широкая часть исследований использовала локальные Git-объекты и закреплённые данные прошлых серий на D. В архив результатов включены код и записи прогонов. Полные Git-объекты, общие справочные корпуса прошедших серий, исполняемый рантайм и веса Qwen остаются отдельно в рабочем хранилище. Путь к входам, версия и соответствующие исходные идентификаторы указаны в протоколах. Для G3 в начале из папки proofs запускаются run.py и score.py, затем transfer/transfer.py и independent_audit.py. Полный новый просмотр проверяемого ответа из чистого локального клона описан в lazy/RESULTS_RU.md. Специальные опции при повторном запуске остальных ветвей перечислены в их собственных отчётах. По вопросам о корректности сравнения сначала проверять первичный критерий и момент доступности информации, затем происхождение baseline, бюджет чтения, фигурирующий в опыте решатель и уровень группировки ошибок.

Для методического обзора и фиксации гипотез использован программный набор Scientific Agent Skills; при докладе результаты и выводы можно проверять по подробным первичным файлам. [Описание набора](https://arxiv.org/abs/2609.00065)
