# Frozen before scoring: query-guided retrieval through observed edit anchors

2026-11-18 (workspace clock). All method configurations below are fixed before producing the rankings for this round. We have previously measured the aggregate baselines and have reused these benchmark queries in earlier research. No train/test independence or independent confirmation is claimed. There is no fitting, model call or parameter sweep. Raw predictions are frozen before scoring.

**Question.** Does an explainable reranker, using a graph of limited event-derived edit anchors, improve first retrieval on SWE-ContextBench Related Lite's public 99 queries and complete static 300-session library? Prior event cards record paths targeted by a write and identifiers in its replacement payload. An edge records historical editing activity, not static code dependence or proof that the identifier was declared or executed. Card caps and masking exactly as earlier (up to 85 edit-field words per history). Remove harness/log paths and strings with digits, dunder symbols and bookkeeping words; path nodes are the lowercase filename and kept as a separate role. Identifier nodes require underscore or camel case. Query membership uses exact identifier or filename; no model, regex target IDs, project label, target patch, answer, relation, or curated list of examples.

**Arms.** Keep a frozen top ten shortlist from each first stage and score every candidate at original rank r. Build a bipartite historical session -- anchor graph over the permitted pool. For entity e with document frequency df and N sessions define w=log((N+1)/(df+1)). Direct A is the sum of weights of a session's exact query anchors; divide by the maximum among the ten candidates (zero if absent). Neighbor support B is the sum of weighted Jaccard similarities with distinct sessions among the first five of the baseline, weighted by 1/r for the peer, excluding self; divide by the maximum on that shortlist. This is an untrained local agreement prior. Primary reranker: -log(r) + log(3)*(0.65*A + 0.35*B); ties use original rank. Normalization lets a rare shared edit move an item up by a limited factor and provides a readable explanation. May hurt if candidates share boilerplate, a legitimate target is isolated, or weak anchors become inflated by max normalization. A and B are heuristic evidence scores, not calibrated probabilities. Compare baseline, A-only, B-only and a degree-preserving document relabeling (bijection; cyclic shift after SHA-256 sort of allowed keys) feeding the same combined rule. Do not select a winning arm after scoring.

**Tests.** Primary is combined vs fixed fusion on all 99 static Lite queries at Match@1 (success if any public labeled source ID in first place). Compare the same arm to direct-only to isolate graph neighbor gain. Secondary applies identical reranking to archived upstream Recall hybrid top tens for the same 99, and to the 258 previously seen non-Lite queries using the same restricted 300-session library. Non-Lite is a transfer diagnostic, not the complete official experience library. A temporal diagnostic starts from frozen online_fields BM25 ranked solely on earlier same-repository merged candidate histories for the 99 Lite, estimates graph weights independently inside each permitted pool, and reports all 99 and queries with an available reference. Empty pools score zero. Published static benchmark permits future-completed histories. All rerankers have the same cards, top-ten ceilings and read budget as their corresponding control. Reuse precomputed search ranks, including the earlier project fusion baseline (BM25 + Contriever) and upstream Recall ranking with its native query preprocessing. For perspective give frozen reader baseline separately, never as a matched test of our local reranker.

**Reports.** Retain all per-item ranks and top-choice feature contributions, permitted pool fingerprint, run metadata, graph inventory, source/prediction hashes, and input and outcome file separation. Report Hit@1/5/10, truncated MRR@10, wins/losses and cluster bootstrap intervals (10,000 repo resamples seed 20261118) for paired absolute Hit@1; exact paired sign test on discordant tasks descriptive. Report how often a selection changed and how often the eligible shortlist had a query-anchor witness. A null, a tie or degradation is a result. Do not claim solving code tasks, time valid writing for static mode, or new SOTA. A historical merge time is a proxy for eligibility, not evidence of when an agent actually saw the trajectory.
