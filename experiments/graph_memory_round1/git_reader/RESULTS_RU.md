# Читает ли локальная Qwen связи графа изменений

На 24 задачах с десяти репозиториев Qwen3.8-27B выбрала подходящий файл 11 раз с верными весами связей, 7 раз со скрытыми весами и 1 раз с перепутанными весами. Детерминированный граф без модели тоже дал 11 правильных ответов. Данные показывают чувствительность модели к тому, как свидетельства привязаны к именам файлов. Уверенной прибавки качества от показа правильных чисел по сравнению с их сокрытием в этой выборке не установлено.

## Что именно делали

Репозитории загружены отдельно от первой серии G1. Для каждого события раскрыт один файл, действительно затронутый историческим коммитом. Цель — выбрать любой другой затронутый файл. Восемь кандидатов отбираются по истории предшествующих коммитов. Для каждого показаны путь и число прошлых изменений. В одном режиме добавлены число совместных изменений с якорем и дробный вес связи. Второй режим скрывает эти поля. В третьем те же две колонки циклически переставлены между именами. Наполнение слейта уже использует граф для всех ветвей; проверяется только добавочный эффект показанных весов.

Отобраны 24 коммита хешированием и чередованием репозиториев, без отбора по присутствию правильного ответа или исходам модели. При отборе проверяли обычный инженерный характер задач, наличие восьми кандидатов и разных весов, чтобы перестановка имела смысл. В каждой из трёх ветвей одна и та же задача, порядок восьми путей и контекст. Коммит и список остальных изменённых файлов используются только для формирования примера и оценивания. Модель получила только путь-якорь и краткую таблицу. Предыдущая серия работала на других SHA. Протокол, выборка и хеши запросов зафиксированы до вызовов модели.

Только 18 списков из 24 вообще содержали верный ответ. Каждая тройка прогонов использовала локальную Qwen3.8-27B UD-Q4_K_M на NVIDIA GeForce RTX 3090 через llama.cpp b12441, seed 18112026, temperature 0, отключённое размышление, лимит 8 выходных токенов. Состояние разговора между запросами не переносилось. Обработано 72 отдельных ответа, все корректны по формату, повторов HTTP и кешированных входных токенов — 0. Времена — локальные суммы HTTP-вызовов без загрузки модели, с точностью до сотых.

## Парные различия

В основной паре «верные / переставленные» верные данные дали 10 индивидуальных выигрышей, 0 поражений, 14 ничьих. Модель изменила выбор в 22 случаях. Разница составила 41,67 п.п., двусторонний точный тест Мак-Немара по событиям p=0,00195. События внутри репозитория зависимы. Дополнительно переставили подписи режимов совместно во всех событиях каждого из десяти репозиториев (все 1024 знаковых перестановки). Шесть репозиториев дали положительную разницу, четыре — нулевую, двустороннее p=0,03125.

В паре «верные / скрытые» 4 выигрыша, 0 поражений, 20 ничьих. Выбор изменился в 11 случаях, разница 16,67 п.п., p=0,125 по событиям и 0,25 при перестановке внутри целых репозиториев. Перестановки — проверка чувствительности при предположении обменности меток. Сравнение с намеренно нарушенной той же таблицей не является сравнением с лучшей известной памятью. В шести эпизодах никакой выбор из слейта не мог решить задачу.

## Проверка и ограничения

Файлы `PROTOCOL.md`, `freeze.json`, `selection_receipt.json`, `selection.json`, `requests.jsonl`, `responses.jsonl` хранят дизайн, отбор, точные запросы и полные сырые ответы. `results.json` содержит исход по каждому SHA. Команда `python score.py` заново сверяет запросы с исходными данными и хешами, затем пересчитывает результаты. Реквизиты весов и сервера находятся в `model_receipt.json` и `runtime_receipt.json`; параметры запуска и подтверждение завершения выделенного локального процесса записаны в `launch.json` и `stopped.json`.

Измеряли локализацию при уже известном первом файле и информативном графе. Исследование не проверяет первичный поиск, сборку программ, использование пояснений в длинной траектории или прохождение тестов после фактического исправления. Публичные репозитории могли быть знакомы модели; все три ветви имели один и тот же решатель, слейт и порядок. Выгоднее для проверки решателя на следующем этапе сначала подтвердить выигрыш над детерминированным графом в независимых задачах.
