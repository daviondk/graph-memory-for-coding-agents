# Почему вес является оптимальным на прошлых событиях и не выигрывает на следующих

На девяти новых репозиториях и 437 отложенных коммитах формально выведенная поправка дала **47,05%** средней по проектам Recall@5. Нормированный граф без поправки дал **47,39%**. Разница −0,34 п.п., парный 95% бутстрэп по проектам [−0,97; +0,35] п.п. Выигрыш наблюдался на одном репозитории, равенство на трёх и снижение на пяти. Основная эмпирическая гипотеза G1c не подтвердилась.

## Вывод

В каждом историческом событии S_t размера m_t сначала равновероятно раскрывается один якорь a. Остальные m_t−1 элементов — цели. Для каждого якоря заранее выбирается список K(a) из не более чем k путей. При фиксированном множестве допустимых кандидатов средняя историческая награда за T равноценных событий составляет

$$
\frac1T\sum_t \frac1{m_t}\sum_{a\in S_t}
\frac1{m_t-1}\sum_{y\in S_t\setminus\{a\}}\mathbf 1\{y\in K(a)\}
= \frac1T\sum_a\sum_{y\in K(a)}\sum_{t:\,a,y\in S_t,\,y\ne a}\frac1{m_t(m_t-1)}.
$$

Отсюда результат по обмену: если в K(a) есть кандидат с меньшей внутренней суммой, чем у оставленного за списком кандидата, их обмен не уменьшает награду. Выбирая k максимальных весов для каждого якоря, получаем точный максимум этого эмпирического критерия. Это утверждение относится к усреднению *по всем возможным раскрытиям* якоря в старых событиях. В реализации для оценки будущего события имеется ровно один псевдослучайный якорь. Период работы системы, её кандидаты и набор последующих изменений отличаются от фиксированного обучающего множества. Сглаживание добавляет априорную информацию и тоже меняет оптимизируемую величину.

Для честного теста изменили только распределение веса соседей. Обе политики для данного якоря имели одинаковый доступный суммарный вес исторических наблюдений, один и тот же prior путей, одинаковые входные данные и ограничение в пять кандидатов. Иначе новый масштаб незаметно усилил бы или ослабил влияние prior. 1/[m(m−1)] формализует вероятность увидеть якорь и долю каждого оставшегося файла в награде. Отдельного доказательства мирового приоритета этой поправки нет.

Девять локальных shallow-копий полны для заявленного вычисления; десятый адрес pypa/cachecontrol не отдал публичную ссылку на HEAD при анонимной проверке. Получение остановлено, недоступный проект не заменяли. Анализ прошёл по локальным копиям без дальнейших сетевых обращений. В девяти историях использовано 2329 переходов первой родительской линии, 476 пригодных задач разминки. Средний по репозиториям потолок полноты с доступными путями — 88,29%. Сходство путей дало 35,88%, сырой граф 47,06%, фиксированная смесь 47,79%, ранее предложенная адаптивная смесь 48,07%. Последние цифры — вторичные; по ним не менялся объявленный контраст.
