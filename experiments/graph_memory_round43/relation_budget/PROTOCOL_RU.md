# Какой тип связи стоит поддерживать в памяти

В эксперименте R42 вклад дали межсобытийные признаки. Проверяем, можно ли хранить и считать только один вид зависимостей. Выбор гипотезы основан на уже известном результате R42; те же тестовые траектории не считаем независимым подтверждением. Для каждого вида связь направлена. FEEDS обозначает перенос значения между событиями, RESOURCE_FLOW — связь через ресурс по определению эталонного построителя графа. Основной контраст до просмотра новых исходов — модель только с FEEDS против модели только с RESOURCE_FLOW по Full Support@2048, двусторонний парный 95% интервал. Важны также сравнения с обоими классами рёбер и вообще без межсобытийных отношений. Если более дешёвый одиночный класс сохраняет качество, критерий неуступания относительно обоих типов — нижняя граница ≥ −1,00 п.п. для заранее названного FEEDS-only. Дешевизна — отдельное эмпирическое утверждение, по одной лишь размерности её не устанавливаем.

Повторяем протокол R42 целиком. Из 3 894 обучающих вопросов в физически усечённой истории подходят 1 966 с положительными и отрицательными кандидатами. Всем моделям доступны 15 метаданных и 4 семантических признака. Оба направления и внутри-ролевые процентили каждого разрешённого отношения. Контроли — бинарное наличие любого соответствующего соседа вместо степени и числа связанных фрагментов, а также два типа вместе и полное отсутствие межсобытийных признаков. Фиксируем те же веса, HGB, гиперпараметры и разрешение равных оценок. Не меняем пороги и не оптимизируем тест. Одна главная панель 901/657, пять общих семян, одинаковые выводимые токены (одинаковый потолок, фактический расход сообщается), 10 000 перекрёстных бутстреп-повторов. Сохраняем все поштучные ответы, подтверждаем baseline по цепочке SHA-256 и полные наборы предыдущего опыта. Число строк, где класс даёт ненулевой сигнал, характеризует распространённость; не заменяет измерение затрат на весь граф.
