# Воспроизведение

Самодостаточная проверка пяти разбиений по целым репозиториям, выходных рангов и верхней границы требует только стандартной библиотеки Python 3.11+.

```powershell
python -B verify.py
```

Для нового полного расчёта необходимы подписанные R37–R42, NumPy и scikit-learn. features.py не загружает будущие запросы. labels.py создаёт пять отдельных файлов супервизии. run_folds.py запускает чистый Python-процесс для каждого репозитория; rank.py открывает только четыре других файла меток. После записи всех пяти файлов с прогнозами grade.py присоединяет фактическое расписание будущих запросов из R42/future_reads. verify.py проверяет непересечение всех ID, ограничения вместимости и строит второй точный решатель с разреженной таблицей затрат для максимума при известном будущем.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B features.py
& $runner -B labels.py
& $runner -B run_folds.py
& $runner -B grade.py
& $runner -B analyze.py
& $runner -B verify.py
```

Обучение выполнялось на CPU. Полные имена репозиториев не требуются, разбиение задают необратимые идентификаторы. В файлах seal для каждого fold записаны размеры и хеши каждой из четырёх обучающих частей, параметры стандартизации и все коэффициенты модели. Признаки строк не включают будущий запрос, итог задания или идентификаторы репозитория.
