# Воспроизведение

Проверка подписанного архива, дублирования сведений с квитанциями, равенства всех 40 440 поштучных выдач их соответствующему базовому пакету и основных агрегатов использует стандартный Python 3.11+.

```powershell
python -B verify.py
```

Полный расчёт требует локального комплекта Handoff Debt, PyArrow, NumPy и подписанных входов R37–R43. Оригинальный update_literal загружается из memory_session5/packets/common.py. Публикация кандидатов проходит только на белом списке полей — содержимом прежнего видимого запроса, тексте аргументов действия и видимом ответе редактора. Ранжирование не использует будущие чтения. grade.py после фиксации прогнозов загружает полную версию затронутого файла для сверки и подписанные будущие окна для оценки спроса. Файлы корпуса и команды редактирования в этом эксперименте не исполняются.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B predict.py
& $runner -B grade.py
& $runner -B analyze.py
& $runner -B verify.py
```

В архиве остаются координаты, хеши буквального текста, размеры, тип доступности и счётчики. При переносе изменить корень локального корпуса в shared.py. Времена отдельного повтора могут меняться.
