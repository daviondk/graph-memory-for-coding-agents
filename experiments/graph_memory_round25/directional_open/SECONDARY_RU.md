# Дополнительная проверка фактической цены двухстороннего чтения

После получения агрегированных результатов у 128+128 выше число полных покрытий на трёх корпусах. Фиксируем последующий симметричный контроль. Для пар both/right и both/feasible-left обрезаем ответы до одного и того же фактического количества WordPiece по каждому вопросу, полностью пересчитывая обе уже выбранные стороны с их настоящими заголовками. Проверяем воспроизведение сохранённых исходов при капе 256. Печатаем исходные пары и равнозатратные варианты, число выигрышей и потерь, парные ДИ и точный тест на уровне исходного кластера. Это дополнительное сравнение с учётом уже известных результатов. Считать его первичной проверкой в будущей публикации можно будет после независимого подтверждения.
