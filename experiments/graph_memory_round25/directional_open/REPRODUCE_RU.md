# Воспроизведение

`./run.ps1` проверяет исходные хеши и запускает недостающие стадии последовательно на CPU. Предыдущие стадии R23 и R24 должны лежать в том же рабочем каталоге. Для ISETrace и MultiDoc2Dial нужны локальные приватные кэши исходных полей, зависящие от окружения. Для SQuAD скачайте официальный `dev-v1.1.json` в `D:/CodexResearch/x20-r25-squad/`. Сценарий проверяет SHA-256 исходника 95aa6a52d5d6a735563366753ca50492a658031da74f301ac5238b03966972c9. Текст датасета в отчёте и архиве не дублируется. [Официальный файл](https://rajpurkar.github.io/SQuAD-explorer/dataset/dev-v1.1.json)

`freeze.py` сверяет план с предшествующими квитанциями. `dataset.py select` выбирает адрес и направление по видимой памяти, `dataset.py run` обращается к полю и сохраняет диапазоны/стоимость. При использовании SQuAD проекция читает из официального JSON только ID и вопросы при выборе и текст абзацев при построении общей исходной выдачи. Список допустимых ответов впервые используется через `analyse.targets` после фиксации решений. `analyse.py` считает показатели, `secondary.py` проводит отдельно помеченную дополнительную парную проверку цен. `audit25.py` пересчитывает результат другим sweep-алгоритмом, заново декодирует текст каждого уникального ответа из настоящего источника и проверяет цену индивидуальных и объединённых заголовков. Перезапуск на проверенной машине воспроизводит хеши всех результатов. В файлах opened длина и адрес заголовка у каждого диапазона записаны явно.
