# Что меняет проекция первого вопроса для следующего действия

До оценки итогов смены вопроса фиксируем вторичный исход. Сохранилась адресованная память, которую выбрал первый вопрос. При втором вопросе в той же истории сравним лучший адрес точного BM25, приближённую проекцию только на старые слова, самый первый расширяемый участок и адрес, который предпочитал прежний вопрос. Все открывают продолжение соответствующего участка до 256 WordPiece с заголовком, используя одну и ту же исходную геометрию; прошлые ответы остаются в памяти. На ISETrace проверим полное покрытие исходных символьных интервалов разметки второго вопроса. На SQuAD успех означает покрытие хотя бы одного полного официального диапазона ответа в известной статье. Отдельно зафиксируем расходы и число изменённых адресов. Проверка диагностирует полезность точного выбора по сравнению с дешёвыми приближениями; она не подразумевает, что BM25 оптимален, или что LLM даст правильный ответ.
