# Воспроизведение смены запроса

Нужны Python с NumPy и tokenizers, подготовленные публичные ISETrace и SQuAD v1.1, одинаковая версия BERT WordPiece и материалы `directional_open` этого раунда, а также исходные скрипты раундов 23–24. Привязки к локальным данным перечислены в `directional_open/dataset.py` и импортируемых там модулях. Для сверки записанных исходов на автономном снимке достаточно стандартной библиотеки и `python -B ../verify.py`, запущенного из этой директории.

На копии эксперимента выполните последовательно:

```powershell
python -B make_fixture.py
python -B evaluate.py
python -B summarize.py
python -B outcome_read.py
python -B hydrate.py
python -B term_index.py
```

Первый скрипт пишет отдельную SQLite-базу на D. Тексты, необходимые для воспроизведения, получаются из исходных корпусов. Архив включает индивидуальные решения, координаты, стоимость доступа и времена. При изменении порядка исходных строк нужно проверить хеши когорты и подготовленной базы. Повтор измерения времени создаёт собственные квитанции и изменяет хеш соответствующего журнала. Размер SQL-ответа и выбранное окно при том же входе детерминированы. Для независимого контроля ранжирования и интервалов см. соседнюю директорию `release_audit`.
