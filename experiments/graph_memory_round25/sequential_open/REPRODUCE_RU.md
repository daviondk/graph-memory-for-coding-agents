# Воспроизведение

После подготовки серий 23 и 24 выполнить `python -B collect.py`, `python -B score_sequences.py`, `python -B strata.py`. Схема collect.py допускает к планировщику только уже видимые тексты, длины полей и историю собственных обращений. Исходный текст подгружается делегированным вызовом после решения о координате. Все четыре действия хранятся в квитанциях, отдельно приводятся префикс до 768 токенов и пары с одинаковым фактическим расходом. Скрипт оценки присоединяет размеченные интервалы после публикации хешей предсказаний. Для диагностики исходной доступности используется пакет attainable_open.
