# Перенос протокола чтения на другую настоящую задачу

До получения патчей выбран первый пригодный объект независимого реестра target_screen — PyBaMM-4267. На предыдущем traitlets все три метода решили задачу. Здесь проверяем те же три условия при тех же пределах 8 / 18 действий: общий разведочный просмотр, затем пустой контекст, конец журнала или выбранные наблюдения со ссылками на показанные строки. Весь промежуточный контекст одинаково ограничен 1 600 байтами, две непустые передачи используют одинаковое фактическое число байтов с точностью до одного символа UTF-8. Оригинальный публичный текст и чистый исходный коммит одинаковы для всех. Учёт выполненных действий теперь сериализован межпроцессной блокировкой. Каждая копия исходника самостоятельна. Доступ к исходным открытым тестам даёт шлюз. Итоговый оценщик добавляет к другой, чистой копии официальный тестовый патч и проверяет 1 F2P и 7 P2P. Исходная версия даёт 0/1 + 7/7, авторское исправление 1/1 + 7/7. Результат определяется закрытыми от исполнителя тестами по заранее названным ID и через две независимые формы разбора логов. После заморозки всех трёх патчей проводим последовательное внешнее оценивание.

До первого решателя фиксируем пакет адресных карточек и равновеликую хронологическую выдачу. Модель и настройки наследуются от одного окружения Codex, точный снимок сервиса скрыт. Все исполнители запускаются с пустой историей. Будущие решения, тестовая правка и исполнители других условий исключены из контекста. Дополнительно указываем число действий, байты поиска и чтений, размер исправления, стоимость передачи. Это ещё одна задача с одной реализацией на условие, не оценка полного бенчмарка. Появление одинаковых результатов будет сохранено. Протокол предыдущей задачи и предварительный отбор текущего объекта хранятся отдельно.
