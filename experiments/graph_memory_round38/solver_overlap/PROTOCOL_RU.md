# Повторное чтение кода после передачи наблюдений

Это диагностический разбор одной ранее оценённой задачи. До подсчёта пересечений известны исход 3/3 проходящих патчей и общий объём обращений. Учитываем только поиск и чтение до первого успешно применённого изменения каждого агента, чтобы все строки относились к одному зафиксированному коммиту. Строка идентифицируется путём, номером и точным содержимым. Сравним уникальные просмотренные строки, повторные показы одной строки внутри собственной сессии, пересечение с просмотренным общим исследователем и с полным текстом реально переданного пакета. Для адресных карточек отдельно считаем строки, на которые в них достаточно точно сослались, даже если текст в пакет не вошёл. Пустой пакет имеет нулевое пересечение по определению. Для оценки формы записанного патча считаем покрытие разведанными и переданными строками; чистая вставка представляется соседней строкой-якорем. Это проверка состава наблюдений и возможного повторного поиска; по ней нельзя установить, какие токены использовала модель в рассуждении. Различия длины в токенах оцениваем при наличии локального стандартного токенизатора, отдельно от фактического учёта сервиса Codex.
