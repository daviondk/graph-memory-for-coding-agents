# Детали до открытия эталонов

Для повторяемости при равном расстоянии выбирается меньший номер. В head и tail нумерация применяется ко всем реально показанным строкам. Центр считается по крайним номерам диапазона, включая возможные пропуски. Focus при отсутствии пересечения использует центр нового диапазона. Grid обходит дерево интервалов в ширину, делит каждый интервал по нижней середине и обходит сначала левую половину. Отсутствующий в показе номер ничего не сохраняет.

Новое наблюдение заменяет прежнее по адресу. Когда текст совпадает, ранее установленный признак перевода строки можно сохранить. У каждой оставленной строки есть единственный свидетель из одного реального ответа. При бюджете в байтах перебираются сначала новые строки в порядке приоритета, затем оставшиеся старые в их прежнем порядке. Строка, которая уже не помещается, пропускается, и перебор продолжается. Путь последнего просмотра и его крайние номера переживают инвалидацию конкретного пути, а общий разрыв очищает также эти метаданные.

В файле прогнозов кэш сериализуется как список ссылок на наблюдения. В каждом прогоне ссылки нумеруются с нуля в хронологическом порядке, внутри просмотра по номеру строки. Такая запись позволяет аудитору проверить источник каждого факта и восстановить его модельный объём. Индексы и хеши относятся к журналу доказательств. Доступная политике рабочая память состоит из её ограниченного кэша с порядком приоритета и границ предыдущего просмотра. Политики обрабатывают показанные строки по запросу, с временным рабочим пространством на время одного ответа.

Полное покрытие и средняя доля удостоверенных строк считаются на каждой операции. Первичная разность сначала усредняется по прогонам данного issue, потом по всем представленным issue с одинаковым весом. Перцентильный интервал строится пересэмплированием issue в отсортированном порядке, генератор Python random.Random, 10 000 повторов с seed 380671, линейная интерполяция на уровнях 0,025 и 0,975.
