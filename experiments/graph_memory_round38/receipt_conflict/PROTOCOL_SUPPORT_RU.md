# Дополнительная проверка положительных свидетелей

После основного результата (1 конфликт, 0 из 83 ошибок с видимым конфликтом) проверяем обратное, более консервативное правило. Эффект новых правил на выборке ещё не считался. Анализ разведочный, проводится на той же панели. Разбиваем старые факты каждой стороны по расстоянию до ближайшего подтверждённого квитанцией равного хеша на этой стороне. Предусмотрены взаимоисключающие группы: нет подтверждения на стороне, 1–2 строки, 3–8, 9–32, дальше 32. Границы фиксируем заранее. При неизменной квитанции проверяется сохранение только перенесённых фактов на стороне с любым подтверждением; варианты с расстоянием ≤32, ≤8 и ≤2 служат чувствительностью. Точное повторное свидетельство в момент записи относится только к его собственной строке; ближайшим соседям не приписываем гарантии правильности. Факты квитанции сохраняются во всех условиях.

Для каждой политики считаем снятые проверенные ошибки и утраченные верные факты, а также разность с условным ожиданием случайного снятия ровно того же количества старых слотов в каждом эпизоде. Доверительные интервалы для разностей покрытия и доли неверных адресов — парная перевыборка задач. Доля неверных адресов использует тот же знаменатель видимых строк, что и покрытие. Указанные интервалы не снимают ограничений повторного использования данных. Источник всех признаков — запечатанные прогнозы, содержащие только доступные до следующего просмотра адреса и сравнения.
