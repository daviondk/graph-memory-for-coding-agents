# Воспроизведение

В рабочей копии на одном уровне должны находиться graph_memory_round37 и graph_memory_round38. Для перерасчёта политики нужны R37/code_store и R37/code_visibility, для отчётных интервалов — NumPy. Сами команды архива не выполняются.

```powershell
python -B predict.py
python -B score.py
python -B support.py forecast
python -B support.py score
python -B verify.py
```

Скрипт predict.py проверяет контрольную сумму исходного контейнера, читает только прошлые адреса и ответ редактора и запускает синтетические проверки. Скрипт score.py проверяет контрольную сумму прогнозов, сверяет все адреса T с подписанным независимым контролем и только после этого открывает следующее чтение. В support.py два этапа также разделены. Для автономной сверки поставленного комплекта достаточно Python и команды `python -B verify.py`; она проверяет хеши, переформулирует условия отзыва и перепроверяет итоговые числа по записям отдельных эпизодов.
