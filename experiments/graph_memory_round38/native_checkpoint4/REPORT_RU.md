# Четвёртая общая инициализация штатных графовых моделей ISETrace

На seed 37 бюджетный читатель R35 достиг **80,45%** полного покрытия при 2 048 токенах. Полный штатный R-GCN получил **79,00%**, отдельно обученная версия без смежности фрагментов — **79,85%**. Сравниваются одни и те же 2 000 вопросов из 1 207 траекторий, одна и та же реализация плотного ранжирования и штатная оценка покрытия исходных интервалов. Парные разности R35 составили **+1,45 п.п. [−0,15; 3,05]** и **+0,60 п.п. [−0,97; 2,13]**. Оба интервала по траекториям включают ноль. [Числа по методам и всем метрикам](canonical-just-37.json) · [Исходы по вопросам](canonical-37.json.gz)

Нативные результаты этого seed появились после фиксации метода и протокола проверки на двух дополнительных инициализациях. Оба точечных разрыва меньше среднего по первым трём. На MRR, где качество определяется первым подходящим узлом, R35 имеет 0,6149, полный R-GCN — 0,6340, версия без смежности — 0,6310. Победителя по всем метрикам на этом основании выбрать нельзя. Это снимок одного прогона; окончательное сравнение по двум дополнительным и всем пяти инициализациям и результат смены правила выбора эпохи ведутся отдельно.
