# Воспроизведение

В дереве соседних серий R17–R20 с подготовленными исходниками ISETrace и средой Python из R19 выполните `python update.py`, затем из каталога серии `python assess.py online_update`. Первый этап проверяет базовый архив и поштучные выдачи на совпадение с R19, второй сверяет все восемь хешей прогнозов до оценки. В источниках должны совпасть исходный frozen writer, 1 207 проекций и авторский токенизатор. Все результаты зафиксированы по отдельным вопросам и исходным траекториям.
