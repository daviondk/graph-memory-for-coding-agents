# Отложенный перенос структурного prior

До готовности 80 дополнительных плотных рангов и их оценок фиксируем применение ранее обученного факторизованного prior к 80 вопросам вне авторских dev500. Здесь нет ни одной обучающей траектории обоих компонентов, все они отнесены к разбиению original train. Сравниваем целый префикс и skip по той же формуле с Dense-FT, в том числе только восемь степеней и только форма. Главная пара — факторизованная модель с калибровкой hash64 против Dense-FT для полного свидетельства при 2 048. Анализ availability выполняется отдельно. Нативные графы исходного dev восстанавливаются из исходных траекторий. Хеши, ранги, старые веса и все предсказания проверяются до открытия разметки. При 80 вопросах ожидается широкий интервал.
