# Полный набор метрик опубликованного сравнения

Для уже зафиксированного основного hash64-читателя оцениваем все шесть столбцов таблицы 2 ISETrace и дополнительно нормированную площадь под кривой Coverage и Full Support по шести нативным бюджетам. Full Support@2048 и Coverage@2048 на основном test уже известны. Эти метрики диагностируют, сохраняется ли выигрыш при малом бюджете и улучшается ли позиция первого нужного фрагмента. Дополнительные 80 вопросов открываются только после фиксации прогнозов. Три заранее заданных варианта — исходный Dense-FT, полный факторизованный prior, prior только по типизированным степеням. Если доступны полные нативные перезапуски R-GCN, показываем их как отдельный соответствующий режим, с размером обучающей выборки и seed.

Используем официальные span_metrics_under_token_budget, span_metrics_at, span_mrr и normalized_budget_auc с бюджетами 256, 512, 1024, 2048, 4096, 8192. Recall@5 в данной системе — доля покрытых символов эталонного свидетельства первыми пятью узлами. MRR — обратный ранг первого пересекающегося с разметкой узла. Бюджеты используют строгий префикс. Основной Dense по шести столбцам сверяем с каждой строкой ранее рассчитанного эталона. Парные интервалы считаем по траекториям для всех показателей и обеих поправок; эти вторичные интерпретации разведены с первичным Full Support@2048 в основном протоколе. Опубликованные результаты пяти seed дают описательный ориентир. [ISETrace, табл. 2](https://arxiv.org/html/2609.25913v3#S7.T2)
