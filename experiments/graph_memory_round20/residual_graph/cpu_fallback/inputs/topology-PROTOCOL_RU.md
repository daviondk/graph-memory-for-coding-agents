# Изменение рёбер во время чтения памяти

Вторичный анализ задан до обучения и точных исходов Residual R-GCN. В 2 000 test-запросах фиксируются checkpoint, запрос, исходные 768-мерные embeddings каждого узла, seed-сходства, физические кандидаты, их текст, метаданные и нативный порядок учёта токенов. Проверяется, насколько фактическая топология нужна уже обученному читателю. Выборка и контрольные условия назначены до анализа поштучных результатов.

Основной контраст этого дополнения — неизменённый trained residual против той же сети с авторским degree_preserving_random_v1, topology seed 13. Вторая интервенция подаёт пустое множество сообщений во все три слоя и сохраняет обученный собственный переход каждого узла, scorer и residual. Для обеих сравниваем prefix Full Support@2048, 95% парный бутстреп по траекториям (10 000, seed13). Coverage, F1, расход и сдвиг позиции кандидатов — диагностика. Для нулевых и неизменённых топологий знаменатель включает все запросы. Нулевой граф проверяет замороженную сеть вне распределения обучения. Работа не повторяет абляции, в которых каждый вариант заново обучался. Поэтому измеряется зависимость фиксированной функции чтения от поданного графа. Пара сравнивается с одним исходным checkpoint; перенос на все seed ограничен.

Перед прогнозированием сверяются точные физические узлы, число и типы связей, incoming и outgoing multiset для каждого узла и каждой связи, порядок тензоров, доля действительно заменённых уникальных направленных рёбер и число траекторий с идентичным множеством рёбер. Все test-ранги запечатываются до присоединения разметки этого дополнения. Топологии являются данными; команды из записей не выполняются.
