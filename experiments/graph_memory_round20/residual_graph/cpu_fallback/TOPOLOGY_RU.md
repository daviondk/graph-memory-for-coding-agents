# Внешний по отношению к весам контроль связей на малой train-панели

Дополнение планируется до открытия тестовых исходов уменьшенной панели. Для заранее выбранной по хешу hash64 применяем ранее зафиксированные вмешательства ROOT/topology на всех исходных 2 000 test-запросах. Веса hash64, входные seed similarity, node embeddings, кандидаты и все их координаты фиксированы. Переставленные бэкендом random_edges связи сохраняют все типоспецифичные направленные степени, пустое финальное множество сообщений оставляет собственное преобразование узла. В обоих случаях считаем Full Support@2048 у фиксированного native prefix; сравнение парное с тем же исходным hash64 на GPU-независимой CPU-реализации. Резервная выборка availability в эту дополнительную проверку не входит. Панель hash64 назначена независимо от результатов; подменять ей заявленное full-train вмешательство нельзя.
