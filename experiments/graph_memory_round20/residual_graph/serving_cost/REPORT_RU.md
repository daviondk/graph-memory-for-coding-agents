# Стоимость чтения после общего Dense-FT на CPU

Две политики получают один фактический FP32 cosine для каждого кандидата из подготовленного нативного батча. Считали время до одного и того же типа результата — полный порядок ID кандидатов и набор ID, помещающийся в 2 048 токенов strict prefix. В каждый замер входит сортировка и упаковка. Для R-GCN до этой точки уже собран батч размером один. Для rank + degree уже вычислен скаляр приоритета на каждый кандидат. Локальная машина обслуживала фоновые задачи; порядок двух путей чередовался по вопросу и повтору. [Протокол](PROTOCOL_RU.md)

| Обучение R-GCN | Метод | p50, мс | p95, мс | Среднее, мс |
|---|---|---:|---:|---:|
| hash64 | Ранг и степени | 0,062 | 0,114 | 0,069 |
| hash64 | Нативный R-GCN | 7,538 | 17,547 | 8,764 |
| full | Ранг и степени | 0,071 | 0,127 | 0,078 |
| full | Нативный R-GCN | 8,769 | 19,954 | 10,289 |

**hash64.** Отношение средних задержек rank + degree к R-GCN — 0,00786 [95% ДИ 0,00765; 0,00808]. Обратное отношение равно 127,2. Сначала бралась медиана восьми измерений на каждый запрос, затем одинаковый вес получал каждый запрос.

На 94 уникальных траекториях разовая компиляция структурного приоритета заняла 38,60 мс суммарно. Привязка этого массива к порядку кандидатов всех 96 запросов заняла 2,03 мс. Материализация нативных числовых тензоров для этих запросов заняла 1051,17 мс, отдельная сборка батчей — 31,10 мс. Эти объёмы относятся к разным стадиям и числу обращений. Они не входят в предшествующую таблицу.

Исходные сжатые проекции на диске занимают 4,407,411 байт. FP32-входы узлов имеют 57,569,280 числовых байт до межтраекторной дедупликации, FP32-векторы запросов — 294,912. Компактный массив одного float64 приоритета на PU занимает 97,568 байт. Если хранить восемь int32 вместо скаляра, массив занимает 390,272 байт. Эти величины исключают ID и служебные накладные расходы БД. Коэффициенты ранга и степеней имеют 104 байта численного payload. Сериализованный обученный checkpoint R-GCN имеет 13,402,018 байт, включая метаданные. Масса E5 общая и не входит в оба числа.

Один и тот же cosine-вектор использовался на двух путях для каждого из 96 запросов. Внешний автономный Dense-FT полностью совпал с ранжированием по этим нативным числам в 93 случаях. Проверка prefix с ранее запечатанными независимыми рангами даёт 95/96 у степеней и 96/96 у R-GCN. Максимальное отклонение нативных оценок от пакетной выгрузки — 2.98e-08. Время интерпретации запроса, кодирования E5, доступа к БД и генерации ответа в онлайновый интервал не входит. Числа описывают только добавочный локальный этап после получения семантического сигнала; влияние на полную задержку зависит от доли этого этапа. Для воспроизведения на тех же данных: `python -B bench.py hash64` или `python -B bench.py full`, затем `python -B report.py`. Последняя команда отдельно проверяет арифметику поштучных измерений готового пакета средствами стандартной библиотеки.
