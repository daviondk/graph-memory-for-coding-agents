# Число событий в эталонной опоре

До нового графового обучения и индивидуальных тестовых результатов дополнительно фиксируем описательное сравнение с исходной статьёй. Для каждого test-запроса после запечатывания прогнозов считаем число различных event_id в точной gold-разметке. Сохраняем обе непересекающиеся группы: ровно одно и хотя бы два события. Сравниваем нативный R-GCN с точным passthrough и с rewired/empty на prefix Full Support@2048. Парный 95% интервал отдельно по целым траекториям каждой группы. Термины «direct/linked/multi-fact» из статьи обозначают другие метки; число фактических событий — измеряемый здесь признак. Группы задаются единственным заранее определённым порогом. Выбор выходной модели и применение политики по этому признаку не выполняются.

Количество событий может быть связано с числом участков, длиной доказательств и трудностью вопроса. Групповые разности поэтому описывают состав наблюдаемых случаев; они не дают отдельного причинного эффекта числа событий. При нулевом числе кластеров у группы публикуется её фактическая численность.
