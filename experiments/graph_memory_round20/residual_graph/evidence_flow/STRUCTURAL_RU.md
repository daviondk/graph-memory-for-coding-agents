# Перенос анализа пары на лёгкий читатель

Используем методы выше только на прогнозах читателя, обученного на исходных 3 894 train с BM25 и перенесённого на замороженные Dense-FT ранги. Для каждого запроса источники и порядок индексов восстанавливаются из тех же шардов первоначальных Dense-FT. Сохраняем нативную политику prefix и исходный бюджет 2 048. До вычисления новых показателей задаём две пары — роль + типизированные степени против Dense-FT и чтение типизированных соседей против чтения после перестановки с сохранением степеней. Остальные веса остаются исходными. Поштучный контроль — восстановление исходного full-support из числа полностью покрытых событий для каждой из четырёх политик. Ранее для этих же запросов были доступны агрегаты Full Support, в том числе по много-событийной группе. Поэтому перенос имеет статус разбора механизма, а не независимой проверки качества.
