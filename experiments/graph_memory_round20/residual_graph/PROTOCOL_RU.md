# Нативное графовое дообучение на ISETrace

Цель — воспроизвести одну авторскую конфигурацию при seed 13 на исходном разбиении и проверить гипотезу о совместном чтении связанных аргументов и результатов после уже обученного графового ранжирования. Полная серия Table 1 использовала пять seed. Известны её агрегаты и результаты Dense-FT на той же выборке. Отдельная репликация использует заранее полученный PU Dense-FT из R19 и исходные точные FP32-векторы. Задачи и трассы используются как статические записи.

Объём — 3894 train, 500 dev авторского профиля, 2000 test. Модель full_rgcn, 3 типизированных слоя ширины 256, 14 отношений, нулевой начальный остаток над фиксированным Dense-FT, AdamW, BCE, веса и подвыбор отрицательных согласно публичным настройкам. Для выборки hard-dense отрицательных используется исходный encoder базового E5, для узлов графа и seed-сигнала обученный E5. Выбор сохранённой эпохи по dev_recall_at_5, максимум 15 эпох, официальный размер группы 128 задач. Допускается дедупликация одинаковых строк перед кодированием и хранение на диске при сохранении одинаковых входов, порядка задач, кандидатов и нативной арифметики. Проверяем начальный и финальный графовый контроль по сравнению с соответствующим seed на тех же ID. Тестовые метки открываются только после сохранения индивидуальных рангов и списков выбранных узлов. Предыдущие исследования уже открывали агрегаты тех же test-запросов.

Основной экспериментальный контраст на одном R-GCN — related минус skip при общем лимите 2048 токенов, исход Full Support по символьной разметке. Secondary — native prefix и passthrough Dense-FT под теми же тремя правилами, полнота покрытия, density, F1, расходы, доля полных совпадений и доверительный интервал парным кластерным бутстрепом по траекториям (10000, seed13). Калибруем нативную prefix-строку к опубликованной v3 Table 1 и воспроизведённому seed Dense-FT. Полного пяти-seed сопоставления и новой SOTA один прогон не устанавливает.

Независимая работа может использовать полный скоринг dev PU Dense-FT как побочный продукт до обучения R-GCN. Никакие параметры графа/комплектации по результатам этой работы не меняются.
