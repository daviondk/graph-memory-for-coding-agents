# Обученный графовый читатель и комплектование контекста в ISETrace

На всех 2 000 тестовых запросах при 2 048 токенах нативный residual R-GCN с обычным последовательным чтением полностью покрыл исходные свидетельства в **1562/2 000 (78,10%)**. Его точный Dense-FT seed на тех же входных тензорах дал 1458/2 000 (72,90%). Парный вклад дообученного графового ранжировщика — **5,20 п.п., 95% ДИ [3,28; 7,13]**. В исходной статье сообщено 77,33 ± 0,53% для R-GCN по пяти семенам обучения. Здесь воспроизведён один seed 13. [Калибровка](results.json) · [Статья авторов, таблица 2](https://arxiv.org/html/2609.25913v3#S7.T2)

Гипотеза этой серии: при равном лимите чтения стоит предпочитать сопряжённый аргумент или результат ранее выбранного вызова. После R-GCN правило related дало **1601/2 000**, пропуск непомещающихся кандидатов с сохранением порядка skip — **1611/2 000**. Первичный контраст related − skip составляет **-0,50 п.п., 95% ДИ [-1,09; 0,05]**, с 10 выигрышами, 20 потерями и 1970 совпадениями. Интервал включает ноль. Средний расход различается на -0,22 исходного токена. [Протокол](PROTOCOL_RU.md) · [Поштучные исходы](outcomes.json.gz)

## Что происходит при изменении только связей

Заморозили все обученные веса, seed-сигналы, узлы и текст. В одном проходе заменили концы рёбер нативной перестановкой со случайным seed 13, сохранив степень каждого узла по каждому типу и направлению. Из 574402 направленных сообщений в 1207 траекториях 522854 (по мультимножеству) получили иную связь. Изменились 1207 графов. Во втором проходе графовые слои получили ноль сообщений, сохранив обученное преобразование собственного состояния. Нативный контроль был вычислен повторно, число совпадающих prefix-списков с главным прогоном — 1994/2 000. ## Обучение, входы и расходы

Обучены все 15 эпох, 465 обновлений AdamW, 37262 нативных пар. Выбрана эпоха 11 по dev node Recall@5 = 78,60%. Локальная серия выбирала эпоху по первым 500 из 580 официальных dev-вопросов (331 из 352 траекторий). Авторские команды ISETrace используют все 580. Совпадение локального и авторского train/test подтверждено для каждого ID и порядка. Официальный повтор с выбором по полному dev ведётся отдельно. Train содержит 3 894 вопроса на 2 410 траекториях; test — 2 000 вопросов на 1 207 траекториях. Каждый из 249089 экземпляров PU-кандидата был доступен обоим сравниваемым ранжировщикам. На каждом из 2000 test-запросов нулевая инициализация точно воспроизвела входной cosine в native FP32. У автономного Dense-FT из R19 сравнение top-1 совпало в 2000/2 000, весь порядок — в 1952/2 000. [Checkpoint](best.pt) · [Метрики обучения](checkpoint.json) · [Фиксация прогнозов](forecast-seal.json)

Графовый fit с нативным dev-loop занял 1,9 мин, материализация train/dev-тензоров — 2,4 мин. Два разделённых E5 закодировали 584228 новых ключей «исходная строка, веса энкодера». По сохранённым записям нижняя граница объёма составляет 190957764 токенов без паддинга. Бюджеты считают потоки CPU и GPU отдельно, часть времени которых пересекается. Сумма зарегистрированных длительностей трёх стадий кодирования не менее — 123,0 мин. Полные счётчики отсутствуют у части операций перед перезапуском. Учтённые длительности включают подготовку батчей и запись в дисковый кэш. Артефакт обученного графового слоя занимает 12,78 МиБ. [План векторов](vectors-plan.json) · [Аудит повторно использованных данных](source-cache-audit.json) · [Проверка на CPU](direct-embedding-audit.json)

Промежуточная проекция скачанного файла запросов физически разбирает общие записи, включая строки, где рядом с текстом лежит разметка. Для test выбираются только ID и текст вопроса. Обучающие пары строятся только из train, выбор эпохи — только из dev. Test-спаны подключаются после SHA прогнозов. Агрегаты предшествующей работы на этом же benchmark были известны. Один seed, выполненные траектории ISETrace и один бюджет ограничивают выводы о генерации ответов и переносе на другие задачи.
