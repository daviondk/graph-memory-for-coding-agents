# Проверка по исходным категориям ISETrace

В авторской таблице 3 семантические классы Direct, Linked и Multi-fact характеризуют требуемый способ чтения памяти. В механистическом анализе R20 использовался другой критерий — число разных исходных событий с размеченными символьными диапазонами. Из официального списка всех 2 000 запросов и их исходных меток восстанавливаем таблицу сопряжённости этих двух определений. Объём каждого семантического класса должен совпасть с 641, 906 и 453.

До подсчёта локальных показателей по семантическим классам фиксируем сравнения на нативном prefix@2048. Сначала лёгкий читатель rank + degree с hash64-калибровкой и на том же checkpoint исходный Dense-FT. Дополнительно нативный R-GCN обученный на hash64 и его точный passthrough. После завершения переобучаемой no-next абляции и полной конфигурации рассчитываем также их разность при одинаковом количестве train. Проверяем Full Support и Coverage раздельно. При доступности дополняем диагностические уровни исходной статьи Coverage@1024. Поштучные исходы и группы заморожены ранее, новые веса и прогнозы по этой разметке не выбираются. Заодно считаем парный контраст между величиной эффекта для Multi-fact и Direct (разность разностей). Полные траектории пересэмплируются одновременно для обеих групп, с возвращением, seed 13, 10 000 реплик. Доверительные интервалы являются описательными в этом вторичном исследовании. Опубликованные значения из таблицы 3 — отдельные пятивариантные средние, для прямой репликации нужны те же пять обучающих seed. [Протокол сравнения](https://arxiv.org/html/2609.25913v3#S7.T3)
