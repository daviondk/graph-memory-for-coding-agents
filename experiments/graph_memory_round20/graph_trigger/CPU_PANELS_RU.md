# Раздельная калибровка фиксированного правила для двух CPU-моделей

После отказа GPU доступны две резервные конфигурации residual R-GCN. Первичная проверка для этого семейства — hash64. Availability служит проверкой чувствительности к выбору тренировочных траекторий. Порядок публикации зависит от фактической готовности рангов. Для каждой независимо подгоняются те же 13 коэффициентов к парным дельтам соответствующего графа на 500 dev и калибруются те же бюджеты. Гиперпараметры, правила сравнения и граница допустимой потери качества зафиксированы прежде. Эффективность решения и его перенос на другую конфигурацию графа оцениваются по отдельности.
