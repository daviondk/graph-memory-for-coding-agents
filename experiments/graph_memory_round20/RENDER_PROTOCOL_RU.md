# Проверка фактического контекста и зависимости эффекта от числа событий

Для исходного префикса, skip, двух вариантов обученной выдачи (p/c и p) и варианта без защищённых родителей проверяем, сколько WordPiece содержит буквальная выдача. Берём ровно сохранённые подстроки по адресам, склеиваем одним переводом строки в порядке выдачи, кодируем авторским токенизатором без спецтокенов. Если исходная строка длиннее 2048, отрезаем минимальный конечный суффикс до допустимого размера. При повторном кодировании проверяем итоговую длину; срезы проецируем обратно в исходные координаты. Условия и допустимый бюджет у всех методов общие. После фиксации решений сообщаем FS, покрытие и число изменившихся исходов. В авторском протоколе служебные разделители исключены из бюджета; данная проверка экспериментально проверяет дополнительно исполнимую нагрузку. Для краткости первичное сопоставление строгого рендера ограничено обучением fine_train (Dense и R-GCN), а также диагностикой ранее обученного на dev читателя Dense.

До получения рангов R-GCN фиксируем две страты по эталону: один либо несколько разных событий. В каждой сообщаем выигрыши, потери и изменение покрытия против того же matched skip (после строгого рендера). Страты описательные, без отбора благоприятных случаев. Эти вопросы тестировались и в других сериях.
