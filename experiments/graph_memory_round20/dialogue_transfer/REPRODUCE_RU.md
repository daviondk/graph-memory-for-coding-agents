# Воспроизведение

Для независимой проверки готовых результатов используйте Python 3.12.13, NumPy 2.5.5 и scikit-learn 1.8.0. Запустите `python -B -X utf8 verify.py` из каталога опыта. Скрипт проверяет SHA-256 всех запечатанных файлов, строит слепую панель из хешированных координат, пересчитывает AUC по числу согласованных пар с учётом равенств и Recall по сохранённым вероятностям с авторским порядком сортировки. После этого сравниваются парные разности, стратификация и доверительные интервалы. Групповые числа присутствуют в group-metrics.json.gz, по одной строке представления на историю или уникальную сессию. Предсказания сохранены с исходной точностью float64.

Для повторного обучения нужен локальный checkout авторского проекта LRE, ревизия 1aa51d672d772b27a272cab1393cd9968c13d158, датасеты LoCoMo10 и LongMemEval-S cleaned, а также точный файл study.py из R19/locomo_edges. Переменные окружения LRE_REPO, LOCOMO_FILE, LONGMEMEVAL_FILE и R19_EDGE_STUDY позволяют задать собственные пути. Значения SHA-256 входов и версии SciPy/NumPy/sklearn записаны в input-lock.json. Переменные числа потоков OpenBLAS, MKL и OpenMP фиксированы на 1. Исходный код и данные должны соответствовать закреплённым версиям. [LRE](https://github.com/NusRAT-LiA/LRE/tree/1aa51d672d772b27a272cab1393cd9968c13d158) · [LoCoMo](https://github.com/snap-research/locomo/tree/cbfbc1dba6bc53d00625212a0f22d55ffee7c1fc) · [LongMemEval-S](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/tree/98d7416c24c778c2fee6e6f3006e7a073259d48f)

В новом рабочем каталоге с теми же скриптами и протоколом запустите последовательно:

```text
python -B -X utf8 study.py
python -B -X utf8 score.py
python -B -X utf8 audit_source.py
python -B -X utf8 diagnose.py
python -B -X utf8 verify.py
```

Этап study.py первым делом сверяет данные и SHA протокола. Внешние предсказания замораживаются до расчёта метрик. Тексты и слова из корпуса не сохраняются. Ключ истории — SHA-256 исходного question_id в UTF-8. Ключ сессии — SHA-256 списка пар (роль, нормализованный текст); преобразование полностью задано в study.py. Внутридоменные модели обучаются на других fold LongMemEval и используют отдельный файл прогнозов. При оценке доверительных интервалов выборка формируется из целых компонент с возвращением, среднее считается по всем включённым единицам, seed 13, 10 000 повторов.

**Журнал.** Сверены хеши исходных данных и оригинальной LRE, записан протокол 95fbf1a99ad55f53efa28277c44a8dd499853487d1b16d34f6e7338837a473bb. Выгружены обезличенные прогнозы по 500 историям и по 831 условной сессии. Затем получены парные оценки и проведены дополнительные проверки ролей, вариантов исходного текста и случайного контроля. Общие выводы и границы сопоставимости приведены в REPORT_RU.md. Полная внешняя панель имеет только одну компоненту повторного использования исходных сессий, поэтому в её строке результатов отсутствует доверительный интервал.
