# Обучение выбора масштаба чтения на исходном train ISETrace

На предыдущем этапе коэффициенты первого мелкозернистого читателя оценены на 500 dev-вопросах; результаты Dense-FT на публичном тесте уже известны. Для корректного сравнения повторяем ту же конструкцию, признаки, C=1 и все варианты без настройки на опубликованном train из 3 894 вопросов и 2 410 траекторий. Сопоставляем источник каждой положительной метки с нативной разметкой любого пересечения PU. Обучающий Dense-FT кодирует свой train in-sample; для вывода на test используется тот же замороженный checkpoint. Ни одного dev- или test-интервала для оценки коэффициентов. Эталонные интервалы дают более детальный обучающий сигнал по сравнению с бинарным PU-label в авторском R-GCN, это использование тех же аннотаций оригинального train, а не равенство функций потерь.

Первичная пара на 2 000 общих тестовых вопросах после готовности графа — R-GCN с защищёнными двумя PU и скором p/c против того же графа с добором целых PU (skip), Full Support, парный 95% ДИ по траекториям. Coverage, Density, F1, расход, авторский префикс, абляции и Dense-FT — вторичные. Вход в сумму потерь — каждый имеющий хотя бы одного родителя 64-субтокенный блок, без весов за число вопросов в траектории; class_weight=balanced. Все оценки этой линии на известном тесте разведочные. Внутридоменная проверка переноса — нативные 500 dev вопросов, которых нет в обучении читателя. Отчёт приводит все варианты.
