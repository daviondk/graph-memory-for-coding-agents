# Воспроизведение

Сначала подготовьте исходный train посредством `python ../fine_train/prepare.py` в окружении ISETrace, которое использует R19. Затем из этого каталога последовательно выполните:

```powershell
python transfer.py fit
python transfer.py dev
python transfer.py dense
python ../assess.py fine_lextrain dev
python ../assess.py fine_lextrain dense
```

Подготовка восстанавливает символьную разметку из оригинальных записей, проверяет SHA-256 сырого события и совпадение множества положительных родительских узлов со старым авторским train. Файл apply_at_dense.py сохраняет точную версию общего модуля apply.py на момент запечатывания dev/dense. Затем модуль дополнен чтением рангов малых CPU-моделей, для исходных рангов логика та же. Параметры линейных моделей входят в архив. Большие тексты исходных траекторий и локальные тензоры признаков остаются в закрытом рабочем каталоге на D.
