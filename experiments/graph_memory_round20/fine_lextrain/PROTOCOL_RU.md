# Перенос политики чтения между ранжировщиками

Обучаем тот же линейный читатель 64-WordPiece блоков на всех 3894 train-вопросах ISETrace, но во время обучения родительские интервалы упорядочены авторским лексическим BM25. На тесте применяем те же коэффициенты к замороженному Dense-FT и доступному нативному R-GCN, меняется лишь порядок родителей. Ранговые признаки имеют общую шкалу, распределение качества кандидатов может отличаться между ранжировщиками. Доступны только размеченные фрагменты train. Это отдельный эксперимент переноса, допускающий обучение без расчёта плотных векторов. При дефиците вычислений он остаётся доступным на CPU. Разметка, признаки, сборка бюджета, абляции, финальный ранжировщик и метрики фиксируются по fine_train. Пара для первичного условного сравнения на доступном Dense-FT — p/c против skip, Full Support@2048. Отдельный графовый перенос обозначаем названием фактического checkpoint. Публичные результаты предыдущих методов Dense-FT известны. Полностью перечисляем и покрытие, и неудачи.
