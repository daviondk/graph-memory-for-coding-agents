# Воспроизведение архивной проверки

Локальная проверка целостности и пересчёт итогов доступны через `python -B verify.py` без внешних библиотек. Скрипт сверяет подписанный список тестовых переходов, целостность фиксаций, значения показателей из поштучных результатов, статус каждого повторного запуска и индивидуальные прогнозы. Ревизия набора VibeMemBench — 11164976b4f920cdb0d0cd570ca572e49acea1e8. Публичные записи указывают пути внутри набора и SHA-256 исходных журналов. Содержимое команд и ответов исходного агента не входит в экспорт.

Для полного повтора доступны архивный snapshot с source-manifest.json, подкаталоги R12/negative_external, R15/test_receipts, R16/pytest_action, R17/receipt_invalidation и R19/online_write и write_learned, модель и токенизатор R19. В копии исследования из поддерживаемой среды выполните по порядку `study.py design`, `study.py prepare`, `study.py predict` и `study.py score`. Каждый вызов выполняется через Python с `-B -X utf8`. Исполнитель читает журнал как данные, вызывает только парсеры и оценку памяти на CPU. Второй выпуск pytest уже состоялся в опубликованной трассе. Независимое исполнение выбранных тестов дано в отдельном контролируемом эксперименте. [Панель QuixBugs](../code_transfer/REPORT_RU.md)
