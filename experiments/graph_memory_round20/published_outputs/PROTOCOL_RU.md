# Протокол аудита авторских прогнозов ISETrace и независимой пробы downstream

Проверить официальный публичный репозиторий GraphMemory, refs и releases, историю опубликованных деревьев, репозитории Hugging Face, ссылающиеся на работу авторов, исходные материалы arXiv v3 и индексы Zenodo/OSF/DataCite. Для каждой поверхности фиксируем URL, ревизию, размер/количество и тип доступных записей. Различаем запрос/разметку, путь в документации, макрометрику, контекстные блоки после упаковки, полную ранжировку кандидатов и человеко-/модельно-оценённый ответ. При обнаружении пяти рангов с идентификаторами согласовать анализ с координатором до запуска. При доступном E10 пересечь только явно опубликованные ID, никогда не восстанавливать размеченную подвыборку по догадке. Если авторские данные о QA не опубликованы, не приписывать им локальные прогнозы.

Для независимой downstream пробы сначала проверить LongMemEval-V2, MemDev-Bench и VibeMemBench по исходным материалам и наличие необходимых локальных средств. Дополнительный открытый coding-memory benchmark допустим для объективной небольшой задачи. Выбирать только нейтральные задачи, например преобразование данных, форматирование или конфигурация вывода. Отбирать по публичному описанию и технической исполнимости до результата. Зафиксировать конкретные задачи, варианты памяти и точное происхождение решения отдельным дополнением до проверки результата. Никаких запусков модели на занятой видеокарте, платного API или публикаций. Числа reference/offline scorer отделять от качества решателя. Желателен инструментальный положительный и отрицательный контроль на том же авторском оценщике. Ни запросы, ни траектории ISETrace не исполняются.
