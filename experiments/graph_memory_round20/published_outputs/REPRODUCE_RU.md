# Воспроизведение

Быстрая проверка пакета — `python -B -X utf8 verify.py`. Для независимого повторного исполнения 24 сделанных выборов — `python -B -X utf8 verify.py --replay`; понадобится checkout GiulioDER/agent-memory-bench c1b15726f1153b02dda0490ca1936bb86a809514 в PUBLIC_AUDIT_RUNTIME/agent-memory-bench. Скрипт проверяет контрольные суммы, все 500 ID исходного отбора E4, границы Full Support и авторские вердикты; при --replay заново применяет каждую выбранную реализацию и запускает оригинальный оценщик.

Источники зарегистрированы в surface-audit.json и supplemental-audit.json. audit.py обращается к публичным API без авторизации и проверяет полноценный bare Git-репозиторий, задаваемый GRAPHMEMORY_BARE. followup_audit.py воспроизводит успешную проверку Zenodo с упрощённым запросом и сверяет два показателя BM25 с результатами R18. При новом запросе к online API состояние индексов и служебные поля могут измениться; для независимого повторения используйте новую рабочую директорию. cohort.py в окружении ISETrace вызывает исходную функцию E4 после фиксации 2 000 test ID, читает прежние обученные и лексические прогнозы из R18 и R19. GRAPHMEMORY_REPO и ISETRACE_QUERY_METADATA настраивают пути к коду и метаданным.

Для пересчёта новых решений потребуется локальная сборка llama.cpp с OpenAI-compatible сервером и модель указанной ревизии. fetch_model.py загружает зафиксированный GGUF в PUBLIC_AUDIT_RUNTIME и сверяет SHA-256. downstream.py поднимает только свой временный сервер на localhost:19076 с отключёнными GPU и одним последовательным слотом, проверяет хеш модели, готовит обезличенные программные варианты, регистрирует 24 промпта по их отпечаткам, сохраняет 24 выбора и оценивает каждый. Двоичный файл llama-server задаётся LLAMA_SERVER. В рабочем окружении TMP/TEMP указывали на отдельную директорию на D. Для полного повторного запроса используйте пустой кэш decision-*.json в новом PUBLIC_AUDIT_RUNTIME; существующий кэш используется только при совпадении хешей запроса и модели. Числа после работы другими сборками следует сверять с сохранёнными decisions. Сервер запускается и останавливается внутри процесса на этапе infer. Для повтора проверяющего этапа сервер не нужен.

Пути CHECKOUT, oracle и бинарных файлов относятся к открытым зафиксированным проектам. В результатах содержатся хеши запросов и тестовых сообщений, анонимные буквы выбора, логические исходы и расход токенов. Исходные архивы траекторий ISETrace здесь не исполняются.
