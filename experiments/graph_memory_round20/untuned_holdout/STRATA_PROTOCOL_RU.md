# Проверка границ переноса структурного ранжирования

До получения плотных рейтингов и исходов для дополнительных 80 вопросов фиксируем две вторичные проверки. Положительный основной результат для 2 000 вопросов и его разделение по числу исходных событий уже известны. Вывод по дополнительной панели оценивается отдельно.

1. Сохраняется ли разница Full Support для графовых степеней на вопросах, где ни одно исходное поле с эталонной цитатой не встречалось дословно среди исходных полей 3 894 обучающих вопросов Dense-FT? Для 80 вопросов используем старые неизменённые флаги полного dev580, для 2 000 — исходные флаги test. В обучении читателя также исключены все совпадения по ID траекторий. Анализ оценивает точные совпадения полей, семантические дубликаты остаются возможными.
2. Сохраняется ли направление разности на вопросах, чьи эталонные цитаты относятся к двум или более различным событиям инструментального сеанса? Разбиваем все вопросы по одному или нескольким event_id в исходной разметке. Для официального test уже известны результаты по роли и степени. Проверку на дополнительных 80 замораживаем до получения их исходов.

Обе проверки применяем к train-only правилу ранг + роль + восемь типизированных степеней и к полному факторизованному prior с основной калибровкой hash64, с префиксом целых PU на 2 048 токенов. Контроль — те же ранги Dense-FT без поправки. Отдельно выводим знаменатель, число траекторий, точные успехи каждого метода, выигрыши и потери, изменение FS и Coverage с парным кластерным процентильным бутстрепом по 10 000 выборкам траекторий. В маленьких подгруппах приводим абсолютные числа. Межгрупповую причинную интерпретацию этот анализ не даёт. Результаты публикуем независимо от знака эффекта. Ни выбор группы, ни разметка не участвуют в ранжировании или в расчёте приоритета для запроса.
