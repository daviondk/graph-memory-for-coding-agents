# Восемьдесят дополнительных вопросов

Исходный dev ISETrace содержит 580 вопросов. Для обучения мелкозернистого Dense-FT-читателя и раннего останова исходной модели использовались авторские 500. Берём все оставшиеся 80, без отбора по результату. В 53 вопросах траектория встречалась среди исходных 500, в 27 она там отсутствовала. Эти вопросы имеют известный общий результат только для других методов из предыдущих серий. Для читателя, обученного на исходном train с лексическими родителями, все 80 отделены и по вопросу, и по траектории от его обучающей выборки. Цель — перенос за пределы официальных 2 000 тестовых вопросов и отдельная диагностика пересечения источников.

До просмотра результатов фиксируем первичную пару: замороженный dev-читатель p/c против нативного Dense-FT skip, Full Support в 80 случаях. Также показываем Coverage, варианты p и без защиты двух родителей и полный лексически обученный читатель с прежними весами. Оцениваем исходно все 80, отдельно 27 с новыми траекториями для dev-обучения. По вопросам с повторяющейся траекторией зависимость учитывается кластерным bootstrap. Предел чтения 2 048, тот же токенизатор. Для восполнения недостающих векторов используем неизменённый checkpoint Dense-FT, CPU FP32, отдельный кеш. Нативные идентификаторы и текст родителей сверяем со всеми имеющимися официальными PU-проекциями. Разметка читается только после фиксации всех прогнозов.
