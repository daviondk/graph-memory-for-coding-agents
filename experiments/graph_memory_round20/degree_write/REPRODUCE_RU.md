# Воспроизведение

Используются сохранённые решения записи R19, исходные координаты фрагментов, независимая проекция наблюдений ISETrace, веса обученной записи и prior из factor_reader соседней папки. Пути для test и dev перечислены в input_paths в policy.py. Веса и размеры входов зафиксированы в результатах исходных исследований R19 и R20.

Из этой папки выполните команды в указанном порядке. Первые две повторно вычисляют решения с частично наблюдаемым графом и контрольную политику. Две последние открывают разметку и вычисляют показатели официальным и независимым оценщиками.

```
python policy.py test
python policy.py dev
python score.py test
python score.py dev
```

Проверка без повторной генерации использует два сохранённых seal JSON и восемь сжатых шардов решений на выборку. Итоговый cross-study-audit в родительской папке проверяет совпадение контрольных исходов с set_writer. Для восстановления byte-for-byte следует использовать сохранённые файлы и их хеши. Повторная компрессия может менять служебное время в заголовке gzip.
