# Полезны ли графовые степени при записи до появления вопроса?

Положительный результат при чтении использовал граф завершённой траектории. До появления будущего вопроса граф неполон. Проверяем прямой перенос исходного query-independent degree prior из factor_reader в потоковую запись на 8 192 WordPiece. На каждом завершённом событии известны его тип, абсолютный адрес, содержимое и последовательность собственных PU. Для каждого 64-токенного блока выбираем первый по смещению полностью содержащий его PU. Четыре счётчика доступны сразу или пополняются: есть ли следующий/предыдущий PU в завершённом событии, сколько PU аргументов/результатов того же вызова наблюдалось. Для пришедшего события число ранее виденных партнёров оценивается только по всё ещё хранящимся PU. Если партнёр приходит позднее, степень ранее сохранённых блоков обновляется только до их вытеснения. Две разновидности межвызовных связей из завершённого графа на этом этапе задаём нулём. Это частичный граф с наблюдаемыми рёбрами, без глобального индекса траектории; при выводе модель видит только прошлые события. Постоянная стоимость весов и счётчиков не входит в цену текстовой полезной нагрузки. Условие строгой памяти относится к сохраняемому тексту и невозможности восстановить удалённый блок.

Фиксируем до вычисления результатов сумму исходного линейного скора writer R19 и типизированного degree logit с весом 1. Контроли: исходный R19 full, одинаковые признаки без обратного обновления, вклад только соседних блоков без связей аргумент–результат. Микроблок без полностью содержащего PU получает те же нулевые счётчики. Основная пара: обновляемый вариант минус исходная политика, Full Support после BM25 при чтении до 2 048, все 2 000 исходных вопросов. Дополнительно проверяем 580 dev-вопросов, полную сохранность эталона до чтения, Coverage, интервалы по траекториям. Коэффициенты перенесены без обучения на результатах хранения; оба исходных компонента обучены на original train, но их обучающие данные частично пересекаются. Предыдущие результаты других политик хранения на этом корпусе известны.
