# Дополнительный зафиксированный перенос BM25 → Dense-FT

До открытия новых итоговых метрик основного typed_reader фиксируем дополнительную проверку. Обучить те же четыре компактных модели на всех 3 894 нативных query из официального train с 2 410 непересекающимися траекториями. Вместо development Dense-FT в качестве источника рангов для обучающих признаков использовать нативный BM25TaskRetriever по всем PU родительской траектории. Исходная текстовая модель, граф, веса вопросов, признаки, регрессия, placebo и seed совпадают со study.py. Применить веса без настройки ко всем ранее фиксированным Dense-FT test ranks и отдельно запечатать прогнозы. Первичная метрика здесь также FS@2048 для typed против Dense native prefix; вторичные включают typed−untyped, typed−shuffled и skip, все с теми же CI. Изменяются вместе объём супервизии и природа исходного ранга. Сопоставление этих двух вариантов характеризует перенос, но не изолирует вклад размера обучения от используемого ранжировщика. Будущие вопросы, test-метки и тексты не используются при предсказании результатов. Графы, исходные документы и BM25-запрос подаются как данные без выполнения их содержимого.
