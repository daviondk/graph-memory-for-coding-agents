# Дешёвое графовое переранжирование единиц выполнения ISETrace

Вход — уже обученный Dense-FT из R19 при зафиксированном seed 13. Предыдущие агрегаты этого теста известны исследователям, ранее они использовались для генерации гипотез. Протокол текущих ветвей фиксируется до вычисления их метрик. Выделенный development из 500 запросов использовался ранее также для выбора checkpoint Dense-FT. Только эти 500 используются для обучения нового ранжировщика. На полном тесте 2 000/1 207 фиксируем прогнозы до доступа этапа оценки к тестовой разметке.

Гипотеза — при равной исходной сортировке есть информативное различие направлений и типов связей. Основной контраст — Full Support@2048 предзаданного typed-ранжировщика против исходного Dense-FT в режиме нативного prefix. Для вывода о специфичности графа требуются сравнения с нетипизированной сетью и с переставленными рёбрами той же степени. Первые попарные изменения Coverage@2048 и результаты при skip вторичны. Размер первичного эффекта, ДИ 95% и W/L/T по вопросам; 10 000 кластерных бутстрепов траекторий, seed 13, заранее фиксированная сортировка ключей. Метрики плотности контекста, использованного токенного бюджета и число полученных единиц дополнительно.

Единица — provenance unit в исходном Dense-FT. Проекция графа использует авторскую функцию logical_output_dependencies и в точности те же неориентированные пары, что provenance_candidate_neighbor_edges, с восстановлением направления из исходных рёбер. Фиксируем четыре отношения — следующий chunk; аргумент вызова к всем фрагментам его результата; feed между результатами вызовов; поток ресурса между результатами вызовов. Каждый тип представлен на входе и выходе. Никаких признаков задачи, пути, инструментов или текстового содержимого; граф строится без запроса. Вектор собственных признаков позиции при исходном однобазовом ранге r среди N — −log(r), 1/r и (N−r)/max(1,N−1). В каждом канале соседства добавляем log(1+число соседей), наибольший 1/log2(1+r_neighbor) и log(1+сумма этих величин). При отсутствии соседей все три значения равны нулю. Поэтому высокая позиция соседа даёт больше вклада при одинаковых прочих условиях. Первичная модель использует 3+8×3=27 коэффициентов плюс константу.

Контроли: исходный Dense-FT без изменений, обучение только по своим трём признакам; нетипизированные соседи как неориентированное уникальное объединение (один канал с теми же тремя агрегациями); typed-модель, отдельно обученная и протестированная на переставленном графе. Для placebo двусвязными обменами концов отдельно внутри каждой тройки (тип связи, тип источника, тип цели) сохраняются точные входящие и исходящие степени всех узлов, число связей и отсутствие петель/дубликатов одного типа. Seed детерминирован по SHA256 ID траектории и типа группы, максимум 10·min(64,E) попыток на группу, E — число связей группы. Логируем долю фактически заменённых рёбер. Для учёта разницы размерности дополнительно применяем полностью обученную настоящую typed-модель к этой же переставленной топологии без переобучения.

Метки development — наличие положительного перекрытия PU с авторским размеченным свидетельством, согласованные с нативным набором positive IDs. Каждому вопросу с обоими классами даём одинаковый суммарный вес и поровну веса положительному и отрицательному классу. Веса масштабируем к среднему 1 по обучающим строкам. Для каждой ветви по train обучаются взвешенный StandardScaler и L2 logistic regression с C=1, lbfgs, max_iter=1000, seed 13. Тождественные оценки разрешаются исходным Dense-FT порядком. В skip пропускается блок, который целиком не помещается, и чтение продолжается по рангу. У prefix первый overflow завершает отбор. Размер блоков и тарификация токенов прежние. На тесте отсутствуют подбор параметров, обрезание хвоста кандидатов, обучение весов и настройка по типу вопроса. При расхождении графов, ID или токенов публикуем диагностику. Контроль эффективности включает CPU wall time ранжировщика отдельно от парсинга/оценки, размер модели и число параметров. Тексты действий и исходные реплики не выгружаются. Дополнительный перенос BM25 с train возможен как отдельное исследование с отдельным протоколом.
