# Перенос неизменного упаковщика на резервные CPU-ранги

Из-за сбоя GPU точная исходная R-GCN полного train ещё не доступна. До получения прогнозов резервных вариантов зафиксированы две отдельные панели. Основная CPU-панель — hash64 с выборкой обучающих траекторий по хешу. Availability, использующая ранее готовые векторы, — проверка чувствительности. Первой обрабатывается доступная по времени панель. Результат на ней не меняет параметры ни одного варианта на второй панели. Отсутствующий ранг не подменяется расстановкой другой модели. Обе ограниченные модели различаются с полноразмерной опубликованной системой по выборке обучения.

Адаптер переносит исходные записи query/trajectory/PU/score из подписанного разработчиком архива в восемь разбиений R18 по фиксированному ID траектории. Он проверяет тождество всех 2 000 вопросов и 1 207 траекторий и контрольные суммы рангов. Затем непосредственно вызывает ранее закреплённые функции упаковки из pack.py и overlap_control.py. Общие протокол, тариф WordPiece, строгая коррекция буквального текста, порядок источников и статистика не меняются.
