# Контроль остатка бюджета без удаления прежних повторов

Дополнительный контраст фиксируется после запуска первичного source-only упаковщика Dense-FT и до просмотра его прогнозов, агрегатов или новых эталонных оценок. Первичный контраст и остальные алгоритмы остаются зафиксированными в исходном протоколе.

Повторяем те же два прохода по замороженным рангам и тот же выбор лексического окна для хвоста. Исходный skip выводим в точности в прежнем порядке с прежними повторными цитатами и тарифицируем фактически отрендерованный текст. Сначала при возможности добавляем все недостающие диапазоны очередного целого родителя как самостоятельные цитаты. Затем при возможности добавляем одно окно на родителя с теми же правилами выделения и лексической сортировки. Повторно тарифицируем строку с переносами. Новое содержимое может быть смежно с ранее выбранной цитатой; обе оплачиваются как отдельные части. Фиксируем исходные байты, условия исключительной неосуществимости и стоимость каждого добавления. Прямые вторичные контрасты — F минус этот дробный контроль и W минус этот целочисленный контроль. Эта оценка включает удаление повторов исходного skip и возможное изменение токенизации при объединении новых смежных частей. Отдельно показываем результаты на вопросах с повторно выбранными символами в исходном skip и без них.
