# Воспроизведение

Нужны локальные неизменённые данные ISETrace и рабочее дерево серий R17–R20 с путями, заданными R19. Команды из этого каталога:

```powershell
python train.py
python run.py predict dev
python run.py predict test
python run.py score dev
python run.py score test
```

Обучение проверяет SHA каждого исходного примера выбранной обучающей выборки перед восстановлением точных координат. В test и dev сначала фиксируются решения, затем отдельно вызывается процедура подсчёта. Контрольная политика должна поштучно повторить архивы и выдачи R19. При отсутствии исходных больших файлов сводные данные и исходы по каждому вопросу сохранены в этой папке.
