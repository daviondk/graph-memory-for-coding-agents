# Оптимизация записи по комплекту свидетельств

Индивидуальная классификация размечает каждый блок независимо. Для полного ответа агенту должны остаться доступны все требуемые блоки. На тех же 256 обучающих траекториях, тех же признаках и с тем же бюджетом сравниваем три линейных записи. Исходный writer из R19 заморожен. Две альтернативы переобучают веса относительно него на одних и тех же группах вопросов. Для каждого вопроса положительные элементы — все блоки, пересекающие хотя бы один его эталонный фрагмент. Отрицательные примеры — до 32 неэталонных для этого вопроса блоков той же траектории, ближайших к пороговому исходному скору при бюджете 8192 WordPiece. Исключаем траектории без давления на бюджет. Для каждой группы сравниваем log-mean-exp отрицательных скоров со средним положительным или с мягким минимумом положительных. На разности применяем softplus. Для обеих новых моделей L2-штраф 0,025·||w−w₀||², масштаб мягкого минимума и максимума 1. Константа линейного скора сокращается в разностях. Критерий приближённый, гарантий оптимальности для Full Support при онлайн-вытеснении нет.

Первичный эффект: мягкий минимум против R19 full, полная выдача BM25@2048 на авторском test ISETrace (2 000 вопросов). Дополнительные — сравнение со средним положительным, полнота самого архива до чтения, покрытие, плотность. Внешняя по отношению к обучению вспомогательная проверка — 580 других вопросов R19 write_transfer. Сохраняем предыдущие разбиения, признаки, объёмы, поиск и порядок. Никакого выбора параметров после результатов этих тестов. Bootstrap по траекториям 10 000 раз, seed 13. Test и дополнительный корпус уже знакомы из предшествующих серий, интерпретация разведочная. Контроль совпадения решений базовой ветки с R19.
