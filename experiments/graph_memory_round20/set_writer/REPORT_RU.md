# Сохранение полного комплекта источников при записи

Если будущему вопросу нужны три фрагмента, высокие оценки двух из них ещё не гарантируют, что в архиве останется третий. Проверили простое изменение обучения линейного отборщика. Для каждого обучающего вопроса его наиболее уязвимый положительный блок сопоставляется с блоками около границы вытеснения. Признаки, порядок событий, бюджет 8 192 WordPiece и BM25 с чтением до 2 048 остаются общими. В обучении участвовали 358 вопросов из 224 траекторий с ограничивающим бюджетом. Ещё для 53 обучающих вопросов вся траектория помещалась в память. [Протокол](PROTOCOL_RU.md) · [Веса и диагностика оптимизации](model.json)

| Доступность полного эталона | Исходная модель | Средний скор нужных блоков | Мягкий минимум |
|---|---:|---:|---:|
| В архиве, test (2 000) | 1 595 (79,75%) | 1 610 (80,50%) | **1 615 (80,75%)** |
| После BM25, test | 979 (48,95%) | 983 (49,15%) | **991 (49,55%)** |
| В архиве, dev (580) | 469 (80,86%) | 481 (82,93%) | **483 (83,28%)** |
| После BM25, dev | 292 (50,34%) | 294 (50,69%) | **298 (51,38%)** |

При мягком минимуме полный эталон чаще остаётся в архиве в обеих выборках. Разность против исходной модели составляет +1,00 п.п. [0,10; 1,94] на test и +2,41 п.п. [0,71; 4,16] на dev. Для основного показателя после чтения разность +0,60 п.п. [−0,20; 1,40] и +1,03 п.п. [−0,88; 3,01] соответственно. Отдельный вклад мягкого минимума по сравнению с обычным средним также неопределёнен. Оценивали 95% парные интервалы по траекториям. [Полный test](test-results.json) · [Проверка dev](dev-results.json)

Функция потерь сравнивает log-mean-exp отрицательных скоров с мягким минимумом положительных и штрафует отклонение весов от исходной модели. Градиент увеличивает вклад положительных блоков с наименьшим скором. Во входе нет будущего вопроса в момент записи. При чтении совпадение базового состава и выдачи с R19 проверялось поштучно. Положительный эффект на сохранение пока не даёт основания приписывать ему достоверный рост итогового поиска или решения задач с кодом.
