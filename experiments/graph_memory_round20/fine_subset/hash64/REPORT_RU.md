# Чтение на совпадающей малой обучающей выборке

Веса читателя оценены по точным родительским рангам исходного Dense-FT на 101 train-вопросах из 64 траекторий. Графовая модель этого размера использует те же траектории. Новые ранги графа можно передать готовой линейной модели без изменения весов. Выбор состава, подвыборки и основная пара указаны в общем протоколе.
