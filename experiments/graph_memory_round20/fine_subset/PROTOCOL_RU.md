# Мелкозернистый читатель на малом исходном train

В результате сбоя GPU полностью доступны ранги родительских Dense-FT для всех тестовых траекторий, а расчёт на полном train требует дополнительных векторов. Используем те же заранее зафиксированные обучающие подвыборки, что у быстрого R-GCN. Основная подвыборка — 64 траектории по хешу без учёта готовности их векторов. Дополнительная — 62 траектории по наличию кеша (склонна включать короткие истории). Обе принадлежат только исходному train. Составы, размеры и назначения сверяются с cpu_fallback/cohorts.json. Обучаем тот же бинарный классификатор по пересечению 64-токенного блока с исходной разметкой. Модели каждого размера получат одинаковые Dense-FT и ранги соответствующего R-GCN на 2000 вопросах. Основная пара на графе — p/c против skip с сохранением полного свидетельства, 2048 WordPiece. Прочие варианты, Coverage и проверка фактического контекста — вторичные. Дополнительно к каждой CPU-модели применяем без настройки уже замороженные читатели, обученные на dev Dense-FT или на полном лексическом train. Результаты более раннего Dense-прогона известны, поэтому эта серия разведочная. Отношение к полной авторской конфигурации зависит от размера обучения самого R-GCN.
