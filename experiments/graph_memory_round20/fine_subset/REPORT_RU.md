# Сопоставление двух способов взять малую обучающую выборку

Составы зафиксированы одновременно с CPU-воспроизведением графовой модели. Основная подвыборка по хешу содержит 64 траектории и 101 вопрос. Выборка по уже готовым векторам содержит 62 траектории и 100 вопросов. Выбор по готовности может менять распределение длины траекторий. Каждый читатель использует оба класса сигналов из того же train, включая точные положительные интервалы. [Основной состав и измерения](hash64/REPORT_RU.md) · [Проверка по доступности](availability/REPORT_RU.md) · [Протокол](PROTOCOL_RU.md)

Для воспроизведения нужны восемь частных train-проекций по [исходному протоколу](../fine_train/PROTOCOL_RU.md). [Локальный сценарий](../run_subset.ps1) запускает оценку по мере готовности соответствующих рангов. Для уже запечатанных выдач достаточно общего assess.py или архива outcomes.json.gz.
