# Воспроизведение двадцатой серии

Крупные данные, CUDA-окружение и кеши обученных весов размещены на диске D. Для просмотра результатов достаточно файлов пакета. Обычная раскладка — `D:/CodexResearch/x20-bench-workspace/work/graph_memory_round20/` и соседние серии R17, R18, R19. Штатные команды Python ISETrace использовали `D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe`. Для LongMemEval нужны закреплённые корпус и код LRE из соответствующих инструкций. Исходные тексты пользовательских и инструментальных траекторий, веса нейросетей и многогигабайтные индексы не включены в архив. Прогнозы хранят адреса и индексы.

Чтобы проверить уже созданный ZIP, запустите `python package_local.py ПУТЬ-К-АРХИВУ --verify`. Проверяются SHA-256 каждого содержимого и соответствие локальным манифестам. Скрипты `assess.py` и `render_audit.py` пересчитывают исходы по запечатанным решениям, `summarize_readers.py` собирает таблицы из их результатов. Случайное зерно группового bootstrap — 13, 10 000 выборок. Исходник и ближайшие альтернативы каждого метода перечислены в его протоколе. Разбиения, модели и результаты разведочного исследования фиксируются отдельно, число строк в восстановленном отчёте само по себе не является числом независимых проверок.
