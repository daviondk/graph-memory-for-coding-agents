# Отчёт. Калибровка отбора реплик для полной истории LongMemEval-S

При сохранении 20% реплик добавление **роли говорящего и относительной длины сообщения внутри этой роли** повысило macro Recall с **59,27% до 67,74%**. Основной тест проводился на 62 историях без общих исходных сессий. У 59 имелись размеченные свидетельства. Парное изменение составило **+8,47 п.п.**, 95% бутстреп-интервал **[+2,54; +15,25]**, семь историй улучшились, ни одна не ухудшилась, 52 дали одинаковый результат. Метод уменьшил среднюю долю сохранённых слов с 9,14% до 7,73% при том же числе реплик. Подсчёт слов проведён после основного опыта.

## Метод

Исходная LRE использует TF–IDF текста реплики и шесть признаков позиции, давности и формы сообщения. До появления вопроса ранжировщик получает полную историю, и каждому сообщению назначается оценка сохранения. Для калибровки добавлены три числа. Первое — индикатор пользовательской роли. Второе — процентиль длины сообщения среди реплик той же роли в этой истории, при совпадениях используется средний ранг. Третье — произведение первых двух. Формально, при роли r и длине l это позволяет задавать отдельные сдвиг и наклон зависимости от процентиля Fᵣ(l) для ролей user и assistant. Внутри каждой роли ранговый признак сохраняется при строго монотонном преобразовании длины, применённом ко всем её сообщениям. По полученному сравнению можно оценить эффект добавления трёх признаков вместе. Вклад каждого из них по отдельности не измерялся. [Исходный классификатор LRE](https://github.com/NusRAT-LiA/LRE/blob/1aa51d672d772b27a272cab1393cd9968c13d158/experiments/conversational_qa/lre_qa.py) · [Работа Lia и Mazumder](https://arxiv.org/abs/2606.20954)

Изучены семь ветвей. Помимо исходной и калиброванной LRE, обучена лёгкая логистическая регрессия только на трёх признаках. В двух ветвях к калиброванной LRE добавлены семь признаков связи с настоящей или сдвинутой внутри той же сессии предыдущей репликой. При сдвиге предшественник иногда попадает в будущее. Этот контроль используется для проверки специфичности связи. Два дешёвых контроля — равномерный случайный выбор и случайный выбор сначала среди реплик пользователя. Для них вычислены точные ожидаемые Recall и AUC, поэтому результат не зависит от случайного seed. Обученные модели не получают вопроса будущего пользователя, ответа или идентификатора сессии.

## Полные истории и защита от утечек

В первичной панели используется cross-fitting по пяти блокам целых историй, разделённых по фиксированному порядку SHA-256. Все 62 истории имеют непересекающиеся исходные сессии. Каждый обучающий блок содержит 49–50 историй, 23 993–24 396 реплик, 79–90 положительных. Прямые совпадения текстов между обучающим и тестовым блоками устраняются нормализацией Unicode, регистра и пробелов. В сумме по пяти обучениям исключены 196 отрицательных и ноль положительных реплик.

Для оставшихся 438 историй выполнены ещё 28 проспективно заданных блоков оценки. Источником обучения для каждого такого блока служит исходная панель из 62. До обучения целиком удаляется любая история, у которой с тестом совпал исходный ID или хеш нормализованной последовательности «роль, текст». Затем устраняются индивидуальные совпадающие реплики. В обучении остаются 18–43 истории, 8 805–21 069 реплик, 26–76 положительных. Дополнительно удалена 821 отрицательная и ноль положительных реплик суммарно по 28 обучениям. Все модели получили оба класса во всех блоках. Отдельный аудит повторяет подсчёт пересечений из исходного корпуса; после исключений пересечений целых исходных сессий и нормализованных текстов реплик между train и test соответствующего блока нет. Аудит также воспроизвёл все 466 вероятностей исходной LRE в одной тестовой истории независимым вызовом авторского классификатора, максимальное абсолютное расхождение 0. Перефразирования между разными источниками отдельно не проверялись. Все 500 историй связаны транзитивно через повторное использование сессий между тестовыми блоками. У их совокупного результата допускается только описательная интерпретация.

## Результаты

Метрики — средние по историям, имеющим хотя бы одно размеченное свидетельство. R@20% — доля положительных реплик в первых ceil(0,2N), AUC измеряет вероятность ранжировать положительную реплику выше отрицательной, засчитывая равенство за половину. Слово — последовательность непробельных символов, стоимость усредняется по всем историям панели, включая вопросы без меток. На 479 размеченных историях основной прирост составляет +10,86 п.п., 105 выигрышей, 13 потерь и 361 ничья, при учёте всех 33 запечатанных блоков. На 420 размеченных только из дополнительных 438 историй исходная LRE имеет 62,54%, калиброванная — 73,73%. На первичной панели обнаружено преимущество калибровки относительно случайного выбора из роли user в +33,49 п.п. [24,83; 42,25]. На ней же исходный AUC вырос на 0,02877 [0,00355; 0,05304] после добавления трёх признаков.

**Связь с предыдущей репликой.** Сравнение настоящего и сдвинутого ребра на первичном показателе дало +1,41 п.п. [−3,67; +7,34], три выигрыша и три потери. На всех 479 разность +0,79 п.п., 38 выигрышей и 35 потерь. На первичной панели вторичный AUC выше при настоящем ребре на 0,02916 [0,01058; 0,04928]. На дополнительных историях средний AUC настоящего ребра 0,8416, сдвига 0,8438. При бюджете 10% на всех 479 сдвиг также впереди — 61,32% против 60,79%. Следовательно, первичный контраст даёт основание развивать калиброванное сохранение, а вклад реальной смежности зависит от метрики и выборки. Интервалы для вторичных сравнений вычислены без поправок на множественность.

**Доля текста и совпадающие оценки.** На полной выборке при сохранении 20% реплик исходный метод оставляет в среднем 8,96% слов истории, калиброванный — 7,58%, с настоящим ребром — 8,25%. У этих трёх методов нет совпадающих оценок на границе бюджета. У лёгкой модели только на трёх признаках порог попал в равные оценки у 374 из 500 историй. В основной таблице использован авторский порядок сортировки. При усреднении по равновероятному разрешению этого равенства её R@20% на 479 историях равен 72,43%, на 59 остаётся 68,39%. Число слов характеризует конкретные сохранённые подмножества; точный объём в токенах модели не измерялся.

## Границы вывода

Этот эксперимент возник после наблюдения провала LoCoMo→LongMemEval и знакомства с агрегатами этой же панели. Настоящий протокол зафиксировал семь ветвей до их обучения, однако использование ранее изученного корпуса делает важной внешнюю репликацию. Признаки роли и длины могут учитывать особенности составления LongMemEval. В авторской статье LRE LongMemEval оценивается на уровне сессий, а здесь сравнение выполнено на уровне реплик с оригинальным классификатором и одинаковым бюджетом. Результат поддерживает проверяемую гипотезу по удержанию свидетельств. Превосходство в итоговых ответах агента, в решении задач по коду или над опубликованной end-to-end SOTA требует отдельного опыта. [Первичная работа LongMemEval](https://arxiv.org/abs/2410.10813)
