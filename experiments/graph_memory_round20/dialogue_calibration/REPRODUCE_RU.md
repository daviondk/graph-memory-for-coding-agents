# Воспроизведение калибровки памяти

Используйте Python 3.12.13, NumPy 2.5.5, SciPy 1.18.1 и scikit-learn 1.8.0. Пакет содержит прогноз каждой обученной ветви, признаки ролей для аналитических контролей, отдельные бинарные метки, списки хешированных ID, аудиты каждого блока, протокол и контрольные суммы. Тексты диалогов и вопросы не экспортируются.

В каталоге с распакованными артефактами `python -B -X utf8 verify.py` проверяет целостность манифеста, независимо пересчитывает AUC по сумме рангов, математическое ожидание по равным оценкам для двух контролей, бюджетные Recall и итоговые парные показатели. Для этой команды исходные корпуса и GPU не нужны.

Для полного повторного эксперимента дополнительно нужны соседние dialogue_transfer и graph_memory_round19/locomo_edges, авторский репозиторий LRE фиксированной ревизии и LongMemEval-S по ссылкам из отчёта. При произвольной раскладке задайте DIALOGUE_TRANSFER, R19_EDGE_STUDY, LONGMEMEVAL_FILE, LRE_REPO. SHA корпуса и архитектуры фиксирует split.json. В полном пересчёте опыт выполнен двумя CPU-процессами, одна нить BLAS на процесс. Отдельные команды:

```text
python -B -X utf8 run.py 0/2
python -B -X utf8 run.py 1/2
python -B -X utf8 score.py
python -B -X utf8 audit_overlap.py
python -B -X utf8 diagnostics.py
python -B -X utf8 verify.py
```

Первые две команды можно запустить параллельно. Каждый блок сохраняет оценки и SHA-256 в файлах pred и fold; при перезапуске готовые блоки проверяются. Метка основной оценки загружается в score.py после фиксации соответствующих прогнозов. При новой пустой сборке запись манифеста производится после эксперимента; verify.py независимо пересчитывает метрики и без заранее подготовленного манифеста.

**Журнал.** Исходный протокол SHA-256 398935734a31ae98c802b393a3c42c229f2867733385e2dcfb5a6db7b511d1c2. Заполнены все 33 предзаданных блока и 500 историй. Отдельный скрипт audit_overlap.py повторно разбирает исходный JSON, проверяет перекрытие целых сессий и реплик каждого обучающего блока с тестом, число совпадений в обоих классах и паритет исходной LRE на контрольном прогнозе. Диагностика совпадения оценок и объёма сохранённых слов записана в tie-and-words.json. В results.json strict — основная панель, additional — дополнительные 438 историй и all — описательный результат 500. Параметры для каждого блока и карта допуска в обучение находятся в split.json; поштучные прогнозы сохраняют точность float64.
