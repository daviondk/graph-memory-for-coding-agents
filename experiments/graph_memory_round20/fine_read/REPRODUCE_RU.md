# Воспроизведение

На входе требуются локальные исходные траектории ISETrace, tokenizer.json и проекции из R19, а также запечатанные нативные PU-ранги 500 dev-вопросов. Конфигурация CPU и исходные данные описаны в [отчёте о графовой модели](../residual_graph/PROTOCOL_RU.md). Из этого каталога выполните `python reader.py fit`, `python reader.py dense`, затем из корня серии `python assess.py fine_read dense`. `python runtime.py` повторяет измерение добавочной задержки. Для обработки графовых рангов малого CPU-checkpoint используется [общая процедура](../run_subset.ps1). Исходный `reader.py rgcn` принимает полный нативный R-GCN.

Буквальный контекст и сохранённые позиции проверяют из корня серии командами `python render_audit.py predict fine_read dense` и `python render_audit.py score fine_read dense`. Расширенный полевой допуск и независимый пересчёт интервалов описаны в [протоколе рендера](../RENDER_PROTOCOL_RU.md). Чтобы пересчитать итоговые метрики по уже сохранённым решениям, графический ускоритель не требуется.
