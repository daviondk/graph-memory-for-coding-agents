# Можно ли обучить чтение фрагментов траектории?

На ISETrace проверяем, помогает ли перейти от фрагмента по 504 WordPiece к выбору 64-токенных блоков внутри семантически релевантных участков. Память до вопроса полная. Исходный Dense-FT обучен на авторском train. Коэффициенты нового читателя обучаем только на официальных 500 dev-вопросах, которые ранее также служили для выбора checkpoint исходного Dense-FT. На тесте 2 000 вопросов. Тест публичен, результаты предшествующих методов на нём известны.

Сохраняем два первых родителя целиком, исключаем пересекающиеся с ними блоки по точным координатам. Для каждого остального блока берём наилучший ранг полностью включающего его родителя. Предиктор логистической регрессии C=1 со сбалансированными классами и стандартизацией предсказывает пересечение блока хотя бы с одним эталонным интервалом. Используем ранги родителя, BM25, пересечение слов вопроса, длину, глубину, роль события и структурные признаки того же вызова и близости к лидирующему событию. Первичный метод сортирует по p/cost, первичный контроль — ранжирование целых родителей Dense-FT с пропуском не помещающихся. Другие сравнения: авторский префикс, чистое p, без защищённых родителей, без структурных признаков, ранги родителя и RRF BM25 × ранг. Те же коэффициенты можно перенести на ранги R-GCN без дообучения.

У всех вариантов потолок чтения 2048 WordPiece. Основная метрика Full Support по исходной реализации, вторичные Coverage, Density, использованные токены. Парный кластерный bootstrap 10 000 выборок по траекториям, seed 13. Основная пара фиксирована до вычисления результатов. Прогнозы запечатываем перед оценкой. Значения p после взвешивания классов – скор для ранжирования, бюджетный аргумент p/c справедлив для откалиброванных аддитивных полезностей и дробного выбора; Full Support этим условиям не удовлетворяет.
