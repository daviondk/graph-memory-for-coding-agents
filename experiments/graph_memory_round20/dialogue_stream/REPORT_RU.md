# Три дешёвых признака для памяти с жёстким лимитом

В момент записи нового сообщения агент знает, кто говорил и какой длины обычно были предыдущие сообщения собеседников с той же ролью. На 59 размеченных историях LongMemEval-S использование роли и наблюдаемого процентиля длины повысило среднюю по историям долю сохранённых эталонных реплик **с 49,60% до 60,34%** при бюджете 4 096 WordPiece. Разность +10,73 п.п., парный 95% ДИ [3,95; 18,64]. Восемь историй выиграли, одна проиграла, в пятидесяти результат совпал. Полностью сохранился эталон в 45,76% историй против 35,59%. Процентиль вычисляется до принятия решения из двух гистограмм предыдущих длин, по 32 ячейки для каждой роли (256 байт счётчиков uint32). Модель, словарь TF–IDF, ссылки и накладные расходы структур данных оплачиваются отдельно от лимита на содержимое. У будущего размера диалога нет входа в отбор. Блок дольше всего бюджета пропускается. После вытеснения его нельзя вернуть. Все варианты видят одинаковые завершённые сообщения. Для 2 048 токенов преимущество полной версии +5,14 п.п. [−0,85; 12,20], для 8 192 — +11,02 п.п. ## Из чего складывается выигрыш

После первичного опыта проверены отдельные признаки. На основной панели добавление только роли повысило Recall с 49,60% до 52,99%, только потокового процентиля внутри роли — до 60,62%, обоих без взаимодействия — до 59,77%. Полный вариант дал 60,34%; разность против одной роли +7,34 п.п. [1,69; 14,12]. В варианте «только процентиль» роль используется при выборе гистограммы, поэтому это ещё не изолирует нормировку по роли от нормировки по общей истории. На дополнительных 420 размеченных историях получено **48,24% → 55,63%**, а при одном процентиле — 57,15%. Все проверены обучением с исключением общих исходных сессий и дубликатов реплик между обучением и тестом каждого блока. Среди всех 479 с разметкой исходный и полный варианты дали 48,41% и 56,21%. [Анализ компонентов](components-results.json) · [Протокол анализа](ABLATIONS_RU.md)

Панель составлена из 62 историй без общих исходных сессий. Три истории без положительных реплик учитываются в стоимости. Дополнительные истории пересекаются между собой, поэтому их среднее описательное. На основной панели уже изучались другие параметры памяти. Обучение внутридоменное, признаки отражают особенности этой разметки. Сравнение измеряет сохранность исходного сообщения, оценка правильности ответа пользователя потребует генерации и независимой проверки.
