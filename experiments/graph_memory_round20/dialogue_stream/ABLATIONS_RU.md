# Вклад роли и относительной длины по отдельности

После результата основного опыта на 59 размеченных историях фиксируем диагностическое 2×2 сравнение с теми же TF–IDF, обучением и онлайн-архивом при 4 096 WordPiece. Варианты: исходный, плюс только роль, плюс только процентиль, плюс роль и процентиль, плюс также произведение. Вопрос — какой дополнительный выигрыш остаётся у полного варианта относительно «исходный плюс роль». Это ретроспективная проверка на панели из 62 историй. Дополнительно ровно тот же протокол для всех ранее выделенных блоков LongMemEval-S: 438 остальных случаев без донастройки, с исключением общих сессий и совпадающих нормализованных реплик между train/test каждого блока. Для этой дополнительной группы предыдущие офлайн-агрегаты известны, результаты данного потокового эксперимента ещё не вычислялись. Для зависимых историй даём описательные эффекты. Строго проверяем идентичность прогнозов двух общих ветвей на предыдущей панели.
