# Воспроизведение

Используются те же закреплённые corpus, LRE, версия научных библиотек и правила исключения пересечений, что в [соседнем эксперименте](../dialogue_calibration/REPRODUCE_RU.md), и токенизатор из R19 ISETrace. Авторская разметка берётся только для обучения текущего fold и для последующего подсчёта метрик. Команды:

```powershell
python streaming.py forecast
python streaming.py score
python ablations.py forecast
python ablations.py score
```

Базовая и полная ветвь второго прогона должны побайтно воспроизвести все индексы сохранённых реплик и стоимости первой выборки. Для поздних 438 историй используется назначение из dialogue_calibration; только 420 из них имеют хотя бы одну эталонную реплику. В архивах нет текстов диалогов.
