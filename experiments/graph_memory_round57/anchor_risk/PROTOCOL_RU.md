# Как механизм выбора первого файла меняет оптимальную выдачу памяти

При оценке поиска связанных файлов скрытая правка содержит m путей. Исследователь выбирает правку, затем равновероятно раскрывает один из m путей. Каждый найденный участник даёт 1/(m−1) к Recall. Для фиксированного якоря и известной вероятности каждой исторической транзакции p(e) ожидаемый вклад другого файла пропорционален сумме p(e)/[m(m−1)] по транзакциям, содержащим оба файла. Если для теста равновероятно выбирать одно **участие файла** во всём потоке, вклад равен p(e)/(m−1). При независимом назначении якорей эти протоколы меняют размерный вес наблюдения. Доказательство касается ожидаемого Recall при заданном распределении. Ограниченное окно, меняющийся код и цензура по ёмкости не обеспечивают несмещённой оценки будущего.

**Контраст до раскрытия нового теста.** Используем отдельную панель из шести публичных репозиториев, закрепляемую в ../replication. Хронологические префиксы, 2–64 изменённых Python-пути, вторая половина для теста. Для каждой подходящей правки рассматриваем все допустимые якоря с равным весом внутри коммита. Так точно интегрируется случайность выбора исходного пути. Новые файлы сохраняются в знаменателе. У каждой правки равный вес, в основном итоговом показателе у каждого репозитория равный вес. Вторичные расчёты — равный вес каждой правки в общей панели и равный вес каждого участия. Единица неопределённости — репозиторий; 20 000 парных повторных выборок целых проектов, seed 57104. Также публикуем разности по отдельным проектам.

В первичной паре обоим ранжировщикам предоставляем один и тот же набор эпизодов: восемь из общего горячего слоя R56, сначала последние изменения с m≤6, затем последние остальные. Сравниваем вес 1/[m(m−1)] с 1/(m−1). Топ-8 с известными ранее путями, предыдущая частота за 32 коммита и меньший ID разрешают ничьи, те же правила у всех методов. Чтение и доступ к метаданным у этой пары совпадают для каждого запроса. Модель генерации текста в задаче не участвует.

**Альтернативы и чувствительность.** Кроме первичной пары проверяем сырые голоса и избыточное подавление больших правок 1/[m²(m−1)], чтобы увидеть, достаточно ли произвольной монотонной нормировки. Сравниваем одни и те же веса на собственных последних восьми эпизодах и при полной доступной истории якоря. Контроль полного журнала несёт бо́льшие расходы. Точно считаем вклад всех якорей в оба протокола. Публикуем прочитанные эпизоды, участия и различия в выдаче. При выборке всех якорей новые пути получают стандартный частотный резерв и не раскрывают других участников до выставления оценки. Сохранённые данные — адреса, ранги, измерения и SHA до/для проверяемой правки. Старые панели R56 служат вторичным анализом. Преимущество классического гиперграфового представления перед произвольным современным агентом из этого сравнения не следует.

**Проверка механизма.** На малом конечном гиперграфе сравниваем прямое перечисление допустимых выдач при обоих наблюдательных протоколах с аналитическим максимумом. У весов 1/[m(m−1)] уже есть эквивалентная форма в литературе: равномерное распределение веса гиперребра по всем неупорядоченным парам.
