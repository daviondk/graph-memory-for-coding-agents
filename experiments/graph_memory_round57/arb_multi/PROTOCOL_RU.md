# Тест, подтверждённый несколькими исходными путями

Проверяем перенос идеи групповoго свидетельства на публичный поднабор v2_code2test Agent Retrieval Bench. Это прежние 105 задач из 106 авторских, с неизменной eligibility из R56; предыдущие результаты на этих задачах известны. Нового независимого набора здесь нет. До построения изменённых прогнозов фиксируем одну формулу. Условия запуска — предварительно сохранённые имена файлов, SHA, ранги и история; исходный код задач и командные строки в задачах не исполняются. [Исходный эксперимент, ограничения и источники](../../graph_memory_round56/code2test/REPORT_RU.md).

Контроль — фиксированная схема base_history из R56/additive. Пять источников голосов — опубликованные Qwen3-Embedding-4B/8B, авторские tests-only Lexical и RepoMap и исходное сходство имён. Каждый из первых 20 кандидатов источника получает 11/(10+rank). Шестой источник — список тестов по ограниченной истории local8, его голоса имеют тот же масштаб. Список событий у обоих методов — объединение до восьми последних пригодных событий для каждого distinct seed среди того же префикса не более 64 first-parent переходов. Эпизод, который отобрали два seed, декодируется один раз. Если у задачи один seed, то групповых свидетельств быть не может.

Для тестового файла t и каждого уже выбранного уникального события e с этим тестом, k_e — число различных известных seed-путей задачи в e, m_e — размер этого события. Первичный новый порядок исторического списка лексикографический. Сначала балл пар P(t)=Σ C(k_e,2)/(m_e−1), затем исходный балл L(t)=Σ 1/(m_e−1), затем исходное правило ничьих по давности и пути. Если групповых свидетельств нет, получается прежнее линейное ранжирование без изменения. Остальные пять источников, множество кандидатов, бюджеты чтения и итоговый top‑5 строго зафиксированы. Главное сравнение — новый шестой источник против исходного в том же фиксированном ансамбле. Дополнительно показываем пятикомпонентный base и опубликованные Qwen4, tests-only RepoMap, Oko и CodeNib Dense на том же срезе и при том же известном бюджете адресов. Ансамбль использует больше источников, абсолютное различие с одиночным поисковиком не является чистым эффектом памяти.

Записываем Recall@5, Hit@5 и MRR@5 по всем 105 запросам, по первичной группе задач ≥2 distinct seed и по подгруппам, заданным до построения ответов: есть отобранное событие с ≥2 seed; есть такой эпизод с допустимым тестом; реально поменялся top‑5. Последняя группа лишь описывает случаи, где предсказание метода изменилось. Измеряем число прочитанных уникальных событий и перечисленных путей, изменённых исторических списков и конечных списков/множеств, сколько истинных ответов стало доступно. Для контраста на всех задачах — парные выигрыши/равенства/проигрыши и 95% интервал бутстрэпом по целым репозиториям (20 000, seed 57063). Предсказания фиксируются в журнале до нового объединения с метками. Ранее вычисленные истины остаются доступны только стадии оценки. При совпадении всех прогнозов результатом служит отсутствие идентифицируемого эффекта.
