# Среда и воспроизведение

В этом каталоге сохраняются числовые идентификаторы запросов и полей, адреса, выбранные буквы, результаты SQL-чтения в виде координат и SHA256. Содержимое вопросов, системные журналы сервера с возможным текстом, сами выдержки и SQLite-копия полных полей находятся в частном каталоге диска D. Решение модели не может выполнить действие на машине. llаma.cpp принимает только локальные запросы на loopback, GPU-слои отключены, у процесса два потока, любой допустимый ответ — одна буква. Затем отдельный оценочный процесс интерпретирует валидную букву как один ограниченный запрос SELECT.

```powershell
$py = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $py -B prepare.py
& $py -B candidate_controls.py predict
& $py -B infer.py
pwsh -NoProfile -File finish.ps1
```

Если инференс прерывается, та же команда `infer.py` продолжает с сохранённых результатов при совпадении хеша конфигурации и каждого входа. Постоянные отказы отражаются в журнале как неуспешное предъявление. Отдельный процесс может запустить `finish.ps1 -InferenceProcess <PID>`. Он дождётся окончания указанного процесса и потребует завершённой фиксации выборов; при её отсутствии запишет ошибку до любого оценивания. В обычном режиме новые результаты сначала записываются во временный файл, затем атомарно переименовываются. `progress.json` показывает количество успешно обработанных плюс окончательно неуспешных запросов, общее число, отказы и время обновления. Числа секунд и время обновления зависят от среды.

Снимок требует локальных полей ISETrace, реестра адресов и замороженных receipts из R23/read_causes. Именно их использует prepare.py для создания двух контекстов. После инференса open_sql.py предпринимает отдельный физический SQL-запрос для каждого реального выбора модели, затем проверяет адрес и длину фактически выданного фрагмента. Гипотетические альтернативы для оценки возможного максимума читаются отдельно, их расход не включается в цену действия модели. Порядок и бюджеты восстанавливаются по [плану](PROTOCOL_RU.md), [меню](menus.json.gz) и системной инструкции в [фиксации запросов](plan-lock.json).
