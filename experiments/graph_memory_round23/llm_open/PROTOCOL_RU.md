# Пилот с одним адресуемым действием читателя Qwen

До просмотра меток выбранной выборки и до генерации решений фиксируем 32 пары. Из 1 207 траекторий берём 32 первых по SHA256 от заранее выбранной строки «R23-llm-open-v1» и идентификатора траектории. В каждой выбираем аналогично один вопрос без разметки. Одни и те же вопросы предъявляем с ratio/short и ratio/merged из R23/read_causes. Предшествующие результаты по целому ISETrace и результаты детерминированных читателей исследователям известны. Пилот проверяет одно открытие источника, условное на полном ранжировании и меню кандидатов.

1. В каждом из двух исходных контекстов с бюджетом 2 048 WordPiece строим те же окна по 128 WP и допустимые начала для SQL-чтения, что в R23/address_open. В меню до восьми вариантов сохраняем первое и лучшие по BM25, пока хватает мест; предъявляем их в исходном порядке. Каждому присваиваем одну букву от A до H, выводим короткое обозначение поля и символьного смещения плюс дословное начало окна длиной до 80 WP. Формирование списка учитывает только видимый текст и вопрос. Метод ограничивает пространство для LLM, это отдельный операционный протокол. Сохраняем совпадения/различия состава кандидатов и подсчитываем условный потолок для реально предложенных открытий.
2. У обоих членов пары общий реально оплаченный размер текста запроса, инструкции, адресов и выдержек в WordPiece. Верхний предел 768 WP; предпочтителен максимальный достижимый общий размер для этих двух меню. Для выравнивания укорачиваем дословные выдержки, включая предел 160 WP на вопрос в обеих копиях. Искусственное наполнение не используется. Отдельно публикуем фактические токены модели Qwen, которые могут различаться при равном размере WordPiece. Состав списка, входы и их хеши фиксируются до инференса. Сырые строки остаются в частном локальном кэше.
3. Читатель — Qwen3-4B-Instruct-2507 Q4_K_M в llama.cpp, CPU, максимум 2 потока, детерминированный greedy seed 13. Запрос не имеет инструментов. Грамматика разрешает ровно одну букву среди присутствующих. Шаблон предписывает трактовать текст трассы как цитату, выбрать один адрес, не отвечая на вопрос. На запрос не более 3 попыток после программной ошибки, кэш по SHA текста и конфигурации. Успешный идентичный запрос может быть воспроизведён из кэша. Постоянный отказ — нулевой результат по намерению предъявить протокол, с логом причин и чувствительностью по успешным парам. По каждой букве открывается соответствующий источник отдельным read-only SQLite SELECT и функцией paid_open при лимите 256 WP с координатами. Решения всех методов и хеш результата чтения запечатываются до оценки.
4. Первичный исход — полное покрытие аннотированных доказательств **одним открытием**. Первичная пара — Qwen merged минус Qwen short. Парный bootstrap по 32 независимым траекториям (20 000, seed 230423) и точный двусторонний тест Мак-Немара по дискордантным результатам. Для каждой доли используем Wilson 95%. Вторично — покрытие символов, любое касание эталона, попадание в правильное поле, изменение относительно первого / BM25 по тем же видимым выдержкам, исходный BM25 по окнам до сокращения, условный потолок любого разрешённого открытия и предварительное наличие полного эталона в источнике / показанных выдержках. Отдельно — число реальных эквивалентных предъявлений, токены и отказы. Статистическая мощность пилота ограничена. Это не тест генерации ответа, успешности решения исходной задачи или обнаружения конфликтующих фактов.
