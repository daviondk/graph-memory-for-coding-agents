# Дополнительные простые читатели

Во время генерации Qwen, до открытия локальных индивидуальных эталонов, добавляем два диагностических контроля к тем же меню. Возвращённые варианты уже регистрируются для вычисления достижимого потолка. Первый контроль сохраняет поле первой видимой записи и выбирает окно с лучшим глобальным BM25 среди предъявленных выдержек этого поля. Число и содержание вариантов неизменны. Второй вычисляет точное ожидаемое качество равновероятного выбора из всех восьми, без случайной ошибки одной жеребьёвки. Результаты описательные и дополняют исходную семью с одним первичным сравнением. [Правило выбора поля](../field_first/decide.py)
