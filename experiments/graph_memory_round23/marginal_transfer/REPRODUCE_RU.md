# Повтор расчёта

Нужны зафиксированные решения [transfer](../transfer/REPRODUCE_RU.md), SQLite исходных документов, [проверка первых адресов](../open_transfer/REPORT_RU.md) и общий модуль novelty.py. После них выполнить `python -B select_read.py`, `python -B evaluate_novelty.py`, `python -B sparse_pairs.py` и `python -B cost_control.py`. Первая команда обращается к источнику после принятия решения и сохраняет прогнозы до доступа к эталонным интервалам. Контрольные адреса глобального BM25 и первого окна совпадают с ранее запечатанными 1 322 открытиями. Метрики вычисляются на исходных символьных интервалах, а токены — по фактической строке с указателем на документ. [Фиксация решений](forecast-seal.json) · [Поштучные исходы](per-query.json.gz)
