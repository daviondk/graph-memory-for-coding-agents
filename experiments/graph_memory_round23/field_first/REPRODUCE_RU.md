# Повтор расчёта

После [однократного чтения](../address_open/REPRODUCE_RU.md) запустить `python -B decide.py`, затем `python -B evaluate_factor.py`. Первый шаг использует прежние доступные окна и независимо проверяет совпадение двух контрольных вариантов на уровне каждого выбранного адреса и стоимости. Файл read-lock фиксирует решения до присоединения эталонов. Второй шаг также требует совпадения с прежними исходами на всех 16 000 контрольных наблюдениях. Для расчёта доверительных интервалов используется код кластерной повторной выборки из read_causes. [Фиксация решений](read-lock.json) · [Итог](results.json)
