# Выбор поля и выбор координаты как два решения

Предыдущий опыт однократного чтения показал 454 полных попадания при открытии первого отрывка и 222 при глобальном поиске BM25 в смешанной объединённой выдаче. На тех же публичных вопросах проводим разведочное факторное исследование. Замораживаем все правила до вычисления исходов этой серии. Выводы требуют независимого подтверждения.

Переиспользуем прежние видимые окна, лимиты входа и одного чтения. Два правила выбора поля — первое поле в выдаче и поле окна с максимальным глобальным BM25. Два правила выбора координаты внутри выбранного поля — первое видимое окно этого поля и окно поля с наибольшим тем же глобальным BM25. Это сохраняет одинаковый IDF и одинаковые кандидаты для всех четырёх условий. Ранние индексы разбивают равенства. Нулевые запросы, параметры BM25 и обращение к исходному полю полностью совпадают с предыдущим протоколом. Схема даёт два прежних контроля и две новые перекрёстные комбинации.

До оценки фиксируем два парных сравнения для смешанной объединённой выдачи на всех 2 000 вопросах. (1) При фиксированном первом поле выбор координаты по BM25 против первого окна, по полному покрытию одним открытием в 256 WordPiece. (2) При фиксированном первом окне выбранного поля — первое поле против поля, найденного глобальным BM25. Для двух сравнений используем одновременные 95% интервалы с кластеризацией по траектории, 10 000 повторов. Дополнительно разбираем каждую из четырёх исходных раскладок, число реально изменённых адресов, потолок одного поля и среднее покрытие. Скрипт принятия решения не читает эталоны. Две старые комбинации должны побитно воспроизвести все 16 000 прежних действий и их фактическую стоимость.
