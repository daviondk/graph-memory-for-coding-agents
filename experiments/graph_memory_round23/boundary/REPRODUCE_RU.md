# Повтор расчёта

После [сравнения выбора поля и координаты](../field_first/REPRODUCE_RU.md) запустить `python -B extend.py`, затем `python -B evaluate_boundary.py`. В первом шаге нет доступа к эталонам. Он перепроверяет цену каждого исходного чтения, фиксирует сохранность интервала и считает точную стоимость нового ответа. Во втором шаге контроль совпадает с field_first на всех 4 000 исходных чтениях; соблюдение монотонности покрытия проверяется индивидуально.
