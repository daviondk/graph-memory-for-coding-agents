# Можно ли открыть нужную запись по видимой памяти

После анализа фрагментации на знакомом test ISETrace проверяем отдельную операцию читателя. На каждом из 2 000 вопросов разрешено одно обращение к БД. Входом служат формулировка вопроса и один из четырёх запечатанных контекстов R23 на 2 048 WordPiece. Берём оба способа отбора и оба варианта с коротким адресом (раздельные фрагменты или объединение соседей). Получатель видит только исходные выдержки и локальные координаты. Генерация текста и вызов внешних инструментов не требуются.

Замораживаем двух детерминированных читателей. Первый открывает начало первого выданного фрагмента. Второй делит каждый показанный фрагмент на неперекрывающиеся окна по 128 WordPiece и применяет BM25 (k1=1,2, b=0,75, IDF Робертсона с прибавлением единицы под логарифмом, регистронезависимые буквенно-цифровые слова). Коллекцией для IDF служат видимые окна этого же запроса и условия. Побеждает максимальный балл, при равенстве используется порядок выдачи. Читатель передаёт идентификатор поля и координату начала окна. База разрешает идентификатор в пространство конкретной истории и возвращает префикс исходного поля с данной координаты, максимум 256 WordPiece вместе с адресом. Последний токен пересчитывается на реально отрезанном тексте. Поиск читателя ограничен показанным материалом, исходное поле читается после выбора адреса. Операция может открыть продолжение, которого прежде не было видно.

Первичная метрика — доля всех вопросов, для которых одно чтение BM25 вернуло все размеченные символьные интервалы. Сравниваем объединённые и раздельные фрагменты при одном и том же отборе мелких блоков. Первичен полный test; отдельно описываем вопросы, в которых одного поля в принципе достаточно. Дополнительные метрики — доля попаданий в любое эталонное поле, доля возвращённых эталонных символов и число токенов ответа. Вычисляем парный процентильный 95% интервал бутстрэпом 10 000 выборок из историй с возвращением, seed 2302. При одинаковом числе доступных чтений прямой переход по первому адресу и отбор только целых блоков служат контролями. Разметка доступна отдельному скрипту оценки после фиксации действий. Это стенд для изоляции выбора источника, внешняя валидность для взаимодействия с языковой моделью остаётся открытой.
