# Повтор расчёта

Нужны запечатанные выдачи и каталог [read_causes](../read_causes/REPRODUCE_RU.md), исходные тексты из приватного локального кэша и numpy/tokenizers. Запустить `python -B choose.py`, затем `python -B evaluate.py`. Скрипт выбора получает вопросы из кэша без целевых ответов, строит окна только по предъявленным интервалам и сохраняет одно фактическое чтение для каждой из восьми комбинаций. Первый шаг не импортирует оценщик. Второй проверяет хеш фиксации решений, присоединяет эталонные интервалы и рассчитывает парный ДИ. Восьмёрки файлов reads содержат номер поля, начало, конец и число реально оплаченных токенов ответа БД. [Запечатанные решения](read-lock.json) · [Покомпонентные метрики](per-query.json.gz)
