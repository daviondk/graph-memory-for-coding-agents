# Что можно восстановить за одно обращение к памяти

На 2 000 вопросах ISETrace читатель получает до 2 048 токенов адресованной памяти и может один раз открыть продолжение одного из показанных источников. Здесь открытие — проверяемое обращение по идентификатору в каталоге SQLite и чтение исходного текста с выбранной координаты, максимум 256 токенов с заголовком. Это даёт 16 000 решений двух детерминированных читателей. Заранее заданная метрика требует, чтобы одно открытие покрыло все эталонные интервалы вопроса.

| Ранее доставленная память | Первое окно, полное покрытие | Глобальный BM25, полное покрытие | Глобальный BM25, попадание в поле | Глобальный BM25, среднее покрытие |
|---|---:|---:|---:|---:|
| Целые фрагменты, раздельно | 463 | 305 | 875 | 21,97% |
| Целые фрагменты, объединение по координатам | 455 | 297 | 855 | 21,76% |
| Смешанный отбор, раздельно | 463 | 195 | 653 | 15,18% |
| Смешанный отбор, объединение по координатам | 454 | 222 | 647 | 16,26% |

Первичное сравнение двух смешанных выдач с BM25 дало **+27 вопросов** или +1,35 п.п., парный 95% ДИ по 1 207 траекториям [0,40; 2,29] п.п., 59 выигрышей и 32 потери. Средняя длина открытой записи — 205,8 и 200,8 токена соответственно. Успешное открытие эталонного поля потребовалось, но само по себе редко гарантировало чтение нужного места. Для всех 453 вопросов категории multi_fact_recall ни одно из этих двух правил не вернуло весь материал за одно чтение. На 1 484 вопросах, где все доказательства относятся к одному полю, объединённая выдача с BM25 дала 222 полных ответа чтения.

**Сильный контроль** — перейти по первому адресу, сохранив порядок исходного графового ранжирования. На объединённой смешанной памяти это вернуло все доказательства для 454 вопросов, глобальный BM25 — для 222. Это мотивировало [отдельную факторную проверку выбора поля и позиции](../field_first/REPORT_RU.md). Из показателей полноты доступного контекста нельзя вывести такой же прирост в последующей операции. Выбор окна определяется обычным ранжировщиком; качество сгенерированного ответа здесь не измерялось. Исходная работа о передаче свидетельств между агентами мотивирует это разделение этапов.
