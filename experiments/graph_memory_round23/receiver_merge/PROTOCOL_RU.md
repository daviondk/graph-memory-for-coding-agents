# Сильный контроль — реконструкция отрывков у получателя

В раздельной выдаче R23 каждое поле и начальная позиция уже известны. Если передать все символы нужной цитаты, получатель способен самостоятельно склеить смежные отрывки. Поэтому предполагаемый выигрыш в целостности цитат от объединения на отправителе следует сравнить с таким же оператором на стороне получателя. Это последующий анализ знакомого тестового набора.

Протокол фиксируем до его расчёта. Смешанный отбор, 2 000 вопросов, реально переданные 2 048 WordPiece, короткие адреса. Получателю доступны только показанные в раздельной выдаче отрывки. Он группирует их по номеру поля и смещению, удаляет дубликаты, собирает пересекающиеся и касающиеся куски из полученных символов, проверяя буквальное совпадение в зонах пересечения. Группы показываются в порядке первой исходной позиции в ранге. Никакого добора или разрешения просветов. Получившееся внутреннее представление снова ограничивается 2 048 токенами с учётом заголовков. Отдельно измеряется внутренний объём и стоимость первоначальной передачи. Отправитель, напротив, выполняет тот же оператор до применения лимита передачи. У него может поместиться материал из конца выбранного списка.

Основное сравнение — полное покрытие цитат на стороне отправителя против реконструкции на стороне получателя. Для применимости измеряем второй контраст — отличие в полном покрытии при последующем однократном чтении 256 токенов одинаковым читателем BM25 по 128-токенным окнам. Оба сравнения парные, одновременные 95% интервалы по траекториям, 10 000 повторов. Контроль должен совпадать с прежней раздельной выдачей по объединению показанных координат до повторной токенизации. Любая потеря после повторной токенизации регистрируется отдельно. Объединение, выполненное у получателя, само по себе не может добавить свидетельства. Для идентификации источника используем машинные координаты сообщений.
