# Повтор расчёта

После серий read_causes и address_open запустить `python -B receive.py` и `python -B evaluate_receiver.py`. Первоначальные текстовые сообщения восстанавливаются локально из реальных полей по данным запечатанных квитанций. Функция assemble принимает только доставленные пары «смещение, текст» и номер поля. Она посимвольно проверяет перекрытия. Состав координат до финальной токенизации обязан совпасть с исходной выдачей для каждого вопроса. Затем создаются отдельные запечатанные решения однократного чтения. Оценщик обращается к эталонным диапазонам после этой фиксации и проверяет сохранение покрытия, стоимость и оба первичных сравнения.
