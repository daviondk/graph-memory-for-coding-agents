# Одно чтение документа после отбора контекста

До вычисления результатов для отдельных открытий фиксируем перенос правила R23/field_first на те же 661 внешних диалога MultiDoc2Dial. Исходная выдача two_ratio, пообъектные прогнозы, вопросы, весь пул из 488 документов и хеши идентичны исходному R23/transfer. Ранее были известны результаты покрытия из целого контекста и результаты одношагового правила на ISETrace. Результаты одного открытия на этой выборке ранее не оценивались.

Берём ровно предъявленные two_ratio интервалы, не добавляя текста. Первичная версия логически объединяет непосредственно соседствующие интервалы одного документа и сохраняет минимальный исходный ранг каждой серии. Показываем также результат с неизменёнными границами предъявленных записей. В обеих версиях доступны все и только символы замороженной выдачи. Окна для открытия длиной до 128 WP. Токенизатор тот же E5-small-v2 WordPiece, что и в MultiDoc2Dial. Используем исходные ISETrace-функции visible, rank и paid_open. Для каждого вопроса вычисляем общий BM25 единожды по всем доступным окнам с их реальными текстами. Первый видимый документ и документ лучшего глобального окна определяют два варианта первого решения. Первое видимое окно этого документа и его окно с максимальным глобальным BM25 определяют два варианта второго решения. Каждая из четырёх политик получает одно фактическое чтение до 256 WP с коротким адресом, используя SELECT по исходному документу в неизменяемой SQLite-копии. Чтения сохраняются и фиксируются SHA до вычисления метрик. Для каждого варианта отчёт содержит число реальных токенов.

Первичная пара — первый документ + лучшее окно против первого документа + первое окно, на логически объединённых интервалах. Первичный исход Full Support — доля диалогов, для которых все аннотированные символы попали в одно открытие правильного документа. Даём разность, 95% парный bootstrap по диалогам, точный двусторонний Мак-Немар и чувствительность по переиспользуемым эталонным документам. Вся таблица 2×2, попадание в правильный документ, частичное покрытие, расход, расходы первой выдачи и вариант отдельных границ вторичны. Диалоги были отобраны и оценены для другой метрики ранее, поэтому это внешняя проверка фиксированного правила на известном корпусе. Перенос с исполняемого поля на документ проверяет принцип выбора уровня источника, а не семантику вызовов инструментов.
