# Фрагментация доказательств и цена адресов источника

Проверяем, сохраняется ли эффект добора коротких фрагментов, когда координатору нужно уметь открыть источник каждой цитаты, а саму цитату требуется прочитать целиком. В основной паре используем уже запечатанные отдельные списки R22 из сильного R-GCN без content.next. Один список содержит целые PU с добором по рангу, другой — две полные PU и блоки по 64 субтокена с замороженным скором полезности/стоимости. Известны прежние результаты этих методов на test. Настраивать по нему сериализацию не будем.

**Единицы работы.** Имеются 2 000 вопросов из 1 207 историй. Исходник задаётся тройкой «история, идентификатор события, JSON Pointer» и интервалом символов [l,h). Каталог в SQLite ставит локальный номер поля в соответствие событию и указателю. Каждый показанный фрагмент проверяется по точным координатам исходной строки. Парный эксперимент держит фиксированным список ранее отобранных фрагментов. На меньшем бюджете измеряем эффект усечения того же сообщения. Оценка не претендует на оптимальный поиск при каждом бюджете.

**Форматы.** Из исходного списка составляем буквальные срезы в порядке выбора. Выдача без адресов воспроизводит R22 с переводами строки. Первый адресный контроль перед каждым срезом пишет локальный номер поля и исходное смещение. Второй контроль передаёт полный идентификатор события и JSON Pointer вместе со смещением. Форматы фиксированной грамматики, цена включает все префиксы и разделители. Новый вариант использует тот же короткий адрес и объединяет только пересекающиеся или соприкасающиеся диапазоны одного поля в исходном порядке символов; позиция объединённой записи определяется первым рангом её участников. Дополнительная версия допускает промежуток не более восьми символов, исключительно пробельных, причём берёт эти символы буквально из того же источника. Публикуем долю добавленных пробельных символов. Никаких новых смысловых записей и новых запросов к модели. Техническое разрешение локального адреса предполагает общий неизменяемый каталог. Отдельно измерим его физический размер. Без такого каталога уместен контроль с полным адресом.

**Бюджеты и стоимость.** Отдельно для каждой завершённой выдачи используем тот же WordPiece-токенизатор и реальную строку с номерами. Значения 512, 1 024 и 2 048 включают источники и все служебные символы. Последний фрагмент может быть усечён. Голый обрыв адреса считается нулевым содержимым, расход остаётся учтённым. Возможное включение пробелов за последним токеном не может вернуть непоказанное содержимое. Планируемый первичный контраст — Full Support при 2 048 для мелких против целых блоков в одинаковом коротком адресном формате без объединения. Второй заранее названный контраст — разность между обычным адресным и объединённым адресным форматом для одного и того же мелкозернистого списка по доле вопросов, где каждую эталонную цитату можно прочитать в одном показанном фрагменте. Этот критерий строже покрытия объединением разрозненных диапазонов. Знаменатель — все вопросы. Остальные контрасты описательные. Используем парную перевыборку траекторий (10 000, seed 2301), выводим исходные выигрыши/потери и одновременный интервал для двух первичных проверок.

**Диагностика.** Для проигранного вопроса классифицируем наихудший дефицит. Может целиком отсутствовать источник хотя бы одного эталонного диапазона. Если все источники присутствуют, всякий ли эталон пересекается хотя бы с одним видимым интервалом? Далее проверяем полноту символов в объединении. Если покрытие полное, проверяем, помещается ли каждая эталонная цитата в одну реально показанную запись. Опишем переходы между исходами для заданных ранее 114 выигрышей и 70 потерь. Доступ к разметке открывается только в оценщике после фиксации сериализованных координат. Публичный пакет содержит координаты, хеши и стоимость. Исходные журналы читаются как данные. Эти метрики не измеряют генерацию ответа.

У R20 union_read уже проверялись дедупликация целых PU и добор на освободившееся место, адреса находились во внешнем канале. Здесь плата за адрес входит в сообщение, фиксируется состав выбранного списка и проверяется целостность каждой цитаты.
