# Что сравнивать с упаковкой доказательств из истории инструментов

**Ближайший опубликованный контроль — Squeez-2B. Первый практически доступный нейронный экстрактор для ISETrace — VerbatimRAG ModernBERT v2.** Оба видят запрос и текст наблюдения. ModernBERT непосредственно возвращает интервалы символов, которые можно сопоставить с исходным выводом. Это позволяет измерить, поместились ли все требуемые свидетельства в контекст агента. [Squeez](https://arxiv.org/abs/2604.04979) · [ACL-Verbatim, §4.3](https://arxiv.org/html/2605.21102v1#S4.SS3) · [ISETrace](https://arxiv.org/abs/2609.25913)

Поиск охватил arXiv, ACL Anthology, репозитории авторов и карточки моделей. Использованы три группы запросов на английском: *task-conditioned tool-output pruning*, *query-aware extractive compression / reranking*, *working-context compaction agent trajectories*. Отбор учитывал тип входа, возможность восстановить точную цитату, наличие опубликованной оценки и доступность реализации. Это целевой обзор для выбора сравнений.

**Локальная проверка.** Установленные веса MiniLM-L6-v2 совпали с публичным SHA-256. На восьми заранее выделенных dev-запросах к ISETrace классификатор вернул 64 конечных оценки для восьми интервалов на запрос. Токенизация и прямой проход заняли 1,39 с суммарно на двух потоках CPU. Эталонные интервалы в проверке не открывались. Для проверочного прогона ModernBERT загружены веса авторской модели. Для Squeez, BGE и SWE-Pruner потребуются отдельные веса. [Проверка ModernBERT](published_reader/dev-seal.json) · [MiniLM-L6-v2](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L6-v2/tree/233902d25c440f23af6f7d6e94d2946bac0bee0a) · [локальный протокол и 64 оценки](minilm-dev-smoke.json)

**Проверяемое отличие.** Оценку релевантности каждого фрагмента можно оставить фиксированной и варьировать учёт уже показанных агенту символов. Предсказание — при многократном попадании перекрывающихся фрагментов в общий пул выбор по предельной стоимости объединения повысит долю полностью покрытых наборов доказательств при бюджете 2048 токенов. Эффект должен уменьшаться на траекториях с малым перекрытием. Для обоих вариантов нужны идентичные исходные поля, координаты интервалов, начальный порядок, горизонт кандидатов и токенизатор. Учитывать весь сериализованный текст, включая заголовки и разделители. Фиксировать полное и частичное покрытие, превышения бюджета, задержку чтения вместе с экстрактором и парные доверительные интервалы с группировкой по траектории. Для проверки влияния на выполнение задачи CompAct-Bench предлагает продолжать исходную траекторию одним решателем с одинаковой границей сжатия и долей сохраняемого контекста. [ISETrace, протокол](https://arxiv.org/html/2609.25913v3#A1.SS2) · [CompAct-Bench](https://arxiv.org/abs/2611.25673)

Выполнен авторский VerbatimRAG ModernBERT v2. На 192 отдельных траекториях проверены семь раскладок, расход каждого метода и повторный отбор при одинаковом индивидуальном потолке. [Полное сравнение и реальные веса](published_reader/REPORT_RU.md)
