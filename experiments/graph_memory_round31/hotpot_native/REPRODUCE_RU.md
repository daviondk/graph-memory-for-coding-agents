# Воспроизведение

Выполните `python -B verify.py` в этом каталоге для проверки поставленных индивидуальных исходов, 8192 состояний графа и контрольных сумм. Нужен только Python 3.11+. В `forecasts` лежат адреса и индивидуальные logit, исходные вопросы и тексты в этот пакет не входят.

Для повторной нейронной оценки подготовьте HotpotQA по `../support_pairs/prepare.py` на диске D. Исходники автора, конфигурация токенизатора и веса находятся в `D:/CodexResearch/x20-r31-hotpot-native/{upstream,weights}`. Команда `python assets.py` проверяет хеши локальных файлов и скачивает отсутствующие. Если провайдер Google Drive требует подтверждения скачивания, можно положить авторский `hotpot_beam2_retr.pt` в каталог весов или указать `--weight-url` с зеркалом. Скрипт проверяет SHA файла до запуска. Размер весов 1 736 237 843 байта. [Исходная работа](https://aclanthology.org/2024.naacl-long.96/) · [Публикация весов авторами](https://github.com/canghongjian/beam_retriever/issues/1)

Среда инференса — Python 3.12, PyTorch 2.6.0 CPU, Transformers 4.52.4, tokenizers 0.21.4, sentencepiece 0.2.1, protobuf 6.33.6, psutil 7.2.2. Использован предупреждающий о byte fallback стандартный конвертер токенизатора Transformers. Команды повторного расчёта в рабочей копии:

```text
python -B run.py run
python -B measure.py
python -B overflow.py
python -B counterfactual.py
python -B stock_audit.py
python -B reference.py
python -B verify.py
```

Опубликованные файлы не следует перезаписывать при сравнении времени. Для свежего замера используйте отдельную рабочую копию со скриптами, соседним `support_pairs` и зафиксированными plan-файлами, оставив каталог `forecasts` пустым. В этом режиме `run.py run` рассчитывает все прогнозы и создаёт контрольную сумму результатов. Если прогноз уже есть, программа проверяет его принадлежность плану и пропускает повторный проход. Скрипт `theory.py` отдельно воспроизводит исчерпывающую и случайную проверку леммы обмена. Время и RSS определяются загрузкой машины. Файл манифеста в архивном снимке привязан к исходным журналам времени, в новой рабочей копии сравнивайте индивидуальные решения с архивом.
