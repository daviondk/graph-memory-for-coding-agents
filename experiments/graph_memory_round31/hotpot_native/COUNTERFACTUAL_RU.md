# Адресное объяснение выбора пары и точная надёжность

После запуска панели, отдельно от исходной гипотезы, проверяем способ найти минимальное множество отзывов, при котором указанная пара станет ответом. Предполагаем полный, фиксированный строгий порядок пар, фиксированный строгий порядок первого шага и два первых живых документа G при наличии как минимум двух живых документов. Требуется одновременно восстановить причину смены, минимальный бюджет и распределение ответов для явно заданной вероятностной модели отказов.

Для каждого возможного G перебираем только пары e, инцидентные G. Пусть L=G∪e — документы, которые обязаны остаться. Для реализации G удаляются все документы выше последнего члена G в первом порядке, кроме самих G. Для каждого стоящего выше e соперника, инцидентного корню из G, необходимо удалить его второй документ. Если оба документа соперника принадлежат G, либо среди обязательных отзывов оказался член L, данный G невозможен. Иначе множество обязательных отзывов D вместе с живыми L необходимо и достаточно. Остальные документы этого состояния произвольны. Это даёт единственный минимальный сценарий для каждой пары (G,e). По всем G выбираем минимальное число отзывов и передаём адреса. При независимых отказах с вероятностями p_i вероятность этой области равна произведению p_i по D и (1−p_i) по L. Разные G задают непересекающиеся события. Сумма по ним даёт вероятность пары. Вероятность пустого результата получается по событиям с числом живых документов 0 или 1.

Проверяем на каждом из восьми фиксированных вопросов все 1 024 маски, все 45 кандидатов, точные минимальные бюджеты и каждую сохранённую область. Сверяем аналитические вероятности с перебором для 0,05, 0,2, 0,5 и неодинаковых p_i, назначенных по позиции документа независимо от эталона. Выдаём число непустых областей, размер объяснения, вероятность смены решения и доступности ответа. По вероятностной модели нет измерений частоты отказов агентов. Это постфактум системная диагностика.
