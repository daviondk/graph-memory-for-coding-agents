# Отзыв сверх гарантии у двухступенчатого поиска

Фиксируем дополнительный опыт после готовности только первого нейронного вопроса. Берём исходные восемь вопросов, два первых живых документа и семейство победителей при не более двух отзывах. Для 3 и 4 отзывов перебираем все сочетания. Истиной служит полный повторный выбор по всем баллам второго шага с обновлённым первым эшелоном. Цель — доля запросов, которые можно точно обслужить локально. У первого эшелона есть только исходные четыре адреса. Если среди них осталось меньше двух, все методы обращаются к полному источнику.

Прощупываем три сертификата поверх одних и тех же сохранённых пар, одного и того же порядка первого шага. Одиночный сертификат ищет подмножество T текущих отзывов R с |T|≤2, при котором эшелон совпадает с нынешним и выбранная тогда пара выживает. Вариант с раздельным верхним пределом проверяет корни по очереди. Берём лучший доступный сохранённый ответ e под новым эшелоном. Для каждого корня r нынешнего эшелона ищем T⊆R, |T|≤2, при котором r находился в эшелоне и старый победитель был не лучше e. Каждая нынешняя пара, доступная через r, была доступна и при T. Её качество ограничено старым победителем. Когда оба корня покрыты, e точно оптимален, даже если для корней понадобились разные подмножества. Контроль с глобальным префиксом хранит столько же лучших по совместному баллу пар, сколько достигнутых победителей. Любая выжившая запись префикса внутри нынешнего первого эшелона точна. Иначе необходим полный поиск. Объединённый вариант требует дополнительного места и считается отдельно. Непроверенное применение сохранённых пар служит диагностикой ложной уверенности.

Основной контраст — доля сертифицированных состояний для раздельного и одиночного сертификатов, отдельно при 3 и 4 отзывах, по вопросам и вместе. Фиксируем точность всех подтверждённых ответов, число обращений к полному порядку, число частичных проверок. Все структуры опираются на уже материализованные баллы. Абсолютное ускорение сетевых или GPU-запросов здесь не измеряется. Распределение равновесных множеств отказов также диагностическое.
