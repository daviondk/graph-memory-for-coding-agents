# Независимая оценка выдержек

Оценку A выполнил агент Codex в отдельном рабочем контексте по полям claim и excerpt и опубликованной шкале S/P/N. Точные идентификаторы версии серверной модели и сборки в этой оценке не зафиксированы. Оценку B сформировала локальная Qwen3-4B-Instruct-2507 (квантизация Q4_K_M) через llama.cpp на CPU и двух потоках при температуре 0 и seed 31. Сервер увидел только утверждение и пронумерованные фрагменты выдержки. Каждый запрос был отдельным обращением без истории соседних примеров. Номер фрагмента переводится кодом обратно в дословную цитату. A не видел выводы B. Две оценки получены разными моделями, человеческой разметки нет. Преднамеренно сбалансированная выборка из 24 примеров даёт диагностический показатель соглашения, не оценку его частоты для всех 1200 вопросов.
