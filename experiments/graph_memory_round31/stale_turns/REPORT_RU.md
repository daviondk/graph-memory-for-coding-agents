# Локализация факта внутри сессии агентной памяти

На основной панели STALE из 320 ранее не изучавшихся сценариев и 960 вопросов обе точные цитаты доставлены в 285/960 случаях при совместном выборе реплик, в 175/960 при гибридном поиске по окнам и в 286/960 при том же ансамбле без связи. В этом условии два адреса сессий уже известны от составителя теста. При самостоятельном выборе адресов соответствующие числа — 114, 62 и 115 из 960.

В первоначальном пилоте из восьми сценариев адреса обеих записей о состоянии находились чаще, чем в переданной выдержке одновременно помещались полные формулировки. Здесь взяли полную опубликованную коллекцию. Все прежние восемь попали в разведочную часть из 80 сценариев. Алгоритмы зафиксированы до оценки и не обучались на этом корпусе. Проверяется совместное извлечение пары подтверждений при одинаковых адресах, фактических затратах и вопросе. В STALE основная авторская метрика оценивает применение изменений в ответе на три разных вопроса. [Chao и соавт., STALE](https://arxiv.org/abs/2605.06527)

## Парные проверки и простые контроли

- **Pair против «BM25 + E5 по окнам»**. При заданных адресах 11,5 п.п. [7,7 … 15,2], уровень 97,5%. Число исходов в пользу Pair, против и равных по вопросам — 167, 57, 736. При самостоятельном поиске 5,4 п.п. [3,5 … 7,4].
- **Pair против «Ансамбль без связи»**. При заданных адресах -0,1 п.п. [-0,7 … 0,5], уровень 97,5%. Число исходов в пользу Pair, против и равных по вопросам — 3, 4, 953. При самостоятельном поиске -0,1 п.п. [-0,3 … 0,0].
- **Pair против «Начало сессии»**. При заданных адресах 10,0 п.п. [4,8 … 15,0], уровень 95,0%. Число исходов в пользу Pair, против и равных по вопросам — 213, 117, 630. При самостоятельном поиске 5,3 п.п. [2,6 … 8,1].
- **Pair против «Конец сессии»**. При заданных адресах 26,9 п.п. [23,0 … 30,8], уровень 95,0%. Число исходов в пользу Pair, против и равных по вопросам — 276, 18, 666. При самостоятельном поиске 10,6 п.п. [8,1 … 13,1].

Интервалы рассчитаны повторной выборкой 320 целых сценариев, 10 000 повторов. В оценке двух исходных контрастов используется 97,5%-й интервал на каждый, в остальных — описательный 95%-й. Раннее и позднее окна добавлены как позиционные контроли до открытия разметки. Эта проверка существенна на синтетических диалогах, где место исходного утверждения может служить подсказкой. Все вторичные выборы лучшего метода по таблице описательны.

Для совместного выбора / ансамбля без связи / гибридного окна / первого / последнего окна на известных адресах получены dev — 78/78/44/51/3 из 240, all — 363/364/219/240/30 из 1200. Распределения по SR, PR, IPA, T1 и T2 и все 24 000 записей доступны в score.json и score-rows.json.gz. Подсчёты по 400 сценариям включают основную панель и разведочную часть.

## Где теряется материал

Среди 960 вопросов при обычном поиске обе размеченные сессии оказались в выданной паре в 358 случаях. При предоставлении правильных двух сессий и том же точном бюджете диагностический выбор по верной разметке мог доставить обе цитаты в 834 случаях среди всех окон, центрированных на репликах, и в 936 среди всех окон с шагом 48. Когда начало окна ставится около границы известного целевого спана, это удаётся в 945 случаях. Последняя цифра относится к трём заранее определённым позициям, поэтому это достижимый результат с привилегией, а не формальный максимум всех возможных подстрок.

## Калибровка семантической достаточности

Два независимо работавших агента Codex оценили 24 пары «утверждение — реальная выдержка» из разных проверочных сценариев. Они совпали в 18/24 случаях, κ Коэна 0,62. По каждому решению о полной или частичной поддержке проверено буквальное вхождение выделенной оценщиком цитаты. Рецензенты видели только факт и выдержку. S — достаточное обоснование, P — содержательная частичная поддержка, N — отсутствие поддержки.

## Затраты и границы вывода

Во внешнем контуре прочитаны 20000 сессий и 118679 пользовательских реплик, отдельно закодированы 10119 локальных окон затронутых сессий. На T320 одной паре соответствуют в среднем 273,85 нативных токена Qwen при заданных адресах и 273,89 при найденных. В каждую пару включены идентификаторы и даты. Длина каждой выдачи в каждом условии совпадает у всех 10 методов. Независимый аудит проверил 19630 фактических двухчастных выдач, 7270 различных фрагментов и восстановил обычный прогноз при физическом исключении остальных вопросов и диагностических адресов в 8 сценариях.

Глобальный гибрид сначала выбирает две разные сессии среди 50. Локальные окна привязаны к 96 токенам Qwen, у сетки шаг 48. Частная поздняя свёртка применяет MaxSim к эмбеддингам токенов замороженного E5-small-v2. Полноценный обученный ColBERT имеет собственные веса. Адресная информация от авторов доступна только для условной диагностики. GPU или внешние API для расчёта эмбеддингов и метрик не использовались. [ColBERT](https://arxiv.org/abs/2004.12832) · [E5](https://huggingface.co/intfloat/e5-small-v2)

## Повторяющиеся сюжеты и устойчивость вывода

В 400 сценариях обнаружено 1186 разных нормализованных формулировок вопросов из 1200 и 400 различных текстовых пар старого и нового фактов. Консервативная группировка связывает два сценария при точном совпадении хотя бы одного вопроса, совпадении обеих эталонных фраз или сходстве полных троек вопросов по множеству 5-грамм не ниже 0,90. Тогда на 320 проверочных сценариев остаётся 309 компонент, а 2 проверочных сценариев связаны с разведочной панелью. Обучения по их результатам не было. При пересэмплировании компонент альтернативные 97,5%-е интервалы в процентных пунктах для совместного выбора против гибридного окна и против ансамбля составляют соответственно [7.72 … 15.30] и [-0.73 … 0.52].

По точному содержанию пользовательских реплик имеется 12995 уникальных сессий из 20000. 5020 разных текстов встречаются более чем в одном сценарии. Независимость от состава других наборов памяти этот синтетический тест установить не позволяет.

Критерий перехода к дорогому эксперименту с ответами не достигнут. Предварительно требовался положительный прирост по доставке пары на независимой панели против обоих основных контролей. Поэтому для этой версии политики завершены объективная оценка и две семантические проверки одного набора из 24 примеров. Сравнивать её со штатным результатом CUPMem по конечным ответам оснований нет.
