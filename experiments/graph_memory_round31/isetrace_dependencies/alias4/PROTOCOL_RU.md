# Дополнительная проверка на расширенном распознавании полей пути

Исходный учёт ISETrace использовал два имени поля пути. Независимый аудит источника подтвердил ещё два допустимых имени; новая версия журнала — ise4-events.json.gz. До повторного вычисления BM25 и результатов фиксируем все 32 впервые подходящие сессии (11 с ≥3 чтениями и физическим пересечением, 2 с пересечением и двумя чтениями, 19 без пересечения) и отдельно каждые изменившиеся ранее измеренные сессии. Первичная внешняя проверка — только 11 новых ≥3/пересечение. Используются без настройки ранее зафиксированные BM25, K=4, 64 запроса, компилятор масок, producer, дедупликация равных масок. Ранее известные изменённые сессии не включаются в независимый знаменатель. Полное перечисление всех подмножеств продолжает проверять корректность. Латентность на малой панели повторно не измеряем. Из-за малого числа сессий основной отчёт показывает число выигравших сессий и абсолютные разницы наряду с кластерным интервалом.
