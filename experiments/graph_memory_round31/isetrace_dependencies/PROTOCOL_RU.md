# Множества зависимостей на подлинных перекрытиях ISETrace

R30/witness_handoff независимо верифицировал 172 361 наблюдение строки в 3 254 настоящих успешных read-вызовах ISETrace. Единица канонического содержания — SHA пути, исходный номер строки и SHA всех байтов строки, версия которой реально прочитана. Мы используем этот каталог целиком и заново сверяем физический текст отобранных строк со входным траекторным JSON для измерения лексического ранга. Исполнение команд из данных не требуется. Основная когорта — все 67 сессий с ≥3 прочтениями и хотя бы одним настоящим повторным каноническим атомом в разных сообщениях. Отдельные когорты — остальные 37 сессий с таким повтором и только 2 сообщениями, а также 176 сессий с ≥3 прочтениями и без повторов. Произвольных наложений и искусственно выбранных координат для включения в основную когорту нет.

Определяем оператор **отзыва канонического содержания, упомянутого в выбранном сообщении**. Устаревание каждой затронутой версии строки запрещает все её повторные появления в других сообщениях. Это AND-зависимости от атомов. Для сценария потери одной доставки при наличии другой применима иная, ранее исследованная OR-семантика. Для каждой сессии два реальных уровня кандидатов: первичный — каждое действительно полученное вхождение исходной строки; дополнительный — все подтверждённые строки одного реального read как единый составной кандидат. Для целого блока требуется актуальность всех его атомов. Повтор одного и того же кандидата в разных наблюдениях сохраняет свой порядковый номер. Время построения графа, связывания атомов, образования масок, отбора строк и физическое состояние учитываем.

Первичный порядок задаёт BM25(k1=1,2; b=0,75), отдельный локальный корпус кандидатов каждого уровня, запрос — исходное natural_language_intent сессии. Токенизация по буквенно-цифровым словам, casefold. Формула IDF log(1+(N−df+0,5)/(df+0,5)); уникальные термы запроса. Разрешение ничьих — более позднее сообщение, затем меньший исходный номер кандидата. Дополнительный порядок recency использует те же вхождения и детерминированное разрешение ничьих, без BM25. Это явно заданные обычные политики чтения; оценка библиотеки не претендует на качество модельного ответа или совпадение с оценками из статьи ISETrace.

Кэши K=1/2/4/8/64: обычный порядок; один лучший на производителя; дедупликация фактического множества канонических атомов (равенство всех координат с байтами); дедупликация одинаковых ID-масок; недоминируемые по включению масок при фиксированном ранге. Основное сравнение — **K=4, BM25, строки, 67 непустых перекрывающихся сессий**, специальное правило против producer и mask-dedup. Дополнительно показываем общий случай K до 64 и обе другие когорты. Для каждой сессии оцениваем 64 зафиксированные распределениями 0,1/0,3/0,5/0,8 комбинации канонических отзывов (16 хеш-наборов на уровень) и все одиночные удаления. Основная статистика — доля независимо доказанных исходов, включая явно доказанное отсутствие; промежуточный hit не может подменять точную проверку. Для всех политик один благоприятный скалярный сертификат сильнейшего не представленного возможного победителя. И исход производителя, и все части блока при проверке сравниваются с независимым прямым объединением канонических атомов и полным сканированием фиксированного порядка. Дополнительно фиксируем верхнюю границу присутствия точного ненулевого победителя, цену полного fallback, число физических записей и байты.

95% интервалы — парная кластерная выборка сессий с одинаковым весом каждой сессии для 64 событий. Одно и то же сообщение не считаем независимым повтором. Дополнительно проверка возможных победителей по всем подмножествам в сессиях с ≤12 событиями, отдельно от вероятностной панели. Наличие улучшения только над простым producer не обосновывает превосходство над одинаковыми масками. Кандидаты исходно реальны, конкретные операции отзыва сгенерированы; частота отзывов и поведение пользователя в эксплуатации неизвестны.
