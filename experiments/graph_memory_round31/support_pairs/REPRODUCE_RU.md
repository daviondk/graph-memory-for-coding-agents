# Воспроизведение

Использовали Python, NumPy, PyArrow и curl.exe в Windows. Переменная PRIVATE в prepare.py задаёт внешний каталог для корпуса на D. Для нового запуска сохраните отдельную копию папок experiments и используйте пустой каталог данных. Выполните в support_pairs последовательно `python prepare.py`, `python rank.py`, `python measure.py`, `python score.py`. Код загружает ровно ревизию из source.json. Для проверки опубликованного прогона без сети используйте `python ../verify.py`. Время построения в наносекундах является измеряемым полем и зависит от машины. Итоги по правильности воспроизводятся из рангов и списков отказов.
