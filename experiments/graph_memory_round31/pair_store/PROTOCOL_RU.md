# Физическая стоимость сохранения и чтения совместной опоры

Берём зафиксированные входы и ранги всех вопросов HotpotQA distractor dev в support_pairs. Основной режим — заранее вычисленная совместная оценка пары документов, до двух недоступных документов, выбор первой допустимой пары. Каждый способ записи получает тот же ранг и тот же ID вопроса. Сравним фактические размеры независимых SQLite-файлов после VACUUM, размер сохраняемой полезной нагрузки, стоимость записи и время обслуживания запроса. Для таблиц с одинаковым смыслом добавляем компактный сильный контроль: весь список из не более 45 пар можно упаковать всего в 45 байт на вопрос. Новый метод обязан сравниваться и с этим вариантом.

Режимы — индексированные отдельные строки, все ребра в однобайтовом списке по рангу, минимальный список достижимых по дереву, линейно-алгебраическое представительное семейство, обычный top-6 с точным резервом и прямой массив предвычисленных результатов для всех 0/1/2 отзывов. Общая справочная таблица заголовков и исходные документы исключены у всех методов. Во всех точных сравнениях получателем ответа служит один и тот же код пары. Таблица прямых ответов получает адрес по размеру множества и рангу комбинации, наличие резервной БД учитывается в суммарном размере там, где он используется. Читаем реальный файл в SQLite, не используем внешнюю модель и сеть. Сценарии вне гарантированного предела отдельно измеряются с консервативным резервным поиском.

Для 128 вопросов, выбранных только по хешу, до просмотра результатов измеряем 0, 1, 2, 3 и 4 целевых/случайных отзыва, где хватает документов. Намеренно включаем запросы, задевающие лидера. Перемешиваем методы и запросы, проводим пять повторов на тёплом процессе. Публикуем p50 и p95, число SQL запросов, считанные байты и различие по случаям. Время подключения и прогрева отдельно от основного сервиса. Это исследование SQLite в одном процессе, однопоточный режим. Нового обучения нет. Чтение и непредусмотренные отзывы проверяются полным перебором реальных пар. Выгода может ограничиться дисковым размером даже при точном результате.
