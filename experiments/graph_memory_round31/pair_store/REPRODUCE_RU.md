# Воспроизведение

Сначала подготовьте support_pairs по соседней инструкции. Из новой копии каталога выполните `python store.py`, затем `python profile.py`. Первая команда создаёт шесть отдельных физических файлов по пути PRIVATE/stores из соседнего prepare.py и остановится, если обнаружит результат старого запуска. Ранги и компактные списки также входят в архив. Для проверки сохранённых измерений достаточно `python ../verify.py`. Наносекунды в timing.json.gz — фактические показания исходной машины. Колонки журнала заданы в profile.py.
