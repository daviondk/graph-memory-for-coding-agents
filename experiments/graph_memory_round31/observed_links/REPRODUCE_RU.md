# Воспроизведение

Подготовьте наблюдения HotpotQA через `python ../support_pairs/prepare.py`. Для E5-small-v2 используйте ONNX и tokenizer.json из пути E5, указанного в graph_memory_round29/stale_reader/retrieve29.py. Контрольные суммы и 512 ID плотной панели лежат в plan.json. В новой копии каталога последовательно выполните `python predict.py` и `python score_links.py`. Первая команда записывает прогнозы до доступа оценщика к меткам. Вторая восстанавливает все парные сравнения из прогнозов. Проверка сохранённого снимка без корпуса выполняется из родительского каталога командой `python verify.py`.
