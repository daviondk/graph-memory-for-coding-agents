# Как выбрать второе чтение по одному наблюдению

На HotpotQA distractor первое действие имеет доступ лишь к вопросу и названиям предложенных документов. После выбора одного заголовка разрешено прочитать первые 192 WordPiece-токена его текста. Цель — выбрать адрес второго документа и передать два адреса. Тексты остальных кандидатов в момент прогноза недоступны. В предшествующем диагностическом эксперименте на том же dev-наборе уже измерялся результат при полной видимости текстов. Разметка вопроса в процессе выбора адресов этого опыта недоступна. Результаты относятся к новому ограничению на чтение на знакомом корпусе, а не к слепому соревнованию с лидербордом.

Основная панель — все 7 405 вопросов, первое чтение определяется BM25 по названиям. На независимо выбранных по хешу 512 вопросах дополнительно используем E5-small-v2 INT8 CPU для первого заголовка и сильного варианта выбора второго названия по исходному вопросу и фактическому фрагменту первого чтения. В E5 батчи включают только сведения, доступные в текущем запросе. Истина остаётся недоступной до seal. Во всех вариантах внутри панели совпадают первое чтение, максимальное число дополнительных токенов и набор допустимых вторых адресов.

Контроли: второе название по исходному вопросу, расширение запроса словами из прочитанного фрагмента, приоритет заголовка, буквально упомянутого в нём, и тот же приоритет после детерминированной перестановки концов связей. Для явных упоминаний кандидатный метод учитывает соседние слова вопроса в окне ±12 лексических токенов, отбрасывая уже объяснённые самим первым заголовком. Ближайший сильный контроль знает те же упоминания и тот же базовый порядок по расширенному запросу, без анализа окрестности упоминания. При отсутствии явной связи оба используют один запасной порядок. При этом один и тот же текст можно непосредственно искать при запросе или обработать заранее при записи в память. На единичном запросе слово «граф» само по себе не означает выигрыша.

Первичная метрика — доля вопросов, где выбранные два адреса совпадают с двумя эталонными документами. Первичный парный контраст — локальные слова возле упоминания против явного упоминания с расширением запроса на полной панели. Также приводим долю верных первых чтений, условную точность второго при правильном первом, изменение от простого исходного поиска, срабатывание при нескольких кандидатах, расстояние до начала обнаруженной связи и условия переноса на малой плотной панели. Одинаково учитываются случаи, где первая ошибка делает полный успех невозможным. Кластерная единица интервала — вопрос; перекрытия энциклопедических источников учитываем как ограничение. При этом число источников, реально просмотренных до второго решения, всегда равно одному.
