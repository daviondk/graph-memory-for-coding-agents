# Запуск и проверка

Откройте `evidence.html` в браузере. Можно выбрать вопрос, отметить недоступные источники, раскрыть оба сохранённых списка и сравнить результат с эталонными названиями. Для проверки примера на снимке выберите вопрос, начинающийся с «Which dog breed», и отзовите German Spitz и English Springer Spaniel.

Для живого режима выполните в этом каталоге следующую команду стандартного Python и откройте напечатанный локальный адрес. Значение порта 0 выбирает свободный TCP-порт. Сервер работает с локальной копией SQLite в режиме чтения.

```powershell
python serve.py --port 0
```

Для проверки вычислений выполните команды ниже. Первая проходит через функцию SQL-запроса для каждого подмножества источников. Вторая запускает временные локальные процессы Python и Chrome, проверяет интерфейс в обоих режимах и создаёт снимок, отчёт браузера и контрольную сумму автономного перебора. Проверено с Python 3.14.4 и Node.js 24.14.1. Пути к интерпретатору Python, исполняемому файлу Chrome и временному каталогу с профилем настраиваются переменными окружения `PYTHON`, `CHROME_PATH` и `INSPECT_BROWSER_TMP`. Для работы с готовой панелью достаточно поставляемых HTML, SQLite и JSON. Эти проверки можно выполнить в отдельной копии каталога.

```powershell
python -B verify_demo.py
node browser_check.mjs
```

Для повторной сборки из исходных расчётов нужны каталог `../support_pairs`, его таблица рангов, результаты расчёта списков и проекция входных данных HotpotQA, созданная `../support_pairs/prepare.py`. Затем выполняется `python build_demo.py` в окружении с pyarrow. Сборка сверяет хеши проекции входов и разметки, содержимое таблиц и целостность SQLite. Исходная версия, ссылка и SHA256 корпуса указаны в [описании входов](../support_pairs/source.json). Хеши выходных данных и состав панели приведены в [build.json](build.json).
