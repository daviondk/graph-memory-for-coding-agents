# Дополнение по схеме ISETrace

Повторный просмотр документации инструмента и проверка всех физических строк из первичного опыта показали, что функцией read предусмотрены четыре эквивалентных ключа пути. Инвентаризация первоначально охватывала path и file_path. Независимый проход обнаружил также file и filePath, в том числе 348 успешных обращений к отфильтрованным benign-текстовым файлам до проверки информативных строк. Исходные численные файлы ise-* сохраняются. До сравнительных результатов расширенной панели фиксируем повтор всех вычислений на четырёх именах с обычным порядком path, file_path, filePath, file при нескольких строковых вариантах. Другие правила и модели те же. Результаты расширения маркируются ise4-*. Никакого отбора по исходам/нулевым повторам. Основная проверка SWE-Explore независима от этой схемы.
