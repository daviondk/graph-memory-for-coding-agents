# Инвентаризация до выбора алгоритма

Сначала считаем реальные независимые вызовы чтения файла, пересечения между вызовами, многократные назначения тому же адресу и отдельно видимые операции делегирования. Сравниваем две выпущенные трассировки. Первая — англоязычные научные Python-задачи SWE-Explore Verified с ограничениями R27 по безопасности, production Python, положительным ограниченным строкам и фиксированному base_commit; встречаются независимые успешные траектории для одного issue. Вторая — оригинальные журналы ISETrace с настоящими результатами read для безвредных текстовых документов, локальный опубликованный архив. Считаем индивидуальные и групповые отсутствия/обрезки. Входные файлы и команды агентских задач не исполняются. Текст команды и внутренние рассуждения агентов не требуются. До выбора основного теста исследуем схему и частоты; отчетливо укажем, где отказ смоделирован, кто наблюдал один документ повторно и есть ли фактически отдельные работники.
