# Граница применения интервала при пересмотре нескольких источников

На 320 синтетических пулах с точной целочисленной полезностью и единым порядком при равенстве алгоритм одномерного индекса воспроизвёл все 5 760 осевых точек независимого полного перебора. Отдельный пример с четырьмя кандидатами подтверждает необходимость проверять соседние целые значения. На поправках от −4 до −1 лучшим был пакет с маской 2, при нуле — маска 1, при положительных значениях — маска 12. Три равные по полезности прямые сходятся при нуле, и стабильный порядок выбирает внутреннюю по наклону. Отсутствие отрезка ненулевой длины у такого пакета имеет значение для точного поиска. [Протокол](PROTOCOL_RU.md) · [Исполнитель перебора](experiment.py)

**Два независимо допустимых изменения могут вместе сменить пакет.** Для бюджета 2 возьмём дорогой кандидат с ценой 2 и полезностью 5 и два кандидата ценой 1 с полезностями 2. Первый источник поддерживает один дешёвый кандидат, второй источник — другой. Если применить к любому одному источнику прибавку +1, старый пакет удерживается по правилу разрешения равенств. Если применить обе прибавки, два дешёвых кандидата получают 6 и вытесняют дорогой. Независимый выбор точки из каждого осевого интервала поэтому опасен даже при непересекающихся множествах поддержанных кандидатов.

При этом есть дешёвый достаточный двумерный сертификат. Полный пакет сохраняет оптимальность в выпуклой оболочке точек, в каждой из которых он был выбран. Для любого конкурента разность оценок аффинна, а равенство разрешает один и тот же порядок. Если конкурент стоит раньше исходного пакета, разность во всех базовых точках строго положительна; положительна и любая их выпуклая комбинация. Для остальных конкурентов достаточно неотрицательной разности. В каждом квадранте такой сертификат использует треугольник с вершинами в нуле и на двух осевых границах, измеренных с неизменным вторым весом. Вся область сохранения может быть шире.

На сетке 9×9 в 320 пулах исходный пакет сохранялся в 13 180 из 25 920 точек. Прямоугольное правило согласилось на 11 986 точках, 577 из них были ошибочными, ошибки встретились в 152 пулах. Сертификат выпуклой оболочки согласился на 6 052 точках, все оказались корректными. Числа характеризуют выбранный синтетический генератор; частота одновременных поправок в практическом агенте здесь не измерялась. [Данные по каждому пулу](pools.json.gz) · [Итоги](results.json)

`python -B experiment.py` повторяет перебор и сравнивает результаты со всеми записанными масками. Одномерная функция перенесена из исследованной реализации с заменой конечной области теста на −4…+4; сохранены хеши исходной реализации, самой функции и протокола.
