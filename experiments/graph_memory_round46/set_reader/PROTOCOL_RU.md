# Наборная выдача из наблюдаемой памяти при фиксированном качестве фрагментов

До вычисления новых исходов фиксируем 214 публичных удержанных состояний из R45 с 18 598 кандидатами и основной срез 204 вне старого пилота, репозитории отделены от train/dev. Все первичные и дополнительные сравнения парные. Ранее известны результаты Qwen и других ранжировщиков на Cal500. Выводы касаются повторно используемой публичной калибровки. R37 проверил MMR по эмбеддингам BGE; R39 обучал условную вероятность ближайшего полного набора; R45 измерил один и тот же Qwen и слияние рангов. Впервые в этой серии применяем детерминантное ранжирование поверх **неизменных** скалярных оценок Qwen и отдельно проверяем, помогает ли предварительное условие на фрагментах, которые агент видел к началу запроса. [Предыдущая полная панель](../../graph_memory_round45/qwen_panel214/REPORT_RU.md) · [Greedy MAP для DPP](https://proceedings.neurips.cc/paper/2018/hash/dbbf603ff0e99629dda5d75b6f75f966-Abstract.html)

**Вход.** Точное семейство и параметры одиночного Qwen-предсказания взяты из подписанной R45. Слова кандидата представлены BPE-токенами первых 511 позиций той же самой сериализации пути и текста, EOS исключаем из сходства. Признаки альтернативного автора, скрытые сертификаты, пути вне этого префикса и сведения из будущих решений недоступны. В пределах состояния строим TF–IDF с tf = 1 + log(count), idf = 1 + log((1+n)/(1+df)), L2-нормировку и матрицу сходств G = XXᵀ. Релевантность задаётся u(i) = −log(r_i), где r_i — ранг исходной Qwen, согласованный с её детерминированным порядком. Гладкий общий PSD-оператор K = (1−β)I + βG, заранее фиксируем β = 0,8. Kernel L = diag(exp(u/2)) K diag(exp(u/2)). Greedy MAP под фиксированным размером последовательно максимизирует u(i) + log Var_K(i | предыдущие выборы). Выдаём полный порядок, включая позиции при убывании абсолютного детерминанта. Фактор Холецкого проверяем прямыми отношениями детерминантов на малых панелях. Это применение опубликованного алгоритма; авторские модели SERBench и DPP для рекомендаций имели другие входы.

**Контроли.** Основной контраст DPP минус индивидуальный Qwen без обработки признака просмотра на Complete-MSS@5, соответствуя авторскому договору отсутствия маски. Параметры фиксированы до оценки и не подбираются на Cal500. Отдельно считаем β = 0 (точное равенство Qwen), β = 0,5 и 0,95 как анализ чувствительности. Согласованный по единственному ранее выбранному кандидату MMR-контроль считает u(i) + log(1−max_j (β G_ij)^2). Он использует те же признаки и шкалу штрафа и совпадает с DPP после самого первого выбранного элемента. Это вариантизация MMR, указанная формула является её полным описанием.

**Память прежде просмотренного.** Всем вариантам с отсрочкой показываем один и тот же флаг ранее просмотренных кандидатов. Непросмотренные кандидаты идут перед просмотренными. В обычном варианте DPP ковариация будущей выдачи уменьшается только после фактического выбора в текущем пакете. В дополнительном варианте проецируем пространство непросмотренных сначала на дополнение к линейной оболочке всех прежде просмотренных в данной версии, затем осуществляем обычный жадный выбор. Для всех просмотренных элементов используем общий неизменный хвост по Qwen. Контроль исторического эффекта — такая же предварительная проекция, после которой оценка индивидуального кандидата статична и не зависит от других выбранных в пакете. В срезе без ранее просмотренных единиц историческая и обычная DPP обязаны совпасть. Указываем числа состояний, где ранги действительно изменились. Предварительная проекция не содержит ответов, поведенческие признаки наблюдаемости относятся только к режиму с отсрочкой.

**Оценка.** Семь метрик R45, показатели полного набора для последовательного префикса полных единиц при общих 2 048 и 6 144 токенах, расходы, число возвращённых единиц и число затронутых запросов. Вторично добавляем авторский тип ограничения только по токенам: проходим глубже восьмой позиции до первого превышения общего предела. Для кредитования набора пересчитываем сертификат на всём допустимом префиксе. Для безмасочного первичного и остальных помеченных сравнений приводим разницу, случаи выигрыша/потери, макро по репозиториям и парный 95%-й интервал по 20 000 перевыборок целых репозиториев с seed 4621406. Группы seen/no-seen описательны. Никаких отправок в скрытый оценщик. Протокол публикации SERBench использует иную панель Test500 и приватные покомпонентные предсказания.
