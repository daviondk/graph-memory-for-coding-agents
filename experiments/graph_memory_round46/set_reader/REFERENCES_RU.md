# Что опубликовано для сравнения с SERBench

**Авторские числа.** Удержанный Test500 включает 500 состояний из 45 репозиториев. Для основной строки Qwen3-Embedding-8B ранжирует кандидатов, Qwen3-Reranker-8B переупорядочивает первые 100, по результатам эмбеддинга. Уже просмотренные элементы остаются доступны наравне с остальными. На Test500 авторская система имеет Complete-MSS@5/@8 61,4% и 72,4%. Во втором методе DeepSeek-v4-pro предлагает набор из восьми единиц на основании состояния и до 80 кратких карточек. DeepSeek-v4-flash расширяет и затем финализирует набор в бюджете до восьми и 6 144 токенов. Результат 73,0% и 80,6%. Воспроизведение этого контроллера подразумевает конкретные модели, материализацию карточек, поиск дополнений и правила финализации. Использование Codex или Jev изменило бы эксперимент. Для 12 авторских методов независимо получили и сохранили сами JSON-результаты и их SHA-256. Файлы Qwen и MSS содержат агрегированные метрики, включая несколько глубин.
