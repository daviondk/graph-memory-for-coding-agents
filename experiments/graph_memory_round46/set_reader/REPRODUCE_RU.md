# Воспроизведение исследования

Для проверки исходов из этого каталога достаточно стандартной библиотеки Python 3.11+ и команды `python -B verify.py`. Для сопоставления рекурсивного алгоритма с прямым вычислением детерминантов нужны также NumPy и SciPy и команда `python -B verify_dpp.py`. В рабочей копии должны присутствовать сохранённые числовые прогнозы и сертификаты. Исходный код и текст репозиториев в них отсутствуют.

Для полного повтора нужны соседние каталоги [R45](../../graph_memory_round45/qwen_panel214/), [R37](../../graph_memory_round37/serbench_reference/) и локальный официальный [SERBench](https://github.com/LordTARN1SHED/SERBench/tree/8c27a88e48dcbcd4a5745573c95937a4740f4406). Точные входные BPE-массивы хранятся приватно на D в `x20-r39-embedding-runtime/runs-r40-lexical-native-input/matched-tokens.json.gz`. Их можно восстановить по [инструкции R45](../../graph_memory_round45/qwen_panel214/REPRODUCE_RU.md); контрольная сумма проверяется до расчёта. Весовой файл дополнительного cross-encoder скачивается в единственном экземпляре на D, с проверкой размера и SHA-256. Локальный llama.cpp запускается без GPU. В отдельной копии с отложенным исходным манифестом выполняется следующая последовательность.

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python -B sources.py
python -B fetch_small.py
python -B predict.py
python -B verify_dpp.py
python -B neural.py
python -B runtime_audit.py
python -B evaluate.py
python -B check_aggregates.py --export
python -B report.py
python -B verify.py
```

Первые два шага обращаются только к официальным публичным страницам/метаданным и к закреплённым модельным весам по ссылкам из протокола. Все тексты, оценки и ранги остаются локально. У каждого состояния доступны полный порядок, идентификатор репозитория, флаг просмотра, исходы и стоимость всех сравнивавшихся префиксов. Результаты повторного замера времени могут отличаться. [Протокол](PROTOCOL_RU.md) · [Агрегаты исходных авторских систем](public-audit.json)

Команда `python -B check_aggregates.py` отдельно повторяет 3 543 сводные проверки и основной доверительный интервал, используя переносимые списки состояний. При наличии журнала процесса `python -B runtime_audit.py` сверяет число входных токенов с фактическими размерами пар.
