# Рукопись и демонстрация с изменением веса источника

Обновлён четырёхстраничный демо-проект для IEEE ICDE. Поведение графовой памяти теперь можно исследовать в двух режимах: исключение свидетельства и изменение полезности всех наблюдений одного источника. В последнем случае интерфейс показывает точный порог, исходный и текущий пакеты, вошедшие и выбывшие ID. Независимая кнопка проверки заново решает задачу по исходным весам. [Статья PDF](paper.pdf) · [Редактируемый LaTeX](paper.tex) · [Автономная демонстрация](candidate.zip) · [Озвученное видео](walkthrough.mp4)

В сценарии q01 соседние целые Q32 **6 307 132** и **6 307 133** лежат по разные стороны границы. На первом значении сохраняются 9 фрагментов (2 030 токенов), на втором отбираются 13 (2 048 токенов). Обе выдачи подтверждены вторым вычислением. Четыре SQLite-консоли запускаются одной командой `python -B demo.py`. Проверку из распакованного архива выполняет `python -B verify_candidate.py`.
