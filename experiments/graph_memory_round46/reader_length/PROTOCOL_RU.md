# Влияет ли ограничение длины ответа на эффект канала памяти

После первичного опыта известны средние F1 и факт, что 349 из 1 961 различных генераций достигли исходного предела 24 токена. Зафиксируем анализ чувствительности на тех же 1 024 отложенных для проекта вопросах MuSiQue. Одинаковый Qwen3-4B-Instruct-2507, бинарник, токены запроса и правила greedy-остановки. Изменяем только предельную длину ответа с 24 до 96. Заново запустим **все 1 961** уникальных входов. Это исключает допущение, что преждевременно остановившиеся строки идентичны после перезапуска. Порядок входов детерминирован хешем, файл с эталонами не загружается в процесс генерации. Если сервер остановится, повтор безопасен по ключу точных входных токенов.

Первичное сравнение — разность Answer F1 «упоминание плюс расширение» минус «то же расширение без ребра» при 96 токенах; вторичны EM, разность эффектов между лимитами с парным 95% интервалом по 937 кластерам первого документа, расход выходных токенов, длина и частота нового ограничения, контроль без документов. Проверяем совпадение ответов и разбиение по достижению прежнего лимита. Полный знаменатель каждой ветви неизменен. Это обоснованный измерением лимита анализ чувствительности на той же панели.
