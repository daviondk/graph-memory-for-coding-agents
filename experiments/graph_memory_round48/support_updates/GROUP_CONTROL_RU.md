# Дополнительная проверка всей транзакции

После просмотра парных результатов, включая одну совместную смену пакета в q25, фиксируем отдельный анализ всех 1 072 наблюдаемых транзакций. На том же доступном после транзакции пуле сравним полный пересчёт при всех наблюдаемых обновлениях сразу, пакет с прежними счётчиками и результат каждого обновления по отдельности. Тот же порядок, функции доплаты, бюджет и tie-break. Первичная величина этой дополнительной проверки — доля групп **со всеми независимыми результатами, равными старому, но отличающимся полным совместным результатом**, среди групп с двумя или более изменившимися балансами. Покажем также изменения полного пакета среди всех групп, групп с одним изменением, и долю запросов, для которых дешёвое точное достаточное условие переиспользования сработало.

Условие проверяет знак индивидуального изменения полезности: если все выбранные необязательные фрагменты получили неотрицательную прибавку, а все невыбранные допустимые получили неположительную, старый оптимум сохраняется. Для любого конкурента преимущество сохранённого пакета может измениться только за счёт его исключительных фрагментов и фрагментов конкурента; при этих знаках преимущество не уменьшается. Неизменность допустимости, ранга и правила разрешения равенств сохраняет полный ответ. Изменение полезности обязательного или не помещающегося в оставшийся бюджет фрагмента на вывод не влияет. Вывод проверяем полной оптимизацией на каждой группе. Это дополнительный диагностический опыт на ранее рассмотренных траекториях. Публикуем данные по всем транзакциям и отрицательные исходы.
