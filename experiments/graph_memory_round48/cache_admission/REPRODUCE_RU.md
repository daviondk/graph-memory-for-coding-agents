# Воспроизведение

С Python 3.11 и NumPy из этой папки запустите `python -B verify.py`. Для автономного числового контроля доступны все запросы, фактический порядок кандидатных ключей, длины, строгие предшественники, содержимое кеша до запроса и хеши упакованных метаданных. Проверяются 10 980 комбинаций состояния, бюджета и политики, включая варианты GDSF. Независимая реализация повторно вычисляет исследуемую политику и основной LRU-контроль, а также два кластерных доверительных интервала. Локальный Python расходует дополнительную память измерительного стенда; заявленный лимит относится к сериализуемому постоянному состоянию одного кеша вместе с местом под float32-векторы.

Для полной реконструкции нужны соседний каталог [embedding_reuse](../embedding_reuse/REPRODUCE_RU.md), тот же локальный кеш точных числовых токенов на D и зафиксированная конфигурация Qwen. Все алгоритмы воспроизводятся на CPU. Новые GPU-вызовы в этой абляции не требуются.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
python -B admission.py
python -B gdsf.py
python -B diagnostics.py
python -B order_check.py
python -B verify.py
```

Основные числа и заключения по дополнительному GDSF опираются на раздельные заранее записанные документы. Дополнительное исследование порядка и разбиение по глубине не входили в первичную регистрацию. Воспроизведение времени работы меняет значения часов и подпись результатов; исходный манифест сохраняйте отдельно.
