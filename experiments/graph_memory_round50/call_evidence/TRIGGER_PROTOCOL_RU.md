# Дополнительная проверка по восьмому действию

Фиксируем перенос моделей середины истории без переобучения и настройки. Бенчмарк во всех проверках этой папки — ISETrace (Wang et al.); в первой строке основного описания задачи ошибочно указано LiveOPS. Пути R42 и R43, разбиение и панели в нём корректны. Вторичная проверка использует ту же test-панель, граф пересобирается по реально доступным наблюдениям непосредственно в восьмой группе вызовов инструментов. В знаменателе для сравнения ридеров все вопросы, по которым наступил триггер; отдельно приводим число траекторий, на которых он вообще не наступил, и подгруппу с доступными свидетельствами. Заранее оставляем те же четыре модели, упаковку first-fit, разрешение равенств и бюджет. Читаем ранжирование по готовым совпадающим весам с пятью семенами. Сохраняем пакеты до открытия оценок. Сравниваем с исходным HGB/full и доступным нативным ридером без смежности на общей подвыборке. Обе проверки используют одни траектории. Проверка отвечает на вопрос об устойчивости к изменению момента чтения. Она не даёт независимой межкорпусной репликации.
