# Протокол переноса семантического сигнала между фрагментами вызова

Задача — выбрать историю инструментов агента в пределах 2048 токенов. Единица измерения — официальный вопрос LiveOPS на середине доступной истории, включая вопросы с ещё недоступным свидетельством. Используем прежние фиксированные префиксы R42, train с семенем 13, test с пятью опубликованными вариантами эмбеддингов. Эксперимент разведочный: эта панель ранее использовалась для других методов. Эталонные ответы для построения новых прогнозов на test не используются.

Гипотеза — оценка фрагмента улучшается, если ридер знает максимальную семантическую близость другого фрагмента того же вызова для каждой из двух ролей (та же роль и противоположная). Для исключения собственного вклада храним два лучших значения по группе. При равенстве учитываются разные фрагменты. Добавляем cosine и обратный dense-порядок лучшего соседа для каждой роли. Отсутствие соседа кодируется −2 и 0. Сохраняем исходный dense-ридер, признаки позиции, размера и типизированных степеней из R42, модель HGB, веса, сортировку и бюджет.

Условия: исходный HGB/full; исходные признаки плюс четыре признака настоящих соседей; те же четыре с перестановкой целых вызовов внутри каждой истории при точном совпадении числа входных и выходных фрагментов; только противоположная роль. Перестановка фиксирована хешем идентификатора траектории и номера вызова, циклический сдвиг на половину группы. Внутри вызова соответствуют роль и порядковый номер фрагмента. Одиночные группы остаются на месте. Отдельная модель для каждого условия. Прежний HGB/full сверяется с архивными пакетами.

Первичная метрика — доля вопросов с полным покрытием всех эталонных интервалов, усреднённая по пяти семенам. Вторичные — доля покрытых эталонных символов по вопросу, число выбранных фрагментов, фактически израсходованные токены, доля смещаемых фрагментов. Основной контраст — настоящие соседи минус исходный читатель; проверка механизма — сравнение с переставленными соседями. 95% парные интервалы с одновременной перевыборкой целых траекторий и семян. Результат положительный на этой панели, если нижние границы для обоих сравнений выше нуля. Другие сравнения описательные. Модели и пакеты выбора сохраняются до оценки. Нарушения протокола документируются.
