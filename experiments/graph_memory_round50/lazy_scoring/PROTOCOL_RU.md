# Отложенное вычисление полезности фрагмента в точном графовом ридере

Если стоимость и порядок фрагментов известны, обязательный префикс и недопустимые по остаточному бюджету элементы вычисляются до вызова леса решений. Если допустимый хвост целиком помещается, положительная полезность всех кандидатов допускает немедленную выдачу при выполнении численного условия для строгого сравнения binary64. Проверяем на зафиксированном финальном графовом ранге R50/matched_reader, обе архитектуры выбора чекпойнта, все 2000 вопросов и пять инициализаций. В нашей реализации короткий путь использует прежний guarded-селектор и фиктивную единичную полезность для структурно решённых строк. На полном помещающемся хвосте он возвращает все элементы в исходном порядке; это ветвление уже присутствует в служащем эталоном guarded-коде. Порядок, полезность нерешённых кандидатов и результат должны совпасть побитно, включая пустой хвост. Сравнение допустимо в области уже проверенных диапазонов с положительными конечными полезностями.

Проверяем два способа вычисления неизменного ансамбля: интерпретатор деревьев R50 и скомпилированные из **тех же** порогов ветвления. Получаем 2×2: базовый или скомпилированный лес, все строки или только нерешённые. Общие ранговые признаки по-прежнему рассчитываются из целого пула; для ветви, целиком определяемой ценами, можно пропустить и этот шаг. Для сопоставимости подготовка статического кода модели вынесена из обслуживания; стоимость сборки измеряется отдельно. Первичен выигрыш от ленивой стратегии относительно того же скомпилированного леса при равенстве всех 20 000 упорядоченных пакетов. Эффект простой компиляции указываем отдельно. Метрики — доля фактически оценённых строк, p50/p95, отношение сумм медианных времён по запросам с парным интервалом 95% по траекториям и пяти семенам. Измеряем путь от доступных числовых признаков и ранга до списка, прогрев плюс три перемешанных повтора; не включаем вычисление эмбеддингов и R-GCN. Метрики качества наследуются только после проверки идентичности полного списка у каждого запроса. Тест знаком по предыдущим сериям.
