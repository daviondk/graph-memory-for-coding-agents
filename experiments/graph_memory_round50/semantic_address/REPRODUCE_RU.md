# Воспроизведение семантической адресации

Команда `python -I -B verify.py` в распакованном каталоге проверяет все хеши манифеста, два лексических и два плотных порядка по всем 640 вопросам, полные токены префикса, 2 560 оценок EM/F1 и опорных заголовков, парные разности и 32 повтора. Для восьми вопросов по заранее фиксированной хеш-формуле размещены нормированные float32-векторы запроса и всех девяти конкурентов. Стандартный Python пересчитывает 72 скалярных произведения с абсолютным допуском 10⁻⁶. Для остальных вопросов переносимый тест пересчитывает порядок по сохранённым косинусам.

Полный запуск использует R31/R32, R39, R46/R47/R49 и qa_replication с путями paths_sem.py. Официальная GGUF-модель Qwen3-Embedding-8B Q4_K_M запечатана по SHA256 3fcd3febec8b3fd64435204db75bf0dd73b91e8d0661e0331acfe7e7c3120b85. Первый этап читает тексты прежнего публичного каталога только при создании ограниченной проекции, куда включаются вопрос, доступный первый абзац и оставшиеся заголовки. Энкодер читает эту проекцию. Порядок выбирается до открытия остальных текстов ридером. Для оценки используется подлинный 2Wiki v1.1 через тот же архив, авторскую процедуру и эквивалентный стандартный JSON-интерфейс, что и в qa_replication. [Официальный оценщик](https://github.com/Alab-NII/2wikimultihop/blob/13800e5be57df1b4040b9b1588c6c811779e69e9/2wikimultihop_evaluate_v1.1.py)

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
$env:OPENBLAS_NUM_THREADS='1'
& $runner -B projection.py
& $runner -B encode.py
& ./serve.ps1
& $runner -B grade.py
& $runner -B costs.py
python -I -B verify.py
```

Оба сервера завершаются своими процедурами. Эмбеддинги считаются с нуля после нормализации и добавления EOS; пуллинг последнего токена, векторы размерности 4096. Повторный запуск в той же частной папке заимствует уже находящиеся в журнале ответы обычного клиента. Для измерения времени нового запуска требуется пустая частная папка ридера.
