# Контроль по фактическому бюджету

До подсчёта качества на 580 запросах фиксируем вторичное повторение ранее опубликованного на 2 000 test-запросах контроля Hamming. Для каждого вопроса и чекпойнта контроль получает фактический лимит Hamming в токенах. Порог исходного префикса равен половине этого лимита в первом контроле и min(1024, лимит) во втором. Сохраняем исходный код сравнения и 10 000 перевыборок целых траекторий с seed 50086. Такое сравнение уравнивает доступный лимит и допускает различия в фактическом размере за счёт дискретности фрагментов. Порог эквивалентности по качеству не вводится.
