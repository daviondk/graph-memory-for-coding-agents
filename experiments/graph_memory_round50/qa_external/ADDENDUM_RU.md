# Соответствие адаптера корпуса

В 2Wiki единица адреса до чтения — исходный индекс абзаца внутри вопроса. Для проверки размеченных опор используем множество названий, как в R32, так как эталон адресует пару «заголовок, номер предложения». Объединение предложений одним пробелом совпадает с ранее зафиксированной процедурой. До генерации сравниваем все четыре вторых адреса и первый индекс каждого вопроса с R32. У Qwen фиксируются ровно два выданных фрагмента. Для сравнения с прежними MuSiQue-панелями используем точную пару заголовок+текст и нормализованный целый вопрос. Наличие общего материала в предобучении таким способом проверить нельзя.
