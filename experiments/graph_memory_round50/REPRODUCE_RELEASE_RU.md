# Проверка серии

Команда `python -B verify_release.py tree` проверяет полный инвентарь и SHA-256 каждого файла серии. Она использует стандартную библиотеку и не запускает вложенные эксперименты. Для сверки фактических Git blob из корня репозитория выполните `python -B experiments/graph_memory_round50/verify_release.py git experiments/graph_memory_round50 --repo . --ref HEAD --prefix experiments/graph_memory_round50`.

Из каталога серии `python -B check_studies.py --scratch D:/CodexResearch` выполняет численные проверки в отдельных процессах. Нужны NumPy и scikit-learn, для тёплых замеров — выпущенные нативные библиотеки Windows x64 или их пересборка. Проверка основной статьи запускает HTTP-приложения на локальном адресе после распаковки во временную папку. Изолированная проверка версии рукописи с проверкой страниц, текста и видео запускается из каталога предыдущей сборки demo_final командой `python -B verify.py --layout --temp-dir D:/CodexResearch` в окружении с pypdf и ffprobe. Проверка браузера дополнительной консоли выполняется из consensus_view командой `python -B browser_check.py` с установленными Playwright и Chromium.

Для повторной оценки на исходных проекциях сохраните соседние каталоги прошлых серий, включая R42, R43 и R49, на обычных местах полного репозитория. Для обучения моделей, вычисления эмбеддингов или новых LLM-ответов нужны обозначенные в отчётах датасеты, веса и зависимости. Условия каждой работы, фактические входы и команды приведены в соответствующем отчёте и файлах воспроизведения. Метки времени записанных GPU-вызовов используются для аппаратной проверки и не заменяют метрики качества.
