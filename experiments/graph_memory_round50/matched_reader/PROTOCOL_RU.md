# Протокол измерения качества и исполнения одного читателя

До проведения нового совместного замера фиксируем полный финальный срез ISETrace, 2 000 вопросов по 1 207 отложенным траекториям и пять уже обученных инициализаций (13, 17, 29, 37, 41). Обе исторические оценки качества известны. Основной вариант использует исходный checkpoint без смежности чанков, выбранный по Recall@5, подтверждающий вариант — независимо переобученный checkpoint, выбранный на dev по Full Support. Отбор во всём эксперименте получает только числовые признаки, порядок, стоимости и исходные binary64-полезности. Эталонный текст и его диапазоны используются после формирования выдач.

Первичный содержательный показатель — официальный Full Support@2048 и парная разность точной политики с нативным first-fit. Дополнительно фиксируем покрытие символов, токены, парные выигрыши/потери и сравнение с first-fit в порядке абсолютной полезности. В точной и ранжированной по полезности политике исходный последовательный префикс стоит до 1024 токенов. Предшествующие исторические реализации выводили выбранный по полезности хвост в разных порядках; сохраняем обе конвенции для сверки полного списка. Проверяем упорядоченные ID каждого метода с его опубликованными пакетами, исходные опубликованные оценки, затем пересчитываем метрику по официальным диапазнам.

Физический первичный контраст — время точной редукции binary64 из R49 против полного исходного binary64 DP при том же порядке и результате. Отдельный контроль — полный DP с быстрым обходом полностью помещающегося хвоста. Сравнения времени с нативным first-fit и жадной абсолютной полезностью касаются разных результатов. Одна нить и один процесс CPU, без GPU, до пяти методов на одних случаях. Один прогрев, три измеряемых повтора, блокировка по вопросу, случайный порядок вопросов, режимов и checkpoint внутри seed. Замер с готовыми числами включает подготовку служебных данных каждой политики и возврат ID. Дополнительный прямой замер включает восстановление признаков и выполнение деревьев из имеющейся числовой проекции и готового нативного ранга с возвратом ID. Построение исходного графа, получение нативного ранга, эмбеддинги и решение агентом задачи вне этих границ. Время выводится непосредственно для этих же пакетов; отношение времён — отношение сумм парных медиан повторов; 6000 парных bootstrap-повторов по траекториям и инициализациям, одинаковые выборки для всех политик. Для обоих этапов приводим также p50 и p95.
