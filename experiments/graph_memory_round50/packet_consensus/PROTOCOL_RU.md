# Семена как ансамбль читателей при жёстком бюджете

Проверяем, где агрегировать расходящиеся показания пяти обученных экземпляров графового ридера ISETrace. Обычное усреднение объединяет ранги или числовую полезность до выбора при бюджете. Альтернатива использует достижимость фрагмента в фактически допустимых пакетах каждого читателя. Интересует воспроизводимость выбора плюс качество полного набора интервалов. Ранее эта панель из 2000 вопросов исследовалась с другими правилами. Пять семян здесь совместно образуют одну систему; независимые единицы неопределённости — траектории.

Перед вскрытием новых прогнозов фиксируем следующее. Все варианты ансамбля получают те же 5 моделей и числовые входы R50/matched_reader. Используем нативный графовый порядок без рёбер смежности, с двумя ранее выбранными правилами выбора эпохи. Основной результат для первого, ранее зафиксированного по recall чекпойнта, вторичная проверка по dev Full Support. Выходная нумерация привязана к стабильным ID исходных фрагментов. Консенсусный порядок — обратная сумма рангов 1/(60+rank), при равенстве меньший индекс. Общий обязательный префикс потребляет до 1024 из 2048 токенов.

Сильные контроли: first-fit по консенсусному рангу; точный DP с усреднённой по семенам полезностью; жадный отбор по той же полезности; среднее качество исходных пяти точных одиночных систем. Основной новый вариант сначала получает пять пакетов точного читателя. Для каждого фрагмента вычисляет долю пакетов с его присутствием. Завершает консенсусный префикс точным отбором с полезностью, равной числу голосов. Это максимизирует ожидаемое число совпадений с отдельным учителем (линейность ожидания); такое совпадение — лишь заменитель метрики полного покрытия. При равенстве DP сохраняет прежнее решение в порядке консенсуса. Случай нулевых голосов обрабатывается строгим сравнением в DP. Описательные контроли: симметрическая разность с полезностью 2v−5; выдача одного медоида по минимальной сумме симметрических разностей среди пяти допустимых пакетов (равенство по фиксированному порядку seed); жадное упорядочивание по голосам. Для оценки стоимости отдельно считаем число проходов ансамбля и промежуточных упаковок, реальное время LLM на этом опыте не измеряем.

Критерий улучшения — нижняя граница парного 95% интервала по 1207 траекториям выше нуля для Full Support относительно среднего по полезностям при одинаковой вычислительной ёмкости энкодеров. Отдельно публикуем все сравнения с одиночным методом и вторым чекпойнтом, среднее покрытие символов, использование токенов, поштучные исходы.
