# Что объединять у нескольких графовых читателей

Пять независимо обученных версий ридера ISETrace ранжируют одни и те же исходные фрагменты. Ансамбль может агрегировать ранги, числовые полезности или сами пакеты, которые поместились в 2 048 токенов. Для последнего подхода фрагмент получает по голосу за каждое включение в пакет одного из пяти одиночных читателей. Независимая единица статистического анализа — траектория. Ансамбль выполняет пять проходов базовой модели на вопрос, тогда как одиночный читатель — один. [Протокол](PROTOCOL_RU.md) · [Подписанные прогнозы](forecast-seal.json)

**Первичная гипотеза не подтвердилась.** Точный выбор по голосам проиграл точному выбору по средним полезностям на 0,60 п.п., 95% ДИ [−1,41; +0,20]. Он максимизирует ожидаемое число общих элементов с пятью ридерами. Недорогих часто повторяющихся фрагментов для этого достаточно, а полный ответ требует всех эталонных интервалов.

Лучший описательный результат жадного голосования — 1 681/2 000 полных наборов. Выигрыш к среднему одиночному читателю +0,98 п.п. [0,44; 1,54], к точному ансамблю средних полезностей +0,50 [−0,05; 1,05], к жадному ансамблю тех же полезностей +0,35 [−0,35; 1,10]. На втором чекпойнте последний контраст составил +0,05 [−0,69; 0,76]. Модели инициализированы по-разному, но доступаются к одной истории. Для доказательства преимущества самого голосования сравнение двух пятикомпонентных ансамблей существенно. Показатели рассчитаны на неоднократно использованном тесте; условия с лучшим значением перечислены как вторичные. [Все парные сравнения](results.json)

**Более компактный контекст.** При частоте включения p ожидаемая симметрическая разность с одним случайным пакетом равна константе плюс сумме (1−2p) по выбранным элементам. Следовательно, с фиксированным префиксом и известной ценой точный выбор по (2p−1) минимизирует эту потерю на допустимых пакетах. Метод может оставить часть бюджета свободной. В среднем он потратил на 105,79 токена меньше точного ансамбля [97,87; 113,75] при тех же наблюдаемых 83,55% полного покрытия; интервал разницы качества [−0,55; +0,55] п.п. На втором чекпойнте экономия составила 100,89 токена с разницей −0,10 п.п. [−0,66; +0,45]. Эксперимент не задавал допустимую границу ухудшения. Он не устанавливает равенство качества и не включает цену пяти кодирований или задержку генератора. [Метод агрегации решений при ограниченном бюджете](https://web.stanford.edu/~anilesh/files/knapsack_voting_full.pdf)

В дополнительном сравнении каждый контроль получил фактический лимит варианта по симметрической разности для соответствующего вопроса. Относительно точного ансамбля с пересчитанным размером префикса выигрыш в полном покрытии составил +0,40 п.п. [−0,05; +0,86] на первом чекпойнте и 0,00 [−0,50; +0,50] на втором. При сохранении исходного порога защищённого префикса выигрыш равен +0,25 и 0,00 п.п. соответственно. Это оставляет открытым вопрос, насколько именно согласованность пяти выдач помогает при равном выходном бюджете. ## Воспроизведение

За исходными матрицами и независимой проверкой официального оценщика см. [matched_reader](../matched_reader/REPORT_RU.md). В этой папке `python -B run.py` формирует прогнозы без разметки. Затем выполнить `python -B grade_packets.py`, `python -B cost_match.py` и `python -B verify.py`. Для вычисления новых прогнозов нужны NumPy и нативная библиотека предыдущего эксперимента. Интервалы получены 10 000 парными bootstrap-перевыборками 1 207 траекторий.
