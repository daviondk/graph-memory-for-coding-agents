# Сравнение при персональном бюджете

Диагностика после основного теста. Подсчёт симметрической разности сохранил близкое покрытие при меньшем среднем размере пакета. Чтобы отличить содержательный выбор от простого уменьшения контекста, для каждого вопроса и чекпойнта передаём двум контрольным читателям столько токенов, сколько реально потратил вариант Hamming. Референтный пакет и его стоимость доступны до эталонной разметки. Первый точный DP использует среднюю по пяти читателям полезность и защищает половину нового лимита. Второй защищает прежний префикс до min(1024, лимит) и тем самым сохраняет исходную границу. Рассчитываем парные различия полного покрытия, покрытия символов и фактического размера. Снова сравниваем тот же тест; порог неухудшения заранее для данной гипотезы не задавался. Поэтому отсутствие значимой разницы само по себе не устанавливает эквивалентность.
