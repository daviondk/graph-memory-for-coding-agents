# Воспроизведение

В чистом каталоге поставки выполните `python -I -B verify.py`. Скрипт независимо проверяет хеши, все 1 920 строк EM/F1 и опорных заголовков, парные разности, точные токены, детерминированные повторы, порядок вторых адресов и перекрытие первых документов.

Для полного повтора нужны окружение и замороженные исходники R31, R32, R46, R47, R49 и R50 qa_external, модель и сервер, перечисленные в предыдущем исследовании. В paths_repl.py находятся пути к данным и новой рабочей области. Скачайте train.parquet из той же ревизии автора. SHA всех источников указаны в registration.json. На первом этапе выбирают только видимые колонки parquet. При фильтрации исторического MuSiQue из JSON проецируются только ID, вопрос, заголовок и текст. Эталонные ответы отобранных 2Wiki вопросов открывает grade.py только после проверки криптографической квитанции прогноза. [Авторский parquet](https://huggingface.co/datasets/xanhho/2WikiMultihopQA/blob/612bc5039a457880d9e7d84c3b0a4cf154b70e4f/train.parquet) · [Архив и авторский оценщик](https://github.com/Alab-NII/2wikimultihop/tree/13800e5be57df1b4040b9b1588c6c811779e69e9)

В новом рабочем каталоге используют тот же GPU Python, что и в R49. Скрипт serve.ps1 запускает llama.cpp, сбор контекстов и единичную генерацию с 32 повторами, затем завершает сервер. На момент инференса снимается квитанция hardware.json, что требуется для учёта costs.py. Официальный оценщик зафиксирован в qa_external/official-source.json. Интерфейс ujson для его публичной процедуры в этой системе предоставляет json из стандартной библиотеки.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B selection.py
& $runner -B orders.py
& $runner -B read_overlap.py
& ./serve.ps1
& $runner -B grade.py
& $runner -B costs.py
& $runner -B report.py
python -I -B verify.py
```

Интервалы относятся к единственной подмене с семенем 47011. Применимость к близким дубликатам вопросов, повторному обучению модели и другому числу чтений требует отдельных данных.
