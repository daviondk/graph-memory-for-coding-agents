# Сопоставимость фактических длин

У каждого вопроса строятся пять прежних placebo-адресов. Вместе с четырьмя исходными политиками их длины определяют общий предел второго документа. К генератору передаются три адреса — подлинный, лексический и placebo 47011. Это сохраняет прежний размер контекста при сокращении числа проверяемых перестановок.
