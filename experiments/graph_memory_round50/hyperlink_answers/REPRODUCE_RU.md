# Воспроизведение

В распакованной папке `python -I -B verify.py` проверяет подписи, правильность выбора трёх адресов для всех вопросов, общие префиксы и длины промптов, каждую оценку ответа и покрытия, парные разности и оба набора повторов. Для этого достаточно стандартного Python.

Для полного прогона используйте действующий Qwen-стенд R49, запечатанные R50 qa_replication, qa_external и числовую поставку hyperlink_control. Имена и хеши зафиксированы в registration.json. Исходник официального оценщика и алиасы проверяются через qa_external. Стандартный json предоставляет JSON-интерфейс для авторского v1.1. Модель ридера и сервер сверяются с известными SHA. [Официальный оценщик](https://github.com/Alab-NII/2wikimultihop/blob/13800e5be57df1b4040b9b1588c6c811779e69e9/2wikimultihop_evaluate_v1.1.py)

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
$env:OPENBLAS_NUM_THREADS='1'
& $runner -B addresses.py
& ./serve.ps1
& $runner -B grade_href.py
& $runner -B costs.py
python -I -B verify.py
```

Полное повторение сравнивает подписанный исходный массив токенов каждого заимствованного ответа с новым поэлементно. Для замера новых генераций требуется пустая частная папка. Скрипт завершает свой сервер после фиксации выходов.
