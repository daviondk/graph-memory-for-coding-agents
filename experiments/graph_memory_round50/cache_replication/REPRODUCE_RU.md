# Воспроизведение

Для проверки числовых исходов без Интернета и внешних наборов выполните `python -B verify.py` с NumPy. Скрипт воспроизводит 2 946 прогнозов по 491 состоянию, включая выбор резидентов всех шести политик, классификацию положительных попаданий, исходы калибровки ID и интервалы по 43 репозиториям.

Для полного повторного извлечения нужны [замороженная модель](../cache_prediction/REPORT_RU.md), прежние R39 и R48/49 и файлы SDK разработчиков с указанными в selection.json SHA-256. Скрипт lineage.py читает старую публичную выдачу R39 только для воспроизведения предварительного фильтра задач. Сценарий tokenize_cpu.py локально поднимает llama-server на 127.0.0.1 с `-dev none -ngl 0` и `CUDA_VISIBLE_DEVICES=-1`. Он запрашивает только endpoint /tokenize. Для выдачи средствами модели и оценивания скрытых сертификатов внешние запросы отсутствуют. Новый cache checkpoint не обучается. Выборки, регрессии и регистрационные хеши находятся в [первичном протоколе](PROTOCOL_RU.md) и [проверке формата исходных идентификаторов](ORIGINAL_IDS_RU.md).

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B lineage.py
python -B bridge.py
python -B tokenize_cpu.py
python -B evaluate.py
python -B coverage.py
python -B verify.py
```
