# Проверка формата ID, который фактически встречается в Test500

Широкий первичный валидатор дал 203 соответствия из 218 родителей, ниже порога 98%. Все 15 несовпадений содержат хотя бы один Cal-ID с дополнительным суффиксом после номера шага. Такие суффиксы имеют 94 из 484 записей Cal и ноль из 491 выбранной записи Test. Затраты методов на Test в этот момент не вычислялись.

До первой токенизации Test фиксируем отдельную проверку совместимости именно исходного шаблона с концом «-sNNN». На Cal удаляются только дополненные состояния, более короткие допустимые префиксы пересчитываются заново среди оставшихся строк, остальные критерии сохраняются. Сравниваем каждый предложенный ID-парсером путь с фактическими сериализованными событиями, совпадением run_id и base_commit по всему пути. Требуется не менее 50 предложенных переходов, не менее 98% совпадений непосредственного родителя и не менее 98% точных совпадений всей предложенной истории. Выводим отдельно разработческие и переносные Cal-группы, включая знаменатели. Если этот критерий выполнен, замороженные политики применяются единожды к исходным Test-ID, причём выборка Test остаётся той же, что в первоначальном протоколе. История Test после этого всё ещё характеризуется как восстановленная по метаданным, поскольку сырые события не опубликованы. Отдельно приводим первичный неуспех широкого парсера.
