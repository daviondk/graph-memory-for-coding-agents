# Как повторить результаты

Автономная проверка не требует sklearn, репозиториев продуктов или видеокарты. В каталоге находятся только числовые поля, анонимизированные хеши фрагментов и путей, параметры моделей, прогнозы и исходы для каждой строки. Установив NumPy, запустите `python -B verify.py`. Скрипт независимо реализует скалярные признаки, пересчитывает решения по всем сценариям, сравнивает резидентов и интервалы; для моделей абляции проверяется сохранённая ими стоимость по каждой строке.

Полный пересчёт использует Python, NumPy и scikit-learn (на стенде 1.8.0), исходный публичный Cal500, а также предыдущие рабочие каталоги [R48](../../graph_memory_round48/cache_admission/REPORT_RU.md) и [R49](../../graph_memory_round49/cache_controls/REPORT_RU.md). Источники токенов восстанавливаются по соответствующим инструкциям. Для повтора обучения с готовым inputs.json.gz начинать можно со study.py. Числовые расходы токенов воспроизводимы. Измеряемые наносекунды зависят от нагрузки и компьютера.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B build_inputs.py
python -B study.py
python -B ablate.py
python -B resources.py
python -B report.py
python -B verify.py
```

Порядок tie-break основан на ожидаемой стоимости с округлением до 10⁻⁹ токена, затем на полном digest входа. [Уточнение](NUMERICS_RU.md) · [Исходный протокол](PROTOCOL_RU.md) · [План дополнительной абляции](ABLATION_RU.md)
