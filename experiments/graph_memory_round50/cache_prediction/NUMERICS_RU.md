# Уточнение сравнения чисел при сортировке

При автономной проверке первичного прогона два фрагмента с почти тождественными ожидаемыми расходами на границе 31-го места в одной из цепочек development получили разные позиции при скалярном и векторном суммировании логитов. Для всех обученных методов в обоих протоколах фиксируем округление ожидаемой стоимости до 9 цифр после десятичной точки в единицах токенов, затем прежнюю лексикографическую развязку по digest. Это уточнение вычислительной точности записано до повторного расчёта. Исходный первичный эффект на переносе +0,513 п.п. к частоте, +0,341 п.п. к local. Ни входы, ни модели, ни порядок репозиториев, ни статистика оценки не меняются.
