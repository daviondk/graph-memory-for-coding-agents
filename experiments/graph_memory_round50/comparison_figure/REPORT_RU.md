# Парные эффекты на основных панелях

Рисунок сводит условные эффекты из первичных отчётов. На горизонтальной оси разность среднего показателя в процентных пунктах. Положительное значение выгодно первому из двух указанных методов. Доверительные интервалы и единицы выборки те же, что в каждом исходном эксперименте. Три панели используют отдельные шкалы и различные метрики; общей усреднённой оценки у них нет. [Векторный рисунок](comparisons.pdf) · [Версия PNG](comparisons.png) · [Числа](effects.json)

Для перерисовки выполните `python -B figure.py` в среде с Matplotlib. Скрипт сначала сверяет хеши первичных JSON и извлекает парные сравнения. Полный перечень опытов и все вторичные контрасты доступны в [сводном отчёте](../REPORT_RU.md).
