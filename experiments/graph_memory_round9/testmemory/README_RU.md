# Диагностика воспроизводимости на системном Python

Первый прогон выполнен на Python 3.14.4, pytest 9.0.3, coverage 7.13.5 и pytest-testmon 2.3.1. Десять исправлений математического кода SymPy, 106 тестов и оба направления изменения. Статусы 102 тестов совпали с историческими на обеих версиях. У четырёх тестов sympy-24661 воспроизвести их полностью не удалось, в том числе из-за удалённых в этой версии Python псевдонимов ast.Num и ast.NameConstant. Все 212 решений, восемь исключённых направленных наблюдений и журналы сохранены. Затем все десять задач были **полностью пересчитаны** в совместимом Python 3.11.15, где достигнута сверка 106/106. Для выводов используем эту вторую панель. [Совместимый прогон](../testmemory_compat/README_RU.md)

| Системный Python, 102 исхода в каждом направлении | Повторные запуски при исправлении / пропущено изменений | Повторные запуски при откате / пропущено изменений |
|---|---:|---:|
| Перепроверка при изменившемся файле | 102 / 0 | 102 / 0 |
| Точный граф тест→определение | 47 / 0 | 47 / 0 |
| Пересечение исполненных строк | 29 / 1 | 42 / 0 |
| Оригинальный pytest-testmon | 45 / 0 | 44 / 1 |

Начисление «лишний запуск» для приблизительной памяти означает лишнюю проверку относительно точного графа; сам точный граф может выполнять лишние проверки относительно действительной смены исхода. Поштучные прогнозы были запечатаны отдельно от сверки с полными запусками.
