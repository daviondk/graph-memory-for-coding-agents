# Внешний контроль pytest-testmon

До вычисления результатов внешней панели сохранён контроль с публичным исходным плагином pytest-testmon 2.3.1. Та же версия Python, pytest, два направления и те же списки тестов от R7 на отдельной временной копии для каждого направления. Копия сначала выполняет весь старый список с формированием базы testmon, затем применяет или откатывает реальный патч, снова вызывает те же nodeids с принудительным включением штатной селекции. Фиксируем реально исполненные nodeids и исходы, ошибки и размеры базы. Таким образом сравниваются настоящие решения плагина по каждому тесту, включая перепроверку ранее падавших тестов. Итоговые метки по текущей версии проверяются отдельным полным исполнением с покрытием и исторической контрольной квитанцией. Время измеряется как наблюдение при конкурентном запуске, не предназначено для точного сопоставления латентности.
