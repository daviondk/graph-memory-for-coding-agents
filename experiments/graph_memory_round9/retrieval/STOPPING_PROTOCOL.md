# Blind companion study on when to stop reading seed functions

The seven main policies fix the first six source reads. This companion proposal was formed after seeing source-format diagnostics and some unjudged graph activations. It reuses the same 18 projects; hypotheses and outcomes are exploratory, and no qrel on the current panel had been opened. Fix one additional outsider slot for all three policies to distinguish a read-scheduling effect from extra output space.

F6 selects the best corroborated outside function after all six source reads, by distinct callers plus an explicit query mention, breaking ties by dense rank. Early stops on the first seed read after which any outsider becomes corroborated, otherwise uses all six. Early3 additionally stops without proposing a read after seed three when there has been zero outward edge to any dense outsider and no explicit query identifier matches any outsider. A query mention alone cannot nominate a target. Record actual seed sequence length, tokens, bytes, proposed locator and the official rank of that locator before promotion. Primary descriptive tradeoff is mean number of source reads and paired change in all-target Acc@10 for Early3 versus F6. Also compare to strict Early and dense. No inference claim of equivalence or superiority on a dataset of 18. prefix stopping does not use future call outcomes: the replay reads only stored edges whose source is in the prefix and the globally addressable ID list is already available. Conditional on the issue's already-known top-6, the deterministic actions can be replayed online. A ceiling diagnostic on the same outputs shows how many true outside targets exist for any eligible pointer; it is used only by the assessor after sealing.
