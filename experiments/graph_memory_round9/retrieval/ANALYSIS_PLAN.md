# Reading the results

Selection addresses *which function to open next*. It cannot change the first eight dense functions. For a top-k set B, an outsider x and evicted function d, the change in covered positives under a single replacement is 1[x in G] minus 1[d in G], with G the annotated relevant function set. Dividing by |G| gives the corresponding change in recall. All-target accuracy gains one only if x was the sole missing positive and d is irrelevant. It loses one if all positives were present and d was relevant. Thus a graph policy can find a genuinely relevant neighbor without improving all-target accuracy. Both effects are scored. This is an elementary accounting identity, not a learned causal model or a guarantee of benefit.

For the stopping experiment, opening a new source costs one tool read and its observed token count. A positive net time/cost saving relative to F6 can be shown empirically if the stop rules make fewer calls, even when the measured all-target changes are zero. A flat result on 18 issues does not establish population-level non-inferiority. A dense-only caller still needs zero extra source reads unless those six functions were already opened as part of normal work.

The source-availability audit reports what proportion of missed positives have an outgoing AST edge from one of the six opened functions. It is computed retrospectively, and the predictive policy cannot use it. A low ceiling points toward other observations (e.g. runtime traces or incoming references) rather than increased propagation depth in this particular setting. The stricter degree/rank null isolates whether the label of the corroborated target adds information versus promotion at the same dense position and graph popularity.
