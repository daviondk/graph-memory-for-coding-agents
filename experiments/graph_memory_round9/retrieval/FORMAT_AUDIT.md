# Corpus format correction before relevance judgments

On the first eight completed dense queries, 39 of 48 seed functions initially failed AST decoding. Inspection of the released representation showed that methods contain an artificial unindented `class X:` context header immediately followed by an unindented `def`. The concatenation is an input to the encoder, not a valid Python module. The dense input stays byte-for-byte original. For AST parsing only, discard the ID line and synthetic preamble up to the first def or async def, then parse the isolated method. This realizes the preregistered method-body read and exclusion of decorators and defaults. Preserve pre-correction smoke outputs separately. Re-run every memory policy symmetrically, with unchanged candidates, read budgets, seeds, metrics, degree control and official labels still unopened. The main blind seal includes the corrected code and this note.
