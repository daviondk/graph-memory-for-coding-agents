До прогноза два отобранных исторических SHA проекта eclipse/jgit вернули HTTP 404. Оба запрашиваются из действующего зеркала того же проекта eclipse-jgit/jgit по неизменным SHA. Проверяются ровно те же parent/commit, хеши Java-блобов и выбор задач. Старый проектный идентификатор сохраняется в строках эксперимента.
