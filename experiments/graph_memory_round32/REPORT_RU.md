# Отчёт о графовой памяти агента

**На ISETrace структурные признаки увеличили Full Support@2048 с 72,97% до 78,44%.** Агенту нужно найти в журнале все размеченные источники в пределах 2 048 токенов. При одинаковом E5-base-v2, общем наборе кандидатов и пяти инициализациях добавление структурного приоритета дало +5,47 п.п., 95% ДИ [4,16; 6,74]. Проверены 2 000 вопросов из 1 207 траекторий. На 72 вопросах графовый приоритет выиграл при всех пяти seed, на 15 — проиграл при всех пяти. Независимая проверка подтвердила выбор контрольных точек на полном dev и воспроизвела индивидуальные исходы. Более сильная опубликованная абляция R-GCN без связи соседних фрагментов имеет оценку около 78,59%. Её воспроизведение на тех же входах позволит провести парное сравнение. **В демонстрации посетитель может открыть сохранённую версию наблюдения из реальной работы кодового агента.** В 171 передаче из 25 отложенных задач адрес самого большого предыдущего чтения стоил в среднем 46,4 WordPiece, одно открытие — около 476. При чередовании начала и конца фрагмента нашлись обе крайние строки будущего чтения в 48 случаях, при последовательном чтении — в нуле. Когда эталоном стали внутренние строки, результат развернулся до 0 против 4. Интерфейс позволяет проверить это на конкретном файле и увидеть, куда ушёл бюджет. Таблица хранит номера строк, отпечатки и стоимости. Критерий оценивает передачу буквального свидетельства. ## Что уже известно о парах источников

У статического дерева отзывов есть прямой предшественник — q-tree Monien. На всех 412 168 конфигурациях HotpotQA с не более чем двумя отзывами его специализированная реализация точно вернула лучшую пару. В среднем потребовалось 1,40 проверки метки, у плоского списка достижимых победителей — 1,72. При компактной физической записи дерево заняло 120 КиБ, плоский список — 112 КиБ. Обе структуры сильно меньше плотной полной выдачи в 392 КиБ. [Прямой системный контроль](representative_tree/REPORT_RU.md) · [Предшествующие работы и контрпример для разреженного графа](prior_art/REPORT_RU.md)

Более узкая гипотеза для статьи связана с адаптивным двухшаговым поиском. После отзыва меняются одновременно допустимые источники и группа документов, которую поисковик раскрывает на втором шаге. В первых восьми вопросах настоящей Beam Retrieval компактная структура воспроизвела ранги в 360/360 состояний с двумя отзывами против 354/360 у префикса с таким же числом записей. Другой точный контроль — сохранить до трёх лучших соседних пар для каждого из четырёх возможных исходных документов — потребовал в среднем 10,38 сохранённой пары против 4,13. Оба точных подхода также хранят исходные адреса. Для разреженного графа при пустом узле нужны дополнительные ветви по текущей группе документов. [Опыт на опубликованной модели](../graph_memory_round31/hotpot_native/REPORT_RU.md) · [Теоретические условия и точный контроль](prior_art/REPORT_RU.md)
