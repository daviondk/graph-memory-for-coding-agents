# Проверка результатов

Запустите `python -B verify.py` в этом каталоге. Нужны Python 3.11+ и NumPy. Скрипт читает включённую таблицу по восьми метрикам двух вариантов, проверяет все средние и SD по seed, а затем заново считает парные интервалы с ресэмплингом траекторий. GPU и исходные тексты не нужны.

`per-query.json.gz` содержит массивы `[seed, query_id, trajectory_id, dense_metrics, factor_metrics]`. Порядок восьми метрик записан в самом файле. Результат покрывает 10 000 пар, 2 000 различных вопросов и 1 207 идентификаторов траекторий. `results.json` — побайтовая копия исходного агрегата. В `source.json` сохранены хеши каждого прогноза и набора исходов, кода и выбора весов по двум вариантам dev.

Для полной проверки исходных рангов и пересборки таблицы нужен архив результатов R21 со всеми пятью seed. В полном рабочем дереве запустите `python -B verify.py` из `graph_memory_round21/five_seed`, затем аналогичную команду в его `dev580`. Обе проверки были выполнены на исходных данных. После этого `python -B collect.py` из этого каталога вновь объединяет индивидуальные измерения. Полные файлы рангов указаны в исходных прогнозных квитанциях.
