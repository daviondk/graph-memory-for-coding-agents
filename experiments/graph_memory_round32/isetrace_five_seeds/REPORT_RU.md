# Влияние структуры графа на извлечение памяти, пять инициализаций

На официальных 2 000 тестовых вопросах ISETrace (1 207 траекторий) добавление признаков графа к одному и тому же дообученному E5 повысило долю вопросов, для которых агент получает все размеченные источники в бюджете 2 048 токенов, с **72,97% до 78,44%**. Парный прирост **+5,47 п.п.**, 95% ДИ **[4,16; 6,74]**. Исходная гипотеза и основной показатель зафиксированы до новых четырёх инициализаций модели. Ранее были известны исходы на первой инициализации и родственных вариантах тех же тестовых вопросов. [ISETrace](https://arxiv.org/abs/2609.25913) · [Экспериментальный протокол](../../graph_memory_round21/five_seed/PROTOCOL_RU.md)

При каждом seed обе политики ранжировали общие исходные единицы памяти. Для Dense-FT использовался E5-base-v2, обученный на 3 894 тренировочных вопросах. Второй метод прибавляет к калиброванному логиту семантического ранга логит структурного приоритета. Структурные признаки включают роль и геометрию узла, а также степени по восьми направленным типам связей. Семантическую калибровку для каждого seed обучали на одной и той же группе из 101 тренировочного вопроса и 64 траекторий. Контекст наполняется целыми узлами исходного ранжированного префикса в рамках строгого лимита. Выбор контрольной точки Dense по 500 и полным 580 dev для всех пяти seed привёл к одним и тем же весам эпохи 1. Для каждого вопроса усреднено парное изменение по пяти seed. Для интервала сделано 10 000 перевыборок целых траекторий. Итог — среднее по вопросам с учётом размеров выбранных траекторий. Независимых траекторий 1 207, пять прогонов на одном вопросе дают повторные измерения. Выборочное межseedовое SD полной поддержки равно 0,36 п.п. для Dense-FT и 0,29 п.п. после добавления структуры. Интервалы условны по пяти изученным инициализациям. Для вторичных метрик приведены отдельные описательные интервалы.

Сравнение устанавливает выигрыш над контролем Dense-FT при фиксированных весах и кандидатах. Обучаемый полный residual R-GCN и его переобученная абляция требуют отдельного сопоставления на всех пяти seed в официальном режиме выбора эпохи. Качество конечного ответа LLM здесь не оценивалось.
