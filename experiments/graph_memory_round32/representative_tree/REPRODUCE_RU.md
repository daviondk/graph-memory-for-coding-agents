# Воспроизведение

Для отдельной рабочей копии сохраните соседнюю серию R31 с зафиксированными rankings.json.gz и cache-measurements.json.gz. Используйте NumPy, PyArrow, стандартный SQLite и `python benchmark.py`. В D:/CodexResearch/x20-r32-representative-tree временно создаются три независимые базы. Размеры измеряются после VACUUM, содержимое временной копии удаляется при выходе. Сохраняются индивидуальные проверки, размеры, журнал времени и протокол сравнения. Результаты по количеству проверок детерминированы, время зависит от машины.
