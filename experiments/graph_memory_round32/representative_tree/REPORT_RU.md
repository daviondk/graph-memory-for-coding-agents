# Что даёт прямой обход дерева Monien

Для всех 7 405 вопросов HotpotQA сравнили структуру Monien со списком достижимых победителей и полным списком. Упорядочили метки дерева по исходному рангу и хранили семь однобайтовых значений для глубины два. Гарантированное ограничение на поиск в дереве — три проверки метки. Все три метода вернули одинаковый ответ во всех 412 168 возможных ситуациях с нулём, одним или двумя отзывами. Классическая структура даёт сильный контроль одновременно по качеству, времени и размеру. [Monien, с. 246–247](https://digital.ub.uni-paderborn.de/hsx/download/pdf/42079)

Короткий список занимает на 8 КиБ меньше дерева при двух отзывах и требует больше проверок. Измерения на одном процессе SQLite дают близкие задержки. В этом опыте использованы обычные открытые соединения и общая таблица битовых масок, в R31 — отдельный режим immutable. Между этими двумя прогонами сравнивать абсолютные микросекунды некорректно. Данные включают 1 024 сценария и 15 360 измерений после прогрева. Время построения нейронных оценок в этом сравнении отсутствует.
