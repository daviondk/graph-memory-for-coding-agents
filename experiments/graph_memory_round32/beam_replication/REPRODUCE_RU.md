# Воспроизведение

Для проверки опубликованного полного снимка выполните `python -B finish.py --verify` с NumPy из этого каталога при наличии соседнего R31. Проверка пересчитывает оптимальные пары по исходным оценкам каждого вопроса, сравнивает основные контроли на 3 584 состояниях и повторяет два интервала по вопросам. Исходные адресные выборки и полный порядок 45 пар находятся в `forecasts.json.gz`, результаты по каждой комбинации также лежат в `outcomes.json.gz`.

Для нового физического запуска используйте отдельную рабочую копию R31 и R32 с зафиксированным `plan.json`, исходными весами и файлом вопросов по `graph_memory_round31/hotpot_native/REPRODUCE_RU.md`. Далее `python -B replicate.py run` пересчитывает 8 прежних и 64 новых вопроса в среде CPU-модели. Итоговый `forecast-seal.json` создаётся после проверки всех checkpoints. Команда `python -B finish.py` в отдельной рабочей копии оценивает полную панель и создаёт отчёт. Хеши исходных файлов публикуются в планах. Перезапуск продолжает расчёт из каталога private, привязанного к хешу плана. Для повторного измерения времени нужен новый private-каталог с отдельным расположением промежуточных файлов. Одна и та же модель на CPU применяется во всех вариантах. Рабочая копия на Windows хранит большие файлы на D, нужен PyTorch 2.6.0 CPU, Transformers 4.52.4 и зависимости предшествующего выпуска.
