# Репликация на 64 новых вопросах HotpotQA

На 64 заранее выбранных вопросах из HotpotQA dev измеряли воспроизведение решения Beam Retrieval с шириной 2 после удаления двух источников. Вопросы имеют по 10 предложенных документов и не пересекаются с первыми восемью. Полный динамический подбор определяет эталонный результат каждого из 45 сочетаний удалений на вопрос. Графовое дерево воспроизвело 2880/2880 результатов. Префикс с таким же числом строк среди 30 возможных пар четырёх корней воспроизвёл 2710/2880. Парное изменение 5.90 п.п., 95% ДИ [3.72, 8.40], 38 вопросов с выигрышем, 26 с равным результатом. Единица перевыборки — вопрос. Полный динамический лучший адрес и общий негейтированный победитель разошлись в 453/2880 случаях. Совпадение исходно выбранной пары с двумя эталонными документами составило 62/64 без отзывов. Извлечение абзацев и генерация ответа в данный опыт не входят.

На каждом из 64 вопросов при построении реально вычислены 10 баллов документов и ровно 30 баллов уникальных пар по требованию. Без повторного использования порядок обхода запрашивает в среднем 98.19 оценок пар. Контроль из 30 рёбер также требует ровно 30 обращений к модели. Для полного референса отдельно рассчитаны ещё 15 пар. Медиана затрат на каждой фазе составила 7.99 с, 35.81 с и 18.64 с соответственно. Загрузка других процессов меняется. Первичную стоимость ограничивает число потенциально допустимых пар, экономия слотов достигается при последующем хранении. [Доказательство](COST_BOUND_RU.md)

Все 448 результатов при повторном прогоне восьми исходных контрольных вопросов сверены с авторской реализацией ранее вычисленного полного порядка. Основной корпус для репликации ограничен вопросами с десятью кандидатами и является частью знакомого публичного dev. Распределение реальных отказов у кодовых агентов требует собственного наблюдения.
