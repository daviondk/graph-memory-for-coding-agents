# Дополнительный точный контроль по корням

После фиксации основной панели и гипотезы добавляется контроль с локальным индексом лучших соседей. В момент добавления сверяются прежние восемь вопросов. Оценки 64 новых вопросов не открывались. Для первых B+f=4 корней в порядке первого шага храним по f+1=3 лучших инцидентных ребра, отсортированных по совместному баллу. Общий набор содержит ≤12 различных пар плюс четыре адреса корней. При запросе выбираем первые B живых корней и лучшую живую пару в их списках. Если некоторый корень остался жив, каждый отзыв устраняет у него максимум одного из соседей, поэтому при двух отзывах достаточно трёх первых записей. Реальный размер считаем и как число уникальных пар в объединении, и как число инцидентных корневых записей до дедупликации. Для честного счёта компактный вариант также может хранить только объединённый отсортированный список пар. Цену построения на неизвестных scores берём по тем же тридцати рёбрам четырёх звёзд. Валидация на всех 56 масках каждого вопроса. Сравнение с динамическим деревом показывает потенциальную экономию записей при одинаковой точности, плюс число выигрышей и совпадений по размеру и bootstrap по вопросам. Первичный тест префикса сохраняет первоначальный статус.
