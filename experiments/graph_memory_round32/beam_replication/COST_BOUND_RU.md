# Нижняя граница вычисления неизвестных оценок

Предположим, что известен строгий порядок одиночных документов. Каждая потенциальная пара имеет произвольный конечный действительный score, который можно узнать только её вычислением. Метод должен точно отвечать на все удаления мощности ≤f при ширине B. В эксперименте n=10, B=f=2, после любого допустимого отзыва остаются как минимум восемь документов.

Пара может получить оценку на втором шаге ровно тогда, когда хотя бы один её документ входит в максимальный начальный префикс B+f. Действительно, чтобы открыть её лучший по первому шагу документ с позицией j>B (счёт с 1), достаточно удалить j−B более ранних документов. Второй документ стоит ниже и остаётся живым. Документ вне префикса не достигнет первой B даже после f отзывов. Число всех допустимых пар равно C(n,2)−C(n−B−f,2), здесь 45−15=30.

**Необходимость.** Возьмём любую допустимую пару e, которую метод ни разу не оценил. Для соответствующего множества удалений e конкурирует хотя бы с одной другой парой. Изменив неизвестный score e на значение выше всех известных и затем на значение ниже всех остальных, получаем два графа с тождественными наблюдениями метода и различными необходимыми ответами. Процедура, гарантированно обслуживающая все отзывы и все такие чёрные ящики, обязана узнать оценку e. Рассуждение применимо ко всем 30 парам и не требует вероятностной модели.

**Достижимость.** На уровне ноль дерево раскрывает пары, инцидентные каждому из B начальных корней. В текущем выигравшем ребре есть живой корень, удаление которого является одной из ветвей. Идя по такой ветви f раз, на каждом шаге открываем следующий документ первого порядка. Все адреса, стоящие ниже очередного впервые открытого корня, ещё живы на этом пути. Следовательно, все пары с ним и любым нижестоящим адресом будут просмотрены. В других ветвях могли возникать лишь пары с корнями начального префикса B+f. При мемоизации число различных вычислений точно достигает границы. Гарантия для пустых/малых пулов требует отдельного рассмотрения.

**Интерпретация.** Сокращение физического числа нейронных оценок относительно 45 составляет 15, как и у оптимального контроля из 30. Вклад компактного семейства состоит в количестве записей для дальнейшего обслуживания и числе ответов, восстанавливаемых при равном лимите хранения.
