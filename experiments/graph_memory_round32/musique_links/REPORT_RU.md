# Проверка на MuSiQue-Ans с авторской метрикой

На всех 2 417 вопросах dev применили правило из 2Wiki без подгонки. Модель видела названия и не более 192 WordPiece одного выбранного абзаца, среднее 94,01. Кандидаты с одинаковым названием сохраняли различные ID. Сравнили точные будущие адреса с эталонными ID абзацев и запустили оригинальный класс SupportMetric авторов. Независимый расчёт по пересечению множеств совпал с числом авторского оценщика.

| Правило | Точные пары из 1 252 двухопорных задач | Support F1 по всем 2 417 |
|---|---:|---:|
| Исходный BM25 по заголовкам | 104 | 0,4187 |
| Упоминание, затем исходный порядок | 300 | 0,4730 |
| Упоминание и локальное покрытие слов вопроса | 301 | 0,4737 |
| Самое раннее упоминание | 302 | 0,4732 |
| Частота, затем первая позиция | 302 | 0,4735 |
| Частота, затем исходный BM25 | 301 | 0,4731 |

У двухопорных задач первый шаг был верен в 784/1 252 случаях. Для первичного сравнения локального контекста с простым упоминанием наблюдалось два выигрыша и одна потеря. Эффект +0,08 п.п., 95% парный интервал [−0,16; +0,40]. Между первым упоминанием и локальным контекстом разница имеет обратный знак. Уверенно переносится сигнал самого упоминания. Влияние выбора между несколькими упомянутыми адресами на этом корпусе осталось неопределённым.

У 760 задач три опоры, у 405 — четыре. Две области чтения и выхода заданы нами. У авторов модель Select+Answer с выполнением шагов на полном входе получила 0,792 Support F1.
