# Воспроизведение

Внешний каталог корпуса — D:/CodexResearch/x20-r32-musique. Поместите туда файл musique_ans_v1.0_dev.jsonl под именем musique.jsonl из [первой копии](https://huggingface.co/datasets/voidful/MuSiQue/tree/a7d9f9adf6191604fc67cde318ee1a86fcf7babc) или [второй копии](https://huggingface.co/datasets/dgslibisey/MuSiQue/tree/763b65f844118a148e92bb88e7de5cb191b4c5dc). Их SHA-256 совпал, значение SRC_SHA записано в run_musique.py. В подкаталог author/metrics поместите metric.py и support.py из [зафиксированного исходного кода авторов](https://github.com/StonyBrookNLP/musique/tree/922ac98f19a201998dbdae6d7f2887a5258dbdeb/metrics). В отдельной копии каталога экспериментов выполните `python run_musique.py predict`, затем `python run_musique.py score`. Корпус читается как JSON. При построении прогноза используются поля вопроса, заголовка, ID и текста уже выбранного абзаца. Из исходных файлов в результат включены идентификаторы, решения и контрольные суммы.
