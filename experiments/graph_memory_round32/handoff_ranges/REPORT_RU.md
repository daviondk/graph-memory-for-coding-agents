# Что передавать при смене кодового агента

Из реальных траекторий Handoff Debt взяли первое наблюдение файла у преемника и все фактические чтения до соответствующей точки передачи у предшественника. На этапе записи в память доступны только прошлые чтения. При обращении к памяти преемнику известен путь интересующего файла. Он получает одну выбранную прошлую версию наблюдения. Лимиты составляют до 512 WordPiece на адреса и до 512 WordPiece на текст полученного чтения. Адрес, номер строки и точный текст нужны для совпадения. Метод использует внешний архив наблюдений, который остаётся доступным между исполнителями. [Опубликованная работа](https://aclanthology.org/2026.emnlp-main.738/) · [Набор данных](https://huggingface.co/datasets/kc-academy/handoff-debt/tree/79244eedc9d58349da0fcf1a2e05916e0ac5af00)

В тестовой части 25 задач и 171 подходящее последующее чтение. Перечень содержит одно прошлое наблюдение с наибольшим числом информативных строк на каждый путь. Сравнение меняет только выбор строк при чтении исторического наблюдения. Стабильный успех означает, что в ответе присутствуют обе заранее заданные строки с верным историческим содержимым.

Парная разность для двух крайних строк составила +29,24 п.п. с 95%-м кластерным интервалом [17,51 … 42,09]. Для двух внутренних строк, на позициях около четверти и трёх четвертей будущего чтения, разность составила −2,44 п.п. [−6,89 … 0]. В каждом из 171 тестовых событий все четыре позиции различны. Получатель знает только путь. Ограниченный объём, потраченный на окончание большого наблюдения, редко содержит участки внутри. Точность существенно зависит от назначения читаемых строк.

Сложная политика выбора адресов по числу новых цитат на токен и полный перечень адресов дали те же 48 успехов. Оба использовали в среднем 119,5 WordPiece на адреса против 46,4 у таблицы с одной записью на путь. Тексты после открытия у сравниваемых политик совпали по качеству в первичном результате. В повторной проверке на других передачах тех же 25 задач получены 60/339 против 4/339 для крайних строк. Прирост с равным весом задач +16,32 п.п. [8,55 … 24,75]. По внутренним строкам изменения малы и направлены против чтения с концов.

Размер исторического содержимого при наивном повторении для всех 257 снимков составил 7 009 498 байт в точной адресной сериализации строк и 1 947 копий непустых наблюдений. Соседние снимки пересекаются, поэтому эти величины описывают формат логических данных до физической дедупликации. Полный контекст до открытия и время выполнения конечного задания в эксперименте не оценивались. Совпадение пути и строк характеризует повторное использование наблюдения. Частота ссылок и реальные задачи исправления требуют отдельного измерения. Все исходы и единицы повторной выборки находятся в outcomes.json.gz и results.json.
