# Воспроизведение

Восстановите закреплённую версию Handoff Debt и проекцию R31/natural_handoff по её инструкции. В Python с pyarrow, tokenizers и numpy последовательно запустите handoff.py, gold.py, evaluate.py и audit.py. Скрипт gold.py проверяет авторские SHA оригинальных шардов, заново извлекает настоящее следующее чтение только как статические данные и сверяет крайние строки с предыдущей проекцией. Результаты включают замороженные возможные ответы для всех путей до присоединения целевых данных, новые внутренние цели и измерения по каждой передаче. audit.py восстанавливает два основных варианта из прежних текстов по иному коду и повторяет кластерный интервал на 25 issue. Скрипты не исполняют содержимое публичных траекторий.
