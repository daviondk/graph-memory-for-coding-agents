# Воспроизведение

Подготовьте исходные файлы и токенизатор по инструкциям соседних observed_transfer и musique_links. В новой копии экспериментов запустите `python early.py`. Обход сравнивает результаты с зафиксированными полными прогнозами по ID, длине реального фрагмента и выбору первого адреса на каждом вопросе. Возможность досрочной остановки проверена отдельно для порций 16, 32 и 64 WordPiece.
