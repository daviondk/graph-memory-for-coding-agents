# На каких вопросах эффект воспроизводится между seed

У 1 573 из 2 000 вопросов две политики совпали по двоичному исходу Full Support@2048 при каждой из пяти инициализаций. Среди остальных 427 на 309 вопросах структурные признаки хотя бы раз улучшили результат, на 123 хотя бы раз ухудшили, пять вошли в обе группы. У 72 вопросов графовый ранг выиграл во всех пяти прогонах, у 15 — проиграл во всех пяти. Равенство двоичного исхода допускает различный порядок найденных источников.

Если исключать по одному seed, прибавка лежит между +5,39 и +5,56 п.п. При равном весе каждой из 1 207 траекторий эффект составляет +5,43 п.п. Дополнительная чувствительность к совместной повторной выборке кластеров и пяти seed даёт интервал [4,07; 6,83] для среднего по вопросам и [3,95; 6,90] при равном весе траекторий. Планирование новой выборки должно учитывать повторные вопросы из одной сессии и ограниченное число независимых обучений. Все оценки здесь повторно анализируют ту же тестовую коллекцию. Для воспроизведения из этой папки запустите `python check.py` с NumPy, достаточно соседнего per-query.json.gz.
