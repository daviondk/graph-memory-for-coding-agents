# ALFWorld только по текстовой обратной связи

Полностью разыграны 134 игры официальной текстовой выборки valid_unseen, по пять условий в каждой. На любом шаге агент видел только инструкцию, текст обстановки и текстовый ответ на собственную команду. После 50 действий исполнение останавливалось. Контроллер использовал фиксированные шаблоны команд и грамматику бытовых задач. Модель и видеокарта в этой серии не участвовали. При запуске TextWorld запрашивался только флаг победы для внешнего оценщика. [ALFWorld, ICLR 2021](https://arxiv.org/abs/2010.03768)

## Что именно считается памятью

Каждому варианту доступны видимые при входе названия мест, текущая позиция, инвентарь, выбранный подэтап и уже доставленные предметы. Простейший контроль всегда берёт первый пункт общего списка, отличный от текущего. Поэтому он может чередовать два места. Более сильный контроль вычисляет следующий пункт циклического списка прямо по текущей позиции. Для него нужно ноль дополнительных записей о прошлых поисках. Курсор отдельной переменной сохраняет только последнее осмотренное место. Полная история хранит список осмотров до смены подэтапа. Тренировочный вариант ранжирует типы мест по числу увиденных там целевых предметов. Контроллер извлекает объекты и состояния дверей из строк симулятора. Полнота получаемых при входе списков и ограниченная грамматика упрощают эту среду. [Закреплённая грамматика](https://github.com/alfworld/alfworld/blob/aaba6870f86c5be6a08a491f32a50b906227bc3e/alfworld/data/alfred.twl2)

Последовательности всех команд курсора и циклического обхода по текущей позиции совпали в 134 из 134 игр. Для полной истории совпадение с обходом по позиции было в 103 играх. Сравнение количества побед простого порядка с курсором само по себе смешивает порядок навигации с записью прошлого. Команды совпавших условий исполнялись в отдельных физических разыгрываниях.

## Что дала тренировка

39 новых траекторий разведчика на заранее выбранных тренировочных заданиях дали 1 302 выполненных действия, наблюдения в 879 местах и 57 типов найденных объектов. Использовались только доступные строки симулятора. Разведчик открывал явно закрытые места, шёл по фиксированному порядку и учитывал тип вещи не более одного раза на место в игре. Это необработанные частоты встречаемости, они зависят от охвата разведчика. Шесть тренировочных игр использованы для проверки грамматики. Затем хеш политики и частот был закреплён до запуска всех 134 игр.

Сопоставление интерфейсов описательное. Новая политика получает текст, по-своему отслеживает текущий обзор и использует частоты заново исполненных тренировочных разведок. Частоты прежней системы и списки допустимых команд закрытых игр не передавались. Политика общего назначения потребовала бы отдельно освоить парсинг, грамматику и подэтапы. ReAct публиковал результаты на 134 unseen-играх с LLM и размеченными демонстрациями. Эти различия мешают переносить результат данного контроллера в таблицу лидеров языковых агентов. [ReAct, раздел 4](https://arxiv.org/html/2210.03629)

## Перепроверка

Из этого каталога выполнить `python audit.py --check`. Нужна стандартная библиотека Python. Верификатор выводит все собственные действия заново из текстов прошлых наблюдений, проверяет тренировочный набор частот, хеши, финальные флаги и парную статистику. Физический повтор запуска TextWorld описан в REPRODUCE.md. Журналы всех действий находятся в eval/ и train/, точный список задач — в roster.json, 134 строки с исходами условий — в per_episode.csv.
