# Reproduce pose-scoped failure-memory experiments

In a complete copy of this directory run `python verify.py --check`. No external dependencies or parent files are needed. The verifier regenerates actions from the initial text + action feedback and checks all raw observations against the cryptographic input/output inventories. It calculates per-split and per-family counts; paired bootstrap samples use shared episode keys. Success and capped step gains, within-episode repetition and stored negative-entry occupancy are available separately. Source paths and checksums of reused baseline trajectories are preserved in baseline_origin.json. The projected baseline records contain the exact commands and raw feedback from those native computations.

For physical execution use the same official ALFWorld source, Demangler, TextWorld installation and game collection as the parent study, in its x20s3-alfworld CPU container. Paths are fixed by ../..'s engine.py. Keep this directory layout in a separate working copy. `python launch.py seal` imports the immutable upstream actor, training prior, official game lists and 134 raw non-menu baseline trajectories, validating their existing SHA256; this function creates a new seal. The current locked copy is the archival one. `python launch.py run` verifies the seal, opens each game and independently performs the fresh arms. For re-execution use a copy with no valid_unseen or valid_seen result files so resumption does not skip cases. Then run `python verify.py`, `python verify.py --check` and `python make_report.py`. No method reads any game metadata as input to the actor.
