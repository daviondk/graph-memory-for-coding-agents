# Дополнительная стратификация перед открытием итогов
В официальном valid_seen только 47/140 эпизодов (23/76 планировок) действительно имеют планировку среди наших 39 тренировочных игр. Ещё до построения transfer_results.json фиксируем дополнительный срез для интерпретации переноса: сравнить обычное взвешивание всех тренировочных комнат (all_static), чтение по похожей видимой комнате (room_static) и его вариант с текущими промахами (room_miss) отдельно в 47 эпизодах с тренированной планировкой и 93 эпизодах на оставшихся 53 планировках. Метрика — won, среднее число шагов с начислением 50 за неудачу, парная разность шагов, число выигрышей/проигрышей по успеху. Отдельно вывести четыре новых планировки valid_unseen. Это уточнение к интерпретации исходного факторного опыта, не новый независимый test и не повод менять политику.
