The new writer stores the set of observable location classes on entering each training room and counts of the rooms' public examinations/sightings by receptacle. For target and current initial room T, each experience in H gets weight 1 or Jaccard(location classes H, T)^4. Estimate background prevalence p0 from all completed training examinations with add-one smoothing, independent of current goal outcome. For each receptacle class c compute (weighted present+4*p0)/(weighted examinations+4), which shrinks unobserved classes to the overall prevalence. Online arm multiplies by 4/(4+k), k distinct examined locations of that class since the current search began. Remembers actual misses on current target search. Exact optional contrasts: room+miss against all+static, room+miss against room+static and all+miss. Primary step direction fewer steps on both sets, supporting within-split effects required before any broader claim. Cross-split heterogeneity and surprise changes must be retained.
