# Local break-even time for the sealed reuse policies

Registered after the read-policy accuracy experiment, before timing its implementation. Truth and predictions are already fixed. The question is how much a skipped tool invocation must cost to pay for an unoptimized but real provenance tracker, including work done on misses and opaque commands. Primary endpoint is incremental wall-clock overhead divided by the number of matched historical outputs, relative to bypassing the observation tracker. Separately time the marginal price of multi-record range stitching over the stronger single-interval containment comparator. No changes to the frozen parser, eviction or predictions.

Load all projected tool groups in memory before timing. On the same ordered groups run bypass, canonical exact, single containment and range cache. Each simulated deployed cache performs command parsing, conservative effect classification, lookup, output materialization, invalidation and cache updates. Exclude archive decompression, serialization, score comparison and original tool execution from this overhead timer. Shared traversal and reading command references occur in all arms. Shuffle order of arms within five fixed-seed replicate blocks. Record per-run wall time and produced answer count, report median paired difference and its observed range rather than treating timing repetitions as independent tasks. Make no simulator speed claim when hits differ from the locked predictions.

For each presealed range hit create a temporary file on D with matching line count prefix and the exact recovered bytes. The prefix is one newline per preceding line, suffix empty, so absolute offsets are realistic but lengths and original file I/O are not. For each one run the matching installed GNU cat/head/sed directly as a child process and an in-process Python file helper, in shuffled order across requests for two blocks. Inputs are fixed before timing. Verify return status and every byte of each output. Include startup, open/read, stdout collection and teardown for native processes. Keep any fixtures until both blocks finish then clean the dedicated temporary directory. Report observed mean and p50/p95 per backend, two-block total cost, and net local wall time (time saved by those hits less per-pass management overhead). If new-process cost is close to the break-even, preserve a negative or ambiguous outcome. Historical service latency, cloud sandbox performance, downstream token loss and end-to-end repair remain unmeasured.
