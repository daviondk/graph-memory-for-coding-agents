## Проверка после распаковки

Для проверки контрольных сумм и основного пересчёта результатов из каталога с манифестом выполнить `python verify_round.py`. Второй проверяемый контур — `python repair/generalization/offline_verify.py`. Для исходных физических замеров кэша — `python procedure/cost/audit.py`. Для исходного Pi-подобного контроля — `python compact/path_control/score_paths.py --verify`. Синтетические результаты не заменяют исполнение: все сохраняемые stdout, статусы, грамматики и родительские события перечислены в протоколах. Полный набор production-трасс SWE получен из опубликованных ревизий; в архиве его сокращённая достаточная проекция, URL и хеши исходных blobs. Веса модели объёмом 16,56 ГБ берутся по URL и SHA‑256 из runtime/model_receipt.json. Повтор старых длительностей и свободной памяти зависит от машины.

Для нового сбора на исходной машине использовалась база D:/CodexResearch. Общие файлы эксперимента — x20-bench-workspace/work/memory_session3, оригинальные QuixBugs — x20-session3-quixbugs. Для ALFWorld распаковать upstream/json_2.1.3_tw-pddl.zip в x20-session3-alfgames, метаданные оставить архивом x20-session3-alfmeta.zip. Папка x20-session3-alfworld содержит исходники ALFWorld из зафиксированной ревизии. Использован контейнер swerebenchv2/brazilian-utils-brutils-python@sha256:6103d7a91aa8ff7adc6b877ec7e76d9697e81d2fdd51204a7c800675fd528cbc, Python 3.10, TextWorld 1.7.0 и fast-downward-textworld 20.6.4. Полная фиксация окружения в alfworld/pip_freeze.txt. В контроллер среды передаются только открытые наблюдения согласно условию опыта. При переносе на другую машину mount и директории в common.py и engine.py следует настроить на свою копию.

Исходные просмотры успешных/проваленных попыток сохранены раздельно от проверяемых выводов для конкретного контраста. Дата документации на диске является локальной фиксацией протокола, не независимой доверенной отметкой времени. Основные и дополнительные варианты указаны в PROTOCOL, AMENDMENT, PLANNER_PROTOCOL и TRANSFER_PROTOCOL. Корреляция эпизодов одного проекта или одной комнаты ограничивает интерпретацию статистических интервалов. Все результаты анализа относятся к использованному интерфейсу, бюджету и решателю.
