## Как перейти от этих опытов к прямому сравнению

Один и тот же репозиторий или набор задач — только первое условие. В матрице собственной статьи для каждой строки фиксировать модель с версией, инструменты, форму доступных наблюдений, размер памяти, число роллаутов при сборе, лимит действий и стоимость LLM на записи и чтении. Запускать чужой метод и новый метод с одним решателем, одними исходными траекториями обучения, без общей изменяемой памяти между способами. Для stochastic agent повторять парные запуски и отдельно показывать уникальные задачи и seed. Результат из таблицы чужой статьи помечать как сообщённый авторами. Вывод об улучшении основывать на парных исполнимых исходах и дополнительной проверке на другом наборе.
