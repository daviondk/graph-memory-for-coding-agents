# Надо ли вообще показывать найденную память?

Единица — одна из 258 задач SWE-ContextBench вне Lite. Использован фиксированный победитель поиска в среде из уже влитых PR. Три способа оценить уверенность, одинаковые бюджеты 25%, 50% и 75%, плюс заранее заданное отдельное правило. Все прогнозы и коды для их воспроизведения в blind.json и lock.json, итог по каждой политике и репозиторию — results.json. Если показывать всё, 26 из 185 выданных первых записей совпадают с авторской разметкой. Если показывать при буквальном совпадении признаков кода, 14 из 55; случайная выдача с теми же нагрузками по репозиториям сохранила бы в ожидании 7,74. При бюджете 47 обращений отрыв BM25 сохранил 15 связей, идентификаторы — 13, абсолютный BM25 — 8. При бюджете 93 обращения — соответственно 21, 19 и 21. При 139 — 24, 23, 23. Метрика не подтверждает эффект на исполняемый патч. Для воспроизведения python verify.py использует только стандартную библиотеку. Для повторного пересчёта запросов predict.py использует те же исходные данные, pyarrow и requests, что и transfer. Первый технический запуск в окружении recall-venv завершился при импорте отсутствующего requests; рабочий запуск произведён agent-venv до чтения оценок.
