# Историческое чтение на всех 99 запросах SWE-ContextBench Lite

Библиотека содержит 300 реальных источников; 30 задач имеют пустой допустимый пул, ещё 5 — единственную допустимую запись, 64 требуют выбора. Из 99 только у 17 в пуле присутствует хотя бы одна авторская связь. У всех этих 17 имеется минимум 5 допустимых кандидатов; они относятся к 17 уникальным целевым PR и 6 репозиториям.

| Метод | Верная первая из 99 | Из 17 доступных |
|---|---:|---:|
| Самое недавнее исправление | 7 | 7 |
| BM25 по независимым полям, заново построенный только по истории | 11 | 11 |
| Тот же BM25 и реальный выбор локальной Qwen из пятёрки | 15 | 15 |
| Гибридный индекс всей библиотеки, применён фильтр по времени | 12 | 12 |
| Тот же гибрид и реальный выбор локальной Qwen из пятёрки | 16 | 16 |

В первой пятёрке каждого метода содержатся 16 доступных авторских связей. Случайный выбор одного допустимого документа на каждого из 99 дал бы в ожидании 1,28 попадания. Исходные 75/99 получены в исходной статической библиотеке с другим количеством доступных эталонов. Из них только 13 решений сохранили бы правильный источник при механическом удалении недоступных; новый запуск с подбором других разрешённых кандидатов дал 15 или 16. Прежние метрики и новые доли относятся к разным постановкам. Ни одна доля не означает число исправленных программ.

Сохранены все первые ступени, 198 итоговых выборов, 113 реальных ответов модели и токены. Для 15 одинаковых промптов ответ физически использован дважды. Если запускать стратегии раздельно, обеим требовалось бы по 64 запроса, 205 563 и 206 048 входных токенов для гибридной и онлайн-выдачи. Все ответы прошли синтаксическую проверку. Никаких золотых ответов/связей в промпте; точная строка может быть реконструирована по неизменяемым данным предшествующего тома. Приписывать доступность более позднего текста траектории только по дате исторического изменения нельзя; время слияния PR служит приближением доступности информации о правке. Проверка всех 99 списков и исходов выполняется python verify.py.
