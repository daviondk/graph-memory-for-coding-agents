# Pre-score expansion of chronology audit, 16 November 2026
At the parent's request, before reading new non-Lite retrieval scores, we add an audit of the historical availability of the already public/frozen 75/99 Lite Match@1. The research team had identified four examples prompting this audit. This is a retrospective diagnostic of benchmark suitability for deployment, not an alleged defect under the benchmark's original static task.
Use release instance ID only to join a target, then read its explicit pull_number and list of issue_numbers from the target metadata. Never infer the target PR number from its instance ID suffix. For each trace use its published source repository and historical patch PR number. For each case, independently classify source PR merge strictly before, at/after, or unknown at three clocks: primary issue clock (minimum opening of all stated issues and target PR), target PR open, target PR merge. If the target lists only its own PR as an issue, the first clock is its PR opening. Prefer recorded opened event; use the supplied created_at as an upper bound for the PR-open clock where record unresolved; any missing constituent issue timestamp makes the strict primary test unknown unless time or PR identity logically implies ineligibility. If the source and target are the same PR, a completed source patch cannot be eligible at any target clock, including equality at merge. If both dates exist and source is at/after a KNOWN component of an incomplete earliest cutoff, classify as ineligible; if it is earlier than every observed time but an issue time is missing, classify unknown. For gold with several links and a given clock, a target is available if any represented labeled source is past; unavailable if all available-source labels are nonpast or absent and their clocks are conclusive; unknown otherwise. Record library absence separately. Include any, first, last release relations, correct frozen top1 hits partitioned on source chronology, ambiguity, repeated target PR identities and number of same-PR links/picks. Never treat all late links as future under the original static benchmark interpretation. Provide public event provenance per row.
Additional fixed control before scoring: separate lexical fields via 2/(12+rank(issue192))+1/(12+rank(edit64)), as an ordinary late-fusion comparator. It may arbitrarily rank zero-signal edit fields; scope primary remains single card vs issue256. Full data source currently has 1007 prior PRs and 357 unique targets, including 258 disjoint non-Lite. Public HTML fallback for time extraction restricted to GitHub explicit PR merge event and original issue/PR opening timestamp. Input packaging contains no test patch. A source's merged state may predate or postdate the benchmark agent's actual trace collection, which is not captured by this PR-based clock.
