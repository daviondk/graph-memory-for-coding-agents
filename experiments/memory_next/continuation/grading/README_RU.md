# Авторская оценка продолжений

На четырёх формулировках из трёх целевых pull request восемь продолжений получают одинаковые базовый checkout и исходный патч родительского brief. После заморозки всех решений сравниваются ветки last_two и manifest. Для каждой отправки используется независимый экземпляр официального оценщика SWE-ContextBench из того же коммита, который проверил исходные задания. Фиксируются исходный и конечный resolved, совпадение исправлений, выполнение тестов, пересечения исправления с защищёнными тестовыми файлами, количества FAIL_TO_PASS и PASS_TO_PASS. Доли решения приводятся с равным весом формулировок и с равным весом каждого PR. [Авторский код](https://github.com/jiayuanz3/SWEContextBench/blob/12ad6ab14e18e9378e1e293c9edbc3f7ce43d27b/swebench_memory/harness/run_evaluation.py)

Контроли разделяются с первичной проверкой. Файл provenance.json ссылается на все 12 оригинальных калибровок, фиксирует хеши случаев, неизменённого grader, манифест исходных образов и заморозку восьми продолжений. При старте повторно проверяются OCI digest, базовый Git-коммит, дерево кода и хеш каждого из 16 модулей. Пустая отправка имеет официальный исход No patch до тестового запуска. Время проверок и сырые распознанные статусы находятся во вложенном архиве official_execution.zip. Оценщик не вызывает LLM.

Запуск проводится в D-backed WSL из каталога continuation/grading. Формат запуска: `python3 driver.py --wait`. Проверить извлечённые файлы независимо можно командой `python verify.py`. SHA-256 для проверки архива и сводок находится в seal.json.
