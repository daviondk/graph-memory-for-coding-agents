# Выбор формы памяти на другом репозитории

Заморожены четыре доступных действия и одна иерархическая политика. Из обучения удаляется весь репозиторий назначения. Все 1 530 решений записаны в decisions.json; состав 11 групп и хеши тренировочных записей — folds.json. Решение каждой политики можно проверить, потому что авторы Handoff Debt опубликовали исходы для каждого режима передачи. Основной кандидат дал 669 подтверждённых решений, постоянная полная траектория 674, решатель с правилами только по получателю 683. Репозиторные интервалы и стоимость в results.json. Разбор простого контроля против полных траекторий выполнен после основных результатов и помечен как диагностический. У той же политики на выделенных повторах r02/r03 зарегистрированы отдельные исходы (соседний раздел повторов Handoff Debt). Контрольная выборка для второй проверки исключает пересечение исходных issue с тренировочной группой. Для потребителя Qwen выбор только по модели совпал с правилом всегда выдавать краткое резюме.

При повторах сравниваются новые реальные запуски авторов, а не наши новые облачные вызовы. Исходы без официальной отметки приняты за непринятые патчи в консервативной оценке, количество таких случаев и анализ пар с явными статусами сохранены раздельно. Самые большие экономии токенов относятся к нескольким очень длинным историям. Сравнения продолжают зависеть от зафиксированных моделей и программного обеспечения. Независимое воспроизведение: python verify.py проверяет все группы и 1 530 назначений. python diagnostic.py воспроизводит дополнительную таблицу затрат и решений.
