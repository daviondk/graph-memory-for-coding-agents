# Learning which handoff representation to read on other projects

Exploratory follow-up after seeing the published overall counts and the negative result of the fixed post-failure rule. No private or fresh test set. Only a single candidate policy is specified here. All 1,530 matched configurations in the authors' r01 release are retained. Grouped out-of-project evaluation: for each test repository fit solely on the other repositories, including no other issue, predecessor or checkpoint from that test repository. Four released possible outcomes of the target episode are available; policy sees only predecessor, successor and stage at assignment. The locked evaluation permits direct policy replay because each of the four candidate representations has a recorded run for every checkpoint/recipient. This estimates a deployment policy on this retrospective collection, subject to the authors' missing validations.

Primary candidate: hierarchical shrinkage of arm resolution probability. Fit four arm probabilities on training data. Keep sample weights per checkpoint/recipient equal as in published r01 outcome table; each task may contribute multiple configurations. At each successive categorical level (recipient model; predecessor+recipient; predecessor+recipient+checkpoint type) shrink each observed success probability to its parent with 20 pseudo-observations. When a level is absent, retain parent. Pick arm with highest predicted probability, breaking ties in fixed order raw_trace, structured_notes, summary_notes, repo_only. No fitted hyperparameters. Compare the identical held-out predictions with (1) always raw (strongest observed overall), (2) training-best constant per repository fold, (3) the corresponding model restricted to recipient only, and (4) always structured. Primary signed outcome: paired percentage-point difference vs always raw, with and without explicit official status, repository and source-issue counts, mean token difference and denominator on finite pairs, and paired wins/losses. Unavailable official resolution counts zero in conservative all-assignment outcome and is separately reported. No hypothesis of independent model runs. Compute descriptive 95% interval via repo cluster bootstrap on the out-of-fold differences; conditional on fitted predictions, hyperparameter fixed, no retraining inside resamples. Hold discussion of training/validation split limited to what the design protects. All observed aggregate scores known to research team, so positive result remains a candidate, and an independent collection with newly run agents is needed. Log every assignment and per-fold training source count. No new GPU requests.
