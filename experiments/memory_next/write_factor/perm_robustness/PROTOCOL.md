# Чувствительность лексического опыта к назначению переставленных правок

Дата фиксации 16 ноября 2026. Известны итоги ранее зарегистрированного write_factor с единственным контрольным назначением. Это уточнение симуляции на уже изученных запросах. В исходном контроле тексты правок назначались другим источникам близкой длины. Если независимо менять случайную соль, вывод может измениться. Выбор параметров нового опыта и допустимых эталонов фиксируется до подсчёта новых результатов.

Повторить только лексическую часть прежнего эксперимента. Для всех 300 карточек и 357 вопросов использовать прежние BM25 симптома, заключения и правок, те же веса 2,1,1, прежнюю формулу слияния и разрешение ничьих. Отсутствие и верная привязка правок должны восстановить на всех 357 запросах исходные полные списки. Соль первого контроля также должна в точности восстановить исходный полный список. Для 64 очередных назначений определить соль как x20/perm-robustness/20261116/{индекс}, индексы от 0 до 63. Упорядочить 300 записей по длине в словах, при одинаковой длине по SHA-256 от «соль|ключ». Обменять местами соседей 0 и 1, 2 и 3 и т. д. У всех 64 назначений нет неподвижных точек и одинаковый общий объём правок. Это одна семья симметричных парных перестановок, ограниченная близостью длин. Полезные слова могут сохраняться в неизменных полях и у случайного донора.

Сохранить вектор каждого назначения и все полные прогнозы каждого запроса до присоединения эталонов. Вычислить прежние Match@1, Hit@5, MRR и macro Recall@5. Для двух раздельных наборов вопросов (99 Lite, 258 дополнительных) и дополнительного условного среза с доступным эталоном вывести минимум, медиану и максимум по 64 контрольным назначениям, а также число контролей, достигших уровня верной привязки. Это характеристики устойчивости к механизму генерации доноров, а не 64 независимых тестовых выборки, проверка значимости, интервал по новым задачам или поиск лучшей соли. Нулевую выборку заданий не расширять.
