# Отложенные повторы Handoff Debt, регистрация дополнительного анализа

Зарегистрировано после просмотра сводных результатов r01, до проекции или вычисления исходов r02/r03. Из схемы известны наличие 320 повторных прогонов и результаты по моделям на всём r01. Политика разработана после наблюдения r01; тестовые исходы и повторные стохастические исполнения пока не использовались. Авторы преднамеренно выбрали стратифицированные точки для повторов, а задачи уже участвовали в ранее опубликованной работе и общем описательном анализе.

Раскрываем из r02/r03 сначала только identity, модель, точку, вид handoff, attempt. Все source task ID, встретившиеся хотя бы один раз в повторах, полностью исключаем из r01 обучения во всех моделях, предшественниках и точках. Тест — все полные квартеты r02/r03 без какой-либо выборки по результату. Для каждого получателя учим три политики на оставшихся закончившихся r01 квартетах. Фиксированная для модели форма выбирает максимальную долю решённых случаев среди четырёх форм с равным весом каждой наблюдавшейся пары. Основная процедура выбирает форму отдельно для получателя и этапа передачи, сглаживая решаемость в каждой ячейке 16 псевдонаблюдениями со средней долей решений данного получателя для каждой формы по всем этапам. Одинаковые значения разрешаем в пользу меньшей средней стоимости prompt tokens на тренировочном множестве для того же получателя, затем лексикографическое имя. При неизвестном этапе откатываемся к правилу для модели. Способ использования исходов тот же, что в первом опыте: явный официальный resolved=true, остальное даёт ноль в консервативном расчёте. Приводим доли отсутствующих оценок и чувствительность по известным обоим. Ни одна политика не использует стоимость или действия следующей попытки в качестве признаков. Базовые варианты — обученная на тех же обучающих задачах постоянная для получателя форма (первичное сравнение), полный trace и статические формы; также сравниваем замороженное в первом опыте ручное правило.

Основной эффект: парная разница абсолютной доли подтверждённых решений на всех отложенных квартетах. 95% кластерный bootstrap 10 000, единица ресэмплинга — source task, seed 16112026; выводим win/loss и по seed. Дополнительно публикуем частоты четырёх форм, средние парные стоимости входных токенов, агентских событий и median, статистики официального grade, обучение/тест по уникальным идентификаторам. Один независимый тест после фиксации правил; выбор следующей версии по этим повторным результатам будет разведочным. Нельзя обобщать с одной модели или 40 селективных точек без нового независимого набора. Вычисления только на числовом авторском журнале SWE-bench, без вызова LLM.
