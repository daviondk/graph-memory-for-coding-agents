# Graph memory under eviction

Open [index.html](index.html) locally in a browser. All data and code ship inside the page. The workshop is a constructed eight-event query with real packet encoders. Click the two copies of any event in either order, then request its neighbors. Under eviction notifications the missing list grows only when the final copy leaves. Compare against the unchecked notification option by asking again. Reset and replay with another eviction order.

In the evidence tab choose a cohort, workload, capacity and project. Aggregated SQLite read payloads and query counts come directly from [the controlled replay](../coverage/REPORT_RU.md). The limits tab shows replay of editor-window coordinates and the CPU cost of maintaining coverage. These experiments measure the cost of a fixed graph query. No model-generated code or personal trace text is embedded.

```
python -B build.py
python -B verify_ui.py
```
