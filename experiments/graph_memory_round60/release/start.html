Run the real Tablib query

The offline browser lab uses eight constructed events. The accompanying SQLite snapshot holds a real prefix of 137 Tablib change events. Query tests/test_tablib.py in both modes and inspect the statements that executed. With Python 3, run these commands from the extracted folder.

python -B live_query.py
python -B live_query.py --quiet

For a clickable SQLite console, run python -B live_query.py --serve and open the local address it prints. Each button executes a fresh read against the snapshot.
