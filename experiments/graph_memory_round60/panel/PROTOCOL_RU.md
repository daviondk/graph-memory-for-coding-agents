# Новая панель публичной Git-истории

До получения истории и вычисления показателей алгоритмов фиксируем шесть проектов: **sphinx-doc/alabaster, pydata/pydata-sphinx-theme, numpy/numpy-financial, jazzband/tablib, python-poetry/tomlkit, pallets/jinja**. Реестр предыдущих панелей R55–R59 включает 68 уникальных репозиториев при сравнении имён без учёта регистра. В нём уже есть packaging, pluggy и click, поэтому они не вошли в эту панель. Новая выборка включает инструменты документации, шаблонизации и обработки данных и конфигураций. Это целевой набор публичных Python-библиотек. Нулевая или малая активность одного из проектов не является основанием для замены.

Фиксируем текущую вершину основной ветки по Git SHA и далее читаем только эту ревизию. На проект последовательно получаем до 1 024 переходов по первому родителю. Для короткой истории берём все доступные переходы, исключая корневой коммит без первого родителя. Для каждого перехода сохраняем SHA и отсортированные имена затронутых путей с расширением .py; при переименовании считаем исчезнувший и появившийся путь согласно --no-renames. Временный bare-репозиторий с фильтром blob:none не содержит исходного текста файлов. Наборы изменённых адресов, а также цепочка первых родителей сверяются второй реализацией по исходным объектам commit/tree до удаления временной базы. Одновременно существует максимум один клон на D. Развёрнутые данные отдельного проекта ограничены 100 МиБ.

Преобразование и расписания совпадают с R59/holdout. Для записи в граф годятся коммиты с 2–64 Python-путями. Dense B запрашивает каждый такой коммит с порядковым номером ≥64 (нумерация от нуля), якорь — SHA mod m. Sparse long запрашивает после середины всех переходов при SHA mod 11 = 0 и выбирает (SHA div 11) mod m. Вопрос задаётся перед записью того же изменения. Рестарт — сразу после floor(E/2)-го допустимого события; если префикс пуст, начинаем с холодной памяти. Сохраняются все проекты, включая сочетания с нулём дальнейших вопросов. Два расписания одной истории зависимы.

Этот каталог содержит только источники, доказательство независимой проверки деревьев, состав панели и подсчёт сформированных вопросов. Правила оценки исследуемых механизмов и вычисление метрик находятся за пределами этого каталога. Сбор источников и описание панели не используют их результаты.
