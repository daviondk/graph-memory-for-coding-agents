# Независимая панель истории Python-репозиториев

После запланированного рестарта доступны 485 вопросов в плотном расписании и 45 в разреженном. Все проекты сохранены в исходном составе. У Alabaster после рестарта нет разреженных вопросов. Jinja и PyData Sphinx Theme достигли потолка 1 024 переходов. Для четырёх остальных проектов цепочка закончилась у первого коммита. По всей истории десять изменений затронули более 64 Python-путей. До применения границы рестарта плотное расписание содержит 852 вопроса, разреженное — 47. Наибольший вклад в оба пострестартовых потока даёт Jinja. Расписания используют одну историю каждого проекта, а пути и вопросы одной библиотеки могут зависеть друг от друга. Результаты методов в этом каталоге не вычислялись.

Архив [events.json.gz](events.json.gz) содержит по каждому репозиторию хронологические пары «SHA коммита, список изменённых Python-путей». SHA‑256 файла: `0e0590566b60acc4b15007c45550c42ee6f6287068c9693609196426555d16fa`. Полные идентификаторы версий и адреса источников доступны в [heads.json](heads.json). Независимая процедура сопоставила имена из Git log со сравнением сырых Git-деревьев и проверила родителей каждого коммита. В каждом из шести временных клонов счётчик локально присутствующих объектов типа blob составил ноль; максимальный временный размер по первому сбору — 2 230 709 байт. [Проверка по объектам](raw-objects.json)

Из этой директории команда `python -B sources.py --verify-local` проверяет локальный архив, число переходов и паспорт. Команда `python -B sources.py --verify-git` заново извлекает строго те же шесть закреплённых ревизий, независимо сверяет изменения путей и воспроизводит архив. Обе проверки выполнены. Для удалённой проверки требуется сеть. Временные каталоги создаются по одному на том же диске, что и [сборщик](sources.py).
