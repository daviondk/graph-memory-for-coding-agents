# When to read a full memory card

Protocol fixed before joining predictions and labels for these policy rules. Prior results and 75/99 for the full-card chooser are known. This is a retrospective policy study on an existing test set. Work only from ordinal rankings, anonymized trajectory keys, previous one-item choices, token receipts and official relationship IDs. No task or trajectory text, source diff, reproduction steps or generated patch enters this study.

## Primary hypothesis

For each query rank the same 300 past sessions under the frozen upstream experiment. Inspect the leader under (1) BM25 on closure plus edit metadata, (2) reciprocal-rank fusion of three lexical fields, and (3) the final lexical + dense field fusion. If all three leaders agree, return that session; otherwise consult the archived Qwen 27B full-card decision among the original five fusion candidates. The gate neither changes that shortlist nor requests new generations. Match@1 uses any officially linked session, and all 99 Lite queries remain in the denominator. Secondary sensitivity takes first, last, and the worst possible choice of one official positive per query. List the range of possible paired wins/losses and McNemar p against REM using only published marginal counts; a shared denominator is insufficient for a paired point estimate.

## Baselines and interpretation

Compare to always query, always skip, two-way agreement of the lexical fusion and the final fusion, and a random no-information schedule. A repository-stratified random schedule skips exactly the same count per repository as the primary gate; expectation and exact null distribution of returned correct-ID counts are computed via sampling without replacement. Token budget may differ for the cost-matched-by-calls control; report its expected actual token spend. The primary comparison is against always query: report micro and repo macro effects, 20,000 repo block bootstraps, wins/losses, changed choices and exact McNemar. This small sample has no established noninferiority margin. Log actual archived prompt/completion counts simulated by the gate, total avoided decisions, and the number of differing decisions. Rank extraction and initial document preprocessing are shared overhead and excluded from rerank-token savings. Report strongest available archived 27B variants, original-code Recall keyword/hybrid, field fusion, BM25, MiniLM controls. No method selection on this evaluation. Report any input and candidate-pool differences.
