# Symmetric hot-read optimization

Exploratory after the complete-list reuse control reduced CPU. For a resident residual packet, if every exception already has an immutable body in B8 or the LRU, every source needed by this query is locally available. Accumulate directly from B8 plus matching LRU bodies, promote matching nonhot LRU objects in exactly the same chronological order, restore the empty residual packet as most recent, and skip reconstruction/serialization of all incidence IDs. No persistent reverse index. Compare (i) enable only for a truly empty packet, (ii) enable for any entirely resident exceptions, with the initial residual-only method, the full-reuse, raw-reuse and hot-only controls at the same 1 and 4 KiB on the same twelve histories and five new randomized blocks. Use the existing fallback (including exact internals) otherwise. Byte traffic + SQL calls and every rank must match the original residual-only for every individual query; differences fail the optimization. A numerical win over every strong control is not presumed. Timing across different blocks is never used to determine which of two arms leads.
