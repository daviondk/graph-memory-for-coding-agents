# Как агент выбирает файл следующей правки
> На ChainSWE три сохранённых пути указали на следующий изменённый файл в 210 из 374 случаев. Защита одного повторявшегося пути дала ещё один успех.
Открытый срез ChainSWE unique содержит 213 цепочек, 956 позиций и 661 уникальный ID в 80 репозиториях. В проверке по пяти блокам целых цепочек для 439/956 позиций (118 цепочек) ID также встречается в обучении. При разделении по репозиториям пересечений нет. Числа относятся к выпуску данных.
Для 374 уникальных задач в 77 репозиториях доступны хотя бы две предыдущие правки разработчиков. Из них извлекали пути рабочих Python-файлов. Успех означает, что среди сохранённых путей оказался хотя бы один файл из скрытой следующей правки.

| Как сохранить три пути | Попадания из 374 | Разность с приоритетом недавним и повторным |
| Недавние, с преимуществом повторных при равенстве | 210 | — |
| Защитить подтверждённый ранее путь | 211 | +0,27 п.п. [0; +0,92] |
| Сохранить все ранее встречавшиеся пути | 236 | Верхняя граница по доступной истории |
Правила при трёх слотах разошлись в 28 задачах. Защита дала одно новое попадание и ноль потерь. Для 138 задач нужный файл отсутствовал во всей истории. Бюджет задан в записях путей.
## Как выбрать один из восьми адресов
На тех же 374 задачах восемь записей с приоритетом недавним и повторным путям давали верхнюю границу 233 попадания. Если разрешить одно открытие, выбор по совпадению слов текущего issue с именем пути дал 175/374, выбор по давности — 154/374. Преимущество пути +5,61 п.п. [2,58; 8,55] при 35 выигрышах и 14 потерях.
Восемь слов из последнего issue с этим файлом дали 161 попадание, защита повторявшихся слов — 166. Разность +1,34 п.п. [0; 2,98], шесть выигрышей и одна потеря. По отношению к выбору только по пути защищённые слова уступили на 2,41 п.п. [−5,46; +0,32]. Полный текст последнего issue дал 147 попаданий.
