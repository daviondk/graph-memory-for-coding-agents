# Одинаковый сигнал для двух читателей
> Если два способа ранжирования расходились в выборе первой записи, мы показывали читателю годы пяти свидетельств. Один читатель выиграл от такого распределения ограниченного бюджета, другой проиграл.
StaleBench публикует ответы на 468 фактов Wikidata с меняющимися значениями. Для каждого читателя сохранились два ответа на одном и том же наборе из пяти записей в порядке косинусной близости. В одном случае перед каждой записью указан год. Второй ранжировщик переставляет по времени первые две записи. Правило использует расхождение первых мест до генерации, сохраняет порядок исходного поиска и показывает даты на 240 вопросах. Агрегаты статьи были известны до выбора правила.
@ 4.1 2.6 2.6 3.2 3.7
| Читатель | Без годов | Годы везде | По сигналу | На случайных 240 |
| Qwen2.5-14B | 261 | 449 | 309 | 357,41 |
| GLM-4.6 | 286 | 448 | 391 | 369,08 |
~ Число правильных ответов из 468. Последний столбец — математическое ожидание равномерного выбора ровно 240 вопросов. Полный показ добавляет 16 380 байт к текстам запросов, выборочный — 8 400 байт при любой маске того же размера.
! reader-effect.png
~ Точки показывают разность с равномерным распределением бюджета. Отрезки — 95%-ные процентильные интервалы, полученные вторичным бутстрепом по 467 субъектам Wikidata. Для Qwen разность −10,34 п.п. [−12,45; −8,20], для GLM +4,68 п.п. [+2,56; +6,74].
На 240 выбранных вопросах год исправил 50 ответов Qwen и испортил два. На пропущенных вопросах он исправил бы ещё 142 и испортил два. У GLM соответствующие пары — 105/0 и 58/1. При раздельном сравнении по девяти типам отношений Qwen уступил равномерному контролю во всех девяти. У GLM знак положителен в шести типах, отрицателен в двух, в одном разность нулевая. Полный показ годов дал максимум среди фактически проверенных постоянных вариантов у обоих читателей.
~ Пара сохранённых генераций позволяет оценить показ метаданных одному читателю. В эксперименте источник уже содержал год, каждый вариант выполнялся одним вызовом.
