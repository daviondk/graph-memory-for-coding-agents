# Когда агенту нужна повторная проверка памяти
> Шестая серия исследует решение, которое возникает после сжатия истории или изменения источника. Достаточно ли сохранённой записи для следующего действия и какой сигнал оправдывает новое чтение?
На новых темах CAsT 2021 правило из Cal500 пропустило 23 из 158 чтений. Разность с постоянным чтением по nDCG@3 составила −0,00111 [−0,01176; +0,01089]. В StaleBench одно и то же правило показа дат относительно случайного выбора потеряло 10,34 п.п. на Qwen и прибавило 4,68 п.п. на GLM. При генерации кода проверка версии задания дала 44 решения из 64 против тех же 44 у слепого контроля. В официальной среде Concord исходный метод повысил F1 локальной Qwen с 0,247 до 0,452. Выделение изменённого текста дало +0,029 относительно сопоставимого по длине контрольного фрагмента, с интервалом, охватывающим ноль.

## Как читать сравнения
Каждый контраст использует состояние, для которого доступны результаты разных действий. Это позволяет отдельно подсчитать случаи, когда чтение исправило ответ и когда ухудшило. В StaleBench показываются доверенные годы уже найденных записей. В MBPP агент получает текущий текст задания после решения открыть файл. В TREC воспроизводится выдача предварительно выполненного поиска. Для каждого вмешательства свой смысл цены — символы, обращения, байты файлов или токены модели.
Данные по репозиториям и темам зависимы внутри групп. Интервалы на следующих страницах сохраняют эту структуру там, где она известна. Перенос на другие темы, проверку тех же программ усиленными тестами и смену модели-читателя приводим раздельно. Для будущей статьи наиболее узкий проверяемый тезис связывает конкретное состояние памяти с ценой и результатом одного следующего действия.
