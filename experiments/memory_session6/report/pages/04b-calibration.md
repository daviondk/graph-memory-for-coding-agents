# Что меняет калибровка под читателя
> Одна и та же модель выбора уступила двум моделям, настроенным отдельно для Qwen и GLM. Однако простое правило с ранее известным направлением сигнала оказалось по меньшей мере столь же сильным соперником.
После обнаружения разных знаков на тех же 468 фактах провели разведочный анализ с жёсткой квотой. Каждый читатель получает годы ровно на 234 вопросах. В каждом из девяти внешних разбиений один тип отношения полностью исключается из обучения. Субъекты, встречающиеся среди отложенных фактов, также исключаются из калибровки. Из обучающей части выбираются 8, 32 или все доступные субъекты. Для малых выборок усреднены 32 детерминированных варианта выбора обучающих примеров.

~ Критерий — точность конечного ответа. У каждой модели одна и та же квота, равная 8 190 добавочным байтам. В общем обучении используются те же примеры и метки обоих читателей. Число калибровочных фактов указано для каждого обучения внутри внешнего разбиения.
При 32 фактах преимущество отдельной модели над общей составило +3,69 п.п. для Qwen [2,93; 4,41] и +3,30 п.п. для GLM [0,47; 6,47]. Отдельная модель использовала расхождение рангов, даты пяти записей и длину вопроса. Простое правило отдавало предпочтение совпадающим первым местам для Qwen и расходящимся для GLM. Против этого правила разность составила −0,90 п.п. [−1,76; +0,10] и −2,72 п.п. [−4,84; −0,95].
## Какова цена этой проверки
В этом опыте квота распределяется пакетом между известными запросами. Метки калибровки требуют иметь по два уже оценённых ответа для каждого обучающего факта и читателя. Интервалы получены 10 000 повторными выборками девяти отношений по усреднённым решениям без повторного обучения. Выбор сильного простого контроля использовал ранее обнаруженные знаки на том же корпусе. Оценка подсказывает, насколько важен этот контроль, но независимая проверка выбора знаков потребует другого корпуса и новых читателей.
~ Источник фактов и генераций тот же, что на предыдущей странице. Состав калибровки, квота и основной контраст зафиксированы до проведения новых обучений. Протокол и пообъектные решения находятся в reader/calibration.
