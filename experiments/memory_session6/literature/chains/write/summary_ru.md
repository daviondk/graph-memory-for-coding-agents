# Какие указатели файлов переживают следующую задачу

На 374 уникальных следующих задачах из 77 репозиториев хотя бы один целевой production-файл Python уже встречался в прошлых правках в 236 случаях (63,1%). Прежние правки выступают здесь наблюдаемыми успешными правками разработчика. Указатель на файл, нужный для решения, измерен по фактически изменённым путям. Использованы две или более предыдущие задачи. Полные деревья и тексты исходников агенту для прогноза не требовались.

| Политика при трёх записях | Задач с попаданием, из 374 | Добавления указателей во всех выбранных префиксах |
|---|---:|---:|
| Недавно изменённые | 209 | 1 445 |
| Недавно изменённые, при равенстве удерживать уже известный путь | 210 | 1 405 |
| Сначала разные директории | 211 | 1 346 |
| Удерживать один повторно подтверждённый путь | 211 | 1 386 |
| Частота, затем давность | 212 | 1 352 |

Основной новый вариант защитил один повторно подтверждённый указатель. Набор указателей изменился в 28 задачах, результат попадания — в одной. Разница +0,27 п.п., процентильный 95%-й интервал с ресемплированием репозиториев [0,00; +0,92] п.п. Единственный случай расхождения не даёт основания говорить об устойчивом улучшении. Размер заметки дал более заметную разность. Простой метод с подтверждением при равенстве дал 161, 210 и 233 попадания при одном, трёх и восьми указателях. Это позволяет отдельно изучать чтение одного подходящего указателя из восьми.

Фиксация методов находится в PROTOCOL.md, разработческие истории обезличены в projection.json.gz, выбор момента предшествует присоединению будущих файлов. Восстановить решения и оценки — `python -B retain.py`, затем `python -B grade.py`. Для повторного извлечения четырёх полей задачи из публичного Parquet и обезличивания путей — `python -B project.py` с requests и PyArrow. Инференса LLM здесь не было. Назначение разработческих правок в качестве истории, выбор связанных задач авторами и ограничение Python-файлами важны для интерпретации. [ChainSWE](https://aclanthology.org/2026.emnlp-main.371/)
