# Frozen implementation details

This note disambiguates the existing protocol before lexical projection and quality scoring. Candidate sets and target/prefix identities are taken from the earlier locked write/decisions.json.gz. The source projection reads only the current issue statement and, within that target's own prefix, earlier issue statements and prior diff-header paths already public at that simulated point. A historical issue in one prefix can serve as a target in another, following each prefix independently. Only SHA-256–derived 96-bit words, pointers and repository IDs persist in this extension. There is no shared feature index across cases. Candidate entries may number fewer than eight; each policy selects exactly one existing pointer.

Terms include the complete ASCII identifier, underscore-separated components, camel/acronym-separated pieces of components. A source occurrence counts each resulting normalized word once. Exclude terms under 3 or over 48 characters, numeric-only tokens, fixed English stopwords; no corpus-trained dictionary. Paths use all ancestor components and production filename stem. Query weighting is binary presence. Independent resident path and cue document frequencies give IDF log((n+1)/(df+1)); ubiquitous terms contribute zero. Lexical contributions sum over distinct matched terms. Match-score ties use latest observed task then opaque path ID. Word TF ties use ascending opaque term ID. Stable retention prioritizes at most four of the old stable eight also present in the newly observed issue, ordered by its current TF, then fills by current TF. Uniform retains eight lowest opaque SHA word IDs. Full-latest retains unique words from the latest issue, scored by the same IDF as compact cues. Terms are stored as sets; the source encounter is ephemeral. Track resident admissions, observed slot distributions, actual stored IDs, nominal 12-byte word storage, prefix total pointer-read counts, top-score ties and where policies actually diverge.

Primary effect is the micro-average paired difference on all 374 tasks. The 95% percentile interval comes from 10,000 paired draws of whole repositories with replacement, seed 18112026, retaining original numbers of tasks per sampled repository. Show wins/losses and ties. Additional contrasts include each augmented rule vs path-only, each compact cue vs recency, stable vs the equal-size uniform control and full-latest. Changed-choice cases and reachable cases are descriptive. No significance claims from treating 374 tasks as independent.
