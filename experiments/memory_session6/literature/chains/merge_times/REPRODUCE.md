# Когда стало доступно изменение

Для исследованной выборки удалось восстановить даты слияния всех 592 уникальных прежних pull request. Первичный архив GitHub PullRequestEvent дал 551 запись. Из открытого GitHub REST API получены даты для остальных 41 и проверены ещё 6 заранее отобранных по хешу записей. Все шесть времён совпали. Ответы хранят только выбранные публичные метаданные; тексты PR не использовались. [Документация GitHub Pull Requests API](https://docs.github.com/en/rest/pulls/pulls#get-a-pull-request) · [Архив публичных событий GitHub](https://www.gharchive.org/) · [Публичный ClickHouse](https://play.clickhouse.com/)

Офлайн-проверка `python -B audit.py` восстанавливает даты из 11 сохранённых ответов на запросы к архиву и 47 ответов GitHub REST. Для отдельной новой выгрузки используйте в окружении Concord `python -B fetch.py` и `python -B verify_dates.py`, оставив родительские обезличенные данные и модуль gate/sources.py. Выгрузка использует закреплённую версию официального датасета. Файл verified_times.json индексирован теми же хешами ID, что и исходная память агента.

Дату целевой задачи надо получать из первой записи официальной таблицы Related с данным ключом, как и задачу в исходном протоколе. При первом извлечении дат для вспомогательной проверки target_dates.json выбрал последнюю строку. Сохранённый исправленный target_dates_first.json и собственный файл порогов в ../gate используют первую. Разошёлся один целевой ID из 228 предварительно допущенных к хронологическому сравнению. Дата 23 июля 2019 заменяет 18 мая 2019. Это не влияет на дату слияния любого из 592 исторических PR. Обе версии вторичного расчёта оставлены в gate; результаты по строгой хронологии в отчёте используют исправленную.
