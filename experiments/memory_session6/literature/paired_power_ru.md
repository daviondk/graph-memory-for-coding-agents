# Сколько независимых задач нужно следующей проверке

Это сценарный расчёт для сравнения **двух политик на одних и тех же задачах** по двоичному результату исполняемых тестов. Предполагаются независимость задач, отсутствие пропущенных оценок, один предварительно выбранный контраст и двусторонний точный тест по несогласным парам с уровнем 5%. Распределение числа расхождений рассчитывается биномиально; для каждого возможного числа пар интегрируется вероятность отклонения нулевой гипотезы.

| Гипотетические вероятности выигрыша и проигрыша | Ожидаемая разница | Мощность при 40 задачах | Первая численность с мощностью не ниже 80% |
|---|---:|---:|---:|
| 10% и 5% | +5 п.п. | 4,6% | 498 |
| 15% и 10% | +5 п.п. | 4,9% | 817 |
| 12% и 2% | +10 п.п. | 20,0% | 114 |

Эти вероятности выбраны как иллюстрации, они не оценены из результатов Concord. При малой частоте расхождений точный тест с 40 задачами бывает особенно консервативен. Различение, например, экономии токенов при заранее допустимом снижении качества потребует другого расчёта для границы не меньшей эффективности. Для серий в одних репозиториях нужен расчёт с кластерной зависимостью и отдельный учёт уровня исходного успеха, доли фактических вмешательств и повторения начальных состояний. При подтверждённом результате сильной политики 39/40 запас возможного улучшения на этой выборке всего один ответ. Меньший интервал обеспечит больше независимых задач или иной заранее выбранный endpoint. Точный расчёт восстанавливает `python -B paired_power.py`.
