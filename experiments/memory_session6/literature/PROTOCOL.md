# StaleBench secondary analysis

The paper's aggregate effect of rendering dates, and the primary author table, were available when this analysis was chosen. Before computing any per-question result for this gate, fix the following rule and outcomes. The comparison is exploratory secondary analysis of a public test split.

- Source is `thenexuslab/stalebench-release`, commit `724fccc1ec4caec10b937d7e63159b4f8da7e6e5`, anchored test (468 facts). Use both released readers without tuning. Each reader has a pair of author-scored answers for the same top-five cosine statements, rendered with or without dates.
- Reveal the dates of the five cosine statements whenever the author's cosine ranking and time-reranked ranking put a different item first. Keep the original cosine order for every answer. The signal can be computed from the two candidate orders before generation and uses no answer key. Report the fraction triggered. Check that the top-five sets coincide, as required by the benchmark design.
- Compare against never displaying dates, always displaying dates, and the expected score of uniformly selecting exactly the same number of questions for dates. Record repairs (0 to 1), regressions (1 to 0), and the accuracy difference between the rule and this random counterpart. Check the same contrast separately for each published relation; use a descriptive relation-macro mean to disclose relation imbalance. Also report how many items gain from dates under both readers and under exactly one reader.
- Resource is the number of answers to which five dates are added. Both branches are single reader calls. A count of rendered date panels cannot identify wall time, inference tokens, a new source lookup, or value after another state transition. The gate presumes the ranker already has source times. The recorded paired answers permit off-line replay for a single fixed reader answer per branch. Intermediate questions and rerunning a reader are outside this experiment.
