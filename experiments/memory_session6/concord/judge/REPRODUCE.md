# Слепой пересчёт семантической правильности

Первичная механическая оценка Concord и исходные решения опубликованного судьи находятся отдельно в родительской папке. В этом каталоге один локальный Qwen3.8-27B оценивает неизменённые исходные ответы трёх авторских решателей и все три ветви первого локального опыта. Для каждого из 720 назначений зарегистрирован хеш того же системного и пользовательского сообщения, которые собирают функции из исходного репозитория авторов. Все три исходных вопроса — тип задания, фактический вопрос и эталон — входят в одинаковый шаблон со строкой ответа модели. Оценщик не получает метку метода, информацию о происхождении ответа или вердикт GLM-5.2.

В исходном окружении Concord выполните `python -B infer.py --verify`, затем `python -B score.py`. Воспроизведение вывода из уже сохранённых квитанций обходится без GPU. Проверка `python -B audit.py` воспроизводит разбор ответов и хеши каждого полностью собранного промпта на стандартной библиотеке, включая ещё 80 продолжений из ../highlight_judge. Для новой независимой генерации требуется отдельная копия папки с тем же PROTOCOL.md, полная фиксация исходных решений и нативный движок, описанный в ../../repair.

Некоторые ответы судьи упираются в лимит и не дают разбираемого JSON. Они отмечены как неопределённые после заранее разрешённого повтора; одинаковый вопрос, эталон и ответ имеют один и тот же неопределённый вердикт. В полных знаменателях «из 40» показано число подтверждённых правильных ответов, которое представляет нижнюю оценку. Доля среди разобранных вердиктов имеет иной знаменатель. В results.json для каждой пары есть число полных пар, их контраст и интервал возможного эффекта без предположений о неизвестных вердиктах с учётом их общности. Бутстреп и sign test по показателю подтверждённого успеха считают неизвестный вердикт отсутствием *подтверждённого* успеха. В согласии с авторами приводятся матрица на разобранных вердиктах, интервал и возможные границы на всех 600. Общая модель исполнителя и оценщика — источник зависимости, возможное завышение собственной полезности этим дизайном устранить нельзя.
