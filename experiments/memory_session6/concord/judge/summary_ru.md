# Насколько результат зависит от судьи

Один локальный Qwen3.8-27B получил вопрос, эталон и окончательный ответ на неизменённом промпте семантического оценивания авторов Concord. Порядок определялся хешем входа. Для 600 опубликованных ответов трёх других решателей сохранились исходные метки GLM-5.2. Локальный судья выдал разбираемый вердикт для 593 и согласился с авторами в 589. Матрица для «правильно» дала TP 475, TN 114, FP 0, FN 4; согласие 99,33%, кластерный 95%-й интервал по 40 вопросам [97,93%; 100%]. При всех возможных завершениях 7 пропусков согласие на полном наборе лежит между 98,17% и 99,33%. Различные политики иногда дали один и тот же окончательный ответ, поэтому количество независимых примеров существенно меньше количества решений. Оценка служит калибровкой относительно другого автоматического оценщика.

На первых локальных прогонах правильными признаны 39/40 ответов исходного Concord и 15/40 при обычной истории; все ответы разобраны. В попарном сравнении по задачам 24 улучшения, 0 ухудшений и 16 равенств, +60 п.п. с интервалом [45;75] п.п. Модель-судья также выступала локальным решателем, возможна систематическая ошибка самооценки. Исходные официальные EM/F1, авторские GLM-5.2 на опубликованных моделях и наш общий локальный судья остаются различными измерениями. [Исходный Concord](https://arxiv.org/abs/2610.05281)

Для каждого нового уточнения и соседнего текста существует дополнительная семантическая проверка в ../highlight_judge. В обеих ветвях не разобрался один идентичный ответ, поэтому в парном контрасте его единственный неизвестный вердикт сокращается. Из оставшихся 39 семантически приняты 38 в ветви исправления и 39 в контроле. Подтверждённых улучшений у исправления нет; одна потеря, точный двусторонний p=1. Среди всех 40 вопросов разница −2,5 п.п. Средний механический F1 при этом был у исправления выше. Совместная проверка 800 назначений восстанавливает каждый первоначальный промпт и вердикт из сохранённых ответов HTTP, включая повторные запросы на случай ошибки разбора.
