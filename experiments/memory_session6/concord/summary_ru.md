Разность окна с исходным Concord 0,0 п.п., 95% парный бутстреп [0,0; 0,0]; точный двусторонний p = 1,0000. Модель получала до трёх актуальных строк в том месте прежнего наблюдения, где Concord обнаружил недействительный фрагмент. Входные данные замерялись для каждого фактического запроса.

Проверены 600 опубликованных ответов — три актора, пять политик (включая alert, diff и oracle) и одни 40 вопросов. Каждый EM и F1 пересчитан по тексту, совпадение подтверждено с обеими исходными версиями отчёта. Семантическая оценка GLM-5.2 прочитана из опубликованного решения судьи. Развёрнутый ответ может семантически совпасть с эталоном и получить нулевой EM. Для локальных Qwen-ответов внешнего судьи не запускали. Опубликованные выводы о восстановлении и экономии токенов относятся к другому набору моделей, сравнению с diff и процедуре оценки. Окно ориентируется на прежнюю координату источника, поэтому после сдвига строк может показать другое место. Гарантированная частота таких изменений в реальных диалогах неизвестна.
