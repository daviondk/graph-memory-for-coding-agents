Серия использует локальные фиксации с SHA-256, без внешнего сервиса регистрации. Для разведочных продолжений факт предыдущего просмотра результатов обозначен в соответствующем протоколе. ZIP содержит исходные извлечённые записи и программы их воспроизведения. Полные модельные веса и временные рабочие копии исходных репозиториев восстанавливаются отдельно. В выходном каталоге рядом с ZIP лежит JSON проверки опубликованного архива.
