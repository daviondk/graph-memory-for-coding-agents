# Независимый перенос на CAsT 2021

Замороженное правило, обученное на репозиториях Cal500, при переносе на 158 новых реплик из 19 тем получило **0,39879 nDCG@3 при 135 вызовах механизма переписывания**. Постоянное переписывание дало 0,39990 при 158 вызовах. Разность −0,00111 с 95% интервалом по темам [−0,01176; +0,01089]. У правила 3 улучшения, 8 потерь и 147 равных исходов. Независимая выборка не подтвердила небольшой выигрыш, наблюдавшийся на CAsT 2020.

| Способ | Вызовы из 158 | nDCG@3 | nDCG@5 |
|---|---:|---:|---:|
| Исходный запрос | 0 | 0,20514 | 0,20433 |
| Всегда включать переписывание | 158 | 0,39990 | 0,39899 |
| Пропускать первую реплику | 139 | 0,40215 | 0,40301 |
| Переключатель из Cal500 | 135 | 0,39879 | 0,39958 |
| Переключатель из CAsT 2020 | 158 | 0,39990 | 0,39899 |

Политика из Cal500 сберегла четыре вызова сверх правила первой реплики, потеряв 0,00336 nDCG@3 [−0,00951; 0]. Она пропустила 18 первых и 5 последующих реплик. Политика из CAsT 2020 при обучении выбрала постоянное чтение и сохранила это решение. По всему набору активная ветвь улучшила 84 ответа, ухудшила 18 и сохранила оценку 56. Верхняя граница при выборе лучшей ветви по известной оценке достигает 0,43656.

Для текущего вопроса обе ветви используют один индекс BM25 (k1=1,2; b=0,75), один лимит в 1000 документов и один monoT5. В открытых настройках меняются источник запроса и имена выходных файлов. Использованы опубликованные выдачи воспроизведения ECIR 2023 с официальными репликами, переписываниями и оценками NIST. В CAsT 2021 ранжируются документы. Обе выдачи уже содержат уникальные идентификаторы документов, каждый nDCG@3/5 сверялся с официальным trec_eval при ограничении 500. Первичные источники данных и хеши находятся в public_sources.json. [Архив авторов воспроизведения](https://github.com/iai-group/ecir2023-reproducibility/tree/a92c2118557d61a65a2c85b3ad783c43c1740f12/data/runs/2021) · [Страница NIST](https://trec.nist.gov/data/cast2021.html)

В девяти первых репликах две сохранённые выдачи дали разные nDCG@3, в том числе в двух случаях, где совпали исходная и формально переписанная строки. Поэтому измеряется эффект выбора между опубликованными выдачами целиком. Часть расхождений на текстово одинаковых запросах может быть вызвана особенностями запусков. Отдельно сохраняются различия в идентификаторах, составе и порядке первых пяти документов. Интервалы включают вариацию между темами при фиксированных моделях.

Официальная пара RUIR2_TURN/RUIR4_HIST использует ручные разрешения контекста в обеих ветвях. Оба адреса сырых выдач NIST вернули HTTP 401. Открытые агрегатные таблицы сами по себе не позволяют оценить правило для каждой реплики. У организаторов CAsT 2019 найдена выдача Indri с разрешением местоимений, в перечне исходных данных не нашлось соответствующей парной выдачи того же конвейера по исходной реплике. Не стали смешивать результаты разных команд, методик или лет. [Официальная регистрация RUIR](https://pages.nist.gov/trec-browser/trec30/cast/runs/#ruir2_turn) · [Архив CAsT](https://github.com/daltonj/treccastweb/tree/33846610b736da392efeab00e4c6f4519e0dacf1)

Для пересчёта нужны исходные модели и установленные зависимости родительской папки reader. Команда python fetch_transfer.py загружает исходники, python frozen_transfer.py заново проверяет каждую метрику обеих ветвей, затем сравнивает результаты с сохранёнными строками. В rows.jsonl можно проверить каждое решение и обе выдачи.
Автономная команда python frozen_transfer.py --offline заново применяет модели, восстанавливает интервалы и проверяет итоги по сохранённым rows.jsonl, не загружая полный архив. При nDCG@5 официальный trec_eval дал 0,20433 и 0,39899, тогда как в README авторов воспроизведения указаны 0,2041 и 0,3969. Источник этого небольшого расхождения не установлен. Во всех строках здесь использованы одинаковые явные настройки официального оценщика.
