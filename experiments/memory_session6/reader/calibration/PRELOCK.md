# Pre-outcome lock: cold-start calibration at capacity

The preceding StaleBench study already established opposite signs of the top-rank-disagreement association in these two reader logs. The present follow-up is exploratory: these data cannot supply independent confirmation of that observation. This file was written before any calibration fit or new OOF results. No generation or first-answer signal.

Use all 468 rows and both frozen writer-condition outcomes from the authors' published logs. Exact capacity 234 rows per reader per realization. Within a test partition, allocate floor(group size/2), then give as many extra slots as necessary to odd folds in a deterministic hash order so total is 234. Each chosen request costs the same 35 extra ASCII bytes. This is an offline batch quota observing all features in that fold; do not interpret it as chronological online control.

Primary transfer is leave-one-relation-out (nine held-out relation types); purge training subjects also present in held-out relation. Secondary transfer is five intact-subject folds balanced by descending group size with deterministic seed. Elements represent 467 subjects. For either split train on 8, 32 or all available distinct other subjects; take at most one deterministic fact per calibration subject. Use 32 fixed hash-seeded nested samples for 8 and 32. IDs only assign samples, folds, tie-break and joins. Both readers contribute records for the same calibration facts. One reader-specific label is the pair of correctness indicators for reading dated versus plain context. For a source pool of n subjects, comparing a shared fit to two separate fits uses the same 2n labeled reader pairs overall. Full data is an exploratory high-data reference.

Use only the disagreement bit from the two observed rank lists, and metadata years on the cosine top 5: signed gap (year2 minus year1), newest year minus top1 year, max-minus-min year, distinct year count, position of first maximal year. Add token count of current question. No answer/verbalized forecast, first response, text of candidate facts, gold value, true final/current IDs or years, fact version counts, query IDs or relation labels are features. Subject IDs may be derived only for grouping from key.fact_key. No supervised feature selection. Some permitted date metadata is correlated with how synthetic facts were constructed; this is an intended signal, not access to a verified current answer.

Fixed untrained controls: random expected outcome conditional on each fold quota; prioritize disagreement for both readers; prioritize agreement for both; and a strong reader-specific sign from previous analysis (Qwen agreement first, GLM disagreement first). Rank ties by identical predeclared hash of query ID, not row order. Calibrate a single-feature signed rule by comparing mean gain conditional on disagreement within the calibration sample; if either cell absent or gains tied, use the prior fixed reader sign. Calibrate a richer reader-specific and shared ridge model on gains (dated correct minus plain correct), lambda=1, train-only standardization, unpenalized intercept. Shared fits target the per-item average gain of both readers and have no reader indicator; each specific fit targets the named reader. Fit the same predeclared features and cost. At zero labels only fixed controls are available; do not claim zero-shot signs were externally learned.

Primary assessment is reader-specific 32-shot ridge minus strong untrained signed rule in leave-relation-out, separately per reader, plus reader-specific minus shared ridge. Report accuracy, exact quota, change vs expected uniform, low/high sample calibration spread (10th/90th percentiles, conditional on fixed target), and a paired cluster bootstrap on seed-mean differences (10,000 draws at held-out relation, or subject for secondary). No model retraining in bootstrap, only nine independent relation groups. Make no general reader-family claim. Keep per-item features, per-item decisions/outcomes or their counts over seeds and model-agnostic replay.
