# Можно ли за 32 факта настроить показ годов для конкретного читателя?

При одинаковой квоте в 234 показа на 468 вопросов читатель-специфичная регрессия опередила общий для двух читателей прогноз на **3,69 п.п. для Qwen и 3,30 п.п. для GLM**. Однако самое простое известное правило достигло 85,47% и 83,12% правильных ответов. Регрессия при 32 калибровочных фактах на модель дала 84,57% и 80,40%. В этой выборке оправдан разный знак правила для двух опубликованных логов. Сложная настройка поверх этого знака дополнительной точности не принесла.

| Способ при 50% показов | Qwen2.5-14B | GLM-4.6 |
|---|---:|---:|
| Равномерный выбор внутри исключённого типа отношения, матожидание | 75,86% | 78,42% |
| Всем один знак, приоритет расхождения первых мест | 67,09% | 83,12% |
| Всем один знак, приоритет совпадения первых мест | 85,47% | 73,72% |
| Прежний знак отдельно для читателя, 0 новых меток | 85,47% | 83,12% |
| Только знак по 8 фактам | 83,51% | 80,58% |
| Только знак по 32 фактам | 85,47% | 81,50% |
| Регрессия общая, 8 пар фактов на читателя | 78,48% | 77,36% |
| Регрессия отдельная, 8 пар | 81,02% | 79,25% |
| Регрессия общая, 32 пары | 80,88% | 77,10% |
| Регрессия отдельная, 32 пары | 84,57% | 80,40% |
| Регрессия отдельная, все доступные обучающие субъекты | 85,90% | 82,91% |

Каждый внешний блок полностью исключает один из девяти типов отношений. Удаляются также обучающие строки с субъектом из проверочного блока. Для калибровки берётся максимум один факт от одного субъекта. В каждом из 32 повторов настраиваются отдельные функции по двум читателям и одна общая функция по тем же парам ответов. Одна пара на читателя означает две сохранённые оценки правильности, при скрытом/видимом годе. Таким образом, вариант «32» использует 32 пары на читателя, 64 пары суммарно на два читателя в каждом блоке. Калибровка только знака сохраняет прежний известный знак, когда выборка не позволяет различить два варианта. Все стратегии показывают 8 190 дополнительных байт в расчёте на читателя.

По исключённым отношениям разность отдельной регрессии на 32 фактах с простым фиксированным знаком равна −0,90 п.п. для Qwen [−1,76; +0,10] и −2,72 п.п. для GLM [−4,84; −0,95]. Разность с общей регрессией равна +3,69 [2,93; 4,41] и +3,30 [0,47; 6,47] п.п. Интервалы получены пересэмплированием девяти отношений для усреднённых по 32 повторениям предсказаний. При изменении самих 32 калибровочных фактов 10-й и 90-й процентили точности отдельной регрессии равны 83,35–85,66% и 79,06–81,62%. Дополнительное разбиение по 467 субъектам на пять групп даёт 84,28% и 80,52% у отдельных регрессий против 85,90% и 83,12% у фиксированного знака. При показе годов всем точность достигает 95,94% и 95,73% соответственно, цена 16 380 дополнительных байт.

## Признаки и проверка утечки

Ранжировщику доступны вопрос, два списка идентификаторов кандидатов и годы пяти источников, найденных по cosine. Семь входных величин описывают расхождение первых мест, расположение годов в пятёрке и длину вопроса. Ключ сущности используется лишь для группировки. Аудит подменил все столбцы вне явно разрешённого набора, включая gold_value, current_ids, final_year, содержимое записей и размеченные поля ключей. Все 468 векторов признаков остались побайтно эквивалентны. Оценки ответа присоединяются отдельным этапом после формирования матрицы. Регрессия получает только исходы калибровочных пар, пропуски выбираются без предварительной генерации ответа.

Даты являются доверенной метаинформацией и могут отражать устройство построенного авторами набора. Эффект показывает, каким запросам выгоднее передать читателю эти даты при общей квоте. Данные всей проверочной партии доступны для распределения 50%-ного бюджета, следовательно численный результат относится к пакетному распределению. Знаки сильного простого контроля известны из ранее рассмотренного полного корпуса. «0» означает ноль новых калибровочных ответов; проверка на новом читателе или новом корпусе остаётся открытой. Повторы калибровки повторно используют одни и те же 468 вопросов. Авторская оценка парных ответов и её ограничения наследуются из исходного StaleBench. [Фиксированный выпуск авторов](https://github.com/thenexuslab/stalebench-release/tree/724fccc1ec4caec10b937d7e63159b4f8da7e6e5) · [Статья](https://arxiv.org/abs/2611.19752)

Для воспроизведения запустите python calibrate.py, затем python audit.py. Малый inputs.jsonl содержит признаки и обе оценки на каждый вопрос. actions.jsonl.gz содержит все решения, сохранённые в 32-битных масках повторов; младший бит соответствует первому повтору. Для нового извлечения признаков из исходных файлов выполните python features.py рядом с полной папкой literature. PRELOCK.md фиксирует дизайн до новых оценок, results.json сохраняет все оценки и интервалы.
