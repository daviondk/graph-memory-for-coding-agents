# Full-corpus transfer to Loc-Bench

The capped SWE-bench Lite experiment cannot establish full-corpus performance. Before opening labels on any panel, we selected six benign Loc-Bench repositories by computational size and topic, inspecting the original issue title and corpus length. Convenience sample of six independent repositories: cleder__crepr-64 (20 original functions), tjorim__pyrail-23 (19), Kuuuube__kanjigrid-11 (35), joselc__life-sim-first-try-2 (57), Happy-Algorithms-League__hal-cgp-180 (207), python-visualization__folium-2003 (189). One screening candidate, jobatabs__textec-53, was excluded because its title concerns code scanning. Do not sample based on outcomes, number of named symbols or qrels availability. Use ALL original BEIR candidates in every final ranking. No lexical or oracle shortlist. 

Transfer the locked dense/cosine, dense/raw dot-product, BM25, equal RRF, direct lookup memory, one-hop graph, and rewired-graph policies using the same weights, prefix, maximum length, code and budget (8 retained identifiers). Use the exact official author-provided code representations and positive function qrels. Primary metric is mean MRR@10, secondary Hit@1/5/10, Recall@10, all-qrels@10 and nDCG@10. Six independent issue/repository pairs are bootstrapped as pairs with 10,000 simple resamples, alongside exact sign test and wins/ties/losses. This miniature diverse panel addresses the candidate truncation limitation but cannot estimate the published result across full Loc-Bench. Store per-candidate scores for the complete corpora and seal before opening labels.
