# Frozen follow-up — does attaching the symbol observation earlier improve candidate coverage?

The primary panel uses a common lexical shortlist. A separate blinded panel tests the earlier selection stage against a path-aware lexical baseline, so candidate misses may be corrected. Choose the next six eligible issues after the first six in the same deterministic hash order for each of the three repositories. Use the original complete author-provided function corpus per instance. Apply the same safety-text exclusion rule and do not condition on presence of anchors or gold.

1. Reuse lexical BM25 unchanged.
2. Field-aware lexical baseline: each function's address contributes an additional independent BM25 score over address strings only (same k1/b as body), combined by equal RRF (offset 10). Only positive field scores receive an address vote.
3. Add the direct exact-identifier observation used in the primary panel (frequency of matched explicit name in query, then lexical rank, top eight) to the field-aware order with a 1/(10+observation_rank) bonus. Candidate functions come from the full corpus.
4. Add calls to/from a remembered anchor as a separate half-strength vote, only for globally unambiguous callee names. A direct anchor cannot receive an additional graph vote. Extract call names from the body text, excluding the definition line. Documents may include comments/docstrings, so this approximates a graph of call-shaped mentions. Break score ties deterministically by official function ID. This virtual lookup scans the supplied corpus, which must be accounted for. No dense model in this separately scoped generation ablation.

Primary metric: mean Recall@40, dividing by all positive function judgments, including unreturned ones. Secondary: Hit@40, MRR@10, Hit@10, Recall@10, nDCG@10 and all-qrels@10. Paired task bootstrap within repo with 10,000 draws; graph versus direct and field baseline identifies any incremental effect. Candidate coverage is an upstream extensive-margin question independent of performance of the published encoder. Rows, original IDs, qrels hashes, supporters for promoted functions, and top-40 predictions retained and sealed before opening judgments on this disjoint panel. Do not attribute changes due solely to address fields to graph propagation. No tuning or threshold selection on either panel.
