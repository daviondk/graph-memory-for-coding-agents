A source audit before qrels access identified two official scoring conventions. The Salesforce model card normalizes CLS embeddings. The pinned GitHub evaluation uses BEIR 2.1.0 dot product and SentenceTransformer 3.4.1 with no normalization module or normalize_embeddings flag. We retain all six preregistered conditions unchanged, add the raw CLS dot-product baseline (dense_dot) using the same 1,024-token input, and log binary AllGold@10 as a secondary diagnostic. The authors' second evaluator computes all-target accuracy using a separate gold source and exclusions. Our AllGold treats all positive BEIR function qrels as relevant. This amendment was written after testing CPU inference and before any gold file or measured outcome was opened. Normalized-only incomplete inference was superseded, with the original sample preserved. Both encoders use FP32 CPU, the official model tensors and the model implementation pinned by the config. No reranking condition uses judgment information.
