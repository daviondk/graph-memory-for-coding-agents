# Сохранение точной строки при сжатии выдачи поиска

Дополнительная разведочная проверка на тех же десяти задачах, выбранная после наблюдения совпавших траекторий в опыте с полной историей. До запуска фиксируем реализацию, исходные поиски, ответы модели на запрос для начального поиска, допустимые файлы и все десять ID; используем тот же порядок, без отбора по попаданиям или тестам. Перекрытие задач исключает интерпретацию как независимой репликации.

После фактически исполненного общего поиска сжимаем его результат, как при сокращении истории. Обе руки получают запрос, число видимых совпадений, одинаковый путь к первому совпадению по исходному неизменному порядку и одинаковый фрагмент строки (не более 120 знаков). Контроль хранит текст и путь. Единственное дополнительное поле у опытной руки — номер строки. У контроля то же поле помечено unavailable. У обеих рук одинаковый лимит в 100 токенов для блока первого совпадения. Из начального поиска недоступны прежние числовые ID, поскольку полное сопоставление удалено из оперативной памяти. Любой агент может заново сделать тот же поиск и вновь получить полный результат с адресами и рабочими ID. Следующие поиски и чтения записываются полностью в обеих руках. Только одна заданная точка сжатия. Поле с номером доступно до конца сеанса, включая генерацию патча, что соответствует сравнению двух способов хранить память после сжатия. Это общий эффект памяти, а не отдельно эффект только выбора действия.

Каждая рука получает одно и то же задание, модель, максимум два действия и одну генерацию исправления. Исходный публичный набор путей, базовые версии, тестовый контур, инструменты и параметры генерации наследуются из первого R8. Первичный исход — все целевые тесты и сохранение исходно проходивших из фиксированной регрессионной выборки. Изменения траектории, совпадения чтений с эталонным местом, применение исправлений, токены и времена — вторичные исходы. Все сравнения парные по задаче. Каталог calls хранит отдельное точное кеширование идентичных запросов. Стоимость повторного использования начальных десяти результатов поиска включается в логическую стоимость обеих рук и показывается отдельно от фактических новых генераций этого опыта. Референсные изменения и тесты используются только для оценки после закрытия ответов. Инструментальная трасса и выходы обеих ветвей сохраняются по задачам.
