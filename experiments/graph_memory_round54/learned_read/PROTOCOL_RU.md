# Предварительный план. Перенос обученной политики следующего чтения между репозиториями

Берём все 283 эпизода next_read без отбора по исходам. Новая проверка относится к тем же данным: уже известны результаты ранее замороженных правил, поэпизодная разметка для этого опыта закрыта до фиксации плана. Каждый запрос выбирает один следующий файл из общего заранее проверенного набора lexical_order исходного снимка. Файлы, прочитанные ранее или заданные заранее, исключены в архиве. Строгий набор уже возвращённых файлов используется только для подсчёта итоговой полноты. Репозиторий служит исключительно для разделения и статистики; ID файлов и задач не являются признаками.

**Модели.** Для каждого из семи прежних ранжировщиков (embed4, embed8, jina, lexical, nomic, pplx, repomap) признак файла равен 1/log2(1+r), где r — первое место в соответствующем исходном top-20; ноль при отсутствии. Учим одну логистическую регрессию с интерсептом и L2 для коэффициентов, каждый запрос имеет суммарный вес один, каждый кандидат вес 1/N запроса. Минимизируем сумму взвешенных бинарных cross-entropy по обучающим запросам плюс 0,5||w||², интерсепт свободен. Запрещены пороги, подбор C, веса от ответов текущего запроса и дополнительные текстовые признаки. В static7 доступны семь признаков, восьмая колонка равна нулю. В memory8 восьмая колонка — обратный дисконтированный ранг в последовательности явно предложенных, ещё не прочитанных и подтверждённых на снимке путей, ноль при отсутствии; нумеруем только подтверждённые. В дополнительном static8 восьмая колонка хранит долю семи исходных ранжировщиков, которые включили файл. Это статический контроль с таким же числом информативных признаков. У всех моделей один оптимизатор и правило разрешения ничьей по исходному доступному порядку. Внеобученные внешние сравнения — RRF семи исходных рангов с k=60 и ранее зафиксированный RRF трёх источников.

**Разделение.** Точное leave-one-repository-out: каждому тестовому репозиторию соответствует отдельный fit на всех и только других репозиториях. Для положительного класса используется принадлежность кандидата эталонным путям соответствующего обучающего вопроса. Перед открытием исходов фиксируем выборку, порядок признаков, определения всех сравнений и хеши входов. Сохраняем вероятности каждого кандидата, параметры, номера и состав фолдов, выбранные адреса и совпадения с разметкой. Это перенос между группами на ранее исследованной панели, не внешний тест отдельного корпуса или независимая репликация.

**Основная оценка** — парная разность NewHit@1 у memory8 и static7, общий знаменатель 283. Вторично сравниваем memory8 со static8, замороженными RRF7 и RRF3; также показатели моделей и долю всех эталонных файлов среди строгой выдачи плюс ровно один новый файл. Для каждой разности — объём, выигрыши/потери, 10 000 парных bootstrap-выборок по репозиториям, seed 541907, с пересчётом среднего по эпизодам. Эти интервалы обусловлены полученными out-of-fold прогнозами и не симулируют повторное обучение. Дополнительно показываем результаты с одинаковым весом репозитория и, для проверки чувствительности, полностью повторяем цикл обучения/оценки после исключения крупнейшего по числу запросов репозитория. Без изменений гипотез и признаков по результатам. Эффект на завершение задач, исполняемые тесты или официальный рейтинг общей выдачи здесь не измеряется.
