# Может ли агент научиться выбирать следующий файл по собственной истории?

На 283 эпизодах из 25 репозиториев обученное правило с памятью нашло дополнительный эталонный файл в 23 случаях. Та же модель с семью статическими признаками добилась 22 попаданий, а замороженное объединение семи поисковых выдач методом Reciprocal Rank Fusion (RRF) — 24. **По этой панели преимущество проверенных предложений агента над сильным статическим поиском не установлено.**

## Задача и механизм

Агент уже открыл часть файлов и назвал пути, которые намерен изучить. Ему доступно ещё одно чтение. Берём только явно названные и действительно существующие в исходном снимке пути, которые он ещё не открывал. Эталон содержит файлы из разметки исходного набора. NewHit@1 регистрирует, входит ли выбранный файл в эталон. Общая полнота — средняя по эпизодам доля эталонных файлов, покрытых исходной строгой выдачей и одним новым чтением. Эти показатели измеряют выбор файла. Успех решения задачи по ним определить нельзя. [Исходная постановка и происхождение панели](../next_read/PROTOCOL_RU.md).

Таблица признаков содержит 16 455 пар «эпизод — кандидат», из которых 159 относятся к эталону. Такой кандидат присутствовал в пуле у 116 из 283 эпизодов. Строгая выдача уже содержала все эталонные файлы у 139 эпизодов. Проверенное предложение было у 274. Знаменатель для основного сравнения включает все 283 эпизода.

Каждый файл описывается дисконтированным рангом в каждой из семи замороженных выдач. Порядок предложения в рабочей памяти образует восьмой признак. Для сравнения с равным числом информативных признаков отдельно обучили static8, использующую восьмым признаком долю поисковых методов, вернувших файл. Вес каждого эпизода при обучении равен единице, а кандидатов внутри него взвешиваем равномерно. Коэффициенты регуляризации и правила ничьих зафиксировали заранее. Для каждого тестового репозитория использовали обучающие метки только других репозиториев. У вероятностного балла смысл бинарной релевантности отдельного файла; суммы баллов по файлам в эпизоде могут отличаться от единицы. [Протокол и функция потерь](PROTOCOL_RU.md).

## Устойчивость и границы вывода

Доверительные интервалы рассчитаны по 10 000 парных кластерных bootstrap-выборок репозиториев при фиксированных out-of-fold прогнозах. Изменчивость повторного обучения в интервалы не входит. При равном весе репозиториев разность memory8 относительно static7 составляет −2,67 п.п. по NewHit@1 и −3,10 п.п. по полноте. При полном исключении крупнейшего репозитория gin-gonic/gin (70 эпизодов) заново обучили все фолды на оставшихся 24 репозиториях. На 213 эпизодах получено 24/213 для memory8, 21/213 для static7 и 23/213 для RRF7. Разность memory8 − static7 составила +1,41 п.п. [−1,25; +4,51] по NewHit@1 и +0,95 п.п. [−1,35; +3,43] по полноте. Повторное обучение меняет веса, поэтому вычитание 70 исходных строк даёт другой эксперимент. [Итоги и числа по каждому репозиторию](results.json).

Панель состоит из ранее исследованных архивных траекторий. Статические правила на ней уже оценивались. Отложенные репозитории защищают от прямого обучения на собственных метках, однако для подтверждения переноса требуется новый корпус с отложенными по времени или происхождению траекториями. Проверялась узкая гипотеза о пользе ранга явного предложения для первого дополнительного чтения. Более содержательные признаки состояния, обучение стратегии нескольких чтений и конечные ответы здесь не исследовались.

## Воспроизведение

Из этой папки с установленными Python 3 и NumPy и сохранённой соседней папкой next_read выполнить по порядку:

```text
python -B features.py
python -B evaluate.py
python -B audit.py
```

Построение признаков и фиксация входов выполняются без чтения меток. Регистрация содержит хеши проекции, протокола, кода и исходных печатей. При первом запуске исправили построение хеша имени файла в служебном коде сохранения результата до расчёта метрик. Сохранились исходная и повторная регистрации с одинаковыми проекцией и протоколом. На другой математической библиотеке или версии NumPy возможны различия в последних разрядах коэффициентов и хешах численных архивов. [Первоначальная регистрация](initial-registration.json) · [Рабочая регистрация](registration.json) · [Хеши прогнозов](prediction-seal.json).

Независимая проверка восстановила признаки по исходным спискам, проверила первую производную функции потерь исключительно по обучающим строкам для всех 147 подгонок и воспроизвела 89 265 out-of-fold оценок кандидатов. Максимальная абсолютная компонента градиента — 9,95 × 10⁻⁹, расхождение вероятностей — 1,39 × 10⁻¹⁷. Попадания, полнота, парные выигрыши и потери пересчитаны из исходных меток в обеих выборках. [Аудит](audit.json) · [Коэффициенты и состав фолдов](oof-models.json.gz) · [Баллы по всем кандидатам](oof-probabilities.json.gz).
