# Дополнительный заранее зафиксированный контроль

После фиксации исходных четырёх политик, до первого SQL-прогона по Git, добавлены L=8 и L=12 с частичным заполнением кэша после отказа сертификата. Сохраняются известные лидеры с порядковым ключом не ниже верхней границы неизвестных элементов; по покрывающему индексу запрашиваются только оставшиеся строки до L. Первичные cutoff-8, eager-12, lazy-12 и classic-12 полностью сохраняются. Добавлены lazy-8, classic-8, partial-8, partial-12. Одни и те же данные, параметры, версии, блоки перезапуска и счётчики. Сравнение на обеих ёмкостях: число и строки тёплых пополнений, полные строки вместе с непустой холодной загрузкой, сверка каждого состояния. Результат может совпадать с классическим точным префиксом, превосходить или уступать ему. Попарно сверяем расписание warm-fallback у full и partial lazy; расхождение будет зафиксировано как результат или исправлено при доказанной программной ошибке. Исходный protocol и policy-seal сохраняются без изменений.
