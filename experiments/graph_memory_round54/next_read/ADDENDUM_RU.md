# Дополнение после проверки формата ответа агента

В исходной реализации проверялось поле raw_final_files, то есть заявленный агентом основной список файлов контекста. Этот зарегистрированный вариант сохранён под исходными именами. Среди 283 задач только три имели новый допустимый путь в данном списке. В одном случае изменился выбор, суммарное число попаданий совпало. При разборе частоты срабатываний выяснилось, что архив содержит отдельное поле suggested_unread_files, соответствующее явным рекомендациям в последнем действии агента. В первоначальный вычислительный вариант это поле не попало. Частота его заполнения известна: у 282 из 287 исходных траекторий список непуст. Содержимое одного исключённого примера и поля записи просматривались для установления схемы. Разметка эталонов для первой проверки уже была открыта, поэтому второй анализ является последовательным дополнительным опытом на тех же данных.

До сопоставления рекомендаций с эталонами в этом документе фиксируем повтор расчёта. Единственное изменение политики — взять упорядоченный массив suggested_unread_files из архива вместо raw_final_files. Независимо сверить его с полем последнего распознанного действия модели и записать расхождения. Отчёт публикует основную пару против трёхстороннего RRF, дополнительное правило с подтверждением в top-20, все семь опубликованных моделей, число отсутствующих адресов и повторные проверки. При наличии нескольких путей выбирается первый допустимый. До оценки заново запечатать решения. Отдельно привести показатель для первого *указанного* адреса, который не открылся бы из-за отсутствия в снимке, и потолок Hit@1 при идеальном выборе среди всех перечисленных допустимых предложений (помечается как апостериорный). Единицы, исключения, бюджет и интервалы прежние.
