# Дополнительная чувствительность к лимиту генерации

После просмотра результата 384 токенов обнаружено семь выводов из 133, остановленных лимитом. Две разницы между caller и BM25 по доле тестов совпали с такой остановкой. До измерения новых ответов регистрируется повтор при разрешении 768 токенов для всех трёх вариантов. Для всех семи ограниченных выводов повторить 384 токена с тем же декодером и request return_tokens=true; проверить полный ранее сохранённый текст и число токенов. Получить 768 токенов из того же входа, сравнить исходные 384 нативных token ID и текст с продолженным результатом. Если старая остановка была EOS, лимит не участвовал в декодировании, поэтому учитывается старый ответ. Для проверки дополнительно повторить при 768 первые три EOS-вывода по фиксированному SHA256("r54-eos-replay|" + prompt_sha). Весь результат на 61 методе рассчитывается заново с теми же условиями и тестами. Публикуем общую разницу и судьбу прежней единичной потери при любом результате. Проверка обусловлена уже известной отрицательной первичной оценкой, вторична и не заменяет 384.
