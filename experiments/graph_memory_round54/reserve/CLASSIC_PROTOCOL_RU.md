# Дополнительное сравнение с опубликованным методом

Зафиксировано после получения первичных результатов reserve и до первого вычисления показателей этого дополнительного контроля. Основой служит алгоритм Yi, Yu, Yang, Xia, Chen, Efficient Maintenance of Materialized Top-k Views (ICDE 2003), §3.1. Перед каждым изменением имеется точный префикс переменной длины ≤L. При неизвестном хвосте порогом служит худший ключ предыдущего префикса. После коррекций оставляем все известные строки с ключом не хуже этого порога, обрезаем до L; это снова точный, иногда более короткий префикс. Пока целиком известна таблица, обрабатываем все изменения даже ниже порога. Переход к неизвестному хвосту происходит при первом вытеснении или при чтении ровно L строк из индекса. До первого вытеснения рождения обрабатываются точно. Если осталось меньше восьми известных строк и хвост возможен, запрашиваем из реального сортированного индекса только недостающие до L строки под последним известным ключом. При отсутствии известных строк это полный top-L. При недоборе хвоста снова знаем всю таблицу.

Если транзакция меняет несколько объектов, берём итоговые значения, допускаем безопасный одновременный пересчёт по одной прежней границе и одно пополнение после всей транзакции. Получает ту же информацию UPDATE RETURNING, те же ничьи, снимки, индекс и режим кэша. L=8,9,12,16. Отметить соответствие описанию оригинала, различие с фиксированным числом объектов и поштучными обновлениями в исходном анализе. Показать запросы, строки и фактическую длину точного префикса, проверить весь поток, инвариант точности самого хранимого префикса, перезапуск и тест вынужденной докачки. Дополнительный результат сравниваем с уже известными эффектами основного анализа. [Авторы, полный текст](https://cse.hkust.edu.hk/~yike/topk/icde03.pdf).
