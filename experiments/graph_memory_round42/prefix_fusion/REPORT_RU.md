# Совместное ранжирование видимых свидетельств

Заранее зафиксированное сложение обратных рангов двух графовых систем при 2 048 токенах дало **85,50%** полного покрытия в середине траектории. У собственной модели с обычным first-fit — **84,73%**, у исходной R-GCN без смежности чанков — **81,38%**. Разность нового метода с собственной сильнейшей компонентой **+0,78 п.п. [−0,54; 2,09]**. С нативной моделью — **+4,13 п.п. [2,62; 5,71]**. Интервалы 95%, парные по траекториям и общим seed. Результат подтверждает преимущество составного читателя над воспроизведённым авторским контролем, дополнительный вклад слияния сверх нашего ранжировщика всё ещё неопределён. 901 вопрос, 657 траекторий, все 5 инициализаций. Сохранённый префикс добавляет относительно собственного порядка +0,91 п.п. [−0,31; 2,14]. При 2 048 фактические расходы базового, слитого и нативного порядка — 2 013,0, 2 014,8 и 2 015,3 токена. Для полноты приведена группа всех 2 000 вопросов, включая те, чьи источники ещё не существовали. Слияние восстановило 40,98%, собственный 40,65%, нативный 39,01%. Момент запроса смоделирован усечением трассы. [Настоящие нативные прогнозы на усечённом графе](../../graph_memory_round41/prefix_native/REPORT_RU.md)

Видимые кандидаты, число токенов, порядок учёта равенств и упаковщик зафиксированы до открытия новых оценок. Проведено 162 705 различных поштучных официальных оценок, каждая совпала с независимым расчётом покрытия исходных символьных интервалов. Для каждого из 10 000 состояний вопрос–seed сверены три исходных пакета (30 000 совпадений). Чтобы воспроизвести, выполнить `run.py predict`, затем `run.py grade` в окружении ISETrace.
