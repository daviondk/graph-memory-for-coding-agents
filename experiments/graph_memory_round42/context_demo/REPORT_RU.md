# Интерактивная проверка контекста операции редактирования

Три наблюдённые операции из отложенной группы Handoff Debt показывают, почему прежнюю память иногда можно восстановить прямо из аргументов редактора. В первом случае инвалидация всего интервала оставляет блоки 0 и 1. Сравнение одинаковых краевых строк восстанавливает также блоки 2 и 3. Во втором случае одного краевого совпадения мало. Сопоставление внутренних строк сохраняет оба исходных блока. В третьей операции фактическая замена разрушает единственное ранее выбранное наблюдение при всех четырёх методах. Примеры подобраны для демонстрации различий. Доли успеха для всей когорты приведены в [исследовании 2 696 операций](../context_edits/REPORT_RU.md).

В SQLite сохранены идентификаторы, стоимость и полезность узлов наблюдений, хеши строк аргументов и диапазоны. Выбор политики и бюджета запускает точное вычисление нового пакета. Кнопка аудита сверяет выбранные строки изменённого пути с отдельной SQLite-проекцией исходной и новой версии. Совпали все 12 основных ответов с заранее зафиксированными предсказаниями соответствующего исследования. Программная проверка трёх бюджетов покрыла 36 комбинаций и 225 проверок строк; через живой браузер отдельно пройдены 12 основных случаев. Непересекающиеся строки редактор подтверждает сдвигом адреса, для строк внутри области требуется непрерывное байтовое соответствие. Доступ к тексту всего репозитория при чтении памяти не требуется.

Запуск `python -B server.py`, проверка `python -B validate.py`. Проекция воспроизводится из зафиксированных исходных данных командой `project.py`. [Фиксация примеров](reference.json) · [Проверка браузера](browser-check.json) · [Экран](console.png)
