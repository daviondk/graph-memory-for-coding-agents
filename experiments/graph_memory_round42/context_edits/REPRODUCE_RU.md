# Воспроизведение

Автономная проверка сохранённых адресов, исходов и агрегатов использует только стандартный Python 3.11+ и файлы этого каталога.

```powershell
python -B verify.py
```

Для полного повтора в отдельной рабочей копии нужны исходные подписанные R38/edit_ready, R40/guarded_updates, R41/structural_invalidation и локальные исходные файлы Handoff Debt, как описано в [R41](../../graph_memory_round41/structural_invalidation/REPRODUCE_RU.md). Исторические команды и фрагменты программ не исполняются. В проекторе считываются только агентские поля текстового действия из заранее выбранных строк. В сохранённых входах присутствуют только коды равенства строк, привязки к идентификаторам и размеры. Финальный аудит сверяет служебные полные версии после подписания рангов.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B project_actions.py
& $runner -B predict.py
& $runner -B exhaust.py
& $runner -B audit.py
& $runner -B analyze.py
& $runner -B timing.py
& $runner -B verify.py
```

В новом окружении исправить путь к локальным Parquet в local.py и в общем модуле R41. Семантические итоги должны воспроизводиться при одинаковом интерпретаторе; времени сопоставления отдельные программы намеренно измеряют независимо. Оригинальный manifest соответствует первому расчёту.
