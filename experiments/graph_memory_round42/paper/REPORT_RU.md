# Материалы демонстрационной статьи ICDE

Рабочая рукопись **Maintaining Source-Linked Evidence Views for Agent Memory** описывает поддержание материального представления из свидетельств, извлекаемых из истории агента при ограничении на токены. Работа включает точный критерий неизменности выбранного пакета при удалении источников, измерение стоимости обновления и отдельную проверку валидности строк после реальных правок. [Рукопись, 4 страницы](paper.pdf) · [Исходник](paper.tex) · [Полный автономный пакет](candidate.zip) · [Озвученная демонстрация, 100 секунд](walkthrough.mp4)

При одинаковом бюджете 2 048 токенов на полном ISETrace гибрид восстановил всю эталонную информацию в 83,07% случаев против 81,19% у воспроизведённой модели без смежности с first-fit. В середине истории среди 901 вопроса с уже доступными свидетельствами сравнение с сильным неграфовым контролем при одинаковом обучении дало 83,57% против 79,16%. Прирост связан прежде всего с признаками межсобытийных отношений, а точное динамическое программирование слабо отличается от простой сортировки по полезности. В Handoff Debt проверены целостность и координаты сохранённых наблюдений. Перенос выравнивания на другую систему оказался неопределённым. [Сравнение графовых признаков](../causal_ablation/REPORT_RU.md) · [Слияние рангов](../prefix_fusion/REPORT_RU.md) · [Проверка фактического спроса](../future_reads/REPORT_RU.md) · [Внешний перенос](../swe_transfer/REPORT_RU.md)

Демонстрация состоит из трёх локальных SQLite-консолей. Для запуска достаточно распаковать candidate.zip и выполнить `python -B demo.py`. `python -B verify_candidate.py` проверяет SHA-256 27 файлов и поднимает все три сервера для сквозной проверки. Итоговый MP4 имеет длительность 99,60 с и размер 2 058 223 байта. [Примеры действий](README.md) · [Отдельная оценка третьего интерфейса](../context_demo/REPORT_RU.md)

Трек ICDE принимает до четырёх страниц вместе с библиографией. Видео необязательно, до пяти минут и 50 МБ. В рабочей рукописи оставлено место для имён и аффилиаций.
