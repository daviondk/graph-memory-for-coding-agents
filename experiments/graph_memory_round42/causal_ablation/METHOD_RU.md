# Зафиксированная реализация до первого тестового прогноза

Для каждого вопроса с двумя классами используем вес 0,5 на каждый класс в сумме. В общей таблице веса умножаются на одну константу до среднего 1. Семантические входы — log(1+rank), обратный ранг, относительный ранг и скалярное произведение двух нормированных E5-векторов. Собственная позиция фрагмента и обе длины сторон вызова следуют из видимых метаданных фрагментов. «Простые» метаданные в таблице соответствуют семи shape-признакам R33. Для интерпретации отдельно сохраняем семантику без метаданных и семантику только с ролью и длиной. Бустинг и логистическая регрессия используют одинаковые строки и веса; логистическая регрессия использует взвешенную стандартизацию и C=1. Равные предсказанные оценки разрешаем по текущему семантическому рангу. Это важно для дискретных предсказаний деревьев.

Для каждого тестового вопроса непосредственно вычисляем актуальные скалярные произведения из кеша энкодера. Позиции отдельных кандидатов берём из того же подписанного независимого Dense-FT порядка, что R41, с обязательным удалением отсутствующих фрагментов и перенумерацией оставшихся. Диагностируем побайтовое совпадение этого порядка с новой сортировкой FP32-сходств. При несовпадении проверяем влияние на первую позицию и отмечаем предел точности. Ни одна графовая ячейка не использует конечные оценки R-GCN или истинный тип/эталон вопроса. Обученные диагностические модели применяются одинаково по пяти seed без отбора победителя.
