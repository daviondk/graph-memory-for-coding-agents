# Контроль обучающей разметки

До окончания построения входов, обучения и получения новых тестовых исходов добавляем два вторичных отрицательных контроля. Для rich и full повторяем тот же бустинг после перемещения истинных меток между кандидатами внутри каждого тренировочного вопроса. Перестановку определяет фиксированный SHA от ID вопроса и локального номера кандидата, с циклическим сдвигом на половину длины. Число положительных и отрицательных, их суммарные веса, обучающие вопросы, все входы, класс модели и число деревьев сохраняются. Сравнения full/rich с этими собственными контролями количественно показывают, насколько важна правильная привязка разметки к кандидатам при обучении. Сохранённый Deep-энкодер уже прошёл обучение на исходной задаче. Поэтому дополнительный ориентир без отдельного обучения селектора — чистый порядок Dense-FT. Основной заранее зарегистрированный контраст не меняется.
