# Воспроизведение

Для автономной сверки исходов из сохранённых наблюдаемых запросов, выданных наборов и квитанций требуется стандартная библиотека Python 3.11+.

```powershell
python -B verify.py
```

Полный повтор также требует подписанных локальных данных R37–R42 и 319 локальных файлов Parquet Handoff Debt, NumPy и PyArrow. Скрипт packets.py фиксирует доступные на момент запроса сведения до загрузки будущих просмотров. demand.py размечает новый материал по уже опубликованным строгим границам и заново проверяет каждый реальный вывод view с тем же парсером, что использовался в R37. В архив записываются адреса, хеши, размеры и ID без текстов репозиториев. Скрипты запускаются из этого каталога.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B packets.py
& $runner -B demand.py
& $runner -B score.py
& $runner -B analyze.py
& $runner -B verify.py
```

Политика объединения берётся по хешу её ранее опубликованных прогнозов и требует точного совпадения адресов и пакетов на всех строках. Конечная задача исправления кода в этом эксперименте повторно не запускается.
