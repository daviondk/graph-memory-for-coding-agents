# Отложенная проверка блоков при изменении исходника

До расчёта известны опубликованные раздельные результаты диапазонов, контентного поиска и AST для этой когорты. Устанавливаем новый общий целевой читатель. Он принимает блоки, подтверждённые геометрией правки. Для пересекающихся блоков требуется единственное точное совпадение полного блока в новой версии при совпадении наблюдения со старой версией. На общем пуле оптимизируется тот же защищённый префикс 1 024 байта плюс точный целочисленный рюкзак при бюджете 2 048 байт. Приоритет адреса при двойном подтверждении — диапазон. Политика детерминирована до любых сведений о метках. Исходные сравнения показывались ранее, поэтому этот запуск разведочный.

**Основной тест корректности.** Для всех 2 696 правок сравнить упорядоченные ID и выбранные адреса с полной проверкой каждого пересекающегося блока. Основная панель — ранее отделённые 1 071 событие 13 задач, дополнительно все 37 задач. Любое несовпадение опровергает утверждение о точном обслуживании.

**Операторы.** Оптимистический план сначала допускает все непроверенные блоки. Простое правило проверяет неизвестные выбранные блоки и первый неизвестный барьер, если он является границей префикса. Усиленное правило проверяет выбранные блоки, затем определяет, существует ли невыбранный блок, который может стать обязательным в хотя бы одном допустимом дополнении. При известном опасном блоке проверяется первый неизвестный предшественник. Группа неизвестных выбранных блоков проверяется одновременно. Прогнозам доступны только ответы по запрошенному ID. Источник ответа — зафиксированные действительные совпадения по полным версиям. Повторно подтверждённый блок больше не запрашивается.

**Фальсифицируемая гипотеза.** На первичной панели усиленный оператор требует меньше логических проверок, чем исчерпывающий, при идентичных ID и адресах. Считать отдельно доли сэкономленных проверок и полных обращений к паре версий при единственном кэшировании в рамках правки, число вызовов упаковщика и полное сохранение исходного пакета. Сравнить точный и консервативный планы. Влияние на сохранение относительно диапазона и содержимого также измерить с равными весами задач и парной 95%-й процентильной кластерной перевыборкой (10 000, seed 420137). Для утверждений о времени требуется отдельное измерение с реальным источником. Контроль доказательства — перебрать все допустимые подмножества неизвестных в малых синтетических пулах с равными полезностями и нулевыми стоимостями. Инференс решателя не входит в задачу.
