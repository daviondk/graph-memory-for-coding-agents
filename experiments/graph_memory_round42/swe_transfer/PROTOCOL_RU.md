# Перенос обновлений при правках на SWE-agent / SWE-bench Verified

Берём все 293 полученные ранее публичные траектории SWE-agent с Claude 4 Sonnet из двух непересекающихся R3 панелей. Решения задач из набора Handoff Debt исключаем по официальному instance_id, до просмотра результата. Набор знаком по другим экспериментам с вытеснением памяти. В этом тесте правила из Handoff Debt переносятся без выбора параметров на SWE-agent. Это офлайн-оценка памяти в опубликованном запуске. Используются только данные сообщений редактора.

Первичная совокупность — все успешные операции str_replace на рабочем Python-файле, у которого в текущем наблюдаемом интервале есть предшествующий видимый просмотр и бюджетный пакет содержит блок затронутого пути до операции. Для локализации требуется по одному совпадению old_str в предыдущем просмотре и new_str в немедленной квитанции с одинаковой начальной строкой. CRLF нормализуются в уже опубликованной проекции. Если точную геометрию установить нельзя, все геометрические варианты переходят к одинаковому файловому отзыву. Такие случаи остаются в основном знаменателе. Инструменты с непрозрачным эффектом очищают кэш. Берутся последние пронумерованные строки каждого пути до первой метки обрезки или разрыва последовательности. Определение production-файла исключает тесты, служебные каталоги и примеры. Блоки, стоимость и полезность из прежнего оператора, 8 строк, бюджет 2048 байт, защищённый префикс 1024.

Сравнения при одинаковом исходном пакете — отозвать файл, отозвать весь интервал, подтвердить общие краевые строки аргументов, подтвердить также внутренние равные серии. Первичная метрика — сохранение исходного упорядоченного пакета, первичный контраст — local минус range с равным весом участвующих задач, парный 95%-й bootstrap по issue, 10 000 повторов, seed 424116. Отдельно отчёт по локализованным операциям, обеим исходным панелям, репозиториям и первой допустимой правке каждой задачи. Для текущего содержимого отдельно сверять только фактически увиденные строки в последующем view до следующей записи/непрозрачного события и показывать знаменатель.
