# Перенос политики с Handoff Debt на SWE-agent

На публичных запусках SWE-agent с Claude 4 Sonnet после исключения совпадающих задач получили **265 подходящих правок 159 задач из 12 репозиториев**. При одинаковом лимите 2 048 байт обычный интервал сохранил прежний пакет в **5** случаях, сопоставление строк аргументов — в **7**. При равном весе задач разность составила **+0,75 п.п. [0,00; 2,14]**. Положительная нижняя граница, полученная на Handoff Debt, во втором корпусе не воспроизвелась. Обе разницы обеспечили неизменные краевые строки замены. Внутреннее выравнивание дополнительно ни одного целого пакета не сохранило. [Протокол](PROTOCOL_RU.md) · [Все результаты](results.json)

Из двух ранее скачанных непересекающихся панелей взяты 293 трассы. Для независимости от исходной разработки исключены все 36 пересечений по официальному идентификатору issue Handoff Debt. Среди оставшихся 257 трасс найдено 995 успешных правок подходящих Python-файлов. Первичная когорта требует видимой памяти об изменённом пути после последнего непрозрачного действия. Предыдущее наблюдение с блоком этого пути в исходном пакете нашлось для 265 правок. Для 178 из них старый текст имел однозначную позицию в предшествующем отображении, а новый — ту же единственную начальную строку в видимой квитанции. Остальные 87 включены с одинаковым откатом к файловому отзыву. Когорты сравнивают перенос одного оператора на другие инструменты и рабочие истории. Панели SWE были ранее доступны для других исследований вытеснения памяти. Различие в числе проверенных будущих строк обусловлено составом выбранных пакетов и последующими запросами. Для большинства адресов независимого последующего просмотра нет. Квитанция поступает раньше следующего действия и уже использована для определения позиции правки, поэтому её сверка существенно слабее отдельного просмотра. По одной парной победе пришлось на каждую из двух прежних панелей, в проектах Flask и SymPy. Протокол измеряет сохранение памяти во время реального исполнения агента, вероятность решения SWE-bench этим опытом не оценивалась.

Прогнозы зафиксированы до прохода по последующим событиям. В журнале сохранены ID пакетов, проверяемые координаты и SHA-256 наблюдений. На исходной машине `transfer.py predict` и `transfer.py grade` воспроизводят расчёт, `python -B verify.py` сверяет итог по сохранённым записям без доступа к репозиториям и моделям.
