# Переход по сохранённому ребру и качество ответов на MuSiQue-Ans

В предыдущем опыте выбор второго абзаца менял полноту поиска размеченных источников. Здесь исследуем другой исход на тех же 2 417 вопросах dev. Может ли независимый экстрактивный ридер использовать полученные тексты для ответа? Ридер и правила перехода заморожены. Работа является переносом на другой исход известного корпуса.

Первичное сравнение — локальная оценка перехода local_static против поиска по заголовку title на Answer F1. Содержательный контроль mention_title использует наличие точного упоминания другого заголовка в уже прочитанном первом тексте. Контроль seed читает только первый абзац. Сравнения вторичных метрик и подгрупп описательные. Возвращаем один сплошной фрагмент длиной до 30 токенов в границах одного заголовка или текста. У всех политик совпадают первый документ, вопрос, порядок, лимит на документ (144 WordPiece с заголовком) и параметры единственного ридера DistilBERT distilled SQuAD, INT8, ONNX CPU. Разделитель между документами — [SEP]. Лимит вопроса 64 WordPiece. Разное фактическое число токенов коротких документов публикуем. Состояние retrieval и выбор документов взяты из запечатанных прогнозов R32. Запечатываем входную проекцию без ответов, декомпозиций и меток абзацев. Ридер видит только выбранные тексты. После завершения запечатываем символьные координаты предсказаний и вычисляем официальные macro EM и F1 с учётом всех допустимых ответов.

Сохраняем первичный эффект в процентных пунктах, парный 95% bootstrap по вопросам, дополнительный кластерный интервал по одинаковому первому документу (нормализованный заголовок + полный текст). Перестановки документов внутри вопроса и повторное обучение отсутствуют. Проверяем разбиение по числу эталонных источников, по фактической смене второго документа, и наличие любого нормализованного ответа в переданном тексте как постфактум-диагностику. Единственное заранее направленное сравнение — local_static минус title по F1 на всех вопросах. MuSiQue публичен, ридер обучался на SQuAD, результаты ограничены этой политикой чтения и данным ридером. Набор содержит задачи с тремя и четырьмя переходами при бюджете двух документов.
