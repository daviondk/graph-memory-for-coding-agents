# Переданное по связи свидетельство и конечный ответ на MuSiQue

На всех 2 417 вопросах MuSiQue-Ans dev использование упоминания следующего документа в первом прочитанном тексте повысило точность ответа экстрактивного DistilBERT. При одинаковом лимите двух документов локальный выбор по графу дал **12,65 Answer F1** против **10,72** при втором выборе по заголовку, +1,94 п.п. [1,14; 2,77] по 1 734 кластерам одинакового первого документа. В контроле с точно одинаковым количеством токенов у каждого вопроса разница сохранилась, +1,99 п.п. [1,19; 2,79]. Простое правило «сначала явное упоминание заголовка» воспроизвело результат сложной политики. В первичном сравнении по F1 на уровне вопроса получено 109 улучшений и 56 ухудшений, остальные дали одинаковый балл. Политики local_static и title выбрали разные вторые документы в 613 вопросах. local_static и простое mention_title расходятся только в 17 случаях. При одинаковой фактической длине у этих двух способов одинаковый балл F1 на каждом из 2 417 вопросов. Для двухшаговых задач F1 вырос с 12,15 до 16,32 при переходе к local_static. Для трёхшаговых упал с 11,14 до 10,41, для четырёхшаговых практически совпал (5,47 и 5,50). Это описательные подгруппы. [Исходы каждого вопроса](outcomes.json.gz)

В первичном опыте четыре логических режима дали 9 668 прогнозов и потребовали 5 459 различных вызовов модели. Ридер — DistilBERT base cased distilled SQuAD, квантованные ONNX-веса, CPU. Первые 144 токена каждого выбранного документа включают заголовок. Результат — сплошной фрагмент одного переданного заголовка или абзаца. Для точного выравнивания длины повторно вычислены 572 изменённых входа, 2 470 различных входов побитно переиспользованы внутри того же вопроса. Общая средняя длина равна 217,30. Получена оценка чувствительности ответов конкретного ридера к смене памяти. Бюджет двух чтений и обучение ридера на SQuAD ограничивают выводы о современных системах полного многошагового QA.
