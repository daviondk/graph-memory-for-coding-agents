# Контроль фактической длины

Основной опыт дал +1,94 п.п. Answer F1. Средняя фактическая длина при одинаковом лимите оказалась на 3,66 токена больше в условии local_static, а на 613 вопросах с разным выбранным вторым абзацем разрыв составил 14,43 токена. Фиксируем дополнительную проверку, прежде чем рассчитать её результаты. В пределах каждого вопроса обрезаем вторые документы трёх политик до минимальной из их фактических длин, включая внутренний разделитель. Первый документ у всех одинаков. Оценки start/end считаются заново для изменившихся представлений, при побитовом совпадении входов берём ранее сохранённый результат. Первичное сравнение local_static против title на официальном Answer F1 по всем вопросам, по 1 734 кластерам исходного документа. Второе сравнение с mention_title. Учитываем, что для определения общего бюджета здесь нужны потенциальные вторые контексты сразу нескольких политик. Это парная проверка объяснения через общую длину. При реальной работе одной политики доступен обычный одинаковый лимит из основного опыта.
