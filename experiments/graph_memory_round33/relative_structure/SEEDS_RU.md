# Проверка устойчивости между реализациями Dense-FT

После получения результата seed 13 зафиксированы четыре дополнительные уже обученные реализации Dense-FT, seed 17, 29, 37, 41. Все используют те же вопросы и эталоны, поэтому это проверка вариативности читателя внутри набора. Заранее фиксируем две модели R33 без переобучения — основной global_role и дополнительный global_trajectory. Для каждой реализации берём её собственный порядок кандидатов и калибровку по тем же 101 тренировочным вопросам hash64. Парная база — global того же seed. Проверяем точное совпадение восстановленного порядка базы со строками R21. Сохраняем заранее зафиксированный набор вторичных метрик в том же порядке, ранги до присоединения эталонов, исходы по seed и парные разности. Для обобщения даём среднее по четырём дополнительным реализациям и отдельно по всем пяти. Сначала усредняем исходы по seed внутри вопроса, затем строим 95%-е интервалы по независимым единицам перевыборки — траекториям. Интервалы условны на выбранные seed и пересечение заданий. Отдельные 10 000 наблюдений как независимые не учитываются.
