# Воспроизведение

Используйте то же дерево каталогов, что у серий R18–R22, с зафиксированными проекциями графов, пулами ISETrace и локальным окружением `D:/CodexResearch/x20-isetrace-e5-gpu/venv`. Все новые расчёты выполнялись на CPU. Программы читают существующие данные R20 и R21, включая восемь тренировочных матриц, веса калибровки позиций и перестановки кандидатов по каждому seed. Тексты трасс не исполняются. Для повторения в независимой копии подготовьте входы по протоколам прежних серий. Сначала выполните основную последовательность.

```powershell
python -B study.py
python -B seeds.py
python -B dev500.py
python -B comparators.py test
python -B rgcn_dev.py
python -B comparators.py dev
```

Основная программа сначала восстанавливает обучающие веса прежнего варианта и проверяет их совпадение. Между независимыми сегментами матрицы сверяется число узлов в пуле для каждой траектории. Затем создаются dev-оценки и фиксируется выбор. Восемь файлов тестовых перестановок получают контрольные суммы до вызова тестового оценщика. Для каждого из 2 000 вопросов и каждой из шести метрик результаты прежнего Dense-FT и global сверяются со значениями R20. Вторая программа до оценки сверяет сохранённый порядок global у каждого дополнительного seed с отдельно вычисленным R21.

`rgcn_dev.py` заново загружает два checkpoint R22, проверяет хеш весов E5 и соответствие конфигурации графа, переводит модели в режим оценки и делает расчёты CPU во временной папке `D:/CodexResearch/x20-r33-relative-scratch`. Для теста используются хешированные поштучные предсказания R22. В сравнении бюджетов применяется исходный оценщик интервалов ISETrace. Параметры, отдельные решения, итоговые таблицы и подтверждения этапов перечислены в `manifest.json`. Сравнение агрегирует шесть метрик в порядке FullSupport@2048, Coverage@512, Coverage@1024, Coverage@2048, Recall@5, MRR. Сохранённые в JSON доли лежат в [0,1], разности и интервалы с суффиксом `_pp` выражены в процентных пунктах.
