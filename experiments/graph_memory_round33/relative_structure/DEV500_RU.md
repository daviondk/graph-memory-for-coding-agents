# Дополнительная проверка 500 официальных dev-вопросов

До загрузки результатов этой группы фиксируем веса R33 и процедуры global, global_role, global_trajectory относительно Dense-FT seed 13. Выбираем оставшиеся 500 вопросов официального dev, полностью исключённые из 80-вопросной процедуры выбора R33. Множества вопросов различны, 53 траектории в dev80 пересекаются по источнику с dev500. Эти 500 вопросов ранее служили для выбора эпохи Dense-FT. Поэтому рассматриваем их как дополнительную проверку переноса структурной надстройки на ранее обученный читатель. Порядок Dense-FT, входной набор кандидатов, обработка интервалов и бюджет 2048 сохраняются. Публикуем также C512, C1024, C2048, Recall@5, MRR и парные интервалы по траекториям. Если доступны сохранённые поштучные прогнозы R22 для этой группы, сравниваем при одном seed и одних датасетах. Если сохранены только ранги R22 на совместном test, используем их лишь на test и ставим рядом факт различия dev-протоколов.
