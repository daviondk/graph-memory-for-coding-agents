# Повторение эффекта при смене обучения Dense-FT

У четырёх дополнительных семантических ранжировщиков общая нелинейная калибровка улучшила раннее покрытие источника сравнительно с R20. **Span Recall@5 составил 78,78% против 78,28%, +0,50 п.п. [0,11; 0,89].** Первичная метрика Full Support@2048 составила **78,45% против 78,475%, −0,025 п.п. [−0,448; 0,402]**. Выигрыш +0,55 п.п. по этой метрике в первом эксперименте с seed 13 уменьшился при переносе.

Коэффициенты поправки, тип модели и нормализация перенесены с seed 13. Каждый из четырёх остальных seed использует собственные исходные Dense-FT и исходную R20-калибровку ранга, ранее обученные без test-разметки. Оба базовых порядка воспроизведены для каждого вопроса и всех четырёх метрик. Отобранные предсказания четырёх seed зафиксированы до совместного оценивания. Кластерный bootstrap даёт неопределённость по 1 207 общим траекториям при фиксированных семантических моделях. Общий набор из 2 000 вопросов уже изучался проектом. **Стойкость вторичного результата.** Против более простого общего множителя графа 0,75 выигрыш по Span Recall@5 на четырёх новых seed равен +0,43 п.п. [0,07; 0,80]. Дополнительная ретроспективная проверка с поправкой Бонферрони по четырём метрикам (интервалы 98,75%) даёт для сравнения с R20 [0,015; 1,001] п.п. При учёте сразу четырёх метрик и двух контролей интервал относительно R20 [−0,035; 1,046] включает ноль. Против множителя 0,75 интервал включает ноль уже при четырёх метриках. [Проверка чувствительности](multiplicity.json)

В исходной работе Wang et al. полная residual R-GCN получила Span Recall@5 78,76% и FS 77,33%. Для абляции смежности исходных фрагментов из опубликованных парных дельт выводятся около 80,48% и 78,59% соответственно. Наши пятиseed-средние 78,83% и 78,53% ниже обеих оценок сильнейшей абляции. Парное превосходство над опубликованной системой текущий перенос установить не позволяет. [Таблица 2 и §7.2](https://arxiv.org/html/2609.25913v3#S7)
