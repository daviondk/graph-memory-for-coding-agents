# Перенос фиксированного общего калибратора на четыре дополнительных обучения

Первичная серия с seed 13 показала 78,85% Full Support для общего калибратора с восемью признаками, 78,30% для R20 и 78,65% для переключателя по неопределённости. Следующая проверка зафиксирована после получения этих результатов, до вычисления оценок новых моделей для seed 17, 29, 37 и 41. Это внешний перенос по инициализации обучения с теми же test-вопросами.

Обучение и повторный подбор отсутствуют. Берём выбранные на dev seed13 общий калибратор global_0.03 и постоянный множитель 0,75. При переносе коэффициенты поправки, интервалы нормирования и prior полностью фиксированы. Нативный семантический порядок и исходная R20-функция ранга берутся из соответствующего seed R21. Сохраняются все кандидаты, их исходные смещения и нативный префикс 2048. Исходная R20 и Dense сравниваются по каждому вопросу с подписанными историческими результатами. Прогнозы четырёх seed фиксируются до чтения исходных gold при оценивании.

Первичный контраст — средняя по четырём seed разность Full Support@2048 между global и factor. Сопутствующий важный контраст — global против α=0,75. Дополнительно Span Recall@5, Coverage@2048 и MRR. Ресэмплирование по 1207 траекториям, 10 000 выборок, четыре seed удерживаются вместе. Общие ошибки между seed сохраняются внутри траектории. Средние по пяти показываем отдельно, с выделением seed открытия. Для чисел из статьи SOTA требуется самостоятельное сопоставление с лучшим контролем upstream на тех же seed.
