# Воспроизведение

Восстановите [графовый опыт и числовые входы](../budget_loss/REPRODUCE_RU.md). Используется его venv и необновляемые Dense-FT, ранги и токенные стоимости. Из текущего каталога выполните `python -B ablate.py`. Служебные файлы с независимыми приоритетами хранятся в D:/CodexResearch/x20-r33-graph-ablation. Ключи JSON сопоставляются по ID вопроса. Проверяйте итоговые показатели в results.json и сырые исходы в test-outcomes.json.gz. В журнале train/dev/test отдельные хеши выборок, ранжирований и выбора моделей. Модель без рёбер на этапе обучения использует архивный prior R20 shape с той же взвешенной логистической регрессией. Сохранённые в test-means.json значения — доли, результаты delta_pp — процентные пункты.
