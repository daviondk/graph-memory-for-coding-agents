# Независимая абляция графа после учёта стоимости чтения

В серии R33 лучший результат при бюджете 2 048 достигнут сочетанием графовых признаков и штрафа за чтение длинных отвлекающих фрагментов. Возникает альтернативное объяснение: возможно ли получить ту же точность только по длине, положению фрагмента в событии и плотному рангу? Проверяем на том же ISETrace. Сравнение предложено после анализа прежних результатов, до расчёта новых ячеек.

Факторы. Исходный сигнал (1) ранг Dense-FT, (2) ранг и семь признаков роли, длины и разбиения события, (3) ранг и те же признаки плюс восемь направленных степеней и восемь их процентилей внутри роли. Семь признаков обучались на тех же 446 251 строках с теми же весами, что и полный структурный приоритет. В режиме 2 нет поиска соседей и степеней. В режиме 1 структурный приоритет равен нулю. Для каждого режима сравниваются замороженный ранг, точечная калибровка и штраф по стоимости перед последним положительным свидетельством. Каждая обучаемая калибровка видит те же четыре признака и 196 вопросов train, использует ту же оптимизацию и две величины L2. Выбор L2 отдельно для каждой ячейки по официальным dev580 (FS2048, затем C2048, затем больший L2). Предсказания теста подписываются до оценки.

Первичный контраст — полный граф с калибровкой по стоимости минус семь локальных признаков с отдельно обученной калибровкой по стоимости по FS@2048 при seed13. Вторичные — все три исходных ранга, взаимодействие «выигрыш калибровки с графом минус выигрыш калибровки без рёбер», C512/1024/2048, R5 и MRR. Контроль подлинности — все новые решения полного режима совпадают с предыдущим R33, а замороженное ранжирование без степеней на всех тестовых вопросах совпадает с ранее сохранённым shape из R20. Бюджет, исходный Dense-FT, упаковка, интервальная разметка и оценщик ISETrace одинаковы. Промежуточные данные включают 2 000 тестовых вопросов и 1 207 траекторий. Парный bootstrap по траекториям, seed13. Признаки позиции внутри одного события предполагают, что его разбиение и размер известны при записи. Опыт измеряет необходимость информации о рёбрах для фиксированной модели и корпуса.
