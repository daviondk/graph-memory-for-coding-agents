# Воспроизведение

Потребуются исходные проекции ISETrace, проверенные результаты R20/R21/R22 и соседние `conditional_prior` и `relative_structure`. Подробности подготовки общих данных даны в [описании структурной надстройки](../relative_structure/REPRODUCE_RU.md). Используйте исследовательское окружение на D с NumPy, SciPy и upstream-пакетом ISETrace. Все расчёты выполняются на CPU. Для тренировочного множества плотные ранги снова извлекаются из кэша векторов E5. Остальные ранги берутся из имеющихся зафиксированных Dense-FT. Новый приватный кэш числовых признаков находится в `D:/CodexResearch/x20-r33-budget-loss`.

```powershell
python -B data.py train
python -B losses.py fit
python -B data.py dev
python -B losses.py dev
python -B evaluate.py dev
python -B data.py test
python -B losses.py test
python -B evaluate.py test
python -B transfer.py
python -B diagnostics.py
```

Последовательность сначала фиксирует исходные 196 вопросов и модели, затем выбирает λ и рабочую политику только на dev580. Для теста сначала сохраняется контрольная сумма перестановок кандидатов, затем присоединяется исходная разметка интервалов. Численные градиенты каждой обучаемой функции проверяются центральными разностями. На dev и test до применения поправок воспроизводится каждая позиция базового ранжирования R33. После теста по всем вопросам проверяются шесть метрик замороженной модели. Перенос сверяет исходную перестановку для каждого добавленного seed с зафиксированным предыдущим экспериментом. Последующая факторная диагностика даёт все восемь сочетаний потери и L2. Доли в JSON лежат в [0,1], в табличном отчёте значения приведены в процентах. Ранги, агрегаты, исходы и проверки этапов перечислены в `manifest.json`.
