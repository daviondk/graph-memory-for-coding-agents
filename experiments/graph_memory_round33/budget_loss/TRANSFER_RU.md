# Перенос выбранной функции потерь между плотными читателями

После выбора cost_worst_0.03 на dev580 фиксируем перенос на остальные четверо Dense-FT (seed 17, 29, 37, 41). Изменяем порядок кандидатов и исходный позиционный сигнал на соответствующие варианту R21 с его калибровкой hash64. Относительный структурный компонент и все четыре поправки из seed 13 сохраняются. Для переноса проверяем только замороженную базу, выбранную точечную калибровку и выбранную рабочую политику. Параметры оптимизации на новых seed не подбираются. Для интервала сначала усредняем эффекты по seed внутри одного вопроса и затем перевыбираем 1 207 траекторий. Эти оценки используют те же 2 000 вопросов и характеризуют перенос по читателям внутри тестового корпуса.
