# Потери при ограниченном бюджете чтения

До новых оценок фиксируем базовый ранг R33 global_role seed 13. Замораживаем как структурные веса, так и калибровку плотного ранга. Четыре одинаковые поправки к счёту для всех методов — log(1+ранг Dense-FT), log(1+цена узла в токенах), роль «результат инструмента» и произведение роли на log(1+цена). Стандартизация определяется только по train, равный вес вопросов. Точечная логистическая функция дополнительно допускает общий свободный сдвиг, который не меняет порядок. Линейные поправки обучаются на 196 тренировочных вопросах из двух существующих групп калибровки; они не входили в исходное обучение структурного prior. Их часть участвовала в калибровке плотных позиций. Полное обучение E5 ранее использовало исходный train.

При обязательности всех положительных узлов весь положительный набор помещается в префикс ровно тогда, когда суммарная стоимость самих положительных узлов и отрицательных перед последним положительным не превышает бюджет. Для обучения используем этот факт как суррогат. Нативная метрика ISETrace оценивает покрытие исходных интервалов, поэтому разные узлы могут покрывать одни и те же интервалы. При оценке суждение «все positive units попали» не заменяет эту метрику.

Сравниваем неизменённый ранг, точечную BCE с половиной веса на положительные, попарную логистическую loss для всех положительных × отрицательных, гладкий минимум положительных с температурой 0,25 против каждого отрицательного и тот же минимум с весом отрицательного, пропорциональным его токенам. Гладкий минимум равен −τ log mean exp(−score/τ). Каждый вопрос имеет одинаковый вес. Если отсутствуют отрицательные кандидаты, вопрос не даёт обучающих пар и исключается для всех целей. Все модели используют L2 c коэффициентами 0,03 и 0,3 (выбор только по dev). Для каждой loss выбираем вес по максимальному FullSupport@2048, затем Coverage@2048, затем более сильной регуляризации. Основной контраст — cost-weighted worst-positive против точечно калиброванной базы. Также сравниваем с неизменённым global_role, попарным и худшим положительным без стоимости. Выбираем единую рабочую политику на dev580 среди пяти методов с теми же метриками и предпочтением более простого варианта при равенстве. После фиксации выбора тестируем на 2 000 вопросах, 1 207 траекториях, на нативном бюджете и с равными пулами. Интервалы условны на тестовый корпус, повторно использованный в других сериях.
