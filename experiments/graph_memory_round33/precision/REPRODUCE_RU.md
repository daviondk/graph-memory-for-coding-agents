# Воспроизведение

Из каталога опыта запустить последовательно `python run.py`, `python physical.py` и `python audit.py` с NumPy. Соседние каталоги серий 20, 21 и 22 должны сохранять структуру репозитория. Файл plan.json перечисляет SHA-256 входных ранжирований. physical.py создаёт временные SQLite в D:/CodexResearch/x20-r33-precision, проверяет integrity_check и закрывает файлы. Ряды времени зависят от машины и конкурирующей нагрузки. Для проверки опубликованных контрольных сумм без новой записи в каталог опыта выполнить `python ../verify.py`.

Программное представление четырёхбитных интервалов в первом симуляторе получено округлением восьмибитного кода вниз. Независимый тест распаковывает только настоящие четыре старших бита и сверяет интервалы. Отдельный физический оператор со словарём действительно извлекает части числа из раздельных SQLite. Смотри [детали реализации](physical.py) и [проверку](audit.py).
