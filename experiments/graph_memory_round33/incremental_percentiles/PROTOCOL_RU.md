# Точное обновление процентилей типизированной степени

Фиксируем R33 global_role без обучения. Проверяем вычислительную гипотезу: обновление групповых распределений степени только по затронутым концам позволяет точно восстановить логиты на любом срезе истории. Во время изменения графа процентиль неизменившихся узлов тоже может измениться. Материализуем сырые степени и счётчики по роли, каналу и целому значению степени. При чтении вычисляем midrank по текущей группе.

**Источники и экспериментальная единица.** Первые 48 траекторий из ранее зафиксированной R21 hash-панели. Для каждой строим авторской функцией ISETrace граф строго из событий до 25/50/75/100% завершённых групп вызовов R22. Для первых восьми берём также каждую завершённую группу. Повторяющиеся точки среза объединяются. Сохраняем численные приращения узлов и связей, значения четырёх атрибутов узла и номера кандидатов в исходном Dense-порядке. Каждый снимок получается отдельным вызовом нативного построителя на физически обрезанной истории, совместное выполнение команд трассы отсутствует. Разности двух соседних снимков дают точную нагрузку на исследуемый индекс. Получение разностей не входит в тайминг. Это измерение обслуживания материализованного признака при заданном верном потоке изменений.

**Проверки.** Для каждого состояния и каждого известного вопроса сравнить восемь процентилей, 23 входа, логиты и полное ранжирование с прямой реализацией через scipy.stats.rankdata. Доли касаний считать отдельно для прямого изменения степени и для фактического изменения процентилей старых узлов. Связки разрешаются исходным порядком Dense-FT. Отдельно тестируется искусственное удаление узлов в обратном порядке реальных обновлений, чтобы отделить отзыв ребра от удаления самих доказательств.

**Тайминг на CPU.** Сравнить инкрементальные гистограммы с векторизованным контролем, который поддерживает те же сырые степени и строит распределения только при чтении, а также с полным отложенным пересчётом из актуальных рёбер. Для каждого состояния измерить выдачу по всем активным узлам или только по первым восьми реального семантического порядка. Расписания чтения — на каждом срезе, на каждом четвёртом и финальном, только в конце. Между повторными запросами без обновления допускается повторное использование подготовленного состояния. Минимум пять чередующихся повторов на траекторию. Зафиксировать изменения, длительности, парные отношения времени, объём числовой памяти и область затрат, включая отрицательные итоги. Генерация текста и улучшение retrieval-качества находятся за пределами этого теста эквивалентности.
