# Как позиционировать результаты по памяти агентов

Для демо ICDE основной объект исследования — поддерживаемый пакет свидетельств. Граф связывает результаты, вызовы и фрагменты наблюдений. Когда меняется источник, обслуживающая система может доказать, что прежний оптимальный набор сохраняется, либо собрать новый. Пользователь может проверить принадлежность источнику, вместимость и причину пересчёта. Для демонстрационного трека из этого получается воспроизводимое действие. Рукопись и видео укладываются в официальные пределы четырёх страниц и пяти минут. Дедлайн анонсирован на 7 декабря, 23:59 AoE. ## Какие утверждения выдерживают текущие контроли

1. **Есть прирост измеренной полноты на общем полном тесте ISETrace.** При исходном выборе эпох, одинаковом нативном ранге и бюджете 2 048 выигрыш гибрида над first-fit +1,88 п.п. [0,76; 3,07]. При выборке эпох по самой целевой метрике +2,04 п.п. [0,71; 3,40]. Обученная полезность дала почти тот же результат при сортировке без рюкзака. Эти повторные эксперименты используют те же тестовые траектории. [Контроль эпох и упаковщика](../../graph_memory_round43/metric_matched/REPORT_RU.md)
2. **Межсобытийные признаки несут измеримую информацию сверх сильного неграфового контроля.** На исполнимом триггере после восьми завершённых групп +4,50 п.п. [2,92; 6,14] при идентичном обучении и семантических признаках. Разница с сильной нативной R-GCN в этом режиме неопределённа. Уже известные эталонные строки особенно часто выигрывают, если они относятся к передаче значения между инструментами. Это ретроспективное объяснение механизма. [Онлайн-триггер](../../graph_memory_round43/fixed_trigger/REPORT_RU.md) · [Диагностика по источнику](../../graph_memory_round44/flow_support/REPORT_RU.md)
3. **Нужна стоимость получения наблюдений.** Счётчики SQLite расходовали 128 КиБ против 208 КиБ у таблицы пар и ускоряли смешанное обслуживание. Общий разбор сырых событий занял свыше минуты против долей секунды на операторы. Перенос результата с Python-словарей на SQLite изменил относительную скорость. Поэтому в статье приводятся физические планы и обе границы замера. [SQLite](../../graph_memory_round44/sql_flow/REPORT_RU.md) · [Контроль в Python](../../graph_memory_round44/flow_view/REPORT_RU.md)
4. **Новая память ещё не показала прироста доли решённых программных задач.** Состояние пакетов сохраняется после части реальных правок. На другом опубликованном запуске SWE-agent получено 7 полных пакетов против 5. Для следующего end-to-end опыта нужен независимый корпус задач с автоматическими тестами, фиксированными версиями решателя и инструментария, одинаковым бюджетом и парной оценкой solved вместе с затратами. [Внешняя проверка](../../graph_memory_round42/swe_transfer/REPORT_RU.md) · [Завершённые пилотные задачи с решателем](../../graph_memory_round38/end_to_end_audit/REPORT_RU.md)

Поиск для этой записки был направлен на ближайшие работы по поддержанию представлений, оптимизационной чувствительности, текущему состоянию кодового агента и стоимости контекста. Это обоснование вклада конкретной рукописи. Приоритет определяется совпадением постановки, допущений и результата; исчерпывающий поиск патентной или математической новизны здесь не проводился.
