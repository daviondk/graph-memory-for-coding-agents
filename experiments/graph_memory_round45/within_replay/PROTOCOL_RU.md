# Сравнение эпох при неизменной траектории обучения

Критерий отбора по dev Full Support/Coverage и исходный критерий по dev Node Recall@5 применяются к одному ранее обученному набору из 16 эпох, уже зафиксированному отдельно для каждой из двух архитектур и пяти seed. R43 подтвердил, что в 5 из 10 пар выбранная эпоха совпала, а при сравнениях с каноническим обучением параметры расходились даже при одинаковом номере эпохи. Мы уже знаем исходы ранее обученных бюджетных победителей на знакомом тестовом наборе; отсутствуют исходы повторных Recall-победителей на пяти несовпавших парах. Это ретроспективная проверка механизма.

Парные модели используют одни эмбеддинги, входы, буквальный порядок кандидатов, CPU float32 inference, правило разрешения равенств и строгую бюджетную отсечку. Все 10 бюджетных победителей повторно оцениваются на CPU. Пяти совпадающим модельным парам присваивается один и тот же результат полного прохода, в пяти несовпавших обе сети исполняются на одном батче. Прогнозы по всем вопросам фиксируются контрольными суммами до оценивания. Сравнение с сохранённым GPU-бюджетным победителем оценивает погрешность смены вычислительного backend отдельно.

Первичные оценки по архитектурам — разницы средних бинарных FS при 2 048 токенах при выборе эпохи по бюджетному критерию относительно повторного Recall@5. Приводим обе независимо от знака и 95%-е условные и перекрёстные парные bootstrap-интервалы (10 000 выборок траекторий, для перекрёстного дополнительно пять общих seed, тот же RNG 34091/34092). Обе нижние границы перекрёстных интервалов должны быть положительны для утверждения о согласованном улучшении у обеих архитектур. Вторичные результаты — символьное покрытие при 512/1024/2048, покрытие в top-5 и reciprocal rank первого пересечения, издержки выборки, число уступок и выигрышей. Новые разметки или генеративная модель не используются.

Полный test — 2 000 вопросов и 1 207 траекторий, seed 13, 17, 29, 37, 41. Технический pilot берёт первые 8 траекторий в порядке обхода и оценивает стоимость без разметки; те же вопросы входят в последующий замороженный прогон. Регистр эпох и SHA протокола записывается до старта.
