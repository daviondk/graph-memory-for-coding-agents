# Исполнение и проверка R45

Из каталога исследования проверка подписанных файлов, поштучных затрат, перекрытия интервалов и парных эффектов использует стандартную библиотеку Python и подписанные источники исходного рабочего дерева.

```powershell
python -B verify.py
Get-FileHash -Algorithm SHA256 -LiteralPath manifest.json
```

Для воспроизведения используйте новый каталог с исходными .py, протоколом и registration.json в аналогичной структуре дерева. Исходные модели, оценщик, версии и контрольные результаты закреплены в манифестах R41/prefix_native, R42/causal_ablation, R43/relation_budget и R43/fixed_trigger. Опыт в середине истории использует готовые числовые матрицы. Во второй проверке нужны архивы и локальные CPU-доступные кэши E5. Команды не исполняют события из архива.

```powershell
$runner='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B likelihood.py
& $runner -B predict.py
& $runner -B audit.py
& $runner -B grade.py mid
& $runner -B analysis45.py mid
& $runner -B fixed.py
& $runner -B grade.py trigger
& $runner -B analysis45.py trigger
```

`table.json` хранит обычные и взвешенные обучающие частоты, четыре условные вероятности каждого класса, логарифмические поправки, код и фиксацию входов. `*-forecast.json` подписывает исходную таблицу и упорядоченные списки для каждого расписания. `*-outcomes.json.gz` содержит исходы для каждого вопроса и seed. `*-results.json` содержит все 95%-интервалы и отдельные эффекты, в том числе расход токенов. `audit.py` независимо подсчитывает частоты скалярно и воспроизводит каждый список таблицы для середины истории отдельной реализацией обхода деревьев и упаковки. `verify.py` проверяет источники расходов и интервалы по всем четырём ветвям на обоих расписаниях.
