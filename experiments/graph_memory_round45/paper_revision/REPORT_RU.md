# Статья для ICDE Demonstrations и автономный пакет

**Maintaining Source-Linked Evidence Views for Agent Memory** — англоязычная рукопись на четырёх страницах IEEE. В ней описано, как выбирать подтверждающие фрагменты в пределах токенов, поддерживать связи по ходу выполнения и определять, какие пакеты остались верными после изменения источника. Сценарий демонстрации даёт посетителю удалить источник, менять бюджет, проследить перенос строк после правки и проверить граф в момент отзыва наблюдения. [Читать PDF](paper.pdf) · [Исходный LaTeX](paper.tex) · [Готовый пакет](candidate.zip) · [Видео](walkthrough.mp4)

По итогам внутренней проверки уточнена гипотеза теоремы. Порядок предпочтения при равной полезности задан на полных пакетах. Он должен сохраняться и тогда, когда фрагмент из необязательного хвоста становится обязательным. Детерминированность, определённая только на составе хвоста, сама по себе этого не гарантирует. Реализованный выбор со строгим обновлением при улучшении полезности сохраняет требуемый порядок. [Разбор и перебор малых входов](../tie_order/REPORT_RU.md)

В раздел физических представлений добавлена проверка кэша ограниченных счётчиков. На одних и тех же 31 279 транзакциях, при семи локальных состояниях на направление, отложенная проверка потребовала 343 индексных суммирования против 490 при немедленной проверке. Они выдали одни и те же флаги на всех транзакциях. Измеряется число обращений к имеющемуся индексу. [Подробный эксперимент](../bounded_counts/REPORT_RU.md)

Архив содержит PDF, исходный текст, видео и SQLite-приложение. Его можно распаковать и запустить командой `python -B demo.py`. Команда `python -B verify_candidate.py` запускает и проверяет четыре локальных HTTP-консоли. Видео длится 118,16 с и занимает 2 419 620 байт. Имена и аффилиации авторов, а также финальная авторская вычитка остаются перед подачей. Исходные результаты компьютерных экспериментов и отрицательные сравнения доступны в связанном отчёте.
