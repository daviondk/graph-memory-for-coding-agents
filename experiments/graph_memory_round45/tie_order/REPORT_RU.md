# Авторская проверка критерия сохранения пакета

Независимый конечный перебор дал **0 расхождений в 3 334 530 сравнениях**. Для каждого исходного упорядоченного пула из 0–4 кандидатов проверены все присваивания цен из {0,1,2}, полезностей из {−1,0,1}, все бюджеты B от 0 до 3, все целые пороги T от 0 до B и все подмножества удалений. Это 73 810 исходных задач. В 2 655 900 сравнениях исходный пул содержал нулевую цену, в 333 453 бюджет равнялся нулю. В 203 690 оставшихся пулах при соответствующем бюджете и пороге оптимум по полезности имел хотя бы одну ничью. Последнее число считается до применения трёх порядков.

Для каждого набора допустимых полных пакетов выбирался вариант максимальной полезности. По очереди ничью разрешали три фиксированных порядка по маске исходных рангов: минимальная маска, максимальная маска и максимальное значение (149×маска+37) mod 257. Последняя функция инъективна на проверяемых масках. Для каждого порядка пакет после удаления D совпал с прежним P ровно тогда, когда D не пересекается с P и новый обязательный префикс H′ входит в P. Отдельная динамическая программа со строгим сравнением воспроизвела выбор минимальной маски в 1 185 320 вызовах. При ничьей она оставляет вариант, исключающий последнюю различающуюся позицию. Продвижение общих элементов из хвоста в префикс сохраняет этот порядок полных пакетов.

**Оговорка для формулировки.** Относительное предпочтение полных пакетов при равенстве должно сохраняться при переходе кандидата из хвоста в обязательный префикс. Фиксированная детерминированная функция только от хвоста допускает контрпример. Возьмём B=2, T=1, исходные ранги 0,1,2,3, цены (2,1,1,1), полезности (1,2,1,1). При ничьей максимизируем маску хвоста со знаком плюс для нечётного числа выбранных элементов хвоста и минус для чётного. Изначально префикс пуст, пакеты (1,2) и (1,3) имеют полезность 3, функция выбирает (1,2). Удалим невыбранного кандидата 0. Новый префикс (1) входит в исходный пакет, однако функция выбирает (1,3). Строгий авторский DP в обоих случаях выбирает (1,2). Достаточно уточнить общий порядок на полных пакетах в тексте теоремы. Доказательство через вложенность допустимых семейств сохраняется. [Точное описание и исходное доказательство](../../graph_memory_round44/paper_final/paper.tex)

Предшествующий R39 проверил 108 204 сценария удаления на 40 реальных траекториях и 20 204 подмножества удалений на 320 малых пулах. Q32 воспроизвёл все 10 000 исходных пакетов и 108 204 исхода удаления. R42 проверил 117 612 дополнений частичной информации на 180 пулах со случайными целыми ценами и полезностями, включая нули и ничьи. Новый перебор покрывает полную малую сетку входов и явно отделяет устойчивость полного порядка от детерминизма хвостового правила.
