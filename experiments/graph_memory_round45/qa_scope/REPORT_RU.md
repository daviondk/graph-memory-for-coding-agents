# Можно ли сравнить качество ответов с авторской R-GCN на ISETrace

В работе Wang et al. два разных результата. Первый измеряет, поместились ли в контекст все размеченные фрагменты при бюджете 2 048 токенов (Full Support). Его мы воспроизводим на 2 000 вопросах, на тех же типах записей и с авторским кодом модели. Второй оценивает уже ответ языковой модели. Из 469 прошедших контроль качества вопросов авторы выделили 315 с типами linked/multi-fact. Для этой проверки исправляли разметку и вручную уточняли набор доказательств. В работе модель `gpt-5.6-luna` используется для формирования ответа и отдельным вызовом для оценки. Авторы сообщают 77,78% у R-GCN и 71,75% у плоского метода, интервал разности от 0 до 12,10 п.п. [Статья и приложение](https://arxiv.org/abs/2609.25913) · [Авторский код](https://github.com/xiaoqi-7/GraphMemory/tree/a98e2c30285a6d557a8b429e59a1a6eb27738537/graph_memory/datasets/isetrace/end_to_end_qa)

Проверили три файла, требуемых опубликованным оценщиком: `human_quality_pass_task_ids.json`, `human_corrected_query_metadata.jsonl`, `review_packet.jsonl`. Искали по именам в закреплённом локальном checkout (273 файла), в актуальной версии GitHub (280 файлов), в артефактах релизов и в обоих публичных датасетах Hugging Face. Совпадений нет. В доступном датасете вопросов есть исходные запросы, цитаты и типы. Точную ручную коррекцию и выборку QA авторов по этим файлам восстановить не удалось. Результат инвентаризации относится к этим источникам и закреплённым ревизиям. [Машинный журнал](source-check.json) · [Публичные вопросы](https://huggingface.co/datasets/HazeLocus/ISETrace-Memory-Queries) · [Траектории](https://huggingface.co/datasets/valiere/ISETrace)

Для статьи сохраняем наблюдаемую границу результата. FS имеет прямой воспроизводимый контроль по метрике и модели. Улучшение качества конечного ответа требует отдельного запуска. Для точного сопоставления с опубликованными 77,78% потребуются три входа из ручного аудита и одинаковый генератор, оценщик и режимы декодирования. На своей открытой выборке можно провести парный опыт при общем читателе и общем оценщике, явно указав состав и знаменатель.
