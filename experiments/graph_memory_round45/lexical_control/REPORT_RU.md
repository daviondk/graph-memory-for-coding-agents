# Сохраняется ли выигрыш, когда в вопросе нет имени файла или другого явного идентификатора

На 896 вопросах ISETrace без явного идентификатора графовый признак передачи значения повысил Full Support при 2 048 токенах с **79,26% до 83,48%**. Разность **+4,22 п.п.**, парный 95% интервал **[2,55; 5,92]**, 655 траекторий и пять инициализаций. В обеих ветвях одинаковые пул кандидатов, текстовая семантика, метаданные и способ наполнения пакета. FEEDS связывает вызовы, когда типизированная строка из одного результата переходит в аргумент другого. Вопрос может описывать требуемый факт, даже если человек не называет конкретный путь, URL, UUID, хеш или имя файла. [Исходные парные результаты](paired.json.gz) · [Вычисленные интервалы](results.json)

Для детектора взяли точное регулярное выражение из публичного кода Wang et al. Воспроизвели разбиение на исходном тексте запроса до соединения с результатами. В полном тесте детектор пометил 8 из 2 000 вопросов, на основном промежуточном срезе — 5 из 901. На этих пяти оба метода совпали во всех парных исходах, среднее 60%. Редкая страта слишком мала для вывода о разнице между типами вопросов. В 62 из 10 000 кластерных перевыборок в неё вообще не попало наблюдений. В файле результатов сохранён формальный условный интервал, в том числе вырожденный нулевой интервал для пяти пар. Обобщать его на новые запросы с идентификаторами нельзя. [Авторский детектор](https://github.com/xiaoqi-7/GraphMemory/blob/a98e2c30285a6d557a8b429e59a1a6eb27738537/scripts/feeds_lexical_stratify.py) · [Фиксация страт](label-lock.json)

Опыт исключает простое объяснение совокупного прироста явным идентификатором в тексте вопроса в смысле авторского детектора. Совпадения обычных слов и связи между наблюдениями остаются возможны. Это диагностический срез прежних трасс. Пять инициализаций входят в интервал как повторные оценки. Проверка использует только промежуточные состояния, в которых эталонный текст уже полностью доступен.
