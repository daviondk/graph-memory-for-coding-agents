# Полная панель R34 — продолжение сравнения с Qwen3-Embedding-8B

Известны исходы пилота R39 на десяти детерминированно выбранных состояниях разных репозиториев. До оценки нового Qwen на остальных состояниях фиксируем единственную расширенную панель. Берём все 214 held-out состояний R34 с разбиением по репозиториям. По их идентификаторам проверяем, что оригинальные десять входят в эти 214. Основное сравнительное множество включает 204 состояния вне пилота. Отдельно выводим все 214 и прежние десять. Все три группы определяются до вычисления исходов. Пилот и продолжение принадлежат одному публичному SERBench Cal500, а исходы некоторых прежних локальных систем ранее использовались для выработки гипотез. Наличие 204 новых Qwen-предсказаний не превращает эти состояния в новый внешний тест.

Повторяем сравнение полных внутрисостоянийных пулов по исходному протоколу. Официальная Qwen3-Embedding-8B-GGUF Q4_K_M с теми же весами, одно локальное устройство RTX 3090, тот же llama.cpp, подготовка запросов, терминальный токен, 512 токенов на строку, последний токен пуллинга, та же сортировка по длинe для пакетной обработки четырёх строк. Маскированный вариант — один и тот же порядок с отсрочкой просмотренных кандидатов. Оба варианта употребляют один набор сырых скалярных оценок. Данные вне станции не передаются. Полный пересчёт GPU включает пилотные десять. Сравниваем ранги top-8, значения косинуса, объём токенизации и факт усечения с сохранёнными десятью строками R39. При расхождениях фиксируем причину и чувствительность. Смешивать CPU-предсказания и GPU-предсказания нельзя.

Для R39 используем 1) согласованный статический одноместный бустинг без прямого флага просмотренности на минимальной остаточной цели с пустым префиксом, 2) тот же полный список с детерминированной отсрочкой просмотренных, 3) обычный ранее зафиксированный one_distance с флагом. Контрольные BGE и union_cost также имеют вариант без и с отсрочкой. Все параметры повторяют R39 и выбирались только на 101 dev после обучения на 179 train. Никакого нового выбора признаков, порогов или весов по 214 состояниям не происходит. Десять старых списков R39 должны в точности совпасть с прежними.

Основная метрика — официальный Complete-MSS@5. Для сравнения без наблюдаемости оцениваем R39 без флага минус Qwen. Для сравнения с общей маской оцениваем R39 без флага с отсрочкой минус Qwen с отсрочкой. Заранее объявляем основным второе сравнение на 204 и печатаем первое независимо от знака. Внутренние исходные представления состояния могут неявно содержать сведения о чтении. Вторичные исходы — MSS@8, MSS@8 под бюджетами 2048 и 6144 Qwen-токенов, GroupRecall@5/@8 и Necessity@5 из официальной функции, среднее число выданных исходных токенов при 5/8, время и доля усечённых строк. Для основных бинарных метрик показываем парные выигрыши/проигрыши и 95%-е процентильные интервалы из 10 000 перевыборок целых репозиториев внутри соответствующего множества. Для 214 и 204 также показываем среднее по репозиториям для основной метрики, знак эффекта по стратам observed-флагов как вторичную проверку. Оцениваем целые ранги восьми единиц. Никакие публикационные значения скрытой Test500 не используются как прямой компаратор.
