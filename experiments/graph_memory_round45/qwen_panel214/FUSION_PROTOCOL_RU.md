# Дополнительное сочетание R39 и сильного семантического поиска

До запуска Qwen на оставшихся 204 состояниях фиксируем отдельный расширенный эксперимент. Числа десятисостоянийного пилота для одиночных систем уже известны. Формула RRF использует два полных порядка из одного и того же замороженного пула. Балл кандидата равен 1/(60 + ранг Qwen) + 1/(60 + ранг R39). Вес обеих ветвей равен единице; k=60 фиксировано, конфигураций по новым данным не выбираем. При точном равенстве итоговых баллов порядок задаёт исходный отсортированный непрозрачный ID, одинаковый принцип в каждой ветви. Главная обученная ветвь — тот же R39 с пустым префиксом и меткой принадлежности кратчайшему набору без столбца observed_by_state. Обучение и настройка только на прежних 179 и 101. Непосредственная проверка попарного слияния — реализация на NumPy плюс независимая целочисленная проверка: для двух положительных дробей сравниваем точные рациональные суммы.

Для каждого состояния сохраняем полные индексы рангов и выдачи 1) Qwen, 2) RRF Qwen и R39, 3) RRF Qwen и BGE, 4) RRF Qwen и union_cost. Каждый из четырёх вариантов выдаём исходно и с одинаковой стабильной отсрочкой уже просмотренных единиц **после** построения общего ранга. Полные списки подтверждают правильность обратного заполнения. Собственных токенных параметров, выбора варианта по пилоту и использования денег на дополнительные Qwen-вызовы нет. Выдачи слияния подписываются до первой оценки их исходов.

Первичный контраст этого дополнительного опыта — RRF Qwen+R39 минус Qwen в одинаковом режиме с отсрочкой на тех же 204 состояниях вне пилота, метрика MSS@5. Вторичные — версия без маски, сравнение с RRF Qwen+BGE и RRF Qwen+union_cost для проверки добавочной ценности обученного читателя; они нужны, потому что само сочетание разных ранжировщиков может повысить качество. Выводим MSS@8, обе стоимости 2048/6144 и парные интервалы по 10 000 кластерным перевыборкам репозиториев, полную 214 и пилотную 10 для прозрачности. Сам reciprocal rank fusion — известный алгоритм, вклад самих особенностей памяти зависит от согласованных контролей. Если эффект положителен только при одном бюджете или относительно одного базового метода, область вывода соответственно ограничена.
