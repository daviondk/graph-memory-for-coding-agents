# Отчёт. Сколько примеров требуется для бюджетной калибровки графового поиска

Расширение обучения коррекции с 196 до всех 3894 вопросов подняло **Full Support@2048 с 80,60% до 81,15%** на 2000 тестовых вопросах ISETrace. Основной парный контраст составляет +0,55 п.п., 21 выигрыш и 10 потерь, 95% кластерный интервал [0,00; 1,09] п.п. Обе интегральные метрики улучшились с интервалами выше нуля. При полном объёме данных исключение пересечения между обучением базового структурного приоритета и последующей коррекции дало ту же долю полностью покрытых ответов, что оба контроля. Это результат одного Dense-FT seed 13 на ранее использованном тесте. [Протокол](PROTOCOL_RU.md) · [Поштучные исходы](test-outcomes.json.gz) · [Все контрасты](test-results.json)

## Обучение

Графовый балл сочетает фиксированный ранговый сигнал Dense-FT и линейный структурный приоритет по 23 признакам, включая наблюдаемые типизированные степени и их процентили среди узлов той же роли. К нему прибавляется линейная поправка по логарифму Dense-ранга, логарифму стоимости узла, роли и взаимодействию роли со стоимостью. Коррекция обучается ранжировать худший из размеченных положительных узлов выше посторонних, с весом стоимости постороннего узла. У каждого вопроса одинаковый вес, температура сглаживания 0,25, λ=0,03. Все eval-ветки используют тождественные плотный порядок и структурный приоритет. [R33](../../graph_memory_round33/budget_loss/REPORT_RU.md) · [Параметры](models.json)

Официальные разбиения содержат 3894 train, 580 dev и 2000 test. Число несмешивающихся траекторий соответственно 2410, 352 и 1207. Предварительно обученный intfloat/e5-base-v2 уже дообучен на официальном train. Перекрёстное обучение касается последующих линейных моделей. Восстановили нативный порядок Dense для 460128 пар вопрос–кандидат из ранее посчитанных векторов. Подписанная числовая матрица занимает 6,55 МБ. На 196 исходных вопросах проверены признаки, смещения и позитивы. Повторное обучение исходного структурного и рангового приоритетов воспроизводит сохранённые баллы с максимальным абсолютным отклонением 7,9×10⁻¹² и 5,4×10⁻¹⁵. [Инвентарь](train-inventory.json) · [Модели складок](fold-models.json)

Вложенные панели включают 196 вопросов с 123 траекторий, 1024 с 637 и 3894 с 2410. Каждая из пяти складок определяется траекторией. В OOF-режиме базовые линейные оценки на train получены с исключением всей траектории текущего вопроса. Структурная модель каждой складки обучалась на 2935–2980 из прежних 3698 вопросов, а линейный калибратор плотного ранга — на 70–90 из прежних 101. При полной подгонке структурная модель видит все 3698, а ранговый калибратор на train по-прежнему исключает текущую складку. При ротации исключается следующая складка структурных данных, чтобы сохранить сопоставимый объём базового обучения. Нулевая пересечённость основных независимых групп и принадлежность каждой траектории проверены по идентификаторам. Параметры не выбирались по dev. Budget-AUC — нормированная площадь по log₂-бюджету на шести авторских точках 256–8192. Разность 3894 OOF относительно исторического R33 по Coverage Budget-AUC составила **+0,352 п.п. [0,132; 0,580]**, по Full Support Budget-AUC **+0,350 [0,114; 0,591]**, по Coverage@2048 +0,478 [0,021; 0,969], по MRR +0,291 [−0,090; 0,675]. Интервалы получены парным bootstrap по 1207 траекториям, 10000 повторов. Вторичные интервалы не скорректированы за множественные сравнения. [Dev](dev-results.json) · [Test](test-results.json)

Внутри одной OOF-процедуры прибавка 196→1024 равна +0,70 п.п. Full Support [0,20; 1,22], 21 выигрыш и 7 потерь; 196→3894 даёт +0,60 [0,05; 1,15], 22 и 10. Для 3894 относительно 1024 разность −0,10 [−0,30; 0,10]. Панель 1024 дала наибольшую наблюдаемую оценку. Предварительно выбранный основной метод сохраняет все 3894. Один вложенный порядок и одна модель не позволяют установить оптимальный размер. Расширение меняет состав корпуса, а также нормировку четырёх признаков. При 3894 OOF и полная подгонка имеют 1044 различающихся порядка, но равные исходы FS2048 для всех 2000 вопросов. Ротационный контроль также совпадает с OOF по FS2048. Эффект самой перекрёстной процедуры в этой метрике не обнаружен. [Поштучные ранги](test-orders.json.gz)

Расчёт: CPU AMD Ryzen 7 8700F, один поток для численных операций, предвычисленные эмбеддинги. Подготовка первых 3698 заняла 168 секунд, после них восстановлены ещё 196. Вычисление пяти пар базовых моделей и всех вторичных поправок заняло 13 секунд. По 12935 различным парам тестовый вопрос–порядок все пять итоговых показателей независимо пересчитаны по атомарным исходным интервалам, включая обе AUC.
