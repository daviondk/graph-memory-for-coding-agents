# Воспроизведение аудита

Все операции доступны на CPU. Используются Python 3.11+ и NumPy, контрольная среда указана в manifest.json. Скрипты читают локальные версии исследовательских артефактов, тексты траекторий и публичный корпус. Действия инструментов в корпусе обрабатываются как записи JSON. Все пути исходников задаются в inspect_inputs.py и unit_overlap.py относительно работы или каталогов D:/CodexResearch. Оригинальные серии остаются только для чтения.

В этой папке выполнить по порядку

```powershell
$pythonAudit = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $pythonAudit inspect_inputs.py
& $pythonAudit unit_overlap.py
& $pythonAudit audit.py
& $pythonAudit cross_check.py
& $pythonAudit verify.py
```

Первый этап читает исходные 8 JSONL сессий и проверяет их хеши, обрабатывает также сырые данные и метаданные вопросов. Второй этап читает реальные train/dev/test пулы PU. Для train он использует проекцию опорных узлов, для dev — графы и метки, для test — графы и точное пересечение исходных символьных интервалов. Для каждого вопроса проверяет число кандидатов через фактический размер train-матрицы или подписанного порядка. Для повторения численных сравнений при уже сохранённых fingerprints и масках достаточно audit.py и cross_check.py. Пересчёт проверяет исходные манифесты, размеры панелей, числа меток и контрольные суммы членства в каждой складке. Финальная проверка сверяет побайтовые SHA-256 всех файлов исследования.
