# Воспроизведение аварийного испытания

Для проверки поставленных результатов достаточно Python со стандартным модулем sqlite3 и доступа на чтение к подписанным operations-0…7 из соседнего каталога deferred_revocation. В данной папке выполнить `python verify.py`. Скрипт сверит манифест, пересчитает диапазоны чтения непосредственно из исходной серии, откроет поставленный внешний журнал в read-only режиме и проверит размер, целостность и хеш исходов. Журнал хранит локальные целочисленные адреса, номер операции и отметку барьера.

Для нового физического прогона создайте соседнюю рабочую копию каталога в пределах graph_memory_round35, чтобы сохранить подписанные результаты. В копии выполните команды последовательно

```powershell
python prepare.py
python run.py
python verify.py --seal
python verify.py
```

prepare.py сверяет SHA-256 восьми исходных файлов операций, фиксирует панель и расписание до открытия исходов и проверяет каждую запись опубликованного SQLite-журнала. При отсутствии source.sqlite3 строит его заново. run.py создаёт отдельный временный каталог на том же диске, формирует по две SQLite-базы на пару «история × точка сбоя» и запускает только свои процессы. Родитель требует код 73 от аварийного дочернего процесса и код 0 от восстановителя. PID обеих стадий записаны для контроля смены процесса и могут отличаться в повторе. Временные файлы баз удаляются после проверки, поставленный журнал и компактные реестры сохраняются. Источники приложения и команды из траекторий не исполняются. Хеш нового отчёта по случаям ожидаемо изменится из-за PID, при той же выборке должны воспроизвестись содержательные счётчики ошибок и событий.

Контракт внешнего источника задаёт неизменный порядок, стабильные номера, отсутствие пропусков, доступ к префиксу и возможность начать после долговечного барьера. Если исходная система сохраняет только прикладные сообщения, перед операциями replay требуется воспроизводимо восстановить из них те же изменения отношений. Время и дисковая стоимость этого преобразования здесь не измерялись. Для одновременных читателей потребуется согласование барьеров, а для нескольких писателей — собственный порядок и политика разрешения конфликтов.
