# Воспроизведение

Нужен подписанный соседний каталог deferred_revocation с восемью operations-*.json.gz. Сценарий использует только числовые идентификаторы пар, состояния и расписания; модель, GPU и сырые тексты не требуются.

```powershell
$experimentPython='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $experimentPython -X utf8 sensitivity.py
& $experimentPython -X utf8 verify.py
```

В per-trajectory.json.gz на каждую траекторию и расписание сохраняются порядок размеров удаляемых пакетов на всех чтениях (нулевые тоже), счётчики вставок, удалений, постановок и реактиваций, пик очереди и конечный остаток. Немедленное удаление задаёт общий знаменатель. Отдельный verify.py рассчитывает обязательное множество удаления по срезам входного потока заново, а для миниатюрных примеров перечисляет все допустимые физические действия. Контрольные суммы содержатся в manifest.json.
