# Отчёт. Сравнение бюджетной коррекции с нативными графовыми читателями

При двух общих инициализациях Dense-FT полное покрытие источников в пределах 2048 токенов достигнуто в среднем на **80,975% вопросов** с бюджетной коррекцией, обученной на всех 3894 train-вопросах. Полный residual R-GCN дал **78,425%**, независимо переобученная абляция без рёбер между соседними фрагментами — **79,075%**. Для каждой инициализации все три модели использовали один и тот же Dense-FT checkpoint, тот же набор 2000 вопросов и тот же бюджет. Средняя доля прочитанных эталонных символов при 2048 токенах составила 85,698%, 82,567% и 83,696% соответственно. В 4000 парах вопрос–seed OOF-3894 и полный R-GCN одновременно потеряли полное покрытие в 547 случаях. OOF-3894 улучшил 316 случаев и ухудшил 214. Для абляции соответствующие числа — 526 общих потерь, 311 улучшений и 235 ухудшений. Коэффициенты φ между индикаторами ошибок составили 0,593 и 0,574. Один и тот же вопрос присутствует в обеих инициализациях. [Таблицы сопряжённости](results.json)

Интервалы рассчитаны 20000 парными перевыборками 1207 траекторий, отдельно для каждого контроля. Перекрёстная оценка дополнительно перевыбирает две наблюдаемые инициализации; столь малое число seed ограничивает перенос вывода на новые модели. Доступны две из пяти запланированных пар исходных нативных моделей. Сравнение разведочное: тест уже использовался в исследовательской программе, а исходы каждого метода были известны до объединения. У нативных графовых моделей исходная процедура выбирает checkpoint по Recall@5 на 580 dev, бюджетная коррекция наследует заранее фиксированную λ=0,03 от R33. Итог охватывает и это различие процедур.
