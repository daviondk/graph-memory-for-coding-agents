# Воспроизведение

Числовые источники доступны в локальных каталогах на D. В исходном каталоге запустить:

```powershell
$experimentPython='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $experimentPython -X utf8 compare.py
& $experimentPython -X utf8 verify.py
```

Первый скрипт проверяет четыре набора хешей исходных нативных моделей, подтверждает совпадение всех идентификаторов и зарегистрированных количественных исходов с отдельно пересчитанным R34. Затем он вычисляет парные интервалы, таблицы пересечения ошибок и числа переключений. Второй читает исходные порядки и независимо вычисляет бюджетное покрытие через атомарные исходные интервалы для 12000 пар вопрос–порядок. Каждый ненулевой код возврата означает остановку проверки. Пофайловые SHA-256 содержатся в manifest.json.
