# Протокол парного сравнения с нативными графовыми читателями

Фиксируем до расчёта: основной показатель Full Support@2048, гипотеза направлена на увеличение по сравнению с каждым из двух заранее названных контролей — полным residual R-GCN и его абляцией без связей между соседними фрагментами. Публикуем оба сравнения и двусторонние интервалы. Модель-кандидат — строго OOF-3894 из подписанного R35. Сравниваем обе доступные общие инициализации 13 и 17, равные веса, все 2000 общих вопросов из 1207 траекторий. Вторичный показатель Coverage@2048. Сравниваем исторические представления моделей в одинаковом наборе кандидатов и бюджете. Выбор гиперпараметров, метрик, checkpoint и исключений по текущим попарным различиям отсутствует.

Считаем разности по вопросу и seed, wins/losses, кластерные перцентильные 95% интервалы по траекториям и перекрёстные интервалы с независимой перевыборкой двух seed, 20000 повторов. Дополнительно выводим двоичные таблицы пересечения ошибок и число выигрышей/потерь по каждой инициализации. Интервалы относятся по отдельности к каждому контролю. При двух seed перекрёстная оценка крайне чувствительна к текущим реализациям. Имеются лишь две из пяти запланированных нативных инициализаций. Тест и оценки каждого метода уже изучались, сравнение разведочное. Архивируем поштучные значения и подписываем используемые источники.
