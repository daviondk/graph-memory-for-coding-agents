# Воспроизведение и формат журнала

Этапы читают реальный исходный ISETrace как JSON. Из содержимого событий команды не запускаются. Локальный ранжировщик работает на CPU. Сначала запустить запечатывание исходных прогнозов, затем оценку и обе независимые проверки.

```powershell
$experimentPython='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $experimentPython -X utf8 replay.py
& $experimentPython -X utf8 analyze.py
& $experimentPython -X utf8 verify.py
& $experimentPython -X utf8 reappearance.py
```

Восемь файлов operations-0.json.gz … operations-7.json.gz содержат компактный журнал для всех 1207 естественных траекторий. Верхний уровень — словарь с идентификаторами траекторий, log — список записей в хронологическом порядке. Каждая запись содержит [номер исходного события с нуля, номер завершённой группы с единицы либо 0, список назначенных чтений из 25/50/75/100, список впервые активных/вновь активных ID пар, список отозванных ID пар]. ID целочисленные и локальны внутри траектории; одна и та же направленная пара сохраняет один ID. Журнал включает все изменения отношения, все границы групп и все назначенные чтения. События без этих эффектов пропущены. На одном событии изменения сначала применяются, потом рассматриваются все условия сброса, после них состояние читается. Отметка 100% означает закрытие последней группы инструментов. Журнал — числовой экстракт из исходного benchmark, в нём нет текстов вызовов и результатов.

states хранит по политике числа вставок, постановок в очередь, отмен очереди, реальных удалений, максимальный размер очереди в данной траектории и неочищенный конечный остаток. Поля drained_* — расчёт стоимости приведения конечного состояния к точному после последнего чтения. Для воспроизведения в табличной СУБД логический ключ строки образуют идентификатор траектории и ID пары. Непустая пачка удаления включает все ожидающие пары данной траектории в момент срабатывания условия. Служебные транзакции, включая вставки и чтение, счётчиком batches не измеряются.

orders-*.json.gz содержит строки [q, t, cut, dictionary], где значения dictionary — три упорядоченных списка индексов исходного Dense-порядка, прочитанных в пределах 512/1024/2048 токенов. Хеши всех журналов и порядков зафиксированы до вычисления результатов в forecast-seal.json. Проверить опубликованный набор можно последовательным пересчётом SHA-256 всех файлов из manifest.json.
