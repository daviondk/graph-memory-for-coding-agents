# Отчёт. Перенос бюджетной коррекции на другие инициализации Dense-FT

Расширенная графовая модель, обученная на 3894 вопросах при исключении своей траектории из линейных приоритетов, достигла **80,825% Full Support@2048** в среднем по четырём дополнительным Dense-FT seed. Прежняя коррекция R33 на 196 вопросах набрала **80,425%**. На той же выборке из 2000 вопросов обе интегральные оценки по бюджету улучшились при учёте неопределённости и по траекториям, и по инициализациям. По всем пяти ранее обученным реализациям итоговый Full Support составляет **80,89% против 80,46%**. [Первичный протокол переноса](PROTOCOL_RU.md) · [Результаты](results.json)

Для нового опыта зафиксированы только две завершённые модели. У расширенной модели λ=0,03, заморожены все четыре коэффициента; дообучения или выбора конфигурации по четырём новым инициализациям не проводилось. Для каждого seed используются его собственный плотный семантический порядок и прежний калибратор ранга, остальные признаки и правила идентичны в обоих вариантах. Результат seed 13 уже был известен перед запуском этого дополнения. Основной контраст переноса проводится на остальных четырёх. Число 3894 было заранее выбрано в первоначальном протоколе; 1024 дали 81,25% на одном test, поэтому смена основного варианта по этой цифре смешала бы отбор и оценку. ## Неопределённость

Разности и двусторонние 95% перцентильные интервалы ниже выражены в процентных пунктах. Использовано 10000 парных перевыборок. При фиксированных seed повторно выбираются 1207 траекторий со всеми их вопросами. При перекрёстном bootstrap дополнительно независимо выбираются seed с возвращением. Повторные результаты одного вопроса зависят друг от друга и сохраняются вместе. Интервалы вторичных метрик не скорректированы за множественные сравнения. Четыре дополнительные инициализации дают ограниченную оценку разброса для будущих seed. [Поштучные исходы](outcomes.json.gz) · [Вычисление](transfer.py)

На четырёх дополнительных инициализациях 73 пары вопрос–seed сменили неполное покрытие на полное и 41 пара — в обратном направлении. Средние по бюджетам показатели устойчивее точечной метрики при 2048. Одни и те же 2000 вопросов использовались в обеих сериях, поэтому дополнительная проверка оценивает перенос между реализациями энкодера внутри корпуса. Ранее полный и ротационный контроли структурного обучения на 3894 дали ровно те же исходы FS при seed 13. Отнести весь выявленный выигрыш к исключению своей траектории из базового обучения оснований нет.
