# Перенос после проверки seed 13

Эта дополнительная проверка сформулирована после получения результатов seed 13. На четырёх ранее обученных Dense-FT seed 17, 29, 37 и 41 переносим ровно две подписанные коррекции: исходную R33 и OOF на всех 3894 вопросах. Параметры, размер и регуляризация фиксированы; панель из 1024 намеренно не выбирается по тесту. Траектории и вопросы остаются прежними. Для каждого seed используются ранее зафиксированные семантический порядок и калибровка ранга. Оцениваем Full Support@2048, обе Budget-AUC, MRR и Coverage@2048. Главный переносной контраст — средняя по четырём новым seed разность. Публикуем оценки каждого seed, интервал по траекториям при фиксированных seed и перекрёстный bootstrap по траекториям и seed, 10000 повторов. Отдельно приводим среднее по всем пяти с включением уже исследованного seed 13.
