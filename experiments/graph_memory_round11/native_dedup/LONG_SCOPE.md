# Дополнительная симметричная проверка сохранения всей истории

Первичные результаты по окну 8 уже известны. Для интерпретации нативного преимущества без ограничения добавляем симметричную проверку. Используем те же журналы sqz и оригинальную реализацию R11 single/union с длиной окна в целую траекторию и видимыми буквальными строками, без восстановления из декодированных ссылок. Проверяем, что каждая выпущенная sqz ссылка ведёт к предыдущему показанному буквальному тексту того же файла. В качестве дополнительного ориентира приводим режим с полностью декодированными прошлыми ответами. Не меняем протокол основного сравнения.
