До получения каких-либо новых Git-исходов уточняем учёт оболочки. В опубликованной выдаче для grep может быть общая фраза о выполнении без вывода при отсутствии явного численного кода возврата. Считаем такие события отдельной дополнительной панелью. До 24 отдельных задач в этой панели отбираем тем же способом, что и в основной, независимо от будущего исхода. Для прозрачности фиксируем узкую интерпретацию простого, ограничивающего количество строк суффикса "| head" только в этой дополнительной панели. Дополнительный верхний предел для Git — суммарно 48 задач до дедупликации. Файлы анализируются в двух реальных деревьях. Если на базовом дереве литерал нашёлся или область запроса недоступна, событие выпадает по заранее объявленному фильтру внешней валидации. Основной анализ всё ещё требует явной диагностики соответствующего пути или однозначного exit-кода. Метрика будущего повторного упоминания оценивается с четвёртого последующего действия после фиксации политики по трём действиям.
