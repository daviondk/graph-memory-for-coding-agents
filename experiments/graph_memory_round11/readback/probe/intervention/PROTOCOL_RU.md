# Меняется ли ответ при изменении только сохранённой строки

Этот дополнительный контроль задан после первоначальных 40 сравнений. Фиксируем те же вопросы, индексы ответов, текущие сжатые наблюдения и модель. В истории изменяем буквальный текст только по запрошенному номеру на один из трёх других реальных ответов из того же вопроса. Альтернативу назначает зафиксированный хеш. Текущая строка передаётся ссылкой и сама не содержит этой литеральной записи. Это сознательная интервенция на истории, позволяющая проверить, действительно ли получатель следует предъявленному свидетельству. Каждый изменённый пример снабжаем явным машинным доказательством заменённых строк. Исходные случаи сохраняются.

Дополнительно удаляем старые выдержки при сохранении тех же ссылок и четырёх возможных ответов. Для одной и той же урезанной формы оцениваем попадания и в исходную, и в альтернативную истину. Порядок и ответные коды фиксируются до обращения к модели. Считаем долю целевых переключений среди всех 40 запросов, правильность без архива, число изменившихся ответов, точный парный результат. Исходный опыт имел высокий потолок точности и целенаправленно выбирал запросы со ссылкой. Интервенция проверяет использование свидетельства при чтении кода, а вероятность решений задач потребует отдельного исследования.
