# Two supplementary checks

These checks were specified after reading the primary QuixBugs scores and actual line-change size, so they are exploratory. For each of the 18 fixed old snapshots use tokenized executable-looking lines as an alternative diff, retaining indentation depth, literal and token content. Exclude comments, formatting and standalone string expressions, including long explanatory strings present in the original distribution. Diff the sequences of line token signatures, map modifications and deletion back to the original old file coordinate, map a pure insertion to the two flanking old lines. Score every archived payload at every capacity and salt, comparing with exact coverage for this new query, occurrence counts and real change recall. Parsing and diffing use no test statuses.

Separately, to interpret what a full-graph control means in the symbol-setting of R10, inspect only its 36 fixed old graphs. Serialize fully qualified UTF-8 names plus their exact nonzero test masks using (i) plain length-prefix entries, or (ii) sorted prefix-length/suffix-length entries; pay for every unique key and literal mask. For each encoding try no general-purpose compression, zlib level 9 or LZMA-alone preset 6, including format/header bytes. Select shortest based solely on old graph; reconstruct exact equality before accepting byte counts. Report cheapest observed bytes per test and fraction fitting each R10 budget. This is a reproducible upper bound for exact storage, not an information-theoretic lower bound. No future SymPy queries are used.
