# Общий план экспериментального отчёта

Зафиксирован после проверки транспорта на единственном сообщении {"ready":true}, до просмотра исследовательских результатов. Дата и SHA-256 сохраняются отдельно. Это локальная фиксация, не публичная пререгистрация. Выбраны три направления из предшествующего обзора: у каждого есть исполняемый критерий и контроль с равным доступом к данным. Итог охватывает все условия и завершённые/ошибочные вызовы каждого стенда.

1. Локализация объявления. 12 парных трёхусловных блоков с реальными модулями CPython в искусственном размещении. Главный контраст — нормализованные ограничения против сырой равноинформативной телеметрии при одном вызове поиска. Случайный порядок; отдельная сессия на вариант. Никакой будущей цели в построителе представления, кроме исходного поискового запроса задачи. Цены — длина переданного опыта, реальные токены, задержка, вывод поиска. Дополнительный контроль — краткая запись. Интервал при совпадающих бинарных исходах не интерпретировать как доказательство эквивалентности.
2. Перенос проверочного примера. Шесть семейств API, стабильная и изменённая версии, три варианта доступа к предыдущему опыту. Главный контраст — ранее сохранённый различающий пример против проверки, составленной непосредственно в новой среде. Один экспериментальный вызов целевого инструмента. Основное качество и unit задаёт зафиксированный протокол стенда. Учёт зависимостей внутри семейства и общего пакета вопросов. Сохранять промпты всех стадий включая наблюдения.
3. Совместная цена чтения. На одних и тех же тестовых запросах измерить успех при ограничении чтений, фактические чтения, ресурсы политики записи. Тесты на групповых и отдельных источниках, сильный блочный контроль. Инференс только по независимо сгенерированным мирам.
4. Дополнительная наблюдательная проверка. На том же зафиксированном снимке VibeMemBench, который использовался для предыдущей карты, исключить целиком восемь ранее рассмотренных проектов. Из оставшихся Python-репозиториев с минимум четырьмя историями выбрать 12 проектов по порядку SHA-256 от seed + пути и 4 истории из каждого тем же правилом. Все 48 входят в знаменатель, доступность и исключения указать. Seed scope-field/20261116/v1. Главный показатель — доля историй с успешно распознанной простой командой текстового поиска, у которой явно ограничена выдача числом результатов (head, grep/rg --max-count). Вторичные — точные повторы команд в рамках истории, доля историй с любым распознанным поиском, результаты по проектам. Наличие лимита не доказывает фактического обрезания или пользу нового интерфейса. Исключаем цепочки shell и прочие неподдержанные формы. Считаем команды только с соответствующим ответом инструмента. Ручной аудит положительных и отрицательных примеров допустим без исправления исходного детектора задним числом.
5. Фиксированные объёмы пилотов, без расширения по промежуточному знаку эффекта. У каждого сравнения свои отметки времени и хеши. Выделять подтверждённый перенос, результат только в симуляторе, оценочную неопределённость и наблюдение в реальных данных. Не складывать виртуальные и реальные действия в общий процент. Анализы подгрупп и дополнительные интерпретации помечать. Для внешней достоверности важнее размер эффекта и условия, чем формальный порог p. Никакого совместного заявления о значимости по семейству всех трёх экспериментов.
