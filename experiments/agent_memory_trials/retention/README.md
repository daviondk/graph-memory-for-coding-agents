# Повторение опыта

Воспроизведено в CPython 3.14.4 x64 для Windows. Достаточно стандартной библиотеки. Выполнить из этого каталога, используя обычный режим Python с включёнными assert.

```sh
python -B verify.py
```

Эта команда проверяет SHA-256 исходного протокола и обоих исполняемых модулей, повторяет симуляцию и оценку во временном каталоге, сверяет контрольные суммы шести сохранённых результатов и независимо восстанавливает каждую операцию из журнала. Контроль gzip использует mtime=0 и фиксированные заголовки. При другой версии реализации deflate сжатый файл может отличаться при одинаковом содержимом.

Для получения отдельной копии в новом каталоге выполнить последовательно:

```sh
python -B experiment.py replay
python -B analyze.py replay
```

## Содержимое

- `protocol.md`, `frozen.json`, `experiment.py`, `analyze.py` — фиксация до измерения, полное описание мира, реализация политик, расчёты и все семена.
- `results/jobs.csv.gz` — каждое задание fit, validation и test с ключами в наблюдавшемся порядке. Поля phase и stream определяют независимый поток. Dataset во всех записях один, synthetic_rank_lookup_v1. Идентификатор наблюдения — seed, rho, phase, step. Шаги нумеруются с нуля.
- `results/builds.json` — снимки мира (включая все 32 точных значения), распределения генератора, маски пяти кэшей, выбор по validation, число записей и число чтений начального полного снимка. Таблица значений нужна для аудита, алгоритм ранжирования получает историю ключей и открытую карту источников.
- `results/steps.csv.gz` — каждое выполнение тестового задания каждой политикой. Поля seed, rho, tool и policy задают прогон. Поле step соответствует test/step в jobs. В actions перечислены реально прочитанные источники или поля в фактическом порядке. В returned_mask перечислены все возвращённые поля, включая незапрошенные. В answer_mask перечислены подтверждённые ключи ответа. required_reads — цена полностью подтвердить ответ, actual_reads — фактические вызовы при лимите, correct — точное совпадение всех значений. Восстановить значения ответа можно по answer_mask и snapshot_uint32 того же мира.
- `results/worlds.csv`, `results/summary.json`, `results/examples.json` — сводка по каждому миру, статистика всех заранее заданных сравнений и три воспроизводимые пары трасс. Коды rho 0, 50, 100 выражают проценты. Направление контрастов в summary положительно при экономии расходов или росте точности у joint. Поля wins в разделе estimates считают число миров с положительной величиной показателя, смысл выигрышей по сравнению с соперником они имеют только в разделе contrasts.
- `REPORT.md` — результаты и интерпретация. `verify.py` написан после прогона как независимая проверка.

Маски кодируются восемью шестнадцатеричными цифрами, младший бит соответствует полю 0. Источник поля k вычисляется как целая часть k/4, роль — остаток k%4. Передача и память учитываются логическими единицами, указанными в протоколе.
