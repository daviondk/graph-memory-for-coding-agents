# Эксперименты с памятью агентов

Word-отчёт представляет все исследованные условия. Этот архив дополнительно хранит входы и независимые журналы, из которых получены все числа. Копия архива входит в DOCX в word/embeddings/experiment-records.zip и доступна без интернета.

## Каталоги

- search: 12 модулей CPython, план, 36 запросов к первой модели, ответы, выбранные команды ripgrep и оценка.
- search_replication: те же промпты для второй модели, самостоятельная фиксация, транспортная проверка, 36 ответов и оценки. Копии исходных материалов сохранены для неизменности протокола.
- probe: шесть искусственных семейств API, исходные наблюдения, скрытые режимы, две стадии действительной работы модели, исполнимые инструменты и ответы по всем четырём тестовым входам.
- probe_real: три Python-библиотеки, манифест PyPI с SHA-256, точные wheel-файлы, лицензии внутри дистрибутивов, журнал вызовов закреплённых версий и проверка всех результатов. Активный Python на компьютере пользователя не модифицировался.
- retention: генератор миров, политики, все тестовые решения и промежуточные маски (steps.csv.gz), задания и семена, сводные таблицы и независимая проверка. Миллионы токенов LLM для этой части не требуются.
- field: снимок выборки, исходные общедоступные URL и хеши, все распознанные команды, независимая перепроверка и разбор подтверждённого обрезания. Полные исходные файлы загружаются из указанного снимка VibeMemBench.
- shared: общий интерфейс Codex CLI и независимая проверка итогов. calibration: отдельная нейтральная проверка транспорта. Префикс промпта, итоговый промпт и его хеш, выбранный модельный псевдоним, время UTC, события, usage и выводы хранятся рядом с каждым запуском модели.

## Восстановление результатов

Распакуйте архив с сохранением каталогов. Для быстрой независимой проверки обоих поисковых запусков, синтетического опыта с API, полевых данных и всех 245 760 строк симулятора:

    python -X utf8 shared/verify_package.py

Для самостоятельного воспроизведения оценок на сохранённых ответах используйте README и протоколы соответствующих каталогов. Например:

    python -X utf8 search/score.py
    python -X utf8 search_replication/replicate.py score
    python -X utf8 probe/study.py score
    python -X utf8 probe_real/study_real.py audit
    python -X utf8 retention/verify.py

Полный повтор с новыми решениями модели требует действующей авторизации Codex CLI, подходящей модели и отдельного выходного каталога. Уже сохранённые ответы переиспользуются, если их промпты идентичны. Для точного воспроизведения локальных команд использовались Windows, Python 3.14.4 и ripgrep 15.2. Генератор удержания и агрегирование используют стандартную библиотеку Python. Полевое получение данных требует requests и соединения с Hugging Face. Протоколы поясняют дополнительные зависимости и ограничения своих стендов.

MANIFEST.sha256 содержит SHA-256 каждого файла поставки, кроме самого списка. Временные файлы интерпретатора не входят в архив. Источники расходов — счётчики ответов сервера. Записаны наблюдаемые промпты, ответы и действия; внутренние рассуждения модели недоступны.
