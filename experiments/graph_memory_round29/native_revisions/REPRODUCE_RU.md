# Воспроизведение

В Python 3 с NumPy выполнить последовательно `python fetch.py`, `python prepare.py`, `python route.py`, `python score.py`. Первый скрипт загружает на диск D исходные данные, прогнозы и исходный файл оценщика из конкретной ревизии AllenAI. Для каждого файла вычисляется SHA-256, сверяемый с поставляемым sources.json. Второй готовит отдельный слепой файл и только обучающие целевые значения. Третий фиксирует ранжирование до оценки, записывает признаки нормировки и коэффициенты. Последний сверяет отдельные метрики с авторской функцией и полностью повторяет официальные агрегаты. Оценка интервалов использует 20 000 перерисовок компонент, начальное состояние генератора фиксировано. Основной режим — 171 обновление. Содержимое corpus в репозитории отсутствует, в outcomes сохранены исходы каждого метода, в routes — порядок обновления.
