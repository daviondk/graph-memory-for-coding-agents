# Точный выбор цитаты после нескольких отзывов

Работа продолжает исследование R28 на фиксированных числовых выходах читателя. Разрешены только ответы, целиком лежащие в одном компоненте дополнения к объединению запрещённых непустых физических интервалов. Если внутри span T есть более высокоранговый span S, каждый набор отзывов, при котором T допустим, также допускает S. T можно удалить из физического индекса. Это даёт один независимый от конкретного запрета набор недоминируемых ответов, содержащий координаты, float32-score и исходный порядковый номер. Для этого достаточно двумерного запроса по началу и концу и строгого порядка по score/tie. Второй механизм — Fenwick range maximum по концам, в каждой канонической ячейке хранить только смены победителя при уменьшении допустимого начала. Для каждого разрешённого компонента [A,B) извлекается максимум с start≥A, end≤B; из максимумов компонентов выбирается один.

До просмотра результатов фиксируем те же 96 вопросов. События — отзыв 2, 4, 8 разных неперекрывающихся физических записей из исходно видимых наблюдений. Соприкасающиеся границы допустимы и объединяются. Если нужной мощности нет, берём достижимый максимум и отдельно считаем случаи недобора. Независимая последовательность использует фиксированный SHA-порядок уникальных интервалов; выбор допускается только если оставшихся независимых интервалов достаточно для достижения цели. Направленная последовательность запрашивает среди ещё доступных записей ту, которая содержит наилучший из ещё отзываемых span по исходному score/tie. Это намеренно трудный сценарий с использованием прошлых выходов модели и без обращения к эталону ответа. В обоих сценариях добавляем полную запись и сохраняем финальный список до исследования лагов или экономии.

Контроли — исходный полный индекс SQLite в физическом порядке score DESC и ord, компактный индекс только недоминируемых кандидатов в том же порядке, двумерный индекс, top-64 с точным fallback по исходным логитам и отбором окон по локальной верхней границе. Две первые SQL-схемы выбирают первого кандидата, целиком вне объединения запретов. У каждой из трёх специализированных структур есть свой независимый файл с полными полезными полями. Сверяем строгий бинарный результат с независимым исчерпывающим NumPy-перебором во всех 576 запросах. Дополнительно проверим крайние случаи (всё закрыто, ничего закрыто, остаётся короткий внутренний промежуток). Основной предмет измерения — число хранимых физических строк и байтов, совпадение ответов, количество просмотренных элементов и прочитанные BLOB. На прежней панели 16 статей × 2 вопроса — 6 нагрузок, 15 повторов в чередующемся порядке в общей read transaction. Для времени показываем p50/p95 по индивидуальным медианам и 95% кластерный интервал по статье. Повторные события и технические тайминги внутри одного вопроса не образуют независимых научных наблюдений. Ключевой сравнительный контроль — полный индекс и top-64+граница. Отдельно оцениваем разницу между 2D-доступом и обычным сканированием компактного порядка. Факторизованные логиты и модель оплачиваются явно лишь в схемах, которые действительно содержат их.
