# Какие выводы допускают опубликованные тесты

В STALE Chao и соавт. оценивают 400 сценариев по трём вопросам. T1 обновляет один атрибут пользователя, T2 требует распространить обновление на связанное состояние. Авторы измеряют распознавание устаревшего состояния (SR), сопротивление старой предпосылке (PR) и применение обновления в предложенном действии (IPA). Результаты различаются по этим измерениям. Например, на T1 авторский Qwen3.5-27B получает 76% по SR и 4% по PR. CUPMem на базе GPT-4o-mini достигает общего 68,0% в авторском протоколе. Сравнение с этим числом требует исходного набора из 400 случаев, одинакового вопроса, ридера, служебного промпта, разрешённого объёма истории и оценщика. Здесь используется другой локальный ридер и строго ограниченная передача обычных текстовых фрагментов. [Эксперимент и таблица 2](https://arxiv.org/html/2605.06527v1#S4) · [Устройство CUPMem](https://arxiv.org/html/2605.06527v1#A6)

Граф в R29 — локальная направленная связь только при запросе. В пределах небольшого пула первичная сессия получает возможную следующую сессию по времени, тематической близости и релевантности. В CUPMem при записи поддерживается семантический статус состояния, обнаруживаются изменения и в момент чтения вводятся ограничения по их статусу. Совпадает практический вопрос о применении изменившегося факта. Наш контролируемый компонент проверяет добавочную ценность связи между двумя уже найденными отрывками при одинаковой стоимости их передачи. [Описание консолидации и чтения CUPMem](https://arxiv.org/html/2605.06527v1#S5)

В работе Zhang и соавт. версии v2 измерены отдельные этапы доступности двух конфликтующих фактов при делегировании на 11 задачах Harvey LAB. У обязательного делегирования 68,7% пар встречаются в чтениях участников, 24,4% сохраняются в доказательствах у координатора, 13,2% конфликтов обнаружены. Для STALE у нас другой объект — изменение состояния во времени. Отдельно измерены допустимость двух исходных сессий в пуле, передача их адресов, буквальное присутствие утверждений в доставленном тексте и конечный ответ одного ридера. Это позволяет проверять механизм потерь доказательств между этапами в другой задаче. Для причинного вывода о делегировании понадобятся независимые агентские контексты и сравнение политики передачи. [Zhang и соавт., §3–4](https://arxiv.org/html/2611.22245v2)
