# Перенос правила обновления между читателями

На 514 отложенных вопросах ROPES из 55 групп в native_revisions проверяем перенос правила обучения с авторского RoBERTa на DistilBERT, обученный на SQuAD. Из результатов на старом читателе уже известен эффект расширенных признаков +1,52 п.п. над базовой регрессией с широким интервалом. Гипотеза для нового читателя состоит в том, что те же веса помогают выбирать полезные повторные вычисления при изменении источника. Ни коэффициенты, ни квоты не подбираются по новому читателю. Повторное использование тех же вопросов делает это проверкой переноса между моделями.

На CPU рассчитываем исходные и пересмотренные ответы DistilBERT для всех контрольных вопросов. Вход состоит из вопроса и одним потоком из трёх явно адресованных наблюдений в порядке «ситуация, фоновый абзац, копия вопроса». Последнее позволяет выбирать сущности, приведённые только в вопросе ROPES. Правило определения разрешённых span и длина окна совпадают с R28, не допускается пересечение границы двух наблюдений. Одни и те же реальные наблюдения получают все режимы. Сравниваем исходный ответ, полный пересчёт, случайное обновление, размер правки, исчезновение старого ответа, простые и расширенные веса опубликованного читателя. Первичный контраст — расширенная против базовой регрессии при 171 повторном чтении. Метрики — официальный F1, EM, правильность в обеих версиях, число новых окон и их длина при одинаковой квоте. По выбору следим за любым уменьшением F1 после пересчёта, сравниваем распределение модели и класс вопроса. Источник нового читателя — [DistilBERT для SQuAD](https://huggingface.co/distilbert/distilbert-base-cased-distilled-squad).
