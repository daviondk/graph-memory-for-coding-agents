# Воспроизведение

Из папки rollback_native выполнить подготовку исходной авторской ревизии, штатного no_repair и контрольных метрик по REPRODUCE_RU.md. Затем из текущей папки запустить скрипт run.ps1. Задействован CPU, sklearn 1.8.0, numpy, стандартный sqlite3 и фиксированные локальные библиотеки официального evaluator. Перед первым созданием проекций используется свободная папка D:/CodexResearch/x20-r29-selective. Повторный запуск проверяет содержимое существующих SQLite-наложений. Исторические исходники не изменяются.

Прогнозы контролируемых и адаптированных задач хешируются до запуска оценивания. Для нового способа или настройки порога нужно новое испытание. Проверка verify.py отдельно повторяет маскирование всех ID, рассчитывает прогноз по сохранённым стандартизации и коэффициентам, сверяет TP/FP/FN с авторским определением, восстанавливает парные bootstrap для всех десяти сравнений с основным методом и проверяет статистику позиции. Полные признаки и именованные ключи отображения сохраняются локально на D. Публичные сжатые прогнозы содержат непрозрачные ID и атрибуты отзыва. Для таблиц использовать controlled-results.json и adapted-results.json. CI фиксируют данные и обученные модели. При выводе на новые шаблоны обучения потребуется отдельная оценка.
