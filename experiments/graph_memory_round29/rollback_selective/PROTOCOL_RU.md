# Выборочный отзыв утверждений с учётом путей к ответу

Этот эксперимент проверяет, какие уже записанные утверждения логично перепроверить после сообщения о недействительном источнике. Графом служит фактически сохранённая неисправная траектория авторского Memory Rollback. Входной сигнал — официально выданные faulty_memory_ids. Тексты рассматриваются как инертные данные. Задачи и их команды не исполняются.

## Фиксация до получения новых результатов

Предыдущие суммарные результаты direct и reach на тех же 150+50 случаях известны. При проектировании проверили схему одной faulty-трассы двух панелей и фрагменты естественного текста без ответов evaluator. Новые правила и модели заморожены до вычисления их исходов. Три домена controlled образуют три внешние складки: каждый домен исключён из оценивания параметров и порога для собственной складки. Адаптированная панель из 50 задач — перенос одного решения, обученного только на трёх controlled доменах. Новые параметры по adapted отсутствуют. Целиком нетронутого benchmark не было, сравнение exploratory. При возможных общих шаблонах трёх генераторов даже исключение домена не гарантирует переноса вне этой задачи.

## Операторы и контроли

Носитель кандидатов — достижимые от отозванного источника claim через used_ids, generated_memory_ids и derived_from. Находится также обратное множество предков последнего наблюдаемого шага final_answer по тем же зависимостям. Сохранённый **неисправный** ответ известен постановке. Используются тип и позиция шага, текст final_answer в признаках не используется. Последний ответ служит приближением актуального потребителя памяти. Промежуточные затронутые утверждения также входят в gold.

- Базовые правила: все достижимые, только непосредственные, последний достижимый по порядку трассы, пересечение достижимости и предков последнего final_answer. Дополнительный гибрид принимает также любое непосредственное цитирование faulty memory.
- Основной метод — объяснимая логистическая регрессия на достижимых claim с признаками близости к источнику и последнему потребителю, прямого цитирования, порядка/размера множества кандидатов, числа входящих ссылок, относительного сходства текста claim с отвергнутыми и сохранными источниками. Дискретная позиция от конца ограничена, чтобы убрать влияние масштаба. Лексическая мера — косинус между множествами токенов claim и memory с IDF только текущей задачи. Без текстового эмбеддера, доменной лексики, параметров LLM. Индекс, task/domain и исходные строковые значения ID не являются признаками.
- Сильные обучаемые контроли на той же выборке: только позиция, только граф без позиции/лексики, только текст, граф + позиция без текста. Фиксированная L2 logistic C=1, liblinear, сбалансированные веса положительных и отрицательных, стандартизация только на train. Порог выбирается по pooled micro-F1 на полных out-of-domain предсказаниях внутренних train-доменов, сетка 0.05, 0.10, …, 0.95. При равенстве — ближе к 0.5, далее больший порог. Модель переобучается на всех доступных ей train-доменах с зафиксированным порогом. Для исключённых controlled доменов внутренних обучающих доменов всего два, поэтому выбор порога нестабилен.
- Дополнительный контроль проверки уникальности пути: ранжировать по логиту основного метода и брать один последний по позиции при точном равенстве максимума на задачу с достижимыми. Альтернативный вывод по памяти — отозвать source плюс только те достижимые промежуточные memory, которые лежат на пути к выбранному claim. Проверяются также память у стандартных reach (все) и direct (только source).
- Вход ограничен диагностикой, исходным порядком, типом, ссылками и content обычных claim и memory в faulty trace. Скрытые oracle_role, fault_type, fact_key/value, статус и clean trace, истинные действия и метки не подаются. Названия инструментов и аргументы не используются. Уникальные ID маскируются до извлечения признаков. Основная задача отзыва issue-independent, text features не используют принадлежность к группе и искусственные идентификаторы узлов. Ответы и метрики оцениваются только после фиксации прогнозов каждой панели. Обучение видит gold только выбранных train-панелей.

## Показатели и альтернативные объяснения

Основной показатель — официальный агрегированный micro-F1 по affected claims, отдельно на объединённых out-of-domain прогнозах controlled и при переносе на adapted. Сравнение относится к точной инвалидизации claim и не измеряет новое сквозное восстановление ответа. 10 000 парных bootstrap по задачам, стратифицированных по доменам, с повторным подсчётом отношения. Отдельно mean определённых официальных per-case F1 и его знаменатель, zero convention (если 0/0, присвоить 0) и альтернативное exact-empty=1, общие TP/FP/FN, precision/recall, категории ошибок только при оценке, диагностированные источники, derived и benign. Основные парные сравнения с direct, reach и самым сильным учётом позиции. Все исследовательские сравнения выводятся без поправки, CI описательные. Успех на одном корпусе или выигрыш за счёт последнего шага сам по себе не подтверждает универсальный метод графовой памяти. Будут сохранены слепые проекции, прогнозы с контрольными суммами, train/held-out ledger, коэффициенты, индивидуальные исходы и ограничения.
