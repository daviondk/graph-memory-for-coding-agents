# Проверка сопоставимости

В этом каталоге `python -B verify.py` повторяет парные расчёты на имеющихся полных seed. Нужны Python и NumPy. Каждый файл `outcomes-<seed>.json.gz` задаёт отображение ID запроса в массив из четырёх элементов: ID полной траектории, вектор из шести метрик кандидата, вектор полного R-GCN и вектор заново обученной абляции без смежности фрагментов. Порядок метрик задаёт `audit-<seed>.json`. Вывод содержит прирост в долях единицы. В отчётах проценты и изменения переведены в процентные пункты.

В полном рабочем дереве команда `python -B publish.py` при появлении новых графовых прогнозов сверяет источники, перезапускает нативное измерение каждого из трёх полных порядков, считает интервалы и создаёт отчёт с количеством завершённых seed. Параметр `--watch` запускает ту же процедуру при готовности очередной полной пары моделей. Для повторного первичного считывания исходных рангов используйте чистую рабочую копию с доступными R18/R19/R21/R22/R33 и исходным окружением ISETrace. Архивные копии отдельных ранних серий могли содержать только завершённую к тому моменту часть таблиц. Автономная проверка готовых индивидуальных исходов использует включённые в этот каталог данные и не требует GPU. [Протокол выбора](PROTOCOL_RU.md)
