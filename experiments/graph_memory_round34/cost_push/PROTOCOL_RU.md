# Обратная постановка TopPush как сильный контроль

Формула (4) статьи TopPush усредняет по положительным объектам выпуклый штраф за преимущество самого сильного отрицательного. После обмена классов и изменения знака оценки формула сравнивает каждый отвлекающий фрагмент с самым слабым положительным. Это прямой аналог нашей постановки. Сравниваем с этим вариантом до заявления о новизне. [Li, Jin, Zhou](https://arxiv.org/pdf/1410.1462) · [Первичная оценка R33](../../graph_memory_round33/budget_loss/REPORT_RU.md)

Для общего замороженного графового приоритета R33, четырёх одинаково нормализованных признаков и тех же 196 train-вопросов считаем факторный контроль. Точный минимум по положительным, одинаковые либо токенные веса отвлекающих, две опубликованные в TopPush формы штрафа — квадрат положительной части с единичным отступом и логистическая. Четыре семейства, в каждом L2 0,03 или 0,3 согласно R33. Выбор одного L2 для каждого семейства — по FullSupport@2048 на dev580, затем Coverage@2048, затем больший L2. Новые тестовые прогнозы подписываем до сопоставления с золотыми интервалами. Передаём тот же обученный seed13 Dense-FT и исходные пулы. Порядки для четырёх вариантов выбираются независимо. Основное сравнение — R33 с весами и мягким минимумом против обратной постановки TopPush с равными весами, усечённым квадратичным штрафом и жёстким минимумом. Вторичные сравнения отделяют веса от сглаживания и от формы штрафа. Это перенос математической цели в многозапросное ранжирование с фиксированным исходным баллом и равным весом каждого вопроса. Исходный оптимизатор статьи не является частью сравнения.

Для численного решения каждый несглаженный выпуклый функционал минимизируем через последовательность нормализованных мягких минимумов с уменьшением температуры до 0,000002. Для λ-сильно выпуклого сглаженного риска F нижняя граница минимума несглаженного риска равна или выше F(w)−||∇F(w)||²/(2λ). Значение несглаженного риска в текущей точке даёт верхнюю границу. Для каждой из восьми задач требуется разрыв не более 0,0001. При превышении уменьшаем температуру и уточняем оптимум до оценки теста. Сохраняем нижнюю и верхнюю границы, веса и перестановки. Интервалы парные по 1 207 траекториям. Основная метрика на известном тесте раньше уже измерялась для R33, поэтому это проверка конкурирующего объяснения.
