# Какие части метода уже известны в информационном поиске

Это целевая проверка ближайших аналогов функции потерь. Нас интересуют обучение по самому трудному положительному примеру, затраты до последнего нужного фрагмента и извлечение свидетельств из исполнения агента. Источники отобраны по соответствию математической постановке. Поиск по «Top Rank Optimization in Linear Time», «p-norm push», «last relevant item total search length» и «cost-sensitive learning to rank» выполнен в академическом и открытом веб-поиске. Дополнительный журнал сохраняет до пяти записей Crossref и OpenAlex по трём запросам. Одна выдача Crossref ограничена сервером HTTP 429; текст статьи прочитан на arXiv и найден в материалах NeurIPS. Это узкая проверка; уникальность метода в полном корпусе работ она не устанавливает. [Журнал](bibliographic-search.json)

Подтверждаемая формулировка вклада — экономная модель ранжирования и обслуживания графовой памяти с экспериментально отделёнными эффектами структуры и стоимости. Смысл крайнего ранга, токенный бюджет в памяти агента и защита нескольких первых кандидатов имеют предшественников. В частности, на этих данных не удалось установить преимущество нормализованного мягкого минимума над жёстким при одинаковых токенных весах. [Проверка на общем тесте](REPORT_RU.md)
