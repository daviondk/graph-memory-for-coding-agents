# Воспроизведение

Подготовьте [базовые входы R33](../../graph_memory_round33/budget_loss/REPRODUCE_RU.md) и выполните из этого каталога `python -B control.py`, затем `python -B audit.py`. Воспроизведение требует NumPy, SciPy, исходного оценщика ISETrace и числовых проекций R33. На каждой конфигурации проверяются начальный градиент, проверяемый разрыв оптимизации и контрольная сумма источника. Библиографический поиск отдельно запускается командой `python literature.py`; удалённая выдача и ограничения скорости меняются. [Зафиксированный журнал](bibliographic-search.json)
