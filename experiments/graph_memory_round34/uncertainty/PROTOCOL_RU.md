# Неопределённость при пяти обучениях Dense-FT на одних траекториях

Анализируем опубликованные пообъектные прогнозы. Основная величина — доля полностью покрытых источников при 2 048 токенах, усреднённая равномерно по вопросам и затем по пяти фиксированным seed. Для анализа чувствительности независимо перевыбираем с возвращением целые траектории (все вопросы вместе) и пять seed (один и тот же набор для каждой траектории итерации). Это двухфакторный bootstrap повторно наблюдаемой прямоугольной таблицы. Публикуем обе оценки рядом, исключение каждого seed и каждой траектории. Процентильные интервалы с пятью наблюдаемыми инициализациями приблизительны, и не показывают вариативность по новым семействам моделей или репозиториям.

Помимо заранее известных точек при 2 048 пересчитываем кривые покрытия при шести официальных бюджетах и обе официальные AUC. Для разностей в шести бюджетах приводим одновременно скорректированные полосы: в каждом повторе берём максимум абсолютного стандартизованного отклонения от наблюдаемого эффекта по шести бюджетам внутри одной метрики и одного сравнения. Это анализ чувствительности имеющегося эксперимента. Новый подбор ранжировщиков не проводится.
