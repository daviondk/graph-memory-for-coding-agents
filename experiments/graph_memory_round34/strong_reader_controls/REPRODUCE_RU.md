# Воспроизведение

В поставке уже есть вычисленные нативные кривые по вопросам и два явно помеченных гипотетических сопоставления. Для автономной проверки контрольных сумм и пересчёта средних достаточно локального Python и стандартной библиотеки. Из рабочей папки запустите `python verify.py`.

Полный пересчёт использует прежнюю структуру каталогов D и официальный код оценки. Нужны кэши графовых кандидатов, модельные ранги R33, фиксированный seed 13 R22 и метаданные ISETrace. Локальные исходные ID и хеши фиксируются в bounds.json и auc.json. При пересчёте сохраняйте соседние папки, поскольку пути в исследовательских зависимостях указывают на общий архив. Скрипты предназначены для CPU и читают готовые численные ранги; никакие команды из траекторий не выполняются.

```powershell
Set-Location 'D:/CodexResearch/x20-bench-workspace/work/graph_memory_round34/strong_reader_controls'
$py = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $py bounds.py
& $py auc.py
python verify.py
```

В файле discovery.json сохранён снимок библиографических API. Для обновления поисковой части можно запустить `python -X utf8 sources.py` в копии папки с установленными requests и beautifulsoup4. Свежие серверные ответы и хеши могут измениться. Воспроизведение математического эксперимента на исходных таблицах использует уже вложенный снимок discovery.json.

witnesses.json.gz — словарь по ID вопроса, с полями траектория, тип, наши бинарные исходы для пяти seed и два искусственных пятимерных вектора. Значения у искусственных конкурентов демонстрируют неидентифицируемость интервала; они пригодны только для этой цели. Для нативных политик оцениваются реальные ранги. В восьми auc-outcomes-*.json.gz хранится сначала Coverage Budget-AUC, затем Full Support Budget-AUC, шесть Coverage, шесть FS по возрастанию бюджета. В auc.json средние умножены на 100, интервалы относятся к разности средних в процентных пунктах.
