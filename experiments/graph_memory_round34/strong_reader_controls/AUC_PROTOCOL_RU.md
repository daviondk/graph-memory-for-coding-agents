# Проверка двух нативных Budget-AUC

После чтения §3.2 и §8.3 v3 фиксируем отдельные показатели Coverage Budget-AUC и Full Support Budget-AUC по шести бюджетам 256, 512, 1024, 2048, 4096, 8192. По каждому вопросу используем строгое целочисленное заполнение префикса и нормированную площадь трапеций по log₂B из штатного кода. Сравниваем существующие порядки global_role, cost_worst и вариант с двумя закреплёнными узлами без подбора параметров на этой метрике. На пяти seed основные две разности — cost_worst минус global_role и два узла минус cost_worst по обеим площадям. Дополнительно сравним cost_worst с локальными full R-GCN и без смежности на полностью готовом seed 13. Все вопросы должны совпасть по ID. Проверяем на каждом общее FS@2048 с уже сохранёнными исходами. Интервалы ресэмплируют траектории после усреднения по seed, 10 000 раз, seed 13. Результаты для других бюджетов и типовых групп приводятся как описательные.
