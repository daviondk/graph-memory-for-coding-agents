# Что можно заключить при наличии только опубликованных средних

Объект сравнения — замороженный cost_worst, сильнейшая опубликованная строка ISETrace для Full Support@2048 и общий пул 2 000 вопросов, 1 207 траекторий и пяти seed. До расчёта восстанавливаем для каждого типа целочисленное число успехов по среднему и допустимые векторы числа успехов по пяти seed по выборочному SD. Учитываем округление в таблице 3 v3. Строго разделяем точечную разность средних (она идентифицируема) и разброс парных разностей (он зависит от неизвестного пересечения успехов).

Для каждого типа и seed при известных размерах и маргиналах строим максимальное и минимальное пересечение двух бинарных векторов. Оптимизируем по всем целочисленным векторам, согласованным с таблицей. Строим два явных гипотетических конкурента, сохраняющих опубликованные типовые средние и SD. Выбираем общую детерминированную очередность вопросов внутри типа, чтобы показать допустимое совпадение разногласий между seed. Считаем 10 000 бутстрэп-повторов по траекториям после усреднения по seed. Эти интервалы служат примерами допустимых завершений, они не являются оценкой для реального неопубликованного конкурента или строгими верхней и нижней границами самого интервала.

В качестве проверки используем локальную нативную пару на seed 13: точно сопоставляем полный результат и результат без смежности с нашим решателем, затем скрываем поштучную разметку конкурента и повторяем расчёт пределов пересечения с его фактически известными маргиналами. Новые правила извлечения и оценка их качества по этому анализу не выбираются.
