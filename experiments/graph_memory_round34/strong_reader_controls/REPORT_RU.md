# Сильнейший опубликованный читатель ISETrace и пределы сравнения

Для полного теста на 2 000 вопросах лучший найденный опубликованный результат Full Support@2048 — **78,59%** у residual R-GCN с исключёнными рёбрами между соседними фрагментами поля. Наша зафиксированная модель cost_worst набрала **80,46%**. Разность +1,87 п.п. точна для двух средних. По опубликованным агрегатам невозможно определить парный интервал их разности. На локальной нативной паре одного seed эта же графовая абляция существенно сильнее основной строки R-GCN. [Статья, таблицы 1–4](https://arxiv.org/html/2609.25913v3#S7) · [Предшествующая проверка R32](../../graph_memory_round32/isetrace_comparison/REPORT_RU.md) · [Наши исходы по вопросам](bounds.json)

## Что именно сравнивают

ISE описывает синтез действий ОС-агента и публикует 23 132 траектории. Отдельная работа Wang и соавт. строит задачи на естественном языке и эталонные символьные интервалы, которые надо извлечь из одной завершённой траектории. В производном корпусе 6 597 сырых запросов, в основном эксперименте после обработки 3 894 train, 580 dev и 2 000 test. Траектории разделены между выборками. Замер касается чтения исторических данных. Перенос результата на онлайн-запись, получение верного ответа и агентное выполнение требует своих испытаний. [Исходная работа ISE](https://arxiv.org/abs/2606.11520) · [Статья о retrieval](https://arxiv.org/html/2609.25913v3#S3) · [Корпус запросов](https://huggingface.co/datasets/HazeLocus/ISETrace-Memory-Queries)

Все обученные строки основной опубликованной таблицы используют seed 13, 17, 29, 37 и 41, одну версию теста, отбор по dev. Dense-FT построен на E5-base-v2. Cross-Encoder-FT обучен на BAAI/bge-reranker-base с фиксированной ревизией 2cfc18c9, использует бинарную кросс-энтропию и оценивает каждую пару. Официальный код обучения доступен. На проверенном публичном GitHub и у владельца производного датасета не обнаружены готовые cross-encoder checkpoint или поштучные scores; веса стартовой BGE-модели доступны, запуск её напрямую создал бы другое условие. Найденная на Hugging Face модель ISETrace-SFT-8B обучена на исходном корпусе для действий агента. [Конфигурации и обучение](https://arxiv.org/html/2609.25913v3#S4.SS3) · [Полные таблицы и версии источников](discovery.json) · [Проверенные площадки и границы поиска](SEARCH_RU.md)

В опубликованном Provenance Path два верхних плотных результата защищены перед добавлением кандидатов из обхода графа. Идея фиксации верхних двух позиций уже имеет прямой прецедент. Наши измерения оценивают этот простой контроль для иной пары ранжирований и при изменении бюджета. Ещё одно различие с более ранними опытами касается Coverage. В данной работе это доля покрытых символов в объединении эталонных координат, включая идентификаторы поля и события. FS требует всех этих символов. Recall@5 — та же символьная доля для первых пяти элементов; MRR опирается на первое ненулевое пересечение. [Метрики и Provenance Path](https://arxiv.org/html/2609.25913v3#S3.SS2)

## Новый контроль по двум официальным Budget-AUC

Повторно обработали полные ранги всех тестовых вопросов на CPU. Штатная функция берёт бюджеты 256, 512, 1 024, 2 048, 4 096, 8 192 и рассчитывает нормированную площадь трапеций на оси log₂ бюджета. Нативный пакетировщик останавливается перед первым не помещающимся узлом. На каждом вопросе совпали сохранённые FS@2048 и пять прежних Coverage для кандидатов R33. MeanCoverage предыдущей серии использовала отдельный протокол из пяти равновесных бюджетов, поэтому здесь необходим новый расчёт. [Нативная метрика](https://github.com/xiaoqi-7/GraphMemory/blob/a98e2c30285a6d557a8b429e59a1a6eb27738537/graph_memory/evaluation/span_suite.py) · [Результаты](auc.json)

Для закрепления двух узлов против cost_worst разности равны +0,046 [−0,120, 0,212] и +0,057 [−0,105, 0,215]. По отношению к R-GCN без смежности разности меньше: +0,813 [−0,054, 1,692] и +0,800 [−0,091, 1,698]. Интервалы парные, кластерный бутстрэп 10 000 раз после усреднения seed внутри вопроса. Только пара с замороженным global_role здесь покрывает пять обучений с обеих сторон. Разности площадей посчитаны без повторной настройки ранжирования. Если к ним прибавить площадь округлённых авторских разностей шести точек полной R-GCN, получаются приблизительно 70,20% и 65,48%. Такие приближённые межсерийные сопоставления имеют тот же предел, что и сравнение отдельных средних. Для лучшей абляции авторов в проверенных источниках отсутствует полный исходный ряд шести точек. Для каждого типа перебрали допустимые пятёрки целых чисел успехов. Их сумма задана средним, а сумма квадратов ограничена округлённым выборочным SD пяти seed. Без учёта перестановок получилось 27, 67 и 139 пятёрок. Если среди n вопросов наш метод успешен на a и конкурент на b, пересечение успехов может изменяться от max(0,a+b−n) до min(a,b). Сопоставление отсортированных количеств между seed минимизирует суммарное число разногласий. Для максимального числа разногласий во всех возможных сочетаниях a+b≥n, поэтому достижимый минимум пересечения равен a+b−n для каждой пары. Обе крайние конфигурации построены по ID вопросов. ## Значение для статьи

Можно утверждать, что на этих пяти обучениях поправка, учитывающая стоимость узлов, повышает обе официальные площади относительно сильного замороженного global_role. Выигрыш по FS@2048 над лучшим найденным опубликованным средним равен 1,87 п.п. При заявлении о превосходстве над графовой архитектурой решающее сравнение — парный результат с абляцией без смежности на всех пяти matched checkpoint. Для online-памяти и эффекта на ответы потребуются отдельные постановки. Последующее улучшение на этапе retrieval можно мотивировать наблюдаемой прибавкой к собственному сильному читателю и объяснимостью её бюджетной зависимости.
