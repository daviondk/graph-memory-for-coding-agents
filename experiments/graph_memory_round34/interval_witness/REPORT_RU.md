# Отчёт. Как определить, когда агент прочитал все нужные фрагменты

Точный подсчёт по исходным интервалам исправил все 20 расхождений бюджетной оценки на ISETrace. При обучении такой подсчёт дал **80,60% Full Support@2048**. Столько же дают два существующих структурных ранжировщика. Фиксированный и адаптивный выбор свидетеля произвели одинаковый порядок на всех 2000 вопросах. В обучающей панели из 196 вопросов реально взаимозаменяемая группа определяла порог полного покрытия в **нуле** случаев при выбранной модели. Это ограничивает вывод о качестве способа обучения. ## Точный критерий полного покрытия

На каждой паре «событие, JSON-указатель» берём объединение полуоткрытых эталонных интервалов. Разбиваем его по всем границам пересекающихся кандидатных интервалов. Для элементарного интервала a множество Gₐ содержит индексы тех узлов, которые покрывают весь интервал. Узел с несколькими пересекающимися адресами учитывается один раз в каждой группе. Пусть rᵢ — позиция в строгом порядке, начиная с единицы. Тогда первый префикс, покрывающий все эталонные символы, заканчивается на позиции

**R = maxₐ minᵢ∈Gₐ rᵢ.**

Действительно, префикс k покрывает атом a тогда и только тогда, когда хотя бы одно rᵢ ≤ k в его группе. Конъюнкция этих условий по всем атомам даёт формулу. Пустая группа означает R = ∞. При положительных стоимостях узлов и чтении до первого превышения бюджета B полный ответ достигается тогда и только тогда, когда сумма стоимостей первых R узлов ≤ B. Для частичного покрытия нужно сохранить длины атомов. Доля покрытых символов — сумма длин атомов, встретивших хотя бы один узел в префиксе, делённая на суммарную длину эталона. [Построение](geometry.py) · [Вычисление и сверка с официальным scorer](measure.py)

Для убывающих различных баллов sᵢ тот же порог равен h = minₐ maxᵢ∈Gₐ sᵢ. При равенствах используем лексикографические ключи (sᵢ, −i), где i — исходная позиция Dense. Тогда h как лексикографический ключ снова однозначно задаёт последний узел. Скаляр h определяет значение балла, но два узла с таким значением могут стоять по разные стороны границы префикса. Группу H можно опустить при вычислении R, если другая группа G строго содержится в H. Первый узел H встретится не позже первого узла G. Оставшиеся минимальные группы достаточны. Узел положительного класса является обязательным для любого полного покрытия ровно тогда, когда он образует одноэлементную группу. Все утверждения относятся к фиксированному набору кандидатов. ## Функция обучения

Прибавляем к замороженному баллу «Dense-FT + структурный приоритет» линейную коррекцию четырёх признаков R33. Для каждого полностью постороннего узла j, не перекрывающего ни одного символа цели, считаем cⱼ softplus(sⱼ − h). Нормируем на суммарную стоимость посторонних узлов этого вопроса, затем усредняем по вопросам и прибавляем λ‖w‖²/2. При λ ∈ {0,03, 0,3} перебрали оба назначения свидетеля. Для любого набора баллов независимый выбор лучшего узла в каждой группе максимизирует минимальный выбранный балл, поэтому минимальная потеря среди назначений равна исходной min–max потере. Каждое фиксированное назначение даёт выпуклую регуляризованную задачу. Для обеих ветвей получены верхние оценки прямой целевой функции и нижние оценки через гладкую миноранту и сильную выпуклость. Разрыв для глобального решения не превышает 3,67×10⁻⁸. При заданных стартах и двух λ выбор одного свидетеля совпал с выбором по замороженному рангу. [Код обучения](learn.py) · [Параметры и сертификаты](models.json)

Указанная потеря оценивает стоимость **посторонних** узлов, попавших до разрешения всех интервалов. Даже при равенстве баллов индикатор попадания такого узла в префикс ≤ softplus(sⱼ−h)/ln 2. Для полной физической цены нужны также все обязательные и необязательные положительные узлы, фактически прочитанные к моменту R. Поэтому вытеснение бюджета проверяем по префиксу всех кандидатов. Покрытие эталона применяется только в обучении и измерениях. При выдаче ранжировщик видит прежние четыре признака и фиксированное смещение. [Покомпонентная стоимость по вопросам](test-costs.json.gz)

## Качество

Все конфигурации выбрали λ = 0,03 на 580 dev-вопросах. У всех пяти семейств Full Support@2048 одинаков, 462/580 (79,66%). Правило разрешения ничьей по Coverage@2048 выбрало основной контроль per-positive (84,49% против 84,26% нового метода). Тест охватывает 2000 вопросов и 1207 траекторий, один заранее выбранный Dense-FT seed 13. Он ранее использовался в исследовательской программе. Сравнение имеет разведочный статус. Основной контраст с per-positive дал 8 новых полностью покрытых вопросов и 3 потери. Разность +0,25 п.п., парный 95% перцентильный интервал с ресемплированием 1207 траекторий от −0,05 до +0,60 п.п. Из восьми выигрышей лишь один содержит какой-либо перекрывающийся атом; ни один не содержит минимальную многовариантную группу. MRR в этом сравнении снизился на 0,230 п.п. (интервал от −0,426 до −0,045 п.п., вторичная метрика). Против R34 hard cost_log нет различий по Full Support и трём бюджетным показателям покрытия. Порядок внутри списка отличается на 568 вопросах. Против R33 счёт переключений Full Support также 0/0. Причинно приписать 0,25 п.п. адаптивному выбору свидетелей нельзя. [Все метрики, включая Coverage@5](results.json)

Для R33 на 81 тестовом вопросе все нужные символы прочитаны раньше последнего перекрывающегося узла. На 20 вопросах между этими позициями пересекается граница 2048 токенов. Все 20 расхождений воспроизводятся новым критерием, включая 9 случаев с минимальной многовариантной группой. На 6032 различных парах вопрос–порядок в test и 3025 в dev все шесть метрик по атомам совпали с официальным интервальным scorer. Конечный перебор дополнительно охватил 10584 бюджетных случая, включая равные баллы. Практическое применение результата — точная разметка момента завершения и проверка абляций обучения. Следующая проверяемая гипотеза требует обучающего корпуса, где альтернативные пути часто определяют именно последний необходимый интервал. [Аудит](audit.json) · [Формулы и тесты](verify.py)
