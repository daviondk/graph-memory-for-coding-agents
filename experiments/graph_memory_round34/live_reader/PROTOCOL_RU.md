# Может ли замороженная бюджетная модель читать незавершённую историю

Метод R33 достигает 80,60% на полном тесте seed 13. В рабочем агенте истории ещё пополняются. Применяем его без переобучения на четырёх уже зафиксированных срезах задачи R22/prefix_read. Вопрос был написан по полной истории, долю истории выбирает исследователь. В основной оценке используются 901 вопрос вне пилотных траекторий, для которых в середине были уже видны все необходимые исходные символы. Этот набор известен из прежней серии. Дополнительно показываем все 1 845 вопросов непилотной панели и остальные срезы, а также знаменатели доступности.

Операционный контраст: причинный cost_worst R33 минус прежний причинный графовый читатель R22 по FS@2048 на первичной панели. Контроли: текущий граф R33 до калибровки стоимости, семь признаков без рёбер с собственной обученной калибровкой R33, Dense-FT, накопление всех замеченных связей без отзывов и недоступный в работе граф с финальными связями между уже имеющимися концами. При сравнении одного вопроса на одном срезе список кандидатов и начальный порядок Dense фиксированы. Перед оценкой сверяем пул на каждом срезе с R22, все итоговые решения строгих контролей R33 на последнем срезе — с ранее опубликованными. Сохраняем упорядоченные прочитанные кандидаты по каждому бюджету 512, 1024 и 2048. По ним вычислим нативное символьное покрытие и полноту. Ресемплируем траектории, не смешиваем неполные состояния в независимые наблюдения и учитываем известность теста. Пилот R22 и предыдущие результаты данным контролем не расширяются до независимой репликации.

Фиксируем также цену ошибок состояния. Если при одном текущем пуле ошибочное сохранение ранее отозванных связей меняет выданные узлы, сравниваем затронутые и все вопросы. Граф с финальными связями предназначен для диагностики эффекта будущих данных. Полностью исчезнувшие до текущего среза связи он не восстанавливает.
