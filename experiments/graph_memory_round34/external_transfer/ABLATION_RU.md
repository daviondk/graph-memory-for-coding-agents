# Разбор результата для простой cost-loss

После оценки сильного baseline фиксируем дополнительный анализ. Для варианта union_cost, который на сильном baseline получил лучшее точечное значение, повторим обучение с нулевыми признаками событий. Для простого контроля на тех же четырёх признаках заменим веса каждого отрицательного по длине равными весами; этот контроль отделяет обучающую роль стоимости от её присутствия в признаках. В обоих случаях λ∈{0,03;0,3} выбирается на исходном dev и сохраняется до расчёта тестовых метрик. На test дополнительно считаем контрасты исходного union_cost с базовым BGE, безрёберным и с обучением без взвешивания негативов. Это последующие описательные проверки на уже исследованной выборке. По каждой записи проверяем основной показатель официальным scorer. Сообщаем долю состояний с рёбрами, число пересекающихся/единичных групп, чтобы объяснить геометрию переноса.
