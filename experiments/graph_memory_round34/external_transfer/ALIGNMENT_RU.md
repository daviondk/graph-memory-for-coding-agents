# Связаны ли значения признаков с нужным файлом

Дополнительная проверка после получения основных результатов. Для каждой уже фиксированной тестовой выдачи сильного BGE и модели union_cost переставляем два признака истории между именами файлов внутри того же состояния. При одинаковом нормализованном имени все фрагменты получают одну и ту же пару признаков. Перестановка применяется только между файлами с одинаковым числом фрагментов в кандидатном пуле, поэтому сохраняются гистограмма признаков по узлам, число узлов каждого файла и связка счётчика с давностью события. Остальные признаки, модель и кандидаты заморожены. В группах размера один изменение невозможно. Берём 64 воспроизводимые перестановки с начальными числами от 0 до 63, средний исход внутри состояния, парная разность с фактической привязкой и кластерный интервал. Это проверка специфичности соответствия пути и фрагмента в этой обученной модели. Искусственно переставленный граф отличается от естественных историй; причинный эффект сбора памяти в живом агенте здесь не измеряется.
