## Строгая граница для префиксного чтения

Пусть B — целый токенный бюджет, P — полная стоимость всех положительных PU (единиц происхождения), N — полная стоимость отрицательных PU. В полном детерминированном порядке с заданным разрешением связок обозначим через A стоимость отрицательных элементов, оказавшихся **раньше последнего положительного**. Все положительные прочитаны тогда и только тогда, когда P+A≤B: левая часть — точная стоимость префикса, заканчивающегося на последнем положительном. При P>B такой префикс недостижим при любом порядке; при P+N≤B любой порядок успешен.

Если P≤B и N>0, положим L=B−P+1. Поскольку стоимости целые, проигрыш наступает при A≥L. Обозначая через Iⱼ индикатор положения отрицательного j перед последним положительным, получаем

```text
1[потерян хотя бы один положительный PU]
    ≤ min(1, A/L)
A/L = (N/L) × Σⱼ (cⱼ/N) Iⱼ
Pr(провал | данный вопрос) ≤ min(1, E[A | данный вопрос]/L).
```

Последняя строка применима к случайному порядку или оценке модели; условный знаменатель фиксирован. Для N=0 исход определяется только P. Эти соотношения доказываются без предположений о независимости рангов. Для нативной метрики ISETrace положительность означает перекрытие с эталонным интервалом. Полное чтение всех положительных PU достаточно, если их объединение покрывает весь эталон. Обратное неверно при избыточных или перекрывающихся PU. Поэтому случай P>B сам по себе доказывает невозможность прочитать все положительные PU; заключение о невозможности покрыть интервалы потребовало бы вычисления минимального покрывающего множества. [ISETrace, нативный критерий](https://arxiv.org/html/2609.25913v3#S5)

Для замены попарного индикатора логистическим штрафом удобно использовать точный минимум положительных оценок s*. Тогда Iⱼ≤softplus(sⱼ−s*)/ln(2), включая верхнюю оценку при равенстве рангов. Ненормированный мягкий минимум тоже не превосходит s*. Исходный R33 применяет нормированный мягкий минимум, способный оказаться выше s*. Добавление τ ln(m) к аргументу softplus при m положительных превращает его в корректный ненормированный вариант. Здесь оставлена прежняя функция R33, чтобы сравнить только веса вопросов. Ни нормирование весов, ни насыщение, ни квадратный корень не наследуют сами по себе строгий статус исходной верхней границы. Перебор всех 3 588 малых сочетаний порядка и бюджета подтвердил тождество префикса; найдено 388 малых конфигураций оценок и меток, где нормированный гладкий штраф без указанного сдвига не мажорирует стоимость инверсий. ## Что удалось измерить

Из 196 калибровочных train-вопросов в 13 вся траектория укладывается в бюджет. Недостижимых прокси-вопросов при B=2048 не встретилось ни на train, ни среди 580 dev и 2 000 test, поэтому такой граничный случай проверен также полным перебором. Все методы используют те же четыре признака кандидата, ту же замороженную R33-модель global_role и те же эмбеддинги seed 13. На dev подбирались только заранее перечисленные преобразования и L2. При инференсе P, N и gold не подаются в модель. Коэффициенты фиксировались до оценки test и перенесены на независимо обученные семантические ранжировщики 17, 29, 37 и 41. Для каждой пары «вопрос, seed» все четыре метрики исходного R33 были воспроизведены в точности. Тестовая панель уже изучалась в прежних экспериментах проекта. [Исходная работа проекта](../../graph_memory_round33/budget_loss/REPORT_RU.md) · [Фиксация всех прогнозов](test-seal.json)

Квадратный корень отношения N/L концентрирует обучение на меньшем числе вопросов. При 183 активных вопросах эффективный размер выборки (1/Σw²) оказался 101,6, а крупнейший вес — 4,67%. Для квадратного корня N/B эффективный размер составил 130,3 и максимальный вес 2,23%. При мягком насыщении N/L эффективный размер 179,1. Концентрация — возможное объяснение снижения устойчивости; непосредственно проверено только изменение распределения весов. [Числа по каждому вопросу](train-query-weights.json.gz) · [Параметры моделей](models.json)

У всех 2 000 test-вопросов объединение положительных PU закрывает эталон. При seed 13 исходный R33 потерял хотя бы один положительный PU в 408 случаях, а не вернул все эталонные символы в 388. Разница в 20 случаях объясняет, почему для оценки метода важна нативная метрика. Среднее ограниченное сверху значение min(1,A/L) составило 33,76% при наблюдаемой частоте прокси-провала 20,40%. У модели запаса соответствующие величины 34,65% и 21,00%. Такой разрыв показывает, насколько грубой может быть верная математическая граница как практическая оценка риска.
