# Физическая стоимость чтения с сохранёнными эмбеддингами

На CPU сравниваются настоящие обученные checkpoint seed 13, выбранные по официальным 580 dev-вопросам, для полной residual R-GCN и абляции без смежности, с замороженными R33 global_role + cost_worst и общим простой Dense-FT ранжированием. Панель — первые 96 из полных 2 000 тестовых ID, отсортированных по SHA256('R34 physical reader v1/'+ID), без использования успеха, ранга или длины. Все кандидаты и контекстный бюджет 2 048 токенов общие. Эмбеддинги уже получены одной E5 Dense-FT ревизии, CPU-измерение не обращается к GPU и не запускает генератор ответов.

Устанавливаем один поток PyTorch, BLAS и OMP, batch=1. Основная тёплая точка входа получает уже вычисленные семантические scores/носители официального graph batch и один раз подготовленную статическую структуру истории. Каждая система возвращает полный порядок ID и строго помещающийся префикс. Время от этих подготовленных представлений до результата включает настоящий forward для R-GCN и оба sort для предлагаемого ранжирования. Проверяем более широкую точку входа, которая получает нативные фиксированные candidate и query embeddings. Она платит за создание требуемого вопрос-зависимого представления и выдачу. Раздельно приводим стоимость обработки структуры на одну историю, SQLite-чтения/выравнивания общих входов, загрузки весов, размер файлов и физических тензорных буферов. Кэши нельзя трактовать как бесплатно созданный индекс. Если доступная реализация не даёт честного широкого сопоставления, объявляем его границу явно. Переиспользовать готовый порядок или готовые ответы запрещено во временной секции.

Каждый вопрос проходит один прогрев на метод, затем восемь повторов тёплого режима в детерминированно перемешанных блоках и два повтора режима с построением представления. Сохраняем все времена по вопросу. Основные p50/p95 — распределение медиан времени запроса по вопросам, дополнительно публикуем p50/p95 всех вызовов. Парные разности средних медиан и отношения средних с 95% интервалом — бутстрэп 10 000 раз по целым траекториям. Следим за хешами и сравнением CPU-порядков и префиксов с исходными замороженными прогнозами: публикуем любые расхождения CPU batch=1 и исходного backend. Переоценим Full Support на тех же 96 вопросах по нативным спанам. Измерение относится только к читателю на данной машине; физическую память отличаем от размера весов, tensor payload и стоимости запуска общего интерпретатора.
