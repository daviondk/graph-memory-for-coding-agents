# Сквозная программная точка входа из локального хранилища

Дополнительная панель — первые 24 ID уже зафиксированной панели. На каждом вопросе три раза в разном порядке делаем полный вызов одной политики, начиная с чтения сжатой истории, десериализации официального графа, восстановления пула, чтения закешированных E5-векторов из локальной SQLite и подготовки данных. Для R33 в каждом таком вызове заново считаем признаки графа, для R-GCN строим настоящий batch и прогоняем полный обученный checkpoint. Во всех случаях возвращаем один тип результата и сверяем с основным CPU-прогоном. Ради одинакового I/O всем методам выдаются векторы для всех узлов графа, хотя Dense и R33 используют только кандидатные. Модели и соединение SQLite уже открыты; файловый и страничный кеши ОС не очищаются. Отдельно вычисляем p50/p95 медиан по запросу и парные интервалы по траекториям. Это время первого чтения данной истории в логическом смысле, при тёплом файловом кеше и заранее вычисленных E5, без текста-генерации и сетевого обмена.
