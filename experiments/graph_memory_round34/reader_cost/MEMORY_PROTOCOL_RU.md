# Дополнительный замер рабочего набора

В отдельных свежих процессах для каждой из четырёх политик удерживаем данные первых восьми вопросов той же заранее выбранной панели. Каждый процесс ограничен тем же одним логическим ядром. Снимаем Windows GetProcessMemoryInfo после общего импорта и открытия базы, после подготовки всех восьми историй и общих векторов, после загрузки одной модели, после создания готовых представлений и после трёх последовательных проходов. Повторяем дважды в обратном порядке методов, без одновременных зондов. Отдельно показываем WorkingSetSize, PeakWorkingSetSize и PrivateUsage. Изменение рабочего набора одного процесса на восьми вопросах сюда входит с аллокатором и служебными структурами, не является теоретической нижней границей памяти модели. Показатели пика могут включать раннее чтение файлов и загрузку библиотек.
