# Односидовое обучение E5 на ISETrace и комплектование графовой памяти

Цель — проверить перенос эффекта добора пар при действительном обучении encoder. Выбрать авторский provenance-unit Dense-FT, seed 13, стандартный полный train, dev первые 500 запросов по нативному split, одна эпоха. Точные train/dev/test формируются из первичного релиза, закреплённой авторской реализации и списка записей, отброшенных по её проверке в R18. Запросы и траектории между разделами попарно не пересекаются. Эталон train и dev используется для обучения и предварительного выбора чекпойнта. Эталон test открывается только после фиксации весов и поштучных прогнозов. Предыдущие агрегаты при frozen retrieval уже известны. Тестовый набор не является новой независимой выборкой.

Используем авторское формирование положительных узлов по пересечению координат, подбор негативов и trainer sentence-transformers 2.7.0 (MNRL, batch 16, 2e−5, training seed 13, нативная оценка на dev). Перед длительным расчётом замеряем фактическую стоимость; при оценке длительности свыше 90 минут или неисправимой ошибке окружения публикуем отличие ограниченного режима. Число seed отличается от пяти обучающих прогонов статьи. Собственного дообучения на test и выбора параметров по его меткам нет.

Все 2 000 запросов, одна и та же сохранённая перестановка кандидатов, окно 2 048 токенов, пять режимов prefix, skip, value, парное дополнение и clip. Основной контраст — парная упаковка против skip при одном обученном ранжировании. Основной исход — Full Support, дополнительно Coverage, Density, F1, число блоков, реальные токены. На 1 207 траекториях парный кластерный бутстреп 10 000 повторов, seed 13. Отдельно сопоставляем с нашим frozen E5, опубликованным 72,78 ± 0,64% FS для обученного PU Dense-FT и 77,33 ± 0,53% для residual R-GCN. При различии конфигураций обозначаем их явно. Все обращения к траекториям предназначены для пассивного выбора текстовых блоков.
