# Отбор изменений по ресурсам до просмотра разметки

Основной проект — Loguru из официального NameRTS, у него уже есть работоспособная закреплённая среда и прежний консервативный контроль на других SHA. Научная единица — пара версий и файл тестов. Для независимой панели исключаем пересечение любого из current, true_parent, direct_parent с физически прокрученными парами R17 и R18, в том числе дополнительной ревизией. Изменение ресурса допустимо при изменении, добавлении или удалении pyproject.toml, файла .pyi под пакетом или Python-файла тестового помощника под tests/, кроме conftest.py и файлов tests/test_*.py первого уровня. Содержимое pyproject читается одинаково парсером TOML обеих ревизий. Изменения потенциально опасной тематики отбираются только по заголовку и исключаются, сами проблемы не воспроизводятся. Прочие изменения программы разрешены и сохраняют прежний модульный и функциональный граф. Слепая сортировка кандидатов SHA-256 от «r19-resource|current», на первых четырёх доступных новых парах исследуем первые 14 файлов по SHA-256 от «r19-file|current|path». Общее множество файлов должно существовать на обеих версиях. Если подходящих пар меньше четырёх, берём все. Для диагностики изменения pyproject, известные из R18, остаются отдельно как калибровочные; повторно не включаем их в тестовую панель. Внешний проект Sphinx кандидатом считается только при возможности получить входы и рабочую среду, и должен публиковаться отдельным блоком с самостоятельным до-разметочным отбором. Обзор R18 уже публиковал агрегаты NameRTS; ниже заранее фиксируется новая политика, а сами авторские метки не подаются ей на вход.
