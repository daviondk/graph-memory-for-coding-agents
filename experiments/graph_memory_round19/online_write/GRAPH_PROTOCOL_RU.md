# Общий ключ записи для двух концов ребра

До просмотра исходов по вариантам записи фиксируем вторую гипотезу на том же корпусе. Две независимо выбранные вершины графа с вероятностью удержания p сохраняются вместе примерно с вероятностью p². Если у вершин общий случайный приоритет, в идеализированной модели равных стоимостей и одного порога вероятность общего удержания равна p. Это иллюстрация механизма, а не формула выигрыша для реальных переменных затрат. Проверяем, соответствует ли ему большее число полностью сохранившихся комплектов evidence при том же лимите.

На входе только сообщения инструментов. Один ключ на каждый call_id вычисляем из SHA-256 без просмотра вопросов, факта будущего появления результата и меток. Обоим концам одного вызова присваиваем этот ключ. Приоритет по глубине такой же, как в Head. Контроли: обычный Head (хеш независимо по идентификатору каждой вершины) и ложная связь (выход получает ключ предыдущего наблюдавшегося вызова по порядку поступления аргументов; при отсутствии предшественника или если аргумент ещё не наблюдался — отдельный детерминированный хеш). Для аргументов общий и смещённый варианты тождественны. Все правила потоковые. У ложного контроля краевые и пропущенные события могут изменить распределение степеней, поэтому покажем долю действительно перепривязанных выходов, маргинальные доли сохранённых блоков по роли и изменение выбора относительно обычного Head.

Первичный исход здесь — разница полного сохранения эталона при бюджете 8192 между общим и смещённым ключом. Вторичные — размер эффекта относительно независимых ключей, результат общего читателя BM25 при 2048, а также подгруппы по наличию в эталоне обеих сторон хотя бы одного вызова или результата без соответствующего аргумента. Непересекающиеся подгруппы кодируем как «есть пара» и «нет пары», сохраняя знаменатели. На всех вопросах — парный кластерный bootstrap 10 000, seed 13. Никакой настройки хеша, отсечения подгрупп или ручного отбора задач по качеству. Конфигурация и прогнозы фиксируются до расчёта любого исхода этого сравнения.
