# Нужна ли точная связь теста с наблюдением о числовой границе

На двух релизах библиотеки boltons проверили, помогает ли история тестов выбрать одну команду pytest, которая обнаружит изменение поведения. Связанное с тестом свидетельство равенства обнаружило **10 из 48** граничных изменений. Столько же дали дешёвый лексический поиск, память о достигнутой строке и память о выполненном сравнении. Последний ранее запущенный тест обнаружил **4 из 48**. [Результаты](summary.json) · [Зафиксированные решения](forecasts.json.gz)

| Какая память доступна при выборе одного теста | Обнаружено / 48 | Доля |
|---|---:|---:|
| Команда и её точное наблюдение о равенстве | 10 | 20,83% |
| Факт выполнения предиката | 10 | 20,83% |
| Факт достижения строки | 10 | 20,83% |
| Jaccard по токенам места изменения и названия теста | 10 | 20,83% |
| Давность запуска | 4 | 8,33% |
| Связи переставлены внутри числа достигших предиката тестов, среднее по 16 seed | 7,4375 | 15,49% |

**Механизм.** Для конечных встроенных чисел результат `x < y` отличается от `x <= y` тогда и только тогда, когда `x == y`. Аналогичное условие верно при подмене `>` на `>=`. Предыдущий запуск каждого теста сохранял по стабильному ключу выражения факт достижения строки, выполнения сравнения и наблюдения равных чисел. Тест с таким наблюдением получает приоритет при соответствующем изменении. Для получения провала pytest локальное изменение результата предиката должно повлиять на значение, которое проверяет тест. Старое наблюдение может также устареть в новом релизе. Вне двух встроенных числовых типов правило не даёт гарантии.

**Выборка и местоположение изменения.** 122 авторских теста из 13 разрешённых модулей прошли в релизе 23.1.1 дважды, без инструментирования и с ним. На 24.0.0 зафиксированы все 81 подходящее стабильное выражение, из которых заранее выбраны 48, 36 функций, 10 модулей. У всех 48 мест между версиями изменился номер строки, поэтому ключом служили функция, AST выражения и номер вхождения. Кандидаты — уже проходившие тесты соответствующего модуля. Медиана числа тестов — 5. Перестановки оставляют состав кандидатов, факт достижения предиката и число наблюдений равенства на том же месте. Различаются только тесты, к которым привязаны эти флаги. Модели и API в этом эксперименте не использовались. [Источники и SHA](source-lock.json) · [Полный протокол](PROTOCOL_RU.md)

**Что показало исполнение.** После фиксации решений выполнено 95 уникальных изолированных запусков выбранных команд против изменений (одна идентичная команда на одно изменение используется несколькими политиками). Все 95 команд прошли на чистом новом релизе. Под изменением 13 завершились на стадии call с провалом, 80 прошли и 2 упали при импорте тестового модуля с авторским самотестированием. Последним двум не приписывается обнаружение конкретным тестом. Для проверки достижимого потолка выполнены также все доступные тесты соответствующего модуля по каждому изменению: 459 наблюдавшихся исходов отдельных тестов, полная матрица для 46 изменений. Из этих 46 только 10 обнаруживались хотя бы одним историческим тестом. Для двух изменений матрица недоступна из-за указанного импорта. Таймаутов не было. [Изолированные исполнения](execution-receipts.json.gz) · [Полная матрица](exhaustive-matrix.json.gz) · [Учёт стадии collection](EXECUTION_NOTE_RU.md)

**Почему перестановки дали другой результат.** Сравнение ранее выполнялось для 34 из 48 мест, равные числа наблюдались в 18. Только у 5 мест флаги равенства различались между достигающими тестами и перестановка могла изменить решение. На 3 местах она ухудшала обнаружение. Настоящие свидетельства дают в среднем +5,34 п.п. к переставленным, описательный 95% кластерный интервал по функциям [0,00; 12,09]. Однако фактически выбранный по свидетельству тест совпадает с выбранным по достижению предиката во всех 48 задачах; с лексическим поиском разошлись 8 команд, результат обнаружения не изменился. Прирост относительно последнего теста +12,50 п.п. [2,38; 23,91]. На этом корпусе у наиболее сильных простых политик уже исчерпан наблюдаемый потолок. Положительный эффект к искусственно повреждённым связям сам по себе не устанавливает выигрыш от более сложной памяти.

Исход относится к детерминированному выбору одного теста на заранее показанный diff и к одному типу синтетических мутаций в реальной библиотеке. Для переноса на естественные регрессии нужна серия с большим количеством различимых тестов и с историческими ошибками следующего релиза.
