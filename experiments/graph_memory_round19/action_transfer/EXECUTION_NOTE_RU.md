# Обработка ошибок запуска

Первый предзапуск остановлен защитной проверкой пути импорта в Windows; сравнение файлового пути исправлено. На Python 3.14 / pytest 9 авторская сигнатура хука протестированных релизов блокировала collection. Источники перенесены в изолированный интерпретатор Python 3.11.15 / pytest 7.4.4 до записи памяти и прогнозов. Два соответствующих хеша сохранены в aborted-design.

После блокировки прогнозов обнаружен upstream вызов test_barrel_list() в теле модуля tests/test_listutils.py. На одном из мутантов выполнение завершается уже при импорте тестового модуля. Исходная обвязка ошибочно останавливала весь эксперимент при отсутствии отчёта о стадии call. Исправлена только классификация и продолжение исполнения в run.py. Ошибка во время collection не приписывается выбранному тесту, её вклад в основной показатель нулевой, доступность oracle для полного файла в таком случае не определена. Список действий, панель, наблюдения и основной знаменатель зафиксированы прежними SHA-256. Входы и тесты прогоняются заново на всех 48 изменениях.
