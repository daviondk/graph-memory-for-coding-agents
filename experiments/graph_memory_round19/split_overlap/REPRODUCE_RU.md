# Воспроизведение аудита

Для проверки результатов запустите из этого каталога `D:/CodexResearch/x20-isetrace-runtime/venv/Scripts/python.exe -B -X utf8 audit.py verify`. Команда проверяет манифест и повторяет все девять агрегатов, включающих исходные панели и обе подгруппы. Нужны NumPy, исходный Python-пакет GraphMemory из локального ISETrace runtime и сохранённые поштучные результаты R19. Исходные строки диалогов в данный пакет не включаются.

Для повторения разбора первичного JSONL в отдельной рабочей копии выполните последовательно `audit.py freeze`, затем `audit.py score` тем же Python. Первый этап читает только данные создания запросов и разбиения для выбора подгрупп. Для исходов методов он записывает контрольные суммы уже зафиксированных файлов, не вычисляя метрики. `overlap-lock.json` содержит эти SHA-256, хеш нативного парсера, замороженного протокола, программы и полученных до оценки флагов. Второй этап сопоставляет бинарные флаги с исходами по идентификаторам и проверяет совпадение всех ID траекторий.

Два набора траекторий в train фиксируются по `trained_rank/split.json.gz` и `write_learned/plan.json`. Полный dev берётся из `write_transfer/cohort.json`. Для бюджета 8 192/2 048 выбираются FS и Coverage **после чтения**, элементы 3 и 4 массивов в `write_learned/transfer-outcomes.json.gz` при нумерации с нуля. Для Dense-FT используются именованные метрики в `trained_rank/outcomes.json.gz`. При каждом повторе бутстрепа число выбранных групп фиксировано, а знаменатель равен количеству получившихся с учётом повторов запросов. Общие группы сортируются по ID и генератор NumPy сбрасывается в seed 13 для каждого контраста. Различия последних сотых п.п. относительно некоторых интервалов исходного отчёта возможны из-за конкретных случайных выборок. Числа успехов воспроизводятся точно.
