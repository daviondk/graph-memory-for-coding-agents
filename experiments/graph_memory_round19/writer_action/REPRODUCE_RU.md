# Проверка и воспроизведение

Численная проверка сохранённых нативных действий и всех показателей по исходным координатам работает с Python 3.11+ и стандартной библиотекой. Выполните `python -B verify.py` в распакованном каталоге. Два исхода по одному точному prompt получают одну и ту же закэшированную реакцию. Отчёт по каждому из 36 вопросов, включая отрицательные исходы, находится в outcomes.json.gz.

Для повторения нужны артефакты R18/isetrace_reader, R18/isetrace_official, исходный кеш D:/CodexResearch/x20-isetrace-e5-gpu/cache/projection, R19/online_write и R19/write_learned. Фиксируются SHA всех источников и финальных входных запросов. Система и остальные параметры inference повторяют ранее проверенный запуск с уточнением, что открыть разрешено событие с несколькими показанными выдержками. Модель, llama.cpp и CUDA берутся из ранее подготовленного локального Qwen окружения на D. В самом исследовании нет удалённых API-вызовов.

На Python окружения x20-isetrace-runtime проведите `study.py lock` и `study.py prepare`. Полные входы и логи сервера окажутся только в D:/CodexResearch/x20-isetrace-runtime/writer-action-private. Пока порт 18952 и GPU свободны, в одном терминале поднимите `./run_native.ps1`. В другом выполните `study.py infer`, дождитесь response-lock.json, затем завершите только выделенный сервер обычным Ctrl+C. Для подсчёта запустите `study.py score`, `report.py` и `verify.py`. При смене устройства точный ID выбора при температуре 0 может зависеть от численной точности. Для воспроизводимой сверки всех чисел сохранены хеши фактически возвращённых строк источника и расход токенов.
