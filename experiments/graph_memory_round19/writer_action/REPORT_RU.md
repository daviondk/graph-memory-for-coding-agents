# Политика записи и действие Qwen при открытии источника

Обученное правило записи дало 14/36 случаев полной поддержки после одного реального действия Qwen, эвристика приоритета начал результатов — 12/36. Парный контраст Full−output_head: 2 выигрышей, 0 потерь, +5,56 п.п. [+0,00; +13,89]. Среднее покрытие изменилось на +5,73 п.п. [-3,88; +16,28].
