# Можно ли улучшить LRE по связи между вопросом собеседника и следующей репликой

Дополнительный внешний домен — диалоговая память. Берём официальный публичный архив LoCoMo10 и нативный протокол query-blind LRE для всех десяти диалогов. Обучение leave-one-conversation-out с удалением дословных повторов между train и test внутри каждого fold. Эталон автора — встречалась ли реплика в атрибуции хотя бы одного подходящего вопроса диалога, category 5 исключена нативным загрузчиком. Модель LRE-supervised использует TF-IDF текста и шесть признаков траектории. На том же входе проверяем дополнительную наблюдаемую связь — кто и о чём говорил непосредственно перед записываемой репликой в той же сессии. Вопросы benchmark для признаков исключены.

Сохраняем тот же векторизатор, train-only scaler, L2-логистическую регрессию и class weights, меняется только набор структурных признаков. При наличии предыдущей реплики используем индикаторы её существования, смены говорящего, вопросительного знака у собеседника, сочетания вопросительности двух реплик, длину предыдущей реплики (log1p), произведение логарифма длины текущей реплики и индикатора предыдущего вопроса и Jaccard по словам. В первом сообщении сессии вектор нулевой. Отдельный контроль — те же признаки с ложным предшественником: внутри каждой сессии циклически сдвигаем назначения предшественников на половину доступного списка, сохраняем первый пустой слот. Такой контроль сохраняет распределение длин/типов собеседника внутри сессии. Это офлайн-перестановка; рабочие признаки используют только прошлую реплику. Текущая длина диалога и recency в авторском LRE доступны в момент уплотнения целого эпизода. Это отдельная постановка по сравнению с необратимой записью событий ISETrace.

Основной исход — macro Recall при бюджете 20% реплик, усреднённый по диалогам (округление числа реплик вверх, формула авторов). Также macro ROC-AUC и Recall при 10/40%. Основной контраст — истинное ребро минус исходный LRE-supervised. Тот же тип запуска с ложными рёбрами проверяет механизм. Для предварительно выбранных контрастов фиксируем все 10 парных разниц, точный двусторонний sign-flip по диалогам (обменность знака в нулевой модели), и percentile bootstrap по 10 диалогам с 10 000 повторов и seed 13. Высокая неопределённость при 10 диалогах и перекрывающихся тренировочных fold. По заранее известному предыдущему использованию корпуса в R3 результат исследовательский. Успех решения новых задач агентом и строгий байтовый лимит здесь не измеряются. Веса и признаки не подбираем по метрикам теста.
