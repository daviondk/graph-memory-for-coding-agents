# Воспроизведение LRE и расширения на LoCoMo10

`python verify.py` пересчитывает 240 групповых метрик, средние и точные p по сохранённым оценкам и бинарным меткам. Нужен только Python 3.10+; текст диалогов в пакете отсутствует. Проверка проверяет и отсутствие ничьих на порогах, которые могли бы влиять на Recall при разном порядке сортировки.

Для обучения укажите LRE_REPO (локальный checkout исходного LRE, ревизия 1aa51d672d772b27a272cab1393cd9968c13d158) и LOCOMO_FILE (locomo10.json, SHA-256 79fa87e90f04081343b8c8debecb80a9a6842b76a7aa537dc9fdf651ea698ff4). В исходном прогоне использовались Python 3.12.13, scikit-learn 1.8.0, SciPy 1.18.1, CPU, UTF-8. При обновлении данных или библиотек сравнивайте по записям input-lock.json и forecast-lock.json. [Исходный код метода](https://github.com/NusRAT-LiA/LRE/tree/1aa51d672d772b27a272cab1393cd9968c13d158) · [Закреплённая версия набора](https://github.com/snap-research/locomo/blob/cbfbc1dba6bc53d00625212a0f22d55ffee7c1fc/data/locomo10.json)

В новой рабочей копии сделайте `python -X utf8 study.py predict`, затем `python -X utf8 study.py score`. Первый этап работает с метками девяти обучающих диалогов в каждом fold, фильтр дублей совпадает с официальным. Второй сопоставляет запечатанные прогнозы с метками соответствующего отложенного диалога. Единственное расширение входа исходного LRE при обучении и применении — семь новых числовых признаков. Сравните результаты с results.json. Масштабирование и словарь TF-IDF обучаются внутри каждого fold нативной библиотекой.

Для дополнительной абляции после основной оценки выполните python -X utf8 ablate.py. Сохранённые прогнозы для этих трёх вариантов также проверяются функцией verify.py.
