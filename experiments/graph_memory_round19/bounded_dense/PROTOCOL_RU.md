# Чтение только сохранённого текста из ограниченной памяти

Останавливаем правила до новых исходов. Сравниваются три ранее зафиксированные политики записи при 8 192 токенах: full (логистическая модель), output_head и FIFO. Всем заданы те же реальные 64-токеновые фрагменты, события и условия записи, что в online_write/write_learned. Читатель получает вопрос после записи, ранжирует только сохранившиеся блоки данной политики, читает не более 2 048 токенов с пропуском переполнений. Обученный encoder берётся из R19/trained_rank, seed 13, выбран на 500 dev по retrieval. Каждый вектор создаётся из точной строки «passage: » + текст соответствующего сохранённого фрагмента; запрос из «query: » + вопрос. Полные 504-токеновые источники и их готовые векторы не используются. Дедупликация по SHA-256 полных байтов внутри физического кэша не меняет трёх логически изолированных видимых множеств.

Проверяем все 2 000 test и 580 dev. Из этих dev 500 участвовали в выборе epoch Dense-FT. Поэтому dev — описательная проверка, test — основной. Первичный контраст — full против output_head при одном Dense-FT. Основной исход — Full Support@2048, дополнительно coverage, density, средние токены хранения и чтения. Парный bootstrap 10 000 раз по целым траекториям с seed 13. Вторично проводится фиксированный reciprocal rank fusion BM25 + Dense-FT, k=60, равные веса. Равные оценки разрешаются по индексу блока. Контроль — точно те же сохранённые BM25-списки, что у исходных работ, с обязательной проверкой на каждом случае. Раздельно учитываются физические байты оригинального текста с координатами/служебными записями и ускоряющего векторного индекса FP32, модель общая. Оценка на исходных символах, координаты совпадают с original evidence в каждой траектории. Условия бюджета включают исходные токены; дополнительные байты persistent-векторов раскрываются отдельно.

Обе проекции используют единый замороженный checkpoint, до меток фиксируются retained IDs, новые ранги и список фактически прочитанного. Доступны агрегаты базовых BM25-исследований, выборка уже использовалась в проекте.
