# Воспроизведение ограниченной записи и обученного чтения

Для проверки готовой работы нужен Python 3.11+ стандартной комплектации, соседний каталог R19/trained_rank со стандартной арифметикой и разметка R18/isetrace_official/gold-spans.json.gz и R19/write_transfer/gold-spans.json.gz. Из каталога bounded_dense выполнить команду:

    python -B verify.py

Она сверяет манифест и индивидуальные прогнозы, проверяет фактически доступные индексы, потолок записи, бюджет чтения и пересчитывает все 23 220 исходов, включая покрытие, плотность, F1 и Full Support по исходным символьным интервалам.

## Полный опыт

Запись использует зафиксированные прогнозы соседних R19/online_write, write_learned и write_transfer. Развернуть их согласно их инструкциям и разместить обе проекции точного текста по путям в inputs.py. Для trained_rank воспроизвести выбранный checkpoint и убедиться в совпадении SHA из reader-plan.json. Используются два локальных Python из инструкции trained_rank и авторский пакет ISETrace. Артефакты не содержат веса, сырой корпус или матрицу векторов. Для нового опыта использовать отдельную копию каталога и пустой приватный рабочий каталог, задаваемый RUN в inputs.py.

Из каталога bounded_dense последовательно запускать:

    python -B inputs.py
    python -B verify_inputs.py
    python -B retrieve_blocks.py plan
    python -B common_support.py plan

Первые три команды подготавливают таблицы точных текстов, проверяют их и фиксируют план прогнозов. Вторая проверяет контрольные суммы проекций, фактические UTF-8 срезы, их повторную токенизацию и ключи SQLite. Четвёртая фиксирует вторичный анализ. На GPU с настройками trained_rank выполнить:

    python -B -u retrieve_blocks.py encode

После появления encoding-cost.json остальные стадии выполняются на CPU. В исходном прогоне OPENBLAS_NUM_THREADS=1, RAYON_NUM_THREADS=2, PYTHONUTF8=1. Стадии:

    python -B retrieve_blocks.py predict
    python -B evaluate_blocks.py
    python -B common_support.py score
    python -B index_cost.py

forecast-seal.json фиксирует списки прочитанных координат до присоединения gold. evaluate_blocks сверяет все BM25-предсказания по метрикам и бюджету с write_learned. index_cost последовательно проверяет размерность, конечность и норму физически записанных векторов. Битовая идентичность логов времени и двоичного отпечатка векторов при смене устройства или ПО зависит от среды. Источником для новых кандидатных скорингов выступает только фактически оставшийся текст блоков. Короткие вопросы добавляются отдельными строками с префиксом «query: ».
