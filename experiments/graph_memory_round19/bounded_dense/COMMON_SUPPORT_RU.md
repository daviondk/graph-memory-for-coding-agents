# Разбор результата по сохранности доказательств

Дополнение задано во время кодирования, до открытия новых результатов. Для test и dev делим все запросы по двум бинарным признакам — полный комплект физически сохранился у full и у output_head. Для каждой из четырёх клеток показываем число запросов, число полных ответных комплектов для каждого читателя и сумму выигрышей/проигрышей. Точное тождество: разность итоговых попаданий равна сумме четырёх поклеточных разностей. Разбиение использует gold и служит описанием механизма. Общая клетка «сохранилось у обоих» позволяет увидеть потерю на этапе поиска. Задачи у политик не меняются. Dev-500, участвовавшие в выборе encoder checkpoint, и оставшиеся dev-80 отражаются отдельно; эти 80 могут делить траектории с dev-500. Интервалы и основная гипотеза остаются как в первичном протоколе.
