# Почему запись перед чтением улучшила полноту BM25

На всех **2 000** тестовых запросах чтение из полной истории дало **831** полный комплект источников. При сохранении только выбранных обученным скорером блоков и сохранении прежних рангов BM25 результат вырос до **976**. Перестройка BM25 на оставшихся данных дала **979**. На полном dev аналогичная последовательность составила **258 → 296 → 292** из 580. Прирост преимущественно объясняется тем, какие кандидаты допускаются к чтению при фиксированном бюджете. Обе проверки оставляют статистическую неопределённость относительно отдельного влияния перестройки корпуса BM25. [Результаты](results.json) · [Протокол проверки](PROTOCOL_RU.md)

В B и C хранятся точно одни и те же записи из опыта write_learned (до 8 192 токенов). Во всех трёх условиях выбираются только целые блоки при предельной цене чтения 2 048 токенов. Оценивание относится к доступности размеченных исходных символов. У B прежний рейтинг берётся из полной истории, поэтому B используется как офлайн-контроль механизма. Пара B−A учитывает одновременно отбор допустимых блоков и восполнение освободившегося бюджета следующими доступными блоками. Пара C−B дополнительно меняет статистику слов и нормировку длины в BM25. Интервалы — парный bootstrap по 1 207 test- и 352 dev-траекториям, 10 000 выборок. Точечные эффекты аддитивны по каждому вопросу; интервалы трёх величин по отдельности не складываются. Нижняя граница общего эффекта по Coverage на dev равна примерно −0,0027 п.п. У части отдельных вопросов перестройка помогла, у других ухудшила результат. Эти данные не позволяют считать её бесполезной для любого запроса или другого читателя.

Диагностика ретроспективная: исход общей пары C−A был известен до постановки B. Перед оцениванием по исходным записям заново получены точные прежние списки прочитанных блоков в A и C для всех 2 580 вопросов. Для B заранее зафиксирована только одна политика. Между B и C состав прочитанных блоков изменился в 633/2 000 test и 180/580 dev-запросах. Частые изменения состава оказались совместимы с малым средним вкладом в метрики.
