# Воспроизведение

Изолированная папка использует замороженные результаты online_write, write_learned и write_transfer. Для offline-проверки по сохранённым блокам, source spans и авторским меткам достаточно Python стандартной библиотеки и указанных соседних каталогов, включая сверенную разметку test из предыдущего раунда. Команда `python -B verify.py` пересчитывает полноту, покрытие и токены всех A/B/C. Она также проверяет хеши и поштучное сложение эффектов в целых эталонных символах. [Манифест](MANIFEST_SHA256.json)

Для повторного полного исполнения исходные частные test- и dev-проекции должны находиться там же, где для write_learned. Ранние входы восстанавливаются по инструкциям его пакета. Из рабочей копии, исходя из CPU-окружения D:/CodexResearch/x20-isetrace-runtime/venv/Scripts/python.exe, выполнить сначала `python -B pipeline.py lock`, затем `python -B pipeline.py predict`, затем `python -B pipeline.py score`. Список достоверных входов в design.json задаётся относительно родительского каталога раунда. Пересчёт SHA в самостоятельно воспроизведённой копии: `python -B verify.py --write-manifest`. [Входы и алгоритм](pipeline.py) · [Среда источника](../write_learned/REPRODUCE_RU.md)

Исходные рейтинги строятся той же реализацией BM25Okapi с тем же content_tokens, адресацией и разрешением ничьих, что базовый опыт. Сначала проверяется равенство восстановленных A и C прежним спискам; B применяет исходный read_diagnostic.pack, пропускающий отсутствующие кандидаты и записи, выходящие за оставшийся бюджет. После сохранения всех 16 архивов B и фиксации их SHA этап оценки использует нативный scorer и независимый расчёт пересечений символов. Полный рейтинг/история используется только для диагностики. Все новые выходы находятся в текущей папке.
