# Воспроизводимость

Решения обоих эмбеддеров считаются отдельно. Источник рангов каждого проверяется через собственный forecast-seal; для обучаемого варианта требуется закрытый отчёт предсказаний R19/trained_rank. Ранги frozen E5 находятся в R18/isetrace_e5. Родительские узлы принадлежат авторскому представлению provenance units. Для лексического ранжирования фрагментов используется уже проверенная по сводному SHA проекция текстов D:/CodexResearch/x20-isetrace-e5-gpu/cache/projection, а разделение на исходные блоки берётся из зафиксированного R19/online_write. В открытых файлах есть координаты, стоимость и решения, сырые тексты остаются только в исходном частном кеше. Воспроизведение не требует GPU и обучения весов.

Команды на Python из x20-isetrace-runtime/venv, при штатном расположении путей:

```powershell
$env:OPENBLAS_NUM_THREADS='1'
python -B tail.py lock
python -B tail.py predict frozen
python -B tail.py score frozen
python -B tail.py predict trained
python -B tail.py score trained
python -B explain.py frozen
python -B explain.py trained
python -B report.py
python -B verify.py
```

Штатный span-оценщик проверяет каждое решение на координатах исходных событий. Для независимой проверки в присутствии соседних подписанных архивов достаточно стандартной библиотеки и `python -B verify.py`. Она пересчитывает число полных комплектов, покрытие, плотность и реальную стоимость по каждому вопросу. Перепроверяются принадлежность каждого мелкого блока исходному узлу, совпадение его границ с подписанным разбиением и отсутствие пересечений с общими целыми узлами. Для сверки одной модели выполните `python -B verify.py frozen` или `python -B verify.py trained`.

Равный ранг разрешается в хронологическом порядке событий и начальных координат. При варианте B глобальный BM25 score используется как второй ключ после минимального ранга родителя. Для C берётся глобальный ранг этого score с фиксированным разрешением равенств. Дубли внутри крупных узлов оплачиваются полностью. Расход на внутренний лексический доступ отличается от выдаваемых агенту токенов. Подробные промежуточные оценки доступны в `frozen-results.json` и `trained-results.json`.
