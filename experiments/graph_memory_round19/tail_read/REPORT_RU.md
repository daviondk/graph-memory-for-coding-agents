# Чем заполнить остаток бюджета чтения после извлечения связанных свидетельств

Две модели независимо ранжируют исходные аргументы и результаты инструментальных вызовов в тех же 2 000 вопросах ISETrace. Все методы сохраняют рекомендованный моделью префикс целых узлов. Контроль related затем поднимает целые фрагменты противоположной роли из вызовов префикса и добирает остальные целые узлы. Альтернативы удерживают префикс и помещающихся партнёров и заменяют только последнюю стадию блоками около 64 WordPiece-токенов. Каждый такой блок целиком принадлежит ранжированному исходному узлу. **frozen E5-base-v2.** После общего префикса и целых связанных узлов оставалось в среднем 88.2 токена. Основной B дал 1146 полных комплектов против 1162 у контроля. Вариант C, объединяющий ранги крупного родителя и лексическую позицию мелкого блока с RRF60, дал 1166 комплектов. Его Coverage — 65.80% против 64.82% у related.

Первичная проверка — B−related по Full Support. A и C были указаны до запуска, результаты по обеим метрикам и обоим эмбеддерам приведены целиком. Полное покрытие эталона чувствительно к потере последнего необходимого символа. Переход на мелкую единицу может повысить число попавших в контекст символов и одновременно исключить целый крупный фрагмент. Интервалы описательные, кластерный bootstrap по 1 207 траекториям, 10 000 выборок. Публикационный trained baseline усредняется по пяти seed; здесь сравниваются методы упаковки на одном локально обученном ранжировщике.

Блоки покрывают все исходные события, для которых выпущены PU. На каждую оценку предвычисляется локальная статистика BM25 по всем мелким блокам текущей траектории, что несёт дополнительные издержки CPU и хранения индекса. Доставка текста ограничена 2 048 токенами. Ранее перекрывающиеся PU в авторском префиксе и его целых партнёрах оплачиваются по цене каждого узла. Мелкие блоки попарно неперекрывающиеся и не дублируют их исходные символы.
