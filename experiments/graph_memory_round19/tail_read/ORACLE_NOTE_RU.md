# Диагностика потерь после смены гранулярности

После получения результатов frozen E5 и до раскрытия сравнений Dense-FT фиксируем диагностическое разложение. Решения всех методов и их результаты остаются прежними. На этапе анализа снимаем из эталонных интервалов символы, уже покрытые общим core. Оставшиеся символы имеют единственное покрытие опорными неперекрывающимися мелкими блоками данной траектории. Если требуемый блок пересекает core, отсутствует среди целиком лежащих в одном PU или если между известными блоками остался пробел, полная поддержка недостижима в новом представлении. В ином случае сумма полных стоимостей требуемых блоков — минимальный расход для покрытия остатка. Сумма выше остатка бюджета также исключает полное покрытие. При соблюдении ограничений существует выбор с полным покрытием, но ранжировщик может его не сделать. При частичном пересечении исходного мелкого блока с уже выбранной крупной единицей отбрасывается весь мелкий блок по первоначальному протоколу.

Цель — указать, какая часть потерь B на вопросах, где целоузловый related достиг полной поддержки, объясняется ранжированием и какая частью условий представления/бюджета. Дополнительно показываем число достижимых запросов среди всех 2 000. Оптимум использует эталон, служит потолком возможностей, не входит в сравниваемые методы и не поступает агенту.
