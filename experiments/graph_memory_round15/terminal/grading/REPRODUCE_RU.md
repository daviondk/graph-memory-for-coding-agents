# Воспроизведение оценщика

Для пересчёта сводки по сохранённым оригинальным ответам и подготовленным эпизодам служит `python -B summarize.py`. Скрипт проверяет манифест каждого эпизода, фактические байты патчей, записи исполнения Docker, соотношение SHA и выбор по зарегистрированной политике.

Для нового исполненного прогона используйте отдельную копию и новый путь PRIVATE в grade.py, либо сохраните старые результаты и укажите новый каталог вывода. В исходной Windows-среде выполнены команды:

```powershell
D:/CodexResearch/x20-official-vibe/solver-runtime/agent-venv/Scripts/python.exe -X utf8 -B grade.py controls
D:/CodexResearch/x20-official-vibe/solver-runtime/agent-venv/Scripts/python.exe -X utf8 -B grade.py models
python -B summarize.py
```

Нужны тот же публичный VibeMemBench с исходным test.parquet и scripts/vendor, мост ../.. из R12/vibe/grading по путям grade.py, включённый WSL Docker без сети у оценочных контейнеров и проверяемые локальные образы из ../cohort.json. Идентичные байтовые патчи одной и той же задачи в этом новом запуске оцениваются один раз. При повторном запуске код проверяет архивные хеши и заново разбирает сырой вывод тестов, не расходуя ещё один контейнер. Записи в grades содержат точные байты входных патчей в gzip, оригинальный отчёт, результат по тестам и журналы выполнения. Оригинальные оценочные JSON со штатными тестовыми патчами живут отдельно в D:/CodexResearch/x20-r15-evaluator-inputs. Исходный код, пины и контрольные суммы каждой спецификации собраны в [environment.json](environment.json). [План проверки](PROTOCOL_RU.md) · [Политика и источник траекторий](../PROTOCOL_RU.md)
