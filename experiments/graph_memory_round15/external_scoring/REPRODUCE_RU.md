# Повторная оценка ранних наблюдений

В `views-seal.json` приведены SHA-256 исходного архива, протокола, кода и прогнозов до просмотра внешней разметки. В `external-scores.gz` находятся записи по задаче и каждому из четырёх способов выдачи. `results.json` хранит агрегаты и парные интервалы. Аудит первого родительского коммита содержит перечисление 45 задач с подтверждённой базой. [Аудит ревизий](REVISION_AUDIT_RU.md)

Чтобы заново получить прогнозы и вызвать авторскую оценку, используйте отдельную рабочую копию. Рядом должны находиться исходные записи R3, R5/R6 и R11. Проверяемые имена и контрольные суммы перечислены в `native.py` и `graph_memory_round11/readback/input-lock.json`. Исходные материалы бенчмарков закреплены по ревизиям в `inventory.py` и `native-source.json`. Для запуска нужны Python, pyarrow и доступ к указанным публичным источникам либо тот же локальный кэш.

```powershell
$env:PYTHONUTF8='1'
python -B inventory.py
python -B views.py
python -B native.py
```

Поле `base_equal` в IssueLoc сравнивает архив с полем `commit_sha` метки. Для оценки по базе сборщика отберите идентификаторы из аудита первого родителя. В SWE-Explore используется база SWE-bench Verified, которую разрешает авторский скрипт `build_commit_map.py`. [Интерпретация метрик](REPORT_RU.md)
