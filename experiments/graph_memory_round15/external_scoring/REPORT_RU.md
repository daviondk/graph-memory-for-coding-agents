# Память о первых чтениях кода под ограничением в 60 строк

Зафиксировали четыре политики отбора уже наблюдавшихся строк до открытия внешних меток. Для каждой задачи доступны первые три чтения редактора и не более 60 строк памяти. Из 199 архивных задач в SWE-Explore нашлись 179, из которых 79 содержали распознанное чтение. Пустые предсказания входят в общий знаменатель. Проверка SWE-bench Verified подтвердила базовую ревизию всех 179 архивных задач. Использованы опубликованные функции оценки в закреплённых ревизиях. [Протокол](ARCHIVED_VIEWS_RU.md) · [Хеши прогнозов](views-seal.json) · [Код внешней оценки](native.py)

| Как выбрать сохранённые строки | SWE-Explore precision | recall | F1 |
|---|---:|---:|---:|
| Первый просмотренный файл в приоритете | 0,3480 | 0,0471 | 0,0730 |
| Последний просмотренный файл в приоритете | 0,2976 | 0,0327 | 0,0517 |
| По числу повторных чтений | 0,3134 | 0,0343 | 0,0545 |
| По числу повторов и общим идентификаторам | 0,3190 | 0,0341 | 0,0543 |

Разница precision между графом и давностью составила +2,14 п.п. (описательный 95% кластерный bootstrap по девяти репозиториям от +0,38 до +5,37 п.п.). Контроль с приоритетом первого файла оказался сильнее обоих. На 147 траекториях Kimi порядок по precision сохранился. В обеих политиках читаются только строки, которые агент уже видел. При лимите трёх просмотров преимущество раннего файла может отражать удачную навигацию исходного агента или особенности аннотации региона. Неполное покрытие просмотров и зависимость от семейства траекторий ограничивают перенос. [Метрики по панелям](results.json) · [Исходный SWE-Explore](https://github.com/Qiushao-E/SWE-Explore-Bench)

Второй пересчёт использовал IssueLoc. По repo и номеру PR совпали 198 задач, из них 91 с чтением. По этой широкой группе Hit@1 составил 59/198 для первого файла, 54/198 для последнего, 58/198 для повторных чтений и 58/198 для графа. В поле base_equal выходного файла для IssueLoc выражено исключительно прямое равенство с commit_sha. Скрипт построения официального дерева использует его первого родителя. По отдельной проверке на 45 задачах архивная база совпала с этим родителем. На них Hit@1 составил 11/45 для первого файла, 13/45 для последнего и 14/45 для графа. Hit@3 всех трёх политик равен 16/45. Такая смена порядка показывает чувствительность к версии и составу задач. Два пересчёта оценивают выдачу памяти после наблюдений. Полноценный поиск агента на всём официальном наборе и вывод о лидерстве требуют отдельного эксперимента.
