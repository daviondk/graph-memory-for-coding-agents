# Проверка вклада записи

После раскрытия основных результатов добавлен диагностический контроль. При сравнении с прежним view_graph одновременно меняются доступный пул и формула оценки. Поэтому у уже зафиксированного typed_union удаляем все новые адреса, сохраняя порядок прежних. Это измеряет, сколько конкретно купленных слотов в фиксированном ранжировании помогли или вытеснили цель. Дополнительно применяем исходную формулу flat_union к прежнему пулу, заново считая BM25 и давность в отсутствие новых кандидатов. Сравнение с ней показывает вместе эффект записи и изменения внутрименюшной статистики при добавлении новых документов. Параметры, состав задач и исходы совпадают с основной фиксацией. Результат описательный, отдельной независимой проверкой этой диагностики пока не располагаем.
