# Интерактивное обслуживание графовой памяти при совместном изменении источников

В демонстрации «Two sources» собрано 1 862 выбранных сочетания двух источников из 40 проекций ISETrace. Посетитель задаёт две независимые поправки и видит три контрфактических результата — для каждой поправки по отдельности и для обеих вместе. В примере q03 повышение каждой оценки на 0,0625 по отдельности оставляет пакет 352, а совместное изменение выбирает пакет 355. Независимая кнопка пересчитывает полный упорядоченный набор из исходных стоимостей, полезностей и принадлежности единиц источникам. Цветовая карта дискретизирует плоскость весов для показа. Сервер отвечает по точным целочисленным параметрам Q32. Все примеры работают локально. [Индекс и исходные измерения](../joint_packets/REPORT_RU.md) · [Проверка области безопасного повторного использования](../joint_certificate/REPORT_RU.md)

Рукопись описывает применимость метода к материализованному контексту агента, доказательство критерия удаления источников, механизм двухкоординатной выдачи, обучение выбора фрагментов и пределы ускорения при повторении параметров. Проекции и исходы удаления либо смены весов отделены от наблюдаемых изменений кода и реальных связей происхождения данных. В отдельном эксперименте измерена частота совместных изменений источников. [Стоимость построения при первом обращении](../cold_queries/REPORT_RU.md) · [Наблюдаемая нагрузка](../observed_updates/REPORT_RU.md) · [Четыре страницы с литературой](paper.pdf)

В комплекте четыре локальных сервера SQLite и видео с десятью сценами из этих серверов, английской речью и общей длительностью 148,8 с, 3 005 233 байта. Проверены 37 файлов в ZIP (включая внутреннюю опись), контраст 352 → 355, также границы диапазона и полный пересчёт. Проверка в браузере при ширине 390 и 1 040 пикселей включает выбор точки на карте, возврат к примеру и независимый аудит. Все четыре страницы PDF отрисованы, видеодорожка H.264 и аудиодорожка AAC прочитаны полностью. Имена и аффилиации авторов заполняются перед подачей. [Состав и запуск](README.md) · [Проверка сборки](build-check.json) · [Требования демотрека](https://icde2027.github.io/cf-demonstrations.html)

`python -B verify.py` проверяет комплект и запускает API четырёх серверов. Для повторной упаковки служит `python -B package.py`.
