# Воспроизведение

Для числовой проверки этого каталога достаточно Python 3.11+ с NumPy и команды `python -B verify.py`. В комплекте есть 315 полных индивидуальных выдач всех политик, ordinals кандидатов и их стоимость, четыре предсказанные ролевые вероятности, вероятности потребности и union, результаты по каждому запросу, разбиения и модель. Алгоритм заново строит 5 290 полных обученных и контрольных выдач, проверяет 7 204 записи исходов, расходы, значения девяти показателей и отдельно интервалы для основного и двух отмеченных вторичных контрастов. [Манифест](manifest.json)

Для повтора обучения и предсказания нужны Python, NumPy, scikit-learn и соседние каталоги R34, R45 и R46. Официальный SERBench SDK и Cal500 лежат в `work/memory_session5/serbench/upstream`. Нужен прежний локальный кеш точных Qwen-токенов по инструкции R45 и словарь Qwen в GGUF, указанном в features.py. Служебная матрица извлечённых признаков сохраняется на D за пределами этого пакета. Архив использует 109 признаков документа в контексте запроса и 56 для оценки потребности в роли. Хеш исходной строки проверен для всех 13 358 уникальных текстов, целиком уместившихся в 511 токенов; для длинных используется декодированный префикс. Никаких действий из собранных траекторий программы не исполняют. [Исходная токенизация](../../graph_memory_round45/qwen_panel214/MATCHED_INPUT_RU.md)

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B features.py
python -B fit_predict.py
python -B evaluate.py
python -B verify.py
```

Полный повтор выполняют в новой копии каталога с перенесённым отдельно исходным manifest.json. Выполнение fit_predict.py повторно измеряет время, из-за чего меняются хеш печати и зависимые хеши отчёта. R46 даёт заранее измеренные Qwen/DPP/MMR только для отложенных 214 состояний. Файл ordinal-judgments публикует только ординальные допустимые множества для калибровки и цену. Разметка для dev и test используется в evaluate.py после фиксации прогнозов. [Код получения прогнозов](fit_predict.py) · [Код проверки](verify.py)
