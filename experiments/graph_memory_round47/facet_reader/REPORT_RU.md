# Как выбирать из памяти свидетельства для следующего шага кодового агента

**Основная гипотеза не подтвердилась.** На 204 запросах из 69 репозиториев динамическое покрытие предсказанных ролей дало 89 полных наборов среди первых пяти фрагментов. Статическое ранжирование с теми же вероятностями дало 90. Разность составляет −0,49 п.п., 95%-й интервал по репозиториям [−4,57; +3,48]. Состав первых пяти изменился в 157 состояниях. В восьми случаях появился достаточный набор, в девяти он исчез. Перестановка ролей при неизменной индивидуальной цене фрагмента дала 92. Результат не поддерживает объяснение через смысловую согласованность названий ролей. [Исходы и интервалы](results.json) · [Протокол](PROTOCOL_RU.md)

**Наиболее перспективный результат дал простой контроль.** Логистическая регрессия училась распознавать фрагменты, входящие хотя бы в одну обязательную группу. Она получила 109 доступных признаков, включая совпадения имён объявлений и вызовов с тремя полями запроса, совпадения пути, признаки теста и контекст BM25. Нормированное предсказание линейно добавляется к 1/√rank Qwen с фиксированным весом 0,65. При одинаковой отсрочке просмотренных фрагментов MSS@8 увеличился с 114 до 131 из 204, разница +8,33 п.п. [3,24; 13,49], 22 выигрыша и 5 потерь. При меньшей глубине MSS@5 разница +3,43 п.п. [−2,70; 9,19]. Без отсрочки при ограничении только в 6 144 токена получили 146 против 127, +9,31 п.п. [3,70; 15,15]. Средний расход в этом сравнении 5 869 против 5 868 токенов, среднее число единиц 13,19 против 12,99. При фиксированных пяти и восьми единицах без отсрочки интервалы включают ноль. Применимость этой интерпретации ограничивают данные. На основной панели только 72/204 запроса требуют несколько различных ролевых классов. Из 100 запросов с несколькими группами у 57 хотя бы два официальных требования отнесены к одной укрупнённой роли. В срезе с несколькими ролями динамика относительно статической оценки потеряла один достаточный набор, в оставшихся 132 разность равна нулю. На кандидатах средняя точность (average precision) составляла 0,046 для поведения при распространённости 0,014 и 0,044 для локализации при распространённости 0,009. Различение ролей содержит сигнал. Надёжность оценки уже покрытых требований остаётся ограниченной. [Разметка по каждому состоянию](ordinal-judgments.json.gz)

**Проверка переноса.** Обучающая часть содержит 179 состояний, 68 репозиториев и 15 411 кандидатов. Репозитории 101 dev и 214 test образуют непересекающиеся с train и друг с другом множества. На dev, где Qwen ещё не измерялась, от одной и той же лексической выдачи получили MSS@5 11/101 для BM25, 20 для динамического покрытия, 23 для статического и 26 для единой вероятности. На полной группе 214 в связке с Qwen соответствующие основной семантический, динамический, статический и единый результаты равны 89, 96, 97 и 100. На основной группе обе обученные модели прочитали тот же текст, который подавался Qwen, и использовали обучение на размеченных состояниях из других репозиториев. [Разбиение](panels.json) · [Обученные веса](model.json)

**Граница результата.** Все положительные сравнения для одноместного метода вторичны; интервалы индивидуальные, без коррекции множественности. Исходы прежних систем на этой публичной части Cal500 уже изучались. Ранее R45 измерила 117/204 у RRF Qwen + union_cost при MSS@8 с отсрочкой, но у этих моделей другие признаки и обучение. Ни одно сравнение здесь не устанавливает результат на скрытом Test500. Приоритет для отдельной проверки — воспроизвести одноместную поправку на репозиториях, на которых ещё не измерена связка с Qwen, с замороженными весами и заранее выбранной метрикой.
