# Независимая проверка после закрытия официальной оценки

После фиксации трёх контрольных сумм и пяти результатов точного авторского оценщика выполняем вторую проверку на том же digest образа. Для пустого исходника, авторского патча и каждого из трёх анонимных патчей в новом контейнере применяем те же изменения и запускаем весь каталог штатных тестов, дополненный опубликованными авторами проверками. Собираем JUnit XML, все идентификаторы тестов и состояния. Проверяем точное совпадение статусов 16 зарегистрированных тестов с независимым чтением XML. Для остального набора вычисляем, сколько штатных тестов ранее проходило и перестало проходить, сколько восстановилось и сколько осталось пропущенными. При сбое сбора сохраняем диагностическое состояние. Общая проверка вторична и ее выбор сделан после просмотра официальных оценок. Тесты за пределами авторского контракта оценивают регрессионный профиль конкретного базового дерева.
