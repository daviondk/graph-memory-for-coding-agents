# Воспроизведение абляций

Числовая проверка запускается из этой папки командой `python -B verify.py` с NumPy. Она измеряет все 8 выдач на 315 состояниях, 9 метрик для каждой, 6 режимов потребления памяти, агрегаты четырёх панелей и основной репозиторный интервал. Файлы models.json и model-audit.json дают коэффициенты и точное соответствие каждому из 109 признаков. Манифест содержит хеши исходных файлов.

Для повтора обучения нужны числовой кеш и зависимости сортировщика R47, а также неизменённые подписанные facet_reader и facet_confirmation. Моделям доступен один CPU-поток. Время формирования эмбеддингов не входит в расходы CPU-поправки. Все этапы абляции переиспользуют готовые Qwen-оценки.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B train_model.py
python -B model_audit.py
python -B cost.py
python -B experiment.py predict
python -B experiment.py grade
python -B report.py
python -B verify.py
```

Прогнозы роли разделены на независимые файлы до и после получения Qwen для подтверждающей группы. Этап вычисления метрик требует подписанного завершения первичного подтверждающего опыта.
