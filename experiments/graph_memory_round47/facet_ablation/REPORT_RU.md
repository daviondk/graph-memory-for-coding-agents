# Что даёт обученной оценке фрагмента её преимущество

**Преимущество полной модели над структурной по заранее выбранному критерию не подтвердилось.** На 101 состоянии из 34 репозиториев с одинаковой отсрочкой просмотренного полная модель собрала полный набор среди первых восьми в **51** случаях, только свойства фрагмента — в **44**. Основная разница **6,93 п.п. [-2,91; 17,17]**, выигрышей 12, потерь 5, изменился состав выдачи в 99 состояниях. Исходный Qwen дал 46, модель совпадения с запросом — 45. |---|---|---|---|---|

Дополнительная разность признаков совпадения против свойств фрагмента на 101 состоянии составляет 0,99 п.п. [-10,20; 12,62]. После удаления свойств самого фрагмента разность полной модели и модели совпадения составляет 5,94 п.п. [1,15; 11,50]. На исходной панели из 204 состояний основная разность между полной и структурной версиями составляла 9,80 п.п. [5,00; 15,00]. Для дополнительных показателей интервалы номинальные, без поправки на множественные сравнения. [Все парные контрасты](results.json)

Роли двух наборов признаков различаются уже на уровне оценок. До открытия результатов на новых репозиториях медианная по запросам корреляция Спирмена полной вероятности с моделью совпадений равнялась 0,84, а с признаками самого фрагмента — 0,73. У двух частичных моделей в среднем общими оказались 1,49 из восьми первых кандидатов до добавления семантического ранга. Среди крупных стандартизованных коэффициентов структурной модели — индикаторы документации, тестового пути и количество строк. Эти коэффициенты измеряют ассоциацию с калибровочной разметкой при коррелированных признаках. Они не устанавливают причинную важность синтаксического свойства для решения агента. [Все коэффициенты и сравнения вероятностей](model-audit.json)

Общее число кандидатов и стоимость всегда сравниваются в одной группе запросов. Переподготовка полной модели воспроизвела ранее зафиксированные вероятности с максимальным расхождением менее 10⁻¹⁵. Для двух абляций менялся разрешённый набор признаков; и единая обучающая цель, и 179 состояний для обучения, и ранги исходной Qwen общие. Запросная абляция включает признаки запроса во взаимодействии с типом теста и числом объявлений. Она сохраняет косвенное влияние свойств самого документа. Двенадцать чисто запросных признаков присутствуют только в полной модели, поэтому отдельный вклад их группы из данного опыта не следует. [Веса и схема](models.json) · [Воспроизведение](REPRODUCE_RU.md)

При числовом входе из того же токенизатора построение всех 109 признаков заняло 3,99 с на 101 состоянии, 8800 кандидатах и 5166 разных выдержках; среднее 39,54 мс на запрос. Само применение логистической регрессии к уже готовым векторам потребовало в среднем 20,02 мкс на запрос, взята медиана семи полных повторений. Замер на одном CPU-потоке, с локальным кешем разбора повторяющихся источников. Чтение архивов, первичная токенизация, плотный поиск и построение окончательного порядка исключены. [Измерения стоимости](cost-audit.json)

Обе панели входят в публичный калибровочный набор SERBench. Подтверждающий срез расположен в других репозиториях и до фиксации протокола ещё не имел результатов для новой комбинации с Qwen. Результаты прежних методов на этих репозиториях использовались в других работах проекта. [История использования панели](../facet_confirmation/SPLITS_RU.md)
