# Что изменили четыре фрагмента унаследованной памяти на одной задаче Click

На публичной задаче `pallets__click-1915` исполнители с графовой и плоской памятью отправили побайтно одинаковый патч. Исполнитель без памяти отправил другой патч. Графовый и плоский варианты сэкономили 1 659 и 1 819 байт последующего чтения относительно ветки без памяти. Сам пакет добавил каждой по 1 856 байт. **В итоге графовая ветка получила на 197 байт больше исходных наблюдений, плоская на 37 байт больше**, чем ветка без памяти. Это одно независимое исполнение на условие в одной задаче. По нему нельзя оценить средний выигрыш по задачам или влияние выбора рёбер на качество исправления.

### Байты, полученные исполнителями

Все объёмы в UTF-8. Поиск включает фактически выданные координаты строк. Чтение учитывает только возвращённую часть диапазона. Память включает заголовки цитат. Нулевые и повторные байты учтены по факту выдачи. Общий предел дополнительного интерактивного чтения составлял 12 000 байт.

| Вход | actor-1 · graph | actor-2 · без памяти | actor-3 · flat |
|---|---:|---:|---:|
| Слепая инструкция с индивидуальным адресом | 2 228 | 2 228 | 2 228 |
| Публичная постановка из start | 1 222 | 1 222 | 1 222 |
| Память из start | 1 856 | 0 | 1 856 |
| Поисковые выдачи | 207 | 272 | 47 |
| Запрошенные фрагменты | 3 600 | 5 194 | 3 600 |
| **Интерактивные поиск и чтение** | **3 807** | **5 466** | **3 647** |
| **Память, поиск и чтение** | **5 663** | **5 466** | **5 503** |
| **Инструкция, постановка, память, поиск и чтение** | **9 113** | **8 916** | **8 953** |
| Уникальные байты самих исходников по координатам в файле с LF | 5 274 | 5 189 | 5 276 |

Две последние строки учитывают весь прикладной ответ шлюза, включая состояние бюджета, экранирование JSON, хеши и квитанции. Сумма по исполнителям равна 26 982 байтам в учёте содержания с инструкциями и 32 811 байтам в учёте инструкций с полными телами ответов. Это две границы измерения одного обмена. Точный шаблон передавался с индивидуальным именем и адресом, переводами LF и без конечных переводов строки. Постановка занимает 1 271 байт на диске и 1 222 байта после нормализации при передаче.

Шлюз сохранил декодированные запросы и ответы для каждого логического действия. Объём исходящих HTTP-запросов, заголовки транспорта, повторные обращения с ранее обработанным идентификатором, форматирование консольного вывода у клиента, системные инструкции, внутренние сообщения и число токенов модели находятся за границей этого учёта. Метрика уникального кода исключает заголовки цитат и префиксы результатов поиска, отождествляет одинаковые координаты в одной версии файла и использует LF. Все чтения и поиски предшествовали изменениям. Побайтное сравнение с чистой копией подтверждает каждый учтённый диапазон. [Ответы шлюза](./responses.json.gz) · [Полный профиль](./profiles.json)

### Подготовка общего опыта

Разведчик один раз выполнил пять ограниченных поисков по `src/click`. Семь попаданий породили семь чтений цитат, в том числе одно повторное. Шесть уникальных цитат охватывали 2 513 различных байт исходника и занимали 2 784 байта с заголовками. Фактическая связь соединяла наблюдаемое обращение к `add_command` с наблюдаемым определением. Граф выбрал цитаты 0, 1, 2 и 4. Плоский BM25 с добавкой недавности выбрал 0, 1, 3 и 4. Три из четырёх цитат общие. Отборщик применил одинаковые правила размера, перекрытия и порядка.

| Подготовительная работа | Объём в байтах |
|---|---:|
| Постановка, прочитанная для ранжирования | 1 222 |
| Полный вывод пяти процессов rg с путями и координатами | 584 |
| Из него текст совпавших строк без служебных полей | 419 |
| Извлечённые тела семи цитат с повтором | 2 931 |
| Те же семь цитат с заголовками | 3 248 |
| Постановка, вывод rg и оформленные цитаты с повтором | **5 054** |
| Суммарный объём исходников, просмотренный rg при повторе тех же запросов | 1 559 980 |
| Семь полных чтений файла Python для извлечения окон | 772 562 |

5 054 байта характеризуют содержание общей подготовительной стадии, включая повторное создание цитаты и пункты, позднее исключённые из пакетов. При раздельной тарификации этих стадий сумма по всему опыту равна 32 036 байтам (5 054 + 26 982). Такой учёт включает повторный перенос одного и того же текста между стадиями. Для измеренного процесса подготовка общая и учитывается один раз. При отдельном запуске варианта без памяти она ему не требуется. Сумма 2 332 542 байта характеризует логический поиск и чтение файлов при воспроизведении; физическое дисковое чтение зависит от кэша ОС. Затраты на копирование рабочих деревьев, контрольные хеши и работу ОС сюда не входят. [Алгоритм](./scout.py) · [Запросы, цитаты и рёбра](./scout.json)

### Действия и фиксация патчей

Все три исполнителя работали с `src/click/core.py`. Каждый начал с получения постановки, применил одну точную замену и завершил отдельным вызовом фиксации.

| Условие | Как собирались сведения после получения постановки | Изменение, байты старого → нового текста | Патч, байты |
|---|---|---:|---:|
| graph | Поиск вызовов `cmd.make_context(` и определения `resolve_command`; одно чтение строк 1643–1741 с ограничением выдачи | 55 → 55 | 502 |
| без памяти | Поиск определения `resolve_command`; два чтения 1626–1725 и 1708–1744; поиск определений `add_command`, `make_context` и обращения к `parent.default_map.get(`; одна проверка статуса | 55 → 67 | 514 |
| flat | Поиск определения `resolve_command`; одно чтение строк 1640–1730 с ограничением выдачи | 55 → 55 | 502 |

У исполнителя без памяти первое чтение также достигло лимита ответа в 3 600 байт. С учётом служебных операций зарегистрировано 6, 10 и 5 ответов в порядке actor-1, actor-2, actor-3. Все завершились HTTP 200. Патч с памятью в обоих случаях имеет SHA256 `d39a8b817bd7b95fcb65218e94a1fe868219eadad5000100f2286b52c6290d63`, без памяти — `9f2da5590f21ce39b950b9c59cd3beb957d83afaaf581abb461ab4cc2d79f440`. [Три замороженных патча](./patches)

До открытия условий независимому оценщику передали три квитанции в фиксированном порядке. SHA256 слепого JSON `e65b1db110411d36f60e528fe16c0948ae3811f0a9792d5dbd68371fe0009f82`. Владелец оценки подтвердил фиксацию всех оценок до раскрытия соответствия. Этот отчёт охватывает затраты и текст патчей. Локальный шлюз остановлен. Доступ исполнителя к собственному API изолировал шлюз; ограничение других доступных инструментов обеспечивала общая инструкция в отдельных беседах. ### Воспроизведение

В этом каталоге `python -B verify.py` стандартной библиотекой проверяет манифест, состав пакетов, опубликованные патчи и входные байты по всем полным ответам. `python -B test_gateway.py` отдельно проверяет синтетические операции шлюза. На машине первичного эксперимента `python -B profile.py` дополнительно сверяет приватные журналы с ранее переданной квитанцией и исходными фрагментами в чистом дереве, повторяет учёт разведчика и строит профили. Для этой команды нужен rg. Полные JSON-ответы публичного API сохранены с очищенными запросами на редактирование (размер и хеш старого и нового текста). Индивидуальные адреса доступа остаются в приватном хранилище.
