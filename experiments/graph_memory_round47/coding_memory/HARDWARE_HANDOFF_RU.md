# Состояние перед исполнителями

Шлюз локальный HTTP, CPU. Свежая беседа получает только текст ACTOR_PROMPT с подставленным анонимным именем и абсолютным loopback-адресом собственного endpoint. Исполнители получают одну и ту же публичную задачу через start. Имена условий отсутствуют в ответах шлюза. Три полные рабочие копии отделены физическими каталогами; API открывает только существующие файлы src/click/*.py своей копии и применяет уникальные точные замены. Другие состояния и оценщик через API недоступны. Ограничение остальных инструментов исполнителя обеспечивается инструкцией в его беседе, не системной песочницей. [Общий протокол](./PROTOCOL_RU.md) · [Точный шаблон](./ACTOR_PROMPT.txt)

Перед назначением условий общее наблюдение выполнило пять запросов к исходникам и сохранило шесть уникальных непрерывных цитат. Получена одна подтверждённая алгоритмом связь. Четыре цитаты в каждом непустом пакете занимают по 1 856 байт UTF-8. Три цитаты у пакетов общие. Это измеренный размер контраста, а не гарантия влияния на решение. Публичные файлы и точные действия разведчика доступны для последующего аудита. [Журнал наблюдений](./scout.json) · [Подпись пакетов](./packet-seal.json)

Для технической проверки нужны стандартный Python и ripgrep в PATH. Команда `python -B test_gateway.py` проверяет отдельный синтетический пример. Исходные обращения, выданные байты, изменения и зафиксированный патч каждого исполнителя сохраняются приватно. Завершающий finish выдаёт хеш и объём патча. Пока работают исполнители, скрытые условия и промежуточные патчи не раскрываются. По завершении всех трёх run `python -B freeze_check.py` без перезапуска акторов сверяет хеш каждой зафиксированной версии и собирает обезличенный лист для отдельного оценщика. Условия раскрываются только после оценки.
