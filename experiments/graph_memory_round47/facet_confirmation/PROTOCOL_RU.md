# Подтверждение фиксированной одноместной модели на других репозиториях

Документ фиксирует проверку до получения первого Qwen-ранга на подтверждающей группе. В R47 на 204 публичных состояниях заметили вторичное преимущество компактной модели. Основной показатель этого нового опыта — **Complete-MSS@8 для Qwen с обученной поправкой против исходной Qwen**, у обеих одинакова отсрочка просмотренных кандидатов. Для состояния с рангом r кандидата и вероятностью p попадания в любую обязательную группу берём 1/√r + 0,65·p/max(p). Вероятности p уже подписаны для каждого нового состояния в facet_reader до этого протокола. Сначала стабильно сортируем непросмотренных по данной сумме; общий хвост просмотренного у обеих упорядочен по базовой Qwen. Отсрочка обусловлена свойством SERBench. У эталонной Qwen с отсрочкой используется тот же порядок. Обученные веса, поля, нормировка, оператор, коэффициент, порядок разрешения равенств, токенизатор, квантизация, длина контекста и расходы сохраняются.

**Панель и ограничение независимости.** Включаем все 101 dev-состояние R34 из 34 репозиториев; пересечения репозиториев с 179 train и 204 первичными состояниями R47 пусты. Использованы ноль размеченных dev-состояний для настройки или обучения R47. Но dev уже оценивали другими системами, в том числе на новой одноимённой модели вместе с BM25 результаты известны. Эта панель является переносом в иные репозитории и первым тестом с новой фактической выдачей Qwen на них. Она не эквивалентна независимой слепой выборке из скрытого Test500. В открытом релизе SERBench не найден дополнительный удержанный набор с доступными официальными сертификатами. Подтверждающая группа и основной показатель определены после исходного положительного вторичного наблюдения. Отправки в официальный сервис не производятся. [Предыдущий эксперимент](../facet_reader/REPORT_RU.md) · [Аудит открытого релиза](../../graph_memory_round46/set_reader/REFERENCES_RU.md)

**Исполнение.** Один заранее фиксированный контрольный запрос из первого элемента старого R45 panel.order используется только для сверки токенизации, чисел Qwen и порядка top-8. Для воспроизведения на одном физическом GPU выполняем тот же process_state из R39, GGUF Qwen3-Embedding-8B-Q4_K_M, llama.cpp, 511 исходных токенов плюс EOS, нормированные 4 096-мерные векторы, косинусная близость. Все 101 состояния обрабатываются в заранее определённом порядке хеша. Полные списки предсказаний сохраняются до обращения к исходам. Чистый CPU-режим или другое квантование не заменяют заявленный GPU.

**Анализ.** Основной контраст — замаскированный union минус замаскированная Qwen на MSS@8; успешное подтверждение положительного выигрыша требует положительной нижней границы 95%-го интервала. Публикуем микроэффект, интервал 20 000 парных перевыборок целых репозиториев (seed 471018), macro, число выигрышей и потерь и фактический расход токенов. Остальные показатели вторичны: MSS@5, полнота групп, взвешенная полнота, два лимита 2 048/6 144 с глубиной до восьми и без неё, те же контрасты без отсрочки. Подпанели по результату не отбираем. Публикуем результаты также при нулевом или обратном эффекте. [Проверяемая формула](../facet_reader/PROTOCOL_RU.md) · [SERBench](https://arxiv.org/html/2609.20050v3)
