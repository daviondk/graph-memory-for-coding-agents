# Проверка одноместного читателя на других репозиториях

**Критерий подтверждения преимущества не выполнен.** В 101 состоянии из 34 других репозиториев одноместный читатель с отсрочкой просмотренных фрагментов собрал полный набор среди первых восьми в **51/101** случаях, одиночный Qwen с той же отсрочкой — **46/101**. Парная разница **4,95 п.п. [-1,91; 11,83]**. В 10 случаях полный набор появился, в 5 исчез. Состав выдачи из восьми фрагментов изменился в 98 состояниях. Макроразность при равном весе каждому репозиторию 7,75 п.п. [-1,42; 18,28]. [Протокол](PROTOCOL_RU.md) · [Все состояния и исходы](outcomes.json.gz)

Исходный результат, который мотивировал проверку, составлял 131/204 против 114/204 на других 69 репозиториях (+8,33 п.п. [3,24; 13,49]). Сравниваемые регрессия, её вероятности на 101 состоянии и вес 0,65 заморожены до этого прогона. В подтверждении заново получили полный порядок Qwen для нового набора. Модель ранжирования обучалась на 179 состояниях из 68 других репозиториев. На обеих панелях сохраняется одинаковая индивидуальная стоимость фрагмента и одинаковый способ отложить просмотренное. Выполнено локальное GPU-ранжирование 8,800 кандидатных записей. Время измеренных 101 кодирований 13,81 мин, входных токенов 3,432,204. Qwen3-Embedding-8B Q4_K_M отработала на RTX 3090. Одно повторно закодированное контрольное состояние R45 имело те же длины и top‑8, максимальное абсолютное расхождение косинусных оценок — 0. Контроль не входит в 101 оценённое состояние. Эталонная функция SERBench сверена для 808 префиксов. [Контроль аппаратного повтора](anchor.json) · [Воспроизведение](REPRODUCE_RU.md)

Обобщение ограничено публичным Cal500. В этой новой связке Qwen не измерялась ранее на 101 состоянии. Иные методы уже сравнивались на них, в том числе R47 с BM25, и направление следующей гипотезы выбрано по результатам предыдущей панели. Отложенные репозитории дают отдельную проверку переносимости при фиксированных параметрах. Эксперимент измеряет чтение памяти из кандидатного пула в зафиксированном состоянии. Обновление графа во времени и успешность решения задачи требуют отдельных экспериментов. Результат на закрытом Test500 и сравнение с официальным лидером остаются открытыми.
