# Воспроизведение подтверждающего эксперимента

Переносимая проверка чисел требует Python 3.11+ и NumPy. Из этого каталога выполните `python -B verify.py`. Программа восстанавливает все четыре ранга из индивидуальных косинусов и предсказаний, считает 9 метрик, стоимость и число единиц на шести префиксах и 18 кластерных интервалов. Для подтверждения неизменности вероятностей из первого опыта при наличии соседнего каталога facet_reader можно дополнительно сопоставить поле p каждой записи predictions.json.gz с полем union для того же идентификатора из предыдущего predicted-roles.json.gz. [Код проверки](verify.py) · [Первичная модель](../facet_reader/model.json)

Для аппаратного повтора нужны работающая исходная копия каталога work с [R39](../../graph_memory_round39/author_baseline/), [R45](../../graph_memory_round45/qwen_panel214/) и [первым R47](../facet_reader/), тот же локальный llama.cpp и GGUF Qwen3-Embedding-8B-Q4_K_M, а также CPU-пакеты NumPy и requests. Готовые данные R45 и R47 проверяются по SHA-256. Исходный SERBench располагается в work/memory_session5/serbench/upstream. На RTX 3090 запускался один локальный сервер с четырьмя слотами. Код проектов и команды из траекторий не исполняются. Состояния служат только входом модели. Сервер слушает 127.0.0.1.

```powershell
./gpu.ps1
python -B evaluate.py
python -B report.py
python -B verify.py
```

Скрипт gpu.ps1 предварительно захватывает тот же локальный mutex, что другие GPU-эксперименты. Счётчик, длительность и хеш аппаратного журнала зависят от выполнения. Повторять следует в копии каталога с отдельно сохранённым исходным манифестом. Покомпонентные контрольные суммы неизменяемых квитанций лежат в forecast-seal.json; полные локальные контрольные точки можно безопасно переиспользовать при идентичной подписи входов. Для аппаратного повторения с нуля укажите пустой отдельный каталог квитанций при сохранении исходника и отпечатка ранее использованной конфигурации. Посылка прогнозов во внешний сервис не нужна.
