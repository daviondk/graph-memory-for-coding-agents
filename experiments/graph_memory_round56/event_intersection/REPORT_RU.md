# Точные границы совместной частоты по двум неполным историям

Каждая многофайловая правка получает общий порядковый номер. Для каждого пути сохраняются полное число таких правок и последние B номеров. Если более поздний из первых полностью видимых моментов равен c, то после него известно точное пересечение z. До c известно число участий каждого файла, r₁ и r₂, в общей вселенной из c позиций. Возможное полное пересечение лежит между z + max(0, r₁ + r₂ − c) и z + min(r₁, r₂).

Для фиксированных двух сводок эти границы достижимы. У файла, задающего границу c своим усечённым списком, ранние позиции можно выбрать произвольно при заданном количестве. При фиксированном допустимом префиксе второго файла это даёт каждое целое значение между границами. Когда обе истории полностью видны, остаток пуст. Полным перебором множеств размера вселенной до 8 проверены 262 143 пары входов с учётом бюджета и 59 557 различных пар сводок. Это теоретическая точность при информации из двух списков. На длинной панели адресная проверка затронула бы 193 292 позиции меньших списков. Прямой проход затронул 89 741 участника. В прогретом SQLite WAL суммарное медианное время по 196 запросам составило 304,19 мс с суффиксными границами и 16,83 мс при одном чтении упакованных эпизодов для известного файла. Метод показывает, какие баллы определены неполными сведениями. В данной реализации сканирование сводок всех кандидатов стоит дорого.
