# Точная выдача из оперативной памяти и архива SQLite

До измерения времени фиксируем все запросы B (880) и long (196), объём последних событий на файл B=8 для сравнения владельцев и общий суффикс из 25 номеров для адресных пересечений. Измеряем все стратегии на одной ревизии каждого запроса. Общие справочники путей, текущие вторичные ключи и девять лучших по частоте для заполнения нулевых мест уже доступны. Политики возвращают те же восемь ID с точными баллами. Холодный в названии слоя обозначает логически вытесненные события; испытание проводится при прогретой базе.

Сравнения: единичный GROUP BY по двум индексам membership, одно чтение упакованных эпизодов по якорю, материализованные пары в SQLite, точные битовые векторы в RAM, адресное уточнение суффиксных границ в SQLite, последние восемь собственных эпизодов с дочитыванием префикса, все разделяемые эпизоды с дочитыванием только полностью вытесненных. Для двух последних политик равны физическое содержимое горячего хранилища, обслуживаемые запросы и возвращаемая информация. Отличаются использование общих ссылок и организация архива. На стороне обновления для полностью вытесненного события требуется записать эпизод и инцидентных участников в слой архива. Учитываем объём логических записей отдельно. Для простого собственного окна весь исходный журнал хранится в долговременной БД. Для общего варианта оперативная часть предполагается уже доступной. Восстановление после аварии потребовало бы и долговременной копии оперативного состояния.

Пять проходов по каждому запросу с детерминированной перемешанной очередностью стратегий, seed 56031. Публикуем медиану пяти сумм времени по запросам, число реально выполненных SQL-запросов, число возвращённых элементов и байты полезной нагрузки упакованных эпизодов. RAM и SQLite в локальном WAL проверяем отдельно. Все эталонные проверки и подготовка входа вне измерения. Полное время операции включает подготовку результата внутри стратегии. Подготовка общих вторичных ключей, запись изменений, запуск процесса и холодный старт не входят в эти отрезки времени. Эти измерения не дают утверждения о времени полной работы агента.
