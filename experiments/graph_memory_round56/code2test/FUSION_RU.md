# Дополнительное объединение сигналов

До вычисления результатов на этой панели регистрируем отдельную политику ранжирования, предназначенную для случаев, когда граф указывает на тест уже в shortlist исходного поиска. В основном опыте R55 бóльшая часть потенциально полезных связей могла быть потеряна из-за разрешённой только пятой позиции.

Для каждого адреса сначала оставляем тестовые файлы по общедоступному классификатору роли. Объединяем полученные порядки Qwen3-4B, Lexical и RepoMap с порядком совпадения имён (равные голоса 1/(10+r), r=1..20). Это сильный исходный контроль без графа. Контекст в графовой политике содержит до восьми предыдущих мультифайловых событий на один указанный файл. Голос истории добавляем только тестовым кандидатам, связанным с реализацией: сумма их исторических голосов определяет сортировку дополнительного списка, его вклад ограничен одним таким же ранговым голосом. Match по имени или поддержка двух других методов не нужны для попадания в этот список. В качестве того же четвёртого/пятого голосования проверяем частоту файлов из всего префикса без условия на исходный файл, независимый Qwen3-8B, всё историческое окно из 64 коммитов и порядок совпадения имён сам по себе. Публикуем все результаты, включая нулевые и отрицательные. Дополнительная проверка выявит, связано ли изменение качества с историей или просто с дополнительным источником рангов. Параметры r/число голосов фиксированы до доступа к разметке; тесты на открытых проектах требуют отдельной прогонки решателя.
