# Независимая проверка SQL для символов

После запечатывания анонимных назначений для 2 696 случаев и до расчёта агрегатов качества добавляем контроль реализации внутри настоящего SQLite. С фиксированной солью «r41-ast-sql/» ранжируем идентификаторы по SHA-256. Берём первые 32 события из удержанных задач и первые 32 из оставшихся. Повторно извлекаем AST только для этих 64 событий, восстанавливаем канонические имена как хеши квалифицированных имён, каждому кандидату присваиваем реальный кодовый тип CODE_OBSERVATION. В исходный SemanticStore.advance_workspace_revision передаём имена именно изменившихся сущностей; при ошибке разбора — единственный ID изменённого файла. В новой чистой SQLite сверяем набор отозванных единиц с ранее запечатанной политикой. Включаем исходные выбранные блоки изменённого и других файлов. Если старый пакет пуст, отдельно записываем отсутствие блоков для SQL. Этот тест проверяет соответствие реализации для реальных идентичностей символов. У него нет независимого эффекта по качеству.
