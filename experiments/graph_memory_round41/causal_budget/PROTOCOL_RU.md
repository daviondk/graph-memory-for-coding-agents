# Читаем ранее накопленную память в середине работы агента

Проверяем главный открытый вопрос R39/R40. Способна ли бюджетная сборка с обученными полезностями улучшать чтение, если состоянием графа и кандидатами являются только наблюдения к моменту запроса? Обычный тест ISETrace показывает завершённые истории. В этих вопросах уже известны итоги ранее предложенного читателя R22 и конечная точка для R39. Новые прогнозы R39 по ходу истории не подсчитывались.

Используем все 2 000 исходных вопросов из 1 207 траекторий и заранее фиксированные срезы R22 по 25/50/75/100% завершённых пакетов вызовов инструментов. Основная популяция — ранее отложенные от R21 пилотных траекторий вопросы в середине истории, на которых все эталонные адреса уже доступны (901 вопрос, 657 траекторий). Доступность эталона вычислена внешним оценщиком и не передаётся ни одной политике. Вопросы написаны по полным историям; время запроса моделируется. Интересующий основной исход — Full Support при 2 048 токенах. Вторичный — доля покрытых символов, стоимость передачи, все вопросы и другие срезы. Отдельно покажем случаи недоступности поддерживающих свидетельств.

На каждом срезе по хронологии пересобираем доступные узлы, действительные связи, локальные степени восьми типов и их ранги внутри наблюдаемой роли. Входы графовой модели и все относительные признаки Dense-FT пересчитываем на актуальном множестве, порядок индивидуально кодированных фрагментов берём из замороженных Dense-FT оценок посредством ограничения на наблюдаемые элементы. Версия модели полезности, голова 1 024 и потолок 2 048 полностью фиксированы R39. При времени 100% необходимо побайтовое совпадение упорядоченных ID с ранее подписанным вариантом R39. Для случайной панели R22 уже сверял инкрементальное построение графа с построением авторским SDK по усечённым событиям. Дополнительно проверим проекцию входов против исходного публикуемого материала.

Основной контраст — точный рюкзак R39 с порядком R35 минус first-fit с тем же причинно доступным R35. Контроли — строгий префикс этого порядка, нативный Dense-FT first-fit и старый R22 exact для seed13. Нативные R-GCN требуют отдельного префиксного обучения либо переисполнения индуктивного инференса. Данному опыту можно приписать только реально исполненные сравнения. Первичная оценка по пяти общим инициализациям 13/17/29/37/41. Используем парный bootstrap 10 000 ресэмплов по траекториям и общим инициализациям, seed 410141. Если интервал центральной разности пересекает ноль, положительное преимущество причинной сборки не установлено. Предсказания запечатываются до вызова оценщика.
