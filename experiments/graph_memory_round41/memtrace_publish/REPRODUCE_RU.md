# Воспроизведение

Для автономной проверки всех сохранённых ответов, причин отказов, контрольных сумм и леммы достаточно Python 3.11+ со стандартной библиотекой.

```powershell
python -B verify.py
```

Для нового нативного расчёта потребуется публичный неизменённый MemTrace из [связанного испытания](../../graph_memory_round40/memtrace_reference/REPRODUCE_RU.md) и POSIX-совместимая файловая система. Установленный источник и всё состояние WSL размещались на диске D. Тест всецело синтетический, записи реальных пользователей и агентские трассы не участвуют. Каждая комбинация режима и условия получает отдельную новую временную SQLite. При базовом успешном или пустом ответе обе службы закрываются, заново открываются из файлов и исполняют повторный запрос. Десять отказов SQL при проекции фиксируются сразу после проверки отката.

```powershell
wsl -d CodexX20MSR --cd /mnt/d/CodexResearch/x20-bench-workspace/work/graph_memory_round41/memtrace_publish -- /usr/bin/python3 -B -u native.py --smoke
wsl -d CodexX20MSR --cd /mnt/d/CodexResearch/x20-bench-workspace/work/graph_memory_round41/memtrace_publish -- /usr/bin/python3 -B -u native.py
python -B verify.py --write
python -B verify.py
```

На иной машине следует адаптировать путь к проверенному upstream внутри native.py. Повтор выполнить в отдельной копии без прежнего manifest.json. Время транзакций зависит от машины и фоновой нагрузки. Повторяемость семантических исходов контролируется по ключам, байтовому содержимому, координатам, ссылкам на два события и типам источников. Значения измерений времени и идентификаторы страниц допускаются различными между запусками.
