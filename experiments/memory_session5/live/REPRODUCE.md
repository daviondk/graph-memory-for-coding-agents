# Воспроизведение

В каталоге находятся материализованные исходники каждого задания, полные нативные запросы и ответы, принятые моделью решения, все созданные программные файлы и статусы тестов. Папка transfer имеет собственные запечатанные входы. Повторная проверка сохранённых материалов работает без загрузки модели и сети.

Из корня live запустить:

```powershell
python -B verify_final.py
python -B verify_final.py --execute --tokens
```

Это окончательная проверка двух наборов тестов с относительными путями от скрипта. Быстрая команда сверяет запечатанные входы, сеансы, контрольные суммы, обе версии разметки, итоги исправления области видимости и парные статистики HumanEvalFix и HumanEval+. Полная команда ещё раз исполняет каждую различную программу для каждой задачи на исправленных авторских и усиленных тестах и пересчитывает бюджеты памяти. Для полной проверки использованы Windows, Python 3.14, numpy 2.4.4, tokenizers 0.22.2. Для воспроизводимости действует лимит 5 секунд и 192 МиБ на каждый дочерний процесс. Время исполнения около лимита зависит от машины.

Отдельно для аудита первоначальной оболочки:

При повторном исполнении расширенного HumanEval+ таймаут зависит от загрузки CPU. verify_final.py --execute сообщает о каждой смене статуса с таймаутом в timeout_disagreements и пересчитывает результаты повторного прогона в repeat_results. Другие расхождения останавливают проверку. Для требования полного совпадения даже по времени доступна команда `python -B verify_plus.py --execute --strict-timing`. Файл evalplus_timing_audit.json фиксирует повторное исполнение на исследовательской машине, а evalplus_timeout_sensitivity.json содержит описательный срез без задач с таймаутами в первом прогоне.

```powershell
python -B verify.py
python -B verify.py --execute --tokens
```

Первая команда использует стандартную библиотеку Python, повторно проверяет хеши, связь каждого запроса и применения правки с её ответом, все основные пообъектные исходы и статистические контрасты. Вторая дополнительно запускает все наборы авторских тестов на физически сохранённых файлах, проверяет свойства повторных чтений и пересчитывает содержимое памяти по исходным наблюдениям сохранённым токенизатором. Для --tokens нужен пакет tokenizers. Запуск с --execute воспроизводился на Windows с отдельным дочерним процессом и лимитом памяти на каждый тест. На других ОС сохраняется лимит времени, Windows Job memory cap потребует платформенной замены.

Скрипт prepare.py фиксирует задачу и создаёт исходный файл. infer.py запускает общий инспектор, читает файлы с диска, исполняет публичные примеры, сохраняет память и получает новые действия модели. transfer.py использует ту же реализацию на оставшихся задачах. grade.py ожидает обе prediction_lock и исполняет фиксированные решения на полных авторских тестах. Отчёт создаёт report.py. Для повторной генерации создавать отдельную копию с отдельными каталогами решений: infer.py намеренно повторно использует имеющиеся результаты. В исходном запуске использован свой loopback llama.cpp на порту 18951, фактические аргументы запуска, SHA бинарного файла и модели сохранены в runtime. Параметры каждого конкретного вызова сохранены непосредственно в calls.

Переносимость отдельных частей ограничена доступностью исходного GGUF (16,56 GB), llama.cpp/CUDA и оригинального программного окружения. Архив содержит проверенные source URLs и SHA, компактный оригинальный parquet и JSONL проекцию. Запуск основного опыта на GPU не нужен для повторной верификации результатов.

Назначения подчинены фиксированному расписанию. Одинаковые запросы внутри одной когорты используют детерминированный cache. В отчёте цена раздельно учитывает все развёртываемые логические ветви и реально оплаченные вычислительные вызовы в данной серии. Сравнение не включает повторные стохастические seeds или новую выборку репозиториев.

Оформленный вместе с основной серией SWE-smith pilot использует отдельные 64 исходных промпта и манифест от соседнего эксперимента. Его результаты находятся под ../packets/live и оцениваются независимо; цифры HumanEval в данном каталоге не включают затраты этого пилота.
