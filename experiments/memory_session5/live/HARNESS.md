# Сопоставимость с опубликованным HumanEvalFix

Корпус — Python test split из HumanEvalPack, 164 задачи исходного набора. Использована оригинальная колонка test вместе с завершающим вызовом check(entry_point). В авторском bigcode-evaluation-harness get_reference также использует эту колонку. Режим HumanEvalFixDocs показывает решателю документированную функцию, режим HumanEvalFixTests показывает исходные тесты. Наш reader получает публичное описание и собственно накопленную память, во время контролируемой паузы потерял остальную историю и может повторно прочитать файл. Колонка test и canonical_solution в его запросах отсутствуют как источники. Общедоступные примеры из описания могут совпадать с отдельными скрытыми для решателя проверками.

Колонка test, интерфейс исправлений и исполняющая оболочка — разные компоненты постановки. Совпадение тестов проверено по авторскому коду. Авторский harness Python автоматически подключает вспомогательные модули, ограничение времени 10 секунд. Мы используем ограниченный набор безопасных AST и модулей, отдельный процесс 5 секунд и лимит памяти Windows 192 MiB. Эталонная функция и исходная неисправная запускаются при тех же условиях. Ограничения среды учитываются отдельным срезом, где canonical проходит, а исходный код проваливает авторские тесты.

Публичные проценты OctoPack и сторонних leaderboard получены с другими моделями, промптами и режимами. Прямое сравнение в этой серии возможно между нашими условиями с той же моделью, задачами, числом повторных чтений и тестами. Для модели исходные HumanEval-задачи могут быть знакомы. Близкий baseline здесь — полное доступное содержимое с тем же Qwen-reader и тем же действием исправления. Это сравнение не воспроизводит целиком ни одну внешнюю SOTA-систему.

Источники: [HumanEvalPack, закреплённая версия](https://huggingface.co/datasets/bigcode/humanevalpack/tree/9a41762f73a8cb23bb5811b73d5aab164efcf378), [OctoPack](https://arxiv.org/abs/2308.07124), [HumanEvalPack harness](https://github.com/bigcode-project/bigcode-evaluation-harness/blob/8fc5bae6479c4fbbb28c3f8b644f6a15b3f3b5bd/bigcode_eval/tasks/humanevalpack.py).
