# Choosing a compact diagnostic memory conditional on the receiving agent
2026-11-17. Protocol fixed before downloading test-result CSV or reading evaluation outcomes. Public paper and metadata only have been consulted. The agent has already run six cheap probes; the receiving test scheduler sees the last probe. Can two additional observations suffice to reproduce the useful decision made with all probes? This is a decision-level memory experiment with observed industrial test executions, as opposed to a standalone LLM benchmark. No user or product code executed.

Primary domain: all nine Westermo systems used by Torbunova et al., regular nightly main sessions. Within each system sort chronologically. Merge duplicate tests within a session to the final verdict, drop resource-unavailable verdict 3, fail=1 or invalid=2. Use up to last 300 sessions that have at least 15 earlier completed sessions; retain all with at least 8 distinct tests. Use previous 15 completed sessions of the same system, never future or current remainder outcomes. The public aggregates for Westermo used as sanity check only. Treat a complete test list as known. Fixed hash order of each session's tests with new salt 's5-probe' chooses six distinct probes; all methods have the same probe outcomes. Feed the last probe to every non-static receiver. Primary packet has capacity 2 extra distinct test-ID/verdict pairs, chosen from first five. No free metadata signalling in inference. Report 1 and 2 as secondary capacity sensitivity. Tie-break deterministic. Every ordered shortlist of pending tests is frozen before accessing the non-probe verdicts.

Fixed reader: from the previous 15 runs estimate marginal risk for each test with empirical global-risk shrinkage (two pseudo observations); also estimate age-decayed static risk (half-life four sessions). Match historic runs to retained current probe outcomes by multiplying weights by 2 for equal verdict, 0.5 for mismatch, 1 for historically absent, base session age weight half-life four. Pending-test risks use a two-observation shrinkage toward the static risk. Rank = descending posterior risk, stable test-id tiebreak. Common full-information reader sees all six probes and serves as target for compression. A failing test is an observed failed invocation, without asserting independent underlying defects.

Primary writer selects the subset maximizing sum of full reader probabilities at the top ceil(0.10*n) pending tests chosen by the compressed reader. This measures loss of predicted decision utility using only prior knowledge and prefix. Competing packets: last B outcomes; most surprising B by static marginal risk conditional on actual prefix verdict; exact receiver-visible dedup (all probes distinct, equals last); same teacher-matching algorithm ignoring the retained final probe while choosing a packet; static risk, retained final only and full six. Extra prior art comparator based on conditional co-failure/co-pass dynamic rank updates with k=0.8 and 15 history followed by ranking (Torbunova et al., 2024), with same last+B probes AND full six, note our fixed prefix/reduced decision horizon and same static initialization. Denominators: primary recall of observed remaining failures in the chosen top 10% averaged over sessions with at least one such failure, then equal average across systems; paired system-level bootstrap interval for differences; report raw counts all sessions and wasted selections, A/PFD secondary on mixed sessions. No global SOTA claim. Main comparison decision-aware vs recent at B=2; compare to strongest baselines and the full-information teacher. Hypothesis rejected as competitive if little added over recent/surprise/current-context or if static wins; query cost/exhaustive combinations disclosed. Do not fit memory policy on evaluation results. Exclude no sessions by policy success. Secondary transport if data available use ABB Paint and IOF/ROL with same parameters and no re-tuning; if times insufficient identify differences. Log per-decision chosen packets, ranking information and metrics, re-run checks with access to only packaged data. Mathematical diagnostic only; functional tests not re-executed here.
