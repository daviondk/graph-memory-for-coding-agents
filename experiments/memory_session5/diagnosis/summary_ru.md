# Выбор записей по следующему решению читателя
Взяли девять промышленных систем Westermo из работы Torbunova et al. (AST 2024) и две независимые последовательности ABB. Работаем только с историей запусков тестов. В каждую сессию поступают шесть одинаковых для всех методов проб. Читатель видит последнее наблюдение, отправитель добавляет два из пяти остальных. Читатель оценивает риск каждого оставшегося теста по 15 завершённым сессиям и наблюдаемым вердиктам. Запись выбирается так, чтобы в первые 10% очереди попадали тесты, которым читатель с полной информацией присвоил наибольший суммарный риск. Основной исход — доля реальных оставшихся падений, пойманных первым децилем очереди, усреднённая внутри системы, затем поровну между системами.
На девяти системах Westermo выбор по ожидаемому решению дал 62,99%, две самые свежие записи — 62,53%, две наиболее неожиданные — 62,82%, тот же отправитель без учёта общей последней записи — 62,96%, все шесть — 62,97%. Разность со свежестью +0,46 п.п., парный 95% bootstrap по системам [+0,29;+0,61], против неожиданности +0,17 [+0,04;+0,32]. Собственный вклад явного учёта общего контекста +0,03 [−0,06;+0,13]. На ABB итог 47,42%, неожиданность 47,49%, свежесть 46,99%. Здесь самый простой сильный конкурент немного впереди. Условный метод Torbunova адаптирован к тем же наблюдениям и укороченной очереди. Это сравнение на реальных промышленных запусках, единица цены — тест, wall time неизвестен.
На других ветвях/режимах дали читателю последние две пробы и выбрали кратчайшую запись, восстанавливающую множество тестов фиксированного учителя с двумя переданными результатами. В 2 027 сессиях N/B понадобились 387 из 4 054 дополнительных записей, 3 188 против 14 189 байт с заголовком, одинаковые 4 039 обнаруженных падений. В I/M (784 сессии) — 37 из 1 568, 895 против 5 488 байт, 975 падений. Равенство решений следует из конструкции. Эмпирический результат — наблюдаемая степень сжатия. На N/B дешёвая проверка префикса из самых неожиданных наблюдений требует 3 284 байта и даёт 4 047 попаданий. Это сильный довод в пользу простого правила остановки. Выигрыш основного алгоритма над случайным распределением той же длины чувствителен к способу учёта зависимости сессий. Объёмы относятся только к переданному сообщению, предполагают общий словарь и детерминированного читателя, не включают вычисление ранжирований или стоимость исходных шести проб.
