# Suppress memories that preserve the entire next action
Registered after results for Westermo main nightly and ABB, before looking at counts or individual outcomes of other session types/branches. Transport to every Westermo system in the original nine with release branch B regular nightly N. Secondary setting main M with issue-targeted sessions I. Do not silently merge the latter. For each test system within each setting require 15 complete eligible earlier sessions as in main. If a branch contains too few sessions, retain and enumerate the exclusions. These are disjoint sessions, overlapping product, time, and possibly tests. Primary analysis only B/N. Public data tables use simulated probe order.

Two of six known probe records (the last two) already reach the receiver free. Writer may transmit zero, one or two of the first four test-ID/verdict pairs. Use the fixed previous reader, chronology and evaluation horizon. Control strongest fixed writer: select the best two records, judged by the six-observation teacher's sum of risks at top 10% of selected pending tests. New writer sends the shortest subset, of at most two, that reconstructs exactly the same unordered set of top-K tests at the receiver as this fixed writer. Exhaustive search over 11 subsets, with deterministic tie-break. The fixed two subset always exists. That specific equality at top K is a design invariant. The empirical hypotheses are that this actually reduces communication substantially on unseen traces, and achieves better failure detection than a simple selector at the same average communication budget. Do not claim discovery of guaranteed parity, ranking equivalence outside the chosen K, lower overall compute or novelty of equivalence compression.
Controls: send no extra, send the most surprising two, most recent two, full six, and a length-matched policy that sends the most surprising (or most recent) first four records with the same packet length distribution. Shuffle packet length assignments within system by independent salted hashes, without labels. Additionally give a strong baseline the same event-specific packet length and pick by surprise to distinguish a useful write gate from better content selection. Save per-session admitted sizes, identities, full rankings, total probes, objective/data scores, and costs. Report standalone packet bytes with 1 byte count + each record as uint16 ID and 1 byte verdict, also count model-agnostic logical records. This setting uses compact indexed IDs, with an already shared historical dictionary and receiver model. Primary admission target >= 25% fewer extra records vs fixed two; report macro paired recall and intervals by system, time-block sensitivity. Reject API-level cost or bandwidth claims beyond this representation.
