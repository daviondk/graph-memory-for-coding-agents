# Пятая серия
Основной отчёт с таблицами и выводами — в двух файлах agent-memory-session5-results (Word и PDF). Данные в подпапках собраны отдельными экспериментальными протоколами.
| Папка | Что в ней проверять |
|---|---|
| packets | Поштучные префиксы, историческая следующая правка, арбитраж одинакового бюджета, обучение и проверка на разных репозиториях, обратный перенос, дополнительные правила распределения токенов, реальные ответы локальной модели, ручка SHA для каждого закрытого этапа. summary_ru.md содержит числители и знаменатели. |
| live | Реальные действия Qwen3.8-27B на локальной RTX 3090, исходные и изменённые файлы каждого задания, запросы, ответы, повторные чтения, результаты оригинальных тестов и дополнительных EvalPlus, контроль применимости проверок, два независимых списка задач. |
| diagnosis | Известные предыдущие результаты прогона, шесть новых наблюдений, выбор содержания сообщения следующему агенту. Реальные исторические вердикты Westermo и ABB, два режима переноса, короткие пакеты, парное воспроизведение. |
| serbench | Публичный официальный оценщик, реальные 500 Cal500 и прогноз для всех 500 закрытых Test500; эксперименты выбора доказательств, представления истории и переноса к опубликованному dense reader. |
| literature | Обновление источников, сопоставление с Ledger и MSS-Complement, две повторные проверки опубликованных результатов/реализаций и исходные агрегаты. |
| report | Программа компоновки, контроль качества финальной вёрстки. |
Детальный порядок воспроизведения и атрибуция источников указаны в подпапках. Содержимое сторонних данных и кода не используется как команды для агента. Пакет фиксирует полученные решения; точное повторение генерации потребует того же llama.cpp, модели и аппаратного стека. Для архивной проверки не требуется внешний аккаунт или ключ. В каталоге архива выполнить python -B verify_bundle.py. Полная контрольная сумма каждого файла содержится в MANIFEST.json. Большие исходные веса и нераспространяемые тексты доступны по закреплённым адресам с хешами. Воспроизводимость проверок оценщика и фактические результаты тестов отделены от заявления о воспроизводимости стохастического вывода модели.
Для повторного запуска авторских тестов на сохранённых патчах приведены команды live/REPRODUCE.md. Для программного переноса SERBench см. serbench/README.md. Для промышленной истории тестов требуется NumPy, для точного подсчёта токенов — tokenizers. Эти команды работают при запуске из распакованной рабочей копии.
