# Что сохранять агенту после прерывания

Обновление тематической карты. Приоритет — работы, в которых содержимое памяти может изменить следующую операцию. Три измерения необходимо отличать: наличие точной строки для действия, покрытие всех смысловых предпосылок, исход исполненной задачи.

## Как измерить, когда память действительно пригодилась

[Chen et al., REM](https://arxiv.org/abs/2610.27377) помещают в начало новой задачи краткую фазовую запись прошлого опыта, а тяжёлую реализацию открывают при трудностях и убирают после одного показа. На SWE-ContextBench Lite авторы измеряют отдельно поиск нужной траектории и решение задачи. Для решённых задач сообщают 27,6% против 24,9% при снижении стоимости на 17%. Такое сравнение требуется для идеи выдавать дополнение по запросу.

[What Is This Memory Useful For?](https://arxiv.org/abs/2611.03930) помещает несколько представлений одного опыта в одинаковое окружение и скрывает будущую задачу от автора записи. Авторы исследуют устойчивость на втором читателе и отдельно отмечают малый эффект на протестированных инженерных задачах. Для нашего эксперимента это основание сравнить отсутствие памяти с тем же окружением и с пустышкой той же длины.

[Xiong et al., ACL 2026](https://aclanthology.org/2026.acl-long.27/) отдельно проверяют добавление и удаление опыта, выявляют повторение ошибок и использование корректных, но неуместных примеров. Метка успешности исходной траектории сама по себе недостаточна для оценки будущей полезности записи.

Прямую тематическую связь даёт прежде всего надпись на фото. Два других слайда описывают поводы извлечь память и правила консолидации. ## Два выполненных эксперимента

1. Воспроизвели исходы опубликованных прогонов The Complexity Trap и проверили, помогает ли знание истории репозитория выбрать метод сжатия в новой задаче. В 2 487 полных парах «модель × задача» глобальное M10 дало 832 решённых, наша обучаемая на одном исходе на задачу локальная политика 824, глобальный обучаемый контроль 827. Против M10 110 выигрышей, 118 проигрышей. Разность −0,32 п.п., интервал с кластеризацией по 12 репозиториям [−1,66; +0,38]. Эксперимент использует существующие исходы авторов и исключает 13 неполных троек. Сводка и решения по каждому примеру в policy/results.json, policy/choices_0.1.json.gz.
2. Оригинальный класс авторов LastNObservations применён к упорядоченным сообщениям инструментов на SWE-smith. Из 925 окон после десяти ответов инструментов на 127 задачах точная строка старого кода была в последних наблюдениях в 561 случае. С доступными аргументами прежних действий — в 741. Условие наличия — дословное совпадение на том же пути. Дополнительная память на 256 токенов закрыла ещё 3 окна. При дедупликации объём уменьшился с 191 701 до 186 739 добавочных токенов с тем же результатом. Последовательности из предыдущего цикла использованы повторно для анализа механизма. Состояние файла и применимость операции только по строке не удостоверены. Полный исход в policy/transfer_results.json и policy/transfer_rows.json.gz.
3. SERBench Cal500 с официальной метрикой реализован в отдельной ветви сессии. Публичные метки Cal500 позволяют оценивать локальное воспроизведение. Для Test500 авторы публикуют только входы. Результаты на двух частях следует показывать раздельно.

## Исследовательские развилки

Наиболее строгий новый тест: возобновить один и тот же агент на одинаковом состоянии с уже имеющимися аргументами действий, поочередно дать старую запись, проверяемый указатель на актуальную версию и локальный фрагмент из журнала. Всем условиям доступны повторное чтение и одинаковое число попыток; мерить принятую правку, реальную тестовую батарею, число повторов и стоимость. Заготовить отдельный стабильный и изменённый после чтения срез. Прогноз для проверки версии — выигрыш должен концентрироваться после изменений, а ложные отказы расходуют повторные чтения. Прогноз для совместного отбора — выигрыш должен проявляться там, где все части необходимы для следующей операции и нет целой строки в общей истории. Независимые свежие траектории и второй актор необходимы, чтобы избежать переобучения на одну оболочку и знакомые задачи.
