# Prior task evidence for selecting the representation of working memory
17 November 2026. This is a supplementary experiment on released trials; no file of per-instance outcomes has been inspected so far. Only published paper-level comparisons, file/schema names and headers are known. Keep this study separate from fresh Qwen edits and trajectory replay. Eligible rows are the main three SWE-agent strategies in the authors' released per-instance cost table, with verified official evaluator labels. Do not run or reproduce any issue, code or patch. Consume only anonymous task identifiers, repository names, outcomes, counts and costs. All score calculation is CPU.
Question: can a compact memory of which memory policy helped on earlier tasks in a repository improve the choice of policy for a different issue, given only the target repository/model at deployment? The possible actions select for the whole run raw context, last-ten observation masking, or LLM summaries. The three real evaluated author runs reveal each candidate endpoint; this is a new retrospective policy evaluation on old runs. No counterfactual beyond the three actually recorded paths is simulated. We cannot infer parallel-world realizations under fresh random seeds.
Include only official complete 3-policy triples with data for each model condition, public counts/denominators and omissions by name. Primary target is paired official resolution fraction. Cost secondary. For choices compute utility y minus 0.1 times actual cost divided by mean raw cost of the available historical calibration outcomes per actor. If none of the selected history has raw observations use mean available costs. This exchange rate is exploratory and is not an actual tool price. Sensitivity rerank independently with coefficient 0 (solve-only) and 0.25. To eliminate leakage across models, same issue gets same evaluation fold, using sha256('hist-mask5|'+issue)%5. Histories include the other four folds of the same actor. For the primary affordable history, expose exactly one policy's outcome per training issue, chosen by fixed SHA256('history-action5|'+actor+'|'+issue)%3 among alphabetic strategy names. Each repository condition stores just counts, solved sums, and cost sums per policy. Smooth each local mean towards its corresponding global mean with eight virtual samples. Use historical mean utility per repository and arm to choose. Ties prefer masking, summary, then raw. Compare always mask, always raw, always summary, training-best global policy using identical logged data, global and local policies using all three historical outcomes, and an unattainable per-issue oracle. Report outcome and absolute cost by actor as well as macro/micro aggregates. Off-manifold history policies are not a deployment guarantee. Report cases where local both wins and loses, paired cluster bootstrap over repositories preserving shared tasks across actors; few clusters. No label-based subset tuning. No claim of reproducing generation; authenticate downloaded author data and reproduce original solve rates independently, cost measure as authors define plus explicit historical training cost.
