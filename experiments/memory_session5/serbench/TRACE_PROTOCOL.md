# Exploratory second-stage comparison of memory writers
Defined after inspecting the first Cal500 scores and the shape of public event streams (one unenriched example). Same 500 calibration states and grouped out-of-fold fitting; conclusions exploratory. Aim: relay the useful part of already observed tool interactions in a budget of 192 Qwen tokenizer tokens. Common current query = issue + information_need + current_subgoal. The writer only sees preceding public action_type, action_input and tool_output, in chronology; never receives candidate pool or gold. The receiving scorer sees the common current query, bounded memory and each candidate. It uses the same lexical-overlap/path/line-location feature template and fits the same supervised independent model with training repositories outside the fold. Test latest raw transcript tail, earliest raw head, per-event uniform tail, reversed recent action inputs, new address ledger (path/line locations found in outputs plus short action inputs across recent steps), null sender and uncapped complete transcript as contextual controls. Compare complete-MSS@5 to strongest of other bounded writers, compare same base query with empty memory, report emitted Qwen token lengths, logged 8-returned IDs, same official grader. Addresses are read from historic observations only, path/line literal recognition is available to all readers. No explicit gold-like metadata fields, no interpreter for external snippets. No hyperparameter tuning or further public submission selection. Public machine-anchored labels and already-inspected split limit inference.
