# Внешний академический контроль в новой Python-репликации
До открытия результатов новой Python-репликации на 4000 задачах взять 32 из каждой её четырёх страт по независимому SHA-256, максимум два задания одного проекта на страту. Запустить фактический UniXcoder в авторском исходном окне; ровно те же объявления и запросы, что у замороженного графа и лёгкой модели R4 + сопоставления частей имени. Вторично сообщить парные Acc@1/3/5 и MRR, на Hard отдельно Acc@5, где у UniXcoder лучшее значение исходной работы ICLR для Python. Его табличный результат не переносится на эту подвыборку. Порядок, исходы и расчёты сохранить. Эта подпанель входит в 4000, её не считать независимой от них.
