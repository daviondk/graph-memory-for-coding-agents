# Дополнительная проверка переноса
До первого чтения новых целевых меток добавлен фактический Semlith на всей запланированной Python-панели fresh. Причина — исходный binary-прогон R4 имел только Java. До объединения сохраняются полные ранги каждого метода и хеш нового запуска. Используется прежний Semlith 0.36.0, опубликованный CPU-бинарник, тот же SDK издателя, индексация кандидатных файлов отдельно в CFF и CFR, фильтр файлов текущего примера, 3 строки, k = n+10 с дополнением ненайденных кандидатов исходным порядком. Каждая конфигурация включает все отобранные easy/hard случаи. Общая статистика индекса видит документы других запросов той же конфигурации; новые модели ограничены пулом данного запроса. Индекс raw UTF-8 исходников без меток. Дополнительное сравнение, без расширения первичной семьи Holm.
