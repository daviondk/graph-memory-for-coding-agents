# Графовая память кодовых агентов · серия 6
Все данные и журналы основной машины находятся на диске D. Итоговые Word и PDF в ../../outputs, там же архив записей и контрольная сумма. Серии 1–5 сохранены отдельно. Эксперименты независимы по операции и единице измерения.
- published/REPORT_RU.md, published/symmetric_results.json и published/published_replay.zip. Работающие модули MemTrace, исходный и симметричный по информации архив, сравнение с 4-КиБ буфером и LRU на двух панелях. Вложенный ZIP содержит код опубликованного релиза, замороженные данные, нативные ответы и скрипт проверки. Для проверки сверяйте восстановленный текст и число открытий по каждому запросу. В последней проверке пути, первая строка и длина получены оценщиком из будущей успешной правки.
- latency/. Дополнительное парное измерение времени получения идентичного конечного JSON. Архивные страницы, SQLite и официальный нативный recall создаются заново. Ранжирование и модель LLM здесь не используются. Времена по каждому запросу в times.jsonl и times_native.jsonl, итоги с интервалами в results.json и native_results.json. Для воспроизведения нужны Python 3.12 в Linux, libzstd, данные и публичные модули из published_replay.zip, состояния version/states_external_0.gz и словарь graph_memory_round4/writer/python_prior.bin. Оригинальный путь репозитория MemTrace внутри published приведён в его README. Замеры WSL использовали дистрибутив CodexX20MSR на диске D. Запускать bench.py и bench_native.py в свежих экспериментальных директориях. Для анализа двух наборов достаточно numpy и соответствующего analyse*.py.
- version/REPORT_RU.md, version/codec/REPORT_RU.md и version/route/REPORT_RU.md. Согласованность адреса после редактирования, кодирование под ограничением объёма и выбор следующего окна при скрытой цели. В upstream_inputs.zip — входные зависимости. В основной комплект включены также сырые снимки и решения.
- repair/ и repair/transfer/. Генерации локального Qwen3.8-27B на RTX 3090, Python-тесты и протоколы. Воспроизводится через repair/README_RU.md и transfer/REPORT_RU.md. Известные координаты отдельно проверены с исходными правами на запись в grade_equal.py. Повторных вызовов модели для такой перепроверки не требуется. Внутри архива сохранены контрольные суммы и адреса исходных снимков вместо 46 копий дерева проекта и весов модели. Верификации и поштучные результаты позволяют перепроверить значения без GPU.
- retrieval/REPORT_RU.md, retrieval/TABLES_RU.md и retrieval/REPRODUCE.md. Прямые сопоставления с UniXcoder, Semlith, авторским Jaccard и прежним графом. Таблицы содержат Hit@1, @3, @5 и MRR. Проектно-отложенная репликация Python вынесена в replication/. Вместо крупного публичного test.zip и выгрузок Parquet в комплект включены метод получения, SHA и замороженные порядки кандидатов. В Р6 нет сопоставимого преимущества по официальному end-to-end решению полного SWE-bench.
- report/pages/ содержит текст и ссылки. Для Word использован существующий шаблон второй серии, прилагаемый в комплект, и собранный в report/build.py макет. report/qa.py проверяет PDF и Word после рендеринга. Внешний источник для каждой основной публикации приведён в отчёте и в published/SOURCES_RU.md.
MANIFEST.json внутри общего ZIP содержит SHA-256 каждого входящего файла. Все файлы сверяются при упаковке, включая контрольные суммы распакованных байтов. Секреты, ключи API и аккаунт GitHub для этих опытов не требовались.
