# Где остаётся место для статьи
**Многоуровневую память уже реализуют.** В Folio, препринте от 12 ноября 2026 года, разные представления истории используют общий идентификатор для восстановления полного источника. MemTrace хранит проверяемые ссылки на доказательства. В REM агент получает более подробную запись о прошлом решении по сигналу затруднения во время работы. Предмет нашего опыта уже: для конкретной версии файла и области строк определить, достаточно ли ранее прочитанного, а затем выбрать самый дешёвый источник, который даст нужный текст. Термин «двухуровневая память» сам по себе не описывает научную новизну. [Folio](https://arxiv.org/abs/2611.16627) · [MemTrace](https://arxiv.org/abs/2610.04838) · [REM](https://arxiv.org/abs/2610.27377).
**Цена открытия страницы и цена решения различаются.** В работе от 17 ноября авторы разделили входные токены с кешированием и без него, а также выходные токены. В их экспериментах добавленный контекст сокращал число поисков, но при некоторых ценах увеличивал полную стоимость. Поэтому наши данные о физических открытиях, байтах протокола, размере полезной выдачи и цене дополнительного слоя должны оставаться разными столбцами. [Context Has a Price](https://arxiv.org/abs/2611.22238).
**У полезного графа должно быть проверяемое ребро.** Структура вызовов, совпадение слов в имени и связь с увиденным traceback могут дать разный эффект. SWE-Pruner учится выбирать относящиеся к текущей задаче строки. Работа The Complexity Trap показывает, почему в таких опытах требуется дешёвый контроль с простым отбрасыванием старых наблюдений. Для нашего варианта такую проверку выполняют LRU с тем же архивом, контроль с перестановкой рёбер и текстовая память того же размера. [SWE-Pruner](https://arxiv.org/abs/2601.16746) · [The Complexity Trap](https://arxiv.org/abs/2508.21433).
Для будущей статьи наиболее содержательный вопрос — сколько стоит **достоверная** следующая подсказка. Ошибочный старый адрес, отказ ответить и точная цитата имеют разные последствия для решателя. Нужен эксперимент, где агент сам запрашивает источник, получает содержимое, редактирует код и запускает тесты. Основной исход — доля решённых задач при равном бюджете или цена одного проверенного решения. Внутренние показатели нужны, чтобы объяснить различие между системами.
