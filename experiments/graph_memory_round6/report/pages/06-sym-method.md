# Как проверяли настоящее исправление
Из 75 задач SymPy в SWE-bench Verified критериям отбора удовлетворили 46. Из них взяли 16 по хешу идентификатора. Перед генерацией для каждой задачи зафиксировали исходный Git-коммит, текст issue, контексты и их SHA-256. При выборе файлов решатель не видел эталонный патч, список его файлов, новые тесты или путь к целевой строке. Локальные копии и все вычисления эксперимента находятся на диске D. [Набор SWE-bench Verified](https://huggingface.co/datasets/princeton-nlp/SWE-bench_Verified).
Первичный проход по исходникам SymPy находит объявления по словам и идентификаторам из issue. Восемью модулями ограничен следующий этап — разбор кода и формирование блоков до 14 строк. Постоянный индекс всего проекта эксперимент не строит. Все три политики получают одни и те же наблюдения. Плоская оценивает блоки по тексту, названию функции, класса и файла. Графовая добавляет сигнал от соседних вызовов и соседних методов класса. Контроль переставляет идентификаторы всех узлов при неизменном графе связей, разрывая соответствие между текстом и соседями. Топология и распределение степеней при этом сохраняются.
Для ребра из x в y дополнительный сигнал пропорционален s(x)/√(d⁺(x)d⁻(y)), где s(x) — лучшая текстовая оценка блока функции x. В обратном направлении сигнал уменьшен вдвое. К исходному баллу добавляется 0,85 от сильнейшего пришедшего сигнала. Это проверяемое предпочтение редких связей. Пропущенный при начальном чтении модуль недоступен любому из трёх ранжировщиков.
Каждый контекст умещается в 1800 токенов. Qwen3.8-27B UD-Q4_K_M на одной RTX 3090 получает одну попытку, температуру 0 и до 850 токенов ответа. Исполнитель проверяет однозначность текстовой замены и синтаксис, накладывает патч и запускает все адресованные FAIL_TO_PASS и до 12 PASS_TO_PASS. Патч авторов и исходный код проходят ту же процедуру. По контрольным прогонам выявлена ошибка области поиска Git и несовместимость старых SymPy с оболочкой py.test. После исправления среды повторили все контроли, сохранили первичные журналы и потребовали фактического изменения байтов в файлах.
