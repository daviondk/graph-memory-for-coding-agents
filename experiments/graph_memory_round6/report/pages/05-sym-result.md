# Граф вызовов и 16 исправлений SymPy
Все 16 исходных версий показали хотя бы один реальный отказ, все 16 эталонных патчей прошли полный набор своих FAIL_TO_PASS. В основных условиях модель получила от 1771 до 1773 токенов памяти в среднем. Ни одна из найденных регрессий не пришлась на задачи с полностью пройденными целевыми тестами. Проверены восстановленные байты 151 исходного файла.

**Где теряется нужный код.** После поиска восьми файлов в 14 из 16 задач присутствовала хотя бы одна строка эталонного изменения. После отбора контекста она осталась лишь в четырёх задачах у каждой практической политики. Граф показал 21 из 42 целевых строк, текстовый поиск — 17. Для чистых вставок учитывалась соседняя исходная строка. Дополнительные строки оказались в задачах, где часть нужного кода и так уже присутствовала. Это иллюстрирует разницу между числом сохранённых строк и числом задач, получивших полезный контекст.
**Что изменили хорошие адреса.** В диагностическом условии показали окрестность правильной строки исходной ошибочной версии. Эталонные замены и тесты были скрыты. В семи задачах это дало дополнительный работающий патч против текстового поиска, обратных расхождений не было, двустороннее точное p = 0,0156. В двух задачах диагностическая ветвь разрешала запись в файл вне исходных восьми. При повторной проверке с одинаковыми разрешёнными путями получено 10/16 против 4/16, шесть выигрышей без потерь, p = 0,03125. Привилегированный контекст в среднем занимал 930 токенов.
Сделаны 46 уникальных генераций для трёх основных условий и 16 для диагностики. Общий расход составил 123 331 входной и 14 276 выходных токенов. Однократное исправление с локальными тестами в одном проекте отличается от официальной контейнерной оценки полного SWE-bench.
