До первых ответов решателя. На каждой задаче исполняются все официальные FAIL_TO_PASS. Дополнительно берём до 12 официальных PASS_TO_PASS, выбранных по воспроизводимому хешу идентификатора задачи и названия теста. Если одно короткое имя обозначает несколько проверок в затронутых тестовых модулях, запускаются все соответствия. Не найденные имена, skips, ошибки сбора и таймауты учитываются отдельно. Положительный контроль — эталонное исправление с новыми тестами, отрицательный — те же тесты на исходном коде. Сигнал регрессии — тест из PASS_TO_PASS, который проходил в исходном контроле и перестал проходить после изменения. Лимит на каждый набор — 120 секунд. Формат ответа из промпта и проверка однозначности замены одинаковы для всех политик. Графовый и текстовый контекст оцениваются дополнительно по покрытию исходных строк эталонной правки. Для чистой вставки используем соседнюю строку. Оценку интерпретируем как проверку короткого ремонта после передачи контекста, без повторных обращений к репозиторию.
При контрольном прогоне обнаружены нулевые diff у авторской правки из-за Git-репозитория родительского диска и несовместимость shim py с ранними версиями SymPy. Изолировали git от родительского репозитория, добавили обязательную проверку фактического изменения байтов обоими патчами и зависимость py 1.11.0. Вся когорта проверяется заново. Первичные технические логи сохранены отдельно.
