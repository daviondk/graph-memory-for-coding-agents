# Граф связей между уже прочитанными фрагментами и реальные исправления SymPy
Протокол зафиксирован до выборки заданий и оценок. Исходная популяция — все SymPy из открытого тестового split SWE-bench Verified с версией 1.5–1.12, хотя бы одной адресуемой проверкой pytest из FAIL_TO_PASS. Хеш-сортировка SHA256("sym-repair-r6|" + instance_id), первые 16 после проверки только области применения. Вход решателя — описание issue и до 1800 токенов памяти одного и того же синтетического сеанса поиска. Сеанс состоит из одного поиска определений по словам и идентификаторам из issue и чтения максимум восьми затронутых модулей. Текст тестов, подсказки, исправление и файлы исправления при построении запросов недоступны. Диагностические контроли выполняются после фиксации списка, по всем задачам раскрываются и не заменяются. Один проект, адаптация к набору и возможное предобучение на нём ограничивают перенос.
Варианты — ранжирование блоков по тексту (flat), плюс распространяемая по наблюдавшимся вызовам и принадлежности классу часть рейтинга (graph), такой же граф с переставленными целями связей (shuffled). Якоря и содержимое доступны всем, формат одинаковый, один потолок 1800 токенов. Сперва фиксируются пакеты и назначения, потом единственный ответ Qwen3.8-27B UD-Q4_K_M без рассуждений, ответ до 850 токенов. Модель может предложить точную замену old/new по одному или нескольким уже посещённым путям. Одинаковые запросы переиспользуют один ответ. Исходные файлы — точные публичные Git-коммиты. Первичная метрика — все официальные FAIL_TO_PASS прошли после патча, при этом исходная версия должна показать хотя бы один действительный отказ, а исправление авторов — пройти все F2P. Знаменатели — фиксированная когорта и отдельно диагностически валидная её часть. Вторичные — применимость, покрытие изменённых строк среди прочитанного и предъявленного, сохранение PASS_TO_PASS (перечень и статус исполнения приводить явно), токены, время, пары выигрыш/поражение и двусторонний точный парный тест. Базовая и авторская версии оцениваются с той же проверкой. Целевые тесты запускаются нативно с фиксированными зависимостями. Это адаптация SWE-bench, её числа нельзя переносить в официальный рейтинг.
До запуска нельзя утверждать, что граф улучшит ремонт. Если поиск не показывает правильное место даже в исходном пуле, это ограничение этапа наблюдения. Если граф улучшает покрытие без дополнительных проходящих исправлений, подтверждён только результат поиска.
Уточнение формата до отбора и генерации. У столбца FAIL_TO_PASS набора Verified названия тестов SymPy часто без имени файла. Принимаем оба формата и разрешаем короткие названия по тестовым модулям после наложения тестового патча. Первичная попытка чтения дала ноль записей.
