Проверка чувствительности после тайминга /mnt/d. На той же машине повторяем полное чтение с физическим каталогом SQLite и страниц на файловой системе Linux в WSL. VHDX этой среды хранится на D:/CodexResearch/x20-msr-range/linux. Чтобы включить сильный простой контроль, добавляем маршрут с тем же ограниченным LRU и идентичным холодным архивом. Три маршрута возвращают один компактный JSON. Декодеры и модели страниц те же. В каждом задании сравниваем медианы трёх повторов каждой ветви, порядок сбалансирован циклической перестановкой в каждой тройке после разогрева. Исходы по времени нельзя обобщать на другие носители, распределения запросов и затраты обновления. Первичный DNS/сетевой запрос отсутствует. Данные о затратах записи и чтения представляются отдельно.
