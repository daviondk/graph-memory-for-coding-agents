# Происхождение производных данных

Исходные траектории ISETrace опубликованы авторами проекта Valiere01/ISE-Trace. Для расчёта использована ревизия e40e04d41c04e4eb4bae181ebdd41b61c688081b набора valiere/ISETrace. Источник распространяется по CC BY 4.0. [Проект ISE-Trace](https://github.com/Valiere01/ISE-Trace) · [Карточка ISETrace](https://huggingface.co/datasets/valiere/ISETrace) · [Условия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Набор HazeLocus/ISETrace-Memory-Queries содержит производные вопросы и разметку диапазонов; для него также указана CC BY 4.0. В этой демонстрации события и области текста представлены хешами, ролями, численными смещениями, отношениями и ограниченной выборкой запросов. Записи модели и замеры программного прототипа добавлены в данном исследовании. [Производная разметка](https://huggingface.co/datasets/HazeLocus/ISETrace-Memory-Queries) · [Исследование EPGM](https://arxiv.org/abs/2609.25913)
