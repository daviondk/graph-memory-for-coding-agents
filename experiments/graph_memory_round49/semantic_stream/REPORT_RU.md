# Семантический префикс и стоимость точного отбора

Гипотеза возникла после обнаруженного в этой серии провала отбора по давности. Сохранение наиболее релевантного вопросу префикса вместо последних наблюдений вернуло полное покрытие к **75,00%** на 2 000 вопросах ISETrace. Контроль Dense first-fit получил **75,15%**. Парная разность −0,15 п.п. с 95%-м интервалом [−1,19; 0,87]. Одинаковая средняя точность сама по себе не доказывает эквивалентность. Эти 2 000 вопросов неоднократно использовались для разработки, перенос на новую выборку остаётся открытым. [Предварительно зафиксированные параметры](PROTOCOL_RU.md) · [Исходная постановка ISETrace](https://arxiv.org/abs/2609.25913)

При поступлении ещё одного кандидата ранжирование Dense-FT может вытеснить из защищённого префикса любой прежний элемент. Строки динамической программы сохраняются в порядке **поступления**. Кандидат, который уже попал в обязательный префикс, получает нулевую полезность для выбора во вторую часть. При равенстве значений текущий элемент пропускается. Поэтому двойной выбор невозможен, а вытеснение элемента из префикса активирует его исходную полезность. При любой смене состава достаточно начинать вычисление с первой изменённой необязательной полезности. Это даёт тот же пакет, включая порядок ID, что и непосредственная оптимизация всех доступных необязательных элементов. Полный контроль сжимает список до необязательных элементов и обрабатывает лишь оставшуюся ёмкость.

Семантический вариант с контрольными точками обработал 531 065 строк против 4 718 722 у полного плана. Прирост против плана с одной терминальной строкой составил 1,33× [1,30; 1,36], а медианный пик основных DP-буферов вырос со 160,8 до 404,2 КиБ относительно полного решателя. Качество семантического варианта на восьмой группе достигло 29,33% против 29,01% у Dense first-fit на 1 906 вопросах (+0,31 п.п. [−0,05; 0,69]). На финале добавка за число подтверждений дала 73,85% (−1,30 п.п. [−2,67; 0,05] к Dense first-fit). Все сравнения порядка на 51 849 границах прошли; 34 524 малых синтетических исхода проверены перебором, 126 реальных пакетов пересчитаны независимым Python-кодом.

**Цена самой оптимизации.** Дополнительное чередующееся измерение сравнивает разные правила формирования пакета. Прямой алгоритм Dense first-fit хранит порядок семантического ранга, при чтении берёт следующий помещающийся элемент. Для всех вопросов и границ он потратил 22,11 мс, точный семантический отбор с контрольными точками — 465,38 мс, отношение 21,05× [20,60; 21,48] в пользу простого алгоритма. Работа прямого варианта воспроизведена независимо на каждом снимке; 20 000 измерений двух планов сохранены. При сопоставимом полном покрытии это аргумент использовать более сложный точный метод тогда, когда важен конкретный контракт выдачи, либо когда обученная полезность приносит самостоятельный выигрыш. Выигрыш в качестве для такой объединённой потоковой системы ещё требует отдельной демонстрации. [Числовые результаты](results.json) · [Прямой контроль](direct-results.json)

Для воспроизведения расположите рядом каталог `stream_packet`. `python -B analyze.py` (NumPy) перепроверяет сохранённые пакеты, необходимые источники и интервалы. `python -B run.py` повторяет основной C++17-опыт, `python -B direct_control.py` — измерение прямого first-fit. Новые прогоны следует выполнять в копии каталога, чтобы сохранить подписанные квитанции.
