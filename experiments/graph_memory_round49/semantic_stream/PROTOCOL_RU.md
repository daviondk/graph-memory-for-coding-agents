# Семантический префикс при динамическом составе кандидатов

После результата потокового эксперимента (64,90% против 75,15% у Dense first-fit) проверяем одну заранее фиксированную замену — порядок обязательных элементов задаёт исходный Dense-FT. Для каждого видимого множества берём самый длинный последовательный префикс плотного ранжирования стоимостью не более 1 024. Остаток бюджета до 2 048 заполняет точный рюкзак по фиксированным Q32 полезностям. Основная политика использует семантические полезности, дополнительная — прибавку по числу связей, как в исходном опыте. Поскольку неопубликованный результат нового варианта оценивается на неоднократно просмотренной панели 2 000 вопросов ISETrace, это разведочный опыт. Параметры, бюджет и выборка остаются прежними. Перебора долей и констант по ответам не проводим.

Новая вставка может вытеснить ранее обязательный элемент, либо присоединить к префиксу ранее необязательный. Сохраняем строки динамической программы по порядку появления всех видимых кандидатов. Обязательному элементу временно присваиваем нулевую необязательную полезность (при ничьей он не включается повторно). Изменение обязательного статуса эквивалентно точечному пересмотру полезности. Восстанавливаем строку строго до первого ранее обработанного обновлённого элемента; сдвиг семантической границы в любую сторону допускается. Выдаём обязательную часть в порядке ранга, оставшуюся в обратном порядке появления. Полностью автономный контроль решает ту же задачу с нуля на каждом снимке до фактической остаточной вместимости.

Основные оценки — Full Support@2048 на финале относительно Dense first-fit и отношение времени C++-решателей при чтении на каждой границе. Группировка по траекториям, 10 000 парных bootstrap-перевыборок. Дополнительно полное покрытие на шаге 8, покрытие символов, строки, цена сохранения таблиц и сравнение с терминальной строкой. Одни и те же исходные кандидаты/связи/стоимости. Одна прогревочная и пять перемешанных попыток. Прогнозы для обеих политик фиксируются до открытия числовых эталонов этого опыта. Независимые расчёты на реальных пакетах и исчерпывающий синтетический тест обязательны. Рост точности по сравнению с хронологическим префиксом сам по себе не означает превосходства над штатным графовым ранжированием.
