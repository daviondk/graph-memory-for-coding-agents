# Воспроизведение

Для повторной арифметической проверки требуются Python и NumPy, достаточно `python -B verify.py`. Локальный отчёт включает все 72 аппаратные квитанции, 24 исходных эталона качества и 16 контрастов по репозиториям. Время исходного полного кодирования в сравнениях отсутствует.

Для точного повтора на Windows с WDDM нужны модель, RTX 3090 и исходная конфигурация из [предыдущего аппаратного опыта](../long_gpu/REPRODUCE_RU.md), а также [подписанное сравнение с авторским C-кодом](../cache_controls/REPRODUCE_RU.md). Все поля и хеши приводятся в подписи запуска. Оригинальные программные проекты из SERBench не выполняются. Дополнительный запуск обращается только к loopback-кодировщику.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
./gpu.ps1
python -B score.py
python -B retained_heap.py
python -B report.py
python -B verify.py
```

Контрольные точки сохраняются в каталоге `D:/CodexResearch/x20-r39-embedding-runtime/r49-modern-physical`. Повтор независимого физического замера выполняется с отдельным пустым каталогом контрольных точек и сохранённой в другом каталоге исходной подписью. Скрипт score.py заново вычисляет агрегаты по существующим квитанциям. Для независимого замера требуются новые физические квитанции. Ранжирование выполняет неизменённая функция drive из long_gpu. Память Python измеряется отдельной реконструкцией постоянных объектов после записи, включая разделяемые ссылки; временные пакеты и зарезервированные общесистемным аллокатором страницы исключены.
