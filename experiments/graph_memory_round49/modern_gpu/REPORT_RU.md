# Задержка выдачи при сравнении с S3-FIFO и SIEVE

**Критерий ускорения относительно обоих контролей не выполнен.** При равной ёмкости 31 вектор и расчётном бюджете 512 КиБ разница сквозного времени относительно S3-FIFO составила **0,31% [-1,30%; 2,14%]**, относительно SIEVE — **0,82% [-0,53%; 2,51%]**. Положительный знак обозначает экономию времени. В отдельных цепочках преимущество наблюдалось на 5/8 и 5/8 репозиториев соответственно. Приведены индивидуальные 95% интервалы парного бутстрепа по репозиториям. [Предварительный протокол](PROTOCOL_RU.md) · [Сводные результаты](results.json)

Один сеанс Qwen3-Embedding-8B Q4_K_M на RTX 3090 обслужил все три режима. Испытано 24 состояния из восьми ранее отобранных репозиториев, по три последовательных снимка одного запуска. Каждый режим начинал с пустым постоянным кешем. Сначала все кандидаты текущего запроса проверялись относительно одного снимка резидентов. При последующей записи S3-FIFO и SIEVE получали тот же заранее проверенный порядок с приоритетом дорогих источников. Расходы в токенах на этих состояниях и результаты прежнего опыта с другими политиками были известны. [Адаптеры, сравненные с оригинальной реализацией](../cache_controls/REPORT_RU.md)
