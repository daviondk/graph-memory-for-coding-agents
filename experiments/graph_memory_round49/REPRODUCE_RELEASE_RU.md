# Проверка и восстановление релиза R49

Корневые документы `REPORT_RU.md` и `PRIOR_ART_RU.md` закреплены отдельными SHA256. Для `*.f64.gz` инвентарь проверяет сжатые и распакованные байты и указывает число элементов little-endian IEEE 754 binary64.

Файл `release.json` содержит список запрошенных и включённых исследований и SHA256 каждого исходного манифеста. В финальном релизе списки совпадают. Исследования находятся в одноимённых каталогах с исходными байтами файлов. `MANIFEST_SHA256.json` задаёт исчерпывающий список файлов архива, кроме самого списка. `FILE_TYPES.json` дополнительно указывает тип по расширению, число байтов, обычный SHA256 и Git blob ID для обоих форматов репозитория. SHA256 самого ZIP следует сверять с опубликованной независимой квитанцией.

Из доверенной копии проверяющего скрипта сначала проверьте ZIP и импортируйте в новый каталог. Само чтение архива проверяет содержимое без исполнения включённых программ. Из уже проверенной распаковки по желанию можно запустить отдельные числовые проверки авторов. Для проверки байтов достаточно стандартного Python. Для расчётных проверок отдельных исследований нужны NumPy и компилятор C++17 в PATH. Для генерации заново модели, весов и специализированных GPU-трасс необходимы отдельно указанные в отчётах среды.

```powershell
python -B verify_release.py zip round49.zip --sha256 $publishedSha
python -B verify_release.py import round49.zip restored49 --sha256 $publishedSha
python -B restored49/verify_release.py tree restored49
python -B restored49/check_studies.py --root restored49
python -B restored49/verify_release.py repack restored49 rebuilt.zip
```

У `rebuilt.zip` будет тот же SHA256. Архив использует сортировку имён, постоянную дату ZIP, фиксированные атрибуты и хранение байтов без повторного сжатия. Когда каталог опубликован отдельным поддеревом Git, следующая команда в режиме чтения сверяет полный состав и байты каждого реального blob, в том числе самого внешнего манифеста. Передайте фактические ref и префикс внутри репозитория.

```powershell
python -B restored49/verify_release.py git restored49 --repo $repository --ref $commit --prefix 'work/graph_memory_round49'
```
