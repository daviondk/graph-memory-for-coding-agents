# Границы полезности при полном пересмотре графовых весов

Из диагностики предыдущего опыта известно, что на четвертях реальной траектории меняются многие старые оценки обученной графовой модели. Проверяем альтернативный точный план. Его цель — дешёво исключить или закрепить кандидаты на основании допустимого контекста и дробной верхней границы целевой функции текущего снимка. Если значение любой конфигурации с противоположным статусом кандидата строго хуже известной допустимой конфигурации, можно безопасно исключить этот выбор, включая сохранение результата правила ничьих. Оставшееся ядро решаем исходной целочисленной DP в исходном порядке ранга. Используем известную технику reduced-cost fixing для рюкзака. Исследовательский вопрос — насколько сокращается работа на реальных графовых выдачах и помогает ли предшествующий контекст как дополнительное допустимое решение после смены графовых оценок. [Работа Пизингера](https://doi.org/10.1287/opre.45.5.758)

Все четыре действительных среза для 2 000 ISETrace вопросов × пять ранее опубликованных инициализаций. Первая инициализация 13 — основная; все пять публикуются. Учитываем 8 000 упорядоченных пакетов на инициализацию, начальное состояние пусто, предыдущая выдача внутри той же траектории. Все планы используют общий обязательный семантический префикс R41, одинаковый Q32, обработку фрагментов, всюду помещающихся хвостов, разрешение ничьих и ограничение 2048. А — полный C++ DP. Б — верхняя граница и допустимое решение по убыванию полезности на токен с пропуском неподходящих. В — тот же алгоритм плюс ещё один допустимый пакет из ранее выбранных и всё ещё доступных необязательных фрагментов, дополненный жадно новыми кандидатами по плотности. Если его значение выше, он заменяет нижнюю границу. Дополнительный контроль Г — то же повторное построение альтернативного допустимого пакета из текущей впервые предъявленной семантической приоритетной последовательности, с тем же проходом заполнения, без доступа к предыдущей выдаче. Никаких эталонных диапазонов при построении. Все методы физически пересчитывают свои собственные последовательности из исходных числовых данных.

Основной endpoint — время полного процесса отбора всех четырёх состояний из готовых рангов и полезностей, отношения А/В, Б/В и Г/В, парные 95% интервалы по траекториям. Один прогрев, пять повторов со случайным чередованием планов и вопросов. Сохраняем число исключённых/обязательных фрагментов, размер ядра, условия/частоту усиления границы и сравнение с исходной выдачей, включая эффекты округления в Q32. Результат считается точным для Q32 только при полном совпадении упорядоченных идентификаторов с независимой разметкой алгоритма. Цель — физическая стоимость, об улучшении Full Support такая эквивалентность сама по себе не говорит. Все итоги публикуются независимо от знака эффекта.
