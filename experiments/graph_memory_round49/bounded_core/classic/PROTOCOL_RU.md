# Независимое точное решение при прежнем бюджете

До открытия ответов фиксируем первые 128 вопросов по возрастанию SHA-256 UTF-8 метки classic-r49: вместе с ID вопроса, seed 13, все четыре среза. Бюджеты 1024/2048, исходные Q32 ценности без изменения разрядности. Независимый специализированный статический решатель должен вернуть подсумму полного DP, вместимость и полный набор ID проверяются раздельно. При наличии официальной целочисленной 64-битной сборки используем её. Вычисляем один прогрев и три перемешанных парных повтора четырёх срезов на запрос, сверяем ответы на каждом. Время сравниваем описательно с указанием API, предобработки и контракта ничьих. Эталонные свидетельства и оценки ответа не используются.
