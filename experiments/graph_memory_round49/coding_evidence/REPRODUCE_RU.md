# Воспроизведение

`python -B verify.py` из этой папки автономно проверяет подписанные файлы, заново ранжирует все 45 наблюдений и воспроизводит байты обоих пакетов. Проверка пересчитывает бюджеты и операции по сохранённым ответам, прогоняет нативный парсер по пяти логам и разбирает 2 120 статусов JUnit. Нужен Python 3.10+ со стандартной библиотекой.

Чтобы повторить оценивание непосредственно на исходниках, загрузите закреплённый образ (Linux amd64) командой `docker pull swerebenchv2/alteryx-woodwork@sha256:c272baa5aa5925f73af651a9feb3505314a03a5b22f4f625a74d853be9f2868b`. Команда `python -B grade_locked.py locked.json replay-official` воспроизводит исходный, эталонный и три анонимных патча в новых контейнерах, без сети. Аргумент `--benchmark` позволяет указать оригинальный parquet вместо включённой проверочной строки. Затем `python -B suite.py replay-suite` выполняет независимый расширенный тест по всему каталогу accessor. Вторичные статусы сверяются с замороженным основным результатом. Выходные папки должны быть новыми. Время, временные пути в логах и хеши полных повторных логов могут различаться.

Исходную часть слепого опыта можно исследовать по [протоколу](PROTOCOL_RU.md), [профилю предыдущей сессии](history.json) и [выданным ответам](responses.json.gz). В журнале запросы редактирования сохраняют длины и SHA256 строк. Итоговые патчи сохранены полностью. Для повторного создания начальных публичных исходников нужны закреплённая [версия VibeMemBench](https://huggingface.co/datasets/Tongyi-ConvAI/VibeMemBench/tree/11164976b4f920cdb0d0cd570ca572e49acea1e8), GitHub codeload для базового коммита из registration.json, настройки путей в prepare_source.py и settings.py и Python с PyArrow. Для повторения новых слепых сессий нужны новая приватная папка, три свежих независимых исполнителя и новые индивидуальные адреса. Опубликованный журнал раскрывает распределение методов; ранее знакомые с ним исполнители для слепого повтора непригодны.
