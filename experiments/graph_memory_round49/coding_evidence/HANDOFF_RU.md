# Передача трём исполнителям

Скрининг рассмотрел все шесть задач зарегистрированных репозиториев. Минимальный полный набор из двух задач весил 1 265 811 333 сжатых байта до загрузки; предельный бюджет пары был 900 000 000. Для индивидуального запуска взят наименьший подходящий образ — Woodwork-640. Его исходники в официальной рабочей папке полностью совпали с публичным базовым коммитом. До открытия официальных меток оценивания источниками были только публичная постановка и класс производственных файлов (28 модулей).

Одинаковый [текст](ACTOR_PROMPT.txt) получает три независимых исполнителя. Координатор подставляет label и endpoint из приватного launch.json. Условия распределены заранее случайно, фактические доступы закреплены в [квитанции](handoff-seal.json). Доступ через localhost 18891. Ограничение других инструментов обеспечивается инструкцией, шлюз технически ограничивает свой интерфейс. Состав графового и плоского пакетов различен. Правило выравнивания представлений обрезает конкатенацию первых четырёх до короткого общего размера 1 509 байт. Служебные ответы и публичная задача имеют самостоятельный учёт.

Проверка до фазы оценки — повторить `python -B prepare_source.py --verify-image`, `python -B build_packets.py`, сравнив хеши исходной постановки, обоих текстовых пакетов и графа. Эти команды используют общий локальный путь с кэшированной открытой базовой версией проекта. Слепые исполнители обращаются только по индивидуальным адресам. После окончания каждого независимого запуска сохраняется SHA256. Только при наличии всех трёх запускается `python -B lock_actors.py SHA1 SHA2 SHA3`, затем `python -B grade_locked.py locked.json grading --benchmark <test.parquet>` в Python с PyArrow. Раскрытие назначения — только после фиксации результатов. Если в исходной команде тестов выбран иной способ запуска, перенос на локальный образ должен сохранить опубликованный вызов.
