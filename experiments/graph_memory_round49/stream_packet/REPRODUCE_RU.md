# Воспроизведение

Все опубликованные пакеты содержат только числовые идентификаторы, времена доступности в группах, цены, целочисленные полезности и идентификаторы исходных источников. Тексты вызовов инструментов не исполняются. Проверка с Python 3.10+ и стандартной библиотекой — `python -B verify.py`. Она перепроверяет 90 000 замеров, итоги покрытия с числовыми свидетельствами, ограничения видимости и независимым решателем выборку из 32 вопросов. `input-seal.json` указывает SHA-256 источников и протокола, `forecast-seal.json` фиксирует предсказания до оценки, `judgment-source.json` указывает исходную таблицу диапазонов. Расчёт доверительных интервалов воспроизводит `analyze.py` с NumPy.

Чтобы повторить измерения, скопируйте каталог в отдельное место и запустите `python -B bench.py` с доступным g++ (C++17). Он компилирует `stream.cpp`, проверяет независимый перебор, затем выполняет один прогрев и пять измерений с чередованием порядка. `PACKET_BUILD_DIR` может указывать на существующий временный каталог для компиляции. Время зависит от оборудования. Числовая оценка финала выполняется и при наличии только поставляемых файлов. Для пересборки входов с нуля `fixture.py` требует исходные публичные шарды, адаптеры ISETrace и закрытые манифестами прогнозы предыдущих серий; `input.json.gz` содержит готовый результат этого объединения. На каждой невидимой границе в разреженном плане запись выполняется, чтение откладывается. Точное совпадение проверяется для всех запрошенных границ.
