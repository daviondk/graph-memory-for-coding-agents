# Воспроизведение

Минимальная проверка сохранённых прогнозов, всех парных контролей и целостности файлов использует только Python 3.

~~~console
python -B verify.py
~~~

Для полного пересчёта разложите каталог рядом с историческими сериями в структуре work/graph_memory_round40/natural_invalidations. Нужны подписанные каталоги work/graph_memory_round38/edit_ready, work/graph_memory_round37/code_visibility и work/graph_memory_round37/edit_demand. Источники и их SHA-256 записаны в plan-seal.json и score-seal.json. Установленный Python должен иметь NumPy. Последовательно запустите следующие команды из natural_invalidations.

~~~console
python -B project.py
python -B score.py
python -B analyze.py
python -B verify.py
~~~

project.py создаёт замороженные кандидаты без будущей цели. score.py присоединяет фактические пути и квитанции после фиксации и пересчитывает результаты для всех активных источников. analyze.py вычисляет контрасты и интервалы. Существующие подписанные результаты проверяются побайтно. verify.py независимо решает ту же задачу с разреженным множеством достижимых целочисленных цен и явным детерминированным разрешением равенства.

В observations.json.gz находится одна запись на попытку записи. Поле by_path сопоставляет каждому возможному пути пару двоичных признаков «оптимум изменился» и «простой достаточный сертификат разрешил возврат». actual_changed и actual_safe относятся к наблюдаемому пути. random_changed содержит точное среднее по допустимым путям, draw_changed — исход фиксированного жребия. В results.json находятся исходные числа, агрегаты с равным весом задач, их парные разности и интервалы. Документ REPORT_RU.md приводит основной зарегистрированный контраст и обязательные страты. Все ссылки внутри каталога относительны.
