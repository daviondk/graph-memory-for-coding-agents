# Воспроизведение

Из каталога этого эксперимента, в исходном рабочем дереве с локальными публичными 319 Parquet-шардами Handoff Debt и подписанными R37/R38/R40, выполните команды. Для raw-проверки нужен PyArrow. Траекторные строки обрабатываются в памяти как данные; в промежуточных и итоговых файлах остаются хеши, номера, категории, длины и счётчики.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B examine.py discovery
& $runner -B detector.py
& $runner -B examine.py holdout
& $runner -B evaluate.py
& $runner -B suffix.py
python -B verify.py
```

Код detector.gate принимает только запросный путь и возвращённый видимый ответ. Исторические планы нужны для проекции его решения на зарегистрированные адреса; поле before в процессе построения прогнозов не открывается. Результаты discovery и holdout диагностики содержат разметку оценщика; оператором gate эти файлы не читаются.
