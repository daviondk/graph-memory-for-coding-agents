# Что сохраняется в памяти кодового агента после правки

Три демонстрационных примера из Handoff Debt показывают, как одна и та же правка меняет контекст при двух правилах отзыва. Посетитель видит исходный пакет и результаты двух настоящих пересчётов. При отзыве целого файла исчезают все его блоки. При более точном отзыве исчезают только блоки, пересекающие строки подтверждённой замены, а адреса остальных сдвигаются в новую версию. Интерфейс показывает номера строк и, после запроса к отдельной базе аудита, байтовые диапазоны UTF-8. Метод консервативно отзывает затронутые строки целиком, включая случай частичного изменения одной строки. [Снимок действующего интерфейса](visitor.png) · [Источник следов взаимодействия](https://aclanthology.org/2026.emnlp-main.738/)

| Пример | Старый пакет | После отзыва файла | После отзыва диапазона | Что установлено по полным версиям файла |
|---|---:|---:|---:|---|
| Перенос адресов | 2 блока, 315 байт | Пуст | Те же 2, 315 байт | Все 11 сохранённых строк совпали с показанным текстом до и после. Например, первый блок перешёл со строк 1895–1902 на 1897–1904, с байтов [65866, 66075) на [66016, 66225). |
| Пересечение | 3 блока, 507 байт | Пуст | 1 блок, 74 байта | Два блока пересекли правку, три строки сохранившегося блока подтверждены. |
| Ранее устаревшие наблюдения | 14 блоков, 2 044 байта | Пуст | Те же 14, 2 044 байта | Три из 101 строки выбранного пакета (596–598 в блоке 75) расходились с полным файлом уже до правки. Повторное использование исходного текста не подтверждено. |

В третьем примере по всем кандидатам совпадение отсутствует у 260 строк из 597. Среди выбранных таких строк три. Перенос адресов не создал новых расхождений в этих трёх эпизодах. Файл в каждом примере один по условию отбора, поэтому грубый отзыв всегда опустошает пакет. Примеры намеренно подобраны по разным исходам и не оценивают распространённость этих событий. Для определения средней доли используются все подходящие правки в родительском исследовании span_updates. [Правило отбора примеров](PLAN_RU.md) · [Привязка к зафиксированным исходным метаданным](source-bindings.json)

Обычный запрос обращается только к reader.sqlite. Никакой исходный текст или команда в базах не хранится. При отдельном запросе аудит сопоставляет SHA-256 ранее показанной строки с хешами строки в полной версии до правки и по новому адресу после правки. По клику на блок доступны все три хеша для каждой уцелевшей строки. Отдельно показаны SHA-256 целых версий и число проверенных строк. Два независимых целочисленных решателя воспроизводят девять сохранённых исходов по трём примерам. Проверены 611 троек хешей. Для просмотра достаточно Python 3 со стандартной библиотекой.
