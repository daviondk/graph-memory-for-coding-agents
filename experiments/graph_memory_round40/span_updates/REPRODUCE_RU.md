# Воспроизведение

`python -B verify.py` из этой директории повторно соединяет результаты по запуску и событию и проверяет число случаев, тексты которых подтвердил отдельный сырой оценщик. Требуется только стандартная библиотека Python.

Для полного повтора расположить рядом каталоги graph_memory_round37, graph_memory_round38 и graph_memory_round40 с natural_invalidations. Запустить `python -B experiment.py` в окружении с NumPy. Для дополнительного аудита смонтировать закреплённые Parquet Handoff Debt в D:/CodexResearch/x20-r31-handoff и запустить по очереди `python -B audit_original.py` и `python -B audit_strict.py` с PyArrow. Оценщики сверяют SHA-256 исходных шардов. Приложения и команды из историй не запускаются. Поштучная проверка сохраняет только числовые результаты и анонимные ключи.

В scored.json.gz поля old и new относятся к позициям в неизменном исходном списке естественной истории, eligible содержит уцелевшие блоки затронутого файла. Неподвижность адресов проверена отдельно от сохранения идентификаторов. [Исходный план видимых наблюдений](../natural_invalidations/REPORT_RU.md) · [Протокол](PROTOCOL_RU.md)
