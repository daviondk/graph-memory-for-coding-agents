# Что остаётся от памяти после реальной правки файла

После 676 подтверждённых замен в основной группе Handoff Debt отзыв целого файла сохранил прежнюю выдачу в **3** случаях. При отзыве только пересекающихся с правкой блоков упорядоченные идентификаторы сохранились в **180** случаях. Дополнительная проверка текста по полным снимкам файла подтвердила **175 из этих 180** случаев. Остальные пять показывают, зачем проверять исходное наблюдение ещё до переноса. В основной группе разность частот по идентификаторам составила **+26,76 п.п.** при равном весе каждой задачи, 95%-й кластерный интервал **[20,36; 33,91]**. Для 395 правок с изменившимся количеством строк сохранили выдачу в 107 случаях, в 59 из них все адреса также остались прежними. При наличии любых исходов исследованных попыток записи консервативное правило откатывается к отзыву всего пути, если подходящей квитанции нет. В основной группе при таком правиле выдача сохранила идентификаторы в 346 из 864 попыток против 169. В обеих группах 1 396 из 3 525 против 711. Сюда включены отсутствующие в памяти пути. [Парные исходы и знаменатели](results.json)

**Метод.** Материализуем набор из ранее наблюдавшихся блоков по восемь строк при бюджете 2 048 байт. Узлы несут адрес и длину показанного источника. Для чистого предшествующего просмотра редактор дал наблюдаемую квитанцию, позволяющую локализовать границы единственной замены. На этом основании отзываем целые пересекающиеся блоки и меняем координаты уцелевших блоков ниже замены. Проверяем, остался ли прежний выбранный набор оптимальным. Число байтов, уцелевших в новой оптимальной выдаче основной группы, составило 431 330 из исходных 662 003. Такой результат относится к хранению уже виденных свидетельств с фиксированными оценками. Здесь не добавляли новые наблюдения и не измеряли успех решения задачи. [Код](experiment.py) · [Воспроизведение](REPRODUCE_RU.md)

**Проверка исходного содержимого.** После фиксации планов отдельно прочитали исходные Parquet и сверили хеши перенесённых строк затронутого пути со служебными версиями до и после каждой из 2 696 правок. Из 74 241 сопоставления в 8 578 строка уже отличалась от версии до записи. Во всех 65 663 остальных сопоставлениях после переноса хеш совпал. Среди 22 466 строк именно выбранных блоков при сохранении всего пакета 428 не совпали с текущим исходником. Это затронуло 27 выдач из 691. Среди 175 подтверждённых пакетов основной группы три вовсе не ссылались на изменённый файл. Прочие файлы в рассматриваемой квитанции полной версии не имеют. Сравнение держит их состояние фиксированным. Служебная версия была доступна только оценщику. В работающей памяти для аналогичной гарантии нужны проверенная версия первоначального чтения либо фактическая сверка источника.
