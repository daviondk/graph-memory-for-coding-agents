# Диагностика исходного содержимого

В первичной проверке 8 578 из 74 241 перенесённых строк уже расходились с исходным файлом до рассматриваемой записи; у 622 из 44 918 строк прежнего выбранного пакета обнаружено расхождение после операции. Сам перенос не создал новых расхождений среди первоначально совпадавших строк. Для оценки публикационного утверждения нужен более строгий исход.

После наблюдения исходных расхождений отдельно считаем точность байтов всего выбранного пакета на затронутом пути при полном повторном использовании, эпизоды с ранее устаревшими выбранными строками, долю подтверждаемых планов в основном и дополнительном наборах. Диагностируем только видимые преобразования строк — снятие/добавление табуляции, удаление правых/левых пробельных символов — и фиксируем необъяснённые случаи. Для других путей полной версии в этой квитанции нет. Проверка равенства по текущему файлу доступна реальной БД лишь при явном повторном чтении либо при доверенном версионном соответствии из записи. При расчёте консервативной нижней оценки любое байтовое расхождение на затронутом пути запрещает утверждение о полном повторном использовании исходного текста. Это вторичный результат с проверкой снимка, подлежащий независимой проверке.
