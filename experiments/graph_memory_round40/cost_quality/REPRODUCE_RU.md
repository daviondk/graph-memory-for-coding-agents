# Запуск читателя и воспроизведение эксперимента

Из каталога этой поставки можно запустить небольшой подписанный пример без прежних раундов и исходных данных проекта. Нативный режим и проверка архива работают в стандартном Windows Python x64. Для обученных вариантов требуется NumPy. DLL собрана GNU C++ для Windows x64, исходник поставляется рядом.

```powershell
python -B verify.py
python -B demo.py native
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B demo.py raw
& $runner -B demo.py density
& $runner -B demo.py dp
```

Команда выводит выбранные ID, число токенов и внутренние компоненты времени в наносекундах. Пример выбирается детерминированно по минимальному хешу вопроса при seed 13. Один и тот же результат у нескольких режимов этого примера допустим. Файлы содержат метаданные и признаки, исходный текст и действия архивной истории не исполняются. Файл kernels.dll можно пересобрать из исходника.

Полный повтор требует сохранённых входов R33/R35, классов из R39/global_packet и рангов предыдущих раундов на тех же относительных путях. Для сравнения со снимком сначала выполните verify.py. Новый замер изменит времена и их контрольные суммы. Используйте отдельную копию каталога на том же уровне.

```powershell
g++ -O3 -std=c++17 -shared -static kernels.cpp -o kernels.dll
& $runner -B inputs.py
& $runner -B bench.py
& $runner -B bench.py cold
& $runner -B analyze.py
& $runner -B check_model.py
& $runner -B check_intervals.py
```

Файлы warm-SEED.json.gz хранят три повтора четырёх режимов каждого вопроса, траектории и хеши списков. Порядок режимов и временных полей дан в time-seal.json. cold.json содержит все 20 измеренных запусков новых процессов. В results.json даны абсолютные значения, попарные интервалы качества и времени, холодные издержки, выбранный порог и результат его применения.
