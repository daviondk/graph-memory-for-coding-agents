# Воспроизведение

Проверка завершённого архива требует только Python 3.11+.

```powershell
python -B verify.py
```

Для повторного расчёта подготовить Python c requests и NumPy на Windows, Linux с Python 3.11+ и SQLite. Исходный PageStore использует POSIX-вызовы для защищённой записи и синхронизации каталога. Для фактического запуска использована WSL-дистрибуция CodexX20MSR с диском на D. Под Windows два авторских теста в исходном виде упирались в отсутствие `os.fchmod` и POSIX-семантики каталога. Исходники и содержимое тестов не модифицировались. Для каждой транзакции создаётся новая временная SQLite и каталог страниц внутри Linux. После проверки временные данные освобождаются. В файл `cases.json.gz` входят ID путей, размеры и диапазоны старых блоков. Тексты команд и содержимое файлов рабочего репозитория не нужны.

Исходники восстанавливаются только из публичного архива коммита, каждое выбранное содержимое проверяется по его Git blob. По умолчанию fetch_source.py использует диск D. Для новой машины/дистрибуции исправить только путь к внешнему кэшу в fetch_source.py и replay.py. В общей рабочей копии каталоги span_updates и natural_invalidations уже содержат проверенные исходные данные. При наличии подписанного `cases.json.gz` шаг project.py можно пропустить.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B fetch_source.py
& $runner -B project.py
wsl -d CodexX20MSR --cd /mnt/d/CodexResearch/x20-bench-workspace/work/graph_memory_round40/memtrace_reference -- /usr/bin/python3 -B -u replay.py
& $runner -B grade.py
& $runner -B verify.py
```

Для полного повтора использовать новую копию архива. Измеренные времена и доступное место зависят от оборудования; проверка сохранённого manifest относится к первоначальному запуску. Проверка доступности расширения до полной панели заранее определена в протоколе. Ручная замена результатов функцией вычисления метрик не нужна — каждый исход имеет собственный SQL-результат, а каждый сохранённый агрегат проверяется по этим строкам.
