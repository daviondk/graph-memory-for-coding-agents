# Воспроизведение статьи и демонстрации

В распакованном каталоге хранятся редактируемый paper.tex, sources.bib, четырёхстраничный paper.pdf, снимок, консоль, две SQLite-базы, MP4 и сценарий его создания. Хеши файлов и отдельно происхождение переносимого пакета данных проверяются из этого каталога.

~~~console
python -B verify_release.py
python -B launcher.py --port 8773
~~~

Откройте адрес, который выводит сервер. Демо запускается на 127.0.0.1 и читает только runtime/ через стандартную библиотеку Python. На q02 кнопка Outside dependencies оставляет прежний пакет, In the packet заменяет №11 на №19. Кнопка At the prefix boundary открывает пример q07, где достаточный сертификат консервативно пересчитывает прежний оптимум. Режим Full recomputation позволяет сравнить с полным расчётом, а независимая оценка открывается через Recompute and score. Источники и лицензии метаданных приведены в runtime/DATA_SOURCE.md. Пример с другими бюджетами показывает чувствительность. Основной бюджет составлял 2 048 токенов.

Для повторения браузерного теста нужны Playwright и Chromium. Можно указать BROWSER_EXE. Перед записью видео нужно установить англоязычный локальный голос Windows System.Speech, FFmpeg, Python Pillow и Playwright. Ролик сохранён в H.264/AAC со встроенными английскими подписями. Семь кадров захватываются из браузера после фактического выполнения запросов и проверок состояния, к ним добавляются пояснения и локально синтезированный голос. Путь для новой записи должен ещё не существовать. Различные версии браузера, системных шрифтов и кодеков могут менять байты и длительность ролика.

~~~console
python -B check_ui.py
python -B record_video.py --out new-recording.mp4
~~~

Исходник PDF использует официальный класс IEEEtran с параметром conference. Сборка проверена на Tectonic 0.17.0. При впервые установленном TeX требуется загрузить его пакет ресурсов. С заполненным кэшем команда выполняется офлайн. Визуальная проверка выполнена рендерингом всех четырёх полос через Poppler и просмотром изображений. Для проверки геометрии требуется PyMuPDF.

~~~console
tectonic --only-cached paper.tex
python -B validate_pdf.py
~~~

Значения измерений доступны в evidence.json. Для обновления этого файла из исходных исследований нужен рабочий каталог work/graph_memory_round40/demo_revision с сериями graph_memory_round39, graph_memory_round40/natural_invalidations. Скрипт audit.py сверяет метрики и хеши первичных расчётов. Содержимое ZIP автономно для запуска консоли, проверки контрольных сумм, чтения черновика и просмотра видео. Результаты не требуют авторизации.
