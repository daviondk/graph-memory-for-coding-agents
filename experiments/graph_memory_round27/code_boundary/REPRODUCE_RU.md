# Воспроизведение

Код выполняет только статическое чтение текста и разбирает дерево Python. На этом стенде кэши лежат в D:/CodexResearch/x20-r27-code-data, канонический WordPiece-токенизатор R23 — в D:/CodexResearch/x20-isetrace-runtime/inputs/tokenizer.json (SHA256 d241a60d5e8f04cc1b2b3e9ef7a4921b27bf526d9f6050ab90f9267a1f9e5c66). Для получения публичных входов запустите fetch.ps1. Перед прогнозом оба семейства входов и протоколы проверяются по SHA.

В данном каталоге выполните run.ps1. Отдельный компьютер может использовать один Python 3 с numpy, tokenizers и pyarrow. Самостоятельные точки входа вызываются в таком порядке:

1. prepare.py и prepare_loc.py скачивают только заранее выбранные файлы на неизменяемых base_commit и сохраняют раздельные карты наблюдений и эталоны. Локальный JSON с адресами файлов и исходники сохраняются в приватном кэше D.
2. predict.py natural и predict.py loc формируют адреса и фактический wire без доступа к эталонам. Прогнозы подписаны SHA.
3. score.py natural и score.py loc открывают эталоны и сопоставляют адреса со строками. Все оценки по задачам остаются в per-case и loc-per-case.
4. audit.py другим кодом заново разбирает исходный diff и сверяет результаты с исходными шагами/токенными смещениями, затем перепроверяет статистику.
5. report.py печатает таблицы в REPORT_RU.md. Для работы с уже запечатанными результатами проверьте SHA256 через verify_release.py. Прогоны в новой копии исследования меняют только измеренные wall time и связанные хэши метаданных. При повторном запуске на геометрически ином железе замеры следует проводить отдельно от официального архива.
