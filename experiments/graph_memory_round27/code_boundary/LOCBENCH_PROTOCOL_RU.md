# Независимая панель Loc-Bench

До формирования любых прогнозов или открытия метрик SWE-Explore добавляем отдельное испытание локализации изменённых строк в известном файле. Основание — после исключения неограниченных и неоднозначных запросов в естественной панели доступно лишь 17 пар до сверки исходников. Панели не объединяем.

Используем публичную тестовую таблицу Loc-Bench ревизии c44cf3b74e07ca642cec841b471a9939907c12a7. Шесть задач прежнего эксперимента R8 с ранжированием функций сюда не входят. Берём все задачи в pandas-dev/pandas, scikit-learn/scikit-learn, jax-ml/jax, scipy/scipy, sympy/sympy, matplotlib/matplotlib, numpy/numpy, dask/dask, modin-project/modin, UXARRAY/uxarray. Фильтры описания и путей те же, что в SWE-Explore. Для каждого issue выбираем один изменённый производственный .py из исходной версии с хотя бы одной удаленной/замененной непустой строкой по минимуму SHA256(issue + NUL + path). Чистые вставки не дают такой цели. Сравниваем каждую исходную целевую строку с текстом base_commit; при любом несовпадении отметим исключение. Решателям передаются только описание задачи, априори известный путь и исходная версия. Diff, текст удалений, координаты правки, подсказки, тесты и поздняя версия не участвуют в выборе окна. Разрешенная задача — извлечение текста, код источников не исполняется.

Первым наблюдением служит один открытый 16-строчный фрагмент из последовательных неперекрывающихся блоков файла. Победителя выбираем по Okapi BM25 по тексту issue (k1=1.2, b=0.75, IDF log(1+(N-df+.5)/(df+.5)), уникальные casefold ASCII identifier/number terms, минимальный порядок при равных баллах). При пустом блоке берем следующий по баллу с видимым токеном. У всех шести R27 политик одинаковый исходный фрагмент. Усиленный индексный контроль открывает следующий по BM25 непустой еще не показанный блок и продолжает вправо от его начала в пределах общего лимита. Индекс использует полный файл и может выйти за соседние области. Замеряем цену первичной обработки. Чувствительность этого сравнения отражает важность дальних переходов.

Первичный контраст в этой панели — both против right в одинаковом фактическом числе токенов, единица issue, исход recall всех полностью видимых человеческих исходных измененных строк. Никакого обучения, выбора подгруппы по эффекту или настройки полубюджета. Вторичные те же, что в натуральной панели, плюс контроль второго BM25; учитываем ограниченный набор репозиториев и явную подсказку пути. Обязательность измененной строки для успешного ответа или причинный эффект на выполнение задачи такой прокси не устанавливает.
