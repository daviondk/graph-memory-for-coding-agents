# Токенные границы и окна предложений при чтении исходной памяти

Первичное сравнение на 5304 вопросах из 442 статей SQuAD использует одинаковые исходную память, выбранную компоненту и фактическую стоимость дополнительного чтения. При 155,25 WordPiece на запрос метод R26 полностью восстанавливает эталонный адрес в **5121** случаях, двухкраевое окно предложений — в **5120**. Разность R26 минус двухкраевое окно 0,02 п. п. При попарном выравнивании с одиночным окном R26 даёт 5125 попаданий и окно 5099, средняя стоимость каждого 205,83 токена. Разность 0,49 п. п. [95% ДИ 0,30; 0,70], 26 выигрышей и 0 потерь, p=1e-05. По исходному онлайн-потолку R26 минус двухкраевое окно 0,13 п. п. [95% ДИ 0,02; 0,26], 9 выигрышей и 2 потерь, p=0,06543.

До хода чтения покрыты 4934 вопросов. Среди 370 исходных пропусков первичный условный эффект 0,27 п. п. [95% ДИ -0,85; 1,47], 3 выигрышей и 2 потерь, p=1. В 132 вопросах отсутствует подходящая компонента для действия. [Построчные результаты](outcomes.json.gz) · [независимая верификация](verified.json)

Настоящий SentenceWindowNodeParser 0.14.26 построил 94831 узлов для 442 целых статей. У каждого совпали исходная подстрока и строка metadata[window] из авторской реализации. Центральное предложение определяется по видимому пересечению с одной заранее определённой компонентой. Только в ходе дополнительного чтения возвращается скрытый текст соседей. Нативный парсер хранит окно, ранжировщик BM25 и бюджетный адаптер добавлены для данного сравнения. Двухкраевое окно вычитает уже известные диапазоны и переносит неиспользованную квоту. У него нет потерь бюджета на повторно выданные символы источника. Пара с одинаковой ценой использует фактические длины обеих выдач. В онлайн-режиме обе политики заранее получают потолок 256 и могут потратить разные суммы. Кластеры для доверительного интервала — статьи. Измеряется доступность адресуемого эталонного текста, а сравнение ограничено выбранной статьёй и ранее использованной выборкой R26. Доступ ко всем границам предложений требует заблаговременного разбора документа. Генерация ответа и полный поиск документов системы лежат за пределами этой проверки.
