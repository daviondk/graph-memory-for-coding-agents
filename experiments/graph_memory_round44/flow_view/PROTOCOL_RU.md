# Поддержание признаков связи по мере поступления вызовов

Основной результат — точное воспроизведение двух бинарных признаков FEEDS при онлайн-обновлении без хранения таблицы пар в пользовательском представлении. Общая часть чтения наблюдаемых инструментальных событий выделяет типизированные значения. Эталонная семантика соседства допускает связь, пока у значения ровно один наблюдаемый источник. Встреча второго источника отзывает прежние связи. На вход сравниваемых представлений подаём одинаковые изменения свидетельств с единичным весом. В альтернативном представлении держим суммы входящих и исходящих весов на уровне результата вызова. Ненулевые суммы дают два признака для всех его видимых фрагментов. Память общей части, которая находит и отзывает свидетельства, нужна обоим планам. Пары источников и адреса объяснений нельзя восстановить только по суммам.

На всех 1 207 тестовых траекториях ISETrace проверяем каждую границу завершённой группы. Эталон 1 — точное множество пар старого инкрементального оператора (R21), включая отзыв. Эталон 2 — признаки физически перестроенных авторских графов в исходной панели 2 000 вопросов R42. Контроль монотонности запоминает однажды выставленные признаки, дальнейшие обнуления игнорирует. Фиксируем частоту ложных признаков, число записей, максимальные и конечные размеры представлений. Цифры сравнения памяти относятся к логически эквивалентному отображению флагов, остальная информация полного графа связей недоступна из счётчиков. Для ограниченного микроизмерения подаём одинаковые уже извлечённые события и запрашиваем все признаки в каждом состоянии. Оба плана — словари Python в памяти, проверяем и вариант с однопроходной агрегацией обычного списка пар. Порядок A/B и B/A чередуем по траекториям, три повтора. Записываем раздельно время обновить и выдать, число обращений, размер сериализованного состояния (единая кодировка идентификаторов и счётчиков), парный интервал отношения сумм на уровне траектории. Публичные траектории читаются как данные. Генерация новых вызовов и оценка решённых задач сюда не входят.
