# Когда двух признаков достаточно и что стоит их обновление

Для выдачи двух признаков передачи значения у каждого результата инструмента достаточно сумм весов его входящих и исходящих свидетельств. Если несколько значений связывают одни и те же вызовы, каждое даёт единичный вклад. Появление второго возможного источника значения отзывает прежние вклады. Индикатор равен единице тогда и только тогда, когда соответствующая сумма положительна. Это следует из неотрицательности числа активных свидетельств. Внутри одного завершённого пакета вызовов изменения публикуются вместе. Общий извлекатель всё ещё хранит сведения, необходимые для отзыва. Само представление для чтения может обходиться без списка пар. [Алгоритм](flow.py) · [Протокол](PROTOCOL_RU.md)

Проверено **31 279** состояний **1 207** траекторий ISETrace. Оператор обработал 17 838 добавлений и 9 227 отзывов доступных свидетельств. Во всех состояниях признаки совпали с отдельным проверенным парным индексом. На историческом срезе **136 892 из 136 892** строк кандидатов также совпали с признаками авторского графа, независимо перестроенного на наблюдавшейся части каждой траектории. Эти два признака в отдельном контроле дали 82,91% полного покрытия против 79,16% у модели без связей. Система, однажды выставляющая флаг навсегда, показала 68 480 лишних флагов по последовательности состояний. Они встречались в 13 661 из 31 279 состояний (838 траекторий). Это число повторных наблюдений устаревших флагов. [Оценка качества чтения](../../graph_memory_round43/relation_budget/REPORT_RU.md)

Простой вариант со счётчиками оказался дороже на этом разреженном графе. При одном чтении всех флагов на группу отношение времени таблицы пар ко времени счётчиков равно **0,623 [0,611; 0,636]**. При суммировании расчётного размера состояний по группам таблице пар требуется 395 865 байт, счётчикам — 498 032 (одинаковая кодировка малых целых без заголовков). Эта сумма характеризует объём снимков, не физический размер БД. Сравниваются два Python-оператора на одинаковых изменениях, текстовый парсер и эмбеддинги за пределами таймера. Сохранён отрицательный результат по скорости и объёму. [Поштучные файлы и интервалы](results.json)
