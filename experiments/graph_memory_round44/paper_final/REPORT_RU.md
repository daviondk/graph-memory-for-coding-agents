# Демонстрационная статья по поддержанию памяти агента

**Maintaining Source-Linked Evidence Views for Agent Memory** — четырёхстраничная англоязычная рукопись в формате IEEE. Демоверсия показывает, как при изменении источников поддерживать отобранные по ширине контекста свидетельства и проверять их происхождение. Математический результат — необходимое и достаточное условие неизменности пакета при исключениях с зафиксированными порядком, бюджетом, стоимостями и полезностями. [Статья PDF](paper.pdf) · [Редактируемый исходник](paper.tex) · [Автономный архив с четырьмя консолями](candidate.zip) · [Видео с озвучкой](walkthrough.mp4)

Эксперименты на полном ISETrace, 2 000 вопросов и 5 общих инициализаций, дали 83,07% полного покрытия против 81,19% при штатном выборе эпохи и 82,94% против 80,90% при выборе по целевой бюджетной метрике. В обеих парах порядок нативной R-GCN и кандидаты одинаковые. Простая сортировка по обученной полезности и точная оптимизация качества близки. При запросе после восьмой завершённой группы вызовов графовая модель с признаками степени дала 85,67% против 81,17% без графа на 649 уже отвечаемых вопросах. По сравнению с R-GCN на этом расписании интервал включает ноль. В кодовых траекториях сохраняемость пакетов и соответствие байтам источника измерены отдельно. В четвёртой консоли можно проиграть фактическое использование результата одного инструмента другим. При появлении второго возможного источника часть старых свидетельств отзывается. Показаны актуальные флаги и лишние флаги, которые сохранил бы режим без отзыва. Выбраны три публичные траектории с различными событиями; это демонстрационные примеры. На каждом из 84 состояний доступна независимая проверка по рассчитанному отдельно списку пар. Исходные аргументы команд и ответы инструментов в переносимый пакет не входят. Остальные консоли воспроизводят бюджетный выбор и проверку строк исходного файла после правок.
