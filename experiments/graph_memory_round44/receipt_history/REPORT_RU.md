# Насколько полезно записывать ответы на прежние правки

История успешных правок дала кодовому агенту некоторое количество запрошенных позднее строк. При общем писателе LRU на 8 192 байта и читателе на 2 048 байт объединение результатов просмотров и прежних правок дало **66/2 696 эпизодов** с реальной востребованностью сверх квитанции текущей правки. Память только просмотров дала **65/2 696**. Один выигрыш, ноль потерь. Разность при равном весе каждой задачи составила **+0,032 п.п.**, 95%-й интервал от **0,000 до +0,097 п.п.** По строкам эффект выразительнее — 415 востребованных вхождений против 379. Дополнительные строки понадобились в трёх эпизодах из трёх задач двух репозиториев. [Зафиксированный протокол](PROTOCOL_RU.md) · [Все 12 режимов и шесть срезов](summary.json)

Все строки таблицы используют читательский бюджет 2 КиБ. При снятии ограничения читателя и записи объединённый пул содержит максимум 465 из 5 685 фактически запрошенных информативных вхождений сверх текущей квитанции (**8,18%**). Исходный пул просмотров содержит максимум 429. Весь глобальный снимок объединённой политики при 8 КиБ занимал медианно 1 492 байта против 1 352,5 для просмотров. На вложенной отложенной части результат 17 против 16 из 1 071, +0,092 п.п. [0,000; 0,275]. На всех 752 окнах, прослеженных до подтверждённого завершения, политики дали по 44 попадания. На основных 676 — по 25.

**Что именно хранилось.** Все политики видели одно хронологическое начало каждой из 1 313 трасс и до появления будущего пути распределяли общий бюджет по всем Python-файлам. Писателю смешанного режима передавались только строки, действительно показанные прежней успешной операцией. Приняты 4 015 квитанций, одна пропущена по признаку усечения. Отдельный оценщик после замораживания прогнозов сверил все **42 489** строк принятых квитанций с фактической версией файла сразу после операции. Совпали все. Среди возвращаемых строк всех 12 политик, независимо проверенных в целевой версии, также ноль ошибочных координат или несовпадающих текстов. Возможная область применения такой памяти — последующее обращение к строкам прежнего изменения. Свидетельство о масштабной экономии самостоятельных чтений или об успехе полного решения задачи потребовало бы другого эксперимента. [Аудит источника](historical-audit.json)

**Воспроизведение.** Проекция и прогноз 12 политик заняли 14,03 и 3,63 с, оценка будущих запросов — 11,58 с, отдельно проведён аудит прежних версий. Предыдущий [эксперимент с несколькими просмотрами](../history_writer/REPORT_RU.md) предоставляет исходный глобальный снимок и дисковое представление. Для проверки сохранённых результатов из этого каталога достаточно Python 3.11+ и `python -B verify.py` при наличии соседнего каталога `history_writer`. Для полного пересчёта нужны PyArrow, NumPy, исходный Handoff Debt и те же зафиксированные R37/R40/R42. В копии с отложенным манифестом выполняются `python -B replay.py`, затем `score_receipts.py`, `audit_receipts.py`, `analysis_receipts.py` и `verify.py`.
