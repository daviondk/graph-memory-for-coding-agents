# Где помогает признак передачи значения

Если хотя бы часть нужного текста находилась во фрагменте, участвовавшем в передаче значения между вызовами, FEEDS повысил Full Support с **79,77% до 86,30%** (+6,53 п.п. [4,54; 8,62], 619 вопросов). На остальных 282 вопросах получили **76,88% против 77,80%** (−0,92 п.п. [−3,78; 1,82]). Разность этих выигрышей **+7,45 п.п. [4,10; 10,96]**, с общими перевыборками траекторий и инициализаций. Это указывает, когда помогает структурный сигнал в данном бенчмарке. Фактическая разметка известна только при оценке. [Протокол](PROTOCOL_RU.md) · [Все страты](results.json)

Оставив только непомещающиеся в 2 048 токенов пулы, в которых вообще есть кандидаты с такими связями, получаем разность эффектов **+8,01 п.п. [3,37; 12,72]**, 603 вопроса с пересечением и 183 без него. Вопросы, которым нужны несколько фактов, получили +6,67 п.п., прямые +1,91 п.п.; разность +4,76 п.п. [0,21; 9,49], вторичный срез. Признак участия в передаче может коррелировать с механизмом создания запросов и сложностью вопроса. Контроли по размеру пула и наличию рёбер отвечают только за эти два фактора. Выбор маршрута чтения с учётом будущего эталона привёл бы к утечке. [Формулировка исходной задачи Wang et al.](https://arxiv.org/abs/2609.25913) · [Данные по 2 000 вопросам без текста](question-strata.json.gz)

`python -B verify.py` пересчитывает основные агрегаты из сохранённых вопросов. В исследовательском окружении `diagnose.py` заново определяет пересечения на авторских координатах и считает парные интервалы.
