# При каких задачах помогает передача значения

Диагностический анализ про уже зафиксированные модели FEEDS (полный числовой вариант и два индикатора), RESOURCE_FLOW и rich без рёбер. Списки кандидатов, пакеты и качества всех этих методов заморожены в R43. Для каждой эталонной позиции вычисляем из независимых символьных интервалов, может ли её закрыть хотя бы один уже видимый кандидат, инцидентный FEEDS. Основной контраст до анализа — разность выигрыша FEEDS−rich по Full Support между вопросами с хотя бы одним таким эталонным символом и без единого такого символа. Это условная диагностическая величина с известной после исполнения разметкой; она не предлагается в качестве маршрутизатора запроса. Повторяем тот же контраст при непомещающемся пуле (сумма стоимостей >2 048) и хотя бы одной наблюдаемой связи FEEDS для всех сравниваемых вопросов. Учитываем исходную трудность и не приписываем эффект признаку причинно при таком разбиении. Вторичные срезы — прямые/связанные/многофактные запросы, число событий источников, любой фрагмент/покрыто всё/часть/ноль. Указываем знаменатель и исходный результат каждого метода.

Основной набор 901/657 и пять общих инициализаций. Для обоих подмножеств совместно пересэмплируем траектории и seed 10 000 раз, сохраняя совпадающие задания и разную численность страт. Бюджет 2 048 токенов. Остальные интервалы индивидуальные. Прямое попадание эталона в endpoint потенциально отражает способ построения исходных запросов и частоту участия нужного вызова в других операциях.
