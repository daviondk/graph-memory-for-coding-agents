# Повтор расчёта

Нужны подготовленные входные данные R23/marginal_open и R23/marginal_transfer и сохранённые вопросы по ISETrace и MultiDoc2Dial, а также токенизатор и SQLite-каталоги на D. Запустить `python -B routes.py`, затем `python -B evaluate_frontier.py`. Первый шаг фиксирует адреса и реально оплаченные возвраты до доступа к эталонам. При необходимости обрезает два фиксированных возврата до меньшего фактического размера для дополнительного сравнения стоимости. Второй шаг присоединяет исходные эталонные диапазоны, объединяет старый и новый текст, проверяет воспроизведение старших контролей. Вычисляет одновременные интервалы по семейству четырёх сравнений, точные кластерные перестановки или 100 000 случайных перестановок при большом числе групп. [Фиксация до оценки](action-lock.json) · [Результаты](results.json)


После подготовки marginal_mmr запустить `python -B against_mmr.py` для последующего сравнения по тем же вопросам. Скрипт фиксирует фактически показанные координаты и равенство расходов по каждому вопросу.
