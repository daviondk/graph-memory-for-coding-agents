# Дополнительное сравнение с MMR

Обе исходные серии уже дали агрегированные результаты. Ниже фиксируем последующее сравнение конкретных адресов. Базовый метод — адаптация MMR при λ=0,5 (пересечение с одним исходным интервалом, вариант max_50). Вопросы, видимый контекст, фактический токенизатор и один новый вызов совпадают. Сравним выступившее лучшее по суммарному Full Support правое продолжение с max_50, в том числе после симметричного выравнивания меньшей длиной каждого ответа в паре. Берём max_50 по исходному протоколу MMR, без выбора λ по новым исходам. Отдельный механистический контроль сохраняет именно адрес, выбранный MMR. Если его показанный непрерывный кусок оканчивается до конца поля, переносим начало на конец этого куска; иначе сохраняем прежний адрес. Контроль изолирует замену смещения без смены поля или дополнительного подбора компонентов. Для него сохранён полный исходный массив кандидатов, а пятый метод не вводится. Это последующие оценки на знакомых данных; сообщим число выигрышей и потерь, диапазоны затрат и парные интервалы.
