# Координатная адаптация MMR для следующего чтения памяти

Carbonell и Goldstein (SIGIR 1998) последовательно выбирают кандидата, максимизирующего λ·Sim1(кандидат, запрос) − (1−λ)·max Sim2(кандидат, ранее выбранный элемент). Переносим критерий на одно чтение после уже выданного контекста. Исходное приложение — разнообразие документов и суммаризация. Материал настоящего опыта — ISETrace и MultiDoc2Dial. [Исходная статья авторов](https://www.cs.cmu.edu/afs/cs/Web/People/jgc/publication/MMR_DiversityBased_Reranking_SIGIR_1998.pdf)

До расчёта новых прогнозов фиксируем все 2 000 вопросов ISETrace, 1 207 кластеров по траекториям, и 661 вопрос MultiDoc2Dial, кластеры по диалогам. Точные выдачи, токенизатор, порядок кандидатов и лимиты повторяем из R23/marginal_open и R23/marginal_transfer. Это повторный анализ обоих знакомых наборов. На каждом вопросе доступны только запрос, текст ранее предъявленных фрагментов, их координаты, длины полей и токенный бюджет. Диапазон Iᵢ=[lᵢ,rᵢ) следующего чтения оцениваем той же замороженной формулой R23. Открытие не более 256 реально повторно подсчитанных WordPiece с заголовком, начальная память до 2 048 токенов сохраняется.

1. Релевантность Rᵢ — видимый BM25 k₁=1,2, b=0,75 с положительным IDF, делённый на максимальный балл запроса. При отсутствии лексических совпадений R=0 для всех. Нулевой BM25 приравниваем к нулю релевантности. Точное равенство итогового балла разрешает лучший исходный ранг BM25, затем порядок появления.
2. Redundancy для MMR-max — наибольшее отношение |Iᵢ ∩ Vⱼ|/|Iᵢ| по отдельным фактически предъявленным диапазонам этого поля. Для MMR-union — |Iᵢ ∩ ∪Vⱼ|/|Iᵢ| по всем предъявленным координатам. Пустой I получает redundancy=1. Интервалы Vⱼ берём в том виде, в каком их предъявили до разбиения на 128-токенные окна. Это асимметричная мера фактически дублируемой доли кандидата, применяемая в роли Sim2. Для любой пары разметки по полям max ≤ union.
3. Фиксируем λ ∈ {0,25; 0,50; 0,75} с λ=0,50 основным. Все шесть MMR-политик могут выбрать кандидата с нулевой ожидаемой новизной, выполняют одно открытие при наличии окон. Ещё два диагностических варианта при λ=0,50 используют общую маску «видна положительная новизна по объединению» и отказываются при пустой маске. Наследуем глобальный BM25, first_positive и rank_novelty. Измеряем отдельно степень совпадения MMR-max и union, сколько кандидатов имеют разные penalties и сколько выборов меняется. Искусственный контроль двух несмежных показанных частей должен разделять определения.
4. Два заранее заданных сравнения на каждом корпусе — FS объединения MMR-max при λ=0,50 минус first_positive и MMR-union при λ=0,50 минус MMR-max. По каждому корпусу берём парный кластерный bootstrap по 10 000 ресэмплам, совместный 95% wild max-|t| на два первичных контраста и дополнительную точную проверку перестановкой знаков на разреженных кластерах, когда таких кластеров ≤20. Прочие λ и метрики описательны. Помимо FS считаем coverage, новые уникальные символы, расходы и нулевые чтения среди выданных, изменения решений. Показываем качество и после симметричной ретроспективной обрезки каждой первичной пары до одинакового реального бюджета по запросу.
5. Раздельно измеряем построение BM25 и окон, оценку координат/пересечений, выбор MMR и простого first_positive; сравнение CPU проведём только на оконных и числовых данных с повторениями. Стоимость обращения к LLM не измеряется. Исследование не подбирает λ по тесту и не заявляет оптимальность. Все решения о выборе делаем до соединения с gold.
