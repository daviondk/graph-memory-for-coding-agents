# Повтор расчёта

После подготовки выпусков R23 на диске D запустить `python -B ceiling.py`. Скрипт читает только исходные материалы, замороженные координаты, токенизатор и отдельные эталоны для диагностики. Он проверяет для каждого вопроса начальное полное покрытие по ранее рассчитанным результатам. Сохраняет число разрешённых адресов в нужном поле и координату одного успешного адреса при его наличии. Эти диагностические данные нельзя передавать модулю принятия решений. [Код](ceiling.py) · [Итог](results.json)
