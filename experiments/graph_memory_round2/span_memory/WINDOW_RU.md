# Насколько помогает простое окно вокруг одной страницы

Дополнительная проверка на том же наборе после основного опыта. Полный текст правки возвращён в 356 из 1 907 случаев основным методом. При расширении окна в обе стороны вокруг самой недавней страницы — 320, при расширении вперёд — 309. Окно вокруг наиболее вероятного начала дало 265 при двустороннем расширении и 322 при расширении вперёд. Для последнего контроля получены 89/55 парных выигрышей/проигрышей, +1,78 п.п., 95% ДИ с ресемплированием репозиториев [0,83; 2,75]. Этот опыт проверяет объяснение, что достаточно всегда добавить соседнюю страницу; оценка показывает добавочную ценность адаптивного выбора по сравнению с четырьмя конкретными окнами.
