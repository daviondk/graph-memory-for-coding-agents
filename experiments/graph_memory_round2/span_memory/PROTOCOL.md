# R2-F. Выбор связного фрагмента рабочей памяти после наблюдаемой правки

Продолжение после результата R2-E, где ранжирование отдельных страниц хуже покрывало целиком следующий редактируемый фрагмент, чем три недавние страницы. Одна фиксированная подтверждающая выборка. Используем опубликованные SWE-smith trajectories. Обучение по прежнему source из 44 train-репозиториев E, результаты R2-E на тестовых траекториях послужили основанием гипотезы. Новая оценка — до 700 других экземпляров из 23 тестовых проектов E (первые по hash r2f-unseen), исключены прежние instance из selection S5 и transfer и корзина, используемая S4. Проверяем отсутствие пересечения по instance при чтении. Не смотрим будущие правки при отборе. Бенчмарк и формат выбора являются адаптацией; цели кода и запуски произвольных команд не исполняются.

На каждые четыре события предсказываем максимум три ранее виденные страницы по 12 строк; для всех методов одинаковый набор первых 48 страниц. Первичный исход — точное покрытие всего уникального аргумента ближайшей принятой замены, даже если текст занимает несколько страниц. Случаи вне памяти входят как неудачи. Цель включает физическую согласованность при соседстве страниц. Контроли: три недавние; три страницы с наибольшей оценкой старта; нижеследующий оптимальный выбор трёх по смеси с общей частотой длин 1/2/3 из обучающих проектов; обучаемая смесь длин по давности предыдущей замены и её наблюдаемой длине. Предлагаемый метод расширяет смесь по наблюдаемой структуре: усечённая длина или неполнота каждой страницы, общая давность и уровень вложения соседних строк, появляется ли вторая область определения на соседней странице. Это модель условной ширины фрагмента. Сохраняется происхождение соседства из номеров строк и версии. Все методы обучения получают одинаковые предшествующие действия и фитятся только на train. Старт оценивается одной моделью flat E у всех графовых вариантов. Вес w_h для непрерывного интервала I длины h = P(start=i|prefix)·P(h|start=i,prefix). Контролям и предлагаемому методу доступны одни и те же допустимые интервалы. Для заданной тройки A сумма w_I по полностью содержащимся I — точная ожидаемая награда при взаимоисключающих гипотезах о следующей правке; перебираем все тройки из ≤48 кандидатов. Если среди памяти меньше трёх страниц, выбираются все. Плацебо переставляет наблюдаемые характеристики соседства между кандидатными стартами на том же шаге. Параметры обучения фиксированы до раскрытия тестовых исходов. Сравниваем наш вариант прежде всего со структурно идентичной моделью общей частоты длины, также со всеми другими контролями. Один вызов ранжировщика на cut, новых вызовов LLM нет. Учитываем 95% парный bootstrap репозиториев, распределение выигрышей и проигрышей, потолок, все исходы и размеры выбранных страниц. Ограничение в три страницы оставляет разный объём текста по токенам; это метрика ограниченного числа чтений, без заявления о равном бюджете токенов. Повтор полного агентского цикла вне текущего offline опыта.
