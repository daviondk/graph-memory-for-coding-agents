# Дополнительный контроль выбора соседних страниц

Исследовательский контроль, добавленный после получения основного результата F и обеих оценок токенного бюджета. Бюджет — до тех же трёх страниц из тех же 48 кандидатов. До подсчёта фиксируем четыре правила. Для точки с максимальной обученной оценкой начала собираем её и две физически следующие страницы, либо предыдущую и следующую. После первого отсутствующего перехода продолжения этого направления недоступны. Пустые места в лимите до трёх заполняем страницами по исходному точечному рангу. Два аналогичных правила используют наиболее недавнюю страницу и дозаполняют по давности. У всех четырёх те же материалы редактора. Контроли проверяют, достаточно ли всегда расширять первый найденный фрагмент вокруг одного места. Это простые детерминированные варианты окна, не реплика опубликованного обучаемого Late Code Chunking. Для прозрачности показываем все варианты; фиксированные веса и данные R2-F. Правильность и ДИ — те же, что у F.
