# Редактируемый научный отчёт

Ориентир оформления — опубликованный исследовательский отчёт первого раунда. Переиспользуется его генератор Word с настройками А4, титульной иерархией, многостраничной навигацией и сравнимыми таблицами. Входной Word предыдущей серии открывается как шаблон в памяти и остаётся нетронутым. Страницы включают внешний ссылочный аппарат и условия интерпретации. Сборка запускается из report с использованием Python workspace dependencies. Для рендера используется уже подготовленная в этом проекте переносимая копия LibreOffice в D:/CodexResearch/x20-office-renderer и Poppler из workspace dependencies. Страницы для проверки и исходники помещены в report; читателю предназначены DOCX/PDF в outputs/.
