# Чтение полного фрагмента для следующей правки
> На 1 907 шагах кодового агента в 17 репозиториях правило вернуло весь будущий фрагмент в 356 случаях. При постоянном распределении длины правки — в 315. Это главный результат серии.
**Что запоминается.** Рабочая память содержит только уже показанные страницы кода по 12 строк. Соседние страницы одного файла и версии связаны. Каждые четыре действия разрешено выбрать до трёх страниц. Обучение прошло на 44 других репозиториях. Для оценки отобрали 567 новых экземпляров SWE-smith. В 558 из них встретился хотя бы один подходящий следующий шаг. Из 1 907 принятых замен весь фрагмент технически можно было восстановить из памяти в 917 случаях. В 538 случаях место не удалось определить однозначно, для 397 правок требовалось более трёх страниц. Засчитывались окна, где первая запрошенная замена была принята; 41 окно с успехом только более поздней замены в знаменатель не вошло.
**Почему правило может помочь.** Даже правильная первая страница может обрываться внутри правки. Модель оценивает вероятность начала на каждой странице и условную вероятность длины фрагмента по коду и истории. Для каждой тройки страниц складываются вероятности всех возможных правок, которые она покрывает целиком. Когда следующая правка одна, эти варианты взаимоисключающие, поэтому сумма равна ожидаемой доле полного попадания в модели. При 48 доступных страницах перебор всех троек допустим. Точный перебор не гарантирует точности самих вероятностей.
