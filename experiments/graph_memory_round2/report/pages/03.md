# Как выбрать файл для первого чтения
> На 407 задачах SWE-bench Verified локальный граф объявлений и употреблений поставил нужный файл на первое место 250 раз. Плоский поиск по тем же файлам дал 235, исходная выдача RiverRider — 193.
**Рабочая память.** Из первых пяти файлов готовой выдачи сохраняем места, где названный в задаче идентификатор объявляется и где он встречается как употребление. Если функция упомянута в нескольких файлах, связь с объявлением помогает оценить, где искать реализацию. Совпадение имени в Python ещё не доказывает связь во время выполнения. Чтение ограничено пятью файлами из состояния репозитория на момент задачи. Оценивалась доля задач с верным первым файлом, Hit@1.

В сравнении внутри RiverRider граф выиграл у плоской модели 27 раз и уступил 12, разность +3,69 п.п., 95% проектный интервал [−0,59; +6,80]. Модель только с локальными объявлениями получила 244. Собственный вклад межфайловых связей — ещё 6, разность +1,47 п.п. [−2,22; +3,29], 9 выигрышей и 3 проигрыша. После перестановки ролей — 235. Даже идеальная перестановка исходной пятёрки нашла бы целевой файл только в 315 из 407 задач. Из 500 исходных задач исключены 93, уже присутствующие среди 300 выдач LocAgent. Авторская метрика засчитывает первый файл при совпадении с любым допустимым эталоном.
**Откуда взялась гипотеза.** Сначала на 274 задачах LocAgent мы пытались дополнить пустые позиции top 5 файлами, которые менялись вместе в прошлых коммитах. Опубликованный LocAgent, классический поиск совместных изменений и новая гипотеза дали по 258. Текстовый поиск дал 259. Гипотеза выбора первого файла сформулирована после этого результата, поэтому её статус разведочный. Вторая выборка дала сигнал при обучении на других проектах той же коллекции. Перенос из LocAgent в RiverRider воспроизвёл исходный порядок. Ещё на 50 пересекающихся задачах Verified с выдачей OrcaLoca (GPT-5.4-mini) исходно 41/50 при потолке 42. Обучение на RiverRider без текущего проекта дало 39 у плоской модели и по 40 у деклараций, графа и перестановки. Веса из LocAgent сохраняли 41.
