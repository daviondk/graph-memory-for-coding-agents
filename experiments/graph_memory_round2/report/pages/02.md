# Что уже проверили в публикациях
> В исследованиях памяти источником выигрыша может быть и содержимое записей, и правило их выбора. Само наличие графа мало говорит о причине улучшения.
**Опыт предыдущих действий.** В EMG агент соединяет наблюдавшиеся состояния и траектории. На новых средах ALFWorld у Qwen3-4B авторы получили 21,64% успеха без памяти, 52,99% с памятью узлов и 60,45% с полным графом. Это пример сравнения, в котором материал узлов сохраняется, а добавляются связи. В MERIT на Spider динамический текстовый поиск и типизированная память дали по 69,79% при 66,34% без памяти. Графовый механизм приходится проверять отдельно для каждого класса решений. [EMG, эксперимент и абляции](https://arxiv.org/html/2607.13884v1) · [MERIT, text-to-SQL](https://arxiv.org/html/2608.05906v1)
**Поиск нескольких свидетельств.** В Beyond One-Shot Expansion на MuSiQue последовательное расширение и финальная проверка покрытия дали полный комплект свидетельств в первой десятке для 57,0% вопросов. Один раунд расширения дал 36,5%. Удаление проверки покрытия снизило полный результат до 54,6%. Корпусный поиск этой работы отличается от постановки с заранее выданными абзацами в наших тестах. Для последних у Beam Retrieval есть поштучные авторские предсказания. [Исследование расширения](https://arxiv.org/html/2609.07050v1) · [Предсказания Beam Retrieval](https://github.com/canghongjian/beam_retriever)
**Выбор реализации по наблюдениям.** CodeT уже группирует программы по согласованности ответов. xTestCluster сравнивает альтернативные исправления по результатам сгенерированных тестов. S* запрашивает различающие входы для пар вариантов. Кластеризацию программ по тестовым исходам или само предложение провести различающий тест нельзя заявлять как самостоятельную новизну нашего метода. [CodeT](https://arxiv.org/abs/2207.10397) · [xTestCluster](https://doi.org/10.1007/s10664-024-10503-2) · [S*](https://aclanthology.org/2025.findings-emnlp.865/)
**Проверка причин.** Совпадающая метрика у графа и у перемешанных связей означает, что доступные данные совместимы с более простым объяснением. Во втором раунде сохранялись входы и бюджеты, а менялись способ чтения, принадлежность свидетельства или формат передачи. Для решений о коде использовались как реальные тестовые исходы, так и предсказание места действия. Это разные измерения.
