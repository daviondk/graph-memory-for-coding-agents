# Перенос до ознакомления с результатами

Дополнение 18 ноября к R2-B. Запущен расчёт признаков HotpotQA, не прочитаны метрики/предсказания нового метода. Проверяем межкорпусный перенос на всех официальных двухшаговых MuSiQue-Ans dev, ID с префиксом 2hop (1 252 в исходной статье). Это отдельная заранее намеченная проверка применимости к другим способам конструирования вопросов, маркерам заголовков и числу кандидатов. Веса, калибровочные пороги и лексические правила для HotpotQA заморожены. Никакого подбора на MuSiQue. Основной контраст тот же, граф с позициями свидетельств против простого графа по точному покрытию двух размеченных индексов абзацев. Сопоставляем с плоским контролем, сдвинутыми свидетельствами и опубликованными индексами Beam на тех же вопросах. Номера исходных абзацев берём из idx. При одинаковых заголовках первичен индекс, любой порядок исходного списка остаётся известным только для детерминированной ничьей. Принудительно не отбрасываем вопросы с повторяющимся текстом. Из-за отсутствия границ предложений используем фиксированный разрез после точки, восклицательного или вопросительного знака с пробелом перед заглавной буквой или цифрой (границы могут ошибаться). Кластеры и прочие правила прежние, метрики сообщаем на корпусах раздельно. Это перенос инструмента выбора пары, не сравнение трёх- и четырёхшаговых задач из общей таблицы статьи.
