## Проверка и перенос

Архив содержит фактические предсказания и оценки каждой ветви. Проверка целостности не требует исходных моделей или сети. В корневом MANIFEST.json для каждого файла указан размер и SHA-256. После извлечения в отдельный каталог выполните:

```powershell
python work/graph_memory_round2/check_package.py
```

Для смысловой проверки используйте отдельные оценщики по ветвям. В исходной раскладке диска D можно выполнить, например:

```powershell
python work/graph_memory_round2/attempt_memory/audit.py
python work/graph_memory_round2/edit_memory/evaluate.py
python work/graph_memory_round2/span_memory/score.py
python work/graph_memory_round2/span_memory/audit_independent.py
```

Для удобства перепроверки вне исходного компьютера рядом с материалами серии в work/ упакованы задействованные общие обработчики и проекции данных предыдущих раундов. Некоторые исходные lock-файлы и пути намеренно сохраняют абсолютный путь на D. Для побайтовой сверки в любой раскладке используйте MANIFEST.json; для перезапуска команд с жёстко записанными путями нужна первоначальная структура каталогов либо её отображение.
