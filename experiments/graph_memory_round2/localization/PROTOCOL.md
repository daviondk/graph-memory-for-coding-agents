# Frozen R2-A. Completing an uncertain localization result using past change episodes

2026-11-18. The released ACL 2025 LocAgent Claude 3.5 file contains 300 SWE-bench Lite localization predictions. Its official scorer defaults to czlll/SWE-bench_Lite test, with 274 rows in the pinned test parquet. At planning we inspected field names, prediction-length frequencies and one example of the base model's prediction, and read the outcome scoring code but did not score any instance. The previous graph round used an oracle anchor in different commits. This time only issue text and already released predictions are available. All 274 dated records are enumerated. Use upstream policy of excluding rows without annotated edit_functions. The new method retrieves a file before a repair; no repo code is executed.

**Question.** When the strong agent leaves some of the first five slots empty, can the pattern of files it currently suspects serve as a partial observation of a past joint change? Predict further files whose co-change evidence exceeds their popularity, after discounting large commits. Fixed maximum 5 output slots. Preserve native rank order/first five, add files only while slots remain. Precommit primary comparison to classical direct co-change plus the same text scorer at the same 5-file limit. Compare also native, text-completion and a frequency-stratified graph relabeling. Native can return fewer than five files; a gain over native alone does not isolate graph information. Never add the current target edits or a gold anchor. No parameter tuning or learned reranker. No secondary policy that replaces native recommendations in this experiment.

**Write memory.** Git base DAG ancestor first-parent histories of up to 384 commits, inclusive of the issue's base commit (all available there). Record each commit's subject and changed files; first-parent diff for merges, no rename detection. Past subjects are data only. File inventory from base revision tree permits existing non-test, non-vendored production .py files. Exclude tests, docs, examples, generated, migrations and ambiguous/special setup paths from append candidates. Preserve native suggestions. Candidate additions share a universe: all eligible production paths in the base tree. For joint evidence take eligible transactions of size 2–24 in original distinct production Python paths, excluding broader mass edits. Rank by historical transaction index; fractional age weight 2^(-index/192). SHA-pinned independent per-issue snapshots. If base unresolvable or sensitive-issue filter fires, preserve native predictions for every method and log it. Metadata projection must remove target patch, hints, labels, feedback, test solutions, original agent generated prose. No network during ranking.

**Read memory.** First up to five native file predictions are uncertain anchors; weights proportional to 1/r, normalised over available anchors. A plain text signal combines separate rankings for issue-to-path token matches, BM25 over prior commit subjects attributed to current files, and historical path frequency. Reciprocal rank fusion, constants and token limits fixed in code to be hashed before joining gold. A weighted classical one-hop co-change arm credits each historical companion path with the sum of matching anchor weights times recency. The candidate method changes only the historical evidence: use the sum of matching anchor weights, plus the sum over pairs of the smaller weights as evidence that the same past transaction explains multiple current suspicions. Distribute each transaction's mass among its unseen files, then divide each candidate's aggregate by sqrt(1+its decayed marginal occurrence count). Both arms mix their graph with identical flat textual score using two shares graph to one share flat and reciprocal-rank constant 10; no graph support means fall back to flat. Keep graph-only, ablated versions without (i) multi-anchor interaction, (ii) rarity and sharing. Placebo applies a deterministic within-frequency-bin permutation to identities as graph input and output while retaining real text scores, native prefixes, and same node set (ten equal-size classes in sorted marginal frequency space). Keep per-item evidence for decisions in anonymised or path-only form.

**Outcomes.** Primary official file Acc@5 across all official evaluable cases, computed exactly as LocAgent (number hits equals min(k, gold count), upstream skips empty). Secondary strict full coverage (gold subset), Hit@5, Recall@5, qualitative cases and dependency on available vacancies. Keep complete rankings and score blind (generate prediction checksum before reading outcome columns). Primary paired delta candidate minus matched co-change; also all controls, no multiplicity-adjusted discovery claims. Report wins/losses, absolute differences and 95% paired repository-cluster bootstrap, holding query weights; exact discordant sign test descriptively. Independently display later chronological half per repo (before any file labels examined) and per-repository values. Fixed historical window, tie by path, no early stopping or selection of preferred arm post hoc. This is an evaluation on reused public benchmark data, no new actual model calls. Original Claude agent archived. A positive delta does not imply more accepted patches or a public SOTA.
