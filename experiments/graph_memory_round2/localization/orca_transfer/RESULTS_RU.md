# Переносятся ли веса на выдачу OrcaLoca

После первого результата с RiverRider проверили тот же графовый ранкер на другом источнике подсказок, независимом публичном воспроизведении OrcaLoca с gpt-5.4-mini на 50 задачах SWE-bench Verified. Веса и способ вычисления признаков уже были зафиксированы. Для каждой задачи взят fold, где весь её репозиторий исключён из обучения. Здесь меняется генератор исходных файлов. Из 50 идентификаторов 8 встречались в исходном архиве LocAgent Lite, остальные 42 — в изученной выборке RiverRider. Это проверка переноса между системами, повторно использующая вопросы. В 32 задачах после удаления повторов исходная выдача содержит единственный путь, в одной — ни одного. Все 74 выданные позиции прочитаны в состоянии соответствующего базового коммита. У оставшихся 17 задач допускается изменение первого файла, и исходник уже закрывает 41/42 достижимых положительных задач. Это объясняет малую возможность улучшения и делает перенос на сильную выдачу уязвимым к одному неверному решению. Собственные LLM-вызовы и повторный запуск исходного локализатора не выполнялись. Сравнение со статьёй по её основной функции метрики function match rate на SWE-bench Lite требует другого артефакта.
