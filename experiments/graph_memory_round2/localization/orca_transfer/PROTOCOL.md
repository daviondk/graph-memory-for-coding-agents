# Дополнительный фиксированный перенос на известного агентного локализатора

После агрегатов R2-A2 и до просмотра любых сравнительных результатов OrcaLoca используем ранее полученный опубликованный файл из 50 задач SWE-bench Verified. В опубликованной независимой репликации локализацию исполнял gpt-5.4-mini. Это другой предиктор для тех же известных задач, 8 из них также входили в архив предсказаний LocAgent Lite, остальные пересекаются с внешними задачами RiverRider. Уникальных новых задач этот опыт не добавляет. Уровень независимости — новая исходная выдача и fit на других репозиториях, явно не новые экземпляры.

Основной перенос замороженных весов RiverRider. Для каждого экземпляра применяем веса flat, decl, graph и placebo из river_loro именно того fold, где весь тестовый репозиторий исключён. Нет вновь подбираемых параметров, повторного обучения и исключения задач по результату. Дополнительный перенос — аналогичные веса loc_loro. Взять не более пяти первых различных путей из found_files точно в исходном порядке, сохранить задачи с пустым результатом. Тот же extractor графа из реально прочитанных Python-файлов базового коммита задачи. Предсказания зафиксировать с хешем перед присоединением меток. Основной исход Hit@1 по любому из файлов фактического патча Verified при точном совпадении относительного пути. Дополнительные исходы any и single по релизу RiverRider, ceiling@5, парные выигрыши, проигрыши, интервалы по проектам. Проверяем прежде всего graph против исходной выдачи и flat. Малый n и повторно использованные задачи, сопоставляемость с оригинальной статьёй только по семейству системы.
