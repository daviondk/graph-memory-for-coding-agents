До присоединения исходов проверен опубликованный код RiverRider tools/verify_bundle.py. Он считает первое совпадение с ЛЮБЫМ gold_files, а не только с полем gold. Исходное описание в протоколе ошибочно называло единственный номинированный файл первичной авторской метрикой. Сохраняем заранее названный вариант с одним файлом как отдельную метрику и везде рядом публикуем воспроизведение настоящей авторской оценки с любым gold_files. Для источников возможна только выдача с теми же наименованиями и проверенным снимком. Для обучения на RiverRider основным операциональным определением качества служит корректная авторская метрика; число совпадений с одним файлом будет приведено в sensitivity без селекции результатов. Дополнительно указать дельту, если учить на единственном gold. Код автора использует строковый suffix для состыковки дерева с именем файла, код здесь нормализует непосредственно один префикс checkout и сверяет расхождения на всех 500.
