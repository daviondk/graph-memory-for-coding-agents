# Предсказание следующего места правки по рабочей памяти

В 67 публичных проектах выделен 3 661 уникальный экземпляр задачи, для оценки целиком отложены 23 проекта. Каждый четвёртый шаг выдача формировалась по доступной на этот момент памяти редактора. На 9 049 границах 1 320 тестовых траекторий запечатаны прогнозы, затем обнаружено 4 320 относящихся к метрике принятых редактором замен в 1 272 траекториях. В 2 873 случаях начальная страница вообще входила в набор из 48 доступных кандидатов. Память обновлялась при подтверждении буквальной замены текста с учётом сдвига номеров строк. Цель — покрытие текста будущего принятого действия; успешная замена в редакторе ещё не говорит о прохождении тестов проекта.

| Метод | Начало на первой странице | Начало в первых трёх | Вся замена в первых трёх |
|---|---:|---:|---:|
| Порядок по давности и центру просмотра | 413 | 962 | 761 |
| Обучаемые признаки редактора | 826 | 1 515 | 545 |
| Плоская история предыдущих замен | 841 | 1 526 | 573 |
| Добавление ребра файл–координата | 834 | 1 533 | 567 |
| Координата и разные роли добавленных и удалённых терминов | 836 | 1 532 | 569 |
| Перестановка владельца координаты | 843 | 1 523 | 569 |

Разность полной и плоской моделей по первичному Hit@1 составила −5/4 320, 22 выигрыша, 27 проигрышей, −0,12 п.п. (95% парный bootstrap репозиториев −0,43…+0,28). После хотя бы одной правки доступно 3 062 случая, 658 против 663. Главный эффект в этой постановке обеспечивает обычная обучаемая оценка страницы по наблюдаемым признакам. На конечной точке «вся будущая замена» порядок недавних просмотров превосходит все поштучные оценки: он часто возвращает подряд несколько соседних страниц. Эта смена порядка методов прямо указывает на новую гипотезу о том, как совместно выбирать страницы. Она стала основанием отдельного опыта R2-F на других экземплярах.

Репозитории отложены целиком, действия записаны авторами [SWE-smith](https://swesmith.com/), для исследования используется безопасное текстовое представление редактора. Генерации LLM в R2-E нет. 70 679 обучающих строк после фиксированного отбора, в том числе 5 631 положительная. Групповые показатели, результаты каждого проекта, числа предсказаний и все интервалы содержатся в results.json. История доступна по split.json и хешам кода. Для воспроизведения итоговых чисел достаточно evaluate.py и сохранённых файлов predict_*.jsonl.gz, gold_*.jsonl.gz. Для повторного обучения — experiment.py. Требуются NumPy и соседние модули memory_session5/packets. Исходные опубликованные траектории несут ошибки автора и фиксируют поведение исходного агента.
