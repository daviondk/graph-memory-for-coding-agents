# Журнал поиска по R2

Дата обращения 2026-11-18. Целевой обзор по англоязычным терминам и проверка программных артефактов у авторов. Выдача веб-поиска меняется. Проверены страницы arXiv и ACL Anthology, публикации у издателей, авторские GitHub и Hugging Face. Из предшествующего обзора исключены повторные описания общих графовых архитектур. Предмет включения — прямой контроль реализации, разбор работы механизма или опубликованные поштучные предсказания, пригодные для сравнения. Ниже приведены воспроизводимые формулировки для повторного поиска по каждой группе.

## Проверка публичных данных

- Файл [Beam Retrieval, MuSiQue dev](https://github.com/canghongjian/beam_retriever/blob/902980bfb5bd47a963569ab9c3621fd5ae81204a/results/retrieval/musique_pred_best.json) получен анонимно и прочитан как JSON. 2 417 ключей ID, значения — индексы параграфов. SHA-256 `968a944db3408bd2538d9bb7af80c0e5c48e43fb9e758483d761616599ea3d38`. Разметку следует совместить по ID и исходному порядку параграфов.
- Файл [LocAgent, Claude-3.5](https://github.com/gersteinlab/LocAgent/blob/4935b557326c154bad8e8dcf3747cc8d32d1f387/evaluation/loc_output/locagent/claude_3-5/loc_outputs.jsonl) содержит 300 результатов. SHA-256 `a03e99aad53c5bfcb7b82034d37e5f5e55ebd8b1bdd115e3b80cb3af86c17f22`. Различие определения accuracy на задачах с более чем k gold-файлами указано в обзоре.
- Файл [HippoRAG, MuSiQue 500 в сторонней репликации](https://huggingface.co/datasets/goethe0101/neurographdb-results/blob/12ae99c3a0a2f0653d3edd9d9158b664fab041e8/runs/hipporag_musique_n500.json) содержит запросы, списки ранжированных заголовков и правильные заголовки. Совпадение названия датасета с distractor-протоколом не обеспечивает тождества корпуса или метрики.
- Файл [BugsInPy, полные измерения пяти ветвей](https://github.com/Weypher/agent-failure-memory/blob/1827cdb9f8a939d653baf6be3d94f1e00589fe93/data/results/full/C.json) содержит 450 первичных попыток, 181 неудачу с повтором и пять форматов памяти. [Код измерения](https://github.com/Weypher/agent-failure-memory/blob/1827cdb9f8a939d653baf6be3d94f1e00589fe93/m1/analyze_main.py) явно задаёт обработку инфраструктурных сбоев. Файл используется в R2-D.
- Этот журнал описывает целевую проверку ключевых конкурентов и артефактов. Число всех документов в области и полноту поиска через PRISMA не оценивали.

Дополнение после появления R2-F. Запросы `retrieval contiguous context code snippets neighboring lines windows budget code completion`, `budgeted retrieval multi-granularity neighboring context code`, проверка цитируемого SWE-Pruner из Rivet. По первичным материалам проверены [SWE-Pruner v4](https://arxiv.org/abs/2601.16746v4), [LongCodeZip](https://arxiv.org/abs/2510.00446), [Late Code Chunking](https://aclanthology.org/2026.acl-short.64/), [Rivet v1](https://arxiv.org/abs/2610.34967v1). Это дополнение к обзору после наблюдения первых результатов селектора, а не пререгистрированный подбор конкурентов.
