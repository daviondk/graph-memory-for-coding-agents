# Дополнительные контролы по опубликованным принципам

Зафиксировано 18 ноября 2026 до открытия исследователем результатов любого нового читателя и скрытых тестов этого раунда. Код основной политики и основной контраст не меняются. Статический выбор крупнейшего точного класса игнорирует совпадения на отдельных входах. Добавляем MBR-Exec-подобный контроль: среди максимумов первого публичного теста выбрать слот с наибольшим числом совпадений с другими слотами на всех сгенерированных пробах. Каждый вход имеет единичный вес, None не считается положительным совпадением, дубликаты попыток сохраняют multiplicity, ничьи — в порядке первой генерации. Это реализация принципа поведенческого согласия в наших данных, не воспроизведение чисел статьи.

Второй контроль задаёт локальной Qwen один прямой вопрос, какой из реализованных кандидатов соответствует спецификации. Тот же круг задач, на которых основная политика совершает вызов, одинаковые первые публичные наблюдения и максимум один вызов. Вместо синтетического входа в запрос включены тексты выживших кандидатов целиком в фиксированном хеш-порядке, ограничение в 1450 символов на код, UNKNOWN допустим. При UNKNOWN вернуть статический выбор. Измерим фактические токены: равное число вопросов не делает длину запросов одинаковой. Для основного метода полезным результатом был бы выигрыш над этими контролами на свежей панели. Код для селекции и её решения записываются отдельно; повторная оценка использует уже добытые тестовые статусы по хешу программы.
