# Добавочный сильный нативный контроль

После первого группового измерения добавляем общий git diff -G по объединению литералов в пределах реальной пары. Для одного литерала достаточно компактного --name-only; для нескольких Git получает объединённое POSIX-выражение и объединение областей, возвращает патч только для затронутых файлов. Читаем добавленные строки и каждому идентификатору выдаём его собственный результат с учётом области. Это устраняет нехватку сильного сравнения, если разные запросы могут разделить работу и внутри штатного -G. Проверяются 77 исходных групп, три случайно перемешанных повтора и те же 96 конечных значений. Общий diff, пакетный grep и варианты с обязательным повторным подтверждением переизмеряются вместе с новым контролем. Вывод о преимуществе возможен только с учётом этого варианта. Изменения выборки и новые несуществовавшие запросы не допускаются.
