# Воспроизведение R12

Полные измерения были выполнены на Windows с Git 2.49.0.windows.1 и Python 3.14.4. Для чтения официального parquet использовался отдельный Python из окружения VibeMemBench с pyarrow и requests. Скрипты не вызывают LLM, не исполняют команды из историй и не требуют Docker. В таблицах времени единица — запрос либо реальная группа запросов после изменения Git, wall-clock в миллисекундах. Три повтора выполняются в фиксированном псевдослучайном порядке и агрегируются по медиане внутри единицы. Повтор временных измерений даст собственные значения.

## Проверить опубликованные здесь числа

`python -B verify.py` восстанавливает знаменатели и результаты из сырых записей обеих Git-ревизий, повторно проверяет контрольные суммы исходной выборки, исходы 1 152 одиночных, 1 386 групповых и 1 155 объединённых нативных измерений и проверяет сохранение результатов после исправления ID. Результат пишется в results.json и verification.json. При проверке архивной копии команда может создать файлы результатов в ней.

## Повторить измерения

Чтобы сохранить изначальные артефакты и версии протоколов, скопируйте скрипты, Markdown и папку prior_identity_audit в новую рабочую папку на D. Исходная коллекция VibeMemBench размещалась в `D:/CodexResearch/x20-official-vibe/VibeMemBench`: каталог `benchmark/history/python` и `memory-stage-fetch/source-manifest.json` содержат оригиналы и SHA закреплённой ревизии 11164976b4f920cdb0d0cd570ca572e49acea1e8. Все включённые файлы перечислены в roster.json. Для другого локального расположения укажите его в константе V в extract.py и сохраните новое фиксированное окружение. [Исходный набор](https://huggingface.co/datasets/Tongyi-ConvAI/VibeMemBench/tree/11164976b4f920cdb0d0cd570ca572e49acea1e8).

```text
python -B extract.py
python -B pairmeta.py
python -B objects.py
D:/CodexResearch/x20-official-vibe/solver-runtime/agent-venv/Scripts/python.exe -B fetch_metadata.py
python -B chronology.py
python -B witness.py
python -B engine.py predict
python -B engine.py oracle
python -B cost.py
python -B batch.py
python -B native_union.py
python -B check_blobs.py
python -B verify.py
```

Для полной сборки нужны публичные исходники GitHub и Hugging Face. Исходный parquet SWE-rebench-V2 сверяется с SHA256 0e0bf9355f892ad74ae98d4e1c404f39fd6654a8e351ee3e6ab162e4a64cd3ad. В анализ загружаются только идентификаторы, репозитории, время создания и базовые SHA, без патчей и тестовых меток из эталона. Ссылки на зафиксированные PR и их публичные merge SHA есть в pr_metadata.json. Контрольные суммы входных действий хранятся в input.lock.json и в строках roster.json. Идентичность исходов прогнозу не используется при отборе.

Зеркала и parquet хранятся на D в `D:/CodexResearch/x20-round12-negative-objects`. Полные деревья с Git-объектами в этой серии занимали около 152 МБ, отдельная история для проверки предков — около 3,5 МБ, оригинальный parquet — около 429 МБ, десятичные единицы. Предварительный автономный переход к старому дереву и загрузка источников выполняются до замеров; это общие условия доступа к данным. Получение списка изменений или самого диффа, запуск Git и разбор полученного результата входят в соответствующее измерение. Повтор на машине с другими версиями, файловым кэшем, платформой, режимом хранения Git или постоянным Git-процессом требует нового сравнения.

В рабочую папку с результатами входят все 96 GitHub-метаданных, 17 репозиторных квитанций, прежние неуспешные действия с исходной командой и обоими полями ответа, пооперационные предсказания, независимые проверки и исходные записи времени. Полные неизменённые истории можно восстановить из закреплённого публичного набора по имени и SHA. Папка prior_identity_audit оставлена для проверки обнаруженного дефекта агрегирования первой версии. Она документирует ход работы и исключается из итоговых таблиц.
