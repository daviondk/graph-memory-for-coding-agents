# Exact edge overlay

Before running any representation on the fixed streams, add a conventional base-plus-deltas comparator that stores the changed **edges**, in addition to the two full-row shadow buffers. On each test completion compare to its latest archived row (charge the bytes), replace this test's added/removed flags for the affected symbols, pack the exact name, add bits and remove bits into a compressed dictionary. Reserve 30% of the resident structure for this overlay and the remainder for a global XOR base; compact by replaying active old rows into the base when the serialized delta exceeds its region. Reapply deletions and insertions during query from bytes. Implement also independent exact compressed forward lists, with a conservative all-keys answer per full slot while over limit. Compactness claims must be compared against both representations. Choice of 30%, two shadows, stripe widths and batch of four are fixed; tuning them on the observed outcomes is outside R12.
