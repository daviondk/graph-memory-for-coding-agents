# Помог ли граф написать работающий метод
> В 108 заданиях из 50 классов локальный Qwen3.8-27B получил контракт, сигнатуры, конструктор и выбранные политикой строки прежних методов. Граф дал 76 методов с полностью прошедшими тестами, поиск BM25 по тем же строкам — 77.
Здесь предшествующие методы взяты из опубликованного эталона. Модель пишет следующий метод с одного запроса. Для проверки результата его вставляют в полный эталонный класс и запускают профильный авторский набор. Цели, будущие тела и скрытая оценка недоступны решателю. В открытых контрактах 54 методов есть вызовы с теми же буквальными аргументами, что в тестах. Все способы видят один и тот же контракт.

Граф связывает присваивания полям объекта со строками, от которых зависят значения и управляющие условия. Доступно до 160 токенов памяти на метод. Контроль полного текста может получить до 800. В сравнении со строковым BM25 получено 0 выигрышей и 1 потерь. Разность полного успеха −0,93 п.п., кластерный 95% ДИ [−2,86; 0,00].
Граф и BM25 показали 76 из 81 доступного нужного поля объекта. На 76 методах запросы полностью совпали, на 32 различались. Шесть назначений для каждого из 108 методов дали 338 разных запросов после объединения совпадающих входов. Qwen3.8-27B-UD-Q4_K_M исполнялся в llama.cpp на локальной RTX 3090, температура 0, один ответ до 384 новых токенов, режим размышления отключён. При независимом повторе с 17 дополнительными чистыми операциями Python все показатели полных успехов сохранились. У пустого контроля отдельные проверки дали 417 вместо 418. Причина переменного результата установлена у метода, который возвращает list(set(...)): тест требует определённый порядок, а хеширование строк зависит от процесса.
