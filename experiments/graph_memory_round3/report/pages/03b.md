# Почему поштучный вес теряет информацию
> Одна и та же строка имеет разную предельную ценность в зависимости от того, какие соседние строки уже сохранены. Это следует прямо из определения полного соответствия будущей правке.
Пусть H — наблюдаемая до действия история, S — множество сохраняемых страниц и I — случайный набор страниц, требующихся для следующей замены. Если память не содержит всего I, операция точной замены не получит из памяти нужный исходный текст. При известных вероятностях интервалов p(I | H) ожидаемое полное попадание имеет простой вид.
**F(S) = Σᵢ p(Iᵢ | H) · 1{Iᵢ ⊆ S}.**
Для интервала из двух страниц A и B с вероятностью p каждая одиночная страница даёт ноль по этому слагаемому. Добавление B к уже сохранённой A даёт p. У аддитивной суммы индивидуальных весов B даёт одну и ту же прибавку независимо от A. Поэтому один набор статических весов не может точно выразить пользу выполнения такого запроса для всех возможных состояний памяти.
## Когда ожидать эффект
Если все запросы одноэлементные, формула сводится к поштучной сумме. Если хватает места на весь наблюдавшийся источник, варианты вытеснения совпадают по полному покрытию. Эксперимент проверяет промежуточный режим. Увеличение размера кольца зависимостей имеет смысл лишь в том случае, когда нужную группу можно предсказать из H лучше, чем случайную группу.
Вероятности в нашей работе оценены по другим проектам. Переключение оптимизатора при одинаковой модели полезности отделяет эффект способа поиска решения от эффекта этой гипотезы. Выигрыш 496 против 464 при точном вычислении отражает лучшие последующие попадания в сохранённый текст. Величина F сама по себе не гарантирует, что языковая модель правильно применит доступные строки.
