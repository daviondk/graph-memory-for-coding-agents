# Когда пользователь не задаёт прямой вопрос
> Замороженное правило лучше плоского контроля извлекало свидетельства, когда обычный вопрос был заменён обращением от лица собеседника.
В LoCoMo-Conv авторы переработали вопросы тех же десяти разговоров в четыре стиля обращения. Каждый ранжировщик применён без переобучения, на истории, исключённой из его обучающей выборки. Доступны лишь строка запроса и архив реплик. Предоставленные исследователями атрибуты нужного говорящего и дополнительные размеченные свидетельства не поступают в поиск.

| Тип обращения | Вопросы | Все в 5, плоский | Все в 5, граф | Разность и 95% ДИ, п.п. |
| Прямое диалоговое | 1 528 | 42,80% | 48,04% | +5,24 [4,07; 6,42] |

| Составное | 1 051 | 2,57% | 3,04% | +0,48 [0,00; 1,02] |
В составном обращении нужно найти свидетельства нескольких исходных вопросов. При менее строгой метрике доля найденных свидетельств в первых десяти репликах увеличилась с 26,35% до 29,57%. У первых трёх стилей прирост этой частичной полноты также положительный. Корпус расширяет разнообразие формулировок; число независимых историй остаётся равным десяти.
При поправке Холма по четырём типам запросов p составили 0,0078 для прямого, 0,0117 для неявного и для ложного, 0,1875 для составного. Разность по прямым обращениям была положительной во всех десяти диалогах.
## Предел сравнения
Эталонный оценщик LoCoMo-Conv сопоставляет произвольный возвращённый текст с исходными репликами по вхождению строки. Сжатый факт или многорепличный блок может отобразиться на другой набор ID. Наш опыт выдаёт ровно пять или десять исходных реплик и использует их явные ID. Для сравнения с чужим числом также требуется воспроизвести фильтры вопросов и гранулярность записей.
