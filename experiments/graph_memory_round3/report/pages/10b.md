# Сравнение с опубликованной графовой памятью
> Тот же поиск проверили официальным оценщиком LoCoMo-Conv. Это даёт внешний ориентир с совпадающими вопросами и правилами подсчёта.
Для этого расчёта сохранены все вопросы в составе каждого стиля по правилам авторов. В dialog и implicit появляются в том числе adversarial-примеры, у которых размеченная реплика служит близким контрпримером. Корректность здесь определяется авторским Retrieval Recall@10 — средняя доля размеченных реплик, найденных среди десяти возвращённых записей. Ответ ассистента эта метрика не проверяет.
@ 5.7 2.3 2.3 2.8 2.2
| Система | Dialog, 1 986 | Implicit, 1 986 | Counterfactual, 1 540 | Composed, 1 069 |
| Плоский контроль R3 | 61,01% | 30,25% | 58,88% | 26,14% |
| Граф авторства R3 | 65,27% | 35,17% | 64,46% | 29,38% |

| Mem0, статья | 54,7% | 45,6% | 51,2% | 37,4% |
В нашей строке нет переформулировки запроса; значения вычислены из реально возвращённых исходных реплик. Внешние строки взяты из таблицы 4 рецензируемой работы. По counterfactual разница с AnchorMem без переформулировки +0,56 п.п.; в полной конфигурации AnchorMem сохраняет преимущество во всех четырёх столбцах.
Во всех сравнениях стоит предел десять записей, но запись у AnchorMem в среднем охватывает больше одной реплики. Авторы приводят около 12,8 покрытых реплик на запрос. Для наших весов использовалась разметка девяти других разговоров. Мы не выравнивали стоимость индексации и обучения и не располагаем поштучными ответами внешних систем для парной оценки этой разницы.
