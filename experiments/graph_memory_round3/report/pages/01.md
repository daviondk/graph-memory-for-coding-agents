# Память кодового агента при записи и чтении
> Самый устойчивый результат этой серии относится к записи. Если последующей правке нужны несколько соседних страниц, полезно сохранять их вместе. На сгенерированных дефектах и реальных пользовательских задачах сохранение групп улучшило полноту по сравнению с оценкой отдельных страниц.
При лимите 4 КиБ на сохраняемые строки графовая политика удержала весь будущий фрагмент в 904 из 2 135 правок. Обычная оценка отдельных страниц дала 806, вытеснение по давности — 783. На другой панели получены 494 из 1 210, 430 и 451 соответственно. В независимой реализации с ограничением всех байтов состояния и перезапуском после каждого шага граф дал 746 против 712 у поштучной оценки, +2,81 процентного пункта [1,37; 4,25].

На 164 реальных задачах SWE-bench Verified связанную запись проверили без переобучения. Из 639 будущих правок целиком сохранились 364, при поштучной оценке — 348. Давность также дала 364. На следующих 129 задачах граф снова опередил поштучную оценку, 295 против 277 из 535. Давность дала 296. Новый переключатель дал 299, его преимущество над графом осталось неопределённым.
