# Когда смешиваются чтение и правка
> Определить вид следующего действия можно точнее, чем по его средней частоте. Этого оказалось недостаточно, чтобы повысить общую полезность памяти.
В третьей панели 282 другие задачи и 13 новых проектов. Помимо принятых операций замены здесь есть 432 реальных обращения для просмотра строк. Полезность полной правки бинарна. При просмотре засчитывается доля запрошенных строк, которые удалось предъявить из ограниченного кэша. Ошибка Brier вычисляется как средний квадрат разницы прогнозируемой вероятности правки и индикатора действия. Меньшее число соответствует более точному прогнозу.
@ 7.0 3.0 3.0
| Результат | Постоянная смесь | Адаптивная |
| Brier для вида действия | 0,249 | 0,157 |
| Доля доступных строк при просмотре | 10,6% | 12,2% |
| Полностью доступны, из 652 правок | 300 | 287 |
| Средняя смешанная полезность | 31,9% | 31,3% |
Интервал разности смешанной полезности включает ноль. При фиксированном бюджете перераспределение места под просмотры стоило полных попаданий для замены. Эта панель проверяет иной режим использования памяти, поэтому её нельзя сложить с количеством успешных правок на первых двух выборках.
Наблюдаемая величина полезности зависит от следующего действия и от того, какую долю источника нужно сохранить. Это делает явным выбор для будущей работы. Для просмотра полезен каждый дополнительный фрагмент. Для точной текстовой замены последняя недостающая строка может определять весь успех.
