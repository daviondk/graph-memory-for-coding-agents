# Кто сообщил факт в диалоге
> Ребро между репликой и её автором повысило вероятность найти все исходные свидетельства среди пяти реплик. На уровне пяти целых сессий преимущество исчезло.
В памяти сохранены оригинальный текст, говорящий, дата и переходы между соседними репликами. При записи создаётся дополнительное представление, в котором местоимения первого и второго лица связаны с участниками. При чтении вес соседней реплики зависит от того, задал ли собеседник вопрос и отвечает ли другой о себе. В плоском контроле уже доступны те же участники, текст соседей, признаки вопроса и говорящего, BM25 и MiniLM. Линейный ранжировщик для каждого из десяти разговоров обучен на девяти остальных.

Для реплик пригодны 1 527 вопросов с полностью разрешимыми ID, для сессионного протокола Memoria — 1 536. Данные включают десять разговоров и 5 882 реплики. Основное сравнение с плоским контролем даёт 846 против 815 попаданий, 70 выигрышей и 39 проигрышей, +2,03 п.п. [0,60; 3,75]. Для первых десяти реплик полное покрытие почти одинаково, 62,67% против 62,74%.
Среди десяти диалогов семь дали положительную разность на репликах, два — нулевую. Для двух основных исходов кластерный перестановочный p по репликам до поправки 0,039, после поправки Холма 0,078. Статистическая неопределённость при десяти единицах остаётся большой.
Во внешнем протоколе на 1 531 вопросе подтверждены контрольные суммы исходного набора и пар вопрос–свидетельства. Наше полное покрытие@5 равно 55,26%, у memory-core RRF5 — 56,43%, у Mem0 при атрибуции по метаданным — 57,74%. Опубликованный сессионный результат Memoria на 1 536 вопросах — 78,32%. Внешние результаты агрегированы авторами.
