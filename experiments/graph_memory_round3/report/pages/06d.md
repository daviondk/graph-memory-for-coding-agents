# Выбирать политику по размеру наблюдения
> На второй выборке из 129 новых задач SWE-bench Verified одно правило переключения сохранило 299 будущих замен из 535. Контроль по давности дал 296, прежний граф — 295. Предварительно заданное требование превзойти оба контроля с интервалом выше нуля не выполнено.
На первом корпусе обнаружилась ничья графа с вытеснением по давности. Затем закрепили один вариант. Если при переполнении свежее наблюдение само укладывалось бы в 4 096 байт адресованного текста, алгоритм учитывает недавность доступа. Если последнее наблюдение больше всей квоты, он оценивает полезность связанных страниц. Логика выбора использует одно сериализованное состояние. Обучения на задачах второй выборки не было.

Из 8 248 событий получено 535 измеримых ближайших принятых замен. Для всех 318 локализованных позиций найдено совпадение с сообщением редактора. Другие 217 остаются нулями у всех. Идентификаторы задач полностью отличны от первой выборки. Восемь проектов входили также в первую выборку.
В сравнении с давностью переключение принесло 5 выигрышей и 2 потери, +0,56 п.п. [0,11; 1,66]. В сравнении с графом — 9 и 5, +0,75 п.п. [−0,45; 2,07]. Повторение прежнего сравнения даёт более определённый результат. Граф выиграл у поштучной оценки 19 случаев, проиграл 1, +3,36 п.п. [2,19; 4,24]. Его разность с давностью −0,19 п.п. [−1,37; 1,50]. Над давностью получено по одной чистой дополнительной правке в Astropy, Matplotlib и SymPy. В других пяти проектах разница нулевая. Двусторонний тест знаков по трём ненулевым проектам даёт p=0,25. В двух выборках вместе на пересечение границ страниц пришлось 31 из 34 чистых выигрышей графа над поштучной оценкой.
