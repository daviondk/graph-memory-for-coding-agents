# Редактируемый исследовательский отчёт

Эталон оформления — опубликованный отчёт второго раунда. Сохранены набор стилей, А4, размеры полей, заголовки разделов, табличные стили и размещение выходных данных. Входной Word предыдущей серии открывается как шаблон в памяти по контрольной сумме, указанной в REPRODUCE.md. В этой серии к таблицам добавлено изображение научного графика из экспериментальных данных полного сериализованного кэша. 
Работающий генератор и UTF-8 источники страниц находятся в report, конечные версии — в outputs. Копии исходных данных, веса, прогнозы и логи перечислены в самостоятельных описаниях каждой ветви. Рендер выполняет упакованный LibreOffice на D, дальнейшая проверка просматривает страницы PDF, документы OOXML и числовые значения из исходных результатов. Журналы публикуются только после подтверждения тождественности SHA-256.
