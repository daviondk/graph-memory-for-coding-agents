# Действующий агент — сборка целого класса

Дополнение фиксируется до получения оценок первичного ClassEval. Проверяем существенное для переноса предположение: если прошлые методы тоже написал этот решатель и в них могут быть ошибки, то полезность выбора памяти может измениться. Выбираем до 14 классов из прежнего безопасного предметного перечня, у которых 3–5 методов и исполняемая эталонная реализация проходит все авторские классы тестов, в том числе интеграционные. В отборе только число методов, пригодность harness и фиксированный SHA256('r3online|'+class), без оценки сгенерированного кода. Из-за частичного пересечения с teacher-forced проверкой это проверка смены режима, а не новый независимый benchmark. Диагностический и исторический набор из 108 методов имеет другой знаменатель.

Агент за один проход реализует все методы каждого назначенного класса в опубликованном порядке, видит одинаковый заданный конструктор, сигнатуры, текущий контракт и по своей памяти части собственных предыдущих генераций. Три политики: BM25 тех же строк (160), новый граф тех же наблюдений (160), вся предшествующая реализация до 800 токенов. Ни эталонные прежние тела, ни готовые тесты, ни выход скрытого оценщика в генератор не поступают. Используется тот же серийный локальный Qwen3.8-27B, температура 0, один ответ, максимум 384 новых токена на метод. Идентичные запросы кэшируются, отличающиеся решаются отдельно. При ошибке формата сохраняется признак неудавшейся генерации и для продолжения локальной истории подставляется заглушка именованного метода; результат её тестов считается по общим правилам без ручного исправления. У каждого варианта собственная замкнутая история. Основной исход — все методы класса вместе проходят весь опубликованный набор (одна выборка на класс); вторичные — сколько методов прошло профильные тесты в реально собранном классе, интеграционные тесты, общее число тестов, число токенов и обращения модели. Уверенность в разностях мала при 14 классах; публикуем все поштучные исходы и дискордантность. Это ближе к опубликованной incremental generation, однако наш subset, промпт, модель и ограничения отличаются от лидерборда ClassEval. В первом эксперименте авторские методы прошлого использованы только для контролируемой изоляции механизма; здесь этот режим заменён полной историей самого агента.
