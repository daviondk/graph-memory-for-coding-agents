# Контроль на опубликованной выборке Semlith

Дополнение определено после чтения независимой страницы результатов до получения результатов R3-R. Проверяем воспроизводимость внешнего сравнения. Открытый scorecard Semlith фиксирует Random("20261003-{config}-{level}") и 500 записей на страту; копируем формулу и их crop через splitlines для keep=3. Сначала воспроизводим четыре опубликованные Acc@1 и четыре Acc@5 лексической контрольной группы по всем 2000 наблюдениям. Если числа совпадут, рассматриваем отбор как подтверждённый по поведению; отчёт Semlith содержит только агрегаты и не гарантирует тождество каждого ID. Далее выдаём для того же протокола наши предсказания с 3 строками (обучены на train независимо от этой подвыборки). Для справки приводим переход с 120 строками как другой режим доступа. Контроль Semlith — внешний отраслевой scorecard, а не подтверждённый лидер всего поля. При несовпадении критериев сравнение только как диагностика. Никакой настройки на его результат.
