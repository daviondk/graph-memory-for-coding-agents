# Является ли выигрыш следствием связности или ранга отдельных страниц

Дополнение к измеренной серии записи на 627 траекториях. Сравняем задачу выбора набора на запись и проверим на 336 других экземплярах из ещё 12 проектов SWE-smith, не участвовавших в обучении. Наблюдались агрегаты чужой проверки чтения на этой панели, результаты записи скрыты до фиксации данной программы. Повторяем исходные фиксированные методы на этой панели; основная новая проверка при 4096 байтах, затем 12288; каждая запись должна остаться в пределах своего ограничения. Та же разметка успешного следующего действия.

Две гипотезы. (1) Для одинакового прогноза распределения будущих интервалов важно учитывать полную утрату полезности, когда отсутствует любая требуемая страница; сильный альтернативный писатель аддитивно делит вес интервала поровну по его страницам и способен выбрать почти тот же набор. (2) Жадное удаление может ошибаться при различных размерах страниц, точный online выбор под тот же предел байтов может увеличить наблюдаемое покрытие. Проверяем матрицу fixed typed weights — additive/conjunctive × greedy/exact. Для аддитивной модели точное решение соответствует классическому 0-1 knapsack, для связной — DP по байтам и длине конца последней непрерывной серии, состояниям 0,1,2+. Потенциальные группы не длиннее трёх страниц. Если в новой последовательности после вывода нельзя восстановить старый edit, ограниченный кэш сбрасывает затронутый файл по исходным правилам. Локальный точный оптимум вычисляется только в момент переполнения, будущих данных алгоритм не видит. Сам по себе локальный оптимум размеченной предсказанной полезности не гарантирует улучшение на реальной траектории. Будут опубликованы все целые совпадения, доли строк, первые строки, объёмы, пары выигрыш/проигрыш, групповые интервалы, а также частота улучшения локальной цели при одинаковой исходной памяти. Веса не корректируются. Первичный contrast — exact conjunctive минус exact additive, то же решение и байтовый бюджет, разная полезность групп. Графовую DP независимо сверяем с перебором всех подмножеств на малых задачах со случайным размером страницы и разрывами сцен. Теория 0-1 knapsack и последовательное динамическое программирование известны. Проверяем новое применение в памяти предыдущих правок и границу его преимуществ.
