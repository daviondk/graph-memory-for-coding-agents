# Поправка на несколько исходов и чувствительность к диалогу

После получения общих результатов проведена дополнительная проверка. Использованы только опубликованные ранее исходы исходных политик. Стандартный точный двусторонний тест меняет знак суммарной парной разности разговоров всеми 1 024 способами. Для двух исходных основных исходов полное покрытие@5 по репликам имеет p=0,0391, после поправки Холма по двум — 0,0781; для целых сессий — 0,375 до и после поправки. У семи диалогов прирост по репликам положительный, у двух нулевой. При поочерёдном исключении любого диалога суммарная разность лежит между +1,27 и +2,35 п.п.

Для четырёх стилей переноса заранее зафиксированных весов значения p после поправки Холма составили 0,0078, 0,0117, 0,0117 и 0,1875 для прямого, скрытого, контрфактуального и составного обращений соответственно. При удалении любого диалога преимущество в первых трёх вариантах остаётся в диапазонах [4,91;5,67], [3,44;4,13] и [6,51;7,78] п.п. В составных обращениях исходная абсолютная доля успехов мала. Все варианты используют те же десять историй.

Воспроизведение: запустить `python family_audit.py`. Файл family_results.json содержит точные величины, число положительных и нулевых групп и проверку исходных p.
