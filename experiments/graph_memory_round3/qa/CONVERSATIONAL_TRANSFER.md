# Перенос весов на LoCoMo-Conv

Дополнительный опыт после LoCoMo. Выпущенный Chang и Chen набор EMNLP Findings 2026 использует те же десять историй с новыми формулировками. Замораживаем R3-ранжировщики точно из основного опыта. Для каждой переформулировки используем веса, обученные только на девяти других историях и исходных вопросах. Все четыре типа — dialog, implicit, counterfactual, composed — в отчёте раздельно. Удаляем из входа сведения о правильном говорящем, supportive_memory, expected_memory_use, исходном вопросе и ответе. Эти сведения иногда доступны разработчику корпуса, но читатель получает только фактическую строку нового пользовательского обращения. Индекс реплик тот же, параметры обучения и представления те же. У нескольких новых формулировок один первоисточник; интервалы отдельно по десяти диалогам. Популяция — все непустые опубликованные формулировки с исходной категорией 1–4 и доступными ID; все composed с полностью доступными ID и непустым запросом. Основные числа — All@5 и средняя доля золотых ID в первых 10 оригинальных репликах. Сравнение с публикацией только после проверки совпадения единиц памяти и метрики. Новых ответов QA или генерации многовариантного retrieval-запроса в этой ветви нет. Тест различает пользу привязки говорящего в прямом QA и её перенос при сокращении ссылок на людей.
