# Чувствительность к фактическому расходу

Заморожено, когда основное прогнозирование ещё выполнялось, до любых новых тестовых оценок или открытия файла исходов. Адаптивное окно может использовать больше токенов, чем R2-F при одинаковом верхнем лимите. На каждом шаге восстановим фактически списанные токены R2-F, а также токены его целого сериализованного пакета. Повторно разрешим каждому методу только решения, удовлетворяющие обеим фактическим индивидуальным величинам того же шага. Пустой вывод R2-F означает нулевой бюджет у любого метода. Старый пакет всегда допустим как fallback. Прочие обучающие данные, предсказатели и наборы вариантов неизменны. Для экономии одна замороженная контрольная чувствительность при номинальных 512 токенах. Для защиты от зависимости от случайного результата её вывод приводится независимо от знака. Подсчитываем точное и частичное покрытие, фактические средние расходы и парные интервалы по репозиториям.
