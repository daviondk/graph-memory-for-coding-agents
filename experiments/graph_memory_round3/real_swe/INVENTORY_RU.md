# Где найдены пригодные реальные траектории

На диске D каталог x20-swe-context/traces содержит 300 Claude Code JSONL (126 379 059 байт). Внутри есть Read и Edit, а также Bash, Write, Grep и другие инструменты. Формат использует пути среды Claude, поля file_path/old_string/new_string и собственные результаты. Метаданные case_metadata содержат отдельные issue, но нельзя автоматически считать каждую такую сессию уникальным официальным решением SWE-bench Verified. Для нового сравнения они не использовались. Наборы SWEContextBench относятся к самостоятельной постановке поиска репозиторного опыта.

В репозитории SWE-bench/experiments просмотрены каталог Verified и материалы SWE-agent за 25 февраля и 22 мая 2025. У отправки 22 мая README указывает на открытый S3 swe-bench-submissions/verified/20250522_sweagent_claude-4-sonnet-20250514. В каталоге trajs имеются отдельные .traj с двумя записями о действии — командой/результатом и историей модельных tool calls. С помощью публичного GET можно получить один объект без скачивания репозитория. Авторский результат 345/500 (69%) относится к исходному SWE-agent с Claude Sonnet 4. В настоящей работе его ответы воспроизводятся как наблюдения. 69% не является показателем изучаемой политики записи. [Авторская карточка запуска](https://github.com/SWE-bench/experiments/blob/40f164d5b8f1d249bf95a6df8b74b577fd8e519d/evaluation/verified/20250522_sweagent_claude-4-sonnet-20250514/README.md)

Выбранные задачи стратифицированы по проекту до получения .traj и не отфильтрованы по успешности патча. Локальный каталог метаданных сверялся с текущей публичной ревизией официального набора. Для 165/165 задач идентичны ID, репозиторий, базовый commit и исходное описание. Все 12 официальных проектов не пересекаются с 44 обучающими проектами R2-F. Оценка использует только исходную формулировку и доступные во время действий наблюдения. [Официальные данные Verified](https://huggingface.co/datasets/SWE-bench/SWE-bench_Verified/tree/78f471bf655a3137b2e8a75af1501690ec009ec3/data)

Для каждого tool-события хранятся хеш команды и идентификатора вызова, диагностические количества строк и пересечение двух представлений. Третьей независимой проверкой на десяти хеш-выбранных задачах сопоставлен уже отрендеренный следующий запрос самой модели. Все 9 576 строк проекции при парной проверке 253 запросов присутствовали в этом следующем запросе с теми же координатами и текстом. Этот тест контролирует риск подстановки лишних строк, которые исходный агент никогда не видел. query_audit.json и metadata_audit.json содержат результаты проверок по каждому источнику.
