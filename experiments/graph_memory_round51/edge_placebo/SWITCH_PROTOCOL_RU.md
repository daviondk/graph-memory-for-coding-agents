# Дополнительный контроль числа вмешательств

После основного расчёта обнаружено сильное ухудшение при перепривязке флагов, даже внутри пары соседних рангов. Часть разности может появиться, когда ложная отметка меняет победителя в вопросе, где корректная ничего не меняла. До расчёта этой чувствительности фиксируем ограничение: из уже перечисленного набора перестановок сохраняем только варианты, для которых факт смены победителя относительно той же полной линейной модели с выключенным для всех флагом равен наблюдаемому. Исходный вариант всегда допустим. Предвыборочные веса, канонические ничьи, число отметок в каждой паре и принадлежность к вопросу остаются фиксированы. Условная вероятность полного покрытия считается равномерно по оставшимся назначениям внутри каждого вопроса. Публикуем также число вопросов, на которых возможны разные победители и исходы. Это вторичный анализ после ознакомления с основным отрицательным контролем. Узкие группы могут давать мало контрфактических адресов. Данный опыт измеряет релевантность расположения отметок среди способов совершить столько же вмешательств.
