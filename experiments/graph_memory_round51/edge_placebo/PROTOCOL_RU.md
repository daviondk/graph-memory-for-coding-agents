# Отрицательный контроль видимого упоминания

Исходы уже опубликованного R51 известны. До расчёта новых контролей зафиксированы модель с прежними пятью коэффициентами и три панели — 2Wiki 1280, Hotpot 640 и Hotpot 1280. Ни один вес и ни одно чтение не переобучаем. Для каждого вопроса сортируем оставшиеся заголовки по независимо обученной модели hybrid без флага упоминания. Сохраняем число помеченных заголовков внутри каждой соседней пары рангов (1,2), (3,4) и т.д., при нечётном числе хвост остаётся неизменным. Назначения флага в каждой маленькой группе равновероятны. Вторая постановка сохраняет только общее число флагов в вопросе. Третья сохраняет их число в соседних тройках. Полным перебором всех допустимых наборов получаем точные вероятности выбора и полного комплекта опорных заголовков при данных первом документе и коэффициентах. Равенства по score разрешаем исходным местом кандидата. Первичная величина на каждой панели — наблюдаемая полнота минус ожидаемая полнота при перестановке внутри пар. Дополнительно публикуем долю эпизодов с действительно изменяемым вторым адресом, распределение ожидаемых результатов, индивидуальный парный 95% интервал разности по первым документам и точный односторонний хвост пуассоновско-биномиального нулевого распределения при независимых назначениях по вопросам. Три первичные проверки обозначим поправкой Холма. Знаки условного эффекта ограничены выбранными группами рангов. F1 не оцениваем: для многих перестановок новый источник решатель не читал.

Независимо пересобираем поле edge из точно того текста, который агенту уже был виден, и заголовка каждого кандидата. Критерий из исторического исходника — непрерывная последовательность Unicode-букв/цифр после приведения к нижнему регистру и удаления разделителей, суммарно не менее трёх символов. Сверяем не только флаг, но все позиции совпадений. Первичный фильтр и число кандидатов остаются как в исходном опыте. При совпадении признака и цифр метод эквивалентен материализации лексического предиката при этих входах. Факты о прочих графовых отношениях или superiority против всех вариантов поиска из этого не следуют.
