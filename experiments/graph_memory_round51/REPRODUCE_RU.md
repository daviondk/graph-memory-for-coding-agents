# Проверка комплекта

`python -B verify_release.py` проверяет состав каталога, SHA256 всех файлов и шесть отдельно зафиксированных манифестов. `python -B verify_release.py --git-ref HEAD` также читает все объекты Git этой серии и сравнивает байты. Численные проверки доступны через `python -B verify_release.py --studies --science-python ПУТЬ_К_PYTHON_С_NUMPY_SCIPY --system-python ПУТЬ_К_PYTHON_3.14`. Для этой версии системный Python содержит NumPy, стандартный compression.zstd, pypdf; ffprobe доступен в PATH. Для проверок по полным исходным признакам нужны оригинальные массивы, описанные в соответствующих протоколах на диске D. Для просмотра автономного пакета и сверки встроенных SQLite-данных достаточно Python 3.10+ и распакованного ZIP.

- [Опорная серия R50](../graph_memory_round50/REPORT_RU.md) содержит результаты для исходных порогов и модели, которую затем проверили на других данных.
- [Перенос](transfer/REPRODUCE_RU.md) и [маршрутизация](routing/REPRODUCE_RU.md) сохраняют исходные поштучные оценки, зарегистрированные условия, модели и журнал работы GPU.
- [Обученный гибрид](baseline/REPRODUCE_RU.md) и [подтверждающий опыт](baseline/confirm/REPORT_RU.md) сохраняют веса и все назначения вариантов. [Маскирование признака](frozen_ablation/REPORT_RU.md) и [случайные перестановки рёбер](edge_placebo/REPORT_RU.md) проверяют механизм.
- [Кодовая память](code/REPRODUCE_RU.md) включает точное декодирование переданных кадров на двух панелях.
- [Оценка политики и два интерфейса](policy_replay/REPORT_RU.md) сверяют действительные решения SQL и наличие ответа для полного ключа входа. [Материалы подачи](submission/REPORT_RU.md) включают отдельный тест запуска из чистого архива.
- [Скрипт рисунка](figure.py) читает интервалы из результатов по четырём панелям. Для построения нужны Matplotlib и NumPy. [Рисунок PDF](ranker-comparisons.pdf)
