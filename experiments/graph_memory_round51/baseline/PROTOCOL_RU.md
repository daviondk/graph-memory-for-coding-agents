# Контроль силы базового ранжирования

Ретроспективный анализ. Авторы уже знают опубликованные в R50 агрегаты порога и dense на обоих holdout. До построения новых ранжирований здесь фиксируются признаки, потери, размеры, метрики и контрасты. Числа из holdout не используются при обучении. R50-порог подбирался на калибровочных ответах по Answer F1. Признаки ниже используют только видимый каталог, один открытый документ и вопрос.

**Панели.** Учим на исходных 640 вопросах R50 semantic_address. Второй набор из 640 (adaptive_address) используется как вторичный, окончательный из 1 280 (gate_confirmation) — основной. Порядок и открытая первая страница фиксированы. Каждая пара сравнивается внутри вопроса. Все три панели из публичной части 2Wiki train. Новых датасетов и генераций в этом эксперименте нет.

**Обученный гибрид.** Признаки каждого из девяти кандидатов: cosine Qwen3-Embedding-8B, 1/(1+r_q) и 1/(1+r_s) для лексического ранга по запросу и по видимому префиксу соответственно, cosine-ранг 1/(1+r_d). Архивные ранги r_q и r_s нулевые, получены по десяти заголовкам до исключения первой страницы, r_d — нулевой среди девяти. Полная модель добавляет бинарный признак точного наблюдаемого упоминания заголовка в префиксе в терминах R50. Метки обучения — принадлежность заголовка эталонной документальной опоре. Для каждой пары «релевантный – нерелевантный» минимизируем логистическую потерю со средним весом по запросу, плюс 0,5 / 640 от квадрата нормы коэффициентов. Стандартизация признаков по всем кандидатам калибровки, нулевая дисперсия замещается единицей. Без подбора регуляризации или вариантов после оценки. Равные итоговые оценки разрешаются порядком исходного dense. Это простой линейный контроль на основе pairwise learning to rank. Дополнительные однофакторные контроли — свободный dense, всегда лучший упомянутый, порог R50 и гибрид без ребра. [Парное ранжирование](https://doi.org/10.1145/1102351.1102363) · [Исследование гибридного поиска](https://arxiv.org/abs/2210.11934)

**Основной вопрос** — полное покрытие эталонных заголовков при двух чтениях, сравнение полной обученной модели с порогом R50, ранжируем все 9. Показываем также полную модель против гибрида без ребра и последнего против dense. Для конечного ответа одинаковый скорер ранжирует только две ранее исполненные альтернативы (dense и лучший упомянутый, которые могут совпадать). Новое решение выбирается из прежних идентичных промптов с той же длиной, позволяя вычислить Answer F1 и EM для всех вопросов. Основной контраст для этого отдельного действия — полная модель на паре против порога. Сопоставление также с безусловными переходами и абляцией. Для открытого выбора из девяти укажем точное покрытие кэшированными действиями при исходном контракте, сумму наблюдаемых F1 и строгие арифметические границы среднего при 0≤F1≤1. Для недостающих результатов никаких замен. Границы предполагают возможность подать новый документ при фиксированной длине прежнего контекста; физическая проверка наличия нужного числа токенов не входит в этот контракт для новых адресов. Не трактуем их как результат нового запуска.

**Дополнительная политика под Answer F1.** Поскольку победитель по покрытию может вредить ответам, на калибровочных вопросах с расхождением пары предсказываем разность F1(linked)-F1(dense) обычной линейной ridge-регрессией с коэффициентом штрафа 10, незаштрафованным свободным членом и четырьмя разностями стандартизованных признаков гибрида без ребра (linked минус dense). Переход при строго положительном прогнозе. Описательный контраст против фиксированного порога, обе альтернативы полностью наблюдались. Это позволяет честно проверить расхождение двух обучающих целей. 

**Оценка.** Публикуем все сравнения, полный список выборов, бинарное полное покрытие, долю найденных опор, EM, F1, число замен и размерность обучающей выборки. Для указанных пар — процентильный 95% парный bootstrap по первым документам, 10 000 выборок, seed 510271. Формируем одну матрицу перевыборки для всех метрик данной панели. При неоднозначных границах вывод ограничиваем наблюдаемым эффектом. Единственный первичный тест — полная модель против порога по покрытию девяти вариантов на 1 280. Вторичные интервалы номинальные без поправки за множественность. Для первичной бинарной метрики также точный двусторонний знаковый тест по несовпавшим вопросам при уникальности первых документов. Сохраняем веса моделей и входные контрольные суммы. [Исходный набор 2WikiMultiHopQA](https://aclanthology.org/2020.coling-main.580/)
