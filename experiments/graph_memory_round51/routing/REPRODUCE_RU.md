# Воспроизведение

Проверка сохранённых результатов выполняется из каталога `routing` командой `python -B verify.py --manifest`. Требуется сохранённый соседний каталог `transfer` со штатным проверяющим скриптом. На этом этапе не нужны видеокарта, веса моделей и сеть.

Для повторного расчёта по исходным данным используйте чистый рабочий checkout прежних серий с двумя отдельными каталогами `transfer` и `routing` в `experiments/graph_memory_round51`. В первом лежат запечатанные материалы предыдущей выборки, во втором — исходники и протокол текущей проверки. Сначала загрузите оба общедоступных parquet и исходный официальный оценщик через `transfer/fetch.py`. Файлы прежних входных каталогов доступны по путям в `study.py` и архиве R50. Для полного повторения нужны два GGUF с совпадающими SHA-256, llama.cpp и библиотека токенизации, использованные в R50. Приватный каталог для логов и новых данных задаётся переменной `P`. Поставьте в него ту же копию `official.py`, что скачана в приватный каталог `transfer`.

```powershell
python -B study.py register select lex_orders projection encode route
python -B reader.py
python -B study.py costs
python -B score.py
python -B overlap_sensitivity.py
python -B report.py
python -B verify.py
```

В отдельном новом запуске значения времени, а также связанные с ними хеши, могут отличаться. `flags.json.gz` хранит решения по видимому вопросу до выбора адресов, `router-choices.json.gz` — адреса до инференса. `gold.json.gz` и независимый `verify.py` позволяют повторить оценку для всех 1 280 × 4 логических исходов. `costs.json` и `timing-events.json.gz` фиксируют физические вызовы, включая 32 независимых повтора.
