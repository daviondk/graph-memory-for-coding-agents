# Можно ли выбирать графовую политику по формулировке вопроса?

На новой панели из 1280 HotpotQA distractor первичная парная разность **0,176 п.п. Answer F1** с 95% ДИ **[-0,189; 0,566]**. Первичная проверка оставляет преимущество над постоянным предпочтением упомянутого заголовка неопределённым. Исходная гипотеза пришла из предыдущих 640 вопросов, где граф сильнее помогал при переходе через промежуточную сущность, а для сравнения двух сущностей такая связь часто вела в сторону. Решение использовало только слова вопроса, например *both*, *same*, *older*, и заранее заданный признак вопросительной конструкции с *and/or*. В 182 случаях правило предложило обычный семантический поиск, в остальных — приоритет упомянутого адреса. Только в **24** из 1280 случаев две политики действительно выбирали разные документы. При сравнении с безусловным переходом F1 вырос на 5 вопросах, снизился на 3, совпал на 1272. ### Данные и границы измерения

Панель отобрана по фиксированной хеш-сортировке из обоих публичных train-шардов HotpotQA, содержащих 90 447 вопросов. Пропущены 260 повторных первых документов и 8 известных или повторных вопросов. При формировании учтены 23181 прошлых вопросов и 139451 документов. Новые первые документы уникальны, а у 798 вопросов хотя бы один другой документ уже встречался. Принадлежность этих примеров к данным предобучения моделей неизвестна. [Реестр панели](panel.json)

Три базовых варианта и маршрутизатор используют Qwen3-Embedding-8B Q4_K_M для адресации и Qwen3-4B-Instruct-2507 Q4_K_M для ответа. Первый документ выбирается прежним BM25. Для чтения использованы две страницы на эпизод и один и тот же фактический бюджет у всех вариантов, 359881 токенов за панель на политику. Стенд выравнивает длины с помощью предвычисленных длин фрагментов; это число доступных модели фрагментов, физические обращения СУБД здесь не измерялись. Для 5120 логических ответов хватило 1505 уникальных полных промптов, затем выполнены ещё 32 проверочных вызова модели. На RTX 3090 генерация и повторы заняли 160,83 с. Эмбеддинги считались отдельно. [Токены и бюджеты](reader-boundaries.json) · [Ресурсы](costs.json)

Официальный HotpotQA eval пересчитал Answer F1/EM на всём наборе. Независимая проверка подтвердила все 5120 комбинации вопроса и метода, исходя из сохранённых токенов, ответов, адресов и эталонных заголовков. Оценка относится к будущим вопросам при том же специально ограниченном двухшаговом интерфейсе.
