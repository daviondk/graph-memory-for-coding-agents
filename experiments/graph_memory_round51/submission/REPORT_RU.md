# Материалы ICDE Demonstrations

[Четырёхстраничная рукопись PDF](paper.pdf) · [Редактируемые исходники](paper.tex) · [Автономный комплект для рецензента](candidate.zip) · [Озвученная видеодемонстрация](walkthrough.mp4)

В восьмой SQLite-консоли посетитель сравнивает способы выбрать следующий источник. На странице «Rank the next source» можно посмотреть фрагмент, отключить его фактическое упоминание, исполнить SQL-ранжирование и проверить, известен ли ответ модели при таком выборе. В режиме «Replay a policy change» два значения бонуса определяют, какие полные входы требуют повторной оценки и какие случаи заведомо дают нулевую парную разность. Доступны две панели 2Wiki и две панели HotpotQA. Первоначальные семь консолей продолжают работать, включая пошаговые операции на траекториях и правках кода.

В архиве находятся PDF и исходники с иллюстрациями, базы SQLite, стандартная библиотека Python как единственная зависимость сервера, двенадцать пунктов меню и 17 сцен видеодемонстрации длительностью **4 мин 37 с**. Авторский блок оставлен для заполнения перед подачей. [Данные и условия распространения](DATA_SOURCES.md) · [Правила конференции](https://icde2027.github.io/cf-demonstrations.html)

В чистой распаковке `python -B demo.py` запускает локальную стартовую страницу, а `python -B verify_candidate.py` проверяет все восемь работающих консолей и примеры смены выбора. Для полного воспроизведения архива из репозитория служит `python -B package.py`. Ключ `--build-paper` пересобирает рукопись Tectonic. Независимый `python -B verify.py` проверяет содержимое ZIP, запуск после распаковки, текст и формат страниц PDF, кодеки и декодируемые кадры видео.
