# Перенос порога на HotpotQA distractor

До построения панели и любых прогнозов фиксируем N=640. Единственный основной исход — разность официального HotpotQA Answer F1 между правилом R50 (порог 0,04178261756896973) и свободным Qwen3-Embedding-8B. Остановка после обработки всех 640. Проверки и выводы относятся к двум чтениям внутри предоставленного каталога. Подбор параметров завершён на другом корпусе, 2WikiMultiHopQA. Публикуем результат любого знака.

Выборка из обоих шардов публичного HotpotQA distractor train, ревизия Hugging Face 1908d6afbbead072334abe2965f91bd2709910ab. Официальный validation уже использовался в более ранних экспериментах проекта. Сортируем ID по SHA256(«r51-hotpot-gate-v1|» + ID). Уникальные нормализованные вопросы и первые документы. Исключаем ID и нормализованные вопросы из HotpotQA validation, прошлых 2Wiki train-панелей семантического метода и полного 2Wiki dev. Исключаем первые документы, тождественные по SHA256(title + NUL + body) любому документу этих выборок. Отбор использует только видимые поля. Содержимое отдельных отвлекающих документов может повторяться и обучающие данные языковых моделей неизвестны.

Без подстройки сохраняются BM25 по заголовкам для первого шага, видимый префикс E5, поиск упоминаний, запрос к семантическому ранжировщику, голые заголовки кандидатов, квантизация Q4_K_M, порог, обработка равенств, два документа и покомпонентное равенство бюджета токенов между тремя ветвями. Сравниваем также политику всегда отдавать предпочтение упомянутому адресу. Применяем прежний Qwen3-4B-Instruct-2507 с прежним промптом, жадным декодированием и пределом 96 токенов. Сохраняем все ранги, токены, ответы и хеши. Идентичные промпты вычисляем один раз для всех политик. Запечатываем выводы перед открытием gold. Вторичные метрики — EM, наличие всех опорных заголовков, доля найденных заголовков, число смен адреса.

Основной 95% ДИ — 10 000 парных bootstrap-перевыборок по уникальному первому документу, seed 470091. Дополнительно двусторонняя смена знака разностей с нулями, исключёнными до расчёта, полный перебор при k ≤ 20, иначе 1 000 000 перестановок seed 500731. Показываем число улучшений, ухудшений и совпадений на всех 640. ДИ и p границ интерпретируем с учётом возможной малой мощности. Бенчмарк и сплиты — [HotpotQA](https://hotpotqa.github.io/), [зеркало данных](https://huggingface.co/datasets/hotpotqa/hotpot_qa/tree/1908d6afbbead072334abe2965f91bd2709910ab/distractor). Официальный leaderboard предполагает доступ ко всем десяти абзацам и локализацию опорных предложений.
