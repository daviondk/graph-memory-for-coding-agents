# Независимая проверка равных рангов

После регистрации и первого расчёта обнаружены различия в порядке пяти пакетов сглаживания с λ=1/2 при проверке через точное целое произведение рангов. Два математически равных логарифмических балла могли округлиться по-разному. Для восстановления предусмотренного исходным протоколом приоритета текущего ранга вычисляем монотонно эквивалентную величину r^(4−t) p^t с t=4λ, где r и p — целые положительные ранги. Для положительных t это целые числа, для отрицательных используем точные рациональные числа. Воспроизводим прежнюю сетку, критерий dev и те же состояния. Проверим изменения порядка, состава и Complete-MSS, включая контроль с переставленными связями. Размещение представления на канале использует только первоначальный текущий порядок и от этих рангов не зависит. Это исправление после ознакомления с результатами; старые сводки и изменения пакетов будут сохранены. Остальные меры не изменяем.
