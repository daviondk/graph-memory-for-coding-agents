# Перенос точного кодирования на официальный SERBench Test500

После положительного результата для физического размера на Cal500 фиксируем внешнюю проверку. На Test500 до этого осматривались схема строки и имена полей, архив R50 уже содержит реконструированную историю без скрытых меток и прежняя серия — независимую выдачу. Выбираем существующие ненулевые топ-8 замороженного test500-lexical-residual из R39. Все 491 допустимое состояние, никаких новых оценок кандидатов и никакой селекции по сжатию. Независимость по репозиториям сверяем явно. Переход берём строго из R50 test-panel; сырых событий Test500 нет, сохранена проверка ID-переходов в R50. Эта неопределённость не меняет равенство декодированного пакета его исходному варианту при одинаково установленном прошлом пакете на обоих концах.

Фиксируем все четыре одиночных кодировщика из предыдущего протокола с прежними уровнями, словарём и правилами литерального восстановления. Основной контраст — экономия полного кадра типизированного кодировщика с вычислимым digest против такого же типизированного кодировщика, передающего 32 байта. Оценка — процент суммы байтов на 491 состоянии и 95% интервал по 20 000 перевыборок целых репозиториев, seed 510314, вслепую к целевому набору. Вторичные — тёплые состояния, доля выводимых хешей, число строгих выигрышей и четыре абсолютных объёма. Проверяем восстановление всех семи полей в исходном порядке. Функцию потерь SERBench на Test500 подсчитать невозможно без скрытых сертификатов, равенство выхода означает сохранение любой детерминированной оценки того же пакета. Сравнение относится к инфраструктуре хранения и доставки, скорость решения задачи не проверяем.
