# Прямой эффект наблюдаемого ребра при фиксированной модели

Ретроспективный разбор ранее завершённых панелей HotpotQA 1 280 и 2Wiki 1 280. Общее превосходство обученной графовой модели над моделью, переобученной без ребра, уже известно. Здесь добавляем ровно одну новую политику. Используем все коэффициенты обученной графовой модели и при выборе зануляем бинарный признак упоминания у каждого кандидата. Для argmax это эквивалентно удалению соответствующего слагаемого из итогового счёта. Масштабы остальных четырёх признаков и их коэффициенты сохраняем. Сравниваем graph, masked и гибрид, заново обученный без ребра (hybrid). Формулы фиксируются до вычисления выбора masked и его ответов. Разделяем вопросы по наличию хотя бы одного наблюдаемого ребра среди доступных вторых страниц.

Единственный первичный контраст — парная разность Answer F1 между graph и masked на всех 1 280 HotpotQA. 2Wiki выступает описательной внешней проверкой. Сопоставление masked с hybrid оценивает вклад изменившихся общих коэффициентов на выбранной шкале предсказаний. Складываем обе парные разности для восстановления общего контраста graph против hybrid. Декомпозиция зависит от выбранного порядка вмешательств. Вопросы с пустым набором рёбер должны дать строго идентичный адрес и ответ у graph и masked. Сравнения в слоях по наличию ребра и Full Support вторичные. Парные процентильные интервалы — 10 000 перевыборок уникальных первых документов, seed 510812. Для основного F1 двухсторонняя проверка случайной смены знака по ненулевым парным разностям: полный перебор до 20 пар, иначе миллион симуляций, seed 510272. Без интерпретации выбора подгрупп как независимой репликации.

Контракт — то же первое чтение и один выбор следующего документа из того же видимого каталога. При выборе новой страницы сохраняем старый общий фактический лимит второй страницы, если она достаточно длинна. Если она короче, все три варианта для этого вопроса получают одинаковый меньший лимит; повторно запускаем все новые массивы токенов. Считаем хэши точных входов, повторяем шесть полностью наблюдавшихся промптов для каждой панели и проверяем исходный официальный оценщик. Никакого переобучения, изменения других признаков или прерывания по достигнутому эффекту.
