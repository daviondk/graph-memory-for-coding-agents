# Контроль с перестановкой связей одного вызова

Дополнительная проверка механизма сформулирована после основных результатов на 2 000 запросах. Используем те же зафиксированные ранги и целые provenance units. Повторно ранжировать текст и пересчитывать модель не требуется. Сохранённый префикс, порядок BM25, порядок разрешения равенств, стоимость и правило заполнения остатка остаются общими для всех условий. Эталон доступен только на шаге оценки после хеширования предсказаний.

Основной placebo P1. Внутри траектории сопоставляем вызовы одной операции с одинаковым числом событий аргумента и результата и с одинаковым числом чанков по каждой стороне. В каждой страте размера ≥2 строим циклический сдвиг в порядке SHA256(seed, траектория, callOrdinal), меняя принадлежность только выходной стороны вызова. Непустые парные вызовы участвуют в перестановке, singleton и односторонние записи сохраняют связь. Это сохраняет роли, степень на уровне событий и выхода на отдельные чанки, а также исходное содержание каждого узла. Изменяем все доступные пары в каждой такой страте. Seed заранее заданы целыми 0…15 без отбора. Каждый seed задаёт один общий граф для всех запросов данной траектории. Дополнительный placebo P2 группирует по операции и числу событий каждой стороны, допуская различия числа чанков. Причина — покрыть больше переставляемых пар при сохранении числа событий.

Основная оценка — разность Full Support@2048 настоящего графа и среднего 16 placebo (в процентах запросов). Считаем средний фактический расход, Coverage, Density, диапазон и отдельный результат каждого seed, долю изменённых пар и долю запросов с изменённым выводом. Интервал описательный кластерным bootstrap по 1 207 траекториям, 10 000 повторов, seed 13; 16 перестановок одной задачи не образуют 16 новых наблюдений. Результат на 1 795 запросах заново считаем после исключения ранее назначенных траекторий. Результат условен относительно фактического числа перемешиваемых пар и выбранной нулевой модели. Никакого подбора seed или политики по результату этой проверки.
