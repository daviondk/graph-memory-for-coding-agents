# Замороженный E5 и упаковка графовой памяти ISETrace

На полном официальном test split v7 сравниваем пять способов уложить одно ранжирование provenance units в 2 048 токенов. 2 000 запросов, 1 207 траекторий. ID и SHA предшествующей когорты фиксируются до ранжирования. Основная гипотеза — добор противоположной стороны инструментального вызова повышает долю полного покрытия (full support) относительно нативного prefix и skip. Сравнения с value и clip проверяют влияние цены блока и полноты заполнения окна. Дополнительный контраст использует тот же PU-pair BM25 на тех же ID. Главный контроль статьи — PU frozen E5 prefix, FS 50,50%, span coverage 58,20%. Опубликованные значения служат калибровкой, величина расхождения сообщается полностью.

Источник, токенизатор разбиения 504/64, нормализация, E5 префиксы query/passage, объединение оценок и сортировка берутся из авторского репозитория и R17. Кеш ключуется точными байтами строки с префиксом. Подготовка использует только текст запроса и доступные события. Упаковки prefix, skip, value, related из R17 заморожены; matched clip отрезает первый непоместившийся блок по исходной границе токена из R18. В каждой ветви учитываются стоимость, число блоков, coverage, density, F1 и FS по официальному оценщику. Точная ожидаемая стоимость равна сумме размеров переданных блоков. Траектория служит кластером для 10 000 парных бутстреп-повторов с seed 13. Единица основного усреднения — запрос.

Основная вычислительная конфигурация — замороженный intfloat/e5-base-v2 на CUDA в FP32 с выключенным TF32, если измеренный темп позволяет завершить за 45 минут. Если прогноз выше, первичный полный прогон выполняется в autocast FP16 с теми же весами FP32, нормализованные векторы сохраняются как float32. Дополнительная панель 32 траекторий с минимальным SHA256("r18-e5-fp32/" + trajectory_id) полностью пересчитывается в FP32, TF32 выключен. Все сравниваемые методы в пределах панели используют одну матрицу сходств. Ускорению не соответствует какой-либо новый метод памяти. Время, тип, объём, идентичность весов и согласие рангов публикуются. Расходы на чтение и на кодирование различаются.

Первичная фиксация протокола предшествует обращениям к меткам. После фиксации прогнозов допускается открыть эталонные spans и агрегаты предыдущего BM25. Предыдущие результаты BM25 на этих же ID известны исследователям, набор не является новым holdout. Никакие команды из траекторий не исполняются.
