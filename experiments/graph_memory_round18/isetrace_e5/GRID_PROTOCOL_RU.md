# Проверка бюджетной кривой

До первого исхода E5 фиксируем полный авторский набор B ∈ {256, 512, 1024, 2048, 4096, 8192} и исходные политики prefix, skip, value, related. Гипотеза — преимущество целого парного блока относительно skip сохраняется при интегрировании по log₂ B. В каждой ячейке используется замороженное ранжирование того же запроса. Первичная для этого дополнения статистика — Full Support Budget-AUC. Вторая — Coverage Budget-AUC. Формула трапеций и сетка из Wang et al., ни одной точки по исходам не выбираем. При B=2048 выбор должен полностью совпасть с основным. Зафиксировать поштучные выборы до присоединения меток. Публикуем все четыре кривые, цена, CI парного разрыва AUC по 1 207 траекториям. Clip ранее определён для основного лимита и в этот тест не входит.
