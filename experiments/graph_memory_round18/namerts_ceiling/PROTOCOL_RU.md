# Сколько решений об отборе файлов можно улучшить относительно NameRTS

Это запланированный описательный аудит всех десяти проектов из авторского RQ1. Из предыдущего анализа уже известны три коммита Loguru и пять примеров matplotlib. Вычисляем доли по всем выпущенным целевым изменениям без ограничения этими примерами. Сначала фиксируем правила, затем читаем наборы индивидуальных меток. Оценка проверяет размер возможного выигрыша. Предсказатель не обучается.

Для каждого целевого коммита официальные списки выбранных файлов и затронутых файлов соединяются по проекту, текущему SHA и контролю базового SHA. Обозначим число тестовых файлов авторов N, официальный набор затронутых файлов G, набор выбранных каждым инструментом S. Считаем |G∩S|, |G−S|, |S−G|. Последнее число — сколько выбранных файлов метод с доступом к эталону мог бы снять, одновременно добавив пропущенные файлы при необходимости. Оптимальный селектор для этой разметки выбрал бы |G|. Отдельно проверим совпадение списка S и G, охват G, полный выбор |S|=N, число и долю лишних назначений, приходящихся на полный выбор. Одинаковое число элементов N и |S| трактуется как полный выбор по мощности, соответствие путей контролируем по меткам G. Суммы по всем парам «изменение — файл» дополним несмещённым к размеру набора средним по изменениям и средними по проектам. Одни и те же файлы на нескольких коммитах — повторные решения. Также считаем число различных базовых SHA, чтобы не выдавать зависимые изменения за независимые.

Включаем NameRTS, EkstaP и BabelRTS из той же версии исходного исследовательского пакета. Отчёт останавливается на расхождениях схемы или несовместимых идентификаторах, если их нельзя разрешить однозначно из авторских файлов. Для встречающихся разных стилей путей логируем их и проверяем штатное представление до преобразования. Пропущенные файлы/записи не считаем нулём. Ранжирование проектов по абсолютному резерву служит лишь выбором следующего исследования. У причин пропусков и лишних назначений на этой стадии нет разметки, а причинную роль импорта таким подсчётом установить нельзя.
