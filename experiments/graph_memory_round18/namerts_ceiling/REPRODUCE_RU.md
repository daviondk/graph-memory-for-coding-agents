# Как повторить аудит

Нужны Git и Python со стандартной библиотекой. Исходные данные — публичный авторский репозиторий [NameRTS](https://github.com/ZJU-CTAG/NameRTS/tree/f1acdae0f2b2d1ed6e3e2956d510db49bb7c276f) на ревизии f1acdae0f2b2d1ed6e3e2956d510db49bb7c276f. Запускайте в копии данной папки. Для другой копии NameRTS подставьте путь к ней.

```powershell
python -B audit.py D:/CodexResearch/x20-r17-namerts/NameRTS
python -B verify.py D:/CodexResearch/x20-r17-namerts/NameRTS
```

Первая команда читает только Git-блобы закреплённой ревизии. Вторая читает проверенную рабочую копию, нормализует CRLF только при расхождении с исходным SHA и перепроверяет состав множеств в SQLite. Она пробует строгое включение без удаления дубликатов. Ни в одном исходном списке не оказалось повторяющихся элементов или превышения официального общего числа тестов.
