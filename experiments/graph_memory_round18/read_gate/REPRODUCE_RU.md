# Воспроизведение

Распакуйте вместе материалы R16/anchor_transfer, R17/line_selection и R17/line_action с их контрольными суммами. Источник исходного кода R17 намеренно переиспользуется для одинаковой сериализации меню, декодирования и статической оценки. Нужны Python с PyArrow и unidiff, проверенный SWE-bench Verified parquet (см. prediction-lock.json R17/line_selection) и прошедшие проверку Git-файлы из D:/CodexResearch/x20-anchor-transfer/base. Компактная папка эксперимента сохраняет все меню, точные запросы, ответы модели, выполненные чтения, разметку и метрики. Для воспроизведения новых действий с нуля используйте отдельную копию каталога, чтобы сохранить исходные артефакты.

```powershell
python gate.py prepare
.\start_server.ps1
python gate.py run
.\stop_server.ps1
python execute.py
python score.py
python verify.py
```

Статистическая часть не требует GPU. Для проверки сохранённых исходов выполните score.py и verify.py. Последний скрипт проверяет SHA-256 всех подготовительных стадий и независимо пересчитывает точное распределение по числу позитивных, негативных и нейтральных эффектов. Результат сопоставлен с динамическим подсчётом всех фиксированных назначений. Подбор гиперпараметров по новым меткам отсутствует. Размер квоты, состав, выбор источника, порядок разрешения одинаковых оценок и назначение каждого вызова доступны до открытия меток.
