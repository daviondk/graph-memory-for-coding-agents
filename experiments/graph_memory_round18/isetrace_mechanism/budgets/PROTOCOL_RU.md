# Чувствительность к лимиту памяти

После проверки при 2 048 токенах заполняем без настройки все шесть точек официальной сетки ISETrace: 256, 512, 1024, 2048, 4096, 8192. На тех же рангах PU-BM25 сравниваем штатный префикс, добор в порядке BM25, score/√стоимости и добор противоположной стороны того же вызова. Схемы полностью совпадают с исходными. Если префикс пуст (это возможно при бюджете 256), у правила связей нет начальных узлов. Проверяем также авторский flat BM25 как независимую калибровку. Основная итоговая величина для этой дополнительной проверки — парная разность Full Support Budget-AUC (граф минус стоимость). Используем исходную нормированную площадь по log2 бюджета, Coverage Budget-AUC и поштучные расходы. Кластер — trajectory ID. При 2 048 сверяем каждое значение с запечатанным независимо посчитанным основным опытом. При прочих бюджетах сверяем нативный scorer. Сеть и модель для анализа не используются. Предсказания по новым бюджетам фиксируются до подсчёта их метрик.
