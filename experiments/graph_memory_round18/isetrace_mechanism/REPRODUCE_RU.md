# Проверка механизма

Программа использует Python, NumPy и только два файла из соседнего isetrace_official. Оба проверяются по SHA из lock.json. Показатели отдельных запросов для каждой политики уже запечатаны в исходном исследовании. Структура эталонных событий строится отдельно, после отбора контекста. Для проверки сохранённого результата запустите из этой папки следующую команду.

```powershell
python -B analysis.py score
```

Скрипт пересчитает четыре типа опорных событий и три класса относительного расхода, выполнит 10 000 кластерных повторов с seed 13 и проверит полное совпадение идентификаторов всех 2 000 запросов. Для такой перепроверки достаточно локальных прогнозов и меток. [Полный эксперимент с первоначальными входами](../isetrace_official/REPRODUCE_RU.md)
