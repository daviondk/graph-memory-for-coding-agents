# Объединение лексического и плотного ранжирования для отбора памяти

При объединении BM25 и E5 правилом reciprocal rank fusion и приоритете пар вызова и результата агент получил полный комплект источников для **1179/2 000 запросов (58,95%)**. При том же приоритете один E5 дал 1162/2 000; парная разность 0,85 п.п. Внутри одного и того же объединённого ранга приоритет пары изменил результат на 2,35 п.п. относительно обычного добора по рангу. ## Как устроено сравнение

Для 2 000 запросов в 1 207 траекториях проверены одинаковые 249089 вхождений кандидатов «запрос × узел» с точными идентификаторами, интервалами исходного текста и стоимостью. У каждой пары рангов одинаковый вес. Параметр k=60 взят из оригинальной работы; порядок задают позиции, начиная с 1. Отбор не читает координаты эталона. По каждому из четырёх вариантов записаны все выбранные узлы; для полного порядка записан контрольный хеш. Для 1249 запросов в полном порядке встретились равные баллы; их порядок задан идентификатором узла. [Исходная работа по RRF](https://doi.org/10.1145/1571941.1572114) · [Протокол перед получением результатов E5](PROTOCOL_RU.md)

Расчёт RRF использует только упорядоченные списки от замороженного intfloat/e5-base-v2 (fp32, NVIDIA GeForce RTX 3090) и BM25. Само слияние прошло на CPU. Время выполнения чтения, проверки координат, слияния и сохранения прогнозов приведено в журнале; оно исключает первоначальное кодирование GPU, извлечение BM25 и последующую оценку по эталону. Токены в таблицах — сумма цен выбранных узлов, перекрытия оплачиваются повторно. Ни расход на генерацию, ни результат ответа агента здесь не измерялись. [Журнал объединения](forecast-log.txt) · [Условия E5](../../isetrace_e5/throughput.json)

Показатель Full Support принимает значение 1 при покрытии всех размеченных символов в нужных полях траектории. Расчёт сверялся с авторским скорером и отдельным объединением интервалов. 95% интервалы для обоих первичных контрастов получены при одном и том же парном бутстрепе целых траекторий; интервалы индивидуальные, без поправки за два контраста. Ранние результаты BM25 на той же выборке известны; первичный протокол и код объединения зафиксированы в отсутствие файла прогнозов и результатов полного E5. Превышение отдельного метода при таком сравнении относится к данной конфигурации. Статья об ISETrace сообщает 77,33% FS у обученного residual R-GCN и 50,50% у frozen provenance-unit Dense c исходным префиксом. RRF — известный метод агрегации, здесь он служит конкурентным контролем для чтения памяти. [Первичная публикация ISETrace](https://arxiv.org/html/2609.25913v3) · [Воспроизведение](REPRODUCE_RU.md)
