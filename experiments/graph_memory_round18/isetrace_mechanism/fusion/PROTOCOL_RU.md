# Проверка безобучающегося гибрида BM25 и E5

План зафиксирован до появления результатов и итогового ранжирования текущего полного E5. Первичные результаты предыдущего опыта BM25 на этих запросах уже известны. Для каждого запроса объединяем обе полные упорядоченные выдачи на тех же единицах аргументов и результатов. Одинаковый вес обоих источников, ранг с единицы. RRF(node) = 1/(60 + ранг BM25) + 1/(60 + ранг E5). Параметр 60 взят из первоначальной работы. Используем точные дроби для сравнения, ничьи разрешаем по возрастанию node_id. Обучения, настройки k, перебора весов, отбора бюджета или запросов нет. [Cormack, Clarke & Buettcher, SIGIR](https://doi.org/10.1145/1571941.1572114)

Используем весь восстановленный авторский test split из 2 000 запросов на 1 207 траекториях при бюджете 2 048. До упаковки сравниваем хеши запечатанных источников и совпадение всех идентификаторов, source spans, позитивных token_count и траекторий. Из единственного порядка получаем четыре политики аналогично R17. Prefix останавливается до первой переполняющей записи. Skip сохраняет префикс и добавляет все помещающиеся целые единицы по порядку. Related сохраняет тот же префикс и сортирует хвост по принадлежности к противоположной роли любого его исходного call_id, сохраняя исходный RRF-порядок внутри двух групп. Value сохраняет префикс и сортирует хвост по убыванию RRFscore/√(число токенов), с node_id при равенстве. Для положительных RRF-баллов это точно эквивалентно сортировке по RRFscore²/token_count. Каждая политика добавляет только помещающиеся целые узлы. Выборка и запросы не меняются по исходам.

Сохраняем и замораживаем списки выборов на каждом запросе до доступа этого опыта к эталону. Первичные контрасты FS@2048 — RRF related минус E5 related и RRF related минус RRF skip. Заранее публикуем оба независимо от знака. Для каждого оцениваем выигрыши, потери, средний расход, разность, 95% парный интервал bootstrap по траекториям, 10 000 повторов и seed 13. Также даём разности к BM25 related и RRF value как описательные контроли, coverage/density и токены. Общий интервал каждого контраста индивидуальный (без поправки за множественные сравнения). Возможное улучшение RRF связано с сочетанием двух известных ранжировщиков и не устанавливает новизну их слияния. Фактическое время обработки описывается отдельно от бюджета выбранных источников.
