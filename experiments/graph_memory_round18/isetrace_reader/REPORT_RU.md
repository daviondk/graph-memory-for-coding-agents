# Нативный Qwen выбирает один подтверждающий фрагмент графовой памяти

Из предложенных фрагментов истории инструментальных вызовов читатель мог открыть один по ID. Успех означает покрытие выбранным блоком всех эталонных символов. Сравниваются две упаковки BM25 при бюджете 2 048 E5-токенов. Related добирает парную сторону уже попавшего в префикс вызова, value добирает по баллу BM25 / √стоимости. Условия используют один вопрос, стабильные ID, хронологическое представление фрагментов и одинаковое задание. Текстовый ранжировщик формирует кандидатов, действие выполняет локальный Qwen3.8-27B-UD-Q4_K_M (llama.cpp b12441; NVIDIA RTX 3090).

На основной условной панели Qwen выиграл для related у value в 1 вопросах и уступил в 0. Разность составляет +3.70 п.п., 95% описательный интервал bootstrap по траекториям [+0.00 … +11.11]. Обе политики могли прочитать одинаковые вопросы и находятся под одним лимитом. Точность локализации моделью ниже достижимого уровня в тех случаях, когда один из выданных блоков содержит все доказательства, но модель выбирает другой.

Исходная выборка — новые относительно R17 прямые вопросы официального теста ISETrace. Первичная страта содержит все 27 траекторий, прошедших строгие предметные фильтры с разными наборами фрагментов. Контроль включает все 9 допустимых траекторий с совпадающей выдачей за пределами первичной страты. Для совпадающих контекстов выполнен один запрос модели на траекторию. После блокировки 63 предсказаний загружены эталонные координаты. Числа относятся к двум условным панелям. Точность свободного ответа, перенос на другие темы и преимущество над обученным R-GCN здесь не измерялись.
