# Воспроизведение

Нужны архив R18/isetrace_official и предыдущая среда R17/isetrace по относительным путям, указанным в исходном коде. Первичные восемь шардов ISETrace, запросы и эталонный токенизатор живут в D:/CodexResearch/x20-isetrace-runtime. Операции над ними ограничены локальным чтением и вычислением хешей. В открытые файлы попадают ID узлов, ранги, токены, координаты, обезличенные значения метрик и хеши исходных байтов. Полные тексты вопросов, контексты и технический stderr сервера лежат в локальном приватном каталоге D:/CodexResearch/x20-isetrace-runtime/reader-private. [Публикационный тест](https://arxiv.org/abs/2609.25913) · [Зафиксированный источник весов](https://huggingface.co/unsloth/Qwen3.8-27B-GGUF/tree/4af51b3542f775b0a8e4b310bfb3f17e01c306c9)

Для независимого пересчёта по сохранённым выборам и исходным интервалам достаточно Python 3.11+ и команды `python -B verify.py`.

Первоначальное воспроизведение использует отдельный каталог, где ещё нет артефактов прогона. Выполните `reader.py lock`, `reader.py prepare`, `controls.py lock`, `controls.py prepare` через Python из указанного окружения. Подготовка принимает контрольные суммы R18, проверяет SHA-256 всех сырых источников на главной панели, устанавливает хеш назначенных ID и каждого поданного prompt. Контроль с одинаковыми контекстами имеет отдельный протокол и журнал.

Для генерации нужен локальный Qwen3.8-27B-UD-Q4_K_M, llama.cpp b12441 и порт localhost:18952. На свободной GPU запустите в отдельном терминале `./run_native.ps1`. После готовности сервера выполните `reader.py infer` и `controls.py infer`, подождите, пока оба запишут response-lock.json, и освободите выделенный терминал обычным Ctrl+C. При возобновлении `infer` пропускает точные хеши полученных запросов. После закрытия двух журналов выполните `evaluate_reader.py` и `verify.py`. Усечённые прогоны не оцениваются. Ответы и входной Qwen-токенаж хранятся для каждого запроса. Полная статистика включает кластеры по траекториям, нативные координаты, oracle при чтении одного блока, а также стоимость полного доставленного набора и реально открытого фрагмента.

Дизайн гарантирует одинаковые содержание и порядок общих фрагментов внутри пар. Контроль одинаковой выдачи вызывает модель один раз на однотипные запросы. При другом GPU, версии CUDA или исполняемого файла допуски численных операций могут изменить выбранный ID даже при температуре ноль. Для сравнения нового запуска с сохранённым можно сопоставить хеши точных входных JSON и пересчитать метрики в отдельных каталогах.
