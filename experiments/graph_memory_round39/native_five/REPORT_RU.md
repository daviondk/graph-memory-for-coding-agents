# Завершённое сравнение графовых читателей по пяти инициализациям

По штатному протоколу обучения R-GCN и выбора эпохи на всех 580 dev-примерах получены все десять нативных моделей. На 2 000 тестовых вопросах R35 при 2 048 токенах дал 80,89% полного покрытия. У полного нативного R-GCN 78,60%, у отдельно обученного варианта без смежности 79,21%. В обоих сравнениях общий парный интервал по пяти семенам положителен. На заранее выделенной паре 37/41 точечные разности также положительны, однако интервал для сильного варианта без смежности включает ноль. Все суммы сверены с подписанными построчными исходами исходного расчёта. [Полная таблица, интервалы и условия](REPORT_canonical.md) · [Машиночитаемые исходы](canonical-complete.json) · [Проверка](verify.py)

Зафиксированная в предыдущей серии пара сравнений была запущена на Windows с RTX 3090, Dense-FT на общих инициализациях, одинаковыми кандидатами и нативным оценщиком. Это прямое исследование того же теста, что и у Wang et al. Авторы в собственной среде сообщали 77,33% на штатном полном R-GCN. Сравнение локальных систем с локально обученной исходной моделью даёт парные оценки. Публикация одной лишь разности с числом из статьи не учитывает различия реализаций, устройства и обучения. [Протокол](PROTOCOL_RU.md) · [Wang et al., таблица 6](https://arxiv.org/html/2609.25913v3#A2)

На последнем seed загрузка отдельной модели заняла часть диска D, и очередь остановила незавершённое обучение по прежнему резерву свободного места. Попытка возобновления с отдельным порогом для финального этапа не прошла внутреннюю проверку свободного места. Десять уже сохранённых входных файлов исследования переведены в прозрачное сжатие NTFS на диске D, с проверкой равенства SHA-256 до и после каждого файла. После этого успешно отработала прежняя каноническая очередь со своим изначальным резервом. Неудачные попытки не включены как результаты, итоговый fit прошёл все эпохи. В отдельной проверке выбора эпох по бюджетной метрике обнаружен лишний аргумент train при вызове tap.py. Исправлен только вызов в отдельном диспетчере, сам подписанный код обучения и исходный протокол сохранены. [Исправленный вызов отдельной очереди](resume_dev.ps1)

Проверка переносимого канонического результата выполняется командой `python -B verify.py`. Оригинальные исходные программы и их хеши сохранены рядом под именами registered-*. Новая серия с выбором эпох по Full Support на dev имеет отдельную процедуру и не входит в эти числа.
