# Когда после отзыва любого набора источников ответ гарантированно прежний

Для порядка и полезностей, зафиксированных в одном снимке, получен точный критерий инвалидации. Пусть P — исходный пакет. После отзыва источников **все члены P должны остаться допустимыми, и каждый узел нового обязательного префикса должен уже принадлежать P**. Если оба условия выполнены, после полного решения вернётся тот же упорядоченный пакет. Нарушение любого условия требует другого ответа. Необходимость следует из определения допустимости. Достаточность следует из сохранения допустимого оптимального решения при сужении множества вариантов и устойчивого правила выбора при ничьих. На 40 траекториях ISETrace точный критерий согласовался с новым решением **во всех 108 204 сценариях**, из которых 73 261 дали прежний пакет. В панель вошли все одиночные источники и пары; тройки и восьмёрки выбирались детерминированно до расчёта. Дополнительно на 320 малых пулах независимый полный перебор исходных решений проверил 20 204 подмножества удалений. В 241 пуле встречались равные полезности кандидатов. Поштучные результаты содержат фактическое решение в виде SHA-256 и флаги всех трёх предикатов. [Исходы](results.json) · [Проверяемый журнал](outcomes.json.gz)

Операция точной перепроверки префикса потребовалась для 264 сценариев сверх быстрого поиска выбранных источников и первого остановившего префикс узла. На этой панели все 264 сохранили ответ, поэтому контроль только по выбранным источникам тоже случайно дал верное решение во всех наблюдениях. Его ошибка при других данных воспроизведена на четырёх узлах. Скорость 5,16× измерена отдельно у достаточного сертификата на одиночных отзывах. Для составных удалений данная серия оценивает правильность предиката. Число сценариев отражает все комбинации на 40 экземплярах и не является числом независимых траекторий. [Эксперимент со временем и контрпримером](../packet_invalidation/REPORT_RU.md)

Для проверки записанных результатов достаточно `python -B verify.py`. Полный вычислительный прогон требует небольшую SQLite-проекцию соседнего демо и собранный C++-решатель. Из каталога запускается `python -B test_certificate.py`, путь к библиотеке задаётся переменной `R39_KNAPSACK_DLL`. [Автономная проверка](verify.py) · [Демонстрационная база](../provenance_packet_demo/REPORT_RU.md)

ISETrace содержит синтетические сценарии взаимодействия с агентом ОС. Вызовы инструментов выполнены в изолированном окружении, а вопросы к зафиксированной истории сгенерированы и привязаны к диапазонам исходного текста.
