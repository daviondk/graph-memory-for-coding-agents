# Запуск

Переносимый демопакет требует стандартный Python с sqlite3. Команды выполняются из этого каталога. URL привязан к localhost. Нажмите Ctrl+C для завершения.

```powershell
python -B verify.py
python -B demo.py --example
python -B demo.py
```

Если порт 8765 занят, используйте любой свободный, например `python -B demo.py --port 8766`. Меню предоставляет доступ к 214 состояниям. Кнопка «Вернуть исходное состояние» восстанавливает текущий выбранный тестовый пример. Перезапуск создаёт чистую копию всей рабочей базы. Предсказания вычисляются из индексированных числовых баллов и обученных деревьев, UI получает результаты от того же Python API.

Полная повторная сборка выполняется в рабочем дереве проекта рядом с R39/set_reader, R34/external_transfer и memory_session5/serbench. Нужны локальные публичные items и labels Cal500, кеши embeddings и признаки R34, закреплённые в исходном R39. Подготовка использует NumPy и SciPy. Рейтинг, исходная проверка и замеры далее исполняются без обучения.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B build.py
python -B benchmark.py
```

Для браузерной проверки нужен установленный Playwright для Node и Chromium. Можно указать PLAYWRIGHT_DIR и CHROME_PATH для сборок, расположенных вне стандартных путей. Запустите `node ui_smoke.cjs`. Проверка открывает локальный временный порт, проверяет состояния, смену MSS@5, добавление, снятие и сброс наблюдения, мобильную ширину и сохраняет снимок интерфейса.

Воспроизведение времени заново изменяет временные значения, контрольные суммы отчётных файлов и снимок браузера. Для проверки поставленных артефактов запустите verify.py до перезаписи. SHA-256 перечислены в manifest.json.
