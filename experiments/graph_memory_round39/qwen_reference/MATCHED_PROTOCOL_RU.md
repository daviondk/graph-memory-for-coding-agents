# Согласование источника наблюдаемости с Qwen

До открытия оценок Qwen на десяти состояниях фиксируем дополнительный контроль. На том же split 179/101/214 обучим статическую R39 с пустым префиксом и остаточной целью без колонки observed_by_state и независимо подберём вес смешивания на прежней dev-панели по исходному правилу. Необучаемая маска — стабильная отсрочка отмеченных кандидатов по полному пулу; с ней сохраняются восьмислотовые условия и проверяется качество именно ранжирования оставшегося пула. Первые прямые сопоставления — Qwen против R39 без колонки наблюдаемости, и Qwen с отсрочкой против того же R39 с идентичной отсрочкой. Скрытые зависимости из других полей состояния, доступных моделям, нельзя полностью исключить. Аналогично формируем парные BGE- и union_cost-контроли.

В качестве проверки переобучаем исходный one_distance со столбцом observed и воспроизводим его ранее запечатанные предсказания. Эту модель отдельно показываем как основной вариант предыдущего исследования. Все эталонные исходы микропанели для Qwen остаются закрытыми до фиксации полных десяти прогнозов на одном оборудовании. Для всех методов сохраняем native MSS@5/@8, строгий восьмислотовый префикс под 2048/6144 токенами, среднее фактическое число токенов пяти и восьми выбранных единиц.
