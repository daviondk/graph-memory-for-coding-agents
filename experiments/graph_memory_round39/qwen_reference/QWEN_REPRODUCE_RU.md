# Воспроизведение Qwen-сравнения

Архив содержит данные, достаточные для автономной проверки прогноза и счёта, а также скрипты полного повтора. Веса модели хранятся отдельно на D и доступны по указанному SHA-256. В `work/graph_memory_round39/author_baseline` должны находиться эти скрипты, рядом с `repo_crossfit` и `set_reader`. Полный расчёт требует локальных входов Cal500 и R34, указанных в panel.py, а также llama.cpp и Python-окружения D. Никакая внешняя отправка данных не нужна.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B panel.py
& $runner -B fetch.py
& $runner -B matched.py
& .\gpu.ps1
& $runner -B reference_grade.py gpu
& $runner -B verify_qwen.py
```

На общей рабочей станции GPU-процесс запускается после финала канонической очереди и удерживает её именованный мьютекс. При занятом ресурсе gpu.ps1 завершается со статусом 2. Для независимого CPU-повтора вместо gpu.ps1 можно выполнить `python -B reference.py`, а затем `python -B reference_grade.py cpu` в отдельной копии каталога. Формирование индексов, проверка разметки и scoring не требуют GPU. В существующем запечатанном снимке launcher проверяет уже выданную контрольную сумму. Для запуска с чистого листа используют отдельную рабочую копию и отдельный каталог для промежуточных результатов, сохраняя предыдущие записи для сравнения.

Скрипт seal_gpu.py фиксирует именно первый эксперимент при исходном уровне подробности сервера, включая один фактически снятый образец телеметрии. Его показания не переносят на другие запуски. Для нового прогона launcher включает более подробное логирование. Скрипт verify_qwen.py использует только стандартную библиотеку. Он сверяет исходные прогнозы, полноту пулов, ранжирование по сохранённым баллам для варианта без маски и агрегаты в отчёте.
