# Порядок вычислений для Qwen3-Embedding-8B

До просмотра оценок новых Qwen-предсказаний зафиксированы отдельные CPU- и GPU-условия. Все 10 состояний остаются в исходном порядке из panel.json. Для сравнительного отчёта используется первая полностью завершённая аппаратная конфигурация с десятью состояниями, выбранная по вычислительной готовности. Обе используют одни веса Q4_K_M, одно формирование запросов, один токенизатор, ограничение в 512 входных токенов, размерность 4096, конечный токен и полный пул каждого состояния. Обе маски выводятся из одних скалярных баллов. Предсказания разных аппаратных конфигураций объединять запрещает протокол оценки. Порядок выполнения не зависит от качества.

CPU использует шесть потоков. GPU возможен только после последней канонической контрольной точки, в свободном временном окне и под общим именованным мьютексом Local\CodexResearchGraphMemoryFiveSeed. Уже идущий процесс другого эксперимента продолжает работать. Для GPU сохраняется отдельный идентификатор, отдельный файл прогнозов и собственный тайминг.
