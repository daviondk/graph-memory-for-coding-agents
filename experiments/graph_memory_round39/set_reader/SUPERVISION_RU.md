# Вторичный контроль обучения до сравнения дополнительных методов

В основном прогоне известны 88/214 у условного читателя, 90 у его одноместного контроля и 91 у условной модели с пустым префиксом. Объект следующего вопроса — происхождение эффекта статического ранжирования. До обучения новых контролей фиксируем полное пересечение двух факторов. Первый — одна начальная выборка на состояние либо все исходные учебные префиксы, с удалением уже выбранных кандидатов. Второй — цель «кандидат входит хоть в один достижимый минимальный сертификат» либо цель «кандидат уменьшает расстояние до кратчайшего достижимого сертификата». Во всех четырёх ячейках применяем одинаковую схему балансировки, features и одноместный бустинг, без поправки при инференсе. Индивидуальный статический вес относительно union_cost выбирается по тому же dev-порядку, без перенастройки размера ансамбля. Ячейка все префиксы + остаточная цель обязана воспроизвести старый matched_unary ранги и исходы. Дополнительно целиком переобучаем модель все префиксы + остаточная цель с удалённым индикатором observed_by_state. Это объяснительная абляция на повторной панели, отдельной независимой проверкой гипотезы она не является. Фиксируем выводы без отбора нового основного варианта на test.
