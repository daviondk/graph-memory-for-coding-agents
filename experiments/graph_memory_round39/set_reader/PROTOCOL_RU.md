# Выбор следующего фрагмента по расстоянию до достаточного множества

До получения новых результатов фиксируем повторно используемое разбиение SERBench Cal500 из R34 — 179/101/214 состояний с непересекающимися репозиториями. Известны ранее опубликованные в этом проекте исходы BGE, union_cost и MMR. Новых test-оценок данного читателя пока нет. Используем только ранее отобранные benign задачи. Опубликованный официальный Test500 использует другую панель, материалы туда не передаются.

На train строим семейство всех минимальных достаточных наборов из авторских альтернатив и декартова произведения допустимых выборов квот обязательных групп. Удаляем недостижимые и надмножества. Для выбранного префикса S расстояние D(S)=min_A |A минус S|. Правильный следующий фрагмент уменьшает это расстояние ровно на единицу. Если S уже достаточен либо подходящих маршрутов в пуле нет, этот учебный шаг пропускается. В отличие от фиксированного обучаемого ранга R34 скоринг при чтении обновляется после каждого добавления фрагмента. Группы, роли, альтернативы и само D(S) при инференсе недоступны.

Учебные префиксы длины 0,1,2,4,6 — верхние фрагменты BGE, фиксированного union_cost и смесь уже выбранных членов одного train-сертификата с трудными отрицательными. Удаляем дубли префиксов. Порядок последней смеси детерминирован. При тренировке одна группа состояний — одно состояние, его вес равномерно делится между оставшимися префиксами, затем между положительными и отрицательными кандидатами. В качестве основного нелинейного оценщика используем HistGradientBoostingClassifier, 65 итераций, 7 листьев, min_samples_leaf=55, learning_rate=.09, L2=4, seed 39013. Признаки кандидата включают стоимость, отдельно BGE/лексический/адресный ранг, балл R34, собственную наблюдаемость, путь, историю пути и лексические совпадения с видимыми полями состояния. Для пар добавляются близость представлений BGE, общий путь или каталог, близость номеров строк, общие идентификаторы и совместные появления путей в прежних действиях. Максимум/среднее относительно уже выбранных фрагментов кодирует условие шага. Метаданные кандидатов служат доступной поисковой выдачей. Построение межшагового графа происходит внутри текущего пула, без исходной индексации всего репозитория.

Статический контроль train обучается на тех же действиях и с теми же весами, но без отношений к выбранному множеству. Шкалу fusion задаёт логарифм ранга, одинаковый для сравниваемых систем. Смешивание статического читателя и фиксированного R34 выбираем на dev среди 0, .25, .5, .75, 1. Для условного обновления добавляем изменение полезности относительно замороженного пустого набора; сравниваем с условной моделью, рассчитанной на пустом наборе. Для величины динамической поправки используем ту же сетку. Приоритет dev — Complete-MSS@5, при равенстве @8, далее 2048 Qwen и более слабое изменение. Базовые контроли — ранее измеренные BGE, MMR, cross-encoder, R34 union_cost, union_cost с отложением уже виденного кандидата, обученный одноместный читатель и перестановка отношений внутри корзин BGE-ранга с замороженной политикой. Отдельно выдаём заранее фиксированную максимальную условную поправку, если оптимум dev равен нулю.

Перед чтением test-разметки сохраняем прогнозы и хеш конфигурации/разделения. Основная метрика — официальный Complete-MSS@5. Контрасты нового читателя по очереди с R34 union_cost, сильным одноместным контролем, переставленными отношениями. Вторичные — официальный @8, первые восемь целых фрагментов под 2048/6144 Qwen-токенов в сериализации R34, среднее покрытие групп. Для всех пар приводим число выигрышей/потерь и двусторонние интервалы на 10 000 парных перевыборках 69 целых репозиториев при равном весе состояний. Контроли и метрики известны заранее, интервалы по отдельности, без корректировки на множество вторичных сравнений. Повторное использование Cal500 означает исследовательский характер, и улучшение над BGE само по себе не доказывает пользу условного обновления.
