# Как читать, редактировать и запустить

В автономный пакет входят PDF, LaTeX, BibTeX, снимок действующего интерфейса, код запуска и две базы SQLite с необходимыми метаданными. Для просмотра достаточно открыть paper.pdf. При изменении текста запустите Tectonic из каталога с paper.tex.

~~~console
tectonic paper.tex
~~~

Используется класс IEEEtran с параметром conference из TeX Live. Первый запуск загрузит отсутствующие шрифты и компоненты TeX. После этого `tectonic --only-cached paper.tex` собирает документ офлайн. QA проведена на Tectonic 0.17.0 с использованием IEEEtran, TeX Gyre Termes, Poppler и PyMuPDF. Текстовый исходник полностью редактируем. Для сохранения четырёхстраничного лимита после добавления авторского блока нужно повторить рендеринг.

Для запуска интерактивного сценария нужен Python со стандартной библиотекой и sqlite3. Запустите команду и откройте выведенный локальный адрес браузером.

~~~console
python -B launcher.py --port 8770
~~~

Выберите q02 и In the packet. Интерфейс показывает замену №11 на №19. В режиме Outside dependencies читатель может вернуть материализованный результат. At the prefix boundary загружает зарегистрированный случай q07. Переключатель Maintenance показывает достаточный сертификат или безусловный полный пересчёт. Кнопка Recompute and score действительно заново вычисляет пакет и затем отдельно оценивает интервалы. Результаты по усиленному необходимому и достаточному условию и Q32 приведены в статье и в журнале. Эти алгоритмы проверены в отдельных экспериментах. Интерактивный переключатель сравнивает достаточный быстрый сертификат с полным пересчётом. Журналы измерений для коэффициента 5,16 получены нативным решателем с теми же правилами. Демо для посетителей использует переносимый Python-решатель.

В исходной структуре репозитория launcher.py подключает базы из соседнего provenance_packet_demo; в автономном ZIP те же байты лежат в runtime/. Код работает в режиме чтения через 127.0.0.1. Для необязательного браузерного smoke-теста понадобится установленный Chromium и пакет Playwright. Укажите BROWSER_EXE, если исполняемый файл Chromium находится за пределами стандартных путей Windows.

~~~console
python -B check_ui.py
~~~

Основные источники библиографии проверены по arXiv, Crossref, авторской институциональной записи и программе ICDE. Данные изменены по отношению к upstream. Сохранены адреса, интервалы и категории, добавлены оценки модели, а исходные текстовые поля не входят в поставку. Сведения об исходных наборах и их лицензиях находятся в runtime/DATA_SOURCE.md автономного ZIP.
