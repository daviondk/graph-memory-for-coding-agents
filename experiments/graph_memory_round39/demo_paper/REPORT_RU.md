# Рабочий четырёхстраничный черновик для ICDE Demonstrations

Английская рукопись описывает материализованную выборку свидетельств агента с ограничением по токенам. Посетитель исключает источник, видит решение о повторном использовании либо пересчёте, проверяет связь каждого выбранного фрагмента с исходным событием и отдельно запускает оценку полноты. Это один вариант темы, подготовленный для обсуждения. Авторы и аффилиации в черновике оставлены пустыми. [Рукопись, четыре страницы](paper.pdf) · [Редактируемый LaTeX](paper.tex) · [Библиография](sources.bib)

Исходные вычисления проведены на записанных синтетических OS-agent траекториях ISETrace с реальным исполнением инструментов. Исключения источников моделируют поведение системы при их недоступности. На 2 000 тестовых запросов, 1 207 траекторий и пяти общих инициализациях пакет с защищённым префиксом дал 82,60% Full Support при 2 048 токенах. Та же модель ранжирования с first-fit дала 82,19%, парный интервал для разности [−0,23; +1,08] п.п. Объём выдачи около 2 039 токенов в обоих случаях. Штатная модель без смежности после применения той же обученной полезности к хвосту дала 83,07%, наивысшую точечную оценку среди приведённых политик. В статье отдельно указаны преимущество по площади под бюджетной кривой и неопределённость по одной точке. [Значения и контрольные суммы исходных результатов](evidence.json)

Для демонстрационной панели из 40 разных траекторий достаточный сертификат повторно использовал пакет на 2 041 из 2 528 одиночных исключений. На всех операциях список совпал с полным пересчётом. Отношение суммарного времени нативных реализаций 5,16, 95%-й интервал [4,36; 6,17]. Необходимое и достаточное условие верно классифицировало 108 204 одиночных и составных сценария. Отдельно проверена точная реализация с фиксированной запятой Q32. В PDF приведены предпосылки доказательства и границы применимости замеров. [Исходный код демонстрационного интерфейса](launcher.py) · [Снимок действующего интерфейса](visitor.png)

PDF свёрстан официальным классом IEEEtran в режиме conference на бумаге US Letter. Две колонки, ссылки, иллюстрации и все четыре страницы проверены после рендеринга. Представленные эксперименты измеряют извлечение свидетельств, корректность обслуживания и время локального оператора. При выборе темы за авторами остаются утверждение текста, авторство и аффилиации, согласование материалов и решение о подаче. Черновик и интерфейс подготовлены локально.
