# Выбор пакета по графу происхождения без загрузки тел

Фиксируем до извлечения панели и измерений. Из 2 000 тестовых запросов ISETrace упорядочить идентификаторы по SHA-256 строки UTF-8 «r39-source-demo-v1|query_id». Сохранить первые 40 с разными ID траекторий. Прогнозы и общие результаты global_packet уже известны, успешность конкретных вопросов и наличие расхождений при отборе не используются. Одна общая инициализация 13, порядок и полезности обученной графовой модели фиксированы. Основной бюджет 2 048 токенов, защищённый префикс 1 024. Проверить совпадение точной последовательности ID и фактической цены с замороженным graph-dp для всех 40 запросов. Независимо вычислить объединение пересечений выбранных диапазонов с эталонными диапазонами по ключу (событие, JSON pointer), сопоставить Full Support и Coverage с авторским оцениванием сохранённых прогнозов. Тип источника, идентификатор и границы привязать к публичной траектории. Исходные тексты задач, тел и команд в БД не помещать.

Демонстрация показывает отношение кандидат → один или несколько диапазонов → источник. Для исключённого источника удаляются все связанные с ним кандидаты до выбора и пересчитываются префикс и рюкзак на оставшемся порядке с замороженной полезностью. Показать дельту выбранных ID, фактические токены, происхождение. Квоты/свидетельства и метрики результата доступны отдельным вызовом после выбора. Варианты бюджета 1 024, 2 048 и 3 072. Для других бюджетов сохраняем половину под префикс. Это исследовательская чувствительность. Целевой размер базы и скорость не используются для выбора панели. Замерим по 5 повторений четырёх сценариев на каждый запрос после одного прогрева. Основной сценарий и фактическая себестоимость, уменьшение/увеличение бюджета и исключение наиболее частого источника (число кандидатов, затем хеш) будут показаны отдельно. Медиана и p95 задержки одного запроса внутри процесса, отдельно от HTTP, единицы микросекунды. Проверить как минимум один живой HTTP-цикл с изменением бюджета, исключением/возвратом источника и явным оцениванием. Малая панель служит для проверки демонстрации и тождества реализации.
