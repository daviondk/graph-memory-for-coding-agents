# Когда помогает информация о предыдущем чтении

Сопоставление опубликованных входов обнаружило различие представлений наблюдаемости. В отобранных 494 состояниях Cal500 флаг observed_by_state установлен у 2 922 кандидатов в 317 состояниях (64,17%). Верхнеуровневый observed_evidence_ids пуст во всех 494 строках входа и эталона. На 500 публичных входах закрытого Test500 обнаружены 953 флага в 186 состояниях (37,20%), и во всех 500 случаях флаг точно совпал с пересечением верхнеуровневого списка и пула. Последние цифры совпали с описанием авторов. Изменение источника наблюдаемости на Cal меняет эксперимент. [SERBench, приложение D.4](https://arxiv.org/html/2609.20050v3#A4.SS4)

Проверили, что в этих 494 калибровочных состояниях ни один фрагмент, отмеченный просмотренным, не входит ни в одну эталонную группу или альтернативное полное множество. Для любого фиксированного порядка действует следующий вывод. Если отправить просмотренные фрагменты в конец, сохранив относительный порядок непросмотренных, все полезные элементы любого исходного top-k остаются в новом top-k. То же верно для непрерывного префикса до бюджета при неотрицательной стоимости чтения — к любому прежнему непросмотренному фрагменту удаётся дойти с меньшими либо равными затратами. Покрытие групп монотонно по включению доказательств. Следовательно, стабильная отсрочка известных пустых по разметке фрагментов не может снизить Complete-MSS. Гарантия относится к этому бенчмарку и фиксированному списку. Переобучение ранжировщика меняет порядок прочих элементов, а в реальном агенте повторное чтение может быть полезно.

Разрез на 177 состояний без наблюдавшихся кандидатов (99 репозиториев) и 317 состояний с наблюдавшимися кандидатами (153 репозитория) использует уже запечатанные прогнозы 5-fold crossfit. Каждый столбец — успехи по всем состояниям конкретной страты.

| Метод | Без наблюдавшихся, @5 / @8 / 2048 | С наблюдавшимися, @5 / @8 / 2048 |
|---|---|---|
| BGE | 69 / 93 / 59 | 81 / 120 / 67 |
| BGE с отсрочкой | 69 / 93 / 59 | 109 / 147 / 95 |
| union_cost с отсрочкой | 70 / 91 / 67 | 107 / 144 / 102 |
| R39 без признака наблюдаемости | 74 / 101 / 70 | 85 / 119 / 83 |
| R39 с наблюдаемостью | 73 / 103 / 69 | 119 / 151 / 106 |

С добавлением признака наблюдаемости прирост R39 по MSS@5 в страте с наблюдавшимися кандидатами составил **+10,73 п.п. [6,96; 14,76]**, а в страте без них **−0,56 [−4,81; 3,74]**. Разности с маскированным union_cost при пяти слотах меньше — +3,79 [0,00; 7,59] и +1,69 [−3,87; 7,51] соответственно. В отсутствие доступных маскируемых кандидатов у R39 остаётся преимущество при восьми слотах относительно union_cost, **+6,78 п.п. [1,09; 12,72]**. Интервал для сравнения с BGE при восьми слотах в той же страте +5,65 [−0,56; 11,67]. На первичной метрике MSS@5 выделить новый независимый эффект в этой страте не удалось. В материале 10 000 парных bootstrap-выборок по репозиториям внутри каждой страты, без поправок на вторичные проверки. Различия частоты флагов и стадии работы агента ограничивают перенос общей калибровочной оценки на Test500.

Воспроизведение из текущего каталога командой `python -B strata.py` с окружением R39. Машиночитаемые результаты, исходы на четырёх метриках и все контрасты сохранены в strata-results.json.
