# Слепая выдача SERBench на общих полях Cal500 и Test500

Подготовлен один локальный файл для закрытого оценщика — test500-lexical-residual.jsonl. В файле 500 строк, у 491 состояния по восемь фрагментов, у девяти пустой список по предварительному отбору задач. Строгий валидатор авторов подтвердил все состояния и идентификаторы по 40 503 фрагментам из публичных пулов. Размер 212 347 байт, SHA-256 82b2ca580ac6c8ba507dc4c50ac8856d2a080238eeaf99dd9013012c6668ae5b. Предсказания остались на диске D. Значения метрик на закрытых эталонах пока неизвестны.

R39-Lexical-Residual обучает одноместный градиентный бустинг на кратчайших достижимых достаточных наборах и использует сведения о просмотренности, BM25, токенной стоимости, пути и совпадениях текста с полями текущего состояния. Плотные представления этому варианту не требуются. При подготовке выявлено расхождение схем. Поле trajectory_prefix есть в каждой из 500 Cal-записей и отсутствует во всех 500 Test-записях. В обоих разделах доступны opened_files и search_queries. До оценки варианта удалили зависимость от полного префикса в обучении и слепом инференсе. Пара полей latest_test_output и current_diff всюду пуста в Cal и отсутствует в Test. Предыдущая R39 сохраняла преимущества дополнительных калибровочных признаков, поэтому её точную политику нельзя автоматически перенести на эту форму теста. Чтобы количественно разделить потери от удаления BGE и истории, потребуется отдельный контроль.

На той же пятикратной межрепозиторной Cal-проверке из 494 состояний получены следующие числа полных успехов. В каждой внешней итерации обучение использовало исходные три группы репозиториев, размеры признаков и гиперпараметры фиксировались до оценивания.

| Читатель | MSS@5 | MSS@8 | 2 048 Qwen | 6 144 Qwen |
|---|---:|---:|---:|---:|
| Авторский стартер BM25 | 34 | 51 | 23 | 51 |
| BM25, просмотренное в конце | 48 | 62 | 32 | 61 |
| Лексический R39 без метки просмотра | 123 | 171 | 112 | 171 |
| Лексический R39 с меткой просмотра | 137 | 193 | 126 | 193 |
| Полный R39 с BGE и доступным Cal-префиксом | 192 | 254 | 175 | 254 |

На MSS@5 лексическая модель с меткой просмотра выигрывает у согласованного варианта без неё на 2,83 п.п. [0,39; 5,38] и у BM25 с отсрочкой на 18,02 п.п. [13,47; 22,62]. До полного R39 остаётся 11,13 п.п. [6,02; 16,27]. Интервалы получены по 10 000 парным перевыборкам 171 репозитория при фиксированных прогнозах. В R39-Lexical-Residual любое содержательное утверждение об эффективности опирается на эти открытые данные. Структурный факт бенчмарка — уже просмотренный фрагмент исключён из необходимых свидетельств. Закрытый файл служит техническим результатом по переносу схемы и подготовке проверяемой выдачи. [Метрики SERBench](https://arxiv.org/html/2609.20050v3#A4.SS4)

Воспроизведение в PowerShell из этого каталога:

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B blind.py
& $runner -B grade.py blind
```

Сводка blind-seal.json содержит хеш полного файла, модель, объём обучающих данных и фактический ответ SDK. Для повторной проверки одного файла без обучения можно использовать команду `python -m serbench validate --split test500 --predictions test500-lexical-residual.jsonl` в окружении официального SDK с указанным путём данных.
