# Повторение разреза по ранее просмотренным кандидатам

После изучения SERBench v3, D.4 и основных агрегатов R39, но до подсчёта результатов по стратам, фиксируем дополнительный описательный анализ. На 494 Cal500 состояниях и готовых предсказаниях repo_crossfit разделяем состояния по наличию хотя бы одного наблюдавшегося ID в пуле. Страта определяется исключительно публичным состоянием. Строго проверяем совпадение флага каждого кандидата и пересечения со списком observed_evidence_ids. Отдельно проверяем отсутствие пересечения эталонных допустимых единиц, включая альтернативные наборы, с наблюдавшимися ID. Основные контрасты — proposed против BGE с маской и против union_cost с маской в подмножестве без доступных маскируемых единиц. Дополнительно сообщаем обе страты и сравнение с вариантом без признака наблюдения. Сравниваем MSS@5, MSS@8 и MSS@8 под бюджетами 2048/6144, фиксированные парные предсказания, bootstrap 10 000 перевыборок целых репозиториев внутри соответствующей страты. Страты могут включать одни и те же репозитории и различаться стадией работы агента. Разности между стратами не интерпретируются как причинный эффект наблюдаемости. Множество вторичных интервалов служит диагностике.
Предметная поправка после проверки входов, до вычисления метрик страт: согласованность двух представлений наблюдаемости на Cal нарушена. В 317 из 494 состояний есть хотя бы один флаг, но во всех 494 состояниях и эталонах верхнеуровневый список observed_evidence_ids пуст. Для стратификации используем прямо объявленный в статье наблюдаемый флаг каждого кандидата. Сохраняем число расхождений с верхнеуровневым списком и проверяем аналогичные агрегаты на публичных входах Test500 без чтения скрытой разметки.
