# Проверка зависимости качества от произвольного порядка при равных баллах

На исходной Cal500 некоторые поля состояния пусты. Лексические признаки R39 отдают каждому кандидату индивидуальный порядковый ранг даже при равных баллах совпадения. Для отсутствующего поля вся последовательность рангов повторяет сортировку непрозрачных идентификаторов, хотя соответствующего свидетельства в поле нет. До просмотра качества нового варианта фиксируем гипотезу: модель опирается на разрешение ничьих, и измеряемая переносимость изменится после удаления искусственного сигнала.

Используем прежний nested crossfit из 494 состояний и 171 репозитория, те же внутренние train/dev и путевые исходные признаки. Первичный контраст по MSS@5 — исходный статический R39 с кратчайшей целью против его полной переобученной копии с midrank во всех девяти полях лексических совпадений. Средний ранг вычисляется для групп совпадающих значений доступного нормализованного скалярного признака. Пустое поле даёт константу для всех кандидатов в состоянии. Поскольку значение хранится в float32, на ненулевых значениях возможно дополнительное объединение близких баллов; фактическая частота фиксируется. Дополнительный контроль случайно разрешает ничьи порядком SHA-256 от state_id и evidence_id с единым фиксированным префиксом; этот порядок общий для полей состояния. Во всех трёх случаях гиперпараметры и прочие признаки одинаковы, коэффициент смешивания с зафиксированным fold-specific union_cost настраивается заново по dev. Ни одна ранняя глобальная модель по Cal не используется.

Три безобучаемых контроля — исходный порядок ID по возрастанию, обратный порядок, и фиксированная перестановка по хешу пары state_id/evidence_id. Глобально выбранная модель не заменяется по итогам теста. Для основных моделей выводим абсолютные успехи при пяти, восьми фрагментах и бюджетах 2048/6144, парные исходы и 95%-е интервалы по 10 000 перевыборкам групп репозиториев. Прогнозы фиксируются до открытия новых исходов. Результаты на повторно используемой Cal500 диагностические.
