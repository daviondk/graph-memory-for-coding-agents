# Устойчивость к порядку идентификаторов кандидатов

При преобразовании совпадения текста в ранг исходный R39 разрешает ничьи порядком ID. В 1 288 из 4 446 пар «состояние × поле» все совпадения имеют одинаковое значение. Порядковый ранг в таких местах способен передать произвольную позицию кандидата. Мы полностью переобучили согласованные модели после замены таких рангов средними, а также после замены порядка равных элементов фиксированной хеш-перестановкой. Исходный обучающий код воспроизвёл все 494 списков top-8 прежнего R39, включая порядок элементов. Одни обучающие, валидационные и отложенные группы репозиториев, прежний набор кандидатов, индивидуальная настройка смешивания только на dev.

| Политика | MSS@5 | MSS@8 | 2 048 | 6 144 |
|---|---:|---:|---:|---:|
| Только ID по возрастанию | 17 | 28 | 12 | 28 |
| Только ID по убыванию | 13 | 23 | 11 | 23 |
| Одна предопределённая случайная перестановка | 22 | 28 | 17 | 28 |
| Обучаемый R39, исходные ранги | 192 | 254 | 175 | 254 |
| R39, ничьи разрешены хешем | 192 | 249 | 175 | 249 |
| R39, совпадающим баллам назначен средний ранг | 198 | 255 | 175 | 255 |

Каждая ячейка — число успешных состояний из 494. При пяти фрагментах замена исходного разрешения ничьих средним рангом дала **+1,21 п.п. [−1,00; 3,78]**. При восьми фрагментах +0,20 [−1,49; 2,00], а при 2 048 токенах 0,00 [−2,04; 2,19]. Разницу непосредственно из-за рангов доказать не удалось. При сравнении с разрешением ничьих хешем разность при пяти слотах +1,21 [−0,81; 3,28]. Произвольный порядок ID в отдельности восстанавливает полный набор лишь в 13–22 состояниях из 494. Из 385 281 пар «кандидат × поле» зафиксированы 140 088 в группах нулевых ничьих и 116 288 в группах ненулевых. Из-за хранения нормализованных признаков в float32 по сравнению с исходными порядковыми рангами изменилась последовательность всего для четырёх строк.

Во вторичном сравнении уже после просмотра прямой абляции версия со средними рангами достигла **198/494 (40,08%)** на MSS@5 против 177/494 у union_cost с отсрочкой просмотренного и 178/494 у такого же BGE. Разности +4,25 п.п. [1,17; 7,55] и +4,05 [1,01; 7,21]. На MSS@8 разность с union_cost +4,05 [1,01; 7,11], с BGE +3,04 [−0,21; 6,14]. При жёстком бюджете 2 048 разность с union_cost +1,21 [−1,35; 3,84], с BGE +4,25 [1,35; 7,27]. Применены парные процентильные интервалы по 10 000 перевыборок 171 репозитория. Все сравнительные прогнозы рассчитаны без обучения на тестовом репозитории своей итерации. Гипотезы исследовались последовательно на уже знакомом открытом Cal500, и вторичные интервалы приводятся без поправки на множественные сравнения. Эти числа определяют кандидата для проверки переноса и пригодность контролей. Они не доказывают преимущество над авторским MSS-Complement или существенность именно обработки ничьих.
