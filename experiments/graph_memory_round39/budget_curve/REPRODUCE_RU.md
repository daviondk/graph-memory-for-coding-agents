# Воспроизведение

Рабочий каталог расположен рядом с global_packet и remaining_budget. Прогноз использует числовую проекцию R33, соответствующие инициализации R21 и R35, подписанные прогнозы исходных R-GCN из R22/official580, выбранную на dev долю и обученную модель global_packet. Полный повтор требует тех же локальных кэшей проекта. Оценка использует опубликованную реализацию ISETrace и официальный интерпретатор проекта. Выводы по каждому вопросу и проверку контрольных сумм можно читать стандартным Python.

В PowerShell соберите общий решатель из зарегистрированного соседнего исходника GNU C++. Для переносимой сборки Windows можно указать расположение DLL во временном каталоге.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
$env:R39_KNAPSACK_DLL = Join-Path $env:TEMP 'r39-budget-curve-choose.dll'
g++ -O3 -std=c++17 -shared -static-libgcc -static-libstdc++ ../remaining_budget/choose.cpp -o $env:R39_KNAPSACK_DLL
& $runner -B predict.py 13 17 29 37 41
& $runner -B grade.py 13 17 29 37 41
& $runner -B summary.py
& $runner -B audit.py
& $runner -B check_intervals.py
& $runner -B check_optimum.py
```

В поставленном прогоне использовалась уже собранная в проекте DLL. Путь по умолчанию расположен в tmp/r39-residual-choice.dll рабочего дерева. Исходник и фактическая библиотека подписаны в каждой квитанции прогноза. SHA-256 нового двоичного файла зависит от сборщика. Для независимого повтора используйте копию каталога на том же уровне и пустой комплект выходов. В существующем каталоге predict и grade проверяют ранее зафиксированные результаты и возобновляют с ближайшей завершённой стадии. Перезапуск дописывает строки в run-log.jsonl.

В test-SEED-packets.json.gz для каждого ID записаны траектория и вложенные массивы в порядке «порядок кандидатов, бюджет, правило упаковки». Перечни находятся в test-SEED-seal.json. В test-SEED-outcomes.json.gz по каждому вопросу и методу лежат пара площадей [Full Support, Coverage] и шесть строк [Full Support, Coverage, использованные токены, число узлов]. В results.json приведены усреднения по вопросам и пяти инициализациям, средние по каждой инициализации, контрасты, парные интервалы с фиксированными и с перевыбранными инициализациями. Журнал run-log.jsonl хранит начало, контрольные суммы, возобновления и фактическую продолжительность этапов. Для проверки поставки до повторного запуска выполните `python -B verify.py`.
