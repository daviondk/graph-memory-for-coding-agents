# Воспроизведение межрепозиторного эксперимента

До обучения фиксируются критерии выбора, основные и вторичные контрасты в PROTOCOL_RU.md. Следующие команды PowerShell выполняются из каталога repo_crossfit в копии дерева work, содержащей прежние кеши.

```powershell
$runner = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $runner -B fit_crossfit.py
& $runner -B evaluate.py
& $runner -B verify.py
```

Первый этап использует сетевые данные только из уже локально сохранённой копии SERBench, R34-таблицу features.json.gz и массив предвычисленных BGE-векторов. На этапе обучения оптимизируется ранжирование на CPU с помощью scikit-learn и сохранённого кода R34 для решения задачи union_cost. Сырые признаки не содержат баллов прежней обученной SERBench-модели. Вычисленные в данной итерации балл и ранг заносятся только после обучения этого базового метода. Все пять моделей ранжируют исключительно ранее определённую локальную панель из 494 состояний. Видимость признаков и формирование индексов можно проверить по public.py.

После завершения fit в predictions.json.gz хранятся восемь идентификаторов на каждый метод и состояние. selection.json содержит все разбиения, выбор параметров и агрегаты dev, models.json.gz — деревья, а seal.json — SHA-256 кода, входов и прогнозов. evaluate.py вызывает авторский score_prediction и сравнивает ответ с локальным критерием достаточности, затем сохраняет отдельные исходы в outcomes.json.gz и полный парный анализ в results.json. Стандартная библиотека Python позволяет автономно проверить архив и фильтрацию по репозиториям командой verify.py. Для полного переобучения требуется указанный локальный runtime и относительное расположение зависимостей из seal.json.
