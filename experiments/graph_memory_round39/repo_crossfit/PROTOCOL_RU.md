# Межрепозиторная проверка доступности и достаточности свидетельств

Основная гипотеза — одноместная модель с признаком просмотренности и разметкой кратчайшего достаточного набора лучше восстановит полный набор к пятому чтению по сравнению с моделью union_cost, откладывающей просмотренные записи. Кандидат выбирается до новых результатов по прежним исследовательским абляциям на той же Cal500. Повторное исследование разметки исключает интерпретацию как независимое подтверждение или сравнение с официальным Test500.

Единица внешнего разделения — репозиторий. Используем все 494 ранее отобранных состояния, по одному внешнему прогнозу на состояние. Сортируем уникальные репозитории по SHA-256 строки «r39-public-repos-01/» + repo и распределяем циклически в пять групп. Для внешней группы f настраиваем гиперпараметры на группе (f+1) modulo 5, обучаем на остальных трёх. Все модели каждый раз строятся заново. Разметка интересующей внешней группы недоступна в соответствующем вызове fit. Предсказания всех пяти групп подписываются до вычисления метрик. Одно и то же состояние в других итерациях может выступать обучающим или валидационным. Пулы кандидатов и токенные стоимости одинаковы для всех сравниваемых систем.

Одноместный бустинг использует признаки R39, выбранный внутри итерации (по dev) балл union_cost и его внутрисостоянийный ранг. Два признака ранее обученного R34 не используются. Для отбора заранее фиксированы MSS@5, затем MSS@8, затем MSS@8/2048, затем меньший коэффициент. Контроли — BGE и BGE с отсрочкой просмотренных, R34 union_cost без и с отсрочкой просмотренных (собственный отбор L2 из {.03,.3} по dev в каждом варианте), бустинг без признака просмотренности, бустинг с классификацией принадлежности любому минимальному сертификату, основной бустинг с классификацией принадлежности кратчайшему такому сертификату. Для трёх вариантов бустинга применяется одна модель с 65 деревьями до семи листьев, один пустой префикс на состояние, половина веса на положительные, половина на отрицательные внутри каждого состояния. Каждый вариант независимо выбирает коэффициент смешивания с обычным union_cost в {0,.25,.5,.75,1} по тому же dev-порядку.

Основная оценка — micro Complete-MSS@5, исходы всех 494 состояний. Первичный контраст — с union_cost + отсрочка просмотра. Дополнительно report MSS@8, полноту при 2 048/6 144 Qwen-токенах, макросреднее с равным весом репозитория, разность и направление в каждом внешнем блоке. Каждый 95%-й интервал получен 10 000 парными bootstrap-выборками репозиториев с фиксированными готовыми прогнозами. Интервалы условны относительно зафиксированных пяти обучений и опубликованного калибровочного набора. Вторичные сравнения без поправок на множественность. Никаких новых методов или изменений матрицы эксперимента по итогам просмотра метрик.
