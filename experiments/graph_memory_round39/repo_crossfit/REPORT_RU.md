# Как данные о предыдущем чтении переносятся между репозиториями

**На 494 состояниях из 171 репозитория отметка просмотренности дала +6,68 п.п. к восстановлению полного набора в первых пяти фрагментах при полном переобучении согласованного контроля.** Два варианта учебной цели дали по 192 успеха. Сильный простой контроль, который отправляет просмотренные фрагменты в конец выдачи union_cost, достиг 177. Основная разность с ним равна +3,04 п.п., 95%-й интервал [−0,20; 6,42] включает ноль.

## Что измеряли

Из состояния кодового агента и одного и того же доступного пула нужно вернуть фрагменты, достаточные для следующего решения. Авторский Complete-MSS даёт единицу, когда набор удовлетворяет всем группам требований с их квотами либо содержит полный допустимый альтернативный набор. Поле observed_by_state доступно всем системам из исходной записи. Главный кандидат — градиентный бустинг над индивидуальными признаками фрагмента и состояния, без генерации ответа LLM. Положительными считаются кандидаты, входящие хотя бы в один кратчайший достижимый достаточный набор.

Сохранены все 494 состояния из ранее отобранной подвыборки авторской Cal500. Репозитории разделены на пять внешних групп. Каждое состояние получило один прогноз из модели, полностью обученной и настроенной на других репозиториях. Регуляризация union_cost и вес смешивания каждого бустинга заново выбирались во внутренней dev-группе из оставшихся четырёх. Три группы использовались для обучения. Параметры, баллы и ранги старой R34-модели в новых признаках заменены результатами обучения внутри группы. Старые метрики Cal500 использовались для выбора самой гипотезы до пяти прогонов. Расхождения между группами и доверительные интервалы характеризуют переносимость внутри открытой Cal500. Проверка не превращает её в свежий внешний набор.

## Общие результаты

В таблице приведены числа успехов из 494. При токенном бюджете берётся непрерывный префикс восьми целых фрагментов по стоимости сериализации пути и текста токенизатором Qwen. Macro усредняет доли успехов 171 репозитория с равными весами. В отдельном results.json доступны оба усреднения для всех четырёх метрик.

Основная метрика — MSS@5 по состояниям. Относительно union_cost с отсрочкой просмотра основной метод дал **38,87% против 35,83%, +3,04 п.п. [−0,20; 6,42]**. В 35 состояниях выиграл и в 20 проиграл. При равном весе репозитория получено +2,30 п.п. [−0,89; 5,59]. На MSS@8 выигрыш по состояниям составил +3,85 п.п. [0,83; 6,97], при равном весе репозитория +2,04 п.п. [−0,91; 5,07]. Под бюджетом 2 048 разность +1,21 п.п. [−1,58; 4,03]. Это парные процентильные интервалы по 10 000 повторных выборок целых репозиториев. Переобучение моделей в каждом bootstrap-повторе не проводилось.

Атрибуция эффекта различает две причины. Удаление прямого признака просмотренности при сохранении остальных полей, включая историю путей, и полном переобучении уменьшило micro MSS@5 на **6,68 п.п. [3,82; 9,58]**, MSS@8 на **6,88 [3,88; 10,06]**, MSS при 2 048 токенах на **4,45 [1,64; 7,33]**. При замене кратчайшей цели на принадлежность любому минимальному набору обе модели достигли 192 на MSS@5, разность 0,00 п.п. [−1,23; 1,23]. На MSS@8 основной метод дал на три успеха меньше. Поэтому межрепозиторный результат поддерживает использование сведений о прочитанном, а предпочтение кратчайшей учебной цели остаётся открытым вопросом.

## Внешние блоки

Числа успехов при прочих равных. Во всех пяти группах основной метод дал положительную разность на MSS@5 относительно union_cost с отсрочкой просмотра. Группы разделяют часть репозиториев для обучения друг друга, поэтому пять знаков разности сами по себе не образуют независимый статистический тест.

Авторы SERBench сообщают результат MSS-Complement на отдельно удержанном Test500. В этом эксперименте использовалась Cal500, предсказания наружу не передавались. Предварительно вычисленные BGE-векторы и авторский пул также отделяют этот опыт от самостоятельного поиска в полном репозитории. Самостоятельный научный вклад потребует проверить поддержание статуса просмотра при изменении источника, потере записи из контекста и последующей потребности перечитать её. Наблюдаемый здесь выигрыш принадлежит задаче поиска достаточного контекста. Последующий успех действий агента и стоимость ведения памяти ещё требуют отдельного измерения.
