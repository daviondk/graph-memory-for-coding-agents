# Функциональная проверка контекста на SymPy

Единица наблюдения — одна задача. До получения ответов выбираются строго элементы `transfer/cohort.json.ids[12:20]` шестой графовой серии в прежнем порядке SHA. Это восемь задач обычной разработки SymPy с доступной исторической версией, отобранных до эксперимента по публичному описанию без сведений из эталонной правки. В шестой серии все эти задачи входили в CPU-оценку локализации; предыдущая генерация для первых 12 их не затрагивала. Для текущего сравнительного пилота выборка фиксирована и мала.

Обе политики получают одинаковые текст issue и восемь допустимых файлов базовой ревизии. Предъявляются пакеты `localization/predictions` с общим максимумом 1800 токенов: `bm25` (плоская лексическая оценка фрагментов) и `doclink` (к ней добавлена связь между контрактом в docstring и исполняемыми фрагментами соответствующей функции). Выбор содержит один фактор — результирующий пакет контекста. Настройка локализатора зафиксирована в соседнем протоколе, результаты не используются для отбора задач. Не используются тестовые имена, эталонные пути, диффы, метки успешности.

Модель Qwen3.8-27B UD-Q4_K_M, один ответ на задачу и условие, temperature=0, seed по идентификатору задачи, отключён thinking, 850 максимум выходных токенов, 4096 контекста, единые системная инструкция и формат JSON правок из R6. Порядок уникальных запросов псевдослучайный по SHA. Равные по байтам запросы выполняются один раз. До обращения к серверу фиксируются полные запросы с SHA, ревизии файлов, модель и генератор; ответы фиксируются до проверки. Повтор транспорта допустим для технического разрыва без полученного ответа и логируется.

Основной исход — число задач, где допустимое изменение применилось и прошли все целевые FAIL_TO_PASS на проверяемой базе с воспроизводимым исходным сбоем и проходящим эталоном. Совпавшие исходы проверяются повторно только при изменении патча. Вторичные — доля синтаксически применимых патчей, число выполненных целевых тестов, ранее зелёные регрессии среди до 12 PASS_TO_PASS, доля строгих решений (основной исход и сохранение всех проверяемых ранее зелёных регрессий), число и токены вызовов. Для 8 пар — точный двусторонний тест по дискордантным исходам и все поштучные оценки. Неприменимый или пустой патч означает 0 по основному исходу. Невалидные тестовые базы или недоступность среды отображаются отдельно, без подмены задачи и без положительного зачёта.

Проверка — локальный тестовый контур шестой серии, те же ограничения разрешённых файлов и допустимых Python-изменений, отдельные копии проверенных checkout, исходная и эталонная контрольные версии, до 120 секунд на группу тестов. Из-за локальной среды и ограниченной регрессионной панели это пилот на подмножестве SWE-bench Verified. Вывод ограничен этой когортой и одной моделью. Если модель/тесты технически недоступны, фиксируется число отсутствующих исходов. Новая гипотеза или другой исход после результатов маркируются отдельно.
