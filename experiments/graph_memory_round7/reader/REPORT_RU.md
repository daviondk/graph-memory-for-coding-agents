# Как выбор фрагментов влияет на исправление ошибок в SymPy

Восемь задач из SWE-bench Verified получены из ранее заданного SHA-порядка, позиции 13–20 в панели SymPy transfer. В предыдущей серии для них измерялось покрытие исходного кода. Текущий пилот добавляет новые ответы модели и исполнение предложенных исправлений. Для каждой задачи фиксированы базовый коммит, текст issue, до восьми доступных файлов, максимальный объём контекста 1800 токенов и одна попытка. Локальная Qwen3.8-27B UD-Q4_K_M работала на RTX 3090 через llama.cpp. Сравнивались BM25 по фрагментам и ранжирование со связью между docstring и исполняемыми строками той же функции.

| Метрика | BM25 | С учётом docstring |
|---|---:|---:|
| Число парных задач | 8 | 8 |
| По крайней мере одна эталонная строка в переданном контексте | 3/8 | 2/8 |
| Синтаксически допустимое, применившееся изменение | 6/8 | 4/8 |
| Прошли все FAIL_TO_PASS | 2/8 | 0/8 |
| Прошли FAIL_TO_PASS и сохранены все ранее проходившие тесты из контрольной выборки | 2/8 | 0/8 |
| Токены собственно переданного кода, сумма | 14 200 | 14 213 |

Все восемь исходных версий воспроизвели целевую ошибку, все восемь эталонных исправлений прошли целевую проверку. Всего было восемь FAIL_TO_PASS и 95 ранее проходивших регрессионных проверок по восьми задачам. При неприменимом патче повторно использован результат исходного кода. Потерь среди исходно проходивших регрессионных тестов не зарегистрировано. Для количества решённых задач разность «doclink минус BM25» равна −25 п.п., две потери без выигрышей, точный двусторонний парный тест p=0,50. Малый пилот на одном проекте совместим со случайным различием. Почти одинаковы и реализованные расходы контекста. Все 16 запросов различались. Было обработано 33 345 входных и сгенерировано 2531 выходных токенов, время запросов составило 122 с. Загрузка модели и тестирование в это время не входят.

## Два расхождения

- В `sympy__sympy-24539` оба ответа указали файл `sympy/polys/rings.py`. В BM25-пакете была строка эталонного изменения, в пакете doclink она выпала. Первый патч прошёл тест, второй не удалось применить из-за отсутствия точной однозначной замены.
- В `sympy__sympy-19637` оба пакета включали эталонные строки и оба изменения применились к `sympy/core/sympify.py`. Целевой тест прошёл только для варианта BM25. Совпадение адресов здесь не определило функциональный исход.

В исходном наборе восьми допустимых файлов хотя бы один файл эталонной правки присутствовал лишь для **4 из 8** задач. Это ограничивает выигрыш переранжирования внутри выбранных файлов. Пилот проверяет однократную генерацию патча в одинаковых условиях. Генератор не делает новых чтений кода после неудачной правки. Проверены все целевые тесты и предписанная подвыборка регрессий в локальной Windows-среде. Следующий независимый тест должен включать другие репозитории, отдельное варьирование поиска файлов и выбор следующего наблюдения в процессе работы.
