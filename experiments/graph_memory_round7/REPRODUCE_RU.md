# Воспроизведение опытов по чтению агентной памяти

В этой папке собраны три набора опытов. Файлы с окончанием `.lock.json` и исторические протоколы сохранены побайтово. Материалы других серий лежат в соседних каталогах `experiments`.

| Эксперимент | Что опубликовано | Основное ограничение |
| --- | --- | --- |
| [Онлайн-прогноз следующего чтения](online/README_RU.md) | Минимальные проекции действий по шагам, прогнозы и парные оценки, три фиксированных среза и дополнительные проверки | Реалистичность работы решателя с предложенным фрагментом оценивается отдельно |
| [Локализация](localization/README_RU.md) и [выбор восьми файлов](localization/frontier/README_RU.md) | 54+20 архивированных предсказаний с точным составом контекста, зафиксированная разметка, исходные координаты и результаты по каждому issue | 30 прежних SymPy, 24 задачи переноса на Sphinx и 20 непересекающихся Sphinx для опыта по выбору файлов |
| [Исполняемая проверка SymPy](reader/REPORT_RU.md) | Протокол, 16 запросов и 16 ответов локального Qwen на 8 ранее выбранных задачах, назначения, поштучные результаты, списки и исходы тестов | Подвыборка входит в 30 задач локализации; повторно прибавлять её к объёму независимых данных нельзя |

[Литература](literature.md) описывает связь с опубликованными системами. У текущей серии два независимых этапа измерения — выбор участка кода и успешность исправления по тестам.

## Проверка данных без модели

В каталоге серии запустите `python -B verify_export.py`. Достаточно стандартной библиотеки Python 3.8+. Из клона репозитория скрипт также проверяет четыре зависимости соседней шестой серии. При раздельном хранении можно передать `--round6 <каталог graph_memory_round6>`. Проверяются SHA-256 прогнозов, попадания в эталонные строки по 74 задачам, исходные запросы и ответы по 8 парным задачам, агрегаты читателя и три фиксации онлайн-прогнозов.

Все восемь команд из раздела воспроизведения [онлайн-эксперимента](online/README_RU.md) выполнены в отдельной копии проекций. Все 37 файлов этого эксперимента совпали побайтово после повторения. Каталог `localization/invalid_external_grade` хранит исходный ошибочный оценщик и его отдельно обозначенный недействительный прогон: родительский Git-каталог машины привёл к пропуску применения эталонных патчей. Текущие результаты получены после изоляции Git в новом временном каталоге при неизменных контрольных суммах прогнозов.

## Официальные входные данные

У каждой из 74 задач указаны публичная ссылка на архив базового коммита и SHA-256. Они собраны вместе с применимыми лицензиями в [реестре исходников](third_party_notices/sources.json). В предсказаниях и полных запросах содержатся выбранные фрагменты Python-кода. Каталоги `inputs` содержат квитанции по исходникам; полные сторонние деревья и архивы скачиваются по ссылкам. Для восстановления 44 снимков Sphinx непосредственно в ожидаемые каталоги выполните `python -B reproduce_sphinx.py restore`. Скрипт проверяет SHA-256 каждого скачанного файла.

Использованные в старом рабочем окружении и у издателя файлы Parquet имеют разные побайтовые контрольные суммы. По всем 74 выбранным issues отдельно проверены девять фактически используемых полей. Совпали все 666 сравнений, включая текст задачи, базовый коммит, эталонное исправление и тесты. [Квитанция проверки и постоянная ссылка на Parquet](primary_input_parity.json).

Для независимой проверки разметки Sphinx установите DuckDB для Python, скачайте официальный Parquet по ссылке из квитанции, восстановите архивы Sphinx и запустите `python -B reproduce_sphinx.py grade --parquet <путь к файлу>`. Потребуется Git в PATH. Эта команда проверяет значения всех девяти полей, применяет эталонные патчи в отдельных временных каталогах и сверяет старые координаты всех 44 задач. После упаковки этот тест успешно прошёл на официальном файле издателя. Для первичной группы SymPy взяты именно координаты предыдущего оценщика, привязанные к `graph_memory_round6/repair/transfer/cpu_rows.json` и исходным базовым коммитам.

## Полные прогоны

В `localization/predict.py`, `localization/frontier/select_frontier.py` и `reader/pilot.py` сохранены исходные методы и параметры. Для полного повторения понадобится токенизатор Qwen из `memory_session5/live/tokenizer.json`, Python-пакет tokenizers и материалы предыдущей серии. Соседний `graph_memory_round6/repair/transfer/collect_tasks.py` описывает отбор, загрузку и проверку исходников SymPy. У опубликованного оценщика зафиксированы путь и SHA локального варианта Parquet. Для проверки на файле издателя используйте `reproduce_sphinx.py`; он подтверждает равенство входных полей. Веса Qwen, сборка llama.cpp и настройки запуска закреплены квитанциями `graph_memory_round6/repair/model_receipt.json`, `graph_memory_round6/repair/runtime_receipt.json` и скриптом `reader/start_server.ps1`. Пути к локально установленным весам и исполняемому файлу можно подставить в копии скрипта запуска; исходник сохранён для проверки хеша назначения.

Для восстановления крупных материалов предыдущих серий используйте [каталог артефактов](../../catalog/README.md) и `tools/records.py` из корня репозитория. Снимки ОС, полные checkout, веса, серверные журналы, PID и локальные отчёты pytest с путями машины не входят в набор. Отдельно опубликованы контрольные суммы исходных снимков, реальные запросы и ответы, сведения об исполнении каждого теста в `reader/test_outcomes.json` и исходная локальная квитанция проверки `reader/verification.json`. Время генерации и служебные отметки приложены внутри зафиксированных научных данных там, где нужны для восстановления сравнения.
