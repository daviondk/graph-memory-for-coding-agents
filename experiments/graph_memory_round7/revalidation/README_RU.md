# Когда перепроверять сохранённое утверждение о коде

## Вопрос и измерение

Если функция уже была прочитана, в памяти можно сохранить имена локальных функций, которые она вызывает, и их объявленные сигнатуры. При выходе новой версии нужно решить, достаточно ли старого ответа. Стенд использует вызовы по простому имени между уникальными определениями верхнего уровня одного Python-модуля. Он учитывает изменения имён параметров, значений по умолчанию, аннотаций, возвращаемой аннотации и вида функции. Объект измерения — синтаксический граф. Динамическая диспетчеризация, декораторы, методы и изменение поведения тел выходят за рамки этого контракта.

Источник — выпуски пакетов из PyPI. Коллекция включает 265 архивов с контрольными суммами. Репозиторий целиком не индексируется для работы с записью. В эксперименте старые модули прочитаны целиком, чтобы создать одинаковую исходную память, а все подходящие записи из изменённых модулей включены в оценку. Политика получает старые интервалы, координаты изменений и, где предусмотрено, имена из изменённых строк объявлений. Результат считается ошибкой, если пропущена перепроверка, а сохранённый ответ расходится со свежим разбором. Все решения зафиксированы локальными SHA-256 до запуска оценщика.

## Результаты

| Политика | Холодные перечитывания / устаревшие ответы, исходная панель (707) | Новые восемь проектов (717) | Ранние непересекающиеся переходы знакомых проектов (2404) |
| --- | --- | --- | --- |
| Весь caller и полные определения его локальных callees | 203 / 0 | 298 / 0 | 726 / 0 |
| Весь caller и только заголовки его callees | 146 / 1 | 244 / 0 | 578 / 0 |
| Также проверять любое изменение объявления в модуле | 317 / 0 | 321 / 0 | 1273 / 0 |
| Проверять изменения объявлений по именам, упомянутым у caller, включая ещё не разрешённые | 147 / 0 | 244 / 0 | 579 / 0 |

Первая гипотеза выполнилась частично. Отслеживание только заголовков дало 560 корректных переиспользований против 504 у полной проверки определений. Средний прирост по восьми проектам +8,86 п.п., описательный 95% ДИ [3,15; 16,68]. Один ответ оказался устаревшим. В boltons появился локальный объект с именем `dumps`, которое уже вызывалось внутри `get_profile_json`. Состав связей изменился, хотя старая связь с `get_profile` по-прежнему была действительна. Пример использован для разработки последующей защиты; фиксация причины приведена в [протоколе переноса](binding/PROTOCOL.md).

На восьми других проектах новая политика потребовала **244 перечитывания против 321 у проверки всех объявлений**, с нулём наблюдавшихся устаревших ответов у обеих. Прирост в корректном переиспользовании в среднем по проектам +11,60 п.п., описательный 95% ДИ [3,99; 19,99]. При пакетной обработке нужно было открыть 84 разных файла против 88. Сильный контроль по полным определениям потребовал 298 холодных чтений и открытия 96 файлов. Более простой контроль только по заголовкам совпал с новой политикой на всех 717 запросах. На 2404 других переходных запросах явная проверка ранее неразрешённых имён вызвала одно лишнее чтение и не предотвратила ни одной ошибки. Поэтому перенос выигрыша от учёта областей изменения подтверждён в рамках этой модели. Внешнего подтверждения пользы дополнительной памяти о неразрешённых именах пока нет.

Из показателей отдельных запросов нельзя напрямую вывести экономию I/O или времени. Количество различных файлов учитывает совместное обслуживание запросов. При одинаковых 717 ответах и семи парных повторах медиана времени полного пересчёта востребованных файлов составила 0,587 с. Политика с готовой дельтой заняла 0,372 с, а с построением дельты внутри измерения — 0,530 с (диапазон 0,525–0,665 с). Измерены операции Python с байтами в оперативной памяти. Формирование старого состояния, дисковый ввод-вывод и вызовы LLM вне замера. [Протокол измерений](COST_PROTOCOL.md) · [Поштучные повторы таймера](cost_results.json)

## Воспроизведение

Python 3.14 и пакет `packaging` нужны для повторного получения данных. Архивы скачиваются в `D:/CodexResearch/x20-round7-wheel-cache`; целостность проверяется по сохранённым SHA-256. На другой машине можно изменить значение `CACHE` в `common.py` и `fetch.py` перед отдельным запуском. Исходная проверка lock предполагает неизменённые файлы.

```sh
python fetch.py
python predict.py
python score.py
python binding/fetch_panel.py
python binding/run.py predict
python binding/run.py score
python rare/run.py fetch
python rare/run.py predict
python rare/run.py score
python cost.py
```

Для повторного вычисления метрик из готовых решений нужны wheel-архивы из каталога источников и соответствующий `score`. В трёх папках сохранены источники, поштучные ответы, решения и агрегаты. Раздел rare включает 717 уже учтённых объектов для дополнительного сравнения на той же панели. Уникальные группы насчитывают 707, 717 и 2404 запроса. Интервалы не исправляют ограничений подбора пакетов и метрики.
