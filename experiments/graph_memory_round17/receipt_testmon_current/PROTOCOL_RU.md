# Нативный CLI двух версий pytest-testmon на всех зафиксированных коммитах

Протокол дополнительной проверки зафиксирован после исходной серии 2.3.0 с наблюдателем графа и до исполнения двух CLI здесь. На всех пяти коммитах основной и восьми дополнительных исторических коммитах проверяем опубликованные pytest-testmon 2.3.0 и 2.3.1. Для обеих сред Python 3.12.13 и pytest 8.4.2, версии coverage.py соответственно 7.10.7 и 7.17.4. Эти две среды представляют два стека программ. Эффект отдельных зависимостей данным сравнением не идентифицируется. Условия отсортированы хешем коммита и версии. Каждый блок получает чистый каталог и чистую базу testmon. Сначала запускаются все ранее зафиксированные nodeid, затем в той же копии штатный выбор без изменений, затем штатный выбор после того же контролируемого отката. У всех выставлены одинаковые флаги pytest и --testmon-forceselect для явных nodeid. Получаем фактические результаты из XML JUnit, без пользовательских pytest-хуков, sys.setprofile или изменения кода testmon. Отдельный полный запуск без testmon в каждой среде проверяет все исходы после отката.

Публикуем первичные количества повторов среди первоначальных pass, долю пропущенных реальных падений и накладные расходы. Случай без начального pass учитывается отдельно. Проверяем совпадение с предыдущими результатами тем же 2.3.0 и изменение выбора в 2.3.1. Предсказания собственного графа уже фиксированы до доступа к исходам соответствующих задач.
