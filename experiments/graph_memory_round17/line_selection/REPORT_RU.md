# Выбор строк для памяти кодового агента по видимой структуре Python

На 54 задачах SWE-bench Verified и 108 архивных эпизодах SWE-agent из репликации R16 проверили, можно ли использовать заголовок видимой функции или класса, когда агент решает, какие 60 строк оставить. Если в запросе упомянуто имя, метод придаёт дополнительный вес видимым строкам тела этой функции. Для такого ребра достаточно уже открытого кода. При одинаковых блоках, бюджете и зарезервированных 24 строках граф поднял нативную точность SWE-Explore с **70,15% до 71,44%**. Разность +1,28 п.п., 95% bootstrap по 54 задачам от +0,40 до +2,28 п.п. При кластеризации по восьми репозиториям интервал расширяется до [−0,06; +2,63] п.п. Оценка переносимости на другие проекты остаётся неопределённой. Все варианты вернули по 5 760 строк. В 12 эпизодах подходящего чтения не было, они остались в знаменателе. Предварительный контраст с резервом изменил набор строк в 45/108 эпизодах. По нативной точности получены восемь выигрышей, один проигрыш и 99 совпадений. На исторических траекториях GPT-4 прибавка составила +2,22 п.п., на Claude 3.5 Sonnet +0,34 п.п. На прежних 179 задачах прибавка +0,18 п.п. с интервалом [−0,45; +0,76]. Адаптация к запросу работает неодинаково на траекториях разных агентов. [Все политики и условные результаты](results.json)

**Что даёт сама связь с функцией.** При снятии резерва текстовый контроль уже достигает 72,85%. В этом сравнении связь добавляет +0,51 п.п. (интервал по задачам от −0,86 до +1,93). Выигрыш первичного контраста зависит от политики распределения бюджета. Порядок восьми контрольных репозиториев устойчив в одном ограниченном смысле: при исключении каждого по очереди средняя разность остаётся положительной, от +0,78 до +1,50 п.п. [Независимый пересчёт 6 027 значений](verification.json)

**Попадание в строку, которая изменилась.** Для 44 из 54 задач эталонный патч удалял или заменял хотя бы одну старую Python-строку. В 46 из 108 эпизодов такая строка присутствовала среди первоначальных чтений. Поэтому 46/108 — наибольшее достижимое число попаданий при использовании только этих источников. Текстовый метод без резерва и граф без резерва достигли 33/108. Граф с резервом и его текстовый контроль дали 31/108 и 29/108. У последнего просмотренного файла нативная precision равна 1 в 78 эпизодах, но в 64 из них ни одна выбранная строка не изменялась в эталонном патче. Различие закономерно: полезный контекст включает строки вне правки. Диагностику определили после основного эксперимента, предсказания для неё не меняли. **Границы.** Наблюдения взяты из завершённых траекторий. Они были видимы до решения, в независимой части их проверили против файлов базовой ревизии. Контракт включает первые три распознанных просмотра и не гарантирует, что это вообще первые команды агента. Метод строит связи по заголовкам и отступам, закрывает область при пропуске строк и может неверно интерпретировать многострочную конструкцию. Дополнительная оценка охватывает только удалённые или заменённые старые строки. Когорта из восьми проектов уже использовалась для проверки первых чтений в R16. Её 54 задачи не пересекаются с первоначальными 199 задачами. На SymPy приходятся 19 из 54 задач. Исследование оценивает память о просмотренном коде. На полное решение задачи и лидерство в SWE-bench выводы не распространяются.
