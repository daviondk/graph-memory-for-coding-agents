# Дополнительная диагностика по строкам эталонной правки

Эта проверка сформулирована после расчёта основного результата SWE-Explore и до открытия поштучных patch-меток для данных политик. Прогнозы остаются зафиксированными. Мы проверяем, совпадают ли высокие значения precision по размеченным полезным для исследования регионам с локализацией строк, которые действительно пришлось изменить. Из gold patch SWE-bench Verified используем только номера удалённых или заменённых Python-строк старой версии. Путь и номер строки рассматриваются вместе. Чистая вставка имеет пустое множество таких строк. Диагностика не покрывает добавление новой функции и случаи, когда понять причину помогает неизменённый код.

Считаем Hit любой такой строки, число сохранённых изменённых строк и долю среди всех сохранённых строк. Отдельно показываем, сколько задач вообще имеют удаление/замену, сколько исторических префиксов уже содержат хотя бы одну такую строку, сколько задач потерялись при выборе 60 строк и в скольких случаях правильная строка вообще отсутствовала среди видимых вариантов. Первичная панель для этого анализа — 54 независимые задачи, где реальные чтения были проверены по базовой ревизии. Два исторических агента являются повторными измерениями на одной задаче. Парный bootstrap по задачам для бинарного попадания сравнивает заранее существующие scope24 и lexical24. Счёт по двум парсерам должен совпасть. [Прогнозы и контрольные суммы](prediction-lock.json)
