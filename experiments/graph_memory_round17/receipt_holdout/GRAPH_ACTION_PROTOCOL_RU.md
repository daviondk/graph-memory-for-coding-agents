# Исполнение графового решения

После фиксации результата нативного testmon закрываем разницу между выбором восьми nodeid графом и их фактическим исполнением. Повторяем на новых копиях тех же пяти коммитов. Первый обычный pytest с наблюдателем графа работает без testmon, фиксируются действительные функции по каждому исходному тесту. Читаем только изменённый производственный файл до и после, сравниваем AST верхнеуровневых функций/классов, планируем и исполняем выбранные nodeid штатным pytest. Условие — все исходные результаты pass, выборка совпадает с заранее записанными графовыми прогнозами. Полный набор известных меток не входит в выбор. Если в блоке не выбран ни один тест, новый процесс не запускается. Сохраняем время прогрева, цена вычисления и исполнения, объём временного списка и результаты настоящих тестов. Сравнение времени с предыдущей нативной серией описательное: это последовательные прогоны на уже прогретой машине, с неодинаковым порядком и форматом хранения состояния. Для разницы числа повторных проверок дополнительно публикуем число коммитов с выигрышем, потери и равенства и парный интервал на уровне коммитов. Восемь отдельных методов теста не принимаем за восемь независимых изменений.
