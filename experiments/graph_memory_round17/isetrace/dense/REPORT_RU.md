# Проверка упаковки с предобученным E5

На восьми траекториях из каждого шарда сравнили две модели ранжирования одних и тех же фрагментов аргументов и результатов. Все 27 запросов (13 и 14) были отобраны до построения векторов. Кандидаты, исходные координаты, результаты базового BM25 и стоимость сначала поштучно сверены с основной серией. Для E5 использовались исходные процедуры Sentence Transformers и авторский DenseTaskRetriever с закреплёнными весами. Для замороженного E5 пропуск относительно исходного префикса дал 1 выигрышей и 0 потерь, разница +3,7 п.п. (+0,0…+11,5). При сравнении приоритета пары с нормировкой по стоимости получили 0 выигрышей и 0 потерь, разница +0,0 п.п. (+0,0…+0,0). Это парные описательные 95% интервалы по траекториям; в выборке 16 кластеров. [Полные показатели при трёх бюджетах](summary.json) · [Поштучные исходы](outcomes.json.gz)

Дополнительное усечение первого не помещающегося элемента до оставшихся исходных токенов дало на E5 10/13 и 4/14. Каждый запрос расходует полный предел 2 048. [Правило усечения](../truncation/PROTOCOL_RU.md) · [Парные сравнения с усечением](../truncation/dense-results.json)

Точный E5-base-v2 (768 компонент) вычислил 1645 различных строк запроса и фрагмента с префиксами query и passage. Вызван авторский код нормировки и ранжирования по скалярному произведению. Использованы CPU float32, 6 потоков, torch 2.6.0+cpu, transformers 4.52.4 и sentence-transformers 2.7.0. Ранжирование завершённого запуска заняло 332.3 с. Первое исполнение было прервано до фиксации результатов. В итог входит полностью завершённый повтор неизменённой замороженной выборки. Второй исполнитель сохранял только векторы точных входных строк для восстановления. [Версии и время](runtime.json) · [Обработка восстановления](resume_cpu.py)

Для пересчёта запустите score из dense.py, затем summary.py. Для получения исходных ранжирований нужны скрипт загрузки provision_e5.py, зафиксированный ранее снимок BM25 и конфигурация из протокола. После появления ранжирований выполните из папки truncation команды python -B clip.py rank dense и python -B clip.py score dense. Размер выборки исключает надёжное ранжирование близких политик; обучение Dense-FT и пяти отдельных R-GCN на полном протоколе авторов здесь не выполнялось.
