# Воспроизведение упаковки ISETrace

Проверка собранных цифр из архивных ранжирований требует Python, NumPy, Pydantic, rank-bm25, requests и tokenizers. В `pilot.py` зафиксирована ревизия авторского Git df29287116fa1565b3fd6b485022cd6090dc0b27. Рабочая копия под D:/CodexResearch/x20-isetrace-runtime/upstream должна содержать именно эту ревизию. Нужный URL репозитория указан ниже. Артефакты на диске D не требуют учётной записи API. Оценка из сохранённых ранжирований обходится без GPU и без скачивания исходных шардов.

```powershell
$env:PYTHONUTF8='1'
python -B pilot.py score
python -B replication/pilot.py score
python -B summarize.py
```

Полное воспроизведение в отдельной копии рабочей директории начинается с `provision.py` для первого шарда, затем `pilot.py cohort`, `pilot.py rank`, `pilot.py score`; в точности в том же порядке следуют `replication/provision.py` и три стадии `replication/pilot.py`. Первая ступень сверяет файлы Hugging Face с SHA LFS либо соответствующим Git blob. В исходной среде два шага `rank` используют неизменённые authoring adapter, flat renderer, provenance graph, BM25, бюджетную функцию и span scorer; импорт модуля обучения Torch в родительском инициализаторе пропущен. Pydantic валидирует ожидаемые поля. Обёртка вокруг закреплённого tokenizer.json передаёт исходному chunker реальные токенные смещения и отключает добавление специальных токенов.

`assignment.json` и `prediction-seal.json` фиксируют спецификацию, входы и содержимое прогнозов. Coherent update требует новой папки, проверка уже существующих файлов разрешает только побайтное повторение. Формирование графа и ранжирование в каждом шарде используют полный файл сырых событий и реальные аргументы/ответы. Артефакты повторения содержат идентификаторы/координаты, размеры и баллы, а также все версии общественного набора. Операции из исходных историй интерпретируются как данные.
