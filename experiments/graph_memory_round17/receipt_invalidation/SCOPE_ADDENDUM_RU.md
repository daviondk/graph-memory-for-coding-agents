# Дополнительная панель с явным абсолютным каталогом

При проверке синтаксиса входных команд до чтения парных исходов выяснилось, что большинство архивных вызовов сначала делают cd в именованный каталог проекта. На /testbed приходится 184 синтаксических префикса cd, на /pandas — 410, на /pennylane — 373. Сохраняем исходную панель /testbed и добавляем отдельную панель с единственным явным cd в абсолютный каталог /<имя репозитория> либо его подкаталог. Строгая пара по-прежнему требует побайтно одинаковой полной команды. Исключаем /tmp и каталоги вне репозитория. Для изменения с другой возможной базой пути требуем повторной проверки, поскольку разные имена корневых каталогов могут ссылаться на одну рабочую копию. Из опубликованных инструкций удостоверяем каталог по умолчанию /testbed. Состояние файловой системы архивного запуска не исследуется. Все группы и ограничения публикуются вместе с результатами.
