# Воспроизведение

Для проверки без нового обращения к модели выполните score.py. Требуются ссылка на более ранние testmon-graded.gz двух панелей и записанные рядом decisions.json, executions.jsonl, calls.jsonl и материалы назначения. Скрипт сверяет каждое допустимое имя теста и JUnit с исходами полного запуска.

Для полного повтора используйте новую рабочую копию. study.py prepare берёт только testmon-graph-forecasts.gz и rollback-roster.json из двух соседних исследований. Затем нужен локальный сервер Qwen с конфигурацией start_server.ps1, study.py model и study.py tests. Исполняющая программа проверяет SHA производственного модуля и файлов тестов перед запуском каждого выбранного nodeid. Условия обращения строго одинаковы, различается только дополнительный признак памяти. Пример runtime сохранён в launch.json, полные тела запросов — в prompts.gz. [Фиксация входов](lock.json)
