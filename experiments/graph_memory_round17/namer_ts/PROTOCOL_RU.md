# Аудит пяти случаев исполнения кода при импорте в NameRTS

Авторы NameRTS указывают, что пять изменений matplotlib затрагивают функцию _get_executable_info, которая вызывается при импорте модуля testing/compare.py. Есть опубликованные авторские списки выбранных файлов тестов и ground truth для 50 целевых пар. Проверяем их на фиксированной ревизии репликационного пакета f1acdae0f2b2d1ed6e3e2956d510db49bb7c276f.

Определяем затронутые пары независимо от числа выбранных авторским алгоритмом файлов. Сравниваем структуру выделенной верхнеуровневой функции между версиями lib/matplotlib/__init__.py в каждом current и true_parent, отдельно между current и direct_parent. Сохраняем хеши исходной версии файла и AST функции. Если число структурных изменений отличается от пяти, показываем точные множества и отдельно уточняем по контексту без подгонки до пяти исходов. Вычисляем пересечение и разность множеств тестовых файлов NameRTS, EkstaP, BabelRTS и эталонной разметки. Проверяем MA-native unit test file по конкретным SHA и спискам, число прежних или новых failing pytest nodeid в этих метках отсутствует. Сравнение с нашим прототипом сохраняет эти ограничения.
