# ISETrace. Неизменяемый срез трёх полных парных сравнений

На каждой из трёх инициализаций измерены три метода на тех же 2 000 вопросов и тех же 1 207 траекториях. Все шесть исходных показателей пересчитаны из фактических полных ранжирований с родной семантикой покрытия и строгого префикса. В срезе сохранены 6 000 сочетаний seed × вопрос с исходами каждого метода. В каждый файл входят ID вопроса и траектории, а также векторы R33, полного R-GCN и заново обученной абляции без chunk adjacency.

## Условия отбора и проверка

Для каждого seed три модели используют общие Dense-веса, эвиденциальные единицы, токенизацию и spans. У R33 политика фиксируется по FS@2048, затем Coverage@2048 на dev580. Штатные R-GCN выбирают эпоху по node Recall@5 тех же 580 запросов. Отдельно зафиксирован повтор выбора всех десяти графовых эпох по той же бюджетной паре критериев, который начинается после основной очереди. Правило финальной проверки требует положительной нижней границы парного эффекта R33 по FS@2048 против обеих баз на пяти seed.

Полные прогнозы закреплены в audit- и seed-файлах. Для отдельного пересчёта шести средних, парных эффектов и обоих типов интервалов из индивидуальных исходов выполнить `python -B check.py` с NumPy. Код для воспроизведения самих исходов из полных порядков сохранён в compare.py; снимок не является рабочей папкой наблюдения.
