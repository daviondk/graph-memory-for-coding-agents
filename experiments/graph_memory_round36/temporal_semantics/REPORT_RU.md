# Семантика времени для связей между фрагментами памяти агента

Пусть Sₜ(i,j) означает, что после события t хотя бы одно значение однозначно связывает производителя i с вызовом потребителя j. Пусть Vₜ(x,i) означает, что конкретный фрагмент x выхода i уже доступен в памяти. Все фрагменты одного выхода в ISETrace появляются при публикации результата. Текущая связь между фрагментами в момент t существует, когда одновременно выполнены Vₜ(x,i), Sₜ(i,j), Vₜ(y,j). Смысл S задаётся правилами извлечения provenance в опубликованной системе. Исследуемый вариант накопления всех старых привязок — построенный нами контроль для потокового случая. [Исходная работа и критерии оценки](https://arxiv.org/abs/2609.25913)

**Исторический запрос.** Обозначим момент появления x и y через tₓ, tᵧ, а текущий срез через T. Связь хотя бы раз наблюдалась между их фрагментами тогда и только тогда, когда существует τ из [max(tₓ,tᵧ), T] с Sτ(i,j). Объединение логических связей за всю историю, к которому позже присоединяются видимые концы, способно связать эти фрагменты при существовании S в более раннее время. Подстановка одного общего τ в три отношения объясняет включение E ⊆ M ⊆ L. Для интервала логической поддержки [a,b) граница в точности требует max(a,tₓ,tᵧ) < b и max(a,tₓ,tᵧ) ≤ T. Равенство момента появления второго конца с b уже исключает пару. Это частный случай семантики временного соединения и согласованных снимков. [Dignös, Böhlen и Gamper, Temporal Alignment](https://files.ifi.uzh.ch/boehlen/Papers/modf174-dignoes.pdf) · [Snapshot Semantics for Temporal Multiset Relations](https://www.vldb.org/pvldb/vol12/p639-dignoes.pdf)

**Число ошибочно добавленных пар.** Если выходы i и j имеют соответственно nᵢ и nⱼ разных фрагментов, один ошибочно сохранённый логический факт порождает nᵢnⱼ ложных утверждений о совместной видимости. При разбиении фрагментов между выходами эти множества попарно не пересекаются. Поэтому число никогда не наблюдавшихся PU-рёбер равно сумме nᵢnⱼ по тем логическим парам, у которых поддержка и совместная видимость не перекрывались. Та же факторизация даёт исходящую степень фрагмента x выхода i как сумму nⱼ по подтверждённым j, входящую степень фрагмента y выхода j как сумму nᵢ по подтверждённым i. Это позволяет посчитать признаки ранжировщика без полного раскрытия всех пар. Различие между семантикой связи и индивидуальной ценностью конкретного ребра при ранжировании проверено отдельной перестановочной абляцией. **Почему для исторического объединения достаточно одной проверки.** У конкретного потребителя множество возможных свидетелей фиксируется его неизменным вызовом. Производитель должен существовать до вызова. После него новый вывод инструмента может лишить значение уникальности, но в данной семантике утраченную уникальность оно не восстанавливает. В момент первого появления результата потребителя либо хотя бы один свидетель ещё жив, либо все исчезли и будущих свидетелей для этого вызова быть уже не может. Алгоритм должен обработать коллизии значений из самого этого результата перед решением о включении пары. Если значение могло бы вновь стать уникальным, потребитель мог бы изменять аргументы, фрагменты публиковались бы с разными временами или несколько результатов принадлежали бы одному вызову, для этого вывода потребовались бы дополнительные условия. **Конечная проверка.** Для временной оси из семи событий перебраны все двоичные последовательности поддержки, оба момента появления концов, включая непоявление, и все срезы. Из 57 344 сочетаний формула по пересечению интервала воспроизвела каждое историческое состояние. Поздняя проекция ошиблась в 4 176. На 2 352 сочетаниях, удовлетворяющих условиям одной проверки при появлении второго конца, сокращённая формула всегда совпала с полной. На произвольных последовательностях найдено 4 099 контрпримеров этому сокращению. Частоты в синтетическом переборе зависят от способа перечисления и не служат оценкой распространённости в ISETrace.
