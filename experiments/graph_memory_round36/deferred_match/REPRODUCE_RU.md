# Воспроизведение

Для быстрой сверки по подписанным поштучным измерениям достаточно стандартного Python. Выполнить в каталоге исследования.

~~~powershell
python verify.py
~~~

Для повторного эксперимента нужны локальный снимок ISETrace, исходный парсер и существующие каталоги R34 и R36 на диске D. Полный список ID подвыборки содержится в plan.json. Проверяются хеши шардов и сырых строк. Сами строки, аргументы и результаты инструментов в выходные файлы не записываются.

~~~powershell
$pythonResearch='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $pythonResearch measure.py
& $pythonResearch timing.py
& $pythonResearch fixtures.py
& $pythonResearch analyze.py
& $pythonResearch verify.py
~~~

Порядок важен, так как реестр фиксирует исходную программу, список историй и контрольную реализацию. Для сохранения опубликованных измерений выполнять повтор в отдельной копии каталога рядом с исходным. При повторном тайминге время и контрольные суммы файлов с временем изменятся. Числа операций и исходы равенства детерминированы. Последнюю сводку текущего запуска содержит summary.json.

Для проверки целостности исходного снимка можно вычислить SHA-256 каждого файла и сравнить с manifest.json.
