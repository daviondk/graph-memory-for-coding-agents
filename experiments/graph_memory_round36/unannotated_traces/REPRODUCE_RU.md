# Воспроизведение

Сверка завершённого опыта с файлами поштучных результатов и родительскими сериями

```powershell
$tracesPython = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $tracesPython -B -X utf8 verify.py
```

Новый полный прогон в копии этой папки рядом с каталогами materialized_append и streaming_witnesses

```powershell
& $tracesPython -B -X utf8 panel.py
& $tracesPython -B -X utf8 measure.py
& $tracesPython -B -X utf8 analysis.py
& $tracesPython -B -X utf8 flow.py
& $tracesPython -B -X utf8 verify.py --seal
```

panel.py читает каждый байт восьми исходных JSONL ради сверки SHA-256. Дополнительно сверяет все ID вопросов между полной таблицей и таблицей метаданных, а все официальные разбиения — с метаданными. Адреса записей, хеш-выборка, контрольные суммы входов и нативная подвыборка сохраняются до построения графа. Для подвыборки из 12 используется собственный префикс хеширования r36-unannotated-native-outputs/v1/. measure.py запускает два CPU-процесса. Они обращаются только к выбранным исходным записям и используют официальные инструменты построения графа и токенизации, которые уже установлены для ISETrace. На данном компьютере для этого используется среда, в имени которой есть e5-gpu; в скрипте GPU скрыт. Модель LLM и эмбеддинги в этом опыте не вызываются.

histories-0…7 содержат агрегаты каждого среза и воспроизводимые хеши нативных префиксов, диагностические коды и хеши исходных записей. Два ряда в каждом срезе дают количества на уровне PU и на уровне групп. Порядок пяти величин — E, M, L, M−E и L−M. В поле memory содержатся пик числа обратных ссылок прежнего индекса, пик числа ссылок открытых потребителей и суммы обеих величин по событиям. Все содержательные метрики и интервалы можно пересчитать с analysis.py без построения исходных графов при наличии агрегатов аннотированной панели R36. Файл excluded.json описывает структурные причины пропуска. Исходные тексты, аргументы, команды и выходы инструментов в пакет не включены.
