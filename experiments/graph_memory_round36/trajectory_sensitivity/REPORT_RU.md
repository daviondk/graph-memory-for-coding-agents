# Насколько эффект зависит от самых крупных историй

В середине 1 207 историй обнаружено 66 920 лишних рёбер при накоплении всех логических связей. Из них 92,88% никогда не были действующей связью между одновременно доступными фрагментами. У 343 историй лишних рёбер вообще не оказалось. Среди остальных 864 медианная доля никогда не существовавших рёбер составила 97,63%, межквартильный интервал [40%; 100%]. Истории существенно отличаются по структуре. На 13 самых больших по числу лишних рёбер приходится 19 901 из 66 920 лишних рёбер. [Результаты](results.json)

| Исключено историй с наибольшим числом лишних рёбер | Доля никогда не существовавших среди оставшихся лишних рёбер | Осталось допустимых вопросов | Прибавка Full Support@2048, п.п. |
|---|---:|---:|---:|
| 0 | 92,88% | 901 | +1,89 [0,56; 3,27] |
| 13 (1%) | 90,74% | 891 | +2,02 [0,68; 3,39] |
| 61 (5%) | 87,85% | 856 | +1,52 [0,35; 2,73] |
| 121 (10%) | 82,53% | 806 | +1,49 [0,37; 2,64] |

При равном весе каждой траектории, в которой есть допустимый вопрос, разность +2,05 п.п. [0,68; 3,50]. Если исключать одну траекторию, оценка по вопросам меняется от +1,67 до +2,00 п.п. Таким образом, сравнение объединения реально наблюдавшихся связей с накоплением всех логических привязок сохраняет положительный эффект за пределами нескольких самых крупных графов. Оба подхода хранят разное число рёбер. Проверка того, нужна ли индивидуальность каждого сохранённого ребра, требует отдельного контроля с одинаковым количеством. Интервалы относятся к исследованному корпусу и одной инициализации.
