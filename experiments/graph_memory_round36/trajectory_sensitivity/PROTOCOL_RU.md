# Влияют ли несколько крупных графов на вывод о лишних рёбрах

Совокупные результаты по всем 901 вопросу известны. До открытия распределения по историям фиксируем анализ чувствительности. В середине каждой из 1 207 историй считаем долю никогда не существовавших рёбер среди всех лишних, отдельно суммарную долю и медиану долей по историям с ненулевым числом лишних рёбер. Нулевые истории показываем явно. Сопоставляем доли у 1%, 5% и 10% самых больших по числу лишних рёбер историй с остальными. При равенстве используется строковый ID траектории, число исключаемых округляется вверх. Графовые признаки определяют отбор без обращения к ответам.

На исходной выборке из 901 вопроса и после исключения этих целых траекторий оцениваем разность Full Support@2048 для накопления фактически материализованных связей и для накопления логических связей с последующей проекцией на фрагменты. Стандартный эффект усредняет вопросы. Второй даёт каждой траектории с допустимыми вопросами одинаковый вес. 10 000 парных перевыборок целых траекторий, одинаковых для обоих методов. Отдельная проверка — исключать по одной траектории из основной панели. Обрезание хвоста и разное взвешивание помогают установить, где сосредоточена наблюдаемая разность. Это анализ уже изученного корпуса и ранее замороженного ранжировщика.
