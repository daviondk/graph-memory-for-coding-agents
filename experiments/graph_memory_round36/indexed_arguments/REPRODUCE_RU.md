# Воспроизведение

Из каталога исследования независимая сверка по имеющимся числовым данным выполняется стандартным Python. Верификатор сверяет подвыборку и интервальные входы, предыдущие подписанные файлы по каждой траектории, итоговые абсолютные числа и центральные отношения времени.

~~~powershell
python verify.py
~~~

Для полного повтора нужна локальная среда с закреплённым снимком ISETrace и каталогами materialized_append, streaming_witnesses и deferred_match рядом. Скопируйте каталог исследования под другим именем на том же уровне, чтобы сохранить исходные тайминги; затем выполните из копии.

~~~powershell
$pythonResearch='D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $pythonResearch experiment.py seal
& $pythonResearch experiment.py timing
& $pythonResearch experiment.py audit
& $pythonResearch fixtures.py
& $pythonResearch summarize.py
& $pythonResearch verify.py
~~~

Панель ID, контрольные суммы исходного кода и протокола находятся в plan.json. Повтор времени формирует новые числовые файлы; счётчики операций и проверки равенства детерминированы. В архиве исследования сохраняются агрегированные счётчики по каждой траектории, измерения времени и контрольные суммы. Содержимое естественных аргументов и выводы инструментов туда не копируются.
