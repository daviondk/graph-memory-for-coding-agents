# Три графа для одного запроса

Источник — зафиксированные полные прогнозы R36/materialized_append, четыре среза и бюджет 2 048. В непилотной доступной панели 50% выбираем три различающиеся траектории. Первая показывает выигрыш только при L→M (FS: E=1, M=1, L=0). Вторая — выигрыш только при M→E (E=1, M=0, L=0). Третья — немонотонный исход (E=1, M=0, L=1). Берём минимальный SHA-256 от «R36-history-demo/» с ID вопроса внутри каждой группы. Классы отобраны по известным исходам. Демонстрация объясняет индивидуальные изменения и не используется в оценке распространённости. В интерфейс экспортируются только анонимные адреса, типизированные рёбра, длины, числовые параметры ранжирования, координаты и хеши полей.

Объединение текущих data.feeds по всем атомарным событиям определяет M. Текущие рёбра дают E. Добавление старых привязок вызовов с текущими видимыми концами даёт L. Для каждого среза и каждого из трёх состояний проверяем список индексов, потраченные токены и полный охват spans по сохранённым исходам R36 и встроенной метрике ISETrace. Списки лишних связей проверяем сравнением с нативным построителем после каждого появления результата и независимым интервальным подходом видимости. Браузер вычисляет ранг, границу бюджета и покрытие для всех 36 комбинаций. [Дизайн основного сравнения](../materialized_append/PROTOCOL_RU.md)
