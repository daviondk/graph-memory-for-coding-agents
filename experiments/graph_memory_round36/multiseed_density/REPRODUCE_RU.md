# Воспроизведение

Для пересчёта из поставленных исходов нужны Python и NumPy. Из каталога исследования запустите

```powershell
$densityPython = 'D:/CodexResearch/x20-isetrace-e5-gpu/venv/Scripts/python.exe'
& $densityPython -B -X utf8 verify.py
```

Для полного прогона используйте рабочую копию каталога рядом с edge_count_control и multiseed_midpoint, сохраняя родительские артефакты. На CPU запустите последовательно

```powershell
& $densityPython -B -X utf8 predict_density.py
& $densityPython -B -X utf8 score_density.py
& $densityPython -B -X utf8 summarize_density.py
& $densityPython -B -X utf8 sensitivity.py
& $densityPython -B -X utf8 verify.py --seal
```

Первый этап сверяет подписанные источники, восстанавливает графы до середины истории, применяет прежний хеш-генератор и использует существующие плотные порядки и rank-calibration для каждого seed. Вызовов LLM или GPU в коде нет. Порядок чтения сохраняется для каждой из 19 политик и четырёх seed, с удалением повторов только на уровне сериализации внутри конкретного вопроса. Файл plan.json задаёт порядок столбцов. Матрица outcomes.json.gz использует индексы в списке values этого же вопроса; значения содержат FS, долю покрытия и целое число выбранных токенов. Оценка нативной функции символьных интервалов выполняется после создания forecast-seal.json. Для быстрого воспроизведения интервалов при готовом outcomes достаточно последних трёх команд, включая зависимости в соседних каталогах.

Восемь солей заданы независимыми именами, но возможны равные маски графа и многократные совпадения исходов. sensitivity.py отдельно считает число различных масок на траекторию, вопросы с действительно различающимся FS и условные интервалы.
