# Проверка ранжирования относительно R-GCN без рёбер между соседними фрагментами

На ISETrace ни один из двух исследуемых методов не превысил переобученный R-GCN без `content.next` со статистической значимостью после поправки Holm. Этот контроль особенно важен для Coverage@1024. При сравнении с исходным полным графом degree давал +3,06 п.п., при сравнении с R-GCN без связей между соседними фрагментами разность сократилась до +0,47 п.п.

Обучение обоих R-GCN охватывало 3 894 запроса, для выбора эпохи использовали 500 dev-запросов, seed 13. Для обычного графа выбрана эпоха 11, для абляции эпоха 12. Набор типов рёбер уменьшен на `content.next` в обоих направлениях. Degree и factor используют зафиксированные прогнозы из предыдущего раунда. Проверены 2 000 парных тестовых запросов из 1 207 траекторий. У всех четырёх ранжировщиков совпадают 249 089 вхождений кандидатов. У обеих R-GCN сверены ID, исходные символьные интервалы и стоимость каждого кандидата с общей таблицей; у degree и factor проверены полные перестановки той же таблицы. Битовые маски независимо воспроизвели 48 000 прежних оценок с максимальным отклонением 2,23 × 10⁻¹⁶. Всего пересчитано 64 000 оценок.

Каждый запрос имеет одинаковый вес. Восемь метрик сравнивают объединение эталонных символьных интервалов с покрытием упорядоченным префиксом кандидатов. Span Recall@5 измеряет покрытую долю символов в первых пяти кандидатах, Span MRR использует первый кандидат с непустым пересечением. При бюджетном ограничении префикс завершается перед первым кандидатом, не поместившимся целиком. AUC — нормированная площадь на логарифмической шкале шести бюджетов от 256 до 8 192 токенов. Для каждого контраста использованы парные стандартные ошибки с кластеризацией по траектории, конечная поправка G/(G−1), двусторонний нормальный тест и step-down Holm.

Из 32 сравнений обоих методов с обеими R-GCN поправку выдержал один проигрыш. Degree по Span Recall@5 дал 76,97% против 80,53% у R-GCN без `content.next`. Разность −3,57 п.п., одновременный 95%-й интервал Бонферрони для семьи из 32 [−6,24; −0,89] п.п., Holm p = 0,000787. Прежнее отличие degree по Coverage@1024 от обычного R-GCN имеет p = 0,0294 в семье из 16 и p = 0,0570 в общей семье из 32. Full Support@2048 при новом контроле равен 80,30% у R-GCN, 78,75% у degree и 78,30% у factor.

Протокол сохранён до просмотра индивидуальных прогнозов абляции в этом анализе. При фиксации SHA файлы абляции уже существовали, прежние результаты на бенчмарке и опубликованные агрегаты могли быть известны. Интервалы учитывают выборку траекторий при фиксированном seed, а пространство прошлых исследовательских решений и вариация повторного обучения остаются за пределами этой оценки. Перенос на другие корпуса и решение агентом задачи целиком требуют самостоятельного измерения.
