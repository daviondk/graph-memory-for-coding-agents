# Проверка переключателя между поиском и чтением соседа

Исследовательское продолжение после просмотра опубликованных сводок этой же коллекции. Ранее уже известно, что из 271 допустимых строк 180 покрывает hybrid, 185 neighbor, 177 BM25, а различие зависит от размеченной области конфликта. Эта информация мотивировала эксперимент. Здесь разметка области недоступна при обучении и прогнозе. Внешнего подтверждения на новом корпусе нет.

- Единицы группировки — запечатанные компоненты сходства фонового текста с порогом Жаккара 0,90 для семисловных шинглов. Все 218 компонент, в том числе компоненты без доступной отдельной цитаты, распределяются по пяти фолдам до чтения пообъектных результатов. Для каждой компоненты берём SHA-256 строки `adaptive-lookup-22|` и псевдонима компоненты, сортируем по хешу и циклически выдаём номера 0…4. Варианты одной компоненты всегда в одном фолде. Идентификаторы не входят в признаки.
- Оба варианта возвращают первый гибридный адрес. Во вторую позицию hybrid возвращает второй адрес гибридного ранга, neighbor — ближайший к уже переданной цитате адрес за вычетом первого. Модель выбирает один из этих двух неизменяемых вариантов. Проверяем шесть заранее заданных признаков: log10(1 + абсолютное смещение) для первого и второго адреса hybrid и второго адреса neighbor, индикаторы точного совпадения первых и вторых адресов BM25 и E5, размер пересечения первых двух адресов BM25 и E5, делённый на два. Расстояния измеряются в блоках предложения. Строки, исходный текст, scope, жанр, наличие разметки и эталон не служат признаками.
- В каждом фолде учим единственную логистическую регрессию на строках **других** четырёх фолдов, где одна политика попала в эталон и другая промахнулась. Цель 1 для выигрыша neighbor, 0 для выигрыша hybrid. Это оценка вероятности выигрыша neighbor **при условии расхождения исходов**, а не вероятности наличия эталона в конкретном документе. Ничьи исключаются только из функции обучения, поскольку выбор политики не влияет на Hit@2 этих строк. Алгоритм liblinear, L2, C=0,25, с регуляризуемой константой, без подбора параметров, seed 2220, tol=1e−9. При одном или нуле представленных классов использовать постоянную оценку (положительный вес + 0,5)/(весь вес + 1). Выбираем neighbor при p ≥ 0,5, иначе hybrid. При одинаковых адресах прогноз также фиксируется.
- До обучения фиксируем все 449 наборов признаков, варианты чтения, группы, фолды и отдельные файлы допустимых обучающих меток каждого фолда. Предсказатель не открывает результаты оцениваемых документов. После заморозки прогнозов отдельная команда сверяет каждый выбор с ранее запечатанными исходами. В основном сравнении — разность Hit@2 переключателя и всегда-neighbor на всех 271 строках с отдельно доступной эталонной цитатой, дополнительные контроли always-hybrid, always-BM25. Отдельно показываем все 377 размеченных записей, стоимость двух ответов в UTF-8, выигрыш/потери/ничьи, размеры фолдов и число отличающихся обучающих исходов.
- Парные доверительные интервалы по компонентам: 10 000 bootstrap-перевыборок зафиксированных out-of-fold решений, seed 2220. Это интервал для уже полученных прогнозов. Дополнительная проверка с повторным обучением при 1 000 кластерных перевыборках, seed 2221: одна компонента целиком в исходном фолде, повторения задают веса её строк при обучении и тестировании. Сохраняем обе оценки. Никакого выбора модели по результату, сравнения с SOTA или генерации ответов LLM.
