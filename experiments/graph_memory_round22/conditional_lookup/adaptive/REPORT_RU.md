# Можно ли выбирать следующую ссылку по положению и согласию поисковиков

На ContraDoc проверили небольшой переключатель между двумя способами получить второе свидетельство. Первый адрес в обоих случаях выдаёт гибрид BM25 и E5. На втором шаге можно открыть следующую запись гибридного списка или ближайший к выданной цитате фрагмент. **Оба варианта — обученный выбор и постоянное чтение соседа — доставили эталон в 185 из 271 документов (68,3%).** Выбор гибридного второго адреса исправил один промах и добавил один новый.

## Метод

Кандидаты, первая цитата и расположение записей заимствованы из ранее зафиксированного условного теста. Шесть числовых признаков описывают расстояние трёх предложенных адресов до первой цитаты и согласие первых двух позиций BM25 и E5. Ранжирование и эмбеддинги не пересчитывались. Регуляризованная логистическая регрессия выбирает вторую политику. Идентификаторы и жанр документов, тип конфликта, истинная область действия и целевая цитата в модель не входят. Обе политики имеют одинаковый бюджет в два чтения.

Разбиение выполнено по компонентам близких текстов, составленным при Жаккаре ≥0,90 по семисловным шинглам. В каждом из пяти фолдов модель получает из четырёх остальных фолдов только примеры, где одна политика нашла цитату, а другая промахнулась. Оценённая вероятность относится к **победе соседа при условии расхождения двух исходов**. Все 449 прогнозов сделаны до запуска отдельного оценщика. Ранее были известны агрегаты этого корпуса, в том числе различия по типу запроса. Поэтому работа является исследовательским групповым cross-fit, внешняя проверка на новом корпусе отсутствует. Среди всех 377 документов с размеченной второй стороной числители Hit@2 те же, у переключателя 49,07%. Размер в байтах относится к возвращённым исходным фрагментам. Out-of-fold (OOF) означает, что для каждого документа оценку дала модель, не обучавшаяся на его компоненте. Первая серия интервалов получена на 10 000 кластерных перевыборок готовых решений. Во второй серии 1 000 раз взвешивали исходные компоненты с возвратом и заново обучали все пять моделей. Ни одна копия компоненты не переходит в другой фолд. Вычислительные файлы проверяют, что при единичных весах процедура воспроизводит исходные вероятности.

При 260 выборах соседа и 11 выборах гибрида только пять из этих 11 действительно изменили второй открытый адрес относительно соседней записи. В оставшихся шести случаях обе политики предложили один адрес. На пяти переключениях случилось одно исправление, один новый промах и три ничьих. Данные показывают малую практическую добавку шести выбранных признаков в данном небольшом корпусе. Интервалы с переобучением допускают как умеренный выигрыш, так и снижение. ## Воспроизведение

Требуются родительские зафиксированные ранги, исходы и аудит компонент. Запуск выполнен на CPU с NumPy 2.5.5 и scikit-learn 1.8.0. В PowerShell из этой папки выполнить команды ниже. Режим проверки строит модели из изолированных временных каталогов с разрешённым набором файлов и сопоставляет каждую вероятность, коэффициенты и запись решения байт в байт. Обучающие данные каждого фолда содержат поля ID и исхода только тех документов, чьи компоненты остались за пределами оцениваемого фолда.

```powershell
python -B freeze.py features
python -B freeze.py training
foreach ($fold in 0..4) { python -B crossfit.py $fold }
python -B crossfit.py seal
python -B evaluate.py
$env:TEMP = (Get-Location).Path
$env:TMP = (Get-Location).Path
python -B verify.py
```
