# Аудит данных ContraDoc для условного поиска второй цитаты

**В основной регистрозависимой оценке допустим 271 документ из 377 с размеченной второй стороной конфликта, или 71,9%.** Это 60,4% всех 449 положительных документов релиза. Поэтому результат поиска имеет два содержательных знаменателя: 271 для измерения выбора среди доступных блоков и 377 для оценки с учётом потерь при подготовке текста. Оставшиеся 72 положительных документа не содержат поля с эталонной второй цитатой. Все 442 отрицательных документа находятся за пределами этой условной задачи. Официальная постановка ContraDoc включает поиск противоречия в документе, а здесь первая сторона заранее известна. [Статья NAACL](https://aclanthology.org/2024.naacl-long.362/) · [Формат и версия данных](https://github.com/ddhruvkr/CONTRADOC/tree/d1c42d1e433595dd6e98fab7b669722cdc050b1d)

## Действительно ли можно доставить вторую сторону одним чтением

Исходный JSON содержит 433 референсные цитаты на 377 строк. В восьми строках поле хранит одну строку вместо массива. Предложения нормализованы теми же правилами NFKC и схлопывания пробелов, что и входные пакеты. Таблица показывает взаимоисключающие результаты дословного сопоставления по документам.

| Доступность хотя бы одной референсной цитаты | Документов |
|---|---:|
| Цитата целиком содержится в одной возвращаемой записи отдельно от якоря | 271 |
| Цитата присутствует в оставшемся тексте на одной стороне якоря, но пересекает границу записей | 49 |
| Совпадение есть в переданном якоре, отдельных доступных цитат нет | 39 |
| В полном тексте не найдено ни одной дословной референсной цитаты | 18 |
| **Всего с разметкой** | **377** |

По самим цитатам целиком доставимы 283 из 433. Из них 247 совпадают со всей записью, 36 — с частью записи. Каждая из 283 встречается ровно один раз в ровно одной доступной записи своего документа. В девяти документах допустимы несколько адресов, поскольку разные эталонные цитаты указывают на разные записи. В 56 документах указано больше одной цитаты. Все перечисленные цитаты доступны по отдельности в 239 из 377 документов. Условие «достаточно одной из нескольких эталонных цитат» соответствует первичному исходу. При диагностическом сопоставлении без учёта регистра основная группа расширяется с 271 до 273. [Подробные счётчики](data-audit.json)

Самая короткая эталонная цитата насчитывает пять слов, медиана — 23, максимум — 104. Три цитаты содержат не больше пяти слов. Пустых или повторяющихся внутри одной строки цитат нет. Четыре различные цитаты повторяются в нескольких вариантах документов одного семейства. Между разными ID-семействами точных повторов референсных цитат не найдено. Словом в этих подсчётах считается непрерывная последовательность Unicode-букв или цифр.

## Насколько независимы исходные семейства

Все 449 ключей положительных документов совпадают с их полем `unique id`. Часть перед последним подчёркиванием выделяет 230 номинальных семейств, размером от одного до семи вариантов. Смешения жанров внутри семейства нет. Полные нормализованные тексты уникальны. После удаления переданного утверждения остаётся 377 различных фоновых текстов. У 135 пар вариантов внутри одного семейства фон совпадает дословно, между разными семействами таких совпадений нет.

При менее строгом сравнении нашлись почти одинаковые документы **между семьями**. Для каждой пары сопоставляли множества последовательных семи слов фонового текста после приведения регистра. При пороге Жаккара 0,90 найдено 320 из 391 внутрисемейных пар и 31 из 100 185 межсемейных пар. Последние связывают 12 пар разных ID-семейств. Объединение связных компонент даёт 218 групп из исходных 230, а в основной выборке — **155 вместо 164**. Порог 0,80 даёт 218 и 155, порог 0,95 — 221 и 157. Это диагностические группы сходства текста. Совпадение шинглов само по себе не устанавливает тождество исходных публикаций. Доверительный интервал с кластеризацией по исходным ID может не учитывать часть зависимости.

В `data-audit.json → document_reuse.map_jaccard90` сохранено полное сопоставление псевдонимов семейств с компонентами при пороге 0,90. Ключ — первые 16 шестнадцатеричных символов SHA-256 от ASCII-строки `contradoc-family-v1|` с дописанным исходным ID до последнего подчёркивания. Идентификатор компоненты состоит из буквы C и наименьшего псевдонима входящего семейства. Группировка использует только текст документов и переданный якорь.

## Граница между прогнозом и проверкой

Повторно вызвали штатную подготовку с полной исходной строкой и с физически удалёнными полями, кроме `text` и `evidence`. Для всех 449 документов совпали записи, адреса и список исключений. Сжатая копия совпала с запечатанным файлом входов байт в байт, SHA-256 `87ca48d451b6c3a5f941c7611eb03eb00c5e9545e6c832e73a4b557f314a6c23`. Аудит использует разметку только для измерения доступности и неоднозначности эталона, не читает прогнозы, эмбеддинги или результаты ранжирования и не пишет во входы предсказателя.
