# Дополнительный контроль объёма переданных текстов

Решение о дополнительной проверке принято до оценки прогнозов. Для всех методов используем первые два заранее выбранных адреса и лимиты 256, 512 и 1 024 байта. Фиксированный общий для методов расход на одну доставленную запись — восьмибайтовый идентификатор, двухбайтовая длина и полный текст UTF-8. Длины записей доступны из локального каталога. Просматриваем оба адреса в выбранном порядке и отправляем запись, если она целиком помещается в оставшийся бюджет. Порядок никогда не пересчитывается после обнаружения размера. Каталог длин, доставка первоначального утверждения, локальное кодирование и выбор адресов исключены из этого вторичного измерения. Метод фиксирует бюджет передачи, но может доставить ноль, одну или две записи.

Для каждого бюджета публикуем число полностью доставленных вторых свидетельств, фактически переданные байты и число записей. На тех же замороженных решениях оцениваем чувствительность парного интервала к повторному использованию практически одинаковых исходных текстов в разных ID-семействах. Группировка близких текстов формируется независимым аудитом до получения результатов.
