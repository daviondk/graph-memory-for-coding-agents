# Воспроизведение выбора действия

1. Восстановить исходные пакеты и таблицу зарегистрированных зависимостей по инструкции [observed_flow](../observed_flow/REPRODUCE_RU.md). В prepare.py указан рабочий каталог на D. При переносе на другую машину нужно указать своё расположение тех же файлов.
2. Запустить `python prepare.py`, затем `python blind_audit.py`. Первый скрипт формирует обезличенные карточки и прогнозные запросы, второй повторяет построение с урезанной таблицей событий. Сверить числа и хеши с selection-lock.json и blind-audit.json.
3. Для нового вывода модели указать локальные пути к файлу Qwen3-4B-Instruct-2507 Q4_K_M GGUF и llama-server в infer.py. Зафиксированы SHA-256 весов, исполняемого файла, ответов и параметры декодирования в reader-lock.json. Локальный запуск `python infer.py` использует три потока CPU, жадное декодирование и грамматику на одну из четырёх букв. Повторные идентичные запросы используют кэш по содержимому.
4. Для повторной оценки сохранённых решений достаточно `python score.py`, NumPy и входных файлов из первого пункта. Скрипт проверяет хеш решений, открывает в SQLite запись для каждого действия и сопоставляет открытый идентификатор с зарегистрированными производителями. В outcomes.json.gz сохранены выбранные идентификаторы, хеш каждого возвращённого нормализованного вывода, число входных токенов и исходы контролей. В results.json сохранены оценки и интервалы.
5. На Windows в каталоге серии используется `python -B verify.py` для проверки компактных артефактов. Повторная проверка прогнозов и агрегированных исходов из архива не требует скачивать модель.
