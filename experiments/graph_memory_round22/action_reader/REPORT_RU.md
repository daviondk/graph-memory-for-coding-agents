# Какую прежнюю операцию откроет агент при одном чтении

В журнале исполнения искали производителя хотя бы одного скалярного значения, которое использовала текущая операция. Один запрос к общей базе возвращал запись одного из четырёх предложенных источников. Проверяли две выдачи при одинаковом бюджете, по 187 токенов в среднем. FIFO предлагала четыре последних записи. Именной индекс учитывал последнее присваивание совпавшему имени, число совпавших имён и значений и расстояние между операциями. Решатель видел только эти числовые признаки и метки A–D. Результат проверялся по версии объекта, зарегистрированной при исполнении.

До сопоставления с разметкой отобраны 77 операций из 21 семейства. У 45 операций из 18 семейств был хотя бы один размеченный скалярный вход. У остальных 32 правильность открытия оценить по этому критерию невозможно. Из 308 намеченных решений получилось 238 уникальных сообщений после точной дедупликации. Каждое из 308 выбранных действий действительно открыло одну запись в SQLite.

| Метод или контроль | FIFO, верных из 45 | Именной индекс, верных из 45 |
|---|---:|---:|
| Qwen3-4B-Instruct-2507, основной порядок | 36 | 41 |
| Тот же Qwen, обратный порядок карточек | 36 | 39 |
| Детерминированное правило по тем же четырём признакам | 36 | 40 |
| В четвёрке есть хотя бы один правильный источник | 37 | 45 |
| Ожидаемое число попаданий при случайном выборе | 11,00 | 13,75 |

Основной контраст Qwen составляет **+11,11 п.п.** в пользу именного индекса, 6 выигрышей и 1 потеря. Описательный парный 95% bootstrap по семействам даёт [2,27; 21,57] п.п. При обращении порядка карточек эффект составляет +6,67 п.п. [−3,70; 18,60]. На именной выдаче Qwen выигрывает у детерминированного правила лишь один случай, +2,22 п.п. [0; 6,67]. Смена порядка меняет выбранный источник в 6 из 45 случаев для именной выдачи и в 7 из 45 для FIFO.

На этих данных заметнее выигрыш от подбора четырёх кандидатов. Признак «последний писатель» близок к процедуре, которой R-регистратор восстанавливает зависимости из языковых выражений. Выборка ограничена операциями с текстовым совпадением и доступными производителями. Поэтому числа характеризуют одно решение о чтении в таком окружении. Остаётся проверить, сохранится ли эффект при другом регистраторе и при нескольких последовательных действиях агента.
