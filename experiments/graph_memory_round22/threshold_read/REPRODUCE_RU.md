# Воспроизведение измерений

Для основной проверки достаточно Python, NumPy и файлов fixture-*.json.gz. В каждой траектории сохранены числовые prior, цены PU, значения калибровки по рангу и упорядоченные идентификаторы для каждого вопроса. Фикстуры не содержат текстов запросов и траекторий. Целые номера обозначают PU внутри своей истории. На машине с исходными кешами ISETrace скрипт prepare.py заново вычисляет каждое число и сверяет полные ранги с R20.

Переносимая проверка сверяет хеши, воспроизводит 16 000 порядков и все счётчики первых четырёх вариантов. Далее она пересчитывает суммарные SQL-счётчики и все опубликованные медианы и p95 из сырых времён. Официальные исходы анализа времени зависят от компьютера, нагрузки и порядка обращений. Для обычной проверки опубликованных данных достаточно первой команды.

```powershell
python -B verify.py
```

Чтобы заново **измерить** время, используйте собственную копию папки. Это сохранит исторические секунды и хеши. Скрипты измерения записывают результаты в каталог исследования. Для приведённого компактного хранилища нужны SQLite и папка на D. Путь можно изменить переменной THRESHOLD_DB_HOME. Первичная база сверяется с ранее зарегистрированным хешем при переиспользовании. Подготовка новой базы из абстрактной числовой фикстуры не требует доступа к исходным текстам ISETrace или нейросетевой модели.

```powershell
python -B check_edges.py
python -B measure.py measure
python -B measure.py stats
python -B sqlite_test.py build
python -B sqlite_test.py bench
python -B native_test.py
python -B sql_report.py
python -B verify.py --seal
```

Нативный повтор использует Windows x64, Python с DLLs/sqlite3.dll и g++ в PATH. native_test.py сам компилирует sqlite_operators.cpp с C++17, O3 и отключённой FMA-контракцией, помещает новую DLL на D и загружает её в отдельном процессе измерения. По имени файла и SHA проверяются версия компилятора, SQLite и полученная бинарная сборка. Скомпилированная DLL остаётся локальной. Контроль каждой выдачи сверяет фактически возвращённые номера PU с числовой эталонной последовательностью. Две линии нативного таймера сохранены под inside_ns и outside_ns.
