# Воспроизведение

Для формирования рангов нужны те же версии и дисковые входы, что в R20 и R21. Используются текущие в момент события подмножества авторских кандидатов и фиксированная модель R20. Восемь исходных шардов сверяются с SHA-256 R18. Выдачи на финальном срезе сверяются с выпущенным R21.

```powershell
python forecast.py
python score.py
```

Файл forecast-plan.json фиксирует состав контролей и хеши; forecast-lock.json фиксирует результаты до доступа оценщика к gold-spans. Для независимой проверки доступны все номера отобранных кандидатов, их наличие на каждом префиксе, исходы всех четырёх политик и числа траекторий в сравнениях. Результаты по 25%, 75%, 100% и исходы по подгруппам вторичные.
