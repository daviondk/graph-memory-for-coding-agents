# Утечка будущего состояния графа при чтении памяти в середине работы

В предыдущей серии фильтрация финального графа по времени теряла ранее доступные обоснования. Проверяем, меняет ли это возможность извлечь всё эталонное свидетельство по графу памяти на строго ограниченном префиксе истории. Исходные 2 000 вопросов ISETrace сформулированы по завершённым историям. Перенос вопроса на более ранний момент — контролируемый replay. Вопрос и его исходные слова не моделируют естественное возникновение той же потребности в середине работы.

На каждой истории определяем по порядку событий контрольные точки 25%, 50%, 75%, 100% от числа замкнутых групп вызовов (округление вверх). До чтения разметки фиксируем связанные с ними префиксы и решения всех политик. На каждом срезе доступны только уже вызванные инструменты и полученные результаты. Для общего исходного поиска ограничиваем список кандидатов теми же видимыми единицами и пересчитываем признаки места в семантическом ранге внутри префикса. Dense-FT здесь двухбашенный, признаки каждой кандидатной единицы независимы от других единиц. Прочие три типа связей ограничиваем видимыми концами. Строим три версии data.feeds: точное состояние счётчика по наблюдавшимся значениям, финальные отношения с видимыми концами и накопительный append-only. Предусмотрен контроль без графа. Роль финальной версии — воспроизвести ошибку ретроспективной реконструкции, она не является доступной реальному агенту политикой. Все варианты с графом используют одни и те же фиксированные веса R20 (обучены на завершённых dev-графах). Официальный prefix и бюджет 2 048 WordPiece.

Основная оценка: разность Full Support между точным префиксом и ограниченным финальным графом при 50% у вопросов, весь эталон которых уже представлен в доступных кандидатах, после исключения 96 ранее изученных историй. Определение возможности покрыть эталон выполняется после фиксации всех решений и проверяет координаты символов. Дополнительно показываем результаты без фильтра ответимости, на всех срезах, против append-only, по Coverage и числу изменённых выдач. Для 100% все прогнозы обязаны повторить прежний эксперимент с завершёнными историями. На первых 48 по заранее записанному хеш-порядку предыдущей панели проверяем все четыре типа рёбер независимой пересборкой авторского физического графа по исходному префиксу. Каждый срез оценивается с парным бутстрэпом на уровне траектории, 10 000 повторов. Результаты по другим срезам и метрикам вторичные.
