# Воспроизведение

На зафиксированной рабочей копии исходного графового ISETrace и R20 сначала воспроизведите полные прогнозы R-GCN без рёбер соседства и веса fine_train. Все численные этапы этого контроля выполняются на CPU. Параметры окружения и версии исходного кода приведены в протоколах R19–R20.

```powershell
./run.ps1
python -B verify.py
```

Очередь ждёт готовности всех восьми исходных шардов, применяет две неизменные политики и независимо запечатывает сначала выбранные PU/блоки, затем реально предъявленные интервалы. После этого открывает эталонную разметку для подсчёта метрик и доверительных интервалов. Проверка из архива не требует запуска моделей. Нужны Python 3.11+, NumPy и имеющийся R18-файл gold-spans.json.gz. Она восстанавливает пересечение объединений символьных интервалов по каждой паре «вопрос—политика» и распределение 10 000 кластерных повторов.
