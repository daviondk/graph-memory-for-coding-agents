# Что сохранять, чтобы дешевле обновлять память

При отзыве одного случайно выбранного исходного фрагмента сохранение первоначальных групп по три потребовало в среднем **247 новых токенов энкодера** на вопрос против **1 013** при повторной упаковке в тройки. Средняя парная экономия 767 токенов, кластерный 95% интервал 650–886. Но точечная оценка качества снизилась с 72,30 до 68,57 Answer F1. Разность −3,72 п.п. [−8,33; +0,30]. Допустимый по данным ущерб существенен для решения о внедрении.

96 вопросов отобраны из 48 статей SQuAD. Для всех методов совпадают текст и порядок доступных источников, начальные состояния двух способов группировки по три идентичны. Удаление физически меняет вход модели. Изменившиеся группы проходят через DistilBERT. Числа ниже учитывают только новые входы после уже оплаченного исходного состояния. Повторяемый текст вопроса входит в стоимость. Каждый новый тензор учитывается вместе с геометрией допустимых цитат.

Перед отзывом стоимость одного полного чтения в тройках 2 421 токен в среднем, у единого потока 3 081, у одиночных наблюдений 2 352. Для одиночных наблюдений в этом наборе сохранившиеся окна полностью совпали с ранее вычисленными. Между исходными и заново сформированными тройками после случайного отзыва совпал ответ в 85/96 случаях, изменение F1 дало 2 победы и 5 поражений исходных троек. В 9/96 случаях случайно отозванная запись содержала исходную победившую цитату. При целенаправленном удалении записи с победителем свежая обработка стоила 338 против 1 885 токенов, F1 разнился на +0,47 п.п. [−3,55; +4,71]. Когда контекст только дополнялся, тройки обоих типов остались одинаковыми.

Выполнено 6 145 уникальных проходов ONNX и 215 независимых контрольных проходов для четырёх вопросов. Проверены совпадения с зафиксированными полными ответами плоского ридера до изменения и после добавления. Количество новых токенов отражает фактическую геометрию входов каждого метода. Оно не равно времени ответа интерактивного сервиса. Выбор размера группы остаётся открытым, как и перенос на изменения настоящего факта в истории агента.
