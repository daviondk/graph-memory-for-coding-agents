# Воспроизведение

В том же окружении ONNX, что и соседнее исследование revoked_evidence, после подготовки R25/R26 и запуска capture.py:

```powershell
python group_reader.py
python score.py
```

Первый скрипт запускает энкодер на всех уникальных входах и записывает ответы без доступа к эталонным строкам. Обработка восстанавливается по идентификаторам вопросов и хешу плана в приватном каталоге D. Ключ совпадения включает все токены и представление допустимых сегментов. Второй скрипт проверяет прогнозы по SHA-256, добавляет официальные эталонные строки, вычисляет стоимость индивидуального обновления из начального состояния конкретного метода и интервалы на 20 000 повторных выборках статей. Поля fresh и fresh_tokens считают уникальные новые окна одного запроса. Токены и время повторного обучения модели не возникают, веса фиксированы.
