# Интерактивная проверка отзыва свидетельства

Для каждого из 96 вопросов можно выбрать отзываемый исходный фрагмент, ранее найденную цитату или произвольный диапазон символов. При каждом обращении локальный сервер выполняет два индексных поиска в реальной SQLite и выводит новую лучшую цитату. В режиме полного отзыва исходной записи рядом показан ранее независимо измеренный ответ модели после физического удаления текста. Для произвольного диапазона интерфейс явно отмечает, есть ли такой независимый прогон.

```powershell
python serve_demo.py
```

Открыть [локальный инспектор](http://127.0.0.1:8079/). Требуется Python 3 со стандартной библиотекой. Координаты, оценки и SQL доступны из поставляемого снимка. Текст вопросов и ответов отображается при наличии официального dev-v1.1.json в каталоге данных проекта на D или при запуске с параметром `--corpus <путь к dev-v1.1.json>`. Порядок и отсчёт символов восстановлены по исходным абзацам. Интерфейс использует предыдущий запуск модели для заранее измеренного сценария. Проверить 288 сохранённых решений, 96 запретов всего источника и обработку запросов HTTP можно командой `python verify_demo.py`. Отдельная проверка действий в Chrome — `node browser_check.mjs`.
