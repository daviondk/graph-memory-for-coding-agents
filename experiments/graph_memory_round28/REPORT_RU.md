# Как память агента переносит исправление уже прочитанного источника

**Самый сильный результат серии относится к хранению.** Для каждого ответа экстрактивного читателя можно сохранить компактный индекс допустимых альтернатив. При запрете цитировать один непрерывный интервал SQLite возвращает в точности ту же лучшую цитату, которую выбрал бы полный перебор с исходными оценками читателя. Для 96 вопросов индекс занимает 108 КиБ, сильный контроль top-64 со сжатыми оценками и досрочной остановкой — 3 836 КиБ. В 28 626 проверках тринадцати реализаций все ответы совпали. Контроль быстрее в медиане. Индекс быстрее на p95. После физического удаления свидетельства читатель может иначе оценить остальной контекст. На 68 из 96 вопросов простой запрет цитирования дал другой ответ, чем повторное вычисление.

## Значение для статьи и границы доказательства

Первичные события можно связать графом происхождения с группами чтения и ответами, зависимыми от конкретной версии. Это позволяет разделить две операции в API памяти. Первая запрещает ссылаться на координаты при прежнем вычислении. Вторая изменяет вход и требует проверки зависимых результатов. В демонстрации посетитель задаёт координаты, видит ответ реальной SQLite и может сравнить его с независимо полученным ответом после удаления, а затем открыть эталон. Само наличие графа не доказывает улучшения поиска по смыслу. На данных SWE и SQuAD сильные простые контроли объяснили ранее наблюдаемый выигрыш ряда эвристик. Превосходство над опубликованными системами памяти по конечному качеству агента остаётся открытым.

Работа Zhang и соавторов дала отдельную проверяемую постановку: два работника могут прочитать конфликтующие факты, а координатор получит один. Наша более ранняя проверка отдельно измеряла передачу исходных фрагментов, служебные байты и решение локального Qwen. В 49 вопросах диагностического режима при одной попытке комбинация передачи обоих свидетельств и положительного решения получилась 21 раз, у E5 — 16 раз. Разность +10,20 п.п. [0,00; 20,75], результаты на этой выборке частично были известны до проверки. Качество на родных Harvey LAB этими опытами не установлено. [Zhang et al.](https://arxiv.org/abs/2611.22245) · [Подробный эксперимент](../graph_memory_round21/handoff/REPORT_RU.md)

Воспроизводимость обеспечивают конфигурации, предварительные планы и хеши прогнозов, исходы по вопросам, исполняемый SQL и сценарии проверки. Запуск `python verify.py` сверяет контрольные суммы и пересчитывает ключевые показатели по сохранённым данным. Входные корпуса и веса доступны по ссылкам внутри отдельных отчётов. ZIP включает локальную SQLite с координатами. Последующие эксперименты STALE, Dependency-Guided Rollback, стоимость построения индекса и пятикратные прогоны графовых моделей учитываются в своих сериях.
