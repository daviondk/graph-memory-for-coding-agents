# Воспроизведение

1. В окружении LlamaIndex серии R27 выполнить native_dev.py. Офлайн-копия NLTK и версия 0.14.26 зафиксированы в sentence-seal.json. Вход содержит только вопросы и тексты 48 статей dev. Для каждого предложения скрипт сверяет текст, смещения, метаданные и штатное окно ±3.
2. В Python 3.12.13 с tokenizers 0.21.4 и ONNX Runtime 1.23.2 выполнить contexts28.py. Он проверяет исходные манифесты, напрямую вызывает замороженную функцию R27 и сохраняет 1 152 набора реально доставленных фрагментов, ширину native и исходного uncased окна, начальные координаты, хеши полного предъявленного текста и число перебранных квот. Исходные тексты остаются в отдельном приватном кэше. Код импортирует неизменные зависимости из соседних серий R25–R27. Проверка служебных заголовков запускается отдельно командой audit_headers.py. [Уточнение аудита](HEADER_CHECK_RU.md)
3. Выполнить predict28.py. Импортируется неизменённая функция read_arm из R26. Она вычисляет логиты с batch 1 на двух потоках CPU. Пара запросов может использовать одни и те же логиты только при равенстве полного вектора входных ID; допустимые сегменты и проверка координат восстанавливаются для каждого запроса заново. По каждому из 576 вопросов сохраняется SHA256 всех нативных окон (включая вопрос и специальные токены), выходные координаты и логическая / физическая стоимость. Обработка может продолжаться из D:/CodexResearch/x20-r28-squad-qa по идентичной конфигурации. Весовой файл проверяется по SHA256. [DistilBERT](https://huggingface.co/Xenova/distilbert-base-cased-distilled-squad/tree/bdbb0a5e9c617c3c7ea9f3cbaf2be3ad871bcd7d)
4. После появления forecast-seal.json и завершения полного аудита запустить score28.py. Он сверяет строку каждого ответа с оригиналом и всеми размеченными координатами, отдельно перепроверяет официальный max-over-references EM/F1 и создаёт per-query.json.gz. Официальный оценщик находится в приватной папке R26, его хеш проверяет импортируемая функция. Исходная полная статья конструируется из штатного порядка абзацев. [Официальный оценщик](https://github.com/allenai/bi-att-flow/blob/498c8026d92a8bcf0286e2d216d092d444d02d76/squad/evaluate-v1.1.py)

В этой постановке область поиска — одна полная статья, исходная память — найденные по статье отрывки. Штатный SQuAD сразу задаёт читателю абзац. Ранее сделанный контроль на тех же 576 вопросах с предоставленным исходным абзацем вынесен в отдельное исследование. [Проверка R26](../../graph_memory_round26/directional_answers/REPORT_RU.md)
