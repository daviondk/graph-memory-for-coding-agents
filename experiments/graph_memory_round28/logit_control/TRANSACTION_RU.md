# Чувствительность к транзакционной границе

После основного результата заморожен дополнительный диагностический контраст с теми же 32 вопросами, тремя событиями и двумя точными методами (sky и zip-64-bound). Будут сравниваться autocommit чтения отдельного SQL-оператора и одна сохраняемая read transaction на весь блок. В обоих случаях используют одну и ту же схему ATTACH и те же БД. Режимы чередуются по 16 блокам; внутри блока каждый сценарий и каждый метод выполняются единожды в случайном порядке. Два прогрева перед включением секундомера. Измеряем 96 пар, p50/p95 по медианам запросов, сохраняем все отдельные измерения. Это отдельная проверка чувствительности конкретной платформы к цене блокировок, файлам и парсеру.
