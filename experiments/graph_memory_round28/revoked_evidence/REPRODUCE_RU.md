# Воспроизведение

В существующем окружении R26 с открытым SQuAD dev, токенизатором и весами из directional_answers выполнить из этого каталога по порядку:

```powershell
python capture.py
python evaluate_views.py
python summarize.py
```

Движок ONNX Runtime использует CPU. Пути модели и входов определены в capture.py и в prepare.py серии R26. План фиксирует хеши входов и исходного кода, порядок 96 вопросов и выбор статей. Для переноса также понадобится подготовленная слепая проекция SQuAD из предыдущих серий. Большие промежуточные массивы двух logit-векторов сохраняются локально на D в каталоге с хешем плана. Снимок содержит предсказания, численные результаты, адреса, хеши и идентификаторы открытых источников. Длительности при повторном измерении зависят от нагрузки. Проверка целостности готового снимка не требует модели.
