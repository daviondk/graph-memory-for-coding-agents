# Что меняется после отзыва свидетельства

Проведены 2 405 полных проходов DistilBERT на CPU для 96 вопросов по 48 статьям SQuAD. Для каждого вопроса добавили фрагменты из уже выполненного следующего чтения и независимо проверили удаление исходного фрагмента с лучшей цитатой. В запросе с удалением убраны все вхождения отозванных координат. Номера вопросов выбраны хешем, правила отзыва и модель зафиксированы до чтения эталонов этой серии. Это повторное использование знакомой панели SQuAD.

**Ограничение на цитирование.** При неизменном входе модели запрещаем выставлять ответом span, пересекающий один полуоткрытый интервал [l, h). Допустимый span [a, b) удовлетворяет b ≤ l или a ≥ h. Сортировка по b и обратная сортировка по a позволяют хранить только места, где меняется лучший ответ. Добавляем к оценке исходный порядок выбора при равенствах. Два поиска по упорядоченным ключам и сравнение двух победителей возвращают лучший разрешённый span точно. Условие применимо к произвольному одному интервалу в том же источнике и к замороженным оценкам. При нескольких запретах часть разрешённых ответов может оказаться между интервалами.

На вопрос приходится в среднем 69 562 допустимых кандидата. Две последовательности смен победителя занимают в средней упакованной записи 637 байт, а исходные массивы оценок — 24 648 байт. В этих числах отсутствуют расход БД на страницы, общие ключи и исходные документы. Реальные размеры БД и сравнение с top-64 + сжатыми оценками приведены в [сравнении SQLite](../logit_control/REPORT_RU.md). При запрете целой выигравшей записи исходный top-64 содержит лучшую альтернативу в 64/96 случаях. При запрете ровно выигравшей цитаты — в 91/96.

**Изменение входа.** После удаления из входа всей записи с первоначальным ответом и обновления оценок совпали лишь 28/96 новых ответов с выбором по старым оценкам. Значение совпадает и для буквального текста, и для его адреса. 95% кластерный интервал для совпадения текста 20,83–38,54%. После такого целевого удаления хотя бы один полностью сохранившийся размеченный span нашёлся только для 10/96 вопросов. Официальный Answer F1 составил 75,10 до отзыва, 12,81 при запрете цитаты и 12,08 при свежих оценках. Эти числа характеризуют чувствительность к удалению свидетельства. Корректность отказа отвечать на утративший опору вопрос здесь не размечена.

**Объём пересчёта.** При добавлении текста у 697 из 901 окон сохранились входные токены и геометрия допустимых span. Для таких окон достаточно прежнего локального победителя. При удалении и повторной упаковке совпали только 59 из 711 окон. На этой раскладке кэш совпадающего префикса воспроизвёл те же счётчики. Упакованный победитель требует около 8 байт на окно сверх ключей, адресов и конфигурации. Общая длина токенов и затраты CPU при разных способах группировки измерены в [следующем эксперименте](../stable_groups/REPORT_RU.md).
