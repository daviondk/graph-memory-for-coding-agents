# Когда стоит открыть следующий диапазон

На SQuAD проверили, можно ли предсказать пользу дополнительного чтения по состоянию до запроса. Использовали фактические ответы экстрактивного DistilBERT, полученные до и после открытия. Разбили 48 знакомых статей по хешу на две половины. Обучили линейную регрессию с регуляризацией на 288 вопросах первой половины. Целевая переменная — изменение официального Answer F1 при чтении. Порог фиксируется на обучающих статьях. Вторая половина содержит 288 вопросов по 24 другим статьям.

| Правило | Вопросов с чтением | Диапазонов | Дополнительных токенов источника в среднем | Answer F1 | EM |
|---|---:|---:|---:|---:|---:|
| Остановиться после первого чтения | 0 | 0 | 0 | 72,75 | 64,58 |
| Всегда читать далее | 288 | 560 | 249,73 | 74,93 | 66,67 |
| Читать при низкой оценке лучшего ответа | 129 | 250 | 112,11 | 75,07 | 66,67 |
| Читать при прогнозируемом приросте F1 | 121 | 236 | 105,19 | 75,12 | 67,01 |

Разница обученного правила и порога по оценке ответа равна +0,05 п.п. F1, кластерный 95% интервал [−1,13; +1,31]. Относительно постоянного чтения разница +0,19 п.п. [−0,93; +1,38]. Порог по оценке ответа проще и даёт близкий результат. 324 обращения к диапазонам удалось пропустить при использовании обученного правила. При заранее равной квоте в 144 чтения эвристика близости исходного span к краю получила 75,19 F1, обученное правило 75,12, порог по оценке 75,07.

При прямой передаче расширенного контекста энкодер обработал 1 000 852 токена. Правило с предварительным прогнозом требует 1 309 309 токенов при полном повторном вычислении и 963 325 токенов при точном повторном использовании окон. Это соответственно +30,82% и −3,75% к прямой передаче. Сокращение чтений из источника само по себе не гарантирует экономии вычислений.

В отдельном инструментальном прогоне выбрали по одному вопросу из каждой из 24 контрольных статей, перемешали порядок пяти методов и выполнили два повтора. 240 запросов дали 2 154 реальных прохода модели. Медиана/p95 полной задержки для прямой передачи 628/704 мс, для обученного правила с кэшем 559/696 мс, при повторном вычислении 559/1 261 мс. Обученное правило открыло продолжение в 4 из 24 уникальных вопросов на этой небольшой панели. На всех 288 это 121/288. Квантили задержки нельзя переносить между такими смесями. Время включает токенизацию, оценку условия, расчёт модели и выбор ответа в одном CPU-процессе. Погрешность измерений и совместную нагрузку машины отражает парное чередование.
