# Воспроизведение

Требуются входы серий R25/R26 и те же веса ONNX и токенизатор, что и в revoked_evidence. Из текущего каталога:

```powershell
python trigger.py
python evaluate.py
python serve.py
python service_summary.py
```

Первый скрипт формирует признаки, обучает модель только на обучающих статьях и фиксирует решения для контрольных вопросов. Второй добавляет эталоны и сравнивает поддержку каждого вмешательства в парном дизайне. Третий воспроизводит полный запрос от токенизации до адреса ответа в перемешанном порядке, проверяет его против сохранённого результата и пишет покомпонентные счётчики. Последний скрипт считает задержку по всем повторам, берёт медиану двух измерений для каждого уникального вопроса и формирует кластерный интервал разности медианных задержек ресэмплингом по статьям. Для сверки готовой серии выполнить родительский verify.py.
