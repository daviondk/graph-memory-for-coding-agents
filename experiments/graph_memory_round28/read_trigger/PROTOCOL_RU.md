# Следует ли читать ещё, когда текущий ответ уже вычислен

Возвращаемся к вопросу, что служит триггером чтения памяти. Для 576 ранее проверенных SQuAD dev вопросов имеются ответы DistilBERT до и после фиксированного двустороннего открытия. Измеряем способность распределить такие открытия там, где они повышают официальный F1. Высокая вероятность ошибиться и возможность улучшить ответ данным конкретным чтением — разные цели. Можно ошибиться, даже если выбранное действие не принесёт полезной информации. Ближайшие работы исследуют калибровку уверенности и цены извлечения. [Selective QA](https://aclanthology.org/2020.acl-main.503/) · [Know Before You Fetch](https://arxiv.org/abs/2606.29959) · [Adaptive-RAG](https://aclanthology.org/2024.naacl-long.389/)

Заранее фиксируем проверку на 24 отложенных по хешу статьях, остальные 24 служат для настройки; по 12 вопросов на статью. Для каждого до нового чтения известны сырой балл лучшей цитаты, длина ответа, положение в уже предъявленном фрагменте, номер фрагмента, число начальных окон, расстояние между ответом и выбранным компонентом для открытия, совпадение координат и лексики на двух его границах. Для оценки возможного улучшения используем линейную ridge-регрессию (штраф 20 после стандартизации, без штрафа на свободный член); целевая величина — F1 после минус F1 до. Контроли: открыть только при низком исходном балле, при малом расстоянии до края фрагмента, обучить то же правило на ошибке начального ответа, случайный хеш, открыть всегда или никогда. Порог — медиана оценки среди тренировочных вопросов; в тесте каждый запрос обрабатывается отдельно. Целевой уровень 50% открытий приблизительный. Сохраняем любые несовпадения реальных долей и токенных расходов.

Дополнительный контроль на одинаковом числе открытий — 144 верхних запроса по оценке каждого из пяти правил на 288 тестовых запросах, без знания ответов. Этот режим требует наличия пакета запросов и отдельно помечен. Основной показатель — F1 на всех вопросах. Фиксируем затраты на чтение, EM, число улучшений/ухудшений, парный интервал по 24 независимым статьям. Основное сравнение — обучение на приросте против сырого балла читателя; рассматриваем также альтернативный объект обучения. Подсчёт стоимости включает стартовый запуск и новые окна после открытия, в двух вариантах — полный перерасчёт и повторное использование побайтно тождественных тензоров при тех же ограничениях на допустимый ответ. Сравниваем с прямым обслуживанием полной памяти в один проход. Итоговые метрики предыдущих систем на этих данных уже известны. Предварительная проверка метода на знакомом бенчмарке не заменяет проверку на новом корпусе.
