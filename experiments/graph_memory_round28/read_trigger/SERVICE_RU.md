# Сколько занимает решение об открытии при живом ридере

После основного анализа фиксируем контроль стоимости. Один вопрос на каждую из 24 тестовых статей по отдельному хешу, без использования эталонов. Два технических повтора. Сравниваем непосредственный ответ по двусторонней памяти, ответ только по исходной памяти, схему с реальным начальным ответом и обученным триггером без кеша, тот же триггер с кешем победителей совпавших окон и простой триггер по исходному баллу с тем же кешем. Процесс использует одни веса ONNX и токенизатор, кеш окон сбрасывается между методами и вопросами. Таймер включает подготовку и токенизацию строки, фактические вызовы ONNX, вычисление лучшей цитаты, признаков и решения, сборку ответа при повторном чтении. Исходная статья в оперативной памяти. Обращения к внешнему серверу или диску с документами не моделируем. Варианты внутри блока перемешаны, одинаковые вопросы и проверенные координаты. Основной контраст этой дополнительной панели — фактический двухпроходный отбор с кешем против непосредственного обслуживания сразу расширенного контекста. Локальное время сопоставимо в пределах данной конфигурации. Нулевая или отрицательная экономия публикуется вместе с основными результатами.
