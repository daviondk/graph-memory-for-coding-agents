# Проверка и восстановление

На стенде используется Python из D:/CodexResearch/x20-r8-swerank-runtime/venv/Scripts/python.exe с PyArrow. Запустите fetch_sources.py, затем formats.py и project_stale.py. Если нужны заново библиографические метаданные и результаты современных поисковых API, sources.py работает отдельно. Новые результаты поиска могут различаться. Инвентаризация формата требует около 1 ГБ дисковой памяти с учётом проекции. Весь новый кэш расположен в D:/CodexResearch/x20-r28-retraction. Проверенный LongMemEval-S переиспользуется из D:/CodexResearch/x20-longmemeval-dretr/longmemeval_s_cleaned.json.

В подпапке stale-projection/history каждая из 400 исходных историй записана в отдельный gzip-файл, в questions.json находятся 1200 индивидуальных запросов. Публичный скрипт blind_reader.py получает идентификатор вопроса и возвращает только его текст, последовательность сессий, время и адресуемые исходные реплики. Папка evaluator хранит старое и новое утверждение, правильные адреса и рубрику. Реальный независимый исполнитель должен получать по одному output функции read_one, без доступа к исходному файлу STALE и к оценщику. Код очистки допускает только заранее перечисленные поля.

Авторы STALE публикуют набор под CC BY 4.0 и включают атрибуцию LongMemEval. Эта локальная проекция переименовывает идентификаторы, хранит исходные сообщения отдельно от эталонных полей и сохраняет хеш каждой получившейся истории; для распространения производного набора нужно сохранить атрибуцию авторов и лицензии оригиналов. [Данные, лицензия и файл атрибуции](https://huggingface.co/datasets/STALEproj/STALE/tree/617c51dc200b5ab09970834144c7e51c77959af0).

Файлы formats.json и blind-seal.json воспроизводимы из выпущенных авторами данных, без вызова модели. В машинном журнале discovery.json сохраняются фактические ответы и ошибки внешних поисковых API. Источники отобраны по следующим семействам запросов — HaluMem operation-level update / original_memories, LongMemEval knowledge-update / haystack_session_ids, MemoryAgentBench Conflict_Resolution / FactConsolidation, memory invalidation / retraction / rollback provenance, obsolete facts in agent memory, recoverable addressable context folding, gist memory / recoverable spans, budgeted execution-provenance memory. Включены первичные исследования с доступной постановкой и, для аудита данных, первичный репозиторий или release. Не включены неофициальные leaderboard-копии, пересказы и агрегаторы. Названия, авторы и идентификаторы четырнадцати работ извлечены с первичной страницы arXiv и сверены через DataCite. Результаты поиска используются для обнаружения работ; они не доказывают полноту охвата.
