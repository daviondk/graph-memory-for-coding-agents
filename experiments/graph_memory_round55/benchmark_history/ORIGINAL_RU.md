# Исходная цена позиции в официальном бенчмарке

Дополнительно повторяем сравнение на той же выборке при исходном учёте позиций авторского Lexical. В этом режиме уже известный якорный файл занимает позицию, если его вернула поисковая система. Используем сохранённый top-20 до исключения якоря. Сохраняем первые четыре исходные позиции, в пятой правило из расширения допускает файл за пределами исходной двадцатки. Согласование требует ещё одного адреса помимо якоря в первой четвёрке. История, множество файлов, границы по первому родителю, пороги и парная оценка те же. Дополнительно проверяем, что исходный контроль совпадает с результатами официального оценщика по каждому вопросу. Выборка содержит 54 из 58 задач.
