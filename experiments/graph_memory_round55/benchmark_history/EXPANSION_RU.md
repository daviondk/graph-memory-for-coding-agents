# Доступ за пределы первой двадцатки

Расширение предложено после получения нулевой разницы при перестановке пятого адреса внутри лексического списка. Все 54 базовых ревизии/задачи остаются теми же (42 различных ревизии). Проверяем следующую причину: история может содержать полезный адрес, который вообще отсутствует среди первых двадцати лексического поиска. Фиксируем основной вариант до извлечения и оценки новых прогнозов.

Сохраняем первые четыре новых файла Lexical. Рассматриваем только реальные пути из корпуса соответствующего base. Для каждого исторического эпизода размером 2–20 с наблюдаемым якорем кандидат за пределами двадцатки получает обычное свидетельство. Если в эпизоде также встречается хотя бы один из **первых четырёх** лексических адресов, кандидат получает ещё признак согласования нескольких источников. Эти четыре адреса предложены поиском и не содержат разметки. Основной вариант допускает кандидата с минимум двумя эпизодами либо минимум одним согласованным эпизодом. Среди допустимых выбираем по сумме 1/(m−1), затем по числу согласованных событий, затем по самому недавнему свидетельству и по пути. При отсутствии допустимого кандидата сохраняется пятый адрес Lexical.

Сравнения: неизменённый Lexical, правило двух эпизодов, наличие хотя бы одного эпизода и частота в любых прошлых эпизодах на том же внешнем множестве при том же факте открытия доступа, что у основного метода. Учитываем испытания по всем 54 задачам, отдельно число изменившихся списков, недостающих в первой двадцатке эталонов и их покрытия кандидатами. Это исследовательское расширение предыдущей постановки на уже использованной выборке, с отчётом обо всех вариантах и без выбора метода после оценки.
