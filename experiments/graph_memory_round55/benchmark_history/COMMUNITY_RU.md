# Перенос правила на открытые внешние поисковые системы

После наблюдения +1,54 п.п. на 54 задачах с Lexical фиксируем проверку неизменного правила с другими публичными исходными списками. Берём все пять вариантов CodeNib и все три опубликованных прогона последней доступной в зафиксированном сравнении Oko 0.9.1. Параметры согласования, окно Git и формулу выбора не меняем. Одна и та же панель проверяет зависимость от поисковой системы. Новых задач здесь нет.

Изначальный top-20 каждого метода формируем из его сохранённого полного ранжирования после исключения уже известного адреса, повторов и адресов вне официального каталога. При более короткой выдаче сохраняем фактически доступный бюджет (если менее пяти файлов, обе политики получают идентичный список). На тех же адресах вычисляем Recall@5, Hit@5, MRR@5 с исходным и расширенным поиском. Для Oko усредняем три прогона внутри задачи перед кластерной оценкой по репозиториям. Разные прогоны одного случая не являются независимыми наблюдениями. Отдельно проверяем исходный метаотчёт каждого автора в его собственном режиме на 58 задачах. Сопоставляем гипотезу о добавке к каждому базовому поиску с абсолютными оценками. Сравнение с агрегатами иных выборок не доказывает лидерства.
