# Какие события о файле стоит сохранять

На шести других проектах история совместных изменений снова улучшила предсказание остальных файлов правки при одном известном пути. На 880 многофайловых коммитах Recall@8 выросла с 29,58% у частоты до 34,75% при поиске по локальным связям последних 32 коммитов. Использование всех прошлых наблюдений за тем же путём дало 48,83%. В этом сравнении именно короткое общее окно теряло полезные связи.

## Откуда взяты запросы

Использованы зафиксированные публичные HEAD для attrs, pytest, pip, Flask, HTTPX и jsonschema. В первоначальной записи протокола организация проекта attrs была указана как `attrs/attrs`. Этот адрес вернул 404, его исправили на официальный `python-attrs/attrs` до чтения путей и расчёта результатов. Проекты отличаются от шестёрки основного опыта R55. Каждый дал 576 последовательных переходов от первого родителя. Первые 64 — общая инициализация. В оставшихся 3 072 переходах было 880 допустимых многофайловых коммитов. Один коммит pip превысил лимит 64 путей. Данные включают 4 171 возможный известный путь в этих 880 коммитах. [SHA и контрольная сумма протокола](pins.json) · [Входные последовательности](commits.json.gz)

Проверялась задача из литературы о совместных изменениях. Одна из затронутых целей сообщается агенту, его выдача ограничена восемью **другими** путями. До формирования ответа доступна только предыдущая история. Новые целевые пути учитываются как пропуски. Ранжирование одинаковых локальных баллов использует частоту за последние 32 коммита, затем ID. Весь префикс означает всю историю **от начала наблюдения**, включая 64 коммита прогрева. В основном измерении индекс SHA выбирает одну подсказку на коммит. Третий числовой столбец сначала усредняет результаты по всем возможным подсказкам одного коммита, затем по 880 коммитам. Метрика — средняя по коммитам доля скрытых целей в top‑8. Число учтённых записей относится к логической опоре прогноза. Взвешивая одинаково проекты, получили разность «локальные W32 минус частота» +4,68 п.п. (описательный парный бутстрэп проектов [2,27; 6,84] п.п., 20 000 повторов). По сравнению с накопительной ассоциацией у W32 −12,40 п.п. [−19,92; −4,96]. У последних восьми событий с известным путём против полного префикса — −0,39 п.п. [−2,19; 1,54]. При том же лимите случайный исторический отбор дал близкие результаты. Гипотеза об особой ценности **давности после обращения к тому же пути** пока не получила подтверждения. Эти интервалы построены всего по шести проектам и не являются формальным тестом не меньшей эффективности.

Вывод для системы памяти — отдельное ограничение истории на каждый изучаемый объект сохраняет больше полезных сведений, чем короткое окно по всему потоку: даже редко затрагиваемому пути остаются доступны связанные прежние правки. При переходе от всего префикса к восьми событиям средняя логическая опора по выбранному якорю уменьшилась с 9,55 до 4,90, Recall@8 — с 48,83% до 48,14%. Публикационный вопрос о стоимости такой памяти требует измерения постоянного размера материализованных связей и их обновления, а прикладной эффект — проверки на работе решателя.
