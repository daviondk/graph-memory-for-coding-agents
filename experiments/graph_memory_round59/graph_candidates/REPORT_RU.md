# Что даёт один дополнительный кандидат из графа прошлых действий

Проверка на **33 задачах из четырёх целиком других репозиториев** SWE-ContextBench Lite показала, что замена пятого кандидата истории может ухудшить результат. Релевантный опыт присутствовал в исходной пятёрке на **28/33** задачах. После замены одного места глобальным поиском по прежним чтениям и изменениям — на **26/33**. Основанный только на тех же вершинах поиск тоже дал 26/33. Настоящие рёбра изменили семь пятых позиций относительно вершин и один финальный выбор модели, при этом по каждой задаче сохранились те же оценки. [Предварительный протокол](PROTOCOL_RU.md) · [Все метрики](results.json)

**Выборка и постановка.** До открытия оценок выбран 33-элементный набор обычных задач из Django (29), Flask (1), Requests (2) и Pylint (1). Эти проекты и целевые ID полностью отделены от [предыдущих 57 задач](../agent_benchmark/REPORT_RU.md). По остальным 9 из 42 официальных Lite-вопросов вне выборки 57 результаты двух опытов не объединялись и общая точность на всех 99 не оценивалась. Оба опыта используют выпущенные 300 исходных сессий и один и тот же набор авторских связей «новая задача — допустимая прошлая задача». Прошлые работы в репозитории уже сообщали агрегаты по всему Lite. Это проверка переноса нового правила между проектами, а не новый независимый бенчмарк. [Первичная статья](https://arxiv.org/html/2602.08316v3#S3.T5) · [Закреплённый выпуск](https://huggingface.co/datasets/jiayuanz3/SWEContextBench/tree/12c65bd15e2559bc808065565e941ee7bbbd008f)

**Правило выдачи.** Первые четыре места сильного прежнего гибридного ранжировщика fusion фиксированы. На пятое место можно вернуть прежний пятый результат или выбрать один любой подходящий эпизод из всей библиотеки вне этой четвёрки. Для 254 разрешённых прежних сессий было построено представление путей и до четырёх идентификаторов из изменений для каждого редактируемого пути, в том числе добавлено 84 исторических сессии из новых групп. Совпадения с публичным описанием задачи ранжируются по IDF. Графовая добавка учитывает, наблюдалась ли пара различных совпавших имён по разные стороны одного настоящего перехода `Read → Edit`. Контроль с перестановкой сохраняет степени рёбер, плоский контроль сохраняет только имена и адреса. Между вопросом и ответом требуется ровно пять различных кандидатов, среди них один выбирает та же локальная Qwen3-4B-Instruct-2507, с равными входными бюджетами и без показа графа. Изменившиеся наборы действительно были предъявлены модели заново. [Выбор всех пятых позиций](decisions.json.gz) · [Списки и выбор модели](scored.json.gz)

| Метод | Есть релевантный эпизод среди пяти, Hit@5 | Средняя доля всех релевантных в пяти, Recall@5 | Релевантен первый эпизод, Match@1 |
|---|---:|---:|---:|
| Исходная пятёрка fusion, текущий Qwen 4B | 28/33 | 83,3% | 15/33 |
| Пятое место из глобального поиска по вершинам, Qwen 4B | 26/33 | 78,8% | 12/33 |
| Пятое место из настоящих рёбер, Qwen 4B | 26/33 | 78,8% | 12/33 |
| Пятое место из переставленных рёбер, Qwen 4B | 26/33 | 78,8% | 12/33 |
| Fusion до чтения моделью | 28/33 | 83,3% | 17/33 |
| Исходный BM25 по полю результата прошлой сессии | **30/33** | **90,9%** | 20/33 |
| Авторский hybrid Recall, закреплённая реализация | 25/33 | 75,8% | 15/33 |
| Сохранённые ответы Qwen 27B на его исходной пятёрке fusion | 28/33 | 83,3% | **22/33** |

Истинные рёбра дали то же пятое место, что переставленные, на всех 33 задачах; пересчёт подтверждает, что баллы хотя бы одного кандидата различались при этом на 25 задачах. В основной паре «истинные рёбра — те же вершины» изменились 7/33 выбранных пятых мест, но не релевантность. Сравнение с исходным fusion более существенно. Пятое место изменилось в 30/33 случаях. При этом извлечён один дополнительный авторский ID на вопросе, где уже был другой правильный опыт, и потеряно по одному правильному ID на двух других задачах. Так объясняется разница между Hit@5 и Recall@5. Для Hit@5 относительно исходной пятёрки парная разница −6,06 п.п. (0 улучшений, 2 потери, остальные 31 без изменения), точный двусторонний знаковый тест p=0,50. По Match@1 (+1, −4) разница −9,09 п.п. (p=0,375). Основной сопоставимый читатель здесь — 4B, старший 27B оценён только на своей сохранённой исходной пятёрке. При 29 из 33 задач одного проекта перенос результатов требует отдельной проверки. [Парные результаты и проектные оценки](results.json)

**Почему одно место оказалось недостаточным.** Общая неизменная четвёрка уже содержала правильный эпизод на 26/33 задачах. Для остальных семи все правильные ответы были представлены в исходной официальной библиотеке. В шести был хотя бы один разрешённый граф правильной сессии, в четырёх он проходил фиксированный порог двух редких совпадений. Их ранги среди претендентов на единственное пятое место составили 5, 8, 8 и 11. Эта диагностика выполнена после получения ответов. Она указывает два разных ограничения — для части вопросов нет доступного лексического свидетельства, для остальных простая схема не ставит нужный прошлый случай первой. [Независимый поштучный пересчёт](audit.json)

**Воспроизводимость.** На 132 назначения потребовалось 68 различных новых GPU-ответов, всего 74 130 входных и 136 выходных токенов. Каждая ветвь использовала 36 177 входных токенов на все 33 задачи, некорректных ответов не было. Вход проверен по SHA, прежние ответы 27B не переносились на модифицированные наборы. `python -B audit.py` перепроверяет действительные равные бюджеты, степени и первые десять альтернативных мест по сохранённым историческим графам. Для полной генерации используются зависимости и исходные кэши из [родственного опыта](../agent_benchmark/REPORT_RU.md). В чистой копии исходников запустить `python -B select_slates.py`, `python -B answer.py`, `python -B evaluate.py`, `python -B audit.py`. Публикация REM оценивает весь Lite, прямого сравнения SOTA на этой выборке нет.
