# Репликация на шести ещё не измеренных историях

Первичный механизм число+XOR выиграл по суммарным байтам у полного упакованного списка на двух ранее использованных плотных панелях при 1 КиБ. Проверяем перенос без подбора параметров. До загрузки результатов фиксируем шесть публичных Python-репозиториев: Textualize/rich, numpy/numpydoc, marshmallow-code/marshmallow, jaraco/inflect, python-pendulum/pendulum и PyCQA/isort. Ни один не входит в реестр ранее использованных панелей истории R55–58. Извлекаем последние 1 024 перехода первого родителя либо всю доступную историю, учитываем Python-пути. Сохраняем SHA и проверяем список путей независимо от вывода git log по деревьям Git. Не подменяем проект в зависимости от количества запросов или результата. Репозитории выбраны целенаправленно и не представляют случайную выборку всего GitHub.

Сохраняем оба расписания и все параметры R59/reconcile. Первичное сравнение — сумма post-restart байтов SQLite у XOR против полного упакованного списка при 1 КиБ, плотное расписание. Дополнительно все четыре алгебраических/упакованных и два исходных контроля, 4 КиБ, редкий режим, результаты по каждому проекту. Предусмотрено сравнение ссылок на события с копированием того же состава при доступной неизменяемой истории. Качество ранжирования должно остаться точным. Отдельно покажем число проектов с выигрышем/ничьей/проигрышем. Исходный результат, если он отличается, приводится рядом. Используем только деревья и изменения адресов; содержимое исходного кода не нужно.
