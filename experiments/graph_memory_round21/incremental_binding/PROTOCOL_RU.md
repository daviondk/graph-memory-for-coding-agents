# Когда вывод инструмента перестаёт быть однозначным источником?

В ISETrace направленное ребро data.feeds связывает вывод с последующим вызовом, использовавшим обнаруженный в нём идентификатор. Условие авторского builder требует единственного производителя значения во всей обработанной истории. Поэтому по мере поступления событий меняется обоснованность уже записанных рёбер. У пары источник–приёмник может быть несколько независимых значений-свидетелей.

До расчёта задаём 96 первых тестовых траекторий по SHA-256 от префикса incremental-feeds-v1 и ID. В каждой берём замкнутые префиксы после завершения всех ожидающих вызовов. Выбираем ближайшие сверху ранги к 25, 50, 75 и 100 процентам списка этих границ и устраняем повторы. Официальный builder в каждой точке получает только накопленные события. Сопоставляем множества направленных рёбер data.feeds, без размножения по текстовым чанкам. Публичный тест содержит сконструированные исполненные OS-истории; действия воспроизводятся как данные.

Сравниваем три хранилища. Потоковое хранилище считает число действующих значений, обосновывающих пару. При появлении второго производителя отнимает только его прежнее обоснование и снимает ребро, когда счётчик становится нулевым. Контроль append-only сохраняет когда-либо созданные рёбра. Дополнительный ретроспективный контроль фильтрует граф конца истории по границе уже видимых событий. Этот контроль имеет доступ к будущему и служит мерой искажения при подобном воспроизведении.

Основная метрика — доля промежуточных срезов (кроме последнего) с несовпадением хотя бы одного ребра с пересборкой авторского builder. Дополнительно измеряем FP/FN по рёбрам, расхождения в финале, число снятий и стоимость состояния в элементах. Считаем точные исходы по каждой траектории и 95% бутстрэп-интервал с пересэмплированием целых траекторий. Доля промежуточных срезов, на которых все три метода совпадают, допустима как исход. Этот тест семантики обновления сам по себе не измеряет качество ответа LLM. Публикуются только непрозрачные идентификаторы траекторий, размеры, хеши и агрегаты.
