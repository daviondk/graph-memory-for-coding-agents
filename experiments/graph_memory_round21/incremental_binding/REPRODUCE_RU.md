# Воспроизведение

В окружении Python для ISETrace нужны исходные восемь шардов, официальный GraphMemory на зафиксированной ревизии и расположенные рядом серии R18, R19 и R20. Код использует те же пути и контрольные суммы, что residual_graph/setup_graph.py. Исходные события передаются индексу последовательно. Эти команды воспроизводят срезы, прогнозы читателя и независимый этап оценки.

```powershell
python evaluate.py
python predict_readout.py
python score_readout.py
```

В plan.json находятся состав панели и хеш кода до расчёта. В prefix-outcomes.json.gz представлены данные по срезам, отметки несовпадений и изменения количества обоснований. В readout-lock.json хранятся SHA-256 результатов принятия решений для последующего открытия разметки. Предыдущие данные R20 о качестве всей выборки использованы только для перекрёстной проверки исходного читателя.
