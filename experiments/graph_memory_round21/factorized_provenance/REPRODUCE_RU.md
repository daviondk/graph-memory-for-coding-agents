# Воспроизведение

Используется Python из окружения R20 с NumPy, sklearn и исходной библиотекой GraphMemory. По умолчанию две базы создаются под D:/CodexResearch/x20-factorized-provenance. Для новой копии задайте FACTORIZED_DB_ROOT равным новому пустому каталогу. Рядом с серией ожидаются R19 и R20, сохранённые эталонные решения typed_reader и частные кэши исходных графов и Dense-FT.

```powershell
python study.py
python benchmark.py
```

Первая команда независимо проверяет полные рёбра, признаки и решения, затем сохраняет базы и контрольные суммы. Вторая повторно открывает обе базы, проверяет их SHA-256, измеряет стоимость парными повторами, сохраняет планы SQL и поштучные времена. Файл projection-lock.json фиксирует реализацию, входы и исходные веса. Время выполнения может меняться в зависимости от нагрузки. Размеры относятся к указанной в results.json версии SQLite и приведённой схеме.
