# Воспроизведение расширенного контроля

Сперва восстановите R19–R21 по инструкциям в основном каталоге пяти seed и подготовьте официальный split и графы в R22. Требуется Python 3.12 с `sys.monitoring`, нативный ISETrace из зафиксированного коммита и среда первоначального R21. Обучение использует RTX 3090, оценка весов — FP32.

1. В каталоге этого исследования выполните `python -B control.py plan` один раз до дополнительных запусков. Хеши исходного скрипта обучения, локального и полного split, авторского evaluator и протоколов хранятся в исходном и дополнительном планах.
2. Запустите `../run_580.ps1` вместо старой очереди. Файл использует общую блокировку исходного R21, ожидает обе нативные модели R20 и переиспользует результаты уже завершённых этапов. Все временные и численные артефакты размещаются на D.
3. Для seed 13 очередь сравнивает две независимые реконструкции исторических 500 dev с агрегатами исходного обучения и выполняет полный официальный dev580 для каждой эпохи. Для новых seed наблюдатель `control.py fit` сохраняет результаты авторского dev500 во время обучения. Затем `control.py select` запускает официальный dev580 у обученной эпохи. Исходные E5-веса общие. Их идентичность и метрики dev500 проверяются для каждого seed.
4. `python -B link_test.py SEED` выдаёт SHA и ссылку на строго парные тестовые массивы. При разном выборе создаётся отдельный cache и расчёт в подкаталоге `alternative`. Для проверки архива достаточно `python -B verify.py` на любом Python 3.11+. Основной проверяющий скрипт R21 отдельно восстанавливает по пермутациям тестовые метрики.

Контроль поставляет все четыре массива исходов по вопросам для каждого завершённого seed. Индивидуальные ответы теста и промежуточные результаты выбора эпохи R-GCN в эксперимент не входят.
