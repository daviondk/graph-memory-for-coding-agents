# Пять независимых обучений

Рассматриваем один заранее зафиксированный факторизованный prior на графе действий, калибруем семантический ранг отдельно внутри каждого исходного train. Структурные веса едины для всех seed. Две политики внутри пары получают один и тот же обученный Dense-FT и те же PU. Для каждого вопроса и seed сохранён полный порядок источников. Траектории и вопросы повторяются между seed, поэтому размер теста составляет 2 000 вопросов.

## Попарное изменение

Расчёт сначала усредняет внутри каждого вопроса разность по готовым seed, затем пересэмплирует траектории. Результат выражен в п.п. с 95% интервалом.

- coverage_512 3,47 [1,97 … 4,95]

- coverage_1024 4,43 [3,04 … 5,82]

- coverage_2048 4,64 [3,46 … 5,80]

- full_support_2048 5,47 [4,16 … 6,74]

- recall_5 6,35 [4,98 … 7,69]

- mrr 7,63 [6,40 … 8,82]

- coverage_auc 3,10 [2,31 … 3,88]

- full_support_auc 3,60 [2,81 … 4,37]

Включённые seed — 13, 17, 29, 37, 41. У исторического seed 13 исходные Dense и factor порядки проверены полным повторным CPU-проходом, все метрики сверены по каждому вопросу. До пяти seed результаты остаются промежуточными. Для статистического сравнения с residual R-GCN требуются пять согласованных массивов исходов этой модели.
