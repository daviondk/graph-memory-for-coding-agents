До панельных измерений добавлена отдельная проверка нативного поля NTFS ChangeTime через GetFileInformationByHandleEx(FileBasicInfo). Оно отражает изменение метаданных файла. При формально одинаковых размере, времени последней записи и идентификаторе этот источник может всё ещё отличить запись того же файла от прежнего наблюдения. Запишем и сравним поведение пакета метаданных с этим полем, количество повторных чтений, байты и стоимость обращения к ОС. Предположение ограничено фиксированным томом NTFS, последовательными операциями, правильным контекстом сессии и конечным диапазоном этого опыта. Добавляем контроли на штатный повтор без объявленной context_epoch и после начала новой сессии, в которых прежний источник текста недоступен.
