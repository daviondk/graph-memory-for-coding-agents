# Проверка на опубликованных переходах версий

После контролируемой серии, до извлечения файлов следующих версий, фиксируем дополнительную панель. Включаем все старые подходящие Python-файлы по прежним правилам, без ограничения до трёх файлов на проект. Сопоставляем один и тот же путь на зафиксированных выпусках Click 8.1.7 → 8.1.8, attrs 24.2.0 → 24.3.0, Hypothesis Python 6.112.0 → 6.112.1 и PyYAML 6.0.2 → 6.0.3. Если отсутствует файл, помечаем выбытие и показываем знаменатель. Обновляющий процесс записывает только файлы с действительно разными опубликованными байтами, обычной локальной записью без навязанных временных меток. Это сочетание естественного изменения содержимого со смоделированным способом применения выпуска на NTFS. Политики mtime+size, с идентификатором и с NTFS ChangeTime сравниваются с подлинным OctoFS whole-view и повторным чтением. Параметры остаются неизменными. Эта панель оценивает естественную долю изменившихся файлов среди выбранных путей, не частоту ручного сохранения метаданных в работе кодовых агентов.
