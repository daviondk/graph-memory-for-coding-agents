# Воспроизведение

В папке эксперимента выполните `python -B audit.py`. Достаточно стандартной библиотеки Python и сохранённых файлов. Независимая проверка заново применяет изменения, возвращённые реальным MCP, к ранее полученному тексту. Проверяются все 468 нативных ответов в контролируемой части при повторном чтении, 413 начальных и повторных нативных вызовов внешней панели и 1240 оценок всех локальных и нативных политик. Скрипт записывает results.json.

Полный прогон выполнялся на томе D с NTFS и Python 3.14.4. Команды в отдельной рабочей копии:

```powershell
python -B acquire.py
python -B mcp.py
python -B experiment.py
python -B natural.py
python -B audit.py
```

acquire.py проверяет официальный SHA релизного архива и сохраняет исходники и исполняемый файл в vendor. Для сбора нужны только открытые GitHub, arXiv и Hugging Face. experiment.py и natural.py запускают отдельные процессы штатного MCP и последовательного писателя. Все изменения идут в scratch. На другой ОС NTFS-вариант требует соответствующего нативного источника версии. Фиксированные входные файлы, их лицензии и фактические исходные пары упакованы. Большие исполняемые и временные файлы, рабочие копии vendor и scratch не входят в манифест. Оригинальная лицензия инструмента — Apache 2.0. Текущий состав локального поиска описан в local_history.json. Точные затраты времени при новой записи меняются.
