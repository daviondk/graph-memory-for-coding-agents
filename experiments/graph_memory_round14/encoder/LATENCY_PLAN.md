# Измерение цены одиночного обращения

До оценки фиксируем вторичный замер для 12 непустых меню. Внутри каждой панели из каждого доступного диапазона размеров 1, 2–3, 4–8, 9+ берём первые два события по SHA256 от идентификатора. В первичной панели используем первые два из первых трёх диапазонов и одно из последнего. В повторной панели — по одному из первых трёх диапазонов и первые два из последнего. Это целевой срез малых и крупных меню, его медиану нельзя переносить на натуральную частоту. Стоимость на том же CPU сравнивается при загруженных весах, с одним прогревочным примером. Измеряются запрос из условия и промаха с закешированными векторами файлов и, отдельно, кодирование всех документов меню. Сумма даёт цену холодного меню. Оба сценария учитывают умножение скалярных оценок и сортировку. Также отдельно замеряем три вызова исходного алгоритма R13 для всех 340 префиксов без GPU. Отдельного права на вход при пустом меню у модели нет; новый вектор для такой строки не вычисляется.
