# Дополнительный аудит до раскрытия новых исходов

До открытия меток фиксируем разбиение меню по числу доступных документов: 0, 1, 2–3, 4–8, от 9. Проверяем, какую долю случаев две системы вообще ранжируют по-разному, и сколько равенств RRF на первом месте разрешает давность. Для контраста RRF(dense,graph) с RRF(dense,strong) приводим чувствительность к равному весу задач. Его первичная оценка остаётся взвешенной по событиям с кластерными интервалами. Страты нужны только для описания, по ним не меняем параметры.
