# Внешняя оценка до вскрытия меток

Главный исход — реальное успешное открытие файла на исходной версии, который затем влитый PR модифицировал, удалил или изменил по типу. Фиксируется ровно определение R13: первый родитель SHA фактического merge тождествен base из бенчмарка и по времени не позже merge. Из существовавших Python-файлов исключаются тесты, документы и примеры. Неуспешное открытие засчитывается промахом. Задачи без надёжной пары либо подходящего production-изменения выводятся в потоке исключений. Главный контраст — named минус pair. Для той же задачи и того же меню также сравниваются named с однопутевой рекомендацией и с независимым выбором. Разбивка по альтернативным исходам описательная.

Перед сбором проверяются присланные SHA выборов, входов и фактов чтения. Ни модель, ни её подсказка не получают состояние после начала работы. Оценщик отдельно извлекает первый успешный просмотр файла в течение пяти следующих инструментальных действий, тем же парсером и среди того же корня, что в R13. Свидетельства с пустым либо неявно адресованным ответом и списки файлов туда не входят. Это диагностический поведенческий исход.

При сравнении показываются выигрыш/проигрыш/совпадение по независимым задачам, число смен реально прочитанного адреса и точный двусторонний парный sign test среди непротиворечивых бинарных итогов (дискордантных пар). Процентильный интервал по задачам вычисляется отдельно, 10 000 повторных выборок с фиксированным seed 22113; если все наблюдаемые эффекты одинаковы, его вырожденность не исключает неопределённость популяции. Эффект касается предъявления идентификатора в выбранном меню при конкретном решателе. Разнообразие репозиториев, доступность правильного адреса, присутствие имени в общем контексте и полные расходы регистрации сохраняются для интерпретации.
