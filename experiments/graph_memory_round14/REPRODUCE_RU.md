# Как проверить результаты четырнадцатой серии

Для чтения основных результатов достаточно распакованного архива и таблиц каждого опыта. Команда `python package_local.py <архив> --verify` пересчитывает общий манифест SHA-256 и проверяет все пять внутренних манифестов. Для нового прогона используйте отдельный рабочий каталог. Значительная часть скриптов обращается к историческим исходникам и наборам на диске D.

| Исследование | Пересчёт и первичные данные |
|---|---|
| Предобученный поиск | В [инструкции](encoder/REPRODUCE_RU.md) описан повтор по записям и полноценный вывод на CPU. Веса SweRankEmbed-Small в ZIP не включены. Сохранены идентификаторы весов, конфигурация, скаляры и порядки до разметки. [Проверка всех методов](encoder/verify.py) |
| Подсказки действующему решателю | `python grounded/prepare.py` с pyarrow строит меню, `python grounded/solver.py` вызывает локальный Qwen с нативным read_file и сохраняет содержательные SHA реальных чтений. Нужны R12/R13 и исходные публичные траектории. При воспроизведении сначала прочитайте [условия](grounded/PROTOCOL_RU.md). Для индивидуальных ответов доступны [квитанции оценщика](grounded/REPORT_RU.md). |
| OctoFS на NTFS | [Условия и версии компонентов](ledger/REPRODUCE_RU.md) · [Наблюдаемый результат](ledger/REPORT_RU.md) |
| Перенос на Linux | [Среда Alpine WSL2, ext4 и tmpfs, команды проверки и strace](linux_replay/REPRODUCE_RU.md) · [Наблюдаемый результат](linux_replay/REPORT_RU.md) |
| Выбор рабочего снимка | Нужны неизменённые эпизоды R12 и запечатанный поток R13. Порядок выбора и границы наблюдаемости зафиксированы в [протоколе](anytime/PROTOCOL_RU.md). В [отчёте](anytime/REPORT_RU.md) ссылки на индивидуальные состояния и проверки. Каждая новая версия оценивалась тем же штатным оценщиком, идентичные состояния сопоставлялись побайтно внутри задачи. |

Тестовые образы, скрытые входные файлы оценщика, полные репозитории зависимостей и модели остаются внешними зависимостями. Публикуемые небольшие записи содержат хеши, исходы отдельных случаев, код и условия сравнения.
