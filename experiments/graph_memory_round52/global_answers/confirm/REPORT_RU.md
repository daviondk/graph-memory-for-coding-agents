# Внешняя проверка на 512 вопросах с новыми первыми адресами

На 512 ранее не задействованных вопросах официального train Qwen3-4B-Instruct-2507 Q4_K_M получил **38,14 Answer F1** при обучаемом выборе второго адреса и **37,94** при фиксированном осторожном правиле. Два метода выбрали разный второй документ всего один раз. Первичная разность составляет **+0,195 п.п. [0; +0,587]**, дополнительный точный двусторонний тест перестановки знаков по первому документу даёт p=1. Такой результат не позволяет предпочесть обучаемый переключатель осторожному правилу.

| Переключатель и резервный переход | Answer F1 | EM | Все эталонные документы среди двух чтений |
|---|---:|---:|---:|
| Логистическая регрессия, обученная на dev; резервная ссылка | 38,14 | 32,03 | 220/512 |
| Независимое название при наличии and/or вне первой сущности; резервная ссылка | 37,94 | 31,84 | 219/512 |
| Независимое название; резервная ссылка | 37,31 | 31,25 | 215/512 |
| Независимое название; резервный поиск буквального названия | 34,70 | 28,52 | 173/512 |

Сравнение двух последних правил выделяет роль подтверждённой ссылки при одном переключателе. Answer F1 вырос на **2,61 п.п. [1,07; 4,28]**, 25 выигрышей и 11 поражений. На предыдущей панели dev размер этого эффекта был +1,43 п.п. с пограничной статистической устойчивостью. Обучаемое правило против фиксированного без условия and/or дало +0,825 п.п. [0,195; 1,650]. Эти сравнения вторичны, без поправки на множественность.

Исходная совокупность — 2 400 вопросов 2Wiki train, отобранных по идентификаторам, тексту вопроса и отсутствию первого адреса в предыдущем dev. Независимый аудит по прежним экспериментам сократил её до 2 374. Перед получением предсказаний сохранён хешированный список из 512 ID. Первый адрес повторился один раз, поэтому для интервалов — 511 кластеров. Одна GPU RTX 3090. Первый и второй документ ограничены 192 нативными токенами каждый, длина второго выровнена внутри вопроса между всеми четырьмя политиками. Средние длины составили 102,29 и 89,92 токена. Из полного корпуса реально открыты 650 различных вторых страниц. Зафиксированы 721 уникальная генерация и 2 048 присвоений ответов политикам. Во всех режимах официальный v1.1 scorer воспроизвёл Answer F1 и EM. Для 155 вопросов у эталона были дополнительные допустимые формы. Во всех интервалах 10 000 парных перевыборок по первому адресу.

Дополнительная более узкая проверка того же обучаемого правила при замене только резервной связи и проверка всех адресных расхождений 2 374 вопросов описаны в supplement/REPORT_RU.md. У этих опытов собственный порядок выравнивания длины и независимые файлы результатов.

Для воспроизведения на машине проекта запустить из этой папки `python prepare.py`, `python answer.py`, `python evaluate.py`, `python audit.py`, `python ../signflip.py --confirm`. Требуется собранная global_confirm с prediction-seal.json, novelty.json и соответствующей директорией входов. Источники, параметры и SHA256 — в registration.json, texts-seal.json и input-seal.json. Полные токены запросов и фактические ответы лежат в prompts.json.gz и answers.json.gz, поэпизодные баллы — в records.json.gz. Политика и первичный контраст зафиксированы в PROTOCOL_RU.md и ADDENDUM_RU.md.
