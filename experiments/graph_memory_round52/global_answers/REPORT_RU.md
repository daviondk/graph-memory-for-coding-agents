# Ответы модели после двух чтений из полного каталога 2Wiki

На 384 вопросах, отобранных хешированием из всего dev, Qwen3-4B-Instruct-2507 Q4_K_M получил 32,72 Answer F1 с резервным переходом по явной гиперссылке и 31,28 с резервным поиском буквального названия. При фиксированном правиле выбора второго источника это **+1,43 процентного пункта**, парный 95% интервал **[+0,018; +2,986]**. Нижняя граница близка к нулю. Дополнительный точный двусторонний тест перестановки знаков по первым документам дал p=0,06358 (26 ненулевых кластеров, 67 108 864 сочетания). При пороге 0,05 вывод зависит от способа оценки неопределённости. На 122 вопросах методы выбрали разные статьи. По F1 зафиксировано 17 выигрышей, 9 проигрышей и 358 ничьих. Сравнение с безусловным предпочтением гиперссылки дало больший эффект, +7,33 п.п. [3,75; 10,95].

Прямой адрес означает второе название в вопросе, удовлетворяющее фиксированному правилу глобальной политики. При отсутствии такого адреса первые два варианта используют наблюдения из уже прочитанного документа. Буквальное совпадение названия и подтверждённая ссылка способны указывать на разные документы. Предсказания на полном dev и его метрики покрытия были известны перед фиксацией этого опыта. Фактические ответы читателя были закрыты. Поэтому это проверка связи показателя покрытия с ответами на уже исследованной совокупности вопросов.

Первые тексты идентичны для всех вариантов, по вторым документам берётся одинаковое число нативных токенов в пределах каждого вопроса. Из подтверждённого авторского ZIP заново прочитаны 654 разные вторые статьи. Средние длины первого и второго контекста — 112,78 и 85,38 токена, средний полный запрос — 273,53. Для 1 152 назначений действительно сгенерировано 715 уникальных токенизированных запросов, одинаковые запросы используют один результат greedy decoding. Вычисления прошли на RTX 3090, quant Q4_K_M. Скрипт авторов версии 1.1 воспроизвёл округлённые метрики для всех трёх методов. Для 216 вопросов официальные aliases или demonyms добавили формы к основному ответу. 10 000 парных выборок bootstrap по 379 уникальным первым адресам. Вторичные эффекты EM и покрытия приведены в results.json. Официальный joint score с предсказанием предложений поддержки в этом опыте не измерялся.
