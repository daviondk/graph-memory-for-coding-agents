# Минимальная история выбранного адреса с восстановлением оценки

На данных первого опыта известны 3 840 начальных адресов, 752 изменения адреса и 5 822 строки журнала оценки. Из этих чисел арифметически следует нижняя граница в 4 592 строки при хранении непересекающихся интервалов постоянного ID и поиске предшественника для каждого запроса. Здесь проверяем физический SQLite-оператор, который достигает границы онлайн и отвечает как ID, так и точной исторической оценкой. Последнюю можно восстановить по исходной записи кандидата и моменту одноразовой активации связи. Прирост оценки текущего победителя не требует новой строки истории адреса.

До измерения фиксируем первичные величины: совпадение пары (ID, двоичная оценка) со свежим ранжированием на всех 80 314 ретроспективных чтениях после 18 006 атомарных обновлений и размер полного файла SQLite после WAL checkpoint на общем наборе из 3 840 вопросов. Контроли: базовая таблица кандидатов с полным перерасчётом, сильный частичный индекс, предшествующий журнал изменений победившей оценки. Дополнительный контроль хранит те же сроки, что исходный журнал, в виде логгируемого адреса и времени без столбцов оценки/приоритета, чтобы различить физический вклад колонок и числа строк. У всех одинаковые базовые записи; порядок загрузки и первоначальные PRAGMA совпадают. Публикуем также размеры после VACUUM. База данных не требует переноса в оперативную память для обслуживания.

Отдельно фиксируем пример одновременных активаций: промежуточный лидер меняется и прежний успевает вернуть лидерство в той же транзакции. После commit в минимальном журнале должна остаться только смена итогового лидера между полными версиями. Проверяем повторное применение совершенной транзакции, откат и переоткрытие. Публикуем урезание записей и реальную разность размера файла даже при проигрыше индексу без истории. Предположение — базовые оценки фиксированы, видимость монотонна, чтение относится к уже зафиксированной версии. Поддержка отзывов связи и полной истории значений всех кандидатов — другая задача.
