# Цена исторического чтения после построения

После полного измерения размера файлов фиксируем дополнительное сравнение заранее относительно задержек. Весь набор 3 840 вопросов, законченные снимки; на каждый вопрос выполняется одно обращение к каждому допустимому префиксу, включая нулевой. Два контракта: только адрес и адрес вместе с его исторической оценкой. Три физических плана: предыдущий журнал оценки, минимальный журнал адресов и сильный покрывающий индекс eligible. Готовые SQLite-таблицы и соединения прогреты. Единый список обращений стратифицирован по вопросам; на каждом из 8 повторов случайно переставляем порядок шести вариантов и 32 блоков со всеми вопросами. Длительность включает вызов SQLite, получение tuple и добавление в список, проверка по эталону за пределами таймера. По каждому контракту считаем отношение суммарных задержек и парный интервал перевыборкой повторов и одинаковых блоков (10 000 bootstrap). Публикуем обе задержки независимо от направления эффекта. Идентичное построение баз и контрольные суммы результатов проверяем отдельно. Стоимость построения и вставок в эти измерения не входит. Вычислительная машина общая; порядки рандомизированы, проверка не даёт аппаратно независимой гарантии задержки.
