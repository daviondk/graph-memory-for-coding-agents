Source-linked evidence views

Trace a title across Wikipedia →

Compare an independently named title with an observed hyperlink, and inspect the evidence for the next read.

Rewind a source read →

Reveal a mention, rewind to an earlier version and compare the stored winner with a fresh SQLite query.

Rank the next source →

Compare two trained readers, suppress a mention and inspect the selected title and its observed answer.

Replay a policy change →

Choose two graph-reading policies and inspect which reader calls determine their difference in Answer F1.

Choose a second source →

Compare two candidate titles, adjust the mention bonus and inspect the recorded answer.

Learned evidence packets →

Change the point in the history and verify which fragments can be ruled out before exact selection.

Streaming packets →

Advance a real tool history, inspect the rows reused after a source change and verify the selected evidence.

Execution traces →

Change the token budget, exclude a source and audit the selected evidence.

Code edits →

Compare file and range invalidation, then verify the line addresses against both file versions.

Edit context →

Change the validation rule and see which observations the editor’s own arguments can preserve.

Value transfer →

Step through observed tool calls and verify when a once-unique source becomes ambiguous.

Source weight →

Adjust a source score, inspect the switching point and verify the full packet.

Two sources →

Compare separate and simultaneous changes, then verify the selected evidence.

Observed updates →

Replay a recorded source update, isolate individual producers and verify the combined packet.
