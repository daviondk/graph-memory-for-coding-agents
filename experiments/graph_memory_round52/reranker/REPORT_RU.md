# Даёт ли ребро пользу после попарного семантического ранжирования?

На 1 280 вопросах HotpotQA добавление признака «заголовок упомянут в уже прочитанном тексте» к обученному ранжировщику с Qwen3-Reranker-0.6B повысило полноту набора опорных заголовков с 63,13% до 65,55%. Парная разность **+2,42 п.п.**, 95% ДИ **[+1,17, +3,75]**. Читатель получил 57,90 против 57,37 официального Answer F1. Для этой заранее выбранной основной метрики разность **+0,53 п.п. [−0,23, +1,30]**, двусторонняя рандомизация знаков p = 0,178. Результаты совместимы и с небольшим улучшением, и с отсутствием эффекта для ответа. На второй панели из 1 280 вопросов 2WikiMultiHopQA при добавлении ребра разность F1 составила **−0,12 п.п. [−0,62, +0,37]**, а полное покрытие заголовков выросло на **+0,47 п.п. [−0,16, +1,09]**. ## Что сравнивалось

Агент получает вопрос, один прочитанный фрагмент и каталог видимых заголовков. Он выбирает ровно один следующий документ. Все остальные тела закрыты для селектора. Восемь правил на каждом вопросе имеют один первый источник, общую длину второго фрагмента в токенах и одинакового читателя Qwen3-4B-Instruct-2507 Q4_K_M. Оба компонента Qwen выполнялись на RTX 3090. Дополнительные оценки для каждой пары «вопрос + прочитанный фрагмент, кандидатный заголовок» дал опубликованный Qwen3-Reranker-0.6B в квантовании Q4_K_M. Сопоставляется конкретная реализация ранжировщика в заданном режиме чтения. Формат, отбор заданий и лимиты отличаются от рейтингов open-domain QA. [Работа авторов модели](https://arxiv.org/abs/2506.05176) · [Контрольная сумма конверсии](checkpoint.json)

Обучили две линейные модели по одной и той же попарной логистической функции потерь, 6 356 пар с метками из 640 прежних калибровочных вопросов 2Wiki, одинаковый вес каждого вопроса и L2 = 1. В обеих моделях шесть признаков — косинус Qwen3-Embedding-8B, его обратный ранг, два обратных лексических ранга (вопрос и фрагмент), сырой балл Qwen3-Reranker и обратный ранг по этому баллу. Полная модель также получает индикатор наличия наблюдаемой связи. Обе модели независимо обучены с нуля на калибровке. Изменение результата оценивает добавление признака при повторном обучении остальных коэффициентов. У коэффициента ребра значение 0,745 для стандартизированного признака, то есть при фиксированных прочих значениях переход 0 → 1 прибавляет 2,803 к попарному линейному баллу. Для прямого выбора по CE и для двух правил «всегда упомянутый» обучение отсутствует. При пустом списке упомянутых правилу доступен весь каталог. Средний recall эталонных заголовков для полного и сокращённого гибридов составил соответственно 78,09% и 76,52% на HotpotQA, 89,22% и 88,98% на 2Wiki. Уровень предложений в этой метрике не оценивается. На 10 вопросах 2Wiki и 65 вопросах HotpotQA новые политики выбрали короткий документ, поэтому пришлось уменьшить единый лимит относительно R51 и пересчитать ответы всех затронутых условий. ## Сколько дают сильные контроли

На HotpotQA замена чистого Qwen3-Reranker полным гибридом даёт +1,73 F1 [ +0,83, +2,66 ], замена правила «всегда упомянутый» по этому же ранжировщику +2,08 [ +1,15, +3,04 ]. Сравнение с «всегда упомянутый» по embedding даёт +0,80 [−0,41, +2,04]. Полный и сокращённый CE-гибриды выбрали разные документы на 111 вопросах. Из них замена изменила F1 в 40 случаях, 24 выигрыша и 16 потерь. На 2Wiki у тех же вариантов 32 замены, 7 выигрышей и 7 потерь. По сравнению с гибридом R51 без ребра добавление двух признаков CE к такому же гибриду дало +1,96 F1 на HotpotQA [ +0,50, +3,44 ] и +1,53 на 2Wiki [ +0,52, +2,57 ]. Интервалы для дополнительных сравнений номинальные. Можно объяснить часть прогресса улучшением качества обычного ранжирования. Для изменившегося результата всего гибрида остаётся открытым вклад каждого сигнала. [Все девять сравнений на каждом наборе](results.json)

## Почему улучшение покрытия не всегда повышает F1

На HotpotQA было 33 вопроса, где признак ребра позволил покрыть все эталонные заголовки, а F1 ответа остался тем же. Первый такой вопрос в порядке исходных ID спрашивает, в каком городе находится школа при Сычуаньском университете. Первый документ про эту школу уже называет Чэнду. Гибрид без ребра затем открыл *Chengdu No.7 High School*, а полный гибрид открыл эталонный *Chengdu*. Второй фрагмент в обоих случаях имел 94 токена, полная подсказка — 260. Покрытие выросло с 1/2 до 2/2, но оба раза читатель выдал точный ответ *Chengdu*. Это задокументированный механизм расхождения метрик для данного примера. [Привязка к поштучным данным](case.json)

## Объём измерений и границы

Ранжировщик реально оценил 28 715 пар за 391,7 с суммарного времени обработки всех трёх панелей при четырёх конкурентных запросах. Сервер учёл 6 467 953 входных токена. Медианное время одного HTTP-запроса по всему кандидатному каталогу при этой конкурентности составило 489 мс для 2Wiki и 495 мс для HotpotQA. Обе модели с признаками CE используют общий набор вычисленных оценок. Для 20 480 назначений читателю (2 560 вопросов × 8 правил) понадобилось 3 758 различных подсказок. Для 3 259 уже были ответы идентичного читателя на тот же полный массив токенов, 499 новых ответов реально сгенерированы за 55,1 с после подготовки входов и проверки. Шесть повторов оценивания по полным каталогам дали те же баллы, 24 повтора читателя дали те же строки, длины и тип остановки. Аудит перепроверил выбор, длину и общую часть каждой подсказки, исходы и агрегаты. [Аудит](audit.json) · [Воспроизведение](REPRODUCE_RU.md)

Выборка использует замороженные панели train-разделов. Текущий протокол зафиксирован до вычисления новых CE-баллов, но исходы прошлых методов на обеих панелях были известны при проектировании. В 10 000 парных bootstrap-повторах единица перевыборки — вопрос с уникальным первым документом. Некоторые вторые документы и отвлекающие материалы повторяются. Тест закрытого лидерборда, перенос между читателями, точность полноформатного читателя и качество задания на реальном кодовом агенте здесь не измерены. Уровень доказательства для статьи — локальный сигнал улучшения выбора источника на HotpotQA и явная оценка его неопределённого вклада в качество ответа при сильном контроле.
