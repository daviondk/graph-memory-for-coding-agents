# Вклад видимой связи поверх отдельного Qwen cross-encoder

До вычисления новых оценок фиксируем первичную разность официального Answer F1 на всех 1 280 вопросах HotpotQA из подтверждения R51. Обе версии исходной гибридной модели получают два дополнительных признака — сырой балл Qwen3-Reranker-0.6B и обратный ранг этого балла. Ребро является седьмым признаком только в полном варианте. Обучение обеих моделей отдельно: исходные 640 вопросов 2Wiki semantic_address, та же попарная логистическая потеря, равный вес вопроса, L2=1 и стандартизация по обучающей панели. Контроли: ранжирование замороженным cross-encoder без обучения, лучший упомянутый по cross-encoder (иначе свободный cross-encoder), лучший упомянутый по исходному dense (иначе dense), исходный плотный ранг, обе ранее обученные R51 модели. Вспомогательный исход — полнота пары подтверждающих заголовков. Заранее предусмотрена вторая панель из 1 280 вопросов 2Wiki gate_confirmation. Ранее опубликованные ответы и описание этих двух панелей известны; для этого нового сравнения нет утверждения о полностью незатронутом тесте.

Веса Qwen3-Reranker-0.6B (автор Qwen, сторонняя конверсия gorse-io Q4_K_M, SHA256 5290f5b9a2636be40baf807feafcfb222e0c4670a083fb3447d87993566190a9). Ранжируем все оставшиеся заголовки, один проход по каждому кандидату. По одной группе на вопрос в нативный API llama.cpp v1/rerank. Запрос — дословная инструкция, вопрос и видимый префикс первого документа, как у плотного R50. Кандидат — только заголовок. Шаблон пары и классификационную голову задаёт GGUF и закреплённый бинарник llama.cpp. Равенства CE и основного обученного балла разрешаем старым плотным рангом. Результаты запроса записываем до открытия обучающих меток и фиксируем все решения до открытия ответов на новые промпты.

Читатель Qwen3-4B-Instruct-2507 Q4_K_M, разрешены два документа. Для каждого вопроса общий префикс первого документа и конечный системный суффикс сохраняются. Ограничение второго документа для всех восьми правил равно минимуму прежней общей длины R51 и реально доступных длин новых кандидатов. Ранее записанный ответ повторно используем только при полном совпадении токенов и спецификации читателя. Для остальных обращаемся к GPU; повторяем заранее выбранные исторические проверки. Проверяем оба официальных оценщика. Для первичного и вторичных контрастов 10 000 парных bootstrap повторов вопросов, внутри панели все первые документы уникальны; вторичные интервалы номинальные. Для первичного дополнительно двусторонняя смена знака, все структурные нули входят в знаменатель. Публикуем обе панели полностью, включая отсутствие эффекта и сравнение с безусловным следованием видимой связи. Замер времени ранжировщика включает нативную обработку/HTTP по одной группе и исключает подготовку/вызов читателя.
