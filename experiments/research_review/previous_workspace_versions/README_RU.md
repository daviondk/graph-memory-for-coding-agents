# Память агентов. Официальные тесты и контрольные эксперименты
Все числовые итоги в Word сопровождаются файлами по отдельным вопросам, задачам или запросам. В папках protocol / PROTOCOL хранятся локальные протоколы с контрольными суммами. Они фиксируют порядок работ в этом исследовании; это не внешняя регистрация. Модели и полные сторонние датасеты загружаются по зафиксированным источникам. Расходы на архивные прогоны поставщиков не известны.
- comparators — перепроверка открытых списков Papr и gbrain и готовых авторских оценок ответов. Варианты разметки и бюджет получения результата указаны в comparison.md. verify_official.py проверяет вывод официальным кодом.
- dretr — полный запуск BM25, Contriever, Stella и абляций на LongMemEval-S. Два разных определения эталонных сессий. см. README.md.
- boundary — слепое перераспределение пяти позиций с открытыми рангами Papr, включая нулевой результат и отдельный бюджетный эксперимент. Команды в README.md.
- action и action_text — две формы выдачи решений на одних и тех же 34 программных задачах с 196 сессиями. Локальные исходные ответы, задания, приговоры исполняемых проверок и отрицательные контроли сохранены. Запуск второй формы следует за диагностикой первой. Попытки не складывать в 68 независимых наблюдений.
- coding и coding_holdout — поиск участков кода в SWE-Explore в исходных снимках репозиториев. Подробности в примыкающих протоколах и README. Полные снимки и зависимости отдельно.
- retainer — оригинальный след обращений и реализации алгоритмов из публикаций, перенос на стоимость группового чтения. Файлы логов на уровне запросов сжаты. Описание в README_RU.md.
- MANIFEST.sha256 — контрольная сумма каждого файла, кроме самого манифеста. verify.py — пересчёт основных таблиц из сохранённых записей без сети. Для перезапуска моделей нужны их веса; те же фиксированные ответы можно оценивать офлайн.
Каждая таблица предназначена для указанной метрики и состава наблюдений. Документ, ZIP и материалы предшествующего этапа хранятся отдельно.
