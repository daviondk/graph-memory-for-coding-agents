Материалы к обзору «Память кодового агента между задачами»

sources/evidence.jsonl — одна самостоятельно аннотированная работа на строку. Поля содержат тему, первичную ссылку, авторов, библиографический ключ, дату, статус использованной версии и глубину проверки. Оригинальные аннотации сюда не копировались.
sources/technical-and-project-sources.json — программы конференции, документация Codex, проектные отчёты и открытые данные отдельно от библиографии исследований.
sources/agent-memory.bib — библиография для Zotero, BibTeX или менеджера статей.
search/database-results.json — параметры запроса, URL, количество найденных и фактически выгруженные названия и идентификаторы. Четыре запроса в каждой из двух баз. Пагинация OpenAlex остановлена на первых 50 ответах каждого запроса.
search/web-searches.json — запросы адресного веб-поиска. Для пакетных запросов список адресов относится к выдаче пакета целиком. Попадание в выдачу не означает включения в обзор. Уточняющие переходы к первоисточнику и поиск метаданных могут отсутствовать в этом журнале.
audit/trace-results.json — выбранная ревизия и 64 пути к трассам, извлечённые тестовые команды с итогами, сводные счётчики.
audit/initial-strict-counts.json — первый вариант без обёрток перенаправления и усечения вывода. После просмотра правила расширены, отбор траекторий прежний.
audit/audit.py — самодостаточный скрипт для Python 3.10+. Для воспроизведения из каталога audit с доступом к публичному Hugging Face выполнить python audit.py. Скрипт печатает JSON; при сравнении использовать значения полей, а не кодировку внешней оболочки. Он только читает структуру и наблюдаемые события готовых трасс. Команды из чужих траекторий не исполняются. Скрипт не вызывает моделей.
protocol/experiment.txt — проект будущего испытания с контекстами, контрольными группами, абляциями и критериями оценки. Ссылки вида [[2611.17316]] соответствуют полю id в evidence.jsonl, текстовые ключи — дополнительным источникам.
protocol/codex-exec-help.txt — локальная справка исполняемого файла Codex на момент проверки. CLI 0.169.0-alpha.11.1. Изоляция и отсутствие посторонней памяти — отдельная часть дизайна стенда.
manifest.json — масштабы поиска и границы применимости.
audit/anchor_sensitivity.py и audit/anchor-sensitivity.json — дополнительный анализ поиска по пути к тестовому файлу. В каталоге audit выполнить python anchor_sensitivity.py trace-results.json. Сравнение проводится на общих 93 событиях. Результат описывает наличие кандидатов независимо от хронологии.

Для продолжения работы сначала открыть обзор и выбрать вопрос, затем найти карточки конкурентов по short_name. Уточнять приоритет по актуальным публикациям. Исходные заметки авторов исследований и фактические исходы тестов отделять от предложения автора обзора.
