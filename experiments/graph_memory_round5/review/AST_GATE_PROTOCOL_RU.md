# Чтение по синтаксически подтверждённому использованию

Дополнительный эксперимент серии 5, зафиксирован рецензентом до получения таблиц исходов и до чтения целевых строк. Размеры подгрупп известны по видимым входам A/B. На момент фиксации часть GPU-запросов A уже выполнена. Это тест нового правила на существующих запечатанных альтернативах с известными размерами выборок, а не полностью независимая репликация раунда.

Для одного и того же репозитория сравнить две уже замороженные подсказки. Вариант выбирает edge, только если на соответствующей строке найдено прямое использование статического имени как получателя метода либо создание экземпляра этого типа по AST (strong из AST_PROTOCOL_RU.md). Иначе выбирает local. Разрешать имена вне файла или запрашивать дополнительный контекст правило не может. Других порогов нет. Исходы берём из raw GPU-запроса точно той ветви, которую правило выбирало бы. Новых генераций для такого воспроизведения не требуется, если итоговый запрос и seed идентичны.

Основная диагностическая панель B, отобранная на наличии изменяющей ввод ссылки. A — проверка на общей выборке. В каждой панели сообщить размер, число переключений, точные совпадения и среднее расстояние (сходство Indel ES) и затраты в токенах, долю и разности против local и edge. Правило нельзя адаптировать по этим ответам. Учитывать реальную стоимость построения AST отдельно, нельзя объявлять ускорение системы по токенам.

Нулевой контроль выбирает столько же изменяющих ввод рёбер случайно, сохраняя число на каждую из четырёх страт. Точную вероятность получить не меньший наблюдаемый прирост EM считаем по двумерной гипергеометрии из числа положительных, отрицательных и нейтральных исходов над local. Общая нулевая статистика — сумма выигрышей минус потери. Также привести парное точное двустороннее p для сравнения с local и отметить малое число различающихся исходов. Сравнение показывает отличие выбора рёбер от равной нормы чтения и не создаёт независимую выборку.
