# Существовала ли в той же памяти более содержательная строка

Дополнительная проверка R5 по видимым входам, с уже известной разметкой ранее выбранной строки. Для каждого A и B оставляем тот же первый узел, все прочие ранее доступные кандидаты и исходное написание названия типа. Ищем среди этих кандидатов все синтаксически непосредственные создания объекта этого типа или вызовы метода, получателем которых буквально служит имя типа. Доказательством служит Tree-sitter Java, правила как в audit_ast.py. Число задач, где подходящее место существует, сравним с числом задач, где исходный лексический выбор уже показал такое место. Разность оценивает доступность альтернативного свидетельства при том же пуле. Это верхняя граница покрытия выбранного синтаксического критерия, а не оценка правильности ответа генератора. Показать число различных проектных узлов, числа дополнительных задач и политику, по которой оценивается наличие использования. Эталонная строка и генератор не используются.
