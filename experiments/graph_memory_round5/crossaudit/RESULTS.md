# Независимая проверка переноса на CrossCodeEval Java

Программу оценки зафиксировали до открытия целевых продолжений на обеих панелях. После фиксации решений сверили SHA-256 каждого ответа и полного текста каждого запроса. Четыре метрики каждого наблюдения пересчитаны двумя способами. Первый выполняет неизменённые функции авторов для Java из коммита 40c68d2b, второй написан отдельно. Результаты совпали на всех ответах и на вспомогательной выборке из 5000 случайных пар строк. SHA-256 исходников и прямые URL находятся в upstream.json. [Реализация CrossCodeEval](https://github.com/amazon-science/cceval/tree/40c68d2b7ca2a8eae95d901ac80e6a540a84a53d/scripts) · [Описание бенчмарка](https://crosscodeeval.github.io/)

В E 2139 задач из 239 проектов. На 2047 входах обе процедуры реально формируют один и тот же запрос, и общий результат декодирования даёт нулевую попарную разность. На 92 оставшихся входах порядок отличается. Исходы посчитаны для всех 92. Поэтому общая разность определена точно и в знаменателе остаются все 2139 задач. Отдельные абсолютные значения на всём E для каждого метода не вычислялись. Из 92 изменившихся входов 90 принадлежат ранее не сопоставлявшимся проектам. В D и E повторяются все 96 задач D, включая пять изменившихся подсказок. Эти панели статистически зависимы.

По EM на полной панели E выигрышей 1, потерь 4. Парный 95%-й интервал с повторной выборкой проектов от -0,421 до 0,078 п. п., двусторонняя кластерная знакоперемена p = 0,500. Интервал описывает перенос между проектами; разность на фиксированном тесте известна. В independent_results.json также приведены интервалы для вторичных метрик, различающихся входов и панели D. Входные веса моделей, число токенов и генерации зафиксированы родительским экспериментом.

## Особенности проверки

Для Java код авторов обрывает ответ на первом символе ; или фигурной скобке (на позиции ноль исходная функция оставляет целое продолжение). После удаления комментариев EM сравнивает списки непустых строк с удалёнными краевыми пробелами. ES вызывается через fuzzywuzzy 0.18.0 с difflib, без необязательного ускорителя Levenshtein; на каждой паре он округляется до целого, затем усредняется. ID EM сравнивает упорядоченные списки идентификаторов, включая повторы. ID F1 сравнивает множества и даёт ноль при двух пустых множествах. Возможные открывающие Markdown-ограды удалялись по правилу официального chat launcher. Оно затронуло 0 из 216 уникальных ответов D и 0 из 184 ответов E.

Воспроизведение из каталога crossaudit — python independent.py score, затем python audit_report.py. В D_independent_rows.jsonl.gz и E_independent_rows.jsonl.gz сохранены оценки по каждой задаче. Внутренние строки метрик используют шкалу [0,1], сводные таблицы — [0,100].
