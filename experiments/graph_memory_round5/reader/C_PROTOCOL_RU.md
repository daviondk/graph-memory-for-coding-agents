# Вторая попытка чтения после собственного черновика
Фиксация до генерации C0 и до доступа к целевым строкам C. На отдельных проектах собираем до 24 задач в каждой из четырёх страт по независимому хешу, по одной строке на проект. Исключаем 192 проекта A/B и контент по тому же фильтру видимых данных. Первая попытка C0 получает только локальные строки. Её фактический ответ используется для адресации памяти. Финальный генератор видит тот же обычный промпт, черновик влияет только на поиск и выбор окна. Сохраняем для каждого условия конечный адрес, причину переключения и токены обеих стадий. Эталонные метки открываем после запечатывания всех финальных ответов.
Четыре условия. head получает первые 256 токенов фиксированного первого кандидата графа, без черновика. static_focus оставляет тот же адрес и с помощью черновика выбирает окно. draft_lex ищет объявление по BM25 по токенам трёх недавних строк и черновика, затем применяет то же окно. verified ищет связи объявления класса и метода с вызовами в черновике. Причины выбора в порядке приоритета — совпадение типа получателя и метода, однозначная ссылка на конструктор, уникальное имя метода среди кандидатов (отсеиваем распространённые имена Java), далее исходный порядок графа. Если сигнала нет, сохраняем первый адрес. Кандидаты и бюджет 256 токенов одинаковы. При возможном нежелательном содержимом черновика запрос к памяти ограничивается исходным контекстом.
Основной контраст C — точное совпадение verified против draft_lex, парный двусторонний тест Мак-Немара и 95% парный bootstrap. Самостоятельная поисковая проверка после фиксации — выбор официального gold_snippet_index. Дополнительно сообщаем сходство строк, F1 идентификаторов, итог без памяти и со статическим адресом, сколько раз меняется чтение, суммарную стоимость применения каждой политики с учётом черновика. Уровень C — исследовательский, отдельная семья от двух заранее записанных сравнений A/B. Никакой настройки по результатам C. Одна промежуточная попытка и один ответ ограничивают интерпретацию коротким циклом чтения для автодополнения.
