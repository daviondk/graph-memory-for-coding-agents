До открытия исходов переноса добавили третий способ формирования очередей: отдельные блоки в Easy и Hard при той же средней квоте 3 внутри каждого из уровней. Для этой диагностической постановки метка уровня разрешена только планировщику очереди. Правило выдачи метку не видит. Точные размеры пула могут различаться внутри уровня.
