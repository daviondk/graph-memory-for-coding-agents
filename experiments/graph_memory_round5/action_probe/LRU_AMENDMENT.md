До появления индивидуальных исходов при 4 КиБ добавляем в тот же проход два контроля по актуальности: LRU с новым правильным адресом и LRU при редакторском входе. Они используют ту же вместимость, прежний cal_neighbor заменён на существующую конфигурацию dict_lru, версионирование строк, поток событий и JSON/Zstandard-15 одинаковы. Хеш предыдущего определения ограниченного прогона сохраняется. Первоначальный запуск на Windows не смог импортировать локальный модуль в дочернем процессе из-за нескольких модулей по имени acquire; исправлен путь импорта без смены правил наблюдения.
