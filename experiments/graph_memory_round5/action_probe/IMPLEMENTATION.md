Посимвольно сохраняются только совпавшие строки двух полей ответа. Для оракула дополнительные распознанные префиксы адреса вида path:line: или число + tab снимаются отдельно от исходных строк; содержимое аргументов минувших правок (`old_str` и `new_str`) считается отдельной диагностикой, без присваивания им адресов. Если после учёта всех наблюдений различить источник нельзя, сообщаем именно отсутствие полного блока в наблюдавшихся каналах. Вторая метрика для адресных политик вычисляет, сколько действительно новых адресов успешно проверились на следующем доступном view. Сохраняем хеши строк и идентификаторы событий. Простой сканер поиска принимает как разделитель совпадения, так и прочие строки только при явном корректном пути и номере. Произвольному фрагменту терминального вывода не присваивается адрес.
