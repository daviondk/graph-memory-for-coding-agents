# Дополнительная проверка после первичного сравнения
Основной результат при 4096 байтах уже известен. Сохраняем выбор Zstandard-15 и все три метода. Один новый бюджет 1024 байта, те же шаги и 253 эпизода, без перебора порогов. На этой повторно используемой панели границы являются описательными. Отдельно разделяем промахи при 4096 байтах на состояние с неограниченной ёмкостью того же алгоритма непосредственно после среза и непосредственно перед следующей правкой. Последняя величина использует промежуточные наблюдения и служит диагностикой доступности. Фиксируем протокол до подсчёта обеих величин.
