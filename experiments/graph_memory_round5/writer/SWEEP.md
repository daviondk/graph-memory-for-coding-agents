# Исследовательский профиль ёмкости
Профиль 512, 1024, 2048, 4096 и 8192 байта, три прежних метода. Протокол расширен после уже открытого результата 4096. До открытия результата уже запечатанных предсказаний 1024 и до расчёта остальных трёх бюджетов. На всех бюджетах повторяется один набор задач и меток. Сетка целиком публикуется, исходная проверка превосходства по-прежнему относится только к 4096. Второй запуск при 1024 и 4096 проверяет идентичность последовательности предсказаний. Собираем задержку каждого обновления perf_counter_ns на общей машине при трёх рабочих процессах, среднее, медиану и p95. Отдельно показываем средний фактический размер, средний размер при одинаковом состоянии, число изменившихся исходов и парный интервал. Для подтверждения найденного режима потребуется новая панель.
