# Как меняется ответ при замене фрагмента
> Лучшее описательное значение на основной панели дали четыре коротких окна кода — 19 правильных строк из 128. Этот опыт не установил устойчивого преимущества какого-либо представления.
@ 6 2.5 2.5 3
| Внешний контекст | Точно из 128 | Сходство строк | F1 имён, % |
| Без внешнего кода | 13 | 51,1 | 36,6 |
| Начало первого объявления | 16 | 54,4 | 40,9 |
| Подходящее окно первого объявления | 14 | 53,8 | 39,7 |
| Окно и пример использования | 16 | 54,8 | 41,3 |
| Начала четырёх объявлений | 16 | 52,8 | 38,2 |
| Подходящие окна тех же четырёх | 19 | 54,4 | 40,3 |
Заранее выбранное сравнение примера использования с окном внутри объявления дало два выигрыша и ноль потерь на A. Разность +1,56 п.п., 95% парный интервал от 0 до +3,91. В независимой панели B каждый из трёх методов дал восемь точных ответов из 64. Ни разу точность отдельной задачи не поменялась. Двусторонние p после поправки Холма на два сравнения равны 1,00.
У четырёх подходящих окон против начал тех же объявлений было пять выигрышей и две потери. Доверительный интервал разности от −1,56 до +6,25 п.п. соответствует вторичному сравнению. Одинаковый предел в 256 токенов допускает разную фактическую длину показанного материала. В архиве для каждого ответа сохранены входные и выходные токены.
