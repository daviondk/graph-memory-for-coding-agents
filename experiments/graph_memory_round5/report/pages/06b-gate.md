# Помогает ли место вызова точнее написать строку

> По синтаксису Java удалось найти больше прямых использований выбранного типа. Проверка на 192 проектах дала один дополнительный точный ответ и одну потерю относительно исходного выбора строки.

Для каждого графового адреса искали вызов метода с именем типа в позиции получателя или создание экземпляра этого типа. Если исходная строка уже подходила, сохраняли её. Если подходящей строки не было, показывали локальное окно. Из 192 предъявлений 171 совпало с ранее отправленным запросом, 21 потребовало нового ответа Qwen.

@ 7 3 3
| Как показали найденный код | A, точных из 128 | B, точных из 64 |
| Локальное окно объявления | 14 | 8 |
| Исходное текстовое ребро | 16 | 8 |
| Пропуск синтаксически неподтверждённого ребра | 15 | 8 |
| Поиск подтверждённого места в других строках | 16 | 8 |

В A последняя политика против локального окна дала два выигрыша и ноль потерь, p = 0,50. Относительно исходного ребра один ответ улучшился и один ухудшился. В новом удачном случае подсказка содержала обращение к другому полю класса Items, а модель правильно вернула Items.snowball. В потерянном случае исходный фрагмент уже содержал правильную строку целиком. В B все четыре политики решили одни и те же восемь задач.

Доступность прямого использования возросла с 21 до 32 задач в A и с 11 до 21 в B. Измерения генерации пока не подтверждают стабильного выигрыша от замены строки.
