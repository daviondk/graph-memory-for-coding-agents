# Помогает ли передача нейронного сигнала соседям?

> На 224 новых Java-запросах из 81 проекта передача сигнала между объявлениями изменила 13 исходов на первом месте. Шесть улучшились, семь ухудшились.

Мы использовали настоящий энкодер microsoft/unixcoder-base, замороженный в режиме FP32 на CPU. Он оценивает сходство кода запроса с каждым объявлением. Если один фрагмент обращается к другому, экспериментальная модель передаёт соседу часть этого свидетельства. Прямая смесь получает те же исходные оценки и структурные признаки. Дополнительные коэффициенты обучены по 320 примерам из другого издания RepoBench. В основной проверке запрос состоит из трёх строк кода.

@ 6.3 2.6 2.6 2.6
| Метод | Top-1 из 224 | Top-3 | Top-5 |
| Только UniXcoder | 46 | 102 | 132 |
| Только исходный граф | 42 | 103 | 142 |
| Прямая обученная смесь | 43 | 101 | 144 |
| Смесь с передачей соседям | 42 | 100 | 146 |
| Перемешанные сообщения | 38 | 103 | 145 |

Разница между передачей и прямой смесью на первом месте составила −0,45 п.п. Парный 95% интервал по проектам от −3,27 до +2,13 п.п. На десяти строках результаты составили 35 против 39. Точность этой выборки допускает как умеренный выигрыш, так и ухудшение. На двух длинах окна преимущества передачи текущим способом подтвердить не удалось.
