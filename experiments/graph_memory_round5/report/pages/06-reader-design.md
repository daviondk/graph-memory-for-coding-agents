# Как граф передаёт сведения генератору
> Верное объявление в выдаче может занять сотни строк. При коротком контексте нужен выбор между сигнатурой, телом и примером того, как объявление использовали в другом файле.
На панели A у каждого из 128 Java-проектов взяли одну задачу. Шесть условий получили одинаковые последние 30 строк текущего файла в пределах 1024 токенов. Для внешней памяти выделили до 256 токенов. Сравнили отсутствие памяти, начало первого объявления, подходящее к запросу окно в нём, добавление примера использования его типа и две формы выдачи четырёх фрагментов. Графовый порядок во всех вариантах был фиксирован.
На 79 задачах A вариант с примером использования дал другой промпт, чем локальное окно. Вторую панель B из 64 новых проектов специально составили из таких случаев. В ней можно изучить воздействие подмены контекста, однако частота найденных связей задана отбором.
До открытия эталонов независимый анализатор синтаксиса Java проверил места использования. Прямой вызов с явным типом получателя или создание объекта найдено в 21 из 79 случаев A и в 11 из 64 случаев B. Простое упоминание в типе или объявлении встречалось в 32 и 31 случаях соответственно. Поэтому тождество имени в двух файлах часто даёт слабое основание для выдачи примера вызова. Это наблюдение проверяется дальше через связь с ответами модели.
