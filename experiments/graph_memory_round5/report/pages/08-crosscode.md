# Что изменилось на полном тесте CrossCodeEval
> На всех 2 139 задачах Java из 239 проектов перестановка фрагментов по графовой связи дала один новый правильный ответ и испортила четыре ранее правильных ответа.
Взяли опубликованную авторами обычную выдачу UniXcoder, без доступа к ответу или коду после курсора. Граф поднимал файл назначения, когда предшествующий контекст обращения к его типу в другом фрагменте был похож на текущий код. В обеих ветвях сохранили список кандидатов, сериализацию, 512 токенов внешнего кода и генератор. У 2 047 задач получился один и тот же вход. Общий декодер даёт для них нулевую парную разность.
