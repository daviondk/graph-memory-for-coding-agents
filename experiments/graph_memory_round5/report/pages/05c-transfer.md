# Адресная запись помогла на новых задачах

> При общем лимите памяти 4 КиБ агент мог восстановить весь исходный блок для 121 из 206 будущих правок. Раньше это удавалось в 73 случаях. Прирост составил 23,30 процентного пункта.

Взяли 98 новых задач SWE-bench Verified из пяти проектов. Ни одна задача ранее не оценивалась на двух панелях Kimi. Повторили тот же алгоритм без настройки. В ходе работы он сохраняет строку из уже показанного терминального вывода, путь к файлу и номер строки. Если редактор меняет файл, память обновляет адреса.

@ 4 3 3
| Источник наблюдений | 4 КиБ | Без вытеснения |
| Только редактор | 73 / 206 | 73 / 206 |
| Редактор и точный адрес | 121 / 206 | 122 / 206 |
| Сдвиг адреса на строку | 72 / 206 | 72 / 206 |

Все 48 изменившихся исходов улучшились. Парный 95%-й интервал по задачам составил от +17,45 до +29,70 п. п. При простом вытеснении по давности адресная запись восстановила 119 блоков. Её разница с более сложным правилом составила всего две правки. На этой выборке основную пользу принесло сохранение самого наблюдения по правильному адресу. Влияние на число исправленных задач ещё предстоит проверить.
