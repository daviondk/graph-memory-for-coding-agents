# Перенос на CrossCodeEval Java
До любых ответов и до чтения groundtruth. Публичный архив CrossCodeEval коммита 40c68d2b7ca2a8eae95d901ac80e6a540a84a53d, файл java/line_completion_rg1_unixcoder_cosine_sim.jsonl, обычный retrieval без oracle. Оставляем по одному заданию на каждый из первых 96 различных проектов по заранее фиксированному SHA256(task_id), после фильтра видимых входов и известных пересечений с проектами обучения графа, предыдущей/текущей генерации RepoBench. Сопоставление имён репозитория с дампом GitHub приблизительное, фиксируем алгоритм. Внешние фрагменты (до 5) и их исходный порядок даны авторами; суффикс и целевая строка недоступны для выбора метода. Проверяется передача опубликованной панели кандидатов, без новой индексации. Локальный Qwen3.8-27B Q4_K_M, greedy, единый простой chat-промпт на один Java statement, до 1536 токенов префикса, 512 внешних, 50 выходных. Комментарии CrossCodeEval и представление пути поддерживаем единообразно.
Условия: empty без внешнего текста, official — начало готового авторами текстового контекста UniXcoder, order — те же фрагменты и файлы в том же порядке, построенные единым шаблоном из списка, bridge — тот же шаблон, где приоритет получит фрагмент файла назначения, если в другом фрагменте встречается его класс. Вес ребра растёт, когда наблюдённые перед использованием строки похожи на последние десять строк текущего кода и когда в префиксе виден тип файла-источника. Требуем сходство ≥0.40 по частям имён и минимум два общих элемента, игнорируем комментарии и импорты; иначе сохраняем исходный порядок. Нулевая стоимость создания внешнего индекса на стороне нашей надстройки, но исходная панель авторов потребовала поиска. Основное сравнение — bridge против order, EM, парный двусторонний Мак-Немар и 95% bootstrap по проектам. Вторичные — официальный ES, ID exact и ID F1, число смен порядка и фактически различающихся запросов, токены и empty. Функции авторов для Java и список ключевых слов фиксируем исходным коммитом. Это парный тест с той же панелью и обработкой ответов, на ограниченной выборке и с другим генератором. Сравнение общих чисел с таблицей публикации требует совпадения режимов и полного теста.
