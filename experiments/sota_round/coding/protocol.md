# SWE-Explore coding-context pilot

Frozen on 16 November 2026 before viewing instance-specific answers, repository snapshots, or scores. Benchmark documentation, schema, aggregate collection size, source method, and repository frequencies have been inspected. The README illustrates a goodconf task outside this sample.

Use the 451 SWE-Explore records tagged verified. For each repository sort its instance IDs by SHA-256 of UTF-8 text `swe-localization-v1|` followed by the raw instance ID and take its first two, or all if fewer. This yields 23 tasks from 12 repositories. Join issue descriptions and base commits from the original SWE-bench Verified release. Use no patches, tests, hints, gold regions, or successful target trajectories during prediction. Retain every selected ID and log download or evaluation failures. No replacement or score-based exclusions.

Compare the official default BM25 explorer with a fixed source-only retriever. For each issue the latter receives the same source chunks and issue text. Combine rankings by reciprocal rank fusion with offset 60. Use one vote from the original upstream BM25, two equal votes from a BM25 index of case-normalized, punctuation-split and CamelCase/underscore-split code and issue identifiers, and one vote from a BM25 index of filenames and directory terms. Only give that final vote to paths sharing a token with the query. Return the highest scoring five chunks with chunk order as tiebreaker. Both arms use the identical upstream chunk inventory, its window size 80, overlap 20 and nominal cap 3,000. Evidence budget five ranked regions with at most 400 raw lines. Use all unfiltered text the upstream scans, without estimates from solution metadata. No LLM calls or tuning. This measures code context localization, an explicit pre-edit stage of a coding agent, without making a patch or training on historical trajectories.

Primary outcome is mean official line F1 averaged over selected issues. Also report mean precision, recall, file-hit rate, region-hit rate, noise-file rate, recall@300, per-task wins/ties/losses and paired 95% bootstrap intervals for F1 by resampling entire repositories (seed 20261116, 10,000 draws). Report absolute values and paired difference. Single run on one OS and a non-population-weighted subset limits comparison with published full-suite figures. Any changed rule or later experiments must stay separate from this record.
