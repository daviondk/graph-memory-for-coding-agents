# Additional comparator and line-budget controls

This protocol was added after observing the primary paired BM25 result. Preserve all 23 locked tasks, existing predictions and primary metric. Use both the benchmark authors' TF-IDF and Potion-8M defaults and their five-region budget. Score the unchanged candidate against both with exact issue pairing. Verify that each control index sees the same ordered chunk content as the original prediction. Also compute each pair's primary F1 after truncating both ordered outputs to the smaller of their two emitted raw line counts on that issue. Count repeated lines each time they appear in the emitted stream and cut the final region as needed. Reuse the repository bootstrap specified in the primary protocol. This is a descriptive sensitivity analysis and these controls were added after the original two-arm result was known.
