## Качество измерения

Перед оцениванием прошли все 34 эталонных решения с решающим фактом. Ожидаемо провалились все 34 наивных решения и все 34 неизменённых дерева. Проверка изоляции подтвердила, что программе выдаются только рабочее дерево, её исходник и системная среда Linux, а наружу нет сетевого маршрута.

Количество срабатываний лимита в 1 280 токенов по условиям «карточка / фрагменты / без памяти» — 1 / 0 / 0. Ошибок инфраструктуры проверяющего модуля — 0. В знаменателе сохранены все 102 назначения, включая неисполняемый ответ. Для программы, завершившейся с ошибкой, проверялось фактически оставленное дерево файлов.

Один детерминированный прогон покрывает 34 авторские задачи и один способ обращения к модели. Реальные задержки генерации получены для пакетов из шести контекстов. Влияние вида памяти на общую задержку из этих пакетов выделить нельзя. Результаты не переносились на официальный рейтинг продуктов или другие модели.

Вариант с Python был зафиксирован после обнаружения, что в первой серии некоторые ответы дословно копировали пример значения JSON. Все 102 назначения повторены с одинаковыми задачами, моделью и расположением в пакете. Причинная интерпретация межсерийной разницы охватывает изменение текста инструкции вместе с формой вывода.
