# Locked hypothesis and analysis plan — boundary reranking, LongMemEval-S
Design fixed on 2026-11-16, before inspecting any per-item labels, scores of candidates, or disagreements. Public aggregate parent performance, its top-20 ceiling and distribution of released grades were known. This is a prospective fixed-policy study on a public test set, with no independent novel holdout. Author rankings and benchmark data are reused, not regenerated.

Population: rank all 500 questions; official full-session all-evidence endpoint on 470 non-abstention questions. Preserve five slots, including any source duplicates. Join IDs by opaque equality; use first occurrence of duplicate IDs for text, like dict.setdefault, and score with the original identifier. Model sees only the question, dates and session role/content. Scoring identifiers and turn annotations excluded by explicit projection. No training or thresholds learned from these labels. Upstream is a fixed public artifact; its training and historical run costs cannot be audited here.

For each of 20 candidates, split role-tagged text into 96-word windows, stride 80, retain two most lexical-relevant windows using within-pool window document frequency. Score question-window pairs with pinned pretrained ms-marco MiniLM cross encoder; use maximum window logit, first window tie break. Eligible incumbents are top five with released grade below 4. Select lowest scoring eligible incumbent, breaking ties by the latest rank. Select best outside (ranks 6–20), breaking ties by initial rank. Propose one replacement if outsider logit >=1.0 and margin >=2.0. Never change if the two text-mapped candidates have the same source or outsider already present. Retain other slots. No parameter sweep.

Primary: verify proposed swap with one isolated Codex call, random-seeming A/B order by SHA-256 of visible question, show two windows per side. Swap only when the judge calls challenger uniquely useful and supplies an exact contiguous quote of at least 12 characters inside a challenger excerpt (case/whitespace folded). Both/neither/invalid/timeout -> original. At most 64 queries (smallest SHA-256 among eligible questions). Secondary: direct swap across entire eligible set; direct swap in verifier subset; flat CE sort; tie-sort by lexical grade then CE; unchanged parent. Paired exact two-sided McNemar test for primary; report net percentage points, discordants, question-pair bootstrap 95% CI conditional on this benchmark. Secondary effects descriptive. Record all 500 outputs, denominators, GPU wall time, requested/actual calls and tokens, output k, failures, cap, exposure to evidence. No claim about QA, equivalent inference budgets, independence of underlying sessions or superiority on another benchmark.
