# Secondary matched reader comparisons
Registered after learning the primary aggregate of 75/99 and before this follow-up generated predictions. Individual item labels, targets of errors and relational rows were not used to design the follow-up. Both comparisons are exploratory; the same 99 tasks were already evaluated. No hyperparameter search.

A. Keep the original 5 fusion candidates, display order, issue, system prompt, fields and word limits. Replace only the explicit edits field in each candidate with the empty string. The symptom and closure may still mention paths or edits. Choice quality therefore measures the incremental contribution of expressly showing those edit records to the reader. The original shortlist still used all fields. The intervention varies prompt length as well as content.
B. Replace the five candidates with the first five of the blind original-author Recall hybrid output. Reuse the complete original card schema, ordering function, reader, issue queries and caps. A fallback uses this arm’s first unreordered item. The shortlist may differ in order and membership, and the original author search received unmasked full issue text. The comparison measures the combination of candidate generation and coverage under a shared reader. Compare top-5 ceilings, raw top-1, edited choices, qualified successes and reader cost.

Run both arms for every ordinal, serially. For each ordinal, the order of arms is determined by SHA-256(arm|ordinal). Qwen3.8-27B UD-Q4_K_M, seed 20261116, temperature 0, nonthinking, max 12 output tokens; same pinned endpoint as primary. A completed response is never resampled. Retry transient transport failures, retaining their logs. Verify every original prompt by reconstructing its hash from saved blind files; lock all 198 planned prompt hashes and candidate orders before running. Use the exact successful native request usage and finish reason for each attempt. Do not preview individual outcomes before the complete prediction hash is saved.

Endpoint: official Lite Match@1 for all 99 related questions. Method-minus-control differences are computed on paired tasks, reported as number of changed predictions, fixes and reversals, 95% repository-cluster percentile interval based on 10,000 draws, exact two-sided McNemar test plus Holm adjustment across the two comparisons against the frozen primary. Also report native candidate top5 coverage, top1, full reader token counts, fallback count, shared candidate count and identical five-member sets. No pooled inference across these arms or claim of patch-solving ability. An inconclusive difference remains inconclusive. All run artifacts stored on D.
