# Reproducing the SWE-ContextBench retrieval experiment

This track measures exact experience selection. Historical data and question releases are pinned in source.json. Run the scripts in this order. The source download is about 131 MB. We used Python, requests, pyarrow, numpy, PyTorch 2.6 and Transformers. Set SWE_CONTEXT_DATA, CONTRIEVER_PATH, MINILM_PATH, SWE_CONTEXT_L12 and SWE_CONTEXT_ENDPOINT to relocate the caches and service. See ../vibe_qwen38/README.md for the exact GGUF worker. Model weights are referenced by revision or hash, not redistributed.

1. Run fetch.py, then cards.py using a Python with requests and pyarrow. Only the problem_statement column becomes question input. Target IDs are used to deduplicate the secondary split. Nothing in these programs reads target patches or relationship rows. The raw public trace 0c18eb7c includes one malformed 95-character JSONL line. The reader skips the line and retains the trajectory. The snapshot has 300 complete three-field cards.
2. Run rank.py with PyTorch, numpy and transformers. The sparse encoding adds code-identifier parts and the dense encoding uses facebook/contriever. The pinned local cross-encoder cache MINILM_PATH is **the six-layer release**, despite its config file retaining a twelve-layer _name_or_path. The before-score check found this mismatch. To include the prospectively declared twelve-layer secondary control, run cross_encoder.py next. It obtains the pinned actual 12-layer encoder and preserves the first run in the additional field minilm6. The automatic mixed ranks used by the primary reranker do not change. Neither auditor had accessed the relation labels.
3. Run choose.py once the 27B service is free. It appends each valid transport result exactly once, captures prompt hash, candidate order, response, elapsed time, finish reason, tokens and timestamp, and writes blind_commit.json only after all 99 cases. Requests use only the public issue and sanitized historical fields. No graders, past-run repository ID filter or tools are exposed to the reranker. The exact first-stage list and all seven controls including the 12-layer encoder are present in blind_ranks.json. The byte hash in rank_run.json is the initial six-layer output. The final hash after the secondary-control correction is in cross_encoder_run.json.
4. Run score.py with pyarrow after all prediction hashes are locked. It joins historical trajectory keys to public issue IDs in the first user message and scores the public relation table. A successful Match@1 requires that the selected issue is an officially associated experience. For multiple relations the benchmark's valid related IDs are treated as a set. Every canonical Lite query contributes to the denominator, including when the related experience is absent from the 300 documents. The primary data contain no self/identity overlap between source and target; a single source ID overlaps with one of the 357 unique targets in the broader auxiliary set.
5. For recomputation without model weights, use the released rankings, Qwen calls and results. SHA-256 and individual labels are checked by the outer verify.py. The external-paper reference follows Appendix D of REM. The maximum possible first-rank result under a five-candidate reranker is the first-stage Recall@5. Identical five-candidate recall for all rerankers follows by construction.

The additional 258 cases are only a diagnostic expansion of the Related split, using the fixed Lite pool as the search space. Explicit links and issue numbers are masked for the new method. Method differences include the extractor, masking, retrieval models, available corpus size and the treatment of missing records. The primary unit for comparison with the paper is the aggregate of the 99 canonical Lite questions, independent of the additional 258 cases. The 95% confidence intervals resample whole repositories with replacement using a fixed random seed. Two-sided exact paired P values describe comparisons on matching cases, without multiplicity correction. A comparison against a published percentage alone cannot provide a paired test.
