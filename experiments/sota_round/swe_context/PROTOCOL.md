# SWE-ContextBench Lite / prospective retrieval experiment
Frozen 2026-11-16 before relationship labels are opened. Source pins in source.json. Endpoint is Match@1, exact labelled prior trajectory among 300 public raw traces for all 99 Lite tasks. Missing targets are failures. Candidate eligibility and public source contents were inspected, without relationship rows or evaluation outcomes.

Write a three-field record at completion of a previous issue: the user's symptom (up to 210 words), the last public assistant answer (up to 135), and the actually issued write/edit paths plus code identifiers (up to 85 words). Source is only the earlier public interaction. No top-level summary, hidden reasoning, target metadata or gold patch, supplied repository name, explicit issue identifiers or URLs. Extract literal paths only from structured Edit/MultiEdit/Write events. These are attempted edits, not certified fixes. No full-repository index. Use opaque trace keys only for stable ties and scoring. Query is only the new problem statement, similarly masked. No repository filter. Store fixed caps on all conditions. Max 280 words of query (first 220 and last 60).
Controls: single BM25 over concatenated record, symptom only BM25, single dense Contriever (mean, masked, normalized) on the concatenated record, and first-stage reciprocal-rank fusion. Additional ablations: prior closure/actions only BM25 and independent field sparse fusion. First-stage retrieval fuses BM25(field symptom weight 2, resolution 1, edits 1), and Contriever on symptom and resolution (2 and 1), RRF constant 12. Two rerankers choose among exactly these first five: fixed cross-encoder MS MARCO MiniLM-L12 on the first five (secondary), or local nonthinking Qwen3.8-27B UD-Q4_K_M at greedy temperature, one call each, index only (primary). Qwen sees five records in hash-defined order, up to 175 words symptom, 90 closure, 40 edit tokens. Keep first-stage top1 if response invalid. Remainder retains initial ranking. Log position, output, tokens, timestamps; infrastructure errors are retried, no reroll of valid responses. Cost includes storage bytes, CPU model time, model tokens.
