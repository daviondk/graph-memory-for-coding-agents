# Cross-harness validation of a read-cache policy

Pre-score sampling frame: 300 public Claude Code past-experience JSONL traces from SWE-ContextBench Lite, GitHub jiayuanz3/SWEContextBench pinned commit 12ad6ab14e18e9378e1e293c9edbc3f7ce43d27b. Verify SHA-256 against the original trace-only manifest. Do not open target questions, relation parquet, current PR metadata, patch labels or final reward. Only structured tools, message IDs/order, turn-local cwd, and actual returned payloads are replayed; no shell/model calls, no repository index. Reset state between traces and at branch/session discontinuities; sidechains out of scope. Treat a split model message with one assistant response ID as one simultaneous tool batch. Group adjacent declarations of the same issued response, attach only later matching IDs before the next distinct assistant response, suppress serving/filling in mixed writer/unknown batches. Control state never uses actual output from a simulated hit.

Admit structured Read(file_path, optional offset and limit) with resolvable path and no extra argument. Canonicalize dot and relative paths against that action's logged cwd, including trace-scrubbed workspace roots such as ./swebench_9_15; preserve offset/limit including absence. Scope never crosses histories. Cache successful, string-valued visible tool_result content only (UTF-8 <=16,384 B), including any reminders and exact whitespace. Prior errors, multimodal results and unknown responses cannot fill. Predict before inspecting the new response. On return score exact observed success plus byte-for-byte entire visible content. A later tool error counts as stale; missing/nontext result on a served prediction is unscorable. No normalized tool output and no hidden reminder synthesis. Record conditional counts for successful observed text and all eligible requests separately.

Policies: bounded unguarded exact LRU, TTL one/three/ten assistant decisions, flush all on every possible file mutation, invalidate overlapping concrete paths on Write/Edit/MultiEdit, and latter plus confirmed Edit write-through. All bounded 32 records and 262,144 bytes including stored key, visible text and optional full-file reconstruction metadata; identical admission and metadata payload for controls. Bash is opaque and clears both safety policies. Unknown, unresolved edits and non-file tools with unclear side effects also clear both. TodoWrite/Grep/Glob/Read are exempt from mutation. Known Write/Edit/MultiEdit invalidate even on failed write attempts. Write-through only for an isolated Edit, confirmed success from the associated tool_result, against a previously complete default Read in this cache. Require file.startLine=1, numLines=totalLines, and source text that recreates the visible numbered lines exactly. Preserve only exact already-observed trailing wrapper bytes (empty or a single literal system-reminder block), never invent a hidden warning. With a unique literal old_string (or explicit replace_all), splice new_string and renumber. Invalidate on ambiguity or over-budget result, never ingest the edited file from auxiliary edit metadata, never derive a whole file from a partial read. Evict other ranges. No Write or MultiEdit synthesis. Preserve chronological snapshots and record refused edits and predictions derived by write-through.

Primary cross-harness comparison: selective vs whole-cache flush at the original fixed budget, strict correct and stale per 1,000 eligible Reads. Prespecified extension: write-through vs selective, including number of edit-updated entries and actual later serves, conditional exact/stale/unscorable and path-free examples if sparse. No claim of task success, live agent acceleration or safety from a zero observed count. Report repo-proxy cluster and trajectory-paired (all 300) percentile bootstrap 95% intervals, 10,000 repeats seed 20261116. Infer repository proxy for analysis only from the first unambiguous GitHub git clone command in the historical trace; all unknowns share an unresolved cluster. Provide all query and batch rows, all hypotheses and results, footprint and run time. No follow-up tuning or further experiments planned.
