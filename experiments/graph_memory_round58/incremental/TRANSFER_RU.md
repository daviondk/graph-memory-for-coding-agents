# Проверка переноса буфера из 16 кандидатов

После наблюдения исходных панелей фиксируем вторичную репликацию наиболее содержательного различия. На 12 других проектах возьмём полностью сохранённые первые родительские истории из каталогов replication и seed_pair предыдущей серии. Эти данные раньше использовались для иных вопросов про поиск следующего файла, но они не использовались для выбора исхода этого сравнения. Обрабатываем все проекты и обе группы по шесть без исключений. Применим исходное плотное расписание B после 64 переходов и редкое расписание long со второй половины каждого проекта (хеш modulo 11). Оба расписания задаются до построения результатов.

Основное вторичное сравнение — 1 КиБ, буфер 16 с границей против полной таблицы счётчиков. Покажем также буфер 8, сброс и пересчёт, вариант 4 КиБ, обе панели отдельно, все индивидуальные объёмы. Проверяется точная выдача. Уменьшение общего числа байтов по проектам может определяться несколькими крупными репозиториями. Сообщаем число выигрышей, равенств и проигрышей по проектам. Исходные 196 запросов и эти проекты принадлежат разным репозиториям; разреженное подмножество и плотное могут пересекаться внутри новой панели.
