# English demonstration walkthrough

[Play the 1 min 50.84 s video](walkthrough.mp4) · [Captions](captions.srt) · [Open the checkpoint and editor replay](../demo/index.html) · [Working paper](../manuscript/paper.pdf)

The recording follows a shared NetworkX change, opens its evidence, switches between cold, recent, demand and full checkpoints, and reveals a short-history case where padding increases cost. It then visits the recorded editor-window results and queries the Dask and synthetic two-file examples in SQLite. Every displayed measurement comes from the checked-in application; the two-file views were captured from the live loopback reader. The checkpoint viewer shows physically measured **fixed-size** frames. The natural-size sensitivity is reported separately. [Natural-size measurements](../restart_transfer/REPORT_RU.md)

The 2,546,335-byte MP4 contains ten captured interactions, English system narration, H.264 video and AAC audio. All frames were decoded and a stable image and speech sample from each scene were checked against the original capture. `python -B record_demo.py` rebuilds the video with Windows system speech, Chromium for Playwright, Pillow, NumPy and FFmpeg.
