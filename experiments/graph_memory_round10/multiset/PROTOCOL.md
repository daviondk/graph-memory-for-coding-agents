# Multi-set memory at a fixed serialized byte price

Exploratory follow-up on the 10 compatible and 8 held-out-in-R9 SymPy issues already analyzed in R9; both directions for each issue. The latter eight are not a fresh holdout for this experiment. Each old test set is its R9 observed symbols union the recorded shared symbols. The scoring population is the original R9 outcome rows, including exact nonintersections and changes of actual test outcomes. Snapshot contents are fit independently for each old direction. No change query or graded outcome may enter state construction. Lock and save every final payload before future queries are evaluated. A fresh Python evaluation process decodes bytes with no old sets, builders or retained dictionaries; actual outcomes and reference intersections are used only by a separate grading pass.

Fixed envelopes are exactly 64 or 256 × test-count bytes for every tested method, with zero padding counted. Payload header identifies representation, number of test positions and salt. For old-R9 comparisons reserve that header inside the budget, and separately replay native R9 with the original public external salt convention as a reference. Roster positions are the labels of the problem, common to every arm and known by the caller. Bytes suffice to return a bitmask over positions without access to the roster strings or old arrays. Publish the encoded cost of the shared position-to-test-name roster separately. The 32 predetermined salts are paired engineering sensitivity replicates, not 32 independent datasets.

Comparators: (1) R9 original learned-on-old choice between adaptive separate Bloom and factored-common Bloom; (2) one hash bucket containing the bitwise OR of all old test masks colliding in it; (3) Flat-Bloofi-style bit-sliced matrix, with 1–8 hashes chosen from old set cardinalities by its expected false positive rate. Reimplementation of the published transposed Bloom membership semantics at bit granularity, without Java's fixed 64-filter block overhead; (4) one-hash OR buckets with an explicitly serialized dictionary of distinct bucket masks and compressed codes; choose the fitting configuration with lowest predicted absent-key mask density among fixed bucket counts; flat OR is its fallback. (5) Static valued Bloomier/XOR variant: peel three-address hypergraph over unique observed keys, assign XOR registers for class values masked by a key-dependent fingerprint. Pay for class-to-mask mapping, construction retry salt and bit-packed table. Store the most frequent old mask classes and the full mask; if space prevents an exact class, return its smallest stored superset. Keys absent at write time mapping out of dictionary return zero. Select dictionary size/register width using equal prior mass for absent/present keys and expected fraction of needless positive test bits; no future frequency. Use the ordinary OR representation if a graph cannot peel in eight deterministic attempts or the minimum registers do not fit. Also retain an explicit selector picking by the same old-only objective between XOR and compressed OR. No false negative relative to the old graph is allowed, and missing changed test outcomes may still occur due to incomplete observed dependencies.

Primary endpoint extra test reruns versus exact symbol-set intersection at 256 bytes/test, separately on each panel and pooled. Primary comparison XOR versus R9; strong baselines flat and compressed OR; 64 bytes is the stress regime. Report false negatives against exact and unselected real outcome changes; count both. Unit of inference is issue, both directions combined, normalize extras to scored decisions for a macro issue effect and retain total extras averaged over salts. Paired stratified issue bootstrap 10,000 draws (fixed seed 10097) and exact sign test on salt-averaged issue effects; salt range/SD is separate. Log build CPU by method, reconstruction included, and end-to-end per-query CPU including decoding; managed Python/NumPy implementation timing is machine-specific. Save actual and padded bytes, parameters/fallback, digests, raw predictions, per-issue scores. Treat the cost of fitting compressed states and peeling retry as a part of writing. No superiority claim beyond this finite workload.
