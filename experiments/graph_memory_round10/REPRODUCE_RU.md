# Воспроизведение и проверка десятой серии

Сохранены фазы подготовки входов и прогнозов, протоколы, решения всех методов, хеши, поштучные исходы, отрицательные результаты, сеансы GPU и журналы исполнения. Источники располагаются в общем дереве x20-bench-workspace/work на диске D. Для вычислительного повтора нужны указанные снимки прежних серий, данные библиотек, среда Python и, для генерации ответов, веса Qwen. Для проверки сохранённых итоговых таблиц веса не нужны.

| Опыт | Точка входа и зависимости | Как проверить |
|---|---|---|
| Отрицательные зависимости | [протокол](absence/PROTOCOL_RU.md), [версии и SHA архивов](absence/sources.lock.json), [скрипт загрузки](absence/fetch.py), отдельные запуски в изолированных окружениях | [пооперационные исходы](absence/rows.json), [повтор без перехватов](absence/uninstrumented_replay.json), [проверка](absence/verification.json). Крупные исходные архивы и установленные пакеты восстанавливаются по lock. |
| Компактные словари | [порядок запуска, версии и коды семян](multiset/REPRODUCE_RU.md) | [манифест](multiset/MANIFEST_SHA256.json), [проверка](multiset/verification.json). В архив включены сжатые бинарные состояния и чтения. |
| Возвращение данных из MemTrace | [команды и commit нативного модуля](provenance/README_RU.md), [зафиксированные планы](provenance/plan-lock.json) | [чтение](provenance/native_reads.py), [квитанция проверок](provenance/verification.json), [снимки SQLite](provenance/native/) и [журналы pytest](provenance/confirmations/). |
| Выбор теста Qwen | В исходном дереве из testagent выполнить python audit.py. Генерирующий скрипт использует клиент R8, свежие испытания используют снимки R7/R8 и привязанные к версиям тесты. Число логических вызовов включает общие тела с одинаковой контрольной суммой. |

Локальный пакет строится командой `python package_local.py --output ПУТЬ_НОВОГО_ZIP` в каталоге серии. Команда `python package_local.py --verify ПУТЬ_ZIP` проверяет имена и SHA-256 каждого файла. Команда с дополнительным параметром `--export НОВЫЙ_КАТАЛОГ` извлекает уже проверенный пакет. Установленные среды, веса, полные исходные checkouts и промежуточные каталоги сборки хранятся отдельно. Контрольные суммы источников и малые журналы входят в архив.
